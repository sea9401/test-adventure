# 아카이브 — v1 시대 설계 문서

여기 있는 문서들은 **v1 시절(~2026-05)에 작성된 설계/계획 플랜**으로, v2 리워크와 운영 승격(`docs/v2-cutover-runbook.md`, 2026-06-03 컷오버)을 거치며 대부분 구현·대체·폐기되었다. 히스토리 보존을 위해 삭제하지 않고 옮겨 두었을 뿐이며, **현행 설계의 출처로 삼지 말 것** — 현재 진행 중인 시스템은 `docs/` 최상위의 `v2-*.md` 문서를 본다.

이동 기준 (2026-06-13 정리):
- 파일 작성 시점이 v1 시대(초기 일괄 임포트)이고,
- 코드(`src/**`)도 작업 메모리도 더 이상 경로로 참조하지 않는 것.

즉 옮겨도 깨지는 링크가 없는 문서만 골라 옮겼다. 참조가 남아 있거나(`items.md`, `battle-tactic-stance-plan.md` 등) 일반 성격인 문서(`changelog.md`, `features.md` 등)는 최상위에 그대로 두었다.

필요하면 언제든 다시 꺼내 쓰면 된다 (`git mv docs/archive/<파일> docs/`).
