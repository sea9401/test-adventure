# 배포 자산 권리 감사

최종 점검일: 2026-08-15

이 문서는 정적 배포 자산의 출처 증거와 출시 전 남은 확인을 기록한다. 법률 자문을 대신하지 않으며, 새 자산을 추가하거나 사용 범위를 바꾸면 다시 점검한다.

## 자동 검사 범위

- `docs/asset-rights.json`에 배포되는 이미지·벡터·글꼴·음원·영상의 경로, SHA-256, 출처 그룹을 기록한다.
- `npm run check-asset-rights`는 파일 누락, 신규 미등록 파일, 내용 변경과 출처 그룹 불일치를 차단한다.
- `npm run check-asset-rights -- --strict`는 권리 확인이 끝나지 않은 출처 그룹까지 출시 차단 사유로 처리한다.
- 사용하지 않는 create-next-app 기본 SVG 5개는 배포 표면에서 제거했다.

## 운영자 확인 기록

운영자는 2026-07-29 아래 사실이 모두 맞다고 확인했다. 이에 따라 `docs/asset-rights.json`의 모든 현재 출처를 `cleared`로 기록하고 strict 출시 게이트를 활성화했다.

> 현재 저장소의 게임 이미지 360장과 앱 아이콘·소셜 미리보기 7장은 모두 내가 직접 만들었거나, 내 계정으로 생성했거나, 이 게임에서 공개 배포할 수 있는 권리를 확보한 파일이다. 제3자 사이트에서 출처 불명으로 내려받은 이미지, 사용 범위를 확인하지 않은 구매 자산, 타인의 캐릭터·상표를 복제한 파일은 포함되어 있지 않다.

앞으로 사실과 다른 자산이 하나라도 추가되면 해당 파일을 삭제·교체하거나, 별도 출처 그룹을 만들고 저작자·원문 URL·라이선스·구매 증빙·수정 여부를 기록한 뒤 출시한다.

## 앞으로의 규칙

- AI 생성 자산은 사용 서비스·계정, 생성일, 프롬프트 또는 작업 PR을 증거로 남긴다.
- 구매·무료 배포 자산은 상품 URL, 저작자, 라이선스 버전, 구매 영수증 위치를 남긴다.
- 사람·상표·기존 캐릭터를 알아볼 수 있는 자산은 생성 도구의 이용약관과 별도로 초상권·상표권·저작권을 검토한다.
- 자산을 교체하면 `npm run update-asset-rights`로 해시를 갱신하고 PR에서 출처 증거를 함께 검토한다.
