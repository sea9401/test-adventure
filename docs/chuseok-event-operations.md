# 추석 이벤트 운영

이 문서는 운영 설정 방법이며 배포 실행 지시가 아니다.

- 이벤트 주소: `/settings/events?tab=chuseok`
- 배포 시 운영 런타임 환경변수 `CHUSEOK_EVENT_STARTS_AT`에 실제 시작 시각을 지정한다. ISO 8601 시간대를 반드시 포함한다. 형식 예: `2026-09-22T21:00:00+09:00` (예시를 그대로 사용하지 말고 확정된 시작 시각을 입력).
- 운영 환경변수는 기존 `/adventure-rpg/production/env` SSM 환경 설정에 포함하며 기존 배포 절차로 반영한다. 이번 변경만으로 설정을 쓰거나 배포하지 않는다.
- 이벤트 기간은 해당 시각부터 정확히 240시간이다. 화면은 한국 시간으로 시작/종료 시각을 표시한다. 시작 시각 미설정/형식 오류는 준비 중으로 표시한다.
- 첫 이벤트 조회 시 `chuseok_events`에 일정이 저장된다. 저장 후에는 환경변수 변경·서버 재시작·재배포로 일정이 변경되지 않는다. 최초 조회 전에 확정된 값을 설정한다.
- `0185_chuseok_event.sql`은 전역 이벤트, 사용자 출석/공격 기록, 멱등 공격 결과 테이블을 추가한다. 기존 길드 토벌전 기록은 사용하지 않는다.
- 출석은 한국 시간 날짜당 한 번, 누적 7회에 5·5·10·10·15·15·20개(총 80개)를 기존 회복약 보관함에 지급한다.
- 복주머니 공격은 한국 시간 날짜당 3회다. 첫 공격 이후 모든 처치 보상(단계당 15개)을 기존 우편으로 자동 발송한다. 한 공격이 여러 단계를 넘기면 보상 우편을 합산한다. 종료 후 추가 참여는 차단하고 발송된 우편은 유지한다.
- 참여자 전체 갱신과 우편 발송은 공유 체력 갱신과 같은 트랜잭션으로 처리한다. 네트워크 재시도는 요청 식별자로 중복 반영을 막는다.

검증용 PostgreSQL 테스트는 배포된 DB에서 실행할 수 없다. 전용 로컬 `chuseok_test` DB에 마이그레이션을 적용한 후 실행한다:

```sh
CHUSEOK_TEST_DATABASE_URL=postgresql://USER@127.0.0.1:PORT/chuseok_test npm test -- src/lib/server/chuseokEvent.integration.test.ts
```
