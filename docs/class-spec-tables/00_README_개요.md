## 핵심 설계 철학

1. **"완벽한 밸런스"보다 "정체성(소속감) 기반 다양성".** 모든 빌드가 동등할 필요 없음. "나는 이 무기·이 갈래"라는 애착이 선택을 다양화.
2. **카운터(대항)로 다양성 강제 — PvE에도 적용.** 단일 최적해를 막기 위해 공↔방, 마공↔마방, 명중↔회피, 치명↔치명저항 등 대항 축을 두고, 몬스터도 축별로 분화(D2).
3. **선택 = 트레이드오프.** 차원의 양극단은 "하나를 키우면 반대를 포기"해야 의미. 같은 방향이면 "정답 N개"로 수렴(필러).
4. **자동전투 = 전투 중 반응 불가.** 빌드를 미리 짜두면 전투가 자동 해결. → 빌드·무기·장비가 곧 전부. 잘못 맞추면 그대로 손해(설계 제약의 핵심).
5. **수치는 정체성, 밸런스는 무기 base로.** 패시브 수치는 정체성이라 안 건드림. 계파가 세면/약하면 **무기의 위력·무게(속도)** base만 조정해 잡음.
6. **단독 전투.** 파티 없음. 아군 힐·수호·버프 전부 없음. 모든 효과는 **자기 대상**.

## ★ 가장 중요한 구조 한 가지 — 차수 / 차원 모델

12계파 전부 이 골격을 공유합니다.

```
계파당 패시브 = 1차 공용 1개 + 2·3·4차 각 "차원" 1개(= 양극단 2개)

배움(learn) : 1차 1 + 2차 2 + 3차 2 + 4차 2 = 총 7개
장착(equip) : 차수당 1개 = 누적 4개
규칙        : 각 차원은 양극단 A↔B. 한쪽만 장착(동시 불가).
```

| 차수 | 배우는 것 | 장착 | 누적 장착 |
|---|---|---|---|
| 1차 | 공용 1개(단일) | 1 | 1 |
| 2차 | 차원1의 양극단 2개 | 1 (A 또는 B) | 2 |
| 3차 | 차원2의 양극단 2개 | 1 (A 또는 B) | 3 |
| 4차 | 차원3의 양극단 2개 | 1 (A 또는 B) | 4 |

**설계 의도**
- 양극단 택1 = 선택이 곧 정체성. 한 계파 안에서 "A형 빌드 ↔ B형 빌드"로 갈림.
- 차수 진행 = 초반(2차)엔 비교적 기초적인 갈림 → 후반(4차)엔 상황형/극단형 갈림.
- 기획 원칙 §6.1의 4방향(순수강화·고위험고수익·조건부·상호배타)이 이 양극단들 안에 녹아 있음.

> ※ 예전 안(2차1·3차2·4차3 슬롯, 풀6중3 자유선택)에서 **변경됨.** 자유도는 줄고(3→ 차원당 택1) 정체성은 강해지는 방향. 자세한 변경 경위는 `02` D7 참조.
