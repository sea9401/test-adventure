# 01. 기반 시스템

12계파 위에 공통으로 깔리는 규칙들입니다. 계파별 디테일은 직군 파일(03~06) 참조.

---

## 1. 전투 개요

- **서버 자동 단판.** 플레이어는 턴마다 조작하지 않음. 빌드(스탯·스킬·패시브·장비)를 미리 짜두면 전투가 자동 해결되고 리플레이만 봄.
- **전투 중 반응 불가** → 빌드/장비를 잘못 맞추면 그대로 손해. (이게 모든 설계의 제약 핵심.)
- 전투 무대: 던전 사냥(PvE) · 1:1 일기토 · 3:3 토너먼트 · 1:1 아레나 · 거점 점령(길드).
- **단독 전투.** 파티가 없음. **아군 힐·아군 수호·아군 버프 전부 없음.** 모든 회복·보호·버프는 **자기 대상**.
  - → 설계 중 신성술의 아군힐, 탱의 아군수호 등은 전부 제거되고 "자기 생존"으로만 재정의됨.

---

## 2. 차수 / 차원 모델 ★

(요약은 README에. 여기선 구현 관점 정리.)

- 계파당 패시브 = **1차 공용 1 + 2·3·4차 각 차원 1개(양극단 2개)** = 배움 7개.
- 장착은 **차수당 1개**, 누적 4개. 각 차원은 **양극단 택1**(동시 장착 불가).
- "차원(dimension)" = 양극단 A↔B로 구성된 한 쌍. 한 계파는 2·3·4차에 차원 하나씩, 총 3차원.
- 양극단은 **서로 대립**(하나를 키우면 반대 방향의 이득을 포기)하도록 설계. 같은 방향이면 차원이 무너짐(둘 다 끼고 싶은 "정답"이 됨).

**검증 포인트(공통):** 각 차원의 A·B가 진짜 대립인지 — "A형 빌드"와 "B형 빌드"의 성능/플레이가 실제로 갈리는지 sim으로 확인. 한쪽이 거의 항상 정답이면 그 극단을 손봐야 함.

## 3. 데미지 계산 모델

> ⚠ 아래는 **sim 기본 ON, 라이브 미반영** 상태(게이트). 라이브 적용 여부는 `02` D3 참조.

- **데미지 = 비율 경감.** `공격력 × 100 / (100 + 방어력)`.
  - 예전 빼기식(공−방)의 "절벽"(공≈방에서 데미지 1로 붕괴 → 교착) 제거. 방어는 이제 %로만 작동. **[확정·채택]**
- **데미지 최소~최대 폭.** 하한 = `0.3 + 0.0015 × (힘 + 0.5×지능 + 0.3×활력)` (최대 0.9). 힘/지능/활력 = 일관, 민첩/행운 = 변동. **[가설]**
- **다단히트 감쇠.** 2번째 타격 ×0.5, 3번째+ ×0.3. **단, 크리/상태이상 발동 기회는 줄이지 않고 데미지만 감쇠.** **[확정]**
  - → 다타 계파(세검·너클·활·비수)의 핵심 제약. "타수 많음"이 데미지로 직결되지 않게.
- **스킬 데미지 ×0.5.** 스킬이 전투를 2~5턴에 끝내 스탯·장비가 무의미했던 문제 → 절반으로 눌러 4~16턴. **[검증됨]**
- **장비 위력 ×2.25** (장비 기여 24%→45%). **[적용됨]**
- 크리 오버플로 + 치명저항(정신이 PvE서도 작동), 시드 고정 RNG(전투 재현). **[적용됨]**

## 4. MP · 스킬 · 시그니처 규칙 ★

- **모든 스킬 발동 시 MP를 소모한다.** (게임 전체 공통 자원.)
- **스킬 = 확률 발동.** 쿨타임 없음. 매 턴 일정 확률로 시전. (예전 "쿨다운 3~5턴" 안은 폐기.)
- **시그니처 액티브** = 계파당 1개의 대표 액티브 스킬.
  - 확률 발동 + MP 소모. 쿨 없음.
  - **sim 토글**로 ON/OFF A/B 비교 후 채택 결정(정체성 이득 > 밸런스 비용인지).
  - 성능 철학: **"터지면 보너스" 수준.** 평타·패시브가 기본 성능을 책임짐. 특히 극딜 계파에서 시그니처가 데미지의 큰 비중이면 **확률 발동 분산 때문에 판마다 클리어 여부가 흔들림.**
- **법사류(신성법사·순수마법·배틀메이지) 시그니처 = 마나회복 계열.** 마법은 스킬=마나 소모라, 마나가 곧 탄약. 그래서 법사 시그니처가 마나회복기.
- **기공패** = 음양 순환으로 MP↔HP를 자동 변환(아래 04 참조). MP가 딜(스킬)·생존(회복) 양쪽 자원이 되는 유일 계파.

> ⚠ **확률 발동 + 자동전투 = 발동 횟수 자체가 분산.** 시드 고정 RNG로 재현은 되지만, "운 좋은 판/나쁜 판" 편차가 존재. 시그니처·확률 기반 패시브 비중이 큰 계파일수록 분산이 커짐 → 검증 시 유의.

## 5. 1차 공용 패시브 (직군별)

각 직군의 3계파가 **공유**하는 1차 패시브. 차원이 아니라 단일(선택 없음). 약하게 무난한 게 정상(정체성은 2차부터).

| 직군 | 1차 공용 | 비고 |
|---|---|---|
| 전사 | 물리 공격력 강화 | 3계파(딜·반격) 모두 유효 |
| 무도가 | 최대 HP 증가 | 권갑·기공패엔 딱 맞음. **너클(빠른 딜형)엔 미스매치** — 인지된 트레이드오프, 그냥 둠 |
| 마법사 | 스킬 피해 증가 | 순수마법·배메엔 맞음. **신성법사(회복형)엔 약함** — 단 신성법사 4차 심판(회복력→딜)과는 시너지 |
| 도적 | 치명 · 회피 증가 | ⚠ **효과 2개** — 다른 직군 공용은 1개. 도적만 약간 셀 수 있음 → 4직군 공용 균형 점검 시 재검토(`07`) |

## 6. 권장스탯 정책

- **모든 계파의 권장/주스탯 표기는 제거.** 공동개발자가 sim으로 결정. (이 문서들엔 "권장 STR" 같은 표기 없음 — 의도된 공란.)
- §3 **자유 수행**: 직군-스탯 1:1 묶음 해제. 어떤 스탯을 키울지는 플레이어가 선택(직업은 권장만 안내).
- **6 스탯 유지**: 힘(str)·민첩(dex)·활력(vit)·지능(int)·정신(spi)·행운(luk). 직군만 4개.
  - 예전 "속도(spd)"는 1차에서 빠지고 **파생 스탯**(민첩 등에서 산출).
- 단, 계파 메커니즘이 특정 스탯을 **전제**하는 경우는 본문에 명시(예: 기공패는 MP 자원, 권갑 반격은 체력계수 기반, 배메 평타는 INT계수 물리딜). 이건 "권장"이 아니라 "이 계파가 작동하는 방식"이라 남겨둠.

## 7. 무기 타입 게이트

- 계파 패시브는 **맞는 무기를 껴야 발동.** 틀린 무기면 패시브 OFF(베이스만) + UI에 "○○ 필요" 명시(조용한 약화 금지).
- 계파 무기는 **2차 전직까지 확정 지급**(자동전투라 무기 잘못 끼면 손해이므로).

---

## 8. 밸런스 레버 — 무기 base (★ 핵심 조정 손잡이)

- **원칙(기획 §6.4): 패시브 수치는 정체성이라 안 건드린다.** 계파가 너무 세거나 약하면 **무기의 위력·무게(속도)** base만 조정해 잡는다.
- 각 계파의 base(위력/속도/타격패턴/고유특성)는 직군 파일에 기재.
- **12무기를 한 표에 모은 비교축(§7.3 산출물)은 아직 미작성** → 다음 작업(`07` 참조). 계파 밸런스의 핵심 레버라 우선순위 높음.

---

## 9. 상태이상 시스템 (★ 미확정 — 여러 계파가 의존)

- 출혈·중독·소각·자동피해(도트)는 **시스템이 아직 "추후"**. 스탯 축만 먼저 깔림.
- 의존 계파: **세검(출혈)·기공패(자동피해)·비수(중독)** — 특히 **비수는 정체성 전체가 중독 스택**이라 시스템 없이는 검증 불가.
- 통일 가설(미확정): 출혈 3턴·중독 5턴·소각 2턴, 확률 발동. 5속성 순환 + 빛/어둠 연계 여부도 미정.
- → 자세한 건 `07_미결정` 참조. **상태이상 설계를 비수 검증 전에 당기는 것을 강력 권장.**
