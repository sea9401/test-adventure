# 02. 핵심 결정 (D1–D9) + 진화 기록

설계 결정들과 **그 이유**입니다. 일부는 상세 설계 중 **진화**했습니다(특히 D4/D9 무도가, D7 슬롯). 진화한 항목은 🔁 표시.

전투 모델 결정(D1·D2·D3)은 계파 설계와 **독립**이라 sim에서 병렬로 검증하면 됩니다.

---

## D1 — 명중 모델 [sim 병렬]

- **공동개발자 권고:** flat 식 `명중% = 95 − 적 회피`.
- **우리 결정: 부분 반대.** flat엔 *내 명중*이 안 들어가서, 카운터 축 중 하나인 **명중↔회피가 죽음.**
- **제안(식 형태):**
  ```
  명중% = 85 + 0.5 × (내 명중 − 적 회피),  [하한 40, 상한 100] 클램프
  ```
  - 상수 1개(0.5)만 튜닝 → 여전히 단순 / 명중·회피 둘 다 작동 → 축 유지 / 하한 40 = "안 맞는 불사신" 방지.
  - **85·0.5·40은 파생스탯 스케일을 몰라 전부 자리표시자.** 추천은 "식의 형태"이고, 숫자는 sim에서 회피빌드가 60~70%쯤에서 멈추게 맞추면 됨.
- **D2와 묶임:** 몹 회피가 0이면 어떤 식이든 PvE 명중은 죽음.
- ⚠ 현재 sim 기본값 명중상수 **C=0은 버그** — 적 공격의 90%를 빗나가게 만들어 게임이 비현실적으로 쉬움. 설계와 무관하게 **즉시 수정 대상**.

---

## D2 — 몬스터에 회피·치명저항 부여 [sim 병렬]

- **강하게 YES.** 안 주면 §1 철학("카운터를 PvE에도")이 깨지고, **명중·치명저항·관통** 세 축이 PvE에서 영구 휴면.
- 몹을 축별로 분화(전부 임시·확정 아님):

| 몹 원형 | 스트레스 주는 축 | 요구 빌드 |
|---|---|---|
| 회피몹 | 명중 ↔ 회피 | 명중 투자 |
| 치명몹(크리 씀) | 치명 ↔ 치명저항(정신) | 정신 투자 — **치명저항 휴면 해제** |
| 고방몹 | 공 ↔ 방 | 관통 / 순수 위력 |
| 균형몹 | 없음(기준선) | 범용 |

- 효과: 던전마다 다른 빌드가 보상받음 = 단일 몰빵 방지 = 카운터 철학의 PvE 구현. D1 선형식과 상호 보강(회피몹이 있어야 명중이 산다).
- **이게 없으면** 다수 계파의 차원이 PvE에서 무의미해짐: 단검·비수·너클(회피), 활(명중·관통), 신성법사(치명저항), 대검(관통) 등. 각 계파 sim 노트에 "D2 의존" 다수 표기.

---

## D3 — 전투 모델 게이트 라이브 ON? [라이브 맥락 필요]

- **C=0 명중상수 = 버그** → 즉시 수정, 게이트 무관.
- 비율경감 · 스킬×0.5 · 신술 구제 = 검증됨 → **D2 몹 원형 넣고 sim 풀세트 통과 후** 플래그 ON.
- 한 번에 전부 뒤집지 말 것. 기존 라이브 유저가 있으면 리밸런스 마이그레이션부터 점검.
- 한마디로: **"버그는 지금, 디자인 리밸런스는 sim 통과 후."**
- 라이브 상황(현재 유저 수·기존 경제 유무)을 알면 더 좁힐 수 있음 — **공동개발자 판단 영역.**

## 🔁 D4 / D9 — 무도가 카운터 & 탱 색분리 [상세설계 중 진화]

이 둘은 같이 묶입니다. **원안에서 크게 진화**했으니 주의.

- **원안(D4·D9):** 무도가 = 반사+경감 / 검방(전사) = 반격 / 권갑(무도가) = 반사. "검방은 때려서 갚고, 권갑은 받은 %를 되돌린다."
- **진화 경위:**
  1. 권갑 "모아서 한 방(축적 후 반사 방출)" → **구현이 어렵고 복잡함** → 폐기. 패시브는 심플하게.
  2. 핵심 차별점 재발견: **권갑은 HP가 높고 방어는 검방만큼 높지 않다 → 그래서 반격딜이 센 게 차별점.** (검방=단단해서 안 맞음 / 권갑=많이 맞지만 HP로 버티며 굵게 반격.)
- **최종 결정:**

| | 검방 (전사·검+방패) | 권갑 (무도가·권갑) |
|---|---|---|
| 카운터 방식 | 매 피격 **즉시 반격**(툭툭, 잘게) | 매 피격 **즉시 반격**(굵게, 한 방이 셈) |
| 스케일 소스 | **공격력(STR 계열)** 기반 | **체력계수 / 받은 피해** 기반 |
| 방어/HP | 방어 높음(단단), HP 보통 | 방어 낮음, **HP 높음**(많이 맞고 버팀) |

- **둘 다 즉시반격이되, 스케일 소스(공격력 vs 체력)와 방어/HP 분포로 차별.** "축적·반사" 메커니즘은 게임에서 빠짐.
- ⚠ 검방 4차(반격증폭↔자체공격)와 권갑 3차(체력계수↔반격강화)가 "반격 vs 자체딜"로 닮음 → **스케일 소스(STR vs 체력)로 구분**되는지 sim 확인. 다른 직군이라 허용 범위로 봄.

## D5 — 속성: 직교 [확정(아키텍처만)]

- **직교.** 속성(불/물/바람/대지/번개/빛/어둠)은 **장비·스킬에만 부착.** 계파는 플레이버만(예: 지팡이/화염은 불 플레이버지만 하드 카운터 없음).
- **이유:** 자동전투 = 전투 중 반응 불가. 속성을 불변 계파에 하드락하면 카운터 속성 던전에 큐 박는 순간 자동 패배 → 빌드 agency 훼손. 직교면 장비/스킬로 속성 바꿔 대응.
- 실제 속성 카운터 수치(5속성 순환 + 빛/어둠 연계 여부)는 **추후.** 지금은 **아키텍처(직교)만 확정.**

## D6 — 시그니처 액티브: 계파당 1개 [확정]

- **계파당 1개.** 확률 발동(쿨 없음, MP 소모). **sim 토글**로 채택 검증.
- "터지면 보너스" 수준(평타·패시브가 기본 성능). 자세한 건 `01` §4.
- 공용 스킬 풀과 병행 가능.

## 🔁 D7 — 패시브 슬롯 [변경됨]

- **원안:** 2차 1 · 3차 2 · 4차 3 슬롯, 풀 6개 중 자유 선택.
- **최종:** **1차 1 + 2·3·4차 각 2 배움(7개), 차수당 1 장착(누적 4개), 차원 양극단 택1.** (`00`/`01` 참조)
- 변화 방향: 자유도↓(차원당 택1) / 정체성↑. §1 "정체성 기반 다양성"과 정렬.

## 추가 합의 (대화 중 확정된 것)

- **스킬 = 확률 발동, 쿨타임 폐기** (게임 전체). → MP가 유일 자원 제약.
- **권장/주스탯 표기 전부 제거** (공동개발자 결정 영역).
- **대표 빌드 갈림 예시는 문서에 넣지 않음** (필요 시 sim에서 확인).
- **배틀메이지 = "만능형(물공+마공+방어 다)" 폐기 → "마공+방어 하이브리드"로 좁힘.**
  - 만능형은 카운터를 다 무시하는 단일 최적해가 되어 게임을 깸 + INT 하나로 물공까지 내면 스탯 효율 2배. "넓지만 얕게(각 전문가보다 약함)"로도 막기 어려워, 아예 물공을 빼고 마공+방어로 좁혀 함정 회피. (자세한 건 `05` 배틀메이지.)
