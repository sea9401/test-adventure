# 03. 전사 (검방 · 대검 · 세검)

공통 1차 패시브 = **물리 공격력 강화.** 차수/차원/장착 규칙은 `00`·`01` 참조.
모든 수치는 [미정](공동개발자·sim). 아래는 **방향과 설계 의도.**

---

# 검방 — 자기 탱 / 즉시반격 (검 + 방패)

| 항목 | 내용 |
|---|---|
| 무기 | 검 + 방패 |
| 역할 색 | **자기 생존 + 매 피격 즉시반격(툭툭, 잘게).** vs 권갑=굵게 반격(체력 기반) / vs 대검=극딜 |
| base | **느림**(낮은 속도) · 매 턴 단일타 · **오래 버팀**(검+방패 자체 방어 보정↑). "딜 느려도 안 죽는다" |

### 차원

| 차수 | 차원 | A극단 | B극단 |
|---|---|---|---|
| 1차 | (공용) | 물리 공격력 강화 | — |
| 2차 | **수성** | **방패태세**: 받피감↑, 반격은 기본 수준 | **응수태세**: 받피감 일부 포기 + **매 피격 반격 발생**(코어 응수) |
| 3차 | **방벽** | **강철방벽**: 물리방어 특화(vs 물리 적) | **수정방벽**: 마법방어 특화(vs 마법 적) |
| 4차 | **검활용** | **반격증폭**: 반격 데미지↑ | **자체공격**: 평타 데미지↑ (대검 극딜은 안 넘게 캡) |

### 설계 의도

- **2차 수성 = "어떻게 맞는가"(방어 태세).** 버틸까(방패태세) ↔ 받아칠까(응수태세). 반격의 *발생 자체*는 응수태세 쪽에 실림. (※ 초기엔 "반격 트리거"를 별도 차원으로 뒀다가, 수성과 같은 얘기라 통합함 — 반격 강약은 수성에서 끝냄.)
- **4차 검활용 = "딜을 어디서 뽑는가"(공격 방향).** 받아친 걸 키울까(반격증폭) ↔ 내가 직접 칠까(자체공격). 2차(방어 태세)와 층이 달라 안 겹침.
  - → "수성 응수태세 + 검활용 반격증폭" = 풀 반격탱 / "수성 방패태세 + 검활용 자체공격" = 버티는 평타딜러. 차원이 직교라 조합 열림.
- **자체공격 캡:** 검방이 극딜까지 되면 대검의 존재 이유가 사라짐. 검방 자체딜은 "탱 유지하며 딜 보강" 선에서 **무기 base 위력으로 캡**(패시브 불변).

### 시그니처
- **방패 일격** — 확률 발동, 큰 반격 1회 + 짧은 받피감 버프. 쿨 없음(+MP 소모).

### sim 검증 노트
- 느린 탱이 자동전투 "빨리 죽이는 게 이득" 환경에서 **약체화** 위험 → **1순위.**
- 응수가 공격력으로 스케일할 때, 생존 위주 빌드(공격력 낮음)면 반격이 약함 → "버티지만 못 이김". 공격·생존 하이브리드가 답인지 확인.
- 응수태세 + 반격증폭 풀반격 조합이 과강한지(다른 차원이라 동시 가능).
- 비율경감 ↔ 반격 상호작용: 반격이 권갑(체력/받은피해 기반)과 어떻게 갈리는지.

# 대검 — 단일 극딜 (대검)

| 항목 | 내용 |
|---|---|
| 무기 | 대검 |
| 역할 색 | **단일 대상 극딜.** vs 검방=탱·반격(같은 무기군이지만 정반대) |
| base | **느림**(낮은 속도) · **매 턴 단일 강타**(다단히트 없음) · 타격당 위력 높음. "느리지만 한 방이 무겁다" |

### 차원

| 차수 | 차원 | A극단 | B극단 |
|---|---|---|---|
| 1차 | (공용) | 물리 공격력 강화 | — |
| 2차 | **템포** | **중검**: 단일 강타 위력↑ · 속도↓ (한 방형) | **쾌검**: 단일 강타를 2타로 전환 · 속도↑ · 타당 위력↓ (다단감쇠 적용) |
| 3차 | **치명** | **일격필살**: 치명피해↑ (올인·운빨 폭발) | **안정타**: 최소데미지 하한↑ (일관딜·운 안 탐) |
| 4차 | **마무리** | **처형**: 적 HP 낮을 때 딜↑ | **선제**: 적 HP 높을 때(=전투 초반) 딜↑ |

### 설계 의도

- **2차 템포 = 진짜 배타쌍.** 쾌검(연타 전환)을 고르면 "단일 강타" 정체성 자체가 사라져서, 중검(단타 강화)이 강화할 대상이 없어짐 → 동시 장착해도 서로 무력. (기획 §6.1 상호배타 자리.)
  - ※ 초기에 "관통(방어관통↔순수위력)"을 2차로 검토했으나 **폐기.** 이유: 둘 다 결국 "딜 증가"라 진짜 트레이드오프가 아니고(상대 방어가 높냐 낮냐로 갈릴 뿐), 자동전투라 상대를 못 골라 "그냥 센 쪽"이 됨. → 기존 코어 갑옷가르기(방어관통)는 대검 풀에서 빠짐. **"조용한 약화" 방지 차원에서, 관통은 장비·스킬로 얻는 축임을 명시.** (관통은 신경 쓰지 않기로 합의.)
- **3차 치명 = 분산 선택.** 운빨 폭발(일격필살) ↔ 일관딜(안정타). 평균은 치명 쪽이 높을 수 있으나 분산 큼.
- **4차 마무리 = 적 상태 기반 상황형.** 막타(처형) ↔ 선제(선제). 단검 4차와 동일 구조.

### 시그니처
- **대검 참격** — 확률 발동, 단일 큰 데미지(스킬 ×0.5 적용) + 순간 방어관통 보너스. 쿨 없음(+MP).
  - "터지면 보너스" 수준 유지 — 극딜이라 시그니처 비중을 너무 키우면 확률 발동 분산으로 판마다 클리어가 흔들림.

### sim 검증 노트
- 느린 단일강타의 총 DPS가 다타 계파에 밀리는지 → 무기 위력으로 보정(패시브 불변).
- 쾌검 2타가 다단감쇠(×0.5)를 먹으니 속도 이득 대비 약할 수 있음 → 타당 위력으로 균형.
- 치명 올인(일격필살)의 분산이 너무 큰지(확률 시그니처까지 겹치면 더).
- 처형/선제가 **D2 몹 원형**(고방·탱몹 등)에서 균형몹보다 유의미하게 강한지.
- 속도 ±%가 행동순서에 의미를 가지려면 **속도 파생식 스케일** 확정 필요(템포 수치 확정의 전제).

# 세검 — 빠른 출혈 딜러 (세검)

| 항목 | 내용 |
|---|---|
| 무기 | 세검 |
| 역할 색 | **출혈 누적 + 속도.** vs 대검=순간 극딜(차별) |
| base | **빠름**(높은 속도) · 다타 가능 · 타격당 위력 낮음(경량) · **공격 시 출혈 확률 30~50%(세검 기본)** |

### 차원

| 차수 | 차원 | A극단 | B극단 |
|---|---|---|---|
| 1차 | (공용) | 물리 공격력 강화 | — |
| 2차 | **출혈운용** ※ | **출혈증폭**: 출혈 계수↑ (도트딜로 갉기) | **발현**: 출혈 걸린 적에게 **직접타 데미지↑** (자체딜) |
| 3차 | **속공** | **쾌속**: 속도↑ (선공·다회) | **정밀**: 속도 일부 포기 · 치명확률↑ (소량, 4차 일점과 시너지) |
| 4차 | **타격형** | **난무**: 타수↑ (잘게, 다단감쇠) | **일점**: 타수↓ · 치명타피해↑ (한방형) |

### 설계 의도

- **출혈 확률 30~50%는 차원이 아니라 "세검 기본"으로 깔림.** → 2차의 어느 극단을 고르든(출혈증폭이든 발현이든) 출혈이 작동. 특히 **발현(출혈 걸린 적에게 추가딜)이 죽지 않게** 하는 장치(출혈을 자기 평타가 기본으로 거니까 조건 자동 충족).
- **2차 = 도트 ↔ 자체딜.** 출혈로 갉을까(증폭) ↔ 출혈 묻은 적을 직접 더 때릴까(발현).
- **3차 속공 = 빠름 ↔ 정확.** 정밀에 **소량의 치명확률**을 실어 4차 일점(치명피해)과 약한 시너지. ⚠ **단, 시너지를 강하게 만들지 않음** — 치명확률(3B)을 일점(4B)보다 작게 둬서 "치명 안 가면 손해"가 되지 않게(그래야 쾌속 3A도 살아있음). `[sim 노트: 3B 치명확률 < 4B 치명피해 비중]`
- **4차 타격형 = 잘게 ↔ 굵게.** 난무(다타)는 다단감쇠를 먹으므로 타당 위력으로 보정. 일점은 타수 줄이고 한 방(치명피해).

### 시그니처
- **연속 찌르기** — 확률 발동, 다단 히트 + 출혈 부여. 쿨 없음(+MP).

### sim 검증 노트
- **출혈 ※ 상태이상 시스템 미확정** → 출혈증폭·발현 수치 보류, 방향만 가설.
- 난무 다타가 다단감쇠로 약할 수 있음 → 타당 위력 보정.
- 정밀 명중/치명이 PvE서 의미를 가지려면 **D2 회피몹·치명저항몹** 필요.
- 속도 파생식 확정돼야 쾌속 수치 잡힘.
- 도트 딜러 공통 위험: 빨리 죽는 적에겐 출혈이 다 안 들어감(자동전투 고DPS 메타에서 약체 가능) — 비수와 공통, `07` 참조.

## 전사 3계파 역할 직교 점검

| 계파 | 역할 | 무기 | 색 구분 |
|---|---|---|---|
| 검방 | 탱·즉시반격 | 검+방패 | 느림·공격력 기반 반격 |
| 대검 | 단일 극딜 | 대검 | 느림·단일 강타 |
| 세검 | 출혈 딜러 | 세검 | 빠름·도트 |

- 검방 ↔ 권갑(무도가)의 "탱·반격" 중복은 **공격력 기반(검방) vs 체력 기반(권갑)**으로 분리(`02` D4/D9).
- 대검 ↔ 세검은 둘 다 물리 딜러지만 **순간 극딜(대검) vs 빠른 도트(세검)**로 갈림.
