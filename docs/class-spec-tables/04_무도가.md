# 권갑 — 느린 카운터 탱 (권갑)

| 항목 | 내용 |
|---|---|
| 무기 | 권갑(맨손/권갑) |
| 역할 색 | **매 피격 즉시 반격(검방보다 굵게) + HP를 딜로 환산.** vs 검방=단단·공격력 기반 / vs 기공패=순환 / vs 너클=속도·회피 |
| base | **느림** · 매 턴 단일타 · **HP 높음 / 방어는 검방보다 낮음** → 많이 맞지만 HP로 버팀 |

### 차원

| 차수 | 차원 | A극단 | B극단 |
|---|---|---|---|
| 1차 | (공용) | 최대 HP 증가 | — |
| 2차 | **수성** (검방과 동일 · 수치까지) | **방패태세**: 받피감↑ | **응수태세**: 받피감 일부 포기 · 매 피격 반격 발생 |
| 3차 | **체력활용** | **강타**: 평타 데미지에 **체력계수**(HP 비례 직접딜) | **반격강화**: **반격피해 증가** |
| 4차 | **인내** | **철산고**: 최대 HP↑ | **재생**: 매 턴 HP 회복 |

### 설계 의도

- **2차 수성은 검방과 통째로 동일(수치까지).** → sim 데이터 재활용 가능(검증 비용↓). 두 계파의 차별은 수성이 아니라 **base(HP/방어 분포)와 3차(체력계수)**에서 나옴.
- **3차 체력활용 = 능동 ↔ 수동.** 내 HP를 직접 딜로 실어 칠까(강타·평타에 체력계수) ↔ 받아친 걸 키울까(반격강화).
  - ⚠ 처음엔 "공방전환" 차원을 검토했으나, 권갑의 진짜 차별점이 "HP를 딜로 환산"이라 **체력계수 ↔ 반격피해**가 더 정체성에 맞음.
  - ⚠ "데미지에 체력계수"는 **평타**에 붙음(반격이 아니라). 반격에 붙이면 반격강화(3B)와 같은 방향이 되어 차원이 무너짐. → A=평타 체력계수(능동), B=반격피해(수동)로 갈라야 진짜 대립.
- **4차 인내 = HP풀 ↔ 회복.** 단독 장기전 색.
- **반격은 공격력이 아니라 체력계수/받은피해 기반**(검방=공격력 기반과 구분). → 권갑은 HP에 투자하면 생존·반격이 동시에 올라감(VIT 정체성).

### 검방 vs 권갑 차별 (핵심)
- 검방: 방어 높음(단단해 안 맞음), 반격은 공격력 기반·잘게(툭툭).
- 권갑: 방어 낮음·HP 높음(많이 맞고 버팀), 반격은 체력 기반·굵게(한 방이 셈).

### 시그니처
- **반격 일격** — 확률 발동, 큰 반격 1회 (HP계수 실린 한 방 등으로 검방 시그니처와 색 차별). 쿨 없음(+MP).

### sim 검증 노트
- 권갑 방어가 검방보다 낮은 만큼 반격딜이 세야 "역할 차별" 성립 → 반격 계수를 검방보다 높게, 단 **무기 base로 조정**(패시브 불변).
- 반격이 체력/받은피해 기반인지 확정(검방=공격력 반격과 구분). 3차 강타도 체력계수라 일관.
- 느린 탱 클리어타임 약체 위험(검방과 공통, 1순위).
- 검방 4차 vs 권갑 3차 "반격 ↔ 자체딜" 겹침 — 스케일 소스(공격력 vs 체력)로 구분되는지.

# 기공패 — 음양 자원순환 (기공패)

| 항목 | 내용 |
|---|---|
| 무기 | 기공패 |
| 역할 색 | **음양 순환(MP↔HP 양방향 자동변환) + 흡혈/딜 운용.** vs 권갑=반격 / vs 너클=속도·회피 |
| base | **중속** · 다타 가능 · "공방이 서로를 먹여살리는 순환" |

### 음양조화 = 핵심 메커니즘 (먼저 이해)
- **MP를 잃으면(= 스킬 시전 시 MP 소모) → HP 회복.**
- **HP를 잃으면(= 피격) → MP 회복.**
- → 싸우면 회복하고, 맞으면 다음 스킬 연료가 차는 **영구 순환.** "공격과 방어가 서로를 먹여살림."
- ⚠ MP 소모는 **스킬이 알아서** 함(따로 MP를 빼 쓰는 액션 아님). 스킬로 MP가 빠지면 거기서 HP 회복이 따라오는 구조.

### 차원

| 차수 | 차원 | A극단 | B극단 |
|---|---|---|---|
| 1차 | (공용) | 최대 HP 증가 | — |
| 2차 | **음양조화** (양방향 항상 작동) | **MP→HP 변환 강화** (회복 특화) | **HP→MP 변환 강화** (자원 특화) |
| 3차 | **운용** | **스킬 시전 확률↑** (딜·발동 빈도) | **흡혈**: 준 피해 %만큼 HP 회복 |
| 4차 | **지속력** ※ | **받피감** (꾸준 버티기) | **매 턴 자동 피해** (도트 갉기) |

### 설계 의도

- **2차는 "특화형(둘 다 항상 작동, 한쪽 강화)".** ← 중요. "택1형(한 변환만 보유)"이 아님.
  - 택1형은 루프가 반쪽이라 끊김: "MP→HP만"이면 MP 수급처가 없고, "HP→MP만"이면 모은 MP로 회복을 못 함 + 확률발동이 안 터지면 자원이 막혀 죽음. → **양방향이 항상 도는 특화형으로 확정.** 2차는 어느 방향에 무게를 둘지(회복 특화 ↔ 자원 특화)만 고름.
- **3차 운용 = MP를 어디에.** 스킬 발동을 늘려 딜(스킬확률) ↔ 흡혈로 회복. 2차 B(자원 특화)와 3차 A(스킬확률)는 시너지("맞아 MP 모아 스킬 난사") — 차원이 달라 동시 가능, 과강하면 sim 조정.
- **4차 지속력 = 버티기 ↔ 갉기.**

### 변경/정리된 것
- 🔁 **§4 흡혈 코어(기공권) 격하:** 흡혈이 "코어"에서 3차 B극단의 "선택지"로 내려옴. 순환이 새 정체성.
- 🔁 **실드(초과 회복분 → 보호막) 폐기:** 회복원이 음양+흡혈로 이미 충분 → 실드까지 가면 무한생존 잡기 어려워 뺌.
- 🔁 시그니처에서 **HP 회복 기능 삭제** → 순수하게 "높은 MP 소모 + 높은 데미지".

### 시그니처
- **기공포** — 확률 발동, **높은 MP 소모 + 높은 데미지** (HP 회복 없음). 쿨 없음.

### sim 검증 노트
- ★ **무한 생존(불사) 방지:** 회복원이 음양(MP→HP) + 흡혈 2중 → 회복 총량 < 받는 피해 상한 필요. **1순위.**
- 특화형이라 루프는 항상 완전(택1형 구멍 없음).
- "맞을수록 도는" 구조 → 강한 적(고난도 던전)에서 오히려 잘 돌 수 있음 → **난이도 역전** 체크.
- 2B(자원 특화) + 3A(스킬확률) 시너지(자원→스킬 난사)가 과강한지.
- 도트 ※(4B) 미확정.

# 너클 — 빠른 연타 (너클) **[잠정 — 수정 가능]**

> ⚠ **이 계파는 잠정안.** 2차(고정딜↔위력) 구분이 실제로 갈리는지, 4차 회피 유지 여부 등 sim 후 재조정 열어둠.

| 항목 | 내용 |
|---|---|
| 무기 | 너클 |
| 역할 색 | **연타 + 속도.** vs 권갑=느린 단일반격 / vs 기공패=중속 순환 / vs 도적=회피 색(겹침 회피) |
| base | **빠름** · **다타(타수 많음 = 기본 색, 차원 아님)** · 타격당 위력 낮음 · 다단감쇠 적용 |

### 차원

| 차수 | 차원 | A극단 | B극단 |
|---|---|---|---|
| 1차 | (공용) | 최대 HP 증가 | — |
| 2차 | **타격질** 🔧 | **고정딜**: 타격마다 추가딜 (다단감쇠 무시·누적·안정) | **위력**: 타격당 위력↑ (한방·터짐) |
| 3차 | **속공** (세검 뼈대) | **쾌속**: 속도↑ (선공·다회) | **정밀**: 속도 일부 포기 · 치명확률↑ |
| 4차 | **회피** 🔧 | **유연**: 회피↑ | **맷집**: 회피 포기 · 받피감 |

### 설계 의도

- **타수는 차원이 아니라 무기 base 정체성.** (검방의 "단일타"가 base이듯.) 타수를 줄이는 극단은 두지 않음(플레이어 평가: "타수 줄이는 건 별로").
- **2차 타격질 = 고정딜 ↔ 위력.** "타수만 늘려선 의미 없다"는 문제 해결용:
  - 다단감쇠는 **비율 데미지**를 깎음. **타격당 고정딜**은 감쇠가 안 깎는 가산이라 타수가 많을수록 그대로 쌓임 → "고정딜로 쌓기(안정·꾸준)" ↔ "타당 위력 키우기(한방·터짐)".
  - 🔧 둘 다 결국 "딜 증가"로 묻힐 위험이 있어 **잠정** — 진짜 다른 빌드로 갈리는지 sim 1순위.
- **3차 속공 = 세검 속공과 같은 뼈대**(쾌속 ↔ 정밀). 무기·직군이 다름.
- **4차 회피 = 도적과 일부 겹침** → 🔧 유지 vs 다른 축 교체는 sim 후 결정.

### 시그니처
- **난타** — 확률 발동, 다단 연타 폭발. 쿨 없음(+MP).

### sim 검증 노트
- ★ 다타 + 다단감쇠 → 너클은 타수 많아 감쇠 영향 큼. 고정딜형(2A)이 위력형(2B)/단타 계파 대비 안 밀리게 타당 위력 보정. **1순위.**
- 빠른 딜형 무도가가 HP 공용(1차)만으론 물러서, 빨리 못 죽이면 위험 → 클리어 속도 vs 생존 트레이드오프.
- 회피(4A) PvE 의미는 D2 적 명중 의존.
- 세검·너클 속도 축 겹침(무기/직군 구분으로 충분한지).
- 🔧 §4 연환격 코어(추가타)가 base 다타로 흡수됨 — OK인지.

## 무도가 3계파 역할 직교 점검

| 계파 | 역할 | 무기 | 색 구분 |
|---|---|---|---|
| 권갑 | 카운터 탱 | 권갑 | 느림·HP·체력 기반 반격 |
| 기공패 | 자원순환 생존딜 | 기공패 | 중속·MP↔HP 순환 |
| 너클 | 연타 딜러 | 너클 | 빠름·다타 |

- 권갑 ↔ 검방 탱 중복은 공격력 vs 체력 기반으로 분리(`02` D4/D9).
- 기공패 회복 ↔ 신성법사 회복은 **자원순환 vs 신성 힐**로 메커니즘 차별(`05` 참조).
- 너클 회피 ↔ 도적 회피는 잠정 — 너클은 연타 메인, 회피는 4차 선택지(`07` 점검 대상).
