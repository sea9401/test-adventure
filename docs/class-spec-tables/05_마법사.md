# 05. 마법사 (신성법사 · 순수마법 · 배틀메이지)

공통 1차 패시브 = **스킬 피해 증가.** 규칙은 `00`·`01` 참조. 모든 수치 [미정].

> ※ 마법사는 §4 원안(화염·신성·빙결)에서 **재구성**됨: 빙결(제어)이 빠지고 **배틀메이지**가 들어옴. 화염 → 일반화된 "순수마법". 신성 → 회복·생존 캐스터로 재정의(단독전투라 아군힐 없음).

# 신성법사 — 회복·생존 캐스터 (성서)

| 항목 | 내용 |
|---|---|
| 무기 | 성서 |
| 역할 색 | **회복·경감 생존 + 신성딜.** vs 배메=방어 생존 / vs 기공패=순환 생존 |
| base | **느림**(생존형 캐스터). "느려도 끝까지 버텨 이김"(§5에서 검증된 신술 컨셉) |

### 차원

| 차수 | 차원 | A극단 | B극단 |
|---|---|---|---|
| 1차 | (공용) | 스킬 피해 증가 | — |
| 2차 | **가호** | **회복**: 자가 회복량↑ | **경감**: 받피감↑ (덜 맞음) |
| 3차 | **회복방식** | **재생**: 매 턴 자동 회복 | **신성치유**: 자가 회복 스킬 강화 |
| 4차 | **신성딜** | **심판**: SPI 회복력 계수로 즉발딜↑ | **천벌**: 매 턴 누적 신성딜 (도트) |

### 설계 의도

- **단독전투라 모든 회복·가호는 자기 대상.** 아군힐·성역(아군 보호)은 전부 제거. → "느려도 자기 회복으로 끝까지 버텨 이기는" 자기 생존 캐스터.
- **2차 가호 = 생존 수단.** 회복으로 버틸까(회복량↑) ↔ 안 맞고 버틸까(받피감).
- **3차 회복방식 = 회복 타이밍.** 꾸준 자동(재생) ↔ 스킬 쓸 때 크게(신성치유).
- **4차 신성딜 = 딜 방식.** 즉발 ↔ 도트.
  - ⚠ **4A "심판"의 의미:** "스킬에 회복력 계수 추가" = **SPI의 회복력 스탯을 딜 계수로 추가** = 사실상 데미지 증가(회복 스탯이 딜로 환산). 회복형 스탯을 키운 신성법사가 그걸 공격에도 쓰는 컨셉.
- 신성법사는 **생존:딜 = 2:1**(2차 생존 + 3차 회복 vs 4차 딜)로 기울어 있음 — "딜보다 생존이 메인"인 정체성이라 의도된 기울기.

> 📌 **공동개발자 확인 권장:** 작업 중 3차 B극단이 원래 "스킬피해 증가"로 제안됐으나, 그게 1차 공용(스킬피해 증가)과 중복돼서 **"신성치유(자가 회복 스킬 강화)"로 바꿈.** 4차가 딜(심판·천벌)을 담당하므로 3차는 회복방식으로 분리하는 게 깔끔하다고 판단. 이 분리가 마음에 안 들면 재논의 가능.

### 시그니처
- **기도** — 확률 발동, 체력·마나를 적정량 회복. 쿨 없음. (딜이 아니라 회복 시그니처 — 생존 색에 맞음. 법사류 마나회복 계열.)

### sim 검증 노트
- §5에서 신술이 "느려도 끝까지 버텨 이김"으로 검증됨 → 단독 장기전 강함 재확인.
- 회복원 겹침(신성법사 힐 / 기공패 순환 / 배메 방어) → 셋이 "안 죽는 캐스터"로 수렴 안 하게 차별 확인.
- 회복 총량이 받는 피해를 못 넘게(무한생존 방지).
- 신성딜(SPI 기반)이 INT 마법보다 약할 텐데 "딜 약한 대신 생존"으로 보상되는지.
- 천벌(도트) ※ 미확정. §5 누적(+0.3) 컨셉은 검증됐으나 상태이상 시스템과 별개인지 확인.

# 순수마법 — 글래스캐넌 폭격 (지팡이)

| 항목 | 내용 |
|---|---|
| 무기 | 지팡이 |
| 역할 색 | **고데미지 글래스캐넌(방어 없음, 마나=탄약).** vs 배메=생존 섞은 딜 / vs 신성=회복 생존 |
| base | **중속** · 폭격형 |

### 차원

| 차수 | 차원 | A극단 | B극단 |
|---|---|---|---|
| 1차 | (공용) | 스킬 피해 증가 | — |
| 2차 | **위력질** | **안정**: 최소데미지 하한↑ (꾸준) | **폭발**: 데미지 폭↑ (평균↑·분산↑·운빨) |
| 3차 | **발동** | **연발**: 스킬 발동 확률↑ (자주) | **일격**: 발동 확률↓ · 발동 시 위력↑↑ (크게) |
| 4차 | **마나운용** | **지속**: 매 턴 마나 회복 (오래 쏨) | **과부하**: 마나 소모↑ + 스킬 데미지↑ (굵게·일찍 고갈) |

### 설계 의도

- **마나 = 탄약.** 모든 스킬이 MP를 소모하므로(`01` §4), 순수마법은 "강하지만 마나 관리가 필요한 폭격기". 시그니처가 마나회복기인 이유.
- **2차 위력질 = 분산.** 대검 치명 차원과 같은 구조(안정 vs 폭발). 평균은 폭발 쪽이 높지만 들쭉날쭉.
- **3차 발동 = 확률발동 운용.** 자주(연발) ↔ 크게(일격). 순수마법이 "발동"을 깊게 파는 유일 계파.
- **4차 마나운용 = 지속사격 ↔ 순간화력.** 오래 쏠까(지속) ↔ 굵게 쏘고 일찍 지칠까(과부하). 마나를 탄약으로 보면 글래스캐넌다운 트레이드오프.

### 미결정 (이 계파 한정)
- **속성:** 불(화염) 유지 vs 중립(그냥 마법 폭격) — 미정. (D5상 속성은 직교라 어느 쪽이든 플레이버.)
- **도트(소각):** 순수마법은 즉발 폭격이 색이라 **도트는 빼는 방향**(차별화). 4차가 마나운용이라 도트 자리도 없음. → 도트 유무 최종 확인 필요.

### 시그니처
- **마나회복기** — 확률 발동. 쿨 없음. (법사류 공통 계열.)

### sim 검증 노트
- 순수마법이 딜 1등이어야 배메가 "딜 양보하고 생존 챙김"이 성립 → 딜 최고치 보장.
- 3차 발동확률 운용이 자동전투 확률발동과 어떻게 맞물리는지.
- 마나 고갈 곡선(과부하 4B가 실제로 "일찍 고갈"되는지, 지속 4A가 "오래 쏨"을 보장하는지).

# 배틀메이지 — 마검 하이브리드 (마법검)

| 항목 | 내용 |
|---|---|
| 무기 | 마법검 |
| 역할 색 | **마공 + 방어 하이브리드, 평타·스킬 교차 운용.** vs 순수마법=글래스캐넌 / vs 신성=회복 생존 |
| base | **중속** · 마법검(**평타 = 물리·INT 스케일**, 스킬 = 마법) · 방어 보정 있음 · **양쪽(물방·마방) 방어를 다 상대** |

### 차원

| 차수 | 차원 | A극단 | B극단 |
|---|---|---|---|
| 1차 | (공용) | 스킬 피해 증가 | — |
| 2차 | **교차사이클** | **연계A**: 스킬 쓰면 다음 평타딜↑ | **연계B**: 평타 쓰면 다음 스킬딜↑ |
| 3차 | **운용속도** | **속도↑** (평타 자주) | **스킬시전확률↑** (스킬 자주) |
| 4차 | **자원운용** | **마검막**: 마나 소모 시 실드 획득 | **순환**: 매 턴 마나 회복 |

### 설계 의도 (★ "만능형 함정" 회피 경위 포함)

- 🔁 **배틀메이지는 원래 "물공+마공+방어 만능형"으로 구상됐으나 폐기.**
  - 만능형은 카운터를 다 무시하는 **단일 최적해**(고방→마공, 마방→물공, 맞아도→방어)가 되어 다른 11계파의 존재 이유를 약화시킴. + INT 하나로 물공까지 내면 스탯 효율이 2배라 압도적으로 강해짐.
  - "넓지만 얕게(각 전문가보다 약함)"로도 막기 어려워, **물공을 빼고 "마공+방어"로 좁혀** 함정 회피. → 현재 배메 = "마법으로 딜하면서 안 죽는 캐스터".
- **평타 = 물리(INT 스케일), 스킬 = 마법.** 마법검이 INT를 물리딜로 변환. → 평타는 적 물방, 스킬은 적 마방을 상대 → **양쪽 방어를 다 상대해야 함** = 자연스러운 페널티(만능 1등 방지 장치).
- **2차 교차사이클 = 마검사 정체성.** "스킬→평타→스킬" 엮어 쓰는 콤보 유도(연계A·B).
- **3차 운용속도 = 평타 자주 ↔ 스킬 자주.** 2차와 같은 "평타 vs 스킬" 계열 — 배메를 "평타-스킬 운용에 다 거는 계파"로 잡음(방어 축은 차원에 안 넣고 base/시그니처로). 이게 플레이어가 원한 그림(길 C).
- **4차 자원운용 = 실드 ↔ 마나회복.** 마법사라 MP가 많으니 "MP를 방패로(마검막)" 쓰는 게 마검사답고, 반격(전사·무도가 색)과 안 겹침.

### 시그니처
- **마검 가호** — 확률 발동, **마나 회복 + 받피감 버프**(회복량은 순수법사보다 적음). 쿨 없음. (법사 마나회복 계열인데 배메는 방어 버프가 붙는 변형 — 마공+방어 색에 맞음.)

### sim 검증 노트
- ★ **만능 방지:** 배메 딜 < 순수마법, 방어 < 탱 계파(검방·권갑). 어느 하나도 1등 아니게 — 무기 base로 조정.
- ★ **2차·3차가 둘 다 "평타 vs 스킬" 계열** → 진짜 다른 선택(딜 크기 vs 빈도)인지, 아니면 사실상 한 축인지 확인. 같으면 한 축 교체.
- ★ 3B 스킬시전확률 vs 순수마법 3A 연발(발동확률) **겹침** → 배메는 확률 폭을 작게(순수마법이 발동 전문). 수치로 차별.
- 교차사이클이 **확률발동 탓에 의도대로 도는지** — 스킬이 안 터지면 2A(스킬→평타딜↑)가 발동 안 함. 콤보가 실제로 도는지 sim.
- 마법검 평타=물리라 적 물방+마방 양쪽 상대(자연 페널티)가 실제로 작동하는지.

## 마법사 3계파 역할 직교 점검

| 계파 | 역할 | 무기 | 색 구분 |
|---|---|---|---|
| 신성법사 | 회복 생존 캐스터 | 성서 | 느림·SPI·회복 |
| 순수마법 | 글래스캐넌 폭격 | 지팡이 | 중속·INT·고데미지·마나탄약 |
| 배틀메이지 | 마검 하이브리드 | 마법검 | 중속·INT·평타스킬 교차·방어 |

- 세 생존/딜러가 **회복 생존(신성) / 딜 최고·물름(순수) / 딜 중간·방어(배메)**로 삼각 차별.
- 신성 회복 ↔ 기공패 순환 회복: **신성 힐(능동·SPI) vs 자원순환(MP↔HP)**으로 메커니즘 차별.
