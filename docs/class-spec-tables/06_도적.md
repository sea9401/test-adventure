# 06. 도적 (활 · 비수 · 단검)

공통 1차 패시브 = **치명 · 회피 증가** (⚠ 효과 2개 — `01` §5 참조). 규칙은 `00`·`01`. 모든 수치 [미정].

> ⚠ 도적 3계파는 회피·치명·중독(도트)에 의존 → **D1(명중모델)·D2(몹 분포)·속도 파생식·상태이상 시스템**이 미확정인 동안 수치는 거의 다 보류. 특히 단검(회피·치명·기습 전부)과 비수(중독 전체)가 미결정에 크게 걸림.

# 활 — 원거리 연사 (활)

| 항목 | 내용 |
|---|---|
| 무기 | 활 |
| 역할 색 | **연사 딜러.** vs 너클=근접 연타 / vs 비수=중독 / vs 단검=회피·치명 |
| base | **빠름** · 다타(다단감쇠) · 원거리 |

### 차원

| 차수 | 차원 | A극단 | B극단 |
|---|---|---|---|
| 1차 | (공용) | 치명 · 회피 증가 | — |
| 2차 | **연사질** | **속사**: 타수↑ (다단감쇠) | **일사**: 타수↓ · 타당 위력↑ |
| 3차 | **치명** | **치명**: 치명↑ (올인·운빨) | **안정**: 노치명 · 대신 데미지↑ (꾸준) |
| 4차 | **화살운용** | **연타완화**: 다단감쇠 덜 깎임 (다타 합↑) | **관통**: 방어관통 (고방 뚫기) |

### 설계 의도

- **2차 연사질 = 잘게 ↔ 굵게.** 너클 2차와 유사 구조지만 무기·직군 다름.
- **3차 치명 = 운빨 ↔ 꾸준.** B(안정)는 치명을 포기하는 대신 기본 데미지를 올려 분산을 줄임 → 진짜 트레이드오프(치명 올인 ↔ 치명 포기).
- **4차 화살운용 = 다타 합 ↔ 방어 뚫기.**
  - ⚠ **이 4차는 "약한 대립".** 연타완화(다타 강화)와 관통(고방 상대 딜)은 *포기 관계*가 아니라 *상황 선택*에 가까움(둘 다 딜 증가, 노리는 빌드가 다를 뿐). 타수를 건드리지 않는 한 연타완화의 깔끔한 반대극이 마땅찮아 이대로 둠. → **sim에서 "거의 항상 한쪽이 정답"으로 수렴하면 4B(관통)를 손봄.** `[sim 1순위]`
  - (※ 대검에서 "관통 양극단(방관↔위력)은 둘 다 딜증가라 무의미"로 폐기한 것과 같은 종류의 약점. 활에선 연타완화와 묶어 "약한 대립"으로 수용.)

### 시그니처
- **연속사격** — 확률 발동 + MP 소모, 다단 화살 폭발. 쿨 없음.

### sim 검증 노트
- 4A 연타완화 + 2A 속사 = 다타 중첩 과강 체크.
- ★ 4차 약한 대립(연타완화 ↔ 관통) — 한쪽 수렴 여부 확인.
- 다단감쇠 보정(속사·연타완화가 일사 대비 안 밀리게).
- 명중·치명·관통 PvE 의미는 D1·D2 의존.

# 비수 — 중독 스택 빌더 (비수)

> 🔁 무기명 변경: **독침 → 비수.** (키워드 중독·회피·연사 유지.)

| 항목 | 내용 |
|---|---|
| 무기 | 비수 |
| 역할 색 | **중독 스택 빌더. 차수↑ = 독 깊어짐. 초반 약·후반 강.** vs 활=순수 연사 / vs 단검=무조건 회피·치명 |
| base | **빠름** · 다타(독 바르기) · 다단감쇠 |

### 차원 (★ 차수마다 독 스택 최대치 +1)

| 차수 | 차원 | A극단 | B극단 | 부가 |
|---|---|---|---|---|
| 1차 | (공용) | 치명 · 회피 증가 | — | |
| 2차 | **독성질** ※ | **맹독**: 도트 계수↑ (독이 아픔) | **침식**: 독 스택당 방깎 (적 약화) | +독스택 최대치 1 |
| 3차 | **병행** ※ | **회피**: 독 스택당 회피↑ | **치명**: 독 스택당 치명↑ | +독스택 최대치 1 |
| 4차 | **만독운용** ※ | **작렬**: 독에 치명 터짐 (도트 크리) | **만독**: 독 최대치에서 독 걸면 추가딜 (풀스택 보상) | +독스택 최대치 1 |

### 설계 의도

- **차수마다 독스택 최대치 +1** = 성장하면 독이 깊어지는 장치. 차수 진행이 독에 자연히 녹음.
- **2차 독성질 = 도트로 직접 딜 ↔ 독으로 적 약화.** 침식(스택당 방깎)은 §2 관통 축과 연결 + D2 고방몹 카운터.
- **3차 병행 = 독 쌓으며 회피 ↔ 치명.** 스택 조건이 붙어서, 단검(무조건 회피·치명)과 **"스택 조건 유무"로 차별**됨.
- **4차 만독운용 = 꾸준 크리 ↔ 풀스택 한방.**
  - 작렬(도트가 크리) ↔ 만독(풀스택 도달 보상).
  - ⚠ **약한 대립:** 작렬(독 깔리면 언제든 발동·범용) 쪽이 더 안정적이고, 만독(만독 상태 전제)은 조건이 까다로움(빌드 의존). 둘 다 죽은 선택지는 아니나 4A가 무난 → 수렴 여부 확인.
- **2·3·4차가 전부 "독 스택" 기반** → 정체성은 선명하나 **초반(0스택)엔 거의 모든 패시브가 놀음.** 초반 무력 / 후반 강세가 극단적.

### 시그니처
- **맹독격** — 확률 발동 + MP 소모, 강한 중독 부여 or 중독 폭발. 쿨 없음.

### sim 검증 노트
- ★ **상태이상 시스템 의존 최상** — 비수는 도트가 정체성 전체. 시스템 미확정이면 수치 **전부 보류.** **상태이상 설계를 비수 검증 전에 당기는 것 강력 권장.**
- ★ **초반 무력 / 후반 강세 극단** → 전투 길이가 짧으면 비수가 스택 쌓기 전에 끝나 약체. **"비수가 제 몫 하는 최소 전투 길이" 1순위.**
- ★ 4A 작렬 = **"도트가 크리 가능한가" 규칙 필요**(보통 도트는 크리 안 뜸 — 시스템 설계 시 결정).
- ★ 4B 만독 = 자동전투에서 풀스택 도달이 현실적인지(적이 그 전에 죽으면 무용).
- 도트 vs 즉발 메타: 빨리 죽는 적엔 도트 손실(세검보다 심함).
- 2B 침식 = D2 고방몹 카운터로 유효.
- 도적 공용(치명+회피 2개)이 약간 셀 수 있음 → 4직군 공용 균형 점검 시 재검토.

# 단검 — 회피·치명 즉발 암살자 (단검)

| 항목 | 내용 |
|---|---|
| 무기 | 단검 |
| 역할 색 | **회피·치명 즉발 암살자. 무조건 회피/치명(비수=스택 조건).** vs 비수=도트 누적 / vs 활=원거리 연사 |
| base | **빠름** · 단검(근접·경량) · 즉발 폭딜형 |

### 차원

| 차수 | 차원 | A극단 | B극단 |
|---|---|---|---|
| 1차 | (공용) | 치명 · 회피 증가 | — |
| 2차 | **기조** | **회피 증가** | **치명 증가** |
| 3차 | **조건부 (교차)** | **회피 시 반격** (회피 → 딜) | **치명 시 회피증가** (치명 → 생존) |
| 4차 | **기습** (대검 마무리와 동일) | **암습**: 적 고HP/초반 딜↑ (선제) | **처형**: 적 저HP 딜↑ (마무리) |

### 설계 의도

- **2차 기조 = 회피 ↔ 치명.** 단검의 두 기둥. 비수 3차(스택 조건부)와 "조건 유무"로 차별.
- **3차 조건부 = 교차 설계 (★ 깔끔한 자기-약점 보완).**
  - 3A 회피 시 반격 = **회피(방어)를 딜로** 환산. 3B 치명 시 회피증가 = **치명(공격)을 회피(생존)로** 환산.
  - → 회피 빌드(2A+3A)는 딜이 부족한데 3A가 채워주고, 치명 빌드(2B+3B)는 물른데 3B가 생존을 채워줌. **각 빌드가 자기 약점을 스스로 메움** → 글래스캐넌 단검의 즉사 문제 완화.
  - 🔁 3B는 처음 "치명 시 피흡(흡혈)"이었으나 **기공패 흡혈과 겹쳐서 "치명 시 회피증가"로 변경.**
  - 차별 포인트: 3A "회피 시 반격"은 검방/권갑(**피격 시** 반격)과 **트리거가 정반대**(맞아야 vs 피해야)라 명확히 구분됨.
- **4차 기습 = 선제 ↔ 마무리.** 대검 4차와 동일 구조(적 HP 기반 상황형).

### 시그니처
- **암살** — 확률 발동 + MP 소모, **치명 확정 대형딜.** 쿨 없음. (시그니처 치명 확정 → 3B "치명 시 회피증가" 자동 트리거 = 시너지.)

### sim 검증 노트
- ★ D1(명중)·D2(몹)·속도식에 회피·치명·기습 전부 의존 → 수치 보류.
- 3B 회피증가의 지속 방식(지속시간/스택/영구) 정의 필요.
- 2·3차가 회피/치명 일관 → 회피형(2A+3A) vs 치명형(2B+3B)으로 깔끔히 갈림. 단 같은 방향끼리 묶여 "풀빌드"가 정답화될 수 있음 — 섞는 이득도 있는지 확인.
- 단검=즉발 폭딜 vs 비수=도트 누적 → 역할 차별. 자동전투 고DPS 메타선 단검(즉발)이 비수(도트)보다 유리할 수 있음 → **역할 불균형 체크.**

## 도적 3계파 역할 직교 점검

| 계파 | 역할 | 무기 | 색 구분 |
|---|---|---|---|
| 활 | 원거리 연사 | 활 | 빠름·다타·원거리 |
| 비수 | 중독 스택 빌더 | 비수 | 빠름·도트 누적·초반약후반강 |
| 단검 | 즉발 암살자 | 단검 | 빠름·회피치명·즉발 |

- 회피 겹침(비수·단검·너클): 비수=스택조건 / 단검=무조건 / 너클=4차 선택지(잠정)로 차별 시도.
- 연사 겹침(활·비수): 활=순수 딜용 연사 / 비수=독 바르는 연사로 목적 구분.
- **즉발(단검) vs 도트(비수)** = 도적 안의 핵심 역할 분기 — 자동전투 메타에서 균형 여부가 검증 핵심.
