# 07. 미결정 사항 · 검증 지표 · 다음 작업

12계파 골격은 완성. 이 파일은 **sim 돌리기 전에 정해야 할 것**과 **검증 지표**, 그리고 **남은 작업**을 모았습니다. 작업 착수 전 필독.

## A. sim 전에 정해야 할 시스템 (우선순위순)

### A-1. 상태이상(도트) 시스템 ★ 최우선
- 출혈·중독·소각·자동피해(도트)가 **아직 "추후"**. 현재 스탯 축만 깔림.
- 의존 계파: **세검(출혈)·기공패(자동피해)·비수(중독)** — 특히 **비수는 정체성 전체가 중독 스택**이라 시스템 없이는 검증 자체가 불가.
- 정해야 할 것:
  - 도트 지속 턴(가설: 출혈 3·중독 5·소각 2), 스택 규칙, 갱신/누적 방식.
  - **도트가 치명(크리)이 터지는가?** ← 비수 4A(작렬)가 이 규칙에 직접 의존.
  - 도트 데미지의 스케일 소스(공격력/스탯).
  - 5속성 순환 + 빛/어둠 연계 여부(D5와 연결, 추후여도 됨).
- **권장: 비수 검증 전에 상태이상 설계를 당길 것.**

### A-2. 속도 파생식 ★
- 템포(대검)·속공(세검·너클)·기습/선공·다회행동 등이 전부 의존.
- "속도 ±%"가 행동 순서에 실제 의미를 가지려면 속도→행동순서 산출식의 스케일이 정해져야 함. 이게 잡혀야 템포·속공 차원의 수치를 확정 가능.

### A-3. D1 명중모델 / D2 몹 분포 (전투 모델, sim 병렬 가능)
- D1: 선형식 `85 + 0.5×(명중−회피)` 클램프 채택 여부 + 상수 튜닝(`02` D1).
- D2: 회피몹·치명몹·고방몹·균형몹 도입(`02` D2). **이게 없으면** 다음 축들이 PvE 휴면:
  - 명중(활·세검 정밀), 회피(단검·비수·너클), 치명저항(신성법사 정화 컨셉), 관통(대검·활·비수 침식).
- C=0 명중상수 버그는 **즉시 수정**(설계 무관).

### A-4. MP 작동 규칙 명문화
- 이미 **"모든 스킬 발동 시 MP 소모 / 스킬=확률발동 / 쿨 없음"**으로 확정(`01` §4).
- 명문화할 디테일: 전투 시작 시 MP 초기값, 자연 재생 여부, 마나 0일 때 거동(평타만?), 회복 수단(법사 마나회복기·기공패 순환·순수마법 4A 지속).
- 기공패 음양순환·순수마법 마나운용·배메 자원운용이 전부 이 규칙 위에서 돎.

### A-5. 1차 공용 4직군 균형
- 전사=물공 / 무도가=최대HP / 마법사=스킬피해 / 도적=**치명+회피(2개)**.
- ⚠ 도적만 효과 2개 → 약간 셀 수 있음. 다른 직군과 균형 점검 후 하나로 줄일지 결정.
- 마법사 공용(스킬피해)이 신성법사(SPI힐)에, 무도가 공용(HP)이 너클(빠른 딜형)에 살짝 안 맞음 — 인지된 트레이드오프(공용은 약하게 무난한 게 정상).

## B. 계파별 sim 1순위 노트 (요약)

| 단검 | D1·D2·속도식 의존 / 즉발(단검) vs 도트(비수) 역할 균형 |

## C. 밸런스 검증 지표 (전 계파 공통)

기획 §7 "빠뜨리지 말 축"에서:

1. **전투 길이 균질성.** 12계파 빌드들의 전투 길이가 한 무리로 모이는지(스킬×0.5로 4~16턴 목표). 특히 **비수(초반약)·검방/권갑(느림)이 너무 길고, 즉발 딜러가 너무 짧지** 않은지.
2. **조합 수렴 여부.** 각 차원의 양극단이 실제로 갈리는지 — "거의 항상 A(또는 B)가 정답"이면 그 극단을 손봄. (약한 대립으로 표기된 곳: 활 4차, 비수 4차, 너클 2차 — 우선 관찰.)
3. **약축 구제.** 명중·치명저항·관통·회피·도트가 D1·D2·상태이상 시스템 도입 후 실제로 작동하는지(PvE 휴면 해제 확인).
4. **PvE / PvP 효용 분리.** 같은 빌드가 PvE·PvP에서 다른 가치를 갖는지(예: 회피 극단 스택의 PvP 불사 → D1 하한 40으로 방지).
5. **역할 직교.** 12계파가 딜/탱/지속/제어/유틸 역할이 겹치지 않는지(각 직군 파일의 "역할 직교 점검" 표 참조). 색 분리가 sim에서도 유지되는지.
6. **★ 도트 vs 즉발 메타 균형.** 자동전투가 "빨리 죽이는 게 이득"이면 도트 딜러(세검·비수·기공패 4B)가 즉발 딜러(대검·단검·순수마법)보다 구조적으로 불리할 수 있음. **이 축의 균형이 검증의 핵심.** 도트가 약하면 도트 계수↑ 또는 적 HP 풀(전투 길이)로 보정.
7. **무한 생존 방지.** 회복원이 여럿인 계파(기공패·신성법사)에서 회복 총량이 받는 피해를 못 넘게 상한.
8. **확률발동 분산.** 시드 고정으로 재현은 되나, 시그니처·확률 패시브 비중이 큰 계파의 판별 편차가 받아들일 만한지.

## E. 다음 작업 (제안 순서)

1. **무기 base 비교축 표 (§7.3 산출물) — 우선순위 높음.**
   - 12무기의 위력 / 무게(→속도) / 타격패턴(단일·다타·원거리) / 고유특성을 **한 표**에.
   - 이게 **밸런스 핵심 레버**(원칙 §6.4: 계파가 세면/약하면 패시브 말고 무기 base로만 조정). 계파 수치 손 안 대고 잡는 유일한 손잡이.
2. **상태이상 시스템 설계** (A-1) — 비수·세검·기공패 검증의 전제.
3. **속도 파생식** (A-2) — 템포·속공 수치의 전제.
4. **임시 데이터 세트** (§7.5): sim 검증용 가짜 장비/무기효과/몬스터 풀(전부 "테스트용·확정 아님" 태깅). 특히 **D2 4원형 몹**(회피/치명/고방/균형)으로 대항축 검증.
5. **차수별 해금·장착표 + 리스펙 비용** 문서화.
6. (선택) **12계파 종합 1페이지** — 차원 전부 모아 겹침·역할 분포 최종 점검.

## F. 한 줄 인계 요약

> 12계파 × (1차 공용 1 + 2·3·4차 차원 각 양극단 2 = 배움 7, 누적 장착 4)의 **구조와 방향·의도는 확정.** 수치는 전부 [미정]으로 비워뒀고, **상태이상 시스템·속도식·D1/D2·무기 base**가 정해지면 sim으로 채우면 됩니다. 약한 대립으로 표기한 차원(활 4차, 비수 4차, 너클 2차)과 도트 vs 즉발 메타 균형이 검증 1순위입니다.
