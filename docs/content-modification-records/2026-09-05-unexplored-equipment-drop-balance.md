# 2026-09-05 미개척지 장비 드랍률 조정 기록

## 기록 상태

- 상태: `recorded`
- 의미: 게임 내용 변경을 저장소에 기록했으며, 공식 내용수정신고 필요 여부는 운영자가
  후속 판단한다.

## 변경 내용

- 미개척지 일반 사냥이 재사용하는 별의 무덤 84단계 장비 풀은 유지한다.
- 미개척지의 무보정 장비 1개 이상 획득 확률을 승리당 `0.05%`, 즉 기대값 기준
  2,000승당 1개로 낮춘다.
- 시그니처 유니크 총 확률 `0.0035%`는 유지하고, 일반 방어구 총 확률을 약
  `0.0465016%`로 조정해 두 독립 굴림의 합산 확률이 정확히 `0.05%`가 되게 한다.
- 별의 무덤 일반 사냥, 미개척지 개척자 무기, 개인 보스 고유 장비 확률은 변경하지 않는다.
- 탐사망 노드와 장비 해방에 따른 추가 보정은 기존 규칙대로 적용한다.
