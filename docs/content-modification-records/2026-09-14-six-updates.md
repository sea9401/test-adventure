# 2026-09-14 미배포 6건 운영 통합 기록

## 배포 범위

사용자가 스쿼시한 `fbcc034e1e7667e5aff11f02aed48b2d78e90e07`의 6건을
운영 기준 `38412cb5ead5be3ba47bf9396d8d54b8baed786f`에 통합한다.

- 사냥·랭킹 계산 중 이벤트 루프를 양보한다. 50회 사냥과 지원권별 기존 상한,
  보상·재생 로그·트랜잭션·동일 사용자 중복 요청 차단을 유지한다.
- 멸검을 전투당 최대 3회 사용할 수 있도록 하고 기존 24 SP를 유지한다.
- 그림자 도약이 사용자가 지정한 조건·순서·제외 설정을 따른다.
- 숙련의 탑 체크포인트를 주간 경계에서도 유지하고 역대 기록으로 복구한다.
- 닭장·외양간의 사료를 한 번에 채우는 기능을 추가한다.
- 파괴 확률이 있는 장비 강화에 위험 확인창을 추가한다. 이전에 운영에서 되돌린
  기능이지만 이번 사용자의 전체 6건 스쿼시 및 배포 요청에 포함된다.

## 운영 구현 보존

기존 운영의 분리된 전투 스킬 모듈, 사냥 HTTP 경계, 희귀 지도 복귀와
성능 계측을 보존한다. 멸검 변경은 `engine.playerSkills.ts`와
`engine.pvpSkills.ts`, 사냥 실행 양보는 `huntRequest.ts`에 적용한다.
랭킹 계산 계측은 비동기 계산 완료까지 기다리도록 유지한다.
DB 스키마와 결제·지원권 가격은 변경하지 않는다.

## 변경 기록 구분

게임 스킬 사용 규칙과 편의 기능 변경을 포함하므로 `recorded`를 사용한다.
이 문서는 내부 변경 기록이며 외부 기관 신고 접수나 완료를 뜻하지 않는다.

## 검증·배포 절차

통합 후 관련 회귀 테스트 18개 파일·279개 케이스 및 모듈 크기 제한 64개를
확인했다. PR 및 정확한 main SHA의 전체 CI와 production-next 산출물을 검증한
뒤 기존 배포 워크플로를 실행한다. 산출물 준비 전에는 기존 서비스를 유지한다.
사용자는 배포 완료 후 점검 모드 해제를 명시적으로 요청했다. 배포 정상 완료와
스모크 검증 뒤 점검을 해제하고 공개 서비스 상태를 확인한다.
