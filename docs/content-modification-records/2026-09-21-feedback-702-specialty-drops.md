# 2026-09-21 미개척지 특화 장비 드랍 누락 수정

## 기록 상태

- 상태: `recorded`
- 이 문서는 내부 변경 기록이며 공식 내용수정신고 접수 증빙이 아니다.
- 사용자 요청: 피드백 #702 수정 배포 및 배포 검증 완료 후 점검 모드 해제.

## 변경 내용

- 기존 신규 12세트·36종의 누락된 드랍을 실제 미개척지 특화 몬스터 보상에 연결한다.
- 특화 몬스터마다 지정 장비 1종을 처치당 기본 0.4%, 해당 군 집중 강화 시 0.6%로
  독립 판정한다. 기존 설계 확률을 복구하며 일반 장비 배율·희귀 복사는 적용하지 않는다.
- 기본 몬스터, 일반 사냥, 희귀 지도에는 이 드랍을 적용하지 않는다.
- 인벤토리 저장, 중복 획득과 일괄 사냥은 기존 장비 지급 경로를 사용한다.
- 노드 보상 목록에 지정 몬스터와 장비 확률을 표시하고 오래된 매뉴얼 안내를 수정한다.
- 개척자 방어구·장신구 제작 및 개척자 무기 드랍, 장비·세트 능력치, DB 형식은 그대로다.

## 검증

- 구현 전 36종 누락과 단판·일괄 지급 실패 및 노드 미리보기 누락 재현.
- 관련 15개 테스트 파일 386개 통과, 전체 타입 검사 및 변경 파일 ESLint 통과.
- 배포 시 병합된 정확한 main SHA의 전체 CI와 `production-next-<SHA>` 산출물을 확인한다.
- 준비 중 기존 서비스를 유지하고, 배포 워크플로가 런타임 교체 직전에 점검을 활성화한다.
- 배포 성공·운영 버전·health 확인 뒤 이번 사용자의 명시적 지시에 따라 점검을 해제한다.

## 운영 영향 및 후속 판단

DB 마이그레이션은 없다. 수정 전에는 획득 불가능했던 기존 장비가 드랍되므로 내부
변경 기록 상태로 배포한다. 공식 신고 필요 여부와 제출 절차는 운영자의 후속 판단이며,
현재 공식 접수번호는 없다. 롤백 시 이전 정상 배포 SHA의 검증된 빌드를 사용한다.
