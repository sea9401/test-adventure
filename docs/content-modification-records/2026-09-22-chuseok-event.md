# 2026-09-22 추석 이벤트와 조작 개선

## 기록 상태

- 상태: `recorded`
- 이 문서는 내부 변경 기록이며 공식 내용수정신고 접수 증빙이 아니다.
- 사용자 요청: 검토한 스쿼시 작업물을 운영에 배포하고 완료 후 점검 모드를 해제한다.
- 원본 스쿼시: `0652851ebeb99efe51e715ed2e9a270adf4a4a88`.
- 기존 운영 변경을 보존하기 위해 최신 main 위에 원본 스쿼시만 적용한다.

## 변경 내용

1. 시작 시각부터 240시간 동안 진행하는 추석 이벤트를 추가한다.
2. 한국 시간 날짜당 한 번, 누적 7회 출석으로 회복약 총 80개를 지급한다.
3. 전 서버가 공유하는 복주머니 토벌에 하루 3회 참여할 수 있다. 첫 공격 이후 처치마다 참여자에게 회복약 15개를 우편으로 지급한다.
4. 출석과 복주머니 화면을 하위 탭으로 분리하고 전용 복주머니 이미지를 표시한다.
5. 아이템 비교창을 게임 공지보다 위에 표시한다.
6. 거대 낚시에서 버튼 포커스 없이 Enter·Space로 조작하고 입력창·다른 버튼의 키 입력을 보존한다.

## 운영 영향과 검증

- `0185_chuseok_event.sql`은 이벤트·참여자·멱등 공격 기록 테이블을 추가한다. 기존 테이블과 데이터를 삭제하지 않는다.
- 새 테이블 3개를 기존 게임 초기화 도구의 게임 진행 데이터 분류에 등록한다. 배포 과정에서 초기화 도구를 실행하지 않는다.
- 운영 일정은 `CHUSEOK_EVENT_STARTS_AT`으로 지정하며 최초 저장 뒤에는 환경변수 변경으로 연장되지 않는다. 설정 절차는 `docs/chuseok-event-operations.md`에 기록한다.
- 원본 검토에서 관련 테스트 105개, TypeScript, 변경 파일 ESLint, 마이그레이션·이미지 검사가 통과했다. 전용 DB 통합 테스트 9개는 해당 검토에서 미실행했다.
- 통합 브랜치 PR CI와 병합 후 정확한 main SHA의 전체 CI 및 `production-next-<SHA>` 산출물을 확인하고 기존 운영 워크플로로 배포한다.
- 준비 중 기존 서비스를 유지한다. 런타임 교체 직전에 점검을 활성화하고, 배포 및 스모크 성공 후 사용자의 명시적 요청에 따라 점검을 해제한다.
- 게임 이벤트와 보상이 추가되므로 내부 변경 기록 상태로 배포한다. 공식 신고 필요 여부와 제출 절차는 운영자의 후속 판단이며 공식 접수번호를 기재하지 않는다.
