# 2026-09-26 피드백 714·715 및 철갑 전열 표시 개선

## 기록 상태

- 상태: `recorded`
- 이 문서는 내부 변경 기록이며 공식 내용수정신고 접수 증빙이 아니다.
- 사용자 요청: 세 미배포 코드 변경을 한 커밋으로 통합해 운영에 배포하고, 완료 후 점검 모드를 해제한다.

## 변경 내용

1. 길드가 주당 3,000만 골드로 길드원 지원품을 구매하면 현재 길드원에게 귀속 스태미나 회복약 3개를 수령할 수 있는 우편을 보낸다.
2. 수련 능력치의 기본값, 효과 적용값과 한계를 함께 표시한다.
3. 고대 유물 보상, 아레나 칭호 등 일부 안내 문구를 실제 결과에 맞게 고친다.
4. 연쇄 구동의 추가 공격을 전투 로그에서 식별하고 세트 효과 설명을 보강한다.
5. 도감의 별의 무덤 방어구 획득 확률 안내를 깊이별 수치에 맞게 표시한다.
6. 철갑 전열의 방어력 누적 증가와 현재 수치를 PvE 전투 로그·다시보기에 표시한다. 숙련의 탑 철벽 태세 반사 동작은 회귀 테스트로 확인했다.

독왕의 양면침 독 폭발 계산은 변경하지 않았다.

## 검증과 배포 절차

- 통합 브랜치의 관련 테스트 13개 파일, 482개 테스트와 타입 검사, 변경 파일 린트가 통과했다.
- 로컬 전체 테스트는 프로세스가 종료되어 완료 결과를 얻지 못했다. PR과 병합된 정확한 `main` SHA의 전체 CI를 확인한다.
- 해당 SHA의 `production-next-<SHA>` 산출물을 기존 운영 배포 워크플로로 설치한다.
- 워크플로가 런타임 교체 직전에 점검 모드를 켜고, 배포 검증 완료 후 사용자 지시에 따라 점검 모드를 해제한다.

## 운영 영향 및 후속 판단

길드 지원품 지급은 게임 보상 변경이므로 내부 변경 기록 상태로 배포한다. 신규 DB 마이그레이션과 의존성 변경은 없다. 공식 신고 필요 여부와 제출 절차는 운영자의 후속 판단이며 현재 공식 접수번호는 없다.
