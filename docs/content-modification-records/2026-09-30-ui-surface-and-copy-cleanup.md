# 2026-09-30 UI 표면·문구 정리

## 기록 상태

- 상태: `recorded`
- 묶음 브랜치: `release/anti-slop-ui-20260930` (main 스쿼시 머지 예정)
- 사용자 요청: 정리한 변경을 운영에 배포하고 배포가 완료되면 점검 모드를 해제한다.
- 이 문서는 내부 변경 기록이며 공식 내용수정신고 접수 증빙은 아니다.

## 변경 내용

1. 화면 패널·목록 행의 반투명 배경을 불투명 배경으로 바꾼다. 격자 던전은 화면 전체에 불투명 어두운 배경을 주어 라이트 모드에서 제목이 읽히지 않던 문제를 고친다.
2. 카드 위·옆의 여러 색 장식 띠를 의미 색 한 가지로 바꾸고, 강화 결과 광택 효과를 무한 반복에서 2회 재생으로 줄인다. 거래소 적용 필터 칩과 장인 순위 보상 칩의 색을 정리한다.
3. 플레이어에게 보이는 문구에서 문장 사이 긴 줄표(—)를 뜻에 맞는 쉼표·괄호·콜론·두 문장으로 바꾼다. 대상은 매뉴얼, 협동 보스 패턴 설명, 장비 고유 효과 설명, 스킬 상세, 알림, 전투 로그, 우편 제목이다. 수치와 효과의 의미는 바꾸지 않는다.
4. 개발 용어가 드러난 문구("리워크", "선택한 상점만 불러옵니다" 등)와 제목을 되풀이하는 부제, 캐릭터 생성 화면의 중복 제목을 정리한다.
5. 운영체제의 동작 줄이기 설정에서 깜박임 애니메이션을 멈추고, 협동 보스 상세의 다음 발악 단계 칩이 계속 깜박이지 않게 한다.

## 검증 및 운영 영향

- 전투 규칙, 스킬 수치, 드랍·보상, 경제 수치, 확률은 바꾸지 않는다. 전투 골든마스터는 로그 문구만 바뀌었고, 로그에서 문구를 뺀 결과가 변경 전 코드와 완전히 같음을 확인했다.
- 문구·표시 변경이 플레이어 화면에 보이므로 `technical-only`가 아닌 내부 기록 상태로 배포한다.
- 신규 DB 마이그레이션, 의존성, 환경 설정 변경은 없다. 이미 발송된 우편 제목은 바뀌지 않고 이후 발송분부터 새 문구가 적용된다.
- 로컬에서 전체 단위 테스트(11,317건), 타입 검사, 변경 파일 lint를 통과했다. 배포 전 PR CI와 정확한 main SHA의 전체 CI 및 운영 빌드 산출물을 확인한다.
- 기존 배포 워크플로가 산출물 검증·전송 후 런타임 교체 직전에 점검 모드를 켠다. 배포 검증이 성공하면 이번 사용자 지시에 따라 점검을 해제하고 공개 표면을 다시 확인한다.
- 공식 신고 필요 여부와 제출 절차는 운영자의 후속 판단이며 현재 공식 접수번호는 없다.
