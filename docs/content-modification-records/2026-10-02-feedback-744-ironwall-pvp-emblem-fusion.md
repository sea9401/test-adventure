# 2026-10-02 피드백 744(724 누락) 아레나 철벽 누적 로그·문장 합성 화면

## 원인

피드백 724의 두 요청이 다른 기능으로 해석되어 처리됐다.

- "철갑누적"은 철갑 전열 3세트 효과(철벽 누적)였지만, 9월 29일 배포분은 금강의 강체 패시브를 PvP에 적용하는 수정이었다. 철벽 누적은 PvP에서 이미 누적·방어 반영이 되고 있었으나, 9월 26일 로그 추가가 PvE에만 들어가 아레나에서는 로그가 없었다.
- "문장 UI·합성"은 문장 화면의 합성이었지만, 같은 배포분은 대장간 조합 화면을 고쳤다. 문장 화면은 9월 20일 이후 바뀌지 않았다.

## 변경 내용

1. 아레나·친선전·대회에서 철갑 전열 3세트의 방어력 누적이 늘 때 PvE와 같은 형식으로 `[철벽 누적] 이름 방어 +증가 (누적 +합계)` 로그를 남긴다. 일반 공격은 타격마다, 직접 피해 스킬은 받은 스킬 한 번에 한 줄로 합산한다. 상한에 막혀 늘지 않으면 남기지 않는다. 누적 수치와 피해 계산은 바꾸지 않는다.
2. 문장 화면에서 합성 확인(성공률, 재료 선택, 합성 실행)을 화면 상단이 아니라 선택한 문장 카드 안에 연다.
3. 합성·장착 결과와 실패 안내를 해당 문장 카드 안에 표시하고, 정렬로 카드 위치가 바뀌어도 결과가 화면에 보이도록 스크롤한다. 슬롯 해제 결과는 기존처럼 상단에 표시한다.

## 검증

- 회귀 테스트를 먼저 추가해 실패를 확인한 뒤 수정했다(PvP 철벽 누적 로그 p1·p2 대칭, 문장 합성 확인·결과의 카드 내 표시).
- 전투·PvP·골든마스터·문장·표면 감사 관련 173개 파일, 2,331개 테스트와 타입 검사, 변경 파일 린트가 통과했다. 로컬 전체 테스트는 돌리지 않았으며 PR CI에서 확인한다.
