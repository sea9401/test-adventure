## 변경 내용

### 게임 규칙·보상

1. 전투 패턴 조건에 상대의 장착 무기 종류와 최대 MP를 추가한다(#722). 아레나 등 PvP에서
   상대 정보가 있을 때만 충족되며, 정보가 없으면 다음 블록으로 넘어간다.
2. 미개척지 난이도-보상 노드의 난이도 합산을 25까지만 적용하고, 남은 난이도만큼 보상
   보정도 비례해 줄인다. 위쪽 특화 경로에서 심부 외곽으로 들어가는 연결을 하나 추가한다(#726).
3. 미개척지 개인 보스는 소환자만 공격할 수 있으므로 무료 지원을 차단한다. 설정 API가
   `support_locked`로 거절하고 화면에서 지원 설정을 숨긴다.
4. 필드 사냥 일반 드랍 장비를 제작소에서 해체해 티어에 맞는 공용 재료 1개를 돌려받을 수
   있게 한다. 대장장이 숙련도는 주지 않는다(#746).

### 이름·표시·로그

5. 주교 스킬 이름을 "주교의 축도"로 바꾼다(#743). 9월 28일 작업(#726)이 같은 이름 겹침을
   "대주교의 성역"으로 고쳤으나 이후 결정인 #743을 따른다. 스킬 ID는 유지한다.
6. 옛 기본 스킬 강타·회복·행운을 내려치기·숨 고르기·행운의 기운으로 바꿔 직업 스킬과 이름이
   겹치지 않게 한다. 스킬 ID는 유지한다.
7. PvP에서 철벽 누적 증가를 전투 로그에 남기고, 문장 합성 결과를 선택한 카드 안에 보여 준다
   (#744). 누적·피해 계산은 그대로다.
8. 바람 정령의 MP 회복을 전투 로그에 남긴다(#730).
9. 기류(바람 흐름) 패시브의 중첩 규칙(#723), 미개척지 희귀 보상 보정의 적용 범위(#736),
   기본 성장 한계 표기(#726)를 설명 문구로 명확히 한다.
10. 활성 특화 풀 카드에 집중 강화 적용 여부를 표시한다. 드롭 계산은 바뀌지 않는다.

### 화면

11. 설정에서 "화면 스타일"(클래식·금빛)을 고를 수 있게 한다. 기본값은 클래식이며, 금빛은
    대문의 니어블랙·금색을 게임 화면으로 확장하고 제목에 명조를 쓴다. 이 브라우저에 저장된다.
12. 캐릭터·마을·전투·광장 메뉴를 한 카드 안의 행과 시설 그림으로, 사냥터 목록에 지역 그림을,
    기본 정보·상세 스탯·생활 기록의 숫자 상자를 라벨·값 행으로 바꾼다. 클래식에도 적용된다.
13. 손으로 칠한 주 버튼 8곳과 홈 랭킹 탭을 공용 색 토큰으로 옮긴다. 쿠폰·길드 창단·캐릭터
    생성 버튼은 클래식에서 남색에서 보라로 바뀐다.

### 보안

14. Next.js를 16.3.3에서 16.3.8로, `eslint-config-next`를 같은 버전으로 올린다. 9월 30일
    공개된 critical 권고 GHSA-vcvr-r3jv-pc5j(`next/og` `ImageResponse` 원격 코드 실행,
    16.2.0 이상 16.3.6 미만)가 PR 필수 검사의 의존성 점검을 막았다. 코드에서 `next/og`·
    `ImageResponse` 사용처는 찾지 못했으나 운영 버전이 해당 범위라 함께 올린다.
    `public/third-party-notices.txt`는 `npm run update-licenses`로 다시 만들었다.

## 검증 및 운영 영향

- 게임 규칙·보상 변경(1~4)이 포함되므로 `technical-only`가 아닌 내부 기록 완료 상태로 배포한다.
- 의존성 변경은 Next.js 패치 업그레이드(14번)뿐이다. 신규 DB 마이그레이션, 환경 설정, 배포 설정 변경은 없다.
- 업그레이드 후 로컬에서 의존성 권고 점검, 라이선스 고지 점검, 전체 lint(오류 0, 새 규칙 경고 3)를 통과했다. 16.3.3 빌드 캐시가 남은 `.next`에서는 글꼴 모듈 해석 오류가 났고, 캐시를 지운 새 빌드는 통과했다. CI와 운영 배포는 새 빌드 산출물을 쓴다.
- 통합 브랜치에서 `tsc --noEmit`, 전체 단위 테스트, 변경 파일 lint, 이미지 참조 검사,
  `next build`를 통과했다.
- 전투 골든 스냅샷은 #722가 `PlayerCombat`에 장착 무기 종류를 더한 4줄만 갱신했고 전투 결과
  스냅샷은 바뀌지 않았다.
- 화면 스타일의 클래식 회귀는 변경 전후 `/dev` 미리보기 캡처를 픽셀 비교해 확인했다(메뉴·
  목록 정리처럼 의도한 변경 화면 제외).
- 공식 신고 필요 여부와 제출 절차는 운영자의 후속 판단이며 현재 공식 접수번호는 없다.
