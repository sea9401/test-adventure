# 2026-10-11 배포 후속 안내 정정(매뉴얼 원정·골렘 중량·단련 촉매)

## 기록 상태

- 상태: `recorded`
- 사용자 지정 묶음: `fix/post-release-docs-20261011` 브랜치의 단일 스쿼시 커밋.
- 사용자 요청: 10월 11일 배포(#2577) 내용이 매뉴얼과 공개 정보에 제대로 들어갔는지 점검하고 빠진 곳을 고쳐 배포한다.
- 이 문서는 내부 변경 기록이며 공식 내용수정신고 접수 증빙은 아니다.

## 변경 내용

1. 길드 매뉴얼의 탐사 본부 원정 표 설명이 "원정대는 한 번에 하나만 파견"으로 남아 Lv.8 동시 파견 규칙과
   어긋났다. 표 설명을 고치고, 새 원정의 길드원 전원 보상(스태미나 회복약·보스 소환서)을 표에 표시한다.
2. 골렘 1~6차 직업 위키에 중량 순환 규칙(중량 0~3, 중량 1당 직접 물리 스킬 피해 +5%·속도 −5%, 해방 효과
   발동 조건)과 예시를 추가한다.
3. 강화 매뉴얼에 단련 촉매 사용 규칙(시도 1회 1개, 하락 확률 최대 10%p를 유지로 전환, 하락 없는 구간 불가)과
   강화석 입수처(길드 연금 공방·교역소)를 추가한다.
4. 생활 매뉴얼 요약에 생활 축제와 생활 전공을 넣는다.
5. 내부 직업 조직도 생성 스크립트가 7차 직업 스킬을 표시하도록 고친다. 게임에는 영향이 없다.

## 검증 및 운영 영향

- 게임 규칙, 수치, 보상, 확률은 바꾸지 않는다. 매뉴얼 문구만 바뀐다.
- DB 마이그레이션, 의존성, 환경 설정, 배포 설정 변경은 없다.
