## 변경 내용

### 콘텐츠·보상

1. 업적 → 장비와 도감에 "마법부여에 쓴 골드" 업적 7단계를 추가한다. 마법부여와 마법부여 이전에 쓴 골드를
   합산하며, 기존 마법부여·이전 요청 영수증의 사용 골드를 합산해 업적 추가 전 사용분도 반영한다. 목표는
   1,500만·1억 5천만·7억 5천만·15억·30억·75억·150억 G, 점수는 5·10·20·30·40·50·60점(합 215점)이다.
   1억 5천만·7억 5천만·30억·150억 단계는 각각 브론즈·실버·골드·레전더리 대표 배지가 된다. 업적 점수 랭킹도
   같은 합계로 계산한다(#793).

### 편의·안내

2. 미개척지 탐사망에서 난이도 노드가 120단 상한에 걸려 보상이 덜 반영되면 점선 테두리로 표시한다. 노드 상세에
   미적용·일부 적용(예: 난이도 +3 중 +1) 안내와 활성화 전 미리보기를 보여 주고, 현재 보상 보정 패널에 해당
   노드 개수를 표시한다. 매뉴얼 사냥 페이지에 난이도 노드와 120단 상한 규칙을 추가한다. 반영 규칙 자체는
   바뀌지 않는다(#795).

## 검증 및 운영 영향

- DB 마이그레이션, 의존성, 환경 설정, 배포 설정 변경은 없다. 세이브 형식 변경도 없다.
- 보상 변경: 업적 최대 점수가 215점 늘어난다. 업적 자체는 칭호·골드 보상을 주지 않는다. 그 밖의 확률·가격·
  판매세·전투 수치 변경은 없다.
- 업적 집계는 기존 `equipment_liberation_requests` 영수증을 사용자별로 합산하는 읽기 전용 쿼리다.
- 검증: 정적 검사(check-secrets·action-pins·images·asset-rights --strict·licenses·migrations·module-budgets·
  production advisories), tsc, eslint, 관련 vitest 327 통과, `npm run build`. #793 브랜치 단독으로 전체 vitest를
  돌렸을 때 실패 6건은 부하로 인한 시간 초과 5건과 버전 확인 호출 횟수 단언 1건이었다. 버전 확인을 포함한
  3개 파일은 단독 재실행에서 통과했고, 장시간 시뮬레이션 2건은 다시 돌리지 않았다. 로컬 E2E는 돌리지 않았다.
