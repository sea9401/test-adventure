# 2026-10-22 태초의 성소 하드 난이도 추가

## 기록 상태

- 상태: `recorded`
- 사용자 요청: 문장 수급이 너무 어렵다는 의견에 대해, 기존 드랍률·합성률은 그대로 두고 난이도를 크게 올린
  하드 난이도를 추가해 그곳에서만 드랍 개수·드랍률·2·3등급 확률을 올린다.
- 이 문서는 내부 변경 기록이며 공식 내용수정신고 접수 증빙은 아니다.
- 원본 브랜치: `feat/sanctuary-hard`(기능 a78bfeca4, 수치 조정 d40d7dc09).

## 변경 내용

### 콘텐츠·보상

1. 태초의 성소에 입장할 때(일괄 진행 포함) 노말과 하드 중 하나를 고른다. 하루 입장 3회는 두 난이도가 함께
   쓴다. 고른 난이도는 그 탐험이 끝날 때까지 유지되며 경로·선택 지점·귀환 규칙은 노말과 같다.
2. 하드의 몬스터는 노말보다 몬스터 깊이 24단계만큼 강해진다(체력 약 4~6배, 공격 약 3.3~3.7배, 방어·명중도
   함께 상승).
3. 하드 문장 보상: 일반 전투 10%(노말 5%), 정예·수호자 30%(노말 15%), 최종 보스 2개 확정(노말 1개), 등급
   확률 1등급 70%·2등급 25%·3등급 5%(노말 89%·10%·1%). 끝까지 깼을 때 기대 개수는 노말 1.5개, 하드 3.0개다.
   노말의 확률과 문장 합성 성공률은 바뀌지 않는다.

### 화면·안내

4. 성소 화면에 난이도 선택, 선택한 난이도의 확률 안내, 진행 중인 탐험의 난이도, 최종 보스 확정 개수를
   표시한다. 일괄 진행 결과에 회차별 난이도를 표시한다.
5. 매뉴얼 사냥 페이지에 난이도별 문장 확률표를 추가하고, 문장 화면 규칙 안내에 하드 등급 확률을 추가한다.
