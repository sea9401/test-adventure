# 2026-11-12 무슨 코인 상점 공개

## 기록 상태

- 상태: `recorded`
- 사용자 요청: 2026-11-12 라이브 결제 확인(1단계)을 마친 뒤 상점을 바로 공개한다. 카카오페이 미노출과 국민카드 심사는
  공개를 막지 않는 사항으로 보류한다.
- 이 문서는 내부 변경 기록이며 공식 내용수정신고 접수 증빙은 아니다.

## 변경 내용

1. 추적되는 `.env.production`에서 `NEXT_PUBLIC_MUSEUN_COIN_SHOP_OPEN`을 `false`에서 `true`로 바꾸고
   `NEXT_PUBLIC_MUSEUN_COIN_PAYMENTS_LAUNCH_DATE`에 `2026-11-12`를 적는다.
2. 로그인한 모든 이용자에게 무슨 코인 상점 메뉴, 충전 화면, 결제·환불 요청, 상점 관련 안내(퀘스트 튜토리얼 탭의
   성장 도약 패키지 안내, 교환소의 상점 연결)가 보인다. 지금까지는 운영자와 심의 계정 3개에만 보였다.
3. 이용약관 제7조의 머리 문단이 사전 안내("아직 운영 환경에서 활성화되지 않았습니다")에서 결제 시작일 표기
   ("2026년 11월 12일부터 운영")로 바뀐다. 제7조의 각 호(사용·환불 기한, 환불 수단, 양도 금지 등)는 바꾸지 않는다.
4. 비로그인 요청의 응답이 바뀐다. 상점 화면은 404 대신 로그인 화면으로 이동하고 상점 API는 404 대신 401을 돌려준다.

상품 구성, 가격, 코인 지급량, 환불 기준, 판매세와 스태미나 관련 수치는 이번에 바꾸지 않는다. 상품과 가격은 이미 공개된
상품 안내 페이지(`/products/museun-coin`)와 같다. 충전 단위는 1,000·2,000·3,000·5,000코인이고 1코인은 10원이다.

## 검증 및 운영 영향

- DB 마이그레이션, 의존성, 코드 로직 변경은 없다. 설정 두 줄과 그 상태를 가정한 브라우저 테스트 기대값만 바꾼다.
- 운영 런타임 env(SSM `/adventure-rpg/production/env`)는 2026-11-12 09:08 KST에 버전 4로 이미 바꿨다
  (`MUSEUN_COIN_PAYMENTS_MODE=live`, 라이브 키, `PG_HOMEPAGE_REVIEW_MODE=false`). 이번 배포에서는 바꾸지 않는다.
- 운영 사전검사는 "열린 상점 + `test` 결제"만 막는다. 지금 런타임은 `live`와 라이브 키라서 통과한다.
- 1단계 검증(2026-11-12, 상점 비공개 상태): 운영자 계정으로 1,000코인(10,000원)을 신용카드로 결제해 지급을 확인했고,
  미사용 상태로 환불을 요청해 자동 취소와 코인 회수를 확인했다. 우리 주문 기록과 토스 결제 조회(승인 `DONE` 10,000원,
  취소 `CANCELED` 10,000원)가 일치했고 승인·취소 웹훅을 모두 받았다.
- 결제창에 보이는 수단: 신용·체크카드, 토스페이, PAYCO. 카카오페이는 계약에는 선택돼 있으나 결제창에 보이지 않는다.
  국민카드는 카드사 심사 중인데 카드 목록에 보이며 결제하면 실패할 수 있다. 두 건은 오너 결정으로 보류했고 안내 문구는
  넣지 않았다. 토스 확인 결과에 따라 후속 변경에서 다룬다.
- 심의 때 만든 테스트 결제 기록(2026-10-15 주문 1건, 심의 계정 유료 잔액 600코인)은 아직 정리하지 않았다. 일반 이용자
  화면에는 보이지 않고 관리자 결제 화면의 집계에만 섞인다.
- 결제를 급히 멈추려면 SSM에서 `MUSEUN_COIN_PAYMENTS_MODE=disabled`로 바꾸고 재시작한다. 상점을 닫으려면
  `.env.production`의 두 값을 `false`·빈 값으로 되돌려 다시 배포한다.
