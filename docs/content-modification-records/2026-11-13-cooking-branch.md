# 2026-11-13 요리 특화 추가

## 기록 상태

- 상태: `recorded`
- 원본 브랜치: `feat/cooking-branch`.
- 사용자 요청: 생활 콘텐츠의 상한 이후 할 것을 넓히는 작업의 요리 편. 기존 전문 랭크를 늘리는 대신 전문 분야 안에서
  제빵·제과처럼 더 좁은 특화를 고르게 하고, 특화마다 전용 요리 3종과 그 계열 음식 제작 보너스를 준다. 특화는 14일에
  한 번 바꿀 수 있고, 그림은 기존 요리 그림과 같은 화풍으로 새로 만든다(2026-11-13 오너 결정).
- 설계: `docs/superpowers/specs/2026-11-13-cooking-branch-design.md`
- 구현 계획: `docs/superpowers/plans/2026-11-13-cooking-branch.md`
- 이 문서는 내부 변경 기록이며 공식 내용수정신고 접수 증빙은 아니다.

## 변경 내용

### 특화

전문 분야 랭크 5(전문 숙련 1,500 이상)가 되면 주방의 전문 분야 탭에서 자기 전문 분야에 속한 특화 하나를 고른다.

| 전문 분야 | 특화 (속하는 조리법) |
|---|---|
| 화덕 | 구이(굽기), 튀김(튀기기), 볶음(볶기) |
| 냄비 | 국물(끓이기), 찜(찌기) |
| 제과 | 제과(오븐), 제빵(발효), 찜과자(찌기·끓이기) |
| 해산물 | 직화(굽기·볶기·튀기기), 탕·찜(끓이기·찌기), 절임(발효) |
| 약선 | 차(우리기), 발효(발효), 약선식(끓이기·찌기) |

- 처음 고를 때는 대기가 없다. 바꾸면 그때부터 14일 동안 다시 바꿀 수 없다.
- 특화 숙련은 특화마다 따로 쌓이고 바꿔도 남는다. 보너스와 전용 요리 제작은 지금 고른 특화에만 적용된다.

### 숙련과 보너스

- 고른 특화에 속한 음식(분야와 조리법이 맞는 기존 음식, 그 특화의 전용 요리)을 만들면 1개당 티어 × 10의 특화 숙련을
  얻는다. 기존 전문 숙련도 그대로 함께 쌓인다.
- 랭크 1~5의 누적 요구량은 0 / 1,000 / 3,000 / 7,000 / 15,000이다.
- 그 계열 음식의 걸작 확률이 랭크당 +2%p(랭크 5에서 +10%p) 오른다. 걸작 확률 상한 75%, 성능 상한, 음식 식별자는
  바꾸지 않았다.

### 전용 요리 42종

특화마다 3종이다. 랭크 1·3·5에서 하나씩 열리고 각각 3·4·5티어다. 연구 없이 조합법이 공개돼 있고, 그 특화를 지금 고른
사람만 요구 랭크와 요리 Lv 20을 채웠을 때 만든다. 음식은 기존 음식과 같은 소모품이라 사용·거래·조건 납품·축제 주문·
명장 요리 전환에 그대로 쓰인다. 최초 발견자 보너스는 없고, 요리 도감 총수(500종)·발견 수·도감 숙련에는 들어가지 않는다.

효과는 주 효과(그 티어의 기존 수치)와 보조 효과(두 티어 아래 수치)로 이뤄진다. 아래는 랭크 1 / 3 / 5 순서다.

| 특화 | 주 효과 | 보조 효과 |
|---|---|---|
| 구이 | 공격력 +160 / 220 / 300 | 적중 +25 / 50 / 80 |
| 튀김 | 적중 +160 / 220 / 300 | DEX +6 / 10 / 16 |
| 볶음 | STR +16 / 24 / 32 | DEX +6 / 10 / 16 |
| 국물 | 최대 HP +1,200 / 2,000 / 3,000 | 방어력 +50 / 100 / 160 |
| 찜 | 방어력 +160 / 220 / 300 | 마법방어력 +50 / 100 / 160 |
| 제과 | 마법공격력 +160 / 220 / 300 | 적중 +25 / 50 / 80 |
| 제빵 | 최대 MP +400 / 670 / 1,000 | INT +6 / 10 / 16 |
| 찜과자 | 사냥 골드 +10 / 12 / 15% | LUK +6 / 10 / 16 |
| 직화 | 공격력·마법공격력 +80 / 110 / 150 | DEX +6 / 10 / 16 |
| 탕·찜 | 사냥 경험치 +10 / 12 / 15% | 최대 HP +300 / 700 / 1,200 |
| 절임 | 적중 +160 / 220 / 300 | 마법공격력 +50 / 100 / 160 |
| 차 | SPI +16 / 24 / 32 | 마법방어력 +50 / 100 / 160 |
| 발효 | 마법방어력 +160 / 220 / 300 | 최대 HP +300 / 700 / 1,200 |
| 약선식 | INT +16 / 24 / 32 | SPI +6 / 10 / 16 |

재료 칸 수는 같은 티어 기존 요리와 같고(3티어 4칸, 4·5티어 5칸) 수량은 3배다. 작물·목장 산물 12 / 15 / 18개,
주방 상점·가공 재료 3 / 6 / 6개, 어획물 3 / 3 / 6개이고, 랭크 5 요리에만 희귀 작물 2개가 들어간다.
요리별 이름과 재료는 설계 문서 5절 표와 안내서의 전용 요리 표에 있다.

### 화면과 안내서

- 주방 전문 분야 탭의 "주 전문 분야" 아래에 "특화"가 생긴다. 고르기 전에는 자기 분야의 특화와 전용 요리를 보여 주고,
  고른 뒤에는 랭크·숙련 진행·걸작 보너스와 전용 요리 제작 줄을 보여 준다.
- 안내서 생활 항목에 "요리 특화"와 전용 요리 표를 추가했다.

## 검증 및 운영 영향

- DB 마이그레이션, 배포 설정, 의존성 변경은 없다.
- 세이브: `cooking.v2`에 선택 필드 `branch`(지금 고른 특화, 특화별 숙련, 마지막으로 바꾼 시각)를 추가했다. 필드가
  없으면 고르지 않은 상태이고, 이 경우 제작 결과는 이전과 같다.
- API: 요리 라우트에 `choose_branch` 동작을 추가했고, 조회·변경 응답에 `branch`가 실린다.
- 그림: 전용 요리 42종(`public/images/items/cooking/branch_*.webp`). 출처는
  `docs/asset-provenance-cooking-branch-2026-11-13.md`.
- 전투 영향(2026-11-13 운영 수치 기준 추정): 랭크 5 전용 요리가 거래소에 풀리면 공격력 +300(전문 보너스가 붙은 걸작
  +375, 명장 요리 +420) 수준의 음식을 누구나 쓸 수 있다. 전직 진행자의 공격력 중앙값 약 2,500의 12~17%다. 이 수치는
  기존 5티어 요리의 범위 안이지만, 5티어 레시피 44종 중 서버에서 발견된 것이 6종뿐이라 실제로는 쓰이지 않던 수준이다.
  전문 랭크 5인 37명의 숙련 속도(주당 중앙값 약 600)로는 특화 랭크 5까지 약 25주, 상위 10%는 약 9주가 걸린다.
