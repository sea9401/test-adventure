# 2026-11-13 위험 해역 하루 어획 한도

## 기록 상태

- 상태: `recorded`
- 원본 브랜치: `feat/dangerous-fishing-daily-cap`.
- 사용자 요청: 위험 해역에 계정당 하루 획득 상한을 둔다(2026-11-13 오너 결정). 수치는 운영 수치를 보고 정했다.
- 이 문서는 내부 변경 기록이며 공식 내용수정신고 접수 증빙은 아니다.

## 변경 내용

- 위험 해역에서 낚을 수 있는 물고기는 계정당 하루 150마리다. 한도는 한국 시간 자정에 초기화된다.
- 한도에 닿으면 새 출항과 새 낚시(실시간, 기존 세 동작 방식 모두)가 `daily_catch_cap`으로 거부된다. 거부는 사고 판정과
  미끼 소비보다 먼저 일어나므로 화물과 미끼는 그대로다.
- 진행 중인 항해의 귀환, 상점, 교환, 장비 강화는 한도와 무관하다.
- 거대어 개인 시도와 보상 수령은 한도에 들어가지 않는다. 거대어 발견은 어획에서만 일어나므로 발견 횟수는 한도를 따라
  줄어든다.
- 실패한 낚시는 수량에 들어가지 않는다.
- 일반 낚시의 어획물별 하루 한도(50/35/25/10/3)는 바뀌지 않았다.

## 수치 근거

운영 수치에서 손으로 낚는 이용자의 하루 어획은 많아도 50마리 안팎이었다. 150마리는 쉬지 않고 한 시간쯤 낚아야 닿는
양이라 평소 이용에는 걸리지 않는다.

## 화면

- 출항 준비와 다음 어획 카드 제목 옆에 `오늘 어획 n/150`을 보여 준다.
- 한도에 닿으면 출항 버튼이 `오늘 어획 한도 도달`로 바뀌어 잠기고, 항해 중에는 낚시 준비 버튼이 잠기며 귀환 안내가 나온다.
- 안내서 생활 항목의 위험 해역 낚시에 한도 문장을 더했다. 수치는 코드 상수를 따른다.

## 검증 및 운영 영향

- DB 마이그레이션, 배포 설정, 의존성 변경은 없다.
- 세이브: `dangerous-fishing.v1`에 `dailyCatch: { date, caught }`를 추가했다. 없거나 손상된 값은 0마리로 읽는다.
  배포 시점에는 모든 계정이 0마리에서 시작한다.
- 한도 상수는 `src/adventure/data/v2/dangerousFishing.ts`의 `DANGEROUS_DAILY_CATCH_CAP` 하나다.
