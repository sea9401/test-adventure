# 2026-11-14 미개척지 최대 난이도 선택(120~130단)

## 기록 상태

- 상태: `recorded`
- 원본 브랜치: `feat/unexplored-difficulty-cap-select-853`.
- 사용자 요청: 건의 #853(난이도 상한이 130단으로 오르면서 노드 반영 순서를 조절해 유지하던 플레이가 달라졌으니
  최대 난이도를 이용자가 직접 정하게 해 달라는 의견)을 반영해 배포하고, 완료되면 점검 모드를 해제한다.
- 이 문서는 내부 변경 기록이며 공식 내용수정신고 접수 증빙은 아니다.

## 변경 내용

### 미개척지 탐사망

1. 탐사망 위쪽 요약 칸에 최대 난이도 선택을 추가한다. 120단부터 130단까지 1단 간격으로 고르며 기본값은 130단이다.
   프리셋마다 따로 기억하고, 바꾸는 데 골드는 들지 않는다. 100레벨 미만은 바꿀 수 없다.
2. 난이도 노드는 먼저 찍은 순서대로 고른 최대 난이도까지만 반영한다. 넘긴 노드는 2026-11-13 이전의 120단 상한과
   같은 방식으로 경로만 연결하고, 보상은 반영된 난이도만큼만 붙는다. 반영 순서 변경(먼저 반영, 후순위로 미루기)도
   고른 최대 난이도를 기준으로 동작한다.
3. 사냥 몬스터의 난이도, 탐사망의 활성화 미리보기, 점선 노드 안내 문구, 안내서의 난이도 노드 항목이 고른 최대
   난이도를 따른다.

몬스터 능력치 곡선, 난이도 노드의 수치, 보상 배율, 노드 반환 비용(노드당 500,000G)은 바꾸지 않는다.

## 검증 및 운영 영향

- DB 마이그레이션, 의존성, 배포 설정, 환경 설정 변경은 없다.
- 세이브: `character.v2`의 미개척지 항목에 프리셋별 최대 난이도(`difficultyCaps`)를 더한다. 값이 없거나 120~130
  정수가 아니면 130단으로 읽으므로, 배포 직후 기존 계정의 난이도와 보상은 달라지지 않는다.
- 하한을 120단으로 둔 이유: 130단 확장 전에도 +25를 넘긴 난이도 노드는 경로로만 쓸 수 있었다. 하한이 그보다
  낮으면 난이도 노드를 위험 없이 경로로만 쓰는 범위가 예전보다 넓어진다.
- 최대 난이도 변경이 무료라, 120~130단 사이에서는 노드를 반환하지 않고도 난이도를 내릴 수 있다. 그만큼 노드 반환
  골드 소모가 줄 수 있다.
- 배포 전 운영 조사(최근 7일 활동 계정 144개): 120단을 넘긴 계정 9개(121~125단), 그중 배포 뒤 전투 기록이 남은
  5개는 모두 전승이었다. 사냥이 막힌 사례는 없었고, 플레이 방식 선택권을 되돌리는 변경이다.
- 서버 요청: `/api/v2/unexplored`에 `difficulty_cap` 변경을 추가했다. 범위를 벗어난 값은 저장하지 않고 거절한다.
- 계산, 세이브 해석, 변경 요청, 사냥 준비, 탐사망 화면을 단위 테스트로 검증했고, 탐사망 화면은 휴대폰·PC 폭과
  라이트·다크 모드에서 확인했다.
