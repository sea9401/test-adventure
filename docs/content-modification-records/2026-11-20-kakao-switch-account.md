# 2026-11-20 다른 카카오 계정으로 로그인 추가(건의 #865)

## 기록 상태

- 상태: `recorded`
- 원본 브랜치: `feat/kakao-switch-account-865`.
- 사용자 요청: 건의 #865(계정 두 개를 쓰는데 로그아웃한 뒤에도 계정 선택 없이 직전 계정으로 바로 로그인된다).
- 이 문서는 내부 변경 기록이며 공식 내용수정신고 접수 증빙은 아니다.

## 원인

게임의 로그아웃은 게임 세션만 끝낸다. 브라우저에 남은 카카오 로그인은 그대로라서, 다시 카카오 로그인을 누르면
카카오가 로그인 화면 없이 직전 계정으로 인가한다. 카카오 로그인 상태는 기본 24시간, 로그인 상태 유지를 고르면
한 달 동안 유지된다. 그 기간이 지난 뒤에만 계정을 다시 고를 수 있어서 선택 화면이 나올 때와 안 나올 때가 갈렸다.

## 변경 내용

1. 로그인 화면의 카카오 로그인 버튼 아래에 `다른 카카오 계정으로 로그인`을 추가한다. 이 버튼은 카카오 인가 요청에
   `prompt=login`을 붙여 카카오 로그인 화면을 다시 띄운다.
2. 기존 `카카오톡으로 로그인` 버튼의 동작은 바꾸지 않는다. 계정 하나만 쓰는 이용자는 전과 같이 바로 로그인된다.

## 검증 및 운영 영향

- 카카오톡 인앱 브라우저에서는 카카오가 `prompt=login`을 지원하지 않아 카카오톡에 연결된 계정으로 로그인된다.
- 카카오 개발자 콘솔 설정, 환경 변수, DB 마이그레이션, 세이브 형식, 의존성 변경은 없다.
- 실제 카카오 화면은 로컬에서 확인하지 못했다. 인가 주소에 `prompt=login`이 실리는 것까지 확인했고, 그 뒤 동작은
  카카오 로그인 REST API 문서의 `prompt` 설명을 근거로 한다.
