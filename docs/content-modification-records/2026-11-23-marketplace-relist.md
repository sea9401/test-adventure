# 2026-11-23 거래소 유찰 매물 다시 올리기

## 기록 상태

- 상태: `recorded`
- 원본 브랜치: `feat/marketplace-relist`(`feat/first-battle-onboarding` 위에 쌓음).
- 사용자 요청: 업데이트 제안 6번 "거래소 유찰 줄이기" 진행(2026-11-23).
- 이 문서는 내부 변경 기록이며 공식 내용수정신고 접수 증빙은 아니다.

## 구현 전에 확인한 것

제안 6번은 "경매 시간을 6·12·24시간 중에 고르게 한다"와 "유찰되면 같은 조건으로 한 번 더 올리는 선택지"였다.
구현 전에 코드와 운영 기록을 다시 확인한 결과는 다음과 같다.

- 경매 시간 선택(6·12·24시간)은 2026-09-06부터 이미 있다. 제안의 이 절반은 전제가 틀렸다.
- 최근 13일 장비 낙찰률은 6시간 24%, 12시간 32%, 24시간 34%다. 시간을 늘려도 3분의 2는 유찰된다.
- 입찰이 한 번이라도 들어온 매물은 거의 전부 낙찰된다. 유찰은 입찰이 0건인 매물이다.
- 최근 30일 유찰된 장비 매물 3,566건 가운데 2,002건(56%)을 판매자가 직접 다시 올렸다. 그중 845건은 같은 가격이었다.
- 다시 올린 장비의 낙찰률: 같은 가격 13.6%, 25% 이하로 낮춤 13.1%, 25% 넘게 낮춤 34.1%(첫 등록 33.5%).
- 같은 장비를 6번 넘게 올린 경우가 100개(매물 850건)이고 그중 32개만 끝내 팔렸다.
- 재료도 유찰 뒤 다시 올린 476건 가운데 61건(13%)만 팔렸다.

따라서 "같은 조건으로 다시 올리기"만 넣으면 수고는 줄지만 유찰은 줄지 않는다. 다시 올릴 때 가격을 낮추기 쉽게 만들었다.

## 변경 내용

1. 거래소 > 내 거래 > 미판매 종료의 유찰된 장비·재료 줄에 `다시 올리기` 버튼을 추가한다.
2. 버튼을 누르면 창이 열리고 유찰된 시작 입찰가, 인하 폭(30% 낮춤·10% 낮춤·같은 가격), 새 시작 입찰가(직접 수정 가능),
   경매 등록 시간(6·12·24시간)을 정해 등록한다. 30% 낮춘 가격이 먼저 들어간다.
3. 등록은 기존 등록 API를 그대로 쓴다. 슬롯 수, 최저가, 거래 제한 같은 조건 검사는 달라지지 않는다.
4. 가방에서 돌아온 장비를 찾지 못하면(장착·잠금·돌아온 뒤 강화) 이유를 알리고 등록을 막는다.
   재료는 보유 수량이 유찰된 묶음보다 적으면 팔기 탭에서 올리도록 안내한다.
5. 취소한 매물과 소모품(희귀 지도·음식 등)에는 버튼이 없다.
6. 안내서의 거래소 항목에 다시 올리기를 추가했다.

## 검증 및 운영 영향

- 서버 변경은 없다. DB 마이그레이션, 세이브 형식, 환경 변수 변경도 없다.
- 창은 `/dev/marketplace-relist` 미리보기에서 라이트·다크로 확인했다. 로그인한 계정으로 실제 유찰 매물을 다시 올려 보는 확인은 하지 않았다.
- 배포 뒤 볼 것: 다시 올린 매물의 가격 변화 분포(같은 가격 42% → ?)와 다시 올린 매물의 낙찰률(13~14% → ?),
  전체 유찰 건수.
