# 골드 싱크 종합 개편 계획

> 배경: `docs/game-fun-audit.md` 보조 문제 — 골드는 벌기만 하고 중후반에 쓸 곳이 없어
> 인플레. 강화·제작·부여 전부 골드 0, 거래소 수수료 0, 상점은 초반용뿐.
> 4개 싱크를 추가해 넘치는 골드를 "플레이어가 가장 많은 시간을 쓰는 곳"에 묶는다.

## 실측 — 현재 골드 경제 (origin/main)

**싱크 (중후반엔 사실상 없음):**
- 강화: 별빛 조각만, **골드 0** (`character/enhancement.ts:35` `ENHANCE_SHARD_COST`, 골드 없음)
- 제작: 재료만, **골드 0** (`data/recipes/types.ts` Recipe 에 gold 필드 자체가 없음)
- 마법부여: **골드 0**
- 거래소 수수료: `FEE_RATE = 0` (`marketplace/ListingCreateModal.tsx:40`, 비활성)
- 상점: "초반 발판용 싸구려 한두 종"뿐 (`shop/BuyTab.tsx:19`)
- 길드 회관 봉납: 골드 5k/20k/60k/150k (`data/guildLodge.ts:25-29`) — 1회성·능력치 0영향·길드 필수
- 스탯 되돌리기: 되돌리기 포인트 1개 = **고정 1G** (`character/GrowthShrineView.tsx:17`) — 사실상 무료

**소스:**
- 퀘스트: 전 퀘 1회 클리어 합계 ~116k G (161개, 평균 720, 상위 1.9k~5k). 반복 49종은 지속 유입.
- 전투 드랍 + 오토헌트(~2~3k/6h) 지속.

→ 만렙층은 골드가 무한 누적. 별빛 강화·고티어 제작이 골드를 안 먹으니 쓸 데가 없다.

## 공통 원칙

- 모든 비용 필드는 **기본 0 / 옵션** → 기존 세이브·밸런스 무변화, **마이그레이션 불필요**.
- 골드가 넘치는 곳(별빛 강화=만렙 전용, 고티어 제작)만 무겁게 → **초보 진입엔 영향 0**.
- 수치는 전부 초안. 실측(누적 골드량) 후 튜닝 — 다른 시스템 튜닝과 동일.
- 주 리스크: 너무 공격적이면 골드 부족층(신규/중간)을 막음 → 티어/레벨 비례로 저층 저렴하게.

## 싱크 4종

### C1. 강화 골드 (별빛 무구 = 만렙 엔드게임 전용)

- `ENHANCE_SHARD_COST` 와 병행하는 `ENHANCE_GOLD_COST` 신설.
- 초안: `[0, 1000, 2500, 5000, 10000, 20000, 40000, 80000]` → +7 풀강 ~158.5k G/무기.
  풀세트(3종) ~475k → 누적 골드를 실질 흡수.
- 별빛 강화는 만렙 전용이라 **골드 넘치는 층만 타격**. 초보 무영향.
- 강화 시 조각+골드 둘 다 소모. 골드 부족 시 강화 불가(분기 추가).

### C2. 제작 골드 (전 티어, 티어 비례)

- `Recipe` 에 `gold?: number` 필드 신설(옵션, 기본 0).
- 티어 비례 초안: t1 ~50, t2 ~200, t3 ~800, t4 ~3k, t5 ~10k, t6 ~30k.
- 저티어 싸게, 고티어만 비싸게 → 초보 무영향, 만렙 제작이 골드 흡수.

### C3. 리스펙 비용 (스탯 되돌리기)

- `GrowthShrineView.tsx:17` 되돌리기 포인트 비용 고정 1G → **레벨 비례** (초안 `level × 20`,
  만렙 2k/포인트). 전면 재빌드(~수십 포인트)면 수만~수십만 G.
- 레벨 비례라 저레벨 저렴. (특기 교체는 현재 무료 — 이번 범위 제외, 후속 검토.)

### C4. 상점 확장 (편의 소비)

- 골드로 사는 편의 소비재: 대량 포션 묶음, 재료 묶음 등.
- **P2W 회피** — 전투력 직결 아이템·진행 단축(쿨다운 스킵)은 넣지 않음.
- (논의거리) "골드→별빛 조각" 교환은 강력한 싱크지만 조각 농사를 무력화 → 넣더라도 환율
  매우 나쁘게 or 일일 캡. MVP 에선 보류 권장.

## 통합 지점 (파일:라인 → 할 일)
