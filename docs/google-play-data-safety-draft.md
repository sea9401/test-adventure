# Google Play Data safety 답안 초안

기준일: 2026-08-08

이 문서는 Play Console 입력용 초안이다. 최종 제출 전 실제 Android AAB, 운영 환경과 외부 사업자 계약을 다시 대조한다. 특히 Google의 서비스 제공자 예외에 해당하는지는 각 사업자의 계약과 실제 이용 목적을 기준으로 판단한다.

## 상위 질문

| 질문 | 제안 답변 | 근거 |
| --- | --- | --- |
| 앱이 사용자 데이터를 수집하거나 공유하는가 | 예 | 로그인, 게임 저장, UGC, 보안 로그와 푸시 정보가 기기 밖으로 전송됨 |
| 전송 중 암호화되는가 | 예 | 앱·웹·외부 처리 API가 HTTPS를 사용하고 DB 연결도 TLS 사용 |
| 계정 생성을 지원하는가 | 예 | 카카오 로그인과 운영자 발급 계정 |
| 계정 삭제를 요청할 수 있는가 | 예 | 앱 내부 환경 설정과 `https://msmsge.com/account-deletion` |
| 독립적인 데이터 삭제 요청을 제공하는가 | 예 | 계정 삭제 안내 페이지의 문의 경로와 앱 내부 탈퇴 |
| 광고 목적으로 데이터를 사용하는가 | 아니요 | 광고 SDK·광고 추적·맞춤 광고 없음 |

## 데이터 유형별 초안

`수집`은 Android 앱이나 TWA에서 기기 밖으로 전송되는 경우를 뜻한다. 선택 여부는 실제 기능 기준이며, 단순히 운영 DB에 장기 저장되는지 여부만으로 결정하지 않는다.

| Google Play 데이터 유형 | 수집 | 필수·선택 | 주요 목적 | 서비스 내 예시 |
| --- | --- | --- | --- | --- |
| 개인 정보 · 이름 | 예 | 필수 | 앱 기능, 계정 관리 | 카카오 닉네임, 게임 닉네임 |
| 개인 정보 · 이메일 주소 | 예 | 필수 | 계정 관리, 보안 | 카카오 이메일 또는 연결 이메일 |
| 개인 정보 · 사용자 ID | 예 | 필수 | 앱 기능, 계정 관리, 보안 | 카카오 회원 식별자, 내부 사용자 UUID, 로그인 ID |
| 사진 및 동영상 · 사진 | 예 | 선택 | 앱 기능 | 프로필 이미지, 길드 엠블럼, 문의 첨부 이미지 |
| 메시지 · 기타 인앱 메시지 | 예 | 선택 | 앱 기능, 안전·규정 준수 | 채팅, 쪽지, 게시글, 댓글, 신고 내용 |
| 앱 활동 · 앱 상호작용 | 예 | 필수 | 앱 기능, 분석, 보안 | 게임 진행, 전투, 거래, 길드, 생활 활동, 정책 동의 |
| 앱 활동 · 기타 사용자 생성 콘텐츠 | 예 | 선택 | 앱 기능, 안전·규정 준수 | 공개 프로필, 길드 설명, 사용자 채팅방, 게시판 콘텐츠 |
| 앱 정보 및 성능 · 진단 | 예 | 필수 | 분석, 보안, 장애 대응 | 요청 실패, 오류·장애와 운영 진단 기록 |
| 기기 또는 기타 ID | 예 | 필수 또는 기능별 선택 | 앱 기능, 보안, 알림 | 세션·기기 식별값, 푸시 구독 주소·키, CAPTCHA 브라우저 신호 |

다음 유형은 현재 수집하지 않는 것으로 제안한다.

- 위치 정보
- 연락처
- 캘린더
- 건강 및 피트니스
- 금융 정보와 구매 내역
- 웹 탐색 기록
- 오디오 파일과 음성
- SMS 또는 통화 기록
- 광고 ID

## 처리 목적 선택 초안

- 앱 기능
- 계정 관리
- 사기 방지, 보안 및 규정 준수
- 분석: 오류·장애 분석, 게임 경제와 운영 지표에 사용하는 데이터에 한정
- 개발자 커뮤니케이션: 문의 답변과 이용자가 동의한 푸시 알림에 한정

광고 또는 마케팅, 개인 맞춤 광고 목적은 선택하지 않는다. 추천·개인화는 실제로 별도 프로파일링을 제공하지 않는다면 선택하지 않는다.

## 외부 처리 사업자 점검

| 사업자·기능 | 전달 가능 데이터 | Data safety 확인 사항 |
| --- | --- | --- |
| 카카오 로그인 | 회원 식별자, 이메일, 닉네임, 프로필, OAuth 정보 | 로그인 제공 목적의 수집과 계정 관리 반영 |
| AWS 서울 리전 | 계정, 게임 저장, UGC, 운영 기록 | 운영자를 위한 호스팅·DB 처리인지 계약 확인 |
| CloudFront·AWS WAF | IP, 요청·헤더·쿠키·TLS·응답 정보, 공격 탐지 시 요청 일부 | 보안·전송 목적 수집 반영 |
| Cloudflare R2 | 사용자 이미지, 객체 경로의 사용자·길드 식별자 | 선택형 사진 수집과 앱 기능 반영 |
| Cloudflare Turnstile | IP, User-Agent, TLS·브라우저 신호, 토큰·결과 | 보안 목적 기기·기타 ID 수집 반영 |
| hCaptcha | IP, 브라우저·운영체제·기기 정보, 상호작용, 토큰·결과 | 보안 목적 기기·기타 ID와 앱 상호작용 수집 반영 |
| 브라우저 푸시 제공자 | 푸시 구독 주소, 공개키·인증값, 암호화된 알림 | 기능 선택 시 기기·기타 ID 수집 반영 |

서비스 제공자가 운영자의 지시에 따라 처리하고 Google의 서비스 제공자 예외를 충족하면 `공유`로 보지 않을 수 있다. 사업자가 독립적인 목적으로 사용하거나 예외 요건을 충족하지 못하면 해당 데이터 유형을 `공유`로도 표시한다. 계약 확인 없이 일괄적으로 `공유하지 않음`을 선택하지 않는다.

## 계정과 데이터 삭제 답안

- 앱 내 경로: `환경 설정 → 회원 탈퇴`
- 외부 웹 경로: `https://msmsge.com/account-deletion`
- 삭제 범위: 계정, 인증 연결, 게임 저장, 회원 귀속 커뮤니티·문의 데이터와 연결 이미지
- 예외 보유: 완료·기각된 안전 신고는 계정 식별값과 표시 이름을 익명화하고 처리 완료 후 최대 180일 보관 가능
- 백업: 장애 복구 목적으로 격리하며 생성 후 최대 90일

## 최종 대조 항목

- Play Console의 모든 데이터 유형과 `src/app/privacy/page.tsx`의 항목·목적·보유 기간이 일치하는지 확인
- SDK Index와 AAB 분석 화면에서 예상하지 못한 광고·분석 SDK가 없는지 확인
- 전송 중 암호화와 계정 삭제 URL을 실제 설치본에서 다시 확인
- 푸시 알림, 이미지 업로드와 CAPTCHA가 선택·조건부라는 점을 각 데이터 유형에 정확히 표시
- 외부 사업자의 서비스 제공자 예외 적용 여부를 계약 기준으로 확정
