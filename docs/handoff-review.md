## 0. TL;DR

- ✅ **비율경감 데미지(ratiodef)** = 채택. 빼기 절벽(atk≈def→1딜 붕괴, Lv3 winT 300+턴)을 구조적으로 제거. C=100 은 저민감 페이싱 손잡이(밸런스 영향 X).
- ✅ **스킬 ×0.5 · 사제 홀리 패시브+누적** = 의도대로 작동(검증됨).
- 🔁 **비율 명중식(C/k/클램프)** = **flat-base 명중(`hit = 95 − 회피`)로 교체 권고.** 동성능인데 튜닝 불필요·읽기 쉬움(아래 §3).
- 🔴 **커밋된 sim 기본 `hitc=0` 은 틀린 값** — 본인도 "C~50 권장(미반영)" 으로 적어둠. C=0 은 회피를 가짜 무적으로 만들어 라이브보다 비현실적으로 쉬움(§2).
- ⚠️ **선결 질문 2개**: (1) §B 게이트를 라이브로 켤 것인가(테스트 마이그 비용), (2) **몹에 회피/치명저항을 부여할 것인가** — 안 주면 명중·critResist 는 PvE 에서 영구 휴면.

## 1. 재현된 주장 (검증 OK)

- **비율경감 절벽 제거**: Lv3 미러 legacy winT ~300턴(atk≈def→1딜) → 비율경감 ~195턴. 확인.
- **스킬 버스트 완화**: 풀스펙 Lv50 코어빌드 winT — 스킬×1.0 = 1.7~4.4턴(스킬 지배) → ×0.5 = 4~16턴. 확인.
- **SPI 구제**: baseline 죽은 축(WR 60~74%) → 홀리 패시브+누적으로 풀스펙 WR 100%·winT ~24턴("느린 생존형"). 확인.
- ⚠️ **헤드라인 "Lv50 WR폭 29→4pt, VIT 103→45턴" 은 확정(미러) 설정에서 재현 안 됨** — 미러·다이얼 도입 전 여정 중간치로 보임. 방향(절벽 제거)은 유효.

## 2. ★ 핵심 발견 — 명중은 라이브 PvE 에서 죽은 축이다

라이브 명중 처리(`engine.ts`, §B 게이트 OFF 기준)는 **양방향 %p 차감**:
- 내가 몹 때림: `적중 = 100 − max(0, 몹회피 − 내명중)`
- 몹이 나 때림: `적중 = 100 − max(0, 내회피 − 몹명중)`

그런데 **라이브 v2 몹(`V2_MONSTERS`)은 evasionPct·accuracy 둘 다 0** (전 엔트리 확인). 따라서:
- **내 명중 스탯(dex×0.25)은 효과 0** — 깎을 적 회피가 없음. 캐릭터 정보에 보이는 명중 수치는 라이브 PvE 에서 아무 일도 안 함.
- **내 회피는 작동** — 몹 명중=0 이라 `100 − 내회피`. (죽은 건 명중[공격]뿐, 회피[방어]는 살아있음.)
- 같은 패턴이 **critResist 에도** 적용 — 라이브 잡몹 critResist 미설정 → 정신 치명저항도 PvE 휴면.

### `hitc` 기본값 — C=0 이 게임을 망가뜨림

회피 0 몹(=라이브) 기준 Lv10 깊은 산 baseline(맨몸):

| 빌드 | 현 라이브(legacy) | §B C=0 (커밋된 기본) | §B C=50 | **flat=95** |
|---|---|---|---|---|
| STR | 25% | 100% | 37% | 39% |
| DEX | 0% | 100% | 25% | 25% |
| VIT | 25% | 100% | 35% | 34% |
| INT | 25% | 100% | 68% | 68% |
| SPI | 23% | 100% | 48% | 48% |
| LUK | 0% | 100% | 31% | 31% |

비율 명중식에서 몹 명중=0 이면 `(0+C)/(0+회피+C)`:
- **C=0** → 하한 클램프로 몹 적중 **10%** = 내 회피가 사실상 90% 무적 → 100% WR(비현실적으로 쉬움).
- **C=50/flat=95** → 몹 적중 ~89% → 현 라이브 난이도와 거의 일치.

→ **"C=50 이 어렵다"가 아니라 "C=0 이 적 피해를 90% 지워 비현실적으로 쉬웠다"** 가 맞는 프레임. C=0 채택 시 깊은 산을 통째로 무력화하는 난이도 회귀.

## 3. 권고 — 비율명중 대신 flat-base 명중

`hit% = clamp(floor, base − 회피×k, base)`, **명중 축 은퇴**(회피만 base 에서 차감). base=95.

### flat=95 가 비율 C=50 을 그대로 재현 (C·k 튜닝 0)

| 시나리오 | flat=95 | §B 비율 C=50 |
|---|---|---|
| 라이브유사(authored, Lv10) | 39/25/34/68/48/31 | 37/25/35/68/48/31 |
| 미러 baseline (Lv100) | 92/90/89/62/53/96 | 92/87/89/64/56/95 |
| 풀스펙 winT (Lv100) | 5.5/12.8/10.9/4.2/·/24.1 | 5.6/12.6/10.9/4.2/·/24.1 |

### PvP 적중 하한(floor) — 비율식이 풀려던 문제를 더 단순하게 해결

일반 빌드는 회피 ≤~19% → hit ≥76%, **floor 안 걸림**(floor 0=40 동일). 고회피 스택(eva×4 강제 시뮬)에서만:

| 고회피 Lv100 미러 | floor=0 | floor=40 |
|---|---|---|
| VIT WR | 44% | 88% |
| SPI WR | 39% | 70% |
| DEX winT | 184턴 | 92턴 |

→ floor=0 이면 "회피 불사"(184턴 교착). **floor≈40 하나로 해결** — 일반 무영향 + 극단 회피만 제어.

### 채택 조합
- ✅ 비율 데미지(ratiodef) = 살림
- ✅ flat-base 명중(`95 − 회피`) = 채택 (비율식과 동성능·읽기 쉬움)
- ❌ 비율 명중식(C/k/클램프) = 버림
- ✅ 명중 스탯 은퇴 (PvE 죽은 축; DEX 공격 정체성 = 크리+다단으로 재정의 필요)
- 🔧 적중 하한 ~40 = 깔아두기(PvP 회피불사 방지)

(구현: `combatShared.setFlatHit(base, floor)` + sim `--flathit[=base] --flatfloor=<n>` 추가해둠.)

## 5. 🔴 충돌 — 무도가 패시브 (디자인 결정 필요, §6)

- **main**: 무도가 = 반격(counterChancePct) · 궁수 = defPenetration · 마법사 = magicBasicAttack
- **이 브랜치**: 무도가 = 받피감(6~16%) + **반사(10~24%)** 로 교체
- 사제 `holyStrikeHealCoef`(우리가 검증한 SPI 구제 핵심)는 main 패시브 위에 **추가 가능**(충돌 아님).
- → **무도가만 택1**: main 반격 유지 vs 반사 채택 vs 병합. 나머지(궁수/마법사)는 main 유지하고 사제 홀리만 얹는 게 최소 충돌 경로.

## 6. 라이브 채택 체크리스트

1. **선결**: §B 게이트 flip 여부 + **몹에 회피/critResist 부여 여부**(안 주면 명중·치명저항 PvE 영구 휴면).
2. flat-base 명중 + 적중하한 40 으로 명중식 교체(비율식 폐기).
3. 명중 스탯 은퇴 → DEX/str/spi 스탯 재정의.
4. 무도가 패시브 충돌 해소(§5).
5. 장비 리팩터(`V2EquipInstance`) 위에 derive 재구현(§6 — main 진화분).
6. gear×2.25/skill×0.5/holy 0.3 을 sim 다이얼이 아닌 실데이터(장비위력·스킬계수·패시브)에 baked + 결정성 테스트 마이그.
7. 미러 강화(잡몹에 스킬/패시브) 후 엔드게임 빌드 형평 재측정(현재 풀스펙 미러 100% 포화 → 측정 불가).
