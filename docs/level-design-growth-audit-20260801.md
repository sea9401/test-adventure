# 오픈 전 성장·보상 페이싱 점검 (2026-08-01)

## 결론

- 운영 플래그(`core loop + stamina hunt + ATB skills`, EXP ×2.5)로 36개 사냥 단계와 7개 대표 빌드를 몬스터당 50회 검증했으며, 전투 경고는 0건이다.
- 심층의 베테랑 Lv1→100은 796~1,466승이다. 목표인 약 1,200승을 중심으로 깊을수록 조금 빨라지고, 레벨 뒤에는 직업 숙련·장비 추격이 남는다.
- 단일 직업 계보 6차까지 필요한 숙련은 `1,000 + 2,500 + 4,500 + 18,000 + 35,000 = 61,000승`이다. 자연회복을 빠짐없이 쓰면 8.5일, 하루 한 번만 최대 에너지를 쓰면 기본 40.7일·지원권 24.4일이다.
- 일반 장비는 밴드 최심부 기준 아무 장비 평균 167승, 특정 장비 평균 1,833~2,167승이다. 고유 장비는 아무 장비 평균 2,000승, 특정 1종 평균 10,000승이다.
- 경험치·직업·드랍 수치를 즉시 바꿀 근거는 없었다. 운영자가 확정한 기본 최대 에너지 1,500도 유지한다.

## 운영상 관찰할 경계

1. 기본 에너지는 5시간 만에 1,500까지 찬다. 자연회복은 하루 7,200이므로 하루 한 번 접속하는 이용자는 20.8%만 회수한다. 지원권도 하루 한 번이면 28.9%다. 의도된 접속 빈도·지원권 가치이므로 임의 상향하지 않았지만, 오픈 후 실제 접속 횟수와 에너지 소실량을 같이 봐야 한다.
2. 들판 최심부(깊이 6)에서 마른 협곡 입구(깊이 8)로 갈 때 평균 EXP/승이 약 18.1배 오른다. 들판은 온보딩, 협곡은 본 성장 루프라는 경계라서 유지했지만, 깊이 8 도달 전 이탈률과 도달 직후 레벨 상승량을 확인해야 한다.
3. 들판에서 액티브 스킬 MP까지 매번 유료 충전하면 일부 빌드는 전투 골드보다 회복비가 크다. 신규 계정에는 HP·MP 충전량이 각각 100,000 지급되고, MP가 없어도 기본 공격으로 사냥할 수 있다. HP 회복비만 보면 시작 빌드도 순이익이다. 신규 충전 지급이 초기화·부트스트랩에서 빠지면 초반 경제가 즉시 무너지므로 회귀 보호가 필요하다.
4. `levelBandExpMultiplier`는 옛 실험값이며 현재 v2 런타임에서 사용하지 않는다. 지금 추가 적용하면 EXP ×2.5와 중복되어 베테랑 약 1,200승 목표를 과속한다.

## 재현 명령

```bash
npm run sim:exp-pacing
npm run sim:level-design -- --strict
npm test -- --run src/adventure/data/v2/levelDesignSim.test.ts src/lib/leveling.test.ts
```

`sim:exp-pacing`은 과거의 최대 에너지 5,000·시간당 120 회복·옛 던전 층 하드코딩을 제거하고 통합 점검기와 같은 운영 계산을 사용한다.
