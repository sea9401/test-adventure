# 생활 텔레메트리·운영 관측 구현 계획

1. 생활 텔레메트리 SQL 집계 결과를 API 응답으로 조립하는 순수 함수를 테스트 우선으로 추가한다.
2. 관리자 API를 전체 기간 SQL 집계로 교체하고 10만 건 잘림 표시를 제거한다.
3. best-effort 배처 스냅샷과 경제 로그 배치 누적 지표를 테스트 우선으로 추가한다.
4. 배치 실패·큐 적체 경보와 런타임 프로파일러의 연속 DB 풀 대기 경보를 추가한다.
5. 보존 처리량 상태 계산을 테스트 우선으로 추가하고 정리 크론 응답·경보에 연결한다.
6. 관리자 운영 화면에 경제 로그 배치 지표를 표시하고 관련 타입과 문구를 갱신한다.
7. 대상 테스트, 타입 검사, 전체 테스트와 빌드를 수행한 뒤 로컬 커밋한다.
