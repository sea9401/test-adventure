# 서버 점검 공지 템플릿

아래 대괄호 항목을 점검 일정에 맞게 바꿔 사용합니다.

```markdown
## 🔧 서버 점검 안내

안녕하세요. 무슨무슨게임 운영진입니다.

[점검 사유]를 위해 서버 점검을 진행합니다.

### 점검 일정

- **일시:** [월]월 [일]일([요일]) 오후 [시작 시각] ~ 오후 [종료 시각]
- **예상 소요 시간:** 약 [소요 시간]

점검 중에는 게임 이용이 일시적으로 제한됩니다.
점검 진행 상황에 따라 종료 시각이 예정보다 앞당겨지거나 연장될 수 있습니다.

안정적인 서비스 제공을 위해 최선을 다하겠습니다.
감사합니다.
```
