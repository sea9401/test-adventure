# 거래소 5차 개편 — 장비 구매 주문

> 상태: 구현 완료 · DB 마이그레이션 생성 · 배포/실DB 반영 전
>
> 구현일: 2026-08-04

## 목표

재료·소모품에 한정됐던 구매 주문을 개별 옵션이 있는 장비까지 확장한다. 구매자는 정확한 장비 이름, 최소 위력, 최소 품질과 최대 가격을 제시하고 판매자는 조건에 맞는 주문에 장비를 즉시 판매한다.

## 체결 규칙

- 장비 주문은 한 주문당 장비 1개이며 주문 가격 전액을 등록 시 보관한다.
- 판매 가능한 미강화·미장착·미잠금 장비만 체결한다.
- 서버가 실제 장비의 옵션·제작 품질을 반영한 위력과 굴림 품질을 다시 계산한다.
- 조건을 만족하는 주문 중 가격이 가장 높은 주문을 선택하고, 같은 가격이면 먼저 등록된 주문을 선택한다.
- 체결 장비, 판매 대금과 남은 보관금은 우편함으로 전달한다.

## 저가 이전·부계정 악용 방어

- 장비 주문 가격은 해당 장비의 NPC 매입가보다 낮게 등록하거나 수정할 수 없다. 1골드 지정 이전을 서버에서 차단한다.
- 판매 요청은 장비 개체 ID만 받는다. 주문 ID와 구매자 ID를 받지 않으므로 판매자가 특정 계정의 주문을 골라 체결할 수 없다.
- 공개 주문 정보에는 구매자 신원을 포함하지 않는다. 본인 주문은 즉시 판매 후보에서도 제외한다.
- 주문 생성 IP와 체결 IP, 판매자·구매자 쌍, 실제 위력·품질, 체결가와 NPC 가격 하한을 감사 기록에 남긴다.
- 관리자 `거래소 경제` 화면에서 동일 IP 체결, 가격 하한 5% 이내 체결, 반복 상대와 비정상 가격을 함께 확인한다.
- 동일 IP는 가족·공용망 오탐 가능성이 있으므로 자동 제재하지 않고 검토 신호로만 사용한다.

## UI

- 장비 구매 화면에서 현재 부위의 정확한 장비를 검색해 주문할 수 있다.
- 주문 생성·수정 시 최소 위력, 최소 품질, 최대 가격과 기간을 설정한다.
- 판매 장비 카드에는 해당 장비가 충족하는 최고 구매 주문만 표시하며, 한 번 더 확인한 뒤 즉시 판매한다.
- 판매자는 구매자를 볼 수 없고 서버 자동 선택 규칙을 화면에서 안내한다.

## 데이터 변경

- `marketplace_buy_orders_v2.kind`에 `equip`을 허용한다.
- `min_power`, `min_quality_pct` 조건 컬럼을 추가한다.
- 장비 주문은 수량 1과 유효한 위력·품질 조건을, 비장비 주문은 조건 컬럼 `NULL`을 DB 제약으로 강제한다.
- 생성된 마이그레이션: `drizzle/0139_kind_invisible_woman.sql`

## 운영 확인

배포 후에는 가격 하한 근접 체결과 동일 IP 체결의 오탐 비율, 특정 판매자·구매자 반복 쌍, 장비 주문 에스크로와 우편 수령 성공률을 먼저 관찰한다. 시장 표본이 쌓이기 전에는 자동 차단 범위를 넓히지 않는다.
