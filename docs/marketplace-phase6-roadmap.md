# 거래소 6차 개편 — 쉬운 장비 시세와 운영 감사

> 상태: 구현 완료 · 운영 관찰 전
>
> 구현일: 2026-08-04

## 원칙

유저에게 분석 도구를 늘어놓지 않는다. 복잡한 수치와 위험 판단은 관리자 화면으로 숨기고, 판매자는 `비슷한 장비 시세`, 명백한 가격 실수 경고, 한 번의 일괄 판매 확인만 보게 한다.

## 유저 기능

- 같은 장비를 위력 25%·굴림 품질 25점 단위로 묶어 비슷한 장비의 최근 체결 시세를 한 줄로 표시한다.
- 표본이 3건 이상일 때 입력 가격이 평균의 절반 이하 또는 두 배 이상이면 짧은 경고만 표시한다. 판매를 강제로 막지는 않는다.
- 현재 필터에서 구매 주문과 매칭되는 장비가 2개 이상이면 최대 10개까지 `일괄 판매`할 수 있다.
- 일괄 판매 전에는 장비 수와 현재 예상 체결가 합계만 보여 주고 한 번 더 확인한다.
- 체결 순간 서버가 주문을 다시 검사하며, 사라진 주문은 건너뛴다. 판매자는 주문 ID나 구매자를 선택할 수 없다.

## 시세 집계

- 일반 판매 매물과 장비 구매 주문 체결을 모두 최근 시세에 포함한다.
- 같은 장비의 위력·품질 구간에 표본이 2건 이상이면 해당 구간을 우선하고, 부족하면 기존 제작 등급·품목 시세로 자연스럽게 되돌아간다.
- 내부 구간 키와 계산 방식은 UI에 노출하지 않는다.

## 관리자 기능

- 장비 주문 생성, 체결, 구매자 우편 생성과 수령 시각을 주문 번호로 연결해 확인한다.
- 동일 IP 60점, NPC 가격 하한 근접 25점, 반복 상대 10~20점을 합산해 `정상·관찰·검토`로 분류한다.
- 점수는 정렬과 검토 보조에만 사용한다. 자동 제재나 자동 정산 보류는 하지 않는다.
- 우편이 생성되지 않은 체결은 `우편 누락 확인`, 아직 수령하지 않은 건은 `우편 대기`로 표시한다.

## 이번 단계에서 보류

- 위험 점수에 따른 자동 정산 보류
- 동일 IP만으로 거래 제한 또는 계정 제재
- 유저 화면의 상세 차트·위험 점수·복잡한 시세 필터
- 관리자 재지급 버튼

자동 정산 보류와 재지급은 정상 이용자 오탐 및 중복 지급 위험이 있어 운영 표본과 별도 승인 흐름을 마련한 뒤 검토한다.
