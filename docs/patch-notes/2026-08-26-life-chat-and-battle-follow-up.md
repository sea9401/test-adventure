# [추가 업데이트] 8월 26일 생활·채팅 및 전투 기록 개선 안내

안녕하세요, 모험가 여러분.

8월 25일 추가 UI 수정 안내 이후 적용된 변경 사항을 안내드립니다.

이번 업데이트에서는 낚시로 얻는 요리 재료의 일일 획득 현황과 생활 지역의 주 생산물 보유량을 필요한 화면에서 바로 확인할 수 있도록 했습니다. 돼지우리의 비육 시간을 생활 주기에 맞추고, 돼지를 두 마리까지 함께 기를 수 있도록 개선했습니다. 위험 해역은 어획과 귀환에서 낚시 코인이 중복 지급되며 보상이 과도해지던 부분을 조정했습니다.

사용자 채팅방에는 참여자 명단을 추가하고, 전투 기록에서는 상대의 마법 공격력과 마법 장벽이 실제 전투와 다르게 보이던 문제를 수정했습니다. 검성·패황·천룡권성은 낮은 행동 속도에 비해 한 번의 공격이 충분히 강하지 않던 부분을 주력기의 직접 피해 계수로 보완했습니다. 인벤토리와 장비 비교 화면, 모바일 로그인 배경 등 여러 화면의 가독성과 조작 편의도 함께 보완했습니다.

1. 낚시 진행 확인과 위험 해역 보상 조정
2. 생활 지도와 사용자 채팅방 개선
3. 전투 밸런스와 기록 오류 수정
4. 인벤토리·요리 및 공통 화면 개선

## [주황]1. 낚시 진행 확인과 위험 해역 보상 조정[/주황]

### 요리 재료 일일 획득 현황

낚시 중 요리 재료를 얼마나 얻었고 오늘 더 얻을 수 있는지 다른 화면으로 이동하지 않고 확인할 수 있도록 진행표를 추가했습니다.

:::details 낚시 일일 획득 표시 내용

- 낚시 화면에 **요리 재료 일일 획득** 진행표를 항상 표시합니다.
- 일반·신선한·고급·특급·전설의 어획물을 등급 순서대로 보여주며, 각 재료의 **오늘 획득량 / 일일 최대치**를 확인할 수 있습니다.
- 등급별 일일 최대치는 일반 40개, 신선한 30개, 고급 20개, 특급 8개, 전설 2개입니다.
- 최대치에 도달한 재료에는 완료 표시가 나타납니다.
- 진행 현황은 매일 00:00에 초기화되며, 어획에 성공하거나 일일 한도에 도달하면 즉시 갱신됩니다.
- 이번 변경은 기존 획득 확률과 일일 최대치를 화면에 표시하는 개선으로, 재료 지급 확률과 한도는 변경되지 않았습니다.

:::

### 위험 해역 귀환 낚시 코인

위험 해역에서는 어획 성공 시 받는 코인과 귀환 시 화물 가치에 따라 받는 코인이 함께 지급됩니다. 높은 위험도에서 두 보상이 겹치며 귀환 보상이 의도보다 커지던 부분을 조정했습니다.

:::details 위험 해역 보상 변경 내용

- 귀환 낚시 코인을 **남은 화물 가치 × 현재 위험도 × 1%**로 조정했습니다. 기존에는 2%가 적용됐습니다.
- 정상 귀환은 전체 남은 화물 가치를, 사고로 강제 귀환하면 사고 후 남은 화물 가치를 기준으로 계산합니다.
- 어획 성공 즉시 받는 어종별 낚시 코인은 기존과 같습니다.
- 거대어 기여도 보상과 발견자 추가 보상, 어종별 화물 가치와 출현 확률, 사고 확률은 변경되지 않았습니다.

:::

## [주황]2. 생활 지도와 사용자 채팅방 개선[/주황]

### 생활 지역 주 생산물 보유량

벌목지나 채광지로 이동하기 전에 필요한 재료의 현재 보유량을 바로 판단할 수 있도록 생활 지도에 재료 정보를 보강했습니다.

:::details 생활 지도 표시 내용

- 생활 지도에서 벌목지를 선택하면 해당 수종의 **주 원목 이름과 보유량**을 표시합니다.
- 채광지를 선택하면 해당 광맥의 **주 광석 이름과 보유량**을 표시합니다.
- 돌·석탄·원석 보석 같은 채광 부산물은 표시하지 않으며, 낚시터 화면은 기존과 같습니다.
- 재료 보유량을 불러오지 못해도 지역 정보 확인과 이동은 그대로 이용할 수 있습니다.

:::

### 돼지우리 출하 주기

돼지 출하 시간이 자정 이후로 계속 밀려 사실상 하루 한 번만 이용하게 되는 불편을 줄였습니다.

:::details 돼지우리 변경 내용

- 돼지 한 마리의 비육 시간을 **16시간에서 12시간**으로 단축했습니다.
- 돼지우리마다 비육 중이거나 출하를 기다리는 돼지를 합쳐 **최대 2마리**까지 둘 수 있습니다.
- 두 돼지는 들어온 시각부터 각각 12시간을 계산하므로 서로 다른 시각에 출하할 수 있습니다.
- 돼지 한 마리를 추가로 데려올 때 배합 사료 2개가 필요하며, 한 마리를 출하하면 돼지고기 4개와 농사 경험치 8을 받습니다.
- 두 자리를 모두 운영할 때 총비용은 배합 사료 4개, 총보상은 돼지고기 8개와 농사 경험치 16입니다.

:::

### 사용자 채팅방 참여자 명단

같은 사용자 채팅방에 누가 참여하고 있는지 확인하기 어려웠던 부분을 개선했습니다.

:::details 채팅방 변경 내용

- 사용자 채팅방 상단에 **참여자 수와 참여자 명단 버튼**을 추가했습니다.
- 참여자 명단에서 캐릭터 이름과 방장을 확인할 수 있으며, 이름을 선택하면 해당 캐릭터의 프로필로 이동합니다.
- 참여자 명단은 현재 접속 여부가 아니라 해당 채팅방의 참여 상태를 나타냅니다.
- 전체·거래·길드 등 기본 채널은 변경되지 않았습니다.
- 데스크톱에서 채팅 패널을 열면 오른쪽 아래 플로팅 채팅 버튼을 숨겨 메시지 전송 버튼을 가리지 않도록 했습니다. 채팅을 닫으면 버튼이 다시 나타납니다.

:::

### 상단 공지 바로가기

상단 알림 메뉴를 정리하는 과정에서 빠졌던 공지사항 이동 경로를 복원했습니다.

:::details 상단 메뉴 변경 내용

- 상단 알림 버튼 옆에 **공지사항 바로가기**를 다시 표시합니다.
- 기존 알림과 환경설정 메뉴의 동작은 변경되지 않았습니다.

:::

## [주황]3. 전투 밸런스와 기록 오류 수정[/주황]

### STR 계열 6차 주력기 계수

검성·패황·천룡권성은 같은 성장 단계의 고속 물리 직업보다 행동 횟수가 적지만, 한 번의 공격력이 그 차이를 보완하지 못하던 부분을 조정했습니다. 보스전과 대련 시뮬레이션을 함께 비교해 이미 PvP가 강한 패황은 상향 폭을 작게 잡았습니다.

:::details 직업별 변경 내용

- 검성 **무심검**의 힘 계수를 **1.04에서 3**으로 높였습니다.
- 천룡권성 **천룡난무**의 타격당 힘 계수를 **0.22에서 1.2**로 높였습니다.
- 패황 **멸왕일도**의 공격력 계수를 **2에서 2.2**, 힘 계수를 **2.4에서 2.64**로 높였습니다.
- 별도의 PvE 피해 증가 옵션은 추가하지 않았습니다. 변경된 계수는 PvE와 PvP에서 같은 공식으로 적용됩니다.

:::

### 검성 계열 7차 직업 자립성 개선

무심검의 힘 계수는 3을 기준으로 다시 검증하고, 무영검신과 멸검제가 선행 스킬 없이 고유 스킬만 장착해도 검성보다 강하도록 직접 피해를 조정했습니다. 일검필살은 7차 스킬에도 기존과 동일하게 온전히 적용됩니다.

:::details 7차 직업별 변경 내용

- 무영검신의 **잔영·무흔** 직접 피해를 높였습니다. 검영은 무영검신 고유 공격을 50%, 선행 직업에서 가져온 계승 공격을 25% 기록합니다.
- 멸검제의 **극한일격·멸검** 직접 피해를 높였습니다. 멸검은 검의가 정확히 3개일 때만 충전을 시작하고 다음 행동 기회에 자동 해방합니다.
- 멸검 해방 뒤 검의 1개를 되찾는 흐름과, 무흔·흑월의 난무가 검영을 한 번 정련하는 흐름은 유지됩니다.
- PvE 상향분은 PvP 직접 피해에 적용하지 않아 기존 대련 피해 수준을 유지했습니다.
- 같은 대표 능력치와 200개 고정 시드에서 두 7차 고유 세트의 장기전 평균 차이는 2% 이내였습니다.

:::

### 사냥 캐릭터 상태 표시

캐릭터 상태를 펼쳤을 때 같은 요약 정보가 위아래로 반복되며 상세 내용을 가리던 부분을 정리했습니다.

:::details 사냥 화면 변경 내용

- 캐릭터 상태를 접었을 때는 이름, HP·MP, 충전약, 직업 숙련도와 경험치 정보를 기존처럼 표시합니다.
- 상태를 펼치면 중복된 요약 정보를 숨기고 **간략히 보기** 조작과 상세 정보에 집중할 수 있도록 변경했습니다.

:::

### PvP 전투 기록 재생

PvP 전투 기록에서 상대의 일부 전투 수치와 방어 효과가 실제 전투와 다르게 표시되던 문제를 수정했습니다.

:::details 전투 기록 수정 내용

- 마법 공격을 사용하는 상대의 **마법 공격력**이 전투 기록에 정확히 전달되도록 수정했습니다.
- 방어자 관점의 전투 기록을 재생할 때 **마법 장벽이 반대편 캐릭터에게 표시되던 문제**를 수정했습니다.
- 이번 변경은 전투 기록의 표시를 실제 판정과 일치시키는 수정으로, 전투 중 피해 계산과 능력치 자체는 변경되지 않았습니다.

:::

## [주황]4. 인벤토리·요리 및 공통 화면 개선[/주황]

### 인벤토리와 장비 비교

장비를 정리하거나 교체할 때 선택 항목과 능력치 비교 정보가 더 분명하게 보이도록 화면을 다듬었습니다.

:::details 장비 화면 변경 내용

- 인벤토리의 장비 정렬 선택지가 라이트·다크 모드에서 배경과 글자색 때문에 읽기 어려웠던 부분을 수정했습니다.
- 도감 등록 버튼 문구를 **도감 일괄 등록 (N)**으로 정리해 버튼의 용도를 바로 알 수 있도록 했습니다.
- PC 장비 변경 화면에서 스크롤할 때 능력치 비교 요약이 상단 공지와 메뉴에 가려지지 않도록 고정 위치를 조정했습니다.

:::

### 요리 이름 구분

비슷한 표현으로 혼동될 수 있던 요리 이름을 조정했습니다.

:::details 요리 변경 내용

- **바삭한 감자튀김**의 이름을 **짭짤한 감자튀김**으로 변경했습니다.
- 요리 효과, 등급과 제작 조건은 변경되지 않았습니다.

:::

### 모바일 로그인 배경

세로 화면에서 가로형 지역 그림의 양옆이 크게 잘려 장면을 알아보기 어려웠던 부분을 개선했습니다.

:::details 로그인 화면 변경 내용

- 모바일에서는 화면을 채우는 배경 위에 원본 지역 그림의 전체 구도가 보이도록 표시합니다.
- 넓은 화면의 기존 배경 표시, 슬라이드 순서와 전환 방식은 변경되지 않았습니다.

:::

이번 추가 업데이트 이후에도 낚시·생활 콘텐츠의 보상 흐름과 채팅·전투 화면의 실제 이용 기록을 확인하며 필요한 부분을 계속 보완하겠습니다.

감사합니다.
