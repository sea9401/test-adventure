# 정식 공개 준비 점검

최종 확인일: 2026-09-03

이 문서는 현재 코드와 운영 설정을 기준으로 정식 공개 전에 확인한 사항을 기록한다. 법령이나 사업 형태, 게임 내용이 바뀌면 기존 판단을 그대로 사용하지 않는다.

## 현재 출시 판정

2026-07-30 운영 빌드 `7246d30f`를 기준으로 **확인된 코드·운영 범위에 정식 공개를
막는 미완료 항목은 없다.** 다음 항목을 완료했다.

- 공개 약관·개인정보처리방침·운영정책·오픈소스 고지를 배포했다.
- 개발 화면과 무슨 코인 상점의 화면·API를 프로덕션에서 404로 차단했다.
- Discord 운영 알림, 자동 백업·복구 검증, 외부 업타임·EC2 자원 감시, 배포 후
  스모크를 구성했다.
- 운영 비밀값을 AWS SSM SecureString으로 옮기고 내부·Kakao·RDS 자격증명을
  교체했으며, 사용하지 않는 Google 자격증명과 옛 Vercel 프로젝트를 제거했다.
- 의존성 라이선스와 정적 자산 권리 원장을 CI 게이트로 고정했다.
- 데스크톱 Chromium과 iPhone 13 크기의 모바일 WebKit에서 공개 화면,
  인증 계정 수명주기, 전투·보상·재접속 복원을 검사하는 28개 E2E를 CI
  게이트에 포함했다.

실제 Kakao 계정 로그인과 휴대전화에서의 로그인·사냥·새로고침·재로그인 확인을
2026-07-30에 마쳤다. 게임물 등급분류는 2026-09-03에 `12세이용가`로 결정됐으며,
이용량 증가 뒤 CDN/WAF 도입은 비용과 DNS 변경을 수반하는 선택 작업이다.

## 2026-08-13 운영 안전장치 후속

- 중요 cron과 DB 백업은 성공할 때만 heartbeat를 기록하고, 독립된 systemd 자원 감시가
  누락·정체를 확인하도록 코드화했다.
- CloudWatch RDS 지표 조회 실패를 정상 상태로 숨기지 않고 감시 장애와 복구로 구분했다.
- 새 파괴적 마이그레이션, 이동 가능한 GitHub Action 태그, 제한된 원본 행 기반 일일 집계를
  CI와 테스트에서 차단했다.
- 서비스 목표, 장애 대응 절차, 운영 변경 체크리스트와 임시 DB 복원 검증 스크립트를
  저장소에 추가했다.
- 주간 복원 timer와 CloudFormation 운영 경보 템플릿은 **준비만 완료**했으며 자동으로
  활성화하거나 AWS에 적용하지 않는다. 템플릿에는 GitHub 업타임 검사와 독립된 opt-in AWS
  Synthetics 검사를 포함했고, 2026-08-13 GitHub 운영 환경은 `main` 브랜치 하나만 배포할 수
  있도록 실제 적용했다. AWS 경보·canary와 RDS 보호 설정은 런타임 EC2 역할이 아닌 별도 AWS
  관리자/배포 권한으로 현재 상태·비용·알림 대상을 확인한 뒤 적용한다.

## 게임물 등급분류

### 공식 결정

게임콘텐츠등급분류위원회는 2026-09-03에 다음과 같이 등급분류를 결정했다.

| 항목 | 결정 내용 |
| --- | --- |
| 게임명 | 무슨무슨게임 |
| 신청사 | 무슨게임 |
| 플랫폼 / 장르 | PC/온라인 게임 / 롤플레잉 |
| 결정등급 | 12세이용가 |
| 등급분류번호 | `GC-CC-NP-260903-001` |

| 게임제작업 등록번호 | 제2026-000005호 |

결정사유는 전투·생활 콘텐츠를 통해 캐릭터를 성장시키는 어드벤처 RPG이며,
무기와 붉은 선혈이 표현된 일러스트에 경미한 폭력 표현이 있다는 것이다. 따라서
「게임산업진흥에 관한 법률」 제21조와 등급분류 규정 제7조제2호에 따라
`12세이용가`로 결정됐다.

공식 결정은 [게임콘텐츠등급분류위원회 등급분류 결정 현황](https://www.gcrb.or.kr/statistics/gameStatistics.aspx)에서
등급분류번호로 확인한다.

### 서비스 표시

- `/`, `/sign-in`, `/create`와 게임 경로에 처음 진입하면 건너뛰기 없이 3.5초 동안
  `12세이용가`, “12세 미만은 이용할 수 없습니다” 문구와 `폭력성` 내용정보를 표시한다.
- 비로그인 공개 경로 `/game-info`에서 게임명, 상호, 이용등급, 등급분류번호,
  제작연월일, 제작업·배급업 등록번호, 결정일과 결정사유를 확인할 수 있다.
- 대문 푸터, 게임 상단 메뉴와 환경 설정에서 `/game-info`를 한 번에 열 수 있어
  게임 이용 중에도 이용등급과 내용정보를 상시 확인할 수 있다.
- 공식 12세이용가·폭력성 표식은 `public/images/rating/`에 두고 출처와 해시를
  `docs/asset-rights.json`에서 검증한다.

### 변경 관리

심의 대상 게임 버전의 제작연월일은 2026.08.07이다. 등급에 영향을 줄 수 있는
선정성·폭력성·언어·약물·사행성·범죄 표현, 유료화 구조 또는 주요 콘텐츠가 바뀌면
배포 전에 내용수정신고나 재등급분류 필요 여부를 확인한다. 특히 현재 결정에 포함되지 않은
내용정보를 새로 추가하거나 폭력 표현의 수위를 높일 때는 기존 `12세이용가` 표시만으로
처리하지 않는다.

Playwright 브라우저 E2E 28개가 모두 통과했다. 인증·핵심 플레이·탈퇴
시나리오 3개는 데스크톱과 모바일에서 모두 순차 실행했다. 같은 `main` CI에서
TypeScript 검사, ESLint, Vitest 3,440개, 이미지 참조, 자산 권리 원장, 의존성
라이선스, 마이그레이션 순서, 운영 의존성 감사와 Next.js 프로덕션 빌드도
통과했다. 인증 E2E는 실행마다 폐기되는
loopback 전용 PostgreSQL과 고정 테스트 계정만 사용한다.

운영 알림은 개인정보를 제거한 Discord 웹훅으로 연결했으며 실제 전송에서 HTTP 204를
확인했다. 배포 워크플로는 서버 내부 스모크가 끝난 뒤 실제 도메인을 통해 빌드 식별자,
로그인·정책·검색 메타 경로와 개발 화면·코인 상점 차단을 자동 확인한다. 운영 환경은
SSM SecureString 한 곳을 원본으로 삼고 EC2 역할이 `/run`의 권한 `600` 파일로만
복호화한다. 자격증명 값·해시·일부 문자는 문서와 CI 로그에 기록하지 않는다.

로컬 프로덕션 서버에서는 DB·Auth 운영 비밀정보를 주입하지 않았기 때문에 로그인·헬스처럼 해당 정보가 필요한 요청을 실제 운영 판정에 사용하지 않았다. 공개 정적 페이지와 프로덕션 404 경계는 로컬 빌드에서 별도로 확인했다.
