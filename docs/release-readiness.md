# 정식 공개 준비 점검

최종 확인일: 2026-07-27

이 문서는 현재 코드와 운영 설정을 기준으로 정식 공개 전에 확인한 사항을 기록한다. 법령이나 사업 형태, 게임 내용이 바뀌면 기존 판단을 그대로 사용하지 않는다.

## 게임물 등급분류

### 현재 판단

현재 서비스는 **개인이 국내에서 단순 공개하는 비영리 게임물의 등급분류 면제 요건에 해당할 가능성이 높다.** 따라서 지금 확인된 운영 형태를 유지하는 동안에는 유료 등급분류 신청을 정식 공개의 선행 조건으로 두지 않는다.

근거는 다음과 같다.

- 「게임산업진흥에 관한 법률」 제21조제1항제4호는 영리를 목적으로 하지 않고 제작·배급하는 게임물 중 대통령령이 정하는 게임물을 등급분류 예외로 둔다.
- 같은 법 시행령 제11조의3제2항은 이를 “개인·동호회 등이 국내에서 단순 공개를 목적으로 창작한 게임물”로 정한다.
- 시행령 제11조의3제3항에 따라 면제 대상인지 게임물관리위원회에 미리 확인받을 수 있다.

공식 근거:

- [게임산업진흥에 관한 법률 제21조](https://www.law.go.kr/법령/게임산업진흥에관한법률/제21조)
- [게임산업진흥에 관한 법률 시행령](https://www.law.go.kr/법령/게임산업진흥에관한법률시행령)
- [게임콘텐츠등급분류위원회 등급분류 안내](https://www.gcrb.or.kr/Institution/EtcForm01.aspx)

이는 법률 자문이나 위원회의 공식 확인을 대신하지 않는다. 공개 범위를 크게 넓히거나 면제 해당 여부가 불명확해지면 시행령 제11조의3제3항에 따른 사전 확인을 우선한다.

### 현재 면제 판단을 뒷받침하는 운영 사실

- 이용약관에 현금 결제와 유료 상품 구매를 제공하지 않는다고 명시되어 있다.
- 광고 SDK, 광고 수익, 구독, 후원, 외부 결제 연동이 없다.
- 무슨 코인 상점은 프로덕션에서 메뉴와 직접 주소, API 모두 비공개 상태다.
- 게임 재화·아이템의 현금화, 환전과 외부 대가 거래를 약관으로 금지한다.

### 등급 관점의 현재 콘텐츠 점검

정식 등급을 신청하거나 면제 확인 자료를 만들 때는 아래 내용을 누락하지 않는다.

| 요소 | 현재 내용 | 내부 준비 기준 |
| --- | --- | --- |
| 사행성 모사 | 게임 골드로 참가하는 시간제 복권, PvP 챔피언십 승자 예측 골드 풀 베팅과 배당 | 반복 가능한 베팅 요소가 있으므로 보수적으로 15세 수준을 가정해 설명 자료 준비 |
| 재산상 이익 | 게임 재화의 현금 구매·환전·외부 거래를 지원하지 않으며 약관으로 금지 | 유료 재화와 연결하거나 현금성 보상을 추가하지 않음 |
| 폭력성 | 판타지 전투, 무기, 몬스터 처치가 있으나 사실적인 신체 훼손이나 유혈 표현은 확인되지 않음 | 새 이미지·연출에 유혈, 신체 훼손을 추가할 때 재검토 |
| 언어·이용자 콘텐츠 | 채팅, 게시판, 길드 소개, 프로필·문의 이미지 업로드 | 신고·차단·운영 제재와 금칙어 정책 유지 |
| 선정성·약물·범죄 | 현재 핵심 콘텐츠에서 직접적 묘사가 확인되지 않음 | 신규 콘텐츠 추가 때 다시 점검 |

`15세 수준`은 내부 준비 기준일 뿐 공식 이용등급 표시가 아니다. 등급분류를 받거나 면제 확인을 받기 전에 임의의 공식 등급 마크나 등급분류번호를 노출하지 않는다.

### 반드시 다시 판단해야 하는 변경

다음 중 하나라도 적용하기 전에는 비영리 단순 공개 면제 판단을 중단하고 등급분류 필요 여부를 다시 확인한다.

- 현금 결제, 유료 코인, 구독, 광고, 후원 또는 제휴 수익 도입
- 게임 재화·아이템을 현금성 가치와 교환하거나 외부 거래를 허용
- 사업자 명의의 상업적 배급 또는 유료 플랫폼 입점
- 청소년이용불가 기준에 해당할 수 있는 선정성·폭력성·사행성 콘텐츠 추가
- 기존 등급 판단에 영향을 줄 정도의 복권·베팅·확률형 아이템 구조 변경

위 변경으로 등급분류가 필요해지면 공개 전에 신청한다. PC·온라인 게임의 전체이용가·12세·15세 등급 신청 창구는 게임콘텐츠등급분류위원회이며, 청소년이용불가 게임물은 게임물관리위원회가 담당한다. 신청 결과가 나오면 초기 화면과 매 1시간마다 이용등급 및 결정된 내용정보를 법정 방식으로 표시한다.

### 나중에 운영자가 직접 해야 하는 최소 작업

현재 면제 판단을 행정기관의 답변으로 확정하려면 게임물관리위원회에 다음 자료로 사전 확인을 요청한다.

- 게임명, 서비스 URL, 제작자와 배급 형태
- 무료·무광고·무후원이며 유료 재화가 없다는 설명
- 전체 플레이 영상과 주요 화면
- 복권 및 챔피언십 골드 베팅 구조, 현금화 불가 설명
- 이용약관의 외부 현금 거래 금지 조항

외부 계정 로그인과 신청자 본인 확인이 필요한 단계이므로 이 요청은 자동으로 제출하지 않는다.

## 자동 사용자 흐름 점검

### 현재 소스

2026-07-27에 다음 흐름을 자동 검증했다.

- 비로그인 랜딩에서 카카오·운영자 발급 계정 로그인 선택지와 약관·개인정보처리방침·운영정책 링크 노출
- OAuth 계정 연결 실패 시 로그인 반복 대신 명시적인 오류와 문의 방법 노출
- 비인증·비활성 기기·잘못된 닉네임으로 회원 탈퇴 요청 차단
- 정상 탈퇴 시 계정 삭제, 서버 세션 만료, 프로필·문의 첨부·해산 길드 이미지의 R2 삭제 큐 등록
- 관리자 가장 중 원래 관리자 계정의 탈퇴 차단
- 프로덕션에서 개발 화면·개발 API·무슨 코인 상점 화면과 API를 404로 차단
- 공개 정책 3종의 비로그인 렌더링과 사이트맵·robots 정책

관련 테스트 11개 파일, 44개 항목이 모두 통과했다. TypeScript 검사, ESLint, 이미지 참조 검사와 Next.js 프로덕션 빌드도 통과했으며 `/terms`, `/privacy`, `/operations`가 정적 페이지로 생성됐다.

### 현재 운영 배포본과의 차이

2026-07-27 읽기 전용 HTTP 점검 결과는 다음과 같다.

| 경로 | 현재 운영 응답 | 판단 |
| --- | --- | --- |
| `/api/health` | 200 | 정상 |
| `/sign-in` | 200 | 정상 |
| `/` 비로그인 | `/sign-in`으로 307 | 정상 |
| `/api/account/delete` 비로그인 POST | 401 | 정상 |
| `/dev` | 404 | 정상 |
| `/terms`, `/privacy`, `/operations` | 404 | 새 정책 페이지 배포 전 |
| `/settings/coin-shop` | 200 | 프로덕션 숨김 변경 배포 전 |

정책 페이지와 코인 상점 차단은 현재 소스와 빌드에는 반영되어 있으나 아직 운영 서버에 배포되지 않았다. 운영 알림 웹훅 주소가 준비되기 전에는 새 프로덕션 프리플라이트를 우회해 배포하지 않는다.

로컬 프로덕션 서버에서는 DB·Auth 운영 비밀정보를 주입하지 않았기 때문에 로그인·헬스처럼 해당 정보가 필요한 요청을 실제 운영 판정에 사용하지 않았다. 공개 정적 페이지와 프로덕션 404 경계는 로컬 빌드에서 별도로 확인했다.
