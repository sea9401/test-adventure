# 퍼센트 보너스 반올림 개선 설계·구현 계획

## 문제

작은 기본값에 `Math.floor(base * (1 + pct / 100))`를 매번 적용하면 표시된
퍼센트가 실제 결과를 바꾸지 못한다. 장비 위력, 길드 사냥 보급, 핫타임·음식
보상, 요리 경험치·재료 절약, 길드 훈련 보상이 이 영향을 받는다.

## 적용 원칙

- 장비 위력: 영구 능력치이므로 0.01 단위까지 보존하고 전투 파생식의 최종
  정수 경계에서만 반올림한다. 강화·제작 품질의 작은 차이도 합산에 남는다.
- 고빈도 보상: 사냥, 낚시, 음식·핫타임, 요리 경험치는 소수 보너스만 확률적
  반올림한다. 한 번의 결과는 정수이고 장기 기대값은 표시 퍼센트와 일치한다.
- 저빈도·예측형 계산: 요리 일반 재료와 일일 길드 훈련은 세이브에 나머지를
  저장해 다음 행동으로 이월한다. 재료 소모나 일일 보상이 임의로 흔들리지 않는다.
- 기존 세이브: 새 나머지 필드는 선택 필드로 파싱하며 없으면 0으로 시작한다.

## 변경 단위

1. 공용 퍼센트 계산 헬퍼에 확률적 반올림과 누적 나머지 계산을 추가한다.
2. 강화·제작 품질 위력을 소수 둘째 자리까지 계산하고 실제 장착 어댑터에도
   같은 계산을 사용한다.
3. 길드 전투 보급과 운영 핫타임 계산이 주입 가능한 RNG로 공용 확률 반올림을
   사용하게 한다. 요리 경험치도 같은 방식으로 계산한다.
4. 요리 재료는 직업 절약과 스킬 절약을 곱연산으로 합친 뒤 재료별 1/10000
   나머지를 이월한다.
5. 길드 훈련은 기본 보너스와 핫타임 보너스의 1/100 나머지를 각각 이월한다.
6. 각 순수 계산에 회귀 테스트를 먼저 추가하고 관련 테스트, 타입 검사, 린트를
   실행한다.

## 비범위

- 퍼센트 수치 자체의 상향·하향과 보상 총량 재설계
- 확률형 희귀 재료 보존처럼 이미 확률을 명시한 효과
- 배포 및 운영 환경 변경
