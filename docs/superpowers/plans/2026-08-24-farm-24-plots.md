# Farm 24-Plot Expansion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend the farm from 8 to 24 plots through four high-cost, four-plot upgrades without relocking the existing endgame shop.

**Architecture:** Keep the existing generic plot-upgrade state transition and persistence format, and extend only its declarative upgrade table and maximum bound. Decouple the endgame shop's historical 8-plot requirement from the new maximum, then adapt the existing all-plots grid to four columns on large screens.

**Tech Stack:** TypeScript, React 19, Next.js 16 App Router, Tailwind CSS 4, Vitest, React server rendering tests

## Global Constraints

- Preserve the existing 2→3→4→5→6→7→8 plot progression and prices.
- Add 8→12→16→20→24 plot upgrades costing 1,000→2,000→4,000→8,000 reputation.
- Keep the endgame shop unlock requirement at 8 plots and four paid ranch pens.
- Render every owned plot on one screen; use one column on mobile, three from `sm`, and four from `xl`.
- Keep batch planting, harvesting, and fertilizing global across all owned plots.
- Do not change crop yields, growth times, rare rates, seed income, reputation income, ranch production, or feed costs.
- Do not deploy, push, or create a pull request.
