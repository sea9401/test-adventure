# 모험 편의성 개선 구현 계획

## 1. 아레나 완료 집계 제외

- `AdventureActivityView`에 완료 집계 여부를 추가한다.
- 서버가 아레나 활동을 반복·비집계 활동으로 반환하게 한다.
- 전체 요약과 그룹 진행률이 비집계 활동을 제외하게 한다.
- 서버, 모델, 체크리스트 컴포넌트 회귀 테스트를 추가한다.

## 2. 거래소 음식 문구 제거

- 음식 소비 아이템에서 희귀 지도 상태 문구가 나타나는 실패 테스트를 추가한다.
- 상태 판별을 희귀 지도 아이템으로 제한한다.
- 유효하지 않은 희귀 지도 차단 테스트가 계속 통과하는지 확인한다.

## 3. 물약 설정 계정 저장

- 자동사냥 물약 설정의 정규화와 저장 형식을 테스트한다.
- 인증된 GET/PATCH 라우트를 추가하고 기존 저장소 패턴을 따른다.
- 훅이 서버 값을 불러오고 로컬 값은 서버 값이 없을 때만 이전하도록 테스트한다.
- 설정 변경을 서버에 저장하되 화면 동작은 낙관적으로 유지한다.

## 4. 농작물 파내기

- 도메인 함수의 성공, 빈 밭, 수확 가능 밭 거부 테스트를 추가한다.
- 잠금과 저장을 사용하는 파내기 API 테스트를 추가한다.
- 성장 중 카드의 확인 동작과 성공 후 갱신을 UI 테스트로 고정한다.
- 도메인, API, UI를 구현한다.

## 5. 전직 로드맵 이동

- 1차 계열 파생과 이동 버튼 렌더링 테스트를 추가한다.
- 스크롤러에 노드·양 끝 이동용 명령 인터페이스를 추가한다.
- 상단 도구 모음 버튼이 선택, 포커스, 중앙 이동을 수행하게 한다.

## 6. 통합 검증

- 변경한 테스트 파일을 집중 실행한다.
- 타입 검사와 린트를 실행한다.
- 사용자 변경 파일을 제외하고 이번 작업 파일만 커밋한다.
