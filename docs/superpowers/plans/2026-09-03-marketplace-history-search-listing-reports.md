# 거래소 최근 거래 검색·판매 중 매물 신고 구현 계획

> 작성일: 2026-09-03

## 1. 최근 거래 검색

- `src/adventure/v2/marketplace/recentTradeSearch.ts`에 품목명 필터 함수를 추가한다.
- 단위 테스트에서 공백 검색어, 부분 검색, 대소문자 비교를 먼저 실패시킨다.
- `V2MarketplaceView` 최근 거래 탭에 검색 입력을 추가하고 필터 결과에 페이지네이션을 적용한다.
- 화면 테스트로 검색 입력과 기존 신고 동작이 함께 노출되는지 확인한다.

## 2. 판매 중 매물 신고 원본

- `marketplaceTradeReport.test.ts`에 활성 매물 스냅샷, 비활성 거부, 자기 신고 거부 테스트를 먼저 추가한다.
- `marketplaceTradeReport.ts`에 `marketplace_listing` 빌더와 resolver를 추가한다.
- DB에서 조회한 상태와 판매자 정보를 기준으로 신고 원본을 구성한다.

## 3. 신고 계약과 저장소

- `ugc-safety.test.ts`와 신고 API 테스트에 새 소스 유형의 허용·거부 조건을 먼저 추가한다.
- 공용 타입, 서버 resolver, API 콘텐츠 전용 검증을 새 소스 유형까지 확장한다.
- 스키마 체크 제약과 `0181_marketplace_listing_reports.sql`, Drizzle 저널 항목을 추가한다.
- `npm run check-migrations`로 마이그레이션 구성을 확인한다.

## 4. 사용자·운영 UI

- 신고 버튼 컴포넌트를 완료 거래와 판매 중 매물 양쪽에서 재사용할 수 있게 확장한다.
- 다른 사용자의 활성 매물에 신고 버튼을 표시하고 본인 매물에는 표시하지 않는다.
- 운영 신고 화면에서 판매 중 매물을 별도 라벨로 표시하고 관련 계정을 보여준다.
- 각 UI 테스트를 먼저 실패시킨 뒤 구현해 통과시킨다.

## 5. 완료 검증과 커밋

- 관련 Vitest 파일, TypeScript, ESLint, 마이그레이션 검사를 실행한다.
- 변경 diff와 사용자 변경 충돌 여부를 검토한다.
- 완료 전 검증 및 코드 리뷰 체크리스트를 적용한 뒤 현재 브랜치에 커밋한다.
