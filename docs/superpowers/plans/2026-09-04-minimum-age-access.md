# 만 14세 이상 접근 제한 구현 계획

1. 연령 확인 토큰의 생성·검증·만료 회귀 테스트를 먼저 작성하고 서명 유틸리티를 구현한다.
2. 동일 출처 요청만 받는 확인 API 테스트를 작성하고 HttpOnly 보안 쿠키 발급을 구현한다.
3. 로그인 대문의 미확인/확인 UI 테스트를 작성하고, 확인 후 서버 상태를 새로 읽도록 연결한다.
4. Proxy, Auth.js 로그인 콜백, 게임 레이아웃과 공통 API 인증 함수에 다층 차단을 추가하고 테스트한다.
5. 이용약관·개인정보처리방침·운영 체크리스트에 만 14세 기준과 자기확인 방식의 한계를 기록한다.
6. 관련 테스트부터 전체 테스트·정적 검사·프로덕션 빌드까지 실행하고 변경을 커밋한다.
