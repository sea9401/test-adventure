# Feedback 587 Implementation Plan

**Goal:** 생활 의뢰 하루 5회 교체, 경매 6/12/24시간 선택, 소모품 요리 필터, 미확인 본인 건의 수정/삭제.
**Architecture:** 기존 저장 및 API 흐름을 확장한다. 의뢰는 일별 사용 횟수와 분야별 누적 offset을 저장하며 기존 1회 저장값을 호환한다. 경매는 기존 종료시각 컬럼을 사용한다. 건의는 소유자 및 관리자 확인/답변 상태를 DB 변경 조건에 포함한다.
**Constraints:** 현재 브랜치에서 순차 실행, 서브에이전트/배포/외부 게시 없음. Next.js 설치 문서 준수. UI 불투명 surface 사용. 기존 세금·납품 제한 유지.

## 검증 결과
- 관련 18개 테스트 파일, 190개 테스트 통과.
- TypeScript: `NODE_OPTIONS=--max-old-space-size=6144 npx tsc --noEmit` 통과. 기본 Node 힙 2GB에서는 전체 프로젝트 검사 중 OOM이 발생해 검사 프로세스 한도만 확대했다.
- 변경 TS/TSX 파일 ESLint 및 `git diff --check` 통과.
- 직접 코드 리뷰: 교체 상태 재파싱, 일별 초기화, 분야별 완료 제한, 모든 매물 종류의 기간 전달, 미확인 조건부 UPDATE/DELETE, 삭제 후 접수 쿨다운 유지 확인.
- UI는 기존 불투명 surface와 라이트/다크 입력 배경을 사용하며, jsdom에서 필터 전환·음식 사용·경매 선택·건의 편집/삭제 확인을 검증했다. 브라우저 실화면/운영 검증과 배포는 수행하지 않았다.
