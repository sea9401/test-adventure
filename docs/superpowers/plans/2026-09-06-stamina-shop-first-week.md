# 회복약 주간제 첫 구매 기간 연장

9/6 주간제로 전환된 회복약의 첫 구매 기간을 9/13까지 연장한다. 9/7에는 8/31 주간 키에 저장된 회복약 구매량만 이월하고 9/14부터 정상 초기화한다. 당일 일간제 기록만 남아 있는 사용자도 9/6 구매량을 이어받는다. 문의 대상인 낚시 상점에 적용한다. 협동 상점은 이번 변경에 포함하지 않는다.

전체 달력 키는 유지한다. 각 상점 상태 파서에서 회복약만 이월하므로 다른 일간·주간 상품과 랭킹은 기존 주기를 유지한다. 읽기 시 변환하고 다음 구매 저장 시 새 주간 키로 저장한다. 이미 이전 주 기록이 초기화되어 저장된 경우 소실된 기록을 복원하지 않는다.

- [x] 테스트: 9/7 이월, 9/13까지 미접속 후 이월, 구매 후 재조회 중복 없음, 30개 한도 유지, 9/14 정상 초기화, 일간제 기록 이월, 다른 상품 정상 초기화.
- [x] 낚시 상점 상태 파서에 기간을 한정한 이월 분기 추가.
- [x] 관련 테스트 22개 및 린트 통과. 변경 검토 완료. 전체 타입 검사는 별도 협동 변경의 coopListSections.test.ts allowFreeSupport 누락으로 실패했다. 해당 파일만 커밋하며 배포하지 않는다.
