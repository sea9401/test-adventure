# 숙련 화면 시인성과 가독성 개선

사용자 요청에 따라 기존 숙련 화면의 표시와 스타일을 조정했다. 수치 계산, 공개 기준, 필터 및 고정 동작은 유지한다.

- 10~11px 글씨를 12px 이상으로 높이고 제목·항목 이름은 16px로 구분한다. 보조 글씨 대비와 행간, 영역 간 간격을 높인다.
- 분야 카드의 이름, 점수, 발견 수를 나누고 선택 카드에 외곽선을 표시한다.
- 등급 이름을 색상 배지로 표시하되 텍스트를 함께 유지한다.
- 목록에서 누적 횟수와 점수를 분리하고 다음 목표 횟수·진행률을 진행 막대와 함께 표시한다.
- 검색, 필터, 고정 및 페이지 버튼의 높이를 44px 이상으로 조정한다.
- 기존 불투명 표면 토큰과 라이트·다크 모드를 유지한다.

표시 중심 변경이므로 스타일 자체를 고정하는 새 테스트는 작성하지 않고 기존 상호작용·공개 기준 회귀 테스트를 재사용했다. 실제 컴포넌트와 프로젝트 CSS를 임시 브라우저 하네스에서 렌더링해 Chromium의 320/390/1024px 및 라이트/다크 6가지 조합을 확인했다. 긴 이름과 큰 숫자를 포함한 샘플에서 가로 넘침이 없었으며 보조 글씨 최솟값은 12px였다. 390px 양 테마 스크린샷을 직접 확인했다. 전체 게임 화면과 실제 계정 데이터에 대한 E2E 검증은 아니다.

검증: CodexMasteryPanel 테스트 21개, ESLint, 8GB 메모리 한도로 실행한 전체 TypeScript 검사 통과. 배포하지 않는다.
