# 건의 618 구현 계획

목표: 건의 여섯 항목을 기존 공통 UI와 점검 경로에 적용한다.
기술: React/Next.js, TypeScript, Vitest, PostgreSQL.
사용자 지침에 따라 추가 승인과 서브에이전트 없이 순차 실행한다.

- [x] 스킬 간략 효과와 장착/펼침/호버/포커스 구분 회귀 테스트 후 공통 라이브러리 수정.
- [x] 거래소 음식 payload의 품질별 효과·시간 렌더 테스트 후 표시 추가.
- [x] 반발 용어 및 관련 유니크 작동 조건 설명 추가, 아이템 상세에서 재사용.
- [x] 장착 해방 상태의 캐릭터 카드/공개 API 전달 테스트 후 수정.
- [x] 점검 중 정산 차단, 마감·만료 연장, 재시도·경계·롤백 테스트 후 점검 경로 연결.
- [x] 영향 테스트·타입·린트·변경 검토 후 현재 작업 브랜치 커밋.


검증 기록: 관련 Vitest 18개 파일 205개 테스트 통과. 전용 임시 PostgreSQL에서 2개 통합 테스트로 경계 시각·재실행·롤백 확인. TypeScript, 변경 파일 ESLint, 모듈 크기 검사 통과. 실제 컴포넌트 SSR와 생성 CSS로 Chromium PC 라이트·다크 장착/미장착 구분 및 호버 강조 확인. 기존 스킬 SP 테스트의 오래된 기본 8 기대값은 현재 데이터의 7로 갱신했다.

전체 개발 서버는 기존 instrumentation의 webpack edge 번들에서 fs 모듈 오류가 발생했다. 실제 앱 라우트 브라우저 검증 대신 동일 컴포넌트·CSS의 독립 렌더링과 컴포넌트 상호작용 테스트를 사용했다. 운영 배포와 실제 점검 조작은 하지 않았다.
