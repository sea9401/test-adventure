# 숙련 성장 중복 합산 수정

## 원인과 적용 범위

사냥은 `groups.cumLevel`(계열 총합)과 `jobCumLevel`(직접 플레이한 직업)에 같은 숙련도를 기록한다. 성장 함수가 두 맵을 모두 더해 계열과 직접 직업의 프로필을 중복 적용했다.

성장 입력은 `jobCumLevel`만 사용한다. 견습 병사·견습 기사·방패병·기사 등 모두 직접 기록을 해당 직업의 프로필로 한 번 반영한다. 계열 총계는 기존 표시·해금 용도로 보존한다. 직업 기록이 없는 과거 총계에서 견습 숙련도를 추정해 만들지 않는다.

현재 생애 시작 스냅샷, 확정 스탯 성장, 확정 HP/MP 기록은 변경하지 않는다. 공통 집계 함수를 쓰는 미래 스탯 성장·재전직 시작값·HP/MP 성장·미리보기에 수정이 적용된다. 계수와 확률 공식은 유지한다.

## 검증 절차

1. 동일 활동의 계열/직업 동시 적립을 회귀 테스트로 재현했다. 견습 병사 100이 힘 200으로 합산되는 실패를 확인했다.
2. 계열 합산 루프를 제거하고 직업별 단일 반영, 계열 총계 변화의 무영향, 과거 기록 보존 테스트를 통과시킨다.
3. 성장 테스트·미리보기·전직·사냥/아이템 경로를 검증한다. 시뮬레이터도 견습 구간의 직접 직업 기록을 저장하도록 맞춘다.
4. 타입 검사·린트·차이 검사를 마친 뒤 이번 수정만 커밋한다. 이번 요청은 로컬 수정이며 별도 운영 배포는 수행하지 않는다.

검증 결과: 중복 합산 회귀 7건과 전직 통합 22건 통과. 관련 전체 검사에서 나머지 2,378건은 통과했고, 공통 견습 테스트 입력에 직접 기록을 넣으며 생긴 기존 무시드 테스트 충돌은 입력을 해당 테스트에 한정하여 해결한 뒤 전직 테스트 전체를 재검증했다. TypeScript, 변경 파일 ESLint, git diff --check 통과.
