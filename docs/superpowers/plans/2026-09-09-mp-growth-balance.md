# MP 성장량 조정

사용자 요청: 성장 개편 후 Lv.100 MP가 기존보다 크게 증가하므로 기존 수준에 가깝게 조정한다.

- 새 생애 시작 MP 120~180과 정신·지능의 기존 영구 보정을 유지한다.
- 버전 2의 레벨당 기본 MP를 3~5에서 2~4로 조정한다. 시작 평균 +70을 99회 성장에서 대체로 상쇄한다.
- 정신·지능 각각의 추가 로그 숙련도 계수를 3에서 0.1로 조정한다. 소수 확률과 연속 성장 방식은 유지한다.
- 버전 1의 기본 범위와 단계 보정은 유지하되 공통 추가 숙련도 계수는 함께 조정한다.
- HP, 여섯 스탯, 기존 저장된 시작값·누적 MP는 소급 변경하지 않는다. 다음 성장부터 적용한다.

## 비교

정신·지능 관련 숙련도가 같고, 현재 재전직 시작 스탯과 기본 수행 한계를 양쪽에 동일하게 넣은 비교다. 개편 전 시작 MP 평균은 80+정신 단계, 레벨당 평균은 4+정신 단계 40%다. 숙련도는 생애 동안 일정하다고 가정한다. 장비·직업·패시브·스탯의 직접 MP 기여는 제외하므로 실제 유저 최종 MP의 보장 범위가 아니다.

| 숙련도 | 개편 전 Lv.100 생애 MP | 조정 후 | 차이 |
| --- | ---: | ---: | ---: |
| 0 | 476 | 447 | -6.1% |
| 5,000 | 478 | 464 | -3.0% |
| 100,000 | 782 | 818 | +4.6% |
| 1,000,000 | 1,086 | 1,171 | +7.8% |
| 10,000,000 | 1,391 | 1,525 | +9.6% |

이 문서의 MP 계수가 기존 continuous-mastery-growth 설계 문서의 MP 3배 및 MP 기본 3~5를 대체한다. 시작 MP와 HP 합의는 유지한다.

## 검증

새 회귀 테스트 7건의 변경 전 실패를 확인했다. 대표 숙련도 구간의 10% 이내 비교, 소수 숙련도에 따른 기대값 증가, 확정 자원 보존을 검사한다. 관련 성장·미리보기·재전직 통합 테스트와 타입·린트 검사를 수행한다.

관련 165개 파일 2,131개 테스트 통과. 확대 검사에서 현재 브랜치의 devGrantRoute 테스트 1건은 기존 고정 3점 예상값 때문에 실패했다. 운영 main에는 독립 성장에 맞춘 테스트가 이미 반영되어 있어 이번 변경에서 해당 파일은 건드리지 않았다.
