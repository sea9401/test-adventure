# 파라곤 구현 계획

합의: 그랜드 챔피언 + 절대자의 7차. 기존 공통 전직 조건을 따른다.

- 퍼펙트 폼: 평타 6회, 쿨다운 8행동, MP 90. 장착한 하위 선언 합성. 평타 방어 전 모든 능력치 합계 ×0.15 추가, 현재 공격력의 40% 상한.
- 브레이크 포인트: 공격력 ×3 + 모든 능력치 합계 ×0.2. MP 150. 적중 시 상대의 다음 적중한 직접 공격 피해 30% 감소, 중첩 없이 갱신. 회복·대기·DoT에는 소비하지 않는다. 다단 스킬은 시전 전체에 적용, 개별 평타는 1회씩 처리한다.
- 완성된 기량: 선언 시전 직후 평타 1회(선언 횟수 소비). 선언 중 공격 스킬은 연속 평타 누적을 초기화하지 않는다. 물약·다른 버프는 기존 초기화 유지. 기존 치명타 공식 유지.
- 기본 성장: 힘2, 나머지 능력치1. 직업 보너스 모든 능력치8. SP 하한20/16/12, 공통 비용 공식으로 최종 검증. 브레이크 포인트는 공통 7차 보정 후 발동률40%, 쿨다운0. 최종 SP20/16/12(총48), MP90/150/0.

순서: 회귀 테스트 → 카탈로그/공통 선언 헬퍼 → PvE·PvP 직접 공격 약화 → 실제 전투 검증 → 타입/린트/모듈 예산 → 로컬 커밋. 배포·통합 없음.

검증 결과:
- 전투·카탈로그·전직 경로 전체 3,020개 실행: 3,014개 통과, 기존 7차 목록 4개 전제의 검증 6개 실패를 목록 갱신으로 해결.
- 목록 수정 및 최종 변경 후 관련 13개 파일 440개 테스트 통과. 파라곤 전용 회귀 25개 별도 재확인 통과.
- TypeScript 전체 검사(6GB 힙), 변경 파일 ESLint, 모듈 예산, diff 공백 검사 통과.
