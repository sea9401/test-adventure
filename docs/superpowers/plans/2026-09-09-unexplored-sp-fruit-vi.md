# 미개척지 SP 열매 VI

- 범위: 노드 선택 후 `/battle/dungeon/unexplored`에서 하는 전용 사냥의 승리 보상. 일반 사냥, 노드 선택 자체, 개인 보스 보상은 제외.
- VI: 거래 가능, 1회당 최대 SP +1, 캐릭터당 5회. I~V는 각 3회 유지. 기존 저장의 VI 사용량은 0.
- 공용 독립 드랍: 기본/특수 몬스터 모두 0.005%(1/20,000), 1개. 노드/장비 배율·희귀 복사·천장 미적용. 기존 RNG 순서를 유지하도록 보상 처리 마지막에 추가.
- 기존 열매 정의와 사용 API를 확장하고 인벤토리 상태는 공용 파서로 처리한다.
