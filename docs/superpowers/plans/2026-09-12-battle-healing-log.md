# Battle Healing Log Implementation Plan

**Goal:** 같은 시전의 피해와 회복을 한 카드에서 표시한다.
**Architecture:** BattleLogList의 표시 그룹화에서 같은 스킬·주체·틱의 직접 회복을 피해 카드의 effects에 보존한다. 회복만 있는 시전과 다른 시전은 분리한다.
**Tech Stack:** React, TypeScript, Vitest.

사용자 지침에 따라 현재 세션에서 직접 실행하며 기존 다른 작업은 보존한다. 배포하지 않는다.

- [x] `BattleLogHealing.test.tsx`: 두 스킬과 양쪽 주체에 대해 피해+회복이 단일 행동이며 회복이 effects에 남는지 확인한다. 신고의 반복 시전 수치와 실제 마크업도 확인한다. 회복만 있는 경우와 다른 틱은 독립 카드여야 한다.
- [x] 해당 테스트 실패를 확인한다.
- [x] `BattleLogList.tsx`: 직접 행동 분기 앞에서 기존 피해 카드와 스킬명, 주체, 틱이 같은 HP/마나 회복 로그를 effects에 추가한다. damageActionHeadline은 피해 타격에만 사용한다.
- [x] 전투 로그 관련 테스트와 수정 파일 lint를 실행한다. diff를 자체 검토한 뒤 해당 파일만 커밋한다.

검증: 최초 9개 중 7개 테스트가 카드 분리로 실패했고, 수정 후 회복 마크업의 기존 쉼표 없는 형식에 맞춰 단언을 정정했다. 다단 피해/마나 회복 사례를 추가한 총 10개 회귀 테스트 및 관련 테스트 75개가 통과했다. 수정 파일 ESLint와 diff 검사가 통과했다. 서브에이전트 없이 직접 변경 범위·시전 경계·주체/틱 분리를 검토했다.
