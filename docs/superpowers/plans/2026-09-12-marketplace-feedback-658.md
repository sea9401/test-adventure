# 구현 계획

1. 실제 마감 시각 정렬, 미판매 본인 조회 조건, 동일 품목의 개별 관심 매물 회귀 테스트를 먼저 작성하고 실패 확인.
2. history API의 본인 미판매 모드와 browse API의 마감 정렬/관심 ID 조회 추가.
3. 관심 매물 저장 훅/버튼과 미판매 조회 훅을 분리하고 기존 화면에 연결. 오류/재시도와 페이지 초기화 포함.
4. 경매장 테스트, 타입 검사, 변경 파일 lint, 모듈 예산 확인 후 자체 diff 검토 및 로컬 커밋.

## 검증 결과

- 초기 회귀 테스트: 마감순·미판매 API·관심 매물 UI가 기존 구현에서 실패하는 것을 확인.
- 경매장 API/컴포넌트/훅 테스트: 30개 파일, 122개 테스트 통과.
- 모바일 미리보기: 320px/390px 가로 넘침 검사 2개 통과. DB 연결이 없는 미리보기 검증으로 실제 거래 실행을 검증한 것은 아님.
- 변경 파일 ESLint, 모듈 예산(12개 파일), diff 공백 검사 통과.
- 자체 검토: 미판매 조회의 판매자 범위와 공개 캐시 분리, 관심 번호/정렬의 DB 제한 이전 적용, 저장소 실패 안내, 매물 종류별 버튼 연결 확인.
- 최종 `NODE_OPTIONS=--max-old-space-size=8192 npx tsc --noEmit` 통과.
