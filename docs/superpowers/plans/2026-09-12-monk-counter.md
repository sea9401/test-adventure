# 무승 반격 독립 성능 개선

승인된 방향: 반격에 활력 피해를 추가하고 보호막이 흡수한 직접 공격에도 반격한다.

- 투승 반격·금강불괴·나한금신에 `counterVitCoef: 1`을 부여한다. 장착 합산은 최댓값으로 계수 중첩을 방지한다. 기존 반격 확률과 실패 확률 곱 방식은 유지한다.
- 반격 원량은 기존 버프 적용 ATK + 버프 적용 VIT × 계수다. 그 뒤 나한금신 증폭과 상대 방어를 기존 순서대로 적용한다. 최대 HP·DEF를 공격으로 변환하지 않는다.
- 위 세 패시브 장착 시 HP 피해 외에 일반 보호막/마나 실드가 흡수한 직접 타격도 반격 기회다. 회피·지속 피해·자해·반사 피해는 새 기회가 아니다. 피격 생존 조건은 유지한다.
- 기본 공격은 기존 타격별 판정, 다단 스킬은 기존 시전당 한 번 판정을 유지한다. 별도 추가 반격이나 반격 연쇄를 만들지 않는다.
- 다른 반사·룬 반격·구 패시브의 조건은 유지한다. 새 효과를 스킬 상세·장착 요약에 표시한다. SP/MP는 기존 비용 체계를 유지한다.

## 순서
1. 계수 장착/합산/derive와 PvE/PvP 보호막 기본·스킬 반격 회귀를 작성하고 실패 확인.
2. 공용 계수/조건 helper, 데이터, derive, 세 피해 경로를 연결한다.
3. 기존 보호막·반사·확정 회피 회귀와 관련 데이터 테스트, 타입/린트/파일 크기 검사.
4. 고정 ATK·VIT 변화 및 다단 직접 공격에서 기존 대비 피해/반격 횟수 비교를 기록하고 로컬 커밋. 배포하지 않는다.

완료: 순서 1~4 구현 및 검증 완료. 실패 회귀 9개를 먼저 확인했고, 추가 경계 사례를 포함한 전용 11개 및 전체 관련 3,722개 테스트가 통과했다. 상세 결과는 `../reports/2026-09-12-monk-counter.md`에 기록했다.
