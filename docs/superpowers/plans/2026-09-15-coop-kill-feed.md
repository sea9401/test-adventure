# 협동 보스 처치 피드 구현 계획

프로젝트 AGENTS.md에 따라 추가 승인 및 서브에이전트 없이 직접 진행한다.

**목표:** 전체 공개 보스만 전체 처치 피드를 발행한다.

**구현:** `src/app/api/v2/coop/attack/route.ts`에서 잠근 세션의 `parseCoopVisibility(s.visibility) === "public"`을 트랜잭션 결과의 내부 필드로 반환하고 `insertFeedEntry` 호출에만 조건을 적용한다.

1. `route.test.ts`에 공개/길드/개인 보스의 일반·무료 지원 처치 피드 및 개인 알림 회귀 테스트를 추가하고 실패를 확인한다.
2. 위 조건을 구현한다. 응답 body와 보상 처리는 유지한다.
3. 비처치와 잠금 중 전체 공개 전환도 검증한다.
4. 협동 보스 API 테스트, 변경 파일 ESLint, 타입 검사를 실행하고 변경 diff를 검토한다.
5. 이번 변경 파일만 현재 브랜치에 커밋한다.
