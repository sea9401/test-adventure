# 협동 보스 설정 구현 계획

**실행:** executing-plans를 사용해 직접 실행한다. AGENTS.md에 따라 추가 승인과 서브에이전트 없이 현재 브랜치에 변경을 남긴다.

**목표:** 자동 무료 지원 설정을 계정에 저장하고 내 활성 보스의 무료 지원/공개 범위를 일괄 변경한다.

**구조:** `coopPreferences.ts` 서버 헬퍼와 `/api/v2/coop/preferences` GET/POST를 만든다. 소환 및 낚시 생성은 저장된 기본값을 읽는다. `CoopManagementPanel.tsx`와 전용 hook/일괄 요청 함수를 분리해 기존 목록과 개별 API에 연결한다.

- [x] 설정 API와 소환·낚시 기본값 테스트를 먼저 추가하고 실패를 확인한다.
- [x] 기본값 false, 명시값 우선, 인증된 사용자 설정 저장을 구현하고 테스트한다.
- [x] 일괄 변경 테스트: 내 보스 필터, 만료 제외, 무료 지원 후 공개 순서, public 축소 제외, 부분 실패, 길드 없는 경우를 작성한다.
- [x] 일괄 요청 함수와 관리 UI를 구현한다. 저장된 자동 지원 값을 재조회하고 기존 소환 checkbox를 계정 설정으로 대체한다.
- [x] DOM 상호작용 테스트로 저장/재진입/실패/적용 버튼/중복 요청 차단을 검증한다.
- [x] 매뉴얼을 갱신하고 관련 전체 테스트, ESLint, TypeScript, diff 검토 후 이번 파일만 커밋한다.
