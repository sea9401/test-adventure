# 길드 창고 장비 상세·비교 구현 계획

목표: 보관 장비를 출고하지 않고 상세 및 착용 장비 비교를 조회한다.
구조: 창고 API에 착용 개체 목록을 추가하고 보관 카드에 기존 팝업을 연결한다.
기술: Next.js 16, React 19, TypeScript, Vitest.
제약: 배포/외부 쓰기 없음. 서브에이전트 없음. 입출고 권한 및 입고 후보 필터 유지.

- [x] 창고 GET 테스트에 착용·귀속 장비가 비교 응답에는 포함되고 입고 후보에서는 제외되는 사례를 추가하고 실패를 확인한다.
- [x] 창고 패널 테스트에 조회 전용 상세 열기, 같은 부위 비교, 미착용 상세, 닫기를 추가하고 실패를 확인한다.
- [x] GET에 equippedEquipment를 추가한다. 보관 장비 버튼에서 V2ItemCard를 열고 같은 부위가 있으면 V2ItemCompareCard로 전환한다.
- [x] 관련 Vitest, TypeScript, ESLint와 diff 검사를 수행하고 현재 브랜치에 커밋한다.
