# 연타 결계와 총계수 정리

사용자가 승인한 설계: 결계는 한 스킬의 같은 피해 유형 전체에 적용하고 1회만 소비한다.
연타 스킬은 총계수로 작성하되 기존 타격별 피해, 타수, SP 비용을 보존한다.
추가 기본공격의 발동·반사·반격·DoT 주기는 이번 변경 범위가 아니다.

## 구현

- [x] `tripleWard.test.ts`에서 모든 양수 타격 감소, 0 피해 무소비, PvP 5×100→300을 검증한다.
- [x] `tripleWardPvp.test.ts`에서 물리·마법 연타의 마지막 결계 1회로도 모든 타격 감소와 다음 스킬 무보호를 검증한다.
- [x] `tripleWard.ts`는 배열 전체를 감소시킨다. PvP는 스킬 내부에 피해 유형별 감소율을 저장해 후속 타격에 재사용한다. 영역 안정의 기존 다음 타격 적용은 유지한다.
- [x] `multiHitDamage.ts`에 총계수를 타격별 damage effect로 분배하는 함수를 만들고 기존 11개 동일 타격 연타를 총계수로 환산한다. 기존 엔진의 타격별 방어·반올림·특화 스탯 처리를 보존한다.
- [x] 기존 카탈로그 전체 effects와 변경 후 effects를 비교하고, 천룡난무 등 실제 피해 회귀 테스트를 실행한다.
- [x] 결계 설명의 첫 타격 문구를 전체 타격으로 갱신한다.
- [x] 전투·데이터 테스트, 타입 검사와 변경 파일 lint를 실행하고 변경 파일만 커밋한다.

현재 작업 트리의 생활 콘텐츠 변경과 파일이 겹치지 않으므로 현재 브랜치에서 작업한다.
배포·푸시·서브에이전트는 실행하지 않는다.

## 검증 결과

- 변경 전 저장한 카탈로그와 전환한 11개 스킬의 effects가 정확히 일치했다.
- PvE/PvP 각각 11종의 실제 타격별 피해와 총피해를 고정값으로 검증했다.
- 물리·마법 연타, 마지막 결계, 다음 시전, 혼합 피해 유형, 0 피해를 검증했다.
- 전투·데이터 관련 120개 파일 / 1,637개 테스트 통과.
- `node --max-old-space-size=6144 node_modules/typescript/bin/tsc --noEmit` 및 변경 파일 ESLint 통과.
- 초기 타입 검사는 기본 2GB 힙 한도에 도달하여 6GB 한도로 재실행했다.
- 인라인 리뷰: 캐시는 스킬별 생성, 소모·영역 안정은 유형별 1회, 추가 기본공격에는 캐시를 전달하지 않는다.
