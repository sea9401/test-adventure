# 성소 일자 노드 지도 수정

사용자 확정 요구: 폭풍 원정과 같은 원형 아이콘 선택 진행 방식, 경로는 일자 맵.

원인: 성소 화면이 경로를 읽기 전용 목록으로 표시하고 전투·선택 버튼을 별도 패널에 직접 노출했다.

설계: 기존 StormExpeditionRouteMap에 linear 배치를 추가해 PC·모바일에서 원형 노드 9개와 연결선을 한 줄로 보여준다. 모바일은 지도 영역만 가로 스크롤하며 현재 노드가 보이도록 한다. StormExpeditionNodeDialog를 재사용해 입장, 현재 전투·효과 선택, 완료·잠김 안내를 표시한다. 완료 후 서버가 지정한 다음 노드를 사용자가 선택해 계속한다. 기존 전투·보상·입장 횟수·서버 상태 전이는 유지한다. 원정 기본 지도는 기존 분기형 배치를 유지한다.

- [x] 노드 선택 전 행동 버튼이 없고, 노드 클릭으로 입장·전투·효과 선택 창을 여는 회귀 테스트 작성 및 실패 확인.
- [x] 일자 배치와 동일한 노드·연결선 컴포넌트 재사용 구현.
- [x] 완료·잠김 노드는 정보만 제공하고 전투 요청을 보내지 않는지 확인.
- [x] 기존 원정 지도·다이얼로그 및 성소 UI·API 테스트, 타입·린트 검사.
- [x] 라이트·다크 불투명 표면 및 모바일 지도 영역 가로 스크롤 확인 후 로컬 커밋. 새 수정의 배포는 별도 요청 시 수행.


검증 결과: 기존 화면에서 새 노드 클릭 회귀 3개가 의도대로 실패함을 확인한 뒤 수정했다. 원정 지도·선택창·명령 패널과 성소 UI·API 5개 파일 35개 테스트 통과. TypeScript는 기본 2GB 한도에서 OOM이 발생해 CI와 같은 4GB로 재실행하여 통과했다. 변경 파일 ESLint, 모듈 크기 64개, diff 공백 검사 통과.

실제 컴포넌트와 프로젝트 CSS를 사용하는 로컬 Vite 미리보기에서 API·라우터·전투 재생만 대체해 Chromium 검증을 수행했다. 390px·1280px 각각 라이트·다크에서 노드 9개가 같은 y좌표의 76px 원형 버튼으로 표시되고, 페이지 넘침 없이 지도 내부 스크롤 및 입장·전투 선택창 클릭이 동작했다. 배경은 불투명이며 브라우저 JS 오류가 없었다. 운영 DB 플레이나 새 변경 배포는 수행하지 않았다.
