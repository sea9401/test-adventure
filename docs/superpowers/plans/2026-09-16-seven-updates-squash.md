## 통합 조정

- 원본 브랜치와 커밋은 보존한다. 오래된 기준 브랜치 전체를 병합하지 않고 위 변경만 적용한다.
- 운영의 협동 보스 생성 헬퍼와 개인 보스 보상 경로를 유지하면서 공개 보스 피드 조건과 저장된 지원 설정을 결합한다.
- 기존 협동 공격 테스트를 유지하고 신규 피드 테스트를 별도 파일로 보존한다.
- 다단히트 수정은 운영에서 분리된 `engine.pvpSkills.ts`에 적용한다.
- 문장 HP·MP 계산은 분리된 `derivePlayerCombatV2Pure.ts`와 `derivePlayerCombatV2FromSaves.ts`에 연결한다.
- 최신 생애 시작 스탯·숙련도 성장 정책을 보존하고 레벨 성장 뒤 문장 추가 성장을 적용한다.
- 재전직 시 문장 추가 성장 초기화·스탯 수행 한계치 적용은 사용자 확정 정책이다.

## 검증

통합 후 전체 Vitest, TypeScript, 변경 파일 ESLint, 이미지 참조, 모듈 크기, diff 공백 검사를 실행한다.
실제 DB 플레이·모바일 화면 검증과 운영 CI·배포는 이번 스쿼시 작업에 포함하지 않는다.

### 완료 결과

- 운영 잠금 파일 그대로 `npm ci --ignore-scripts --no-audit --no-fund`로 격리 설치했다.
- 전체 Vitest: 1,351개 파일 / 10,972개 테스트 실행. 최초 실행은 10,910개 통과, 37개 실패, 25개 건너뜀.
- 실패 중 36개는 샌드박스의 하위 프로세스·로컬 서버 제한 때문이며 해당 10개 파일을 제한 밖에서 재실행해 모두 통과했다. 실제 운영 서비스 호출·배포는 하지 않았다.
- 나머지 1개는 비천무신 파공 UI 테스트의 이전 발동률·계수 기대값이었다. 통합된 확정 수치(발동 60%, 표시 민첩 계수 0.47/1.18)로 갱신하고 관련 2개 파일 9개 테스트를 재검증해 통과했다.
- 재검증 포함 실행 대상 최종 결과: 10,947개 통과, 25개 건너뜀. 전체를 한 번 더 실행한 결과가 아니라 최초 전체 실행과 실패 대상 재검증을 합산한 결과다.
- TypeScript 검사, 변경 파일 ESLint, 이미지 참조 검사(995장), 모듈 크기 검사(64개), diff 공백 검사 통과.
- 원본 작업 브랜치는 변경하지 않았다. 결과는 로컬 스쿼시 브랜치에 보존한다.
