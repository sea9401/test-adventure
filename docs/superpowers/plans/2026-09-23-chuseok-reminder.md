# 추석 이벤트 알림 구현 계획

**Goal:** 추석 출석·복주머니 참여 기회를 기존 출석 알림과 같은 방식으로 표시한다.
**Architecture:** 추석 API 상태를 공유하는 클라이언트 훅과 기존 메뉴·TabBar 배지를 연결한다.
**Tech Stack:** Next.js 16, React 19, TypeScript, Vitest, Testing Library.

프로젝트 지침에 따라 별도 설계 재승인이나 서브에이전트 없이 현재 브랜치에서 직접 실행한다.

- [x] 메뉴·이벤트 탭·하위 탭에 남은 활동이 표시되는 회귀 테스트를 작성하고 현재 실패를 확인한다.
- [x] `useChuseokReminder.ts`에 5분 캐시, 요청 합치기, 날짜·기간 경계 재조회, 최신 상태 보호를 구현하고 훅 동작을 검증한다.
- [x] `useChuseokEvent.ts`의 조회 결과를 알림에 연결한다. 메뉴는 월간 출석과 추석 알림을 함께 표시하고 각 탭은 자신의 조건으로 표시한다.
- [x] 출석·공격 완료 갱신, 시작 전·종료 후, 자정, 조회 실패와 늦은 응답을 검증한다.
- [x] 관련 Vitest, TypeScript, ESLint, diff 검사를 실행하고 자체 리뷰 후 커밋한다.

검증: 최초 화면 회귀 테스트에서 알림 부재로 3개 실패를 확인했다. 구현 후 관련 7개 파일의 27개 테스트, `npx tsc --noEmit`, 변경 TypeScript 파일의 ESLint, `git diff --check`가 통과했다. 기존 탭 테스트는 알림의 접근성 문구가 포함된 이름을 허용하도록 수정했다. 이벤트 분류 탭은 배지가 추가되어도 작은 화면에서 접근할 수 있도록 기존 TabBar의 가로 스크롤을 사용한다. 표면 배경은 기존 불투명 Card를 유지하며 브라우저 시각 검증은 실행하지 않았다.
