# 무승 반격 성능 개선 검증

반격·금강불괴·나한금신에 활력 100% 기반 원량을 추가했다. 같은 계열끼리 계수는 최댓값만 적용한다. ATK와 VIT 버프를 각각 적용한 뒤 기존 반사 증폭 및 상대 방어를 계산한다. 일반 보호막과 마나 실드에 흡수된 직접 공격도 반격 기회다.

기존 반격 확률(30/35/30%), 확률 합성, SP/MP 비용은 유지한다. 룬 반격과 반사에는 새 활력 계수를 적용하지 않는다. 기본 공격은 기존 타격별 판정을 유지하고 다단 스킬은 시전당 한 번만 판정한다.

## 고정 시드 비교

공격력 200, 상대 방어 0, 반격 확률 30%, 행별 1,000개 초기화 표본. PvE는 기본 공격 세 번, PvP는 난격 시전 한 번이다. 기존 조건은 활력 계수를 제외한 동일 PlayerCombat으로 재현했다. 전체 직업 승률 비교가 아니라 반격 단독의 피해와 발동 기회 검증이다.

무보호막 PvE의 반격 횟수는 전후 동일하다. VIT 300에서 발동당 피해는 200→500이며, 일반 보호막 완전 흡수 중에도 같은 500 피해 반격이 발생한다. PvP 다단 스킬은 모든 표본에서 시전당 반격이 최대 1회였다. 표본의 발동률을 전체 게임 승률이나 이론 발동 확률로 해석하지 않는다.
