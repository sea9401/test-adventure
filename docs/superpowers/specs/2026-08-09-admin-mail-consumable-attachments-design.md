# 관리자 대량 우편 소비 아이템 첨부 설계

## 목표

관리자 페이지의 대량 우편 `소비 아이템 첨부` 목록에 다음 세 아이템을 노출한다.

- 스태미나 회복약
- 수행 초기화 물약
- 100레벨 달성의 비약

수행 초기화 물약과 100레벨 달성의 비약은 기존 `무슨 코인샵 아이템 첨부` 목록에서는 제외해 중복 선택을 막는다.

## 구현 방식

관리자 우편 화면 전용 순수 헬퍼에 소비 아이템 옵션, 코인샵 아이템 옵션, 첨부 전송 변환을 둔다.

- 스태미나 회복약은 기존처럼 `staminaPotions` 수량으로 전송한다.
- 수행 초기화 물약과 100레벨 달성의 비약은 서버가 이미 지원하는 `cashItems` 배열로 전송한다.
- 코인샵 첨부에서 고른 아이템과 소비 아이템 첨부에서 고른 두 물약은 하나의 `cashItems` 배열로 합친다.
- 서버 우편 생성·수령 로직과 아이템 사용 효과는 변경하지 않는다.

## 검증

- 소비 아이템 옵션에 세 아이템이 정확히 포함되는지 검증한다.
- 코인샵 옵션에서 수행 초기화 물약과 100레벨 달성의 비약이 제외되는지 검증한다.
- 소비 아이템 선택값이 `staminaPotions`와 `cashItems`로 정확히 분리되는지 검증한다.
- 기존 관리자 우편 화면 테스트와 타입 검사를 실행한다.

## 제외 범위

- 새 우편 payload 필드 추가
- 아이템 효과·거래 가능 여부·상점 판매 여부 변경
- 관리자 우편 외 다른 지급 화면의 분류 변경
- 배포
