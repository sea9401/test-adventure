# 전투 로그 행동 카드 설계

## 목표

전투 로그를 행동 단위로 읽을 수 있게 정리한다. 평소에는 기술명·최종 결과·중요 상태 변화만 보여 주고, 필요할 때 해당 행동의 방어 계산을 펼쳐 확인할 수 있게 한다.

## 승인된 표시 방식

- 플레이어 행동은 왼쪽, 상대 행동은 오른쪽이라는 기존 레인 규칙을 유지한다.
- 직접 공격은 `행동자 · 기술명 / 최종 피해`를 한 카드의 머리말로 표시한다.
- 상태이상, 회복, 반사처럼 같은 행동에서 이어진 결과는 카드 아래의 불투명한 인셋 영역에 묶는다.
- `회피 경감`, `받피감`, `결의`, `인내`, `가드`, `굳건한 의지`처럼 매 공격마다 반복되는 방어 계산은 기본 화면에서 숨긴다.
- 숨긴 방어 계산은 카드의 `계산 상세`를 눌렀을 때 원래 수치와 대상이 보이게 한다.
- 보호막 흡수, 완전 회피, 사망, 회복처럼 실제로 발생한 사건은 기본 로그에 남긴다.
- `└`, `┘` 문자는 행동 카드 안에서 제거한다. 반사·회피 문장은 기존 로그의 주체와 대상을 보존한다.
- 한 번에 하나의 계산 상세만 열리게 한다.

## 데이터와 호환성

전투 엔진과 저장된 리플레이 형식은 변경하지 않는다. `BattleLogList`가 기존 `BattleLogEntry[]`를 표시 직전에 행동 카드로 묶으며, 과거 리플레이처럼 메타데이터가 부족한 로그도 현재의 텍스트·진영 폴백으로 처리한다.

직접 공격보다 먼저 기록되는 연속 방어 계산은 다음 직접 공격에 연결한다. 직접 공격 뒤부터 다음 직접 공격 전까지의 상태·회복·반사 로그는 직전 행동의 결과로 연결한다. HP/MP 스냅샷, 턴 구분선, 전투 시작·종료 안내는 기존 독립 표시를 유지한다.

## 컴포넌트 경계

- `BattleLogList`는 기존 틱/턴 박스 그룹화를 유지하고, 각 박스 안에서 행동 묶음을 만든다.
- 행동 카드 렌더러는 기술명과 결과를 분리하고, 선택적 계산 상세와 일반 효과를 렌더링한다.
- 호출부는 가능한 경우 플레이어와 상대 이름을 전달한다. 이름이 없는 예전·개발 호출부는 `나`, `상대`를 사용한다.
- 기존 `SURFACE_CARD`, `SURFACE_INSET`만 사용해 라이트·다크 모드 모두 불투명 표면을 유지한다.

## 접근성과 검증

- 상세 영역은 키보드로 조작 가능한 네이티브 `details/summary`를 사용한다.
- 요약 텍스트만 읽어도 무엇이 펼쳐지는지 알 수 있게 `계산 상세`로 표기한다.
- 순수 행동 묶음 함수의 순서·연결 테스트와 실제 정적 렌더링 테스트를 추가한다.
- 기존 그룹화, 치명타 라벨, 효과 레인, HP/MP 바 테스트를 회귀 검증한다.

## 범위 제외

- 전투 피해 공식과 장비 발동 조건은 변경하지 않는다.
- 로그 저장 스키마나 과거 리플레이 데이터를 마이그레이션하지 않는다.
- 전체 로그 검색·필터·별도 디버그 화면은 추가하지 않는다.
- 배포하지 않는다.
