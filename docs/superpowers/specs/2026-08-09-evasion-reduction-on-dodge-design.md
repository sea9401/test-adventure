# 일반 회피 경감 연동 `on_dodge` 설계

## 배경

일반 회피는 더 이상 공격을 완전히 빗나가게 하지 않고, 적중도와의 대결로 평타와 직접 피해 스킬의 피해를 줄인다. 그러나 `해연추적`, `봉인된 반지`, `왕도의 그림자`와 일부 속도 증가 장비는 여전히 `on_dodge` 완전 회피 사건에만 반응한다. 현재 실제 플레이에서 완전 회피를 만드는 대표 수단은 `그림자 도약`의 확정 회피이므로, 일반 회피 투자만 한 캐릭터에게 이 장비 효과가 사실상 작동하지 않는다.

## 목표

- 일반 회피 투자와 `on_dodge` 장비 효과를 다시 연결한다.
- 기존 회피 경감의 피해 계산은 바꾸지 않는다.
- 공격 한 번에 장비 효과가 여러 번 발동하지 않게 한다.
- PvE와 PvP에 같은 규칙을 적용한다.
- 확정 회피와 기존 완전 무효 분기의 동작은 보존한다.

## 검토한 방식

### 1. 회피 경감률을 발동 확률로 사용 — 채택

직접 피해가 일반 회피로 실제 경감되었을 때, 계산된 회피 경감률과 같은 확률로 `on_dodge` 반응을 한 번 발동한다. 회피 경감률이 30%라면 해당 공격에서 30% 확률로 장비의 회복·속도 효과가 함께 발동한다.

기존 회피 수치가 높을수록 효과가 자주 발동하고, 적중도가 높은 상대에게는 발동 빈도도 낮아진다. 기존의 확률 회피 체감과 가장 비슷하면서 현재 피해 경감 모델을 유지할 수 있다.

### 2. 회피 경감이 있으면 매번 발동 — 제외

회피도가 조금이라도 있으면 모든 피격에서 최대 HP 6~8% 회복이 발동한다. 다단 공격과 빠른 PvP에서 회복량이 지나치게 커지고, 낮은 회피 투자만으로도 효과를 전부 누릴 수 있어 제외한다.

### 3. 확정 회피 전용 유지 후 아이템별 재설계 — 제외

각 `on_dodge` 장비를 피격 회복, 피해 경감, 전투당 발동 등 서로 다른 효과로 교체하는 방식이다. 장비 정체성과 밸런스를 모두 다시 검토해야 하므로 이번 결함 수정 범위를 넘는다.

## 발동 규칙

1. 대상이 평타 또는 직접 피해 스킬을 받는다.
2. 일반 회피 경감률을 기존 공식으로 계산한다.
3. 회피 적용 전보다 적용 후 직접 피해가 실제로 1 이상 줄었을 때만 반응 판정 대상이 된다.
4. 난수 백분율이 회피 경감률보다 작으면 `on_dodge` 반응이 발동한다.
5. 한 번의 공격 행동 또는 한 번의 스킬 시전에서 다단 피해가 발생해도 판정과 발동은 한 번만 수행한다.
6. 피해를 적용한 뒤 생존한 대상에게 회복과 속도 증가를 적용한다. 회복은 최대 HP를 넘지 않는다.
7. 확정 회피가 먼저 발생한 경우에는 기존처럼 피해와 대상 효과를 무효화하고 `on_dodge`를 한 번 발동한다. 같은 공격에서 일반 회피 반응을 추가로 굴리지 않는다.
8. 가드·흘려막기처럼 회피가 아닌 완전 무효 효과는 새 일반 회피 반응을 만들지 않는다. 기존에 회피로 분류되어 있던 행운의 방패 등은 현재 동작을 유지한다.
9. 지속 피해, 반사 피해, 상태이상 피해에는 일반 회피 경감이 적용되지 않으므로 새 반응도 발생하지 않는다.

## 적용 대상

저장 데이터나 아이템 정의 형식은 바꾸지 않고 기존 `trigger: "on_dodge"`를 그대로 사용한다. 따라서 회복형과 속도형을 포함한 모든 기존 `on_dodge` 장비가 같은 규칙의 적용을 받는다.

장비 설명은 실제 판정을 드러내도록 다음 의미로 변경한다.

- 회복형: `회피 경감률과 같은 확률로 피격 후 HP +N% 회복`
- 속도형: `회피 경감률과 같은 확률로 피격 후 속도 +N% (M행동)`

## 구현 경계

- 회피 반응 확률 판정은 순수 헬퍼로 분리해 경계값을 직접 테스트한다.
- PvE 일반 공격, PvE 직접 피해 스킬, PvP 일반 공격, PvP 직접 피해 스킬의 피해 적용 지점에서 같은 헬퍼를 사용한다.
- 기존 `onDodgeHealAmount`와 `onDodgeSpeedBuff`는 효과 수집 함수로 유지한다.
- 전투 로그에는 장비의 고유 라벨과 실제 회복량 또는 속도 증가량을 기록한다.
- 데이터 마이그레이션과 기존 아이템 변환은 필요하지 않다.

## 테스트

- 경감률보다 낮은 난수에서는 반응이 발동하고, 같거나 높은 난수에서는 발동하지 않는다.
- 회피도가 없거나 정수 피해가 실제로 줄지 않으면 발동하지 않는다.
- PvE와 PvP의 평타에서 회복형·속도형 효과가 공격당 한 번만 발동한다.
- 직접 피해 스킬에서도 같은 규칙이 적용된다.
- 다단 스킬은 타격 수와 관계없이 한 번만 판정한다.
- 확정 회피는 기존 효과를 한 번만 발동하며 일반 회피 반응과 중복되지 않는다.
- 지속 피해와 상태이상 피해는 반응을 만들지 않는다.
- 장비 설명이 새 판정 규칙을 표시한다.

## 비범위

- 회피 경감 공식과 적중 공식 변경
- 장비별 회복·속도 수치 재조정
- 그림자 도약과 기타 확정 회피 스킬의 밸런스 변경
- 가드·방패·피해 무효 효과를 회피로 재분류
- 운영 배포
