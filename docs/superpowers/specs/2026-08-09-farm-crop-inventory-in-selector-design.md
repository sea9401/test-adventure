# 재배 씨앗 선택 카드 작물 보유량 표시

## 배경

농장 재배 탭의 씨앗 선택 카드는 현재 선택 가능한 씨앗의 보유량만 `보유 N개`로 표시한다. 수확한 작물의 보유량은 납품 탭의 농장 보관함에서만 확인할 수 있어, 어떤 작물을 더 재배할지 결정하려면 탭을 오가야 한다.

## 목표

- 재배 탭의 각 씨앗 선택 카드에서 해당 씨앗 수와 일반 수확 작물 수를 함께 확인할 수 있게 한다.
- 보유량이 0인 경우에도 `0개`를 명시해 정보가 누락된 것처럼 보이지 않게 한다.
- 잠긴 작물 카드에서도 재고 정보는 동일하게 보여준다.

## 선택한 접근

각 카드의 기존 보유량 영역을 `씨앗 N개 · 작물 M개` 형식으로 바꾼다. 씨앗 수는 `farm.seeds[crop.id]`, 작물 수는 `farm.inventory[crop.itemId]`에서 읽는다.

별도 재고 패널은 기존 납품 탭의 농장 보관함과 중복되고, 펼침형 상세 UI는 사용자가 다시 조작해야 하므로 사용하지 않는다. 희귀 수확물은 심을 작물 선택에 직접 대응하지 않고 기존 농장 보관함에서 확인할 수 있으므로 이번 카드 표시 범위에 포함하지 않는다.

## 구성과 데이터 흐름

- `AdventurerFarmPanel`이 이미 가지고 있는 `farm.inventory`를 `CropSelector`에 전달한다.
- `CropSelector`는 작물 정의의 `itemId`로 일반 수확 작물 수량을 조회한다.
- 서버 응답, 농장 저장 형식, 수확 및 심기 로직은 변경하지 않는다.
- 기존 불투명 카드 표면과 선택·잠김 스타일은 유지한다.

## 표시 형식

카드 하단 재고 배지는 다음처럼 두 값을 명시적으로 구분한다.

```text
씨앗 3개 · 작물 12개
```

두 값 모두 누락된 키는 0으로 처리한다. 큰 수량은 기존 화면 관례에 맞춰 한국어 로케일 천 단위 구분을 적용한다.

## 테스트와 합격 기준

- 농장 패널을 알려진 씨앗·작물 재고로 정적 렌더링했을 때 같은 카드에 두 수량이 모두 표시된다.
- 재고 키가 없는 작물은 씨앗과 작물이 모두 `0개`로 표시된다.
- 기존 농장 패널 테스트, 타입 검사와 프로덕션 빌드가 통과한다.
- 이미지와 API, 데이터베이스 변경은 없으며 배포하지 않는다.
