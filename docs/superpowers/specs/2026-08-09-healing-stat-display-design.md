# 회복량 상세 스탯 표시 설계

## 목표

캐릭터의 `내 정보 → 상세` 영역에서 현재 전투에 적용되는 최종 회복량 배율을 확인할 수 있게 한다.

## 표시 방식

- 상세 스탯 목록에 `회복량` 항목을 추가한다.
- 내부 배율 `healMult`에 100을 곱해 소수 첫째 자리까지 표시한다. 예를 들어 `1.2744`는 `127.4%`로 표시한다.
- 기본값 `1`도 `100.0%`로 표시한다. 회복 보너스가 없는 캐릭터에게도 스탯의 기준값을 보여 주기 위해 항목을 숨기지 않는다.
- 기존 `StatsPanel`의 불투명 `SURFACE_INSET` 셀을 그대로 사용하며 별도 표면을 추가하지 않는다.

## 데이터 흐름

서버의 `derivePlayerCombatV2`가 이미 정신·활력, 장비의 `healPowerPct`, 장착 패시브를 합산한 최종 `combat.player.healMult`를 계산한다. `/api/v2/me/state`의 `combatStatsSection`이 이 값을 `combat.healMult`로 전달하고, `V2CharacterScreen`이 `StatsPanel`에 넘긴다.

새 계산식이나 저장 필드는 만들지 않는다. 기존 권위값을 화면까지 전달하는 누락된 경로만 연결한다.

## 설명 문구

회복량 툴팁은 다음 내용을 안내한다.

> 회복 스킬·흡혈·일부 자가 회복에 적용되는 최종 배율입니다. 정신과 활력이 높을수록 커지며 장비의 회복 옵션과 장착 패시브도 반영됩니다.

회복 충전약, 치료소, 스태미나 회복처럼 `healMult`를 사용하지 않는 시스템은 설명에 포함하지 않는다.

## 테스트

- `combatStatsSection`이 파생 전투값의 `healMult`를 손실 없이 응답 섹션에 포함하는지 검증한다.
- `StatsPanel`이 `healMult: 1.2744`를 `회복량 127.4%`로 렌더링하는지 검증한다.
- 표시 필드가 없으면 기존 호출 화면에 회복량 항목을 추가하지 않아 레거시 호출부 동작을 유지한다.
- 관련 테스트, 전체 TypeScript 검사, 전체 테스트를 실행한다.

## 비변경 범위

- 회복량 산식과 전투 엔진 적용 방식
- 장비·스킬 밸런스 수치
- 아이템 카드의 개별 회복 옵션 표기
- 포션, 치료소, 스태미나 회복 UI
- 배포 및 운영 상태
