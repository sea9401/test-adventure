# 아이템·스킬 검색 분류 필터 설계

## 목적

거래소와 스킬 장착 화면에서 긴 목록을 이름 검색만으로 찾지 않아도 되도록, 이미 존재하는 분류 데이터를 이용한 조합 필터를 제공한다.

## 범위

- 거래소 구매 화면의 장비 탭에 표시 티어 필터를 추가한다.
- 스킬 장착 화면에 차수와 직업 계열 필터를 추가한다.
- 새 필터는 검색어, 거래소의 제작·즐겨찾기 필터, 스킬의 장착 상태·효과 종류 필터와 AND 조건으로 함께 적용한다.
- 서버 API, 저장 데이터, 매물 정렬 방식은 변경하지 않는다.
- 재료와 소모품은 공통 티어 체계가 없으므로 거래소 티어 필터 대상에서 제외한다.

## 분류 기준

### 아이템

- 장비 카탈로그의 내부 티어를 `v2EquipCatalogTierToDisplayTier`로 변환한 1T~6T를 사용한다.
- 현재 선택한 장비 부위 탭 안에서만 티어를 거른다.
- 알 수 없는 장비 ID는 특정 티어에 포함하지 않으며 `전체 티어`에서는 기존처럼 표시한다.

### 스킬

- `v2c_<jobId>_...` ID의 직업을 `V2_JOB_CATALOG`과 `LEGACY_CLASS_SPEC_BY_JOB`으로 해석한다.
- 차수는 직업 카탈로그의 1~6차를 사용한다. 시작 직업인 생존자(tier 0)는 사용자 관점에서 1차로 표시한다.
- `v2_skill_*` 공용 기본기와 `v2c_none_*` 모험가 스킬은 `공용`으로 분류한다.
- 옛 원소술사 ID는 기존 호환 매핑에 따라 4차·마법 계열로 분류한다.
- 계열은 전사, 무도, 마법, 도적, 생존의 다섯 뿌리 직업을 사용한다.
- 알 수 없는 스킬 ID는 `전체`에서만 유지해 오래된 세이브의 목록을 잃지 않게 한다.

## UI

- 거래소의 기존 `필터` 패널에 `아이템 티어` 선택 상자를 추가한다.
- 스킬 검색 입력 아래에 `차수`와 `계열` 선택 상자를 나란히 추가한다. 좁은 화면에서는 두 칸, 넓은 화면에서도 불필요하게 넓어지지 않게 한다.
- 선택지는 드롭다운으로 제공해 6개 차수와 5개 계열이 기존 칩 행을 과도하게 늘리지 않게 한다.
- 활성 필터 수와 초기화 동작에 새 필터를 포함한다.
- 모든 선택 상자는 명시적인 텍스트 레이블을 갖고 기존 불투명 입력 표면을 따른다.

## 상태와 오류 처리

- 필터는 화면 로컬 상태이며 서버나 `localStorage`에 저장하지 않는다.
- 거래소에서 재료·소모품 탭으로 이동하면 티어 상태는 보존하되 적용·활성 개수에서는 제외한다. 다시 장비 탭으로 돌아오면 사용자가 고른 티어가 복원된다.
- 스킬의 전투·생활 탭을 바꾸어도 차수·계열 선택은 유지한다.
- 조건 조합 결과가 없으면 기존 빈 결과 안내를 그대로 사용한다.

## 테스트

- 장비의 내부 티어가 표시 티어 필터에 정확히 매칭되는지 순수 함수로 검증한다.
- 공용, 1차, 고차, 옛 원소술사, 생활 스킬의 차수·계열 분류를 검증한다.
- 차수와 계열을 동시에 선택했을 때 둘 다 맞아야 통과하고 알 수 없는 ID가 특정 필터에 섞이지 않는지 검증한다.
- 관련 Vitest, TypeScript 검사, 이미지 참조 검사를 실행한다.
