# 숙련의 탑 주간 체크포인트 설계

## 목적

숙련의 탑 고층 이용자가 매일 첫 입장과 패배 후 재입장 때마다 1층부터 반복 전투해야 하는 부담을 줄인다. 한편 매주 한 번은 저층부터 다시 등반하게 해 탑 전체 구간의 의미를 유지한다.

## 진행 규칙

- 체크포인트는 10층 단위로 해금한다.
- 10층을 돌파하면 11층 시작, 20층을 돌파하면 21층 시작처럼 해당 체크포인트의 다음 층에서 시작할 수 있다.
- 탑의 최대 층은 50층이므로 마지막 시작 지점은 41층이다. 50층 돌파는 새 시작 지점을 만들지 않는다.
- 시작 가능한 최근 체크포인트는 이번 주 최고층으로 계산한다. 예를 들어 주간 최고층이 37층이면 최근 체크포인트 시작 층은 31층이다.
- 새로운 등반을 시작할 때 이용자는 `1층부터 시작` 또는 `최근 체크포인트부터 시작` 중 하나를 고른다.
- 새로운 등반은 날짜가 바뀐 뒤의 첫 입장과 패배로 현재 등반이 초기화된 뒤의 재입장을 포함한다.
- 이미 진행 중인 등반이 있으면 시작 지점을 다시 고르지 않고 현재 층 다음부터 이어간다.
- 아직 체크포인트를 해금하지 않은 주에는 1층 시작만 제공한다.

## 주간 초기화

- 주간 기준은 KST 월요일 00:00부터 다음 월요일 00:00까지다.
- 저장 상태에 주간 기준일과 주간 최고층을 둔다.
- API가 숙련의 탑 상태를 읽을 때 현재 주간 기준일과 저장된 값을 비교해 지연 초기화한다. 별도 cron 작업은 추가하지 않는다.
- 주가 바뀌면 주간 최고층과 주간 체크포인트만 초기화한다.
- 날짜가 바뀌는 기존 일일 초기화와 주간 초기화는 함께 적용될 수 있으며, 어느 순서로 실행해도 같은 상태가 되도록 한다.

## 유지되는 기록과 보상

- 역대 최고층은 주간 초기화와 관계없이 영구 유지한다.
- 10층 단위 최초 돌파 보상 수령 기록도 영구 유지한다.
- 당일 최고층, 일일 보상 수령 여부, 하루 첫 입장 스태미나 납부 여부는 기존처럼 KST 날짜가 바뀔 때 초기화한다.
- 체크포인트로 건너뛴 층은 당일 돌파로 간주하지 않는다. 체크포인트에서 시작한 뒤 실제로 승리한 층부터 당일 최고층과 일일 보상에 반영한다.
- 체크포인트 시작 자체에는 추가 스태미나나 재화를 요구하지 않는다. 하루 첫 실제 전투의 기존 스태미나 비용만 적용한다.

## 실패와 재입장

- 패배하면 기존처럼 현재 등반 층은 초기화하고 재입장 대기시간을 적용한다.
- 재입장 대기시간이 끝나면 1층 또는 이번 주 최근 체크포인트에서 새 등반을 시작할 수 있다.
- 패배해도 이번 주 최고층과 해금된 체크포인트는 유지된다.

## 화면 흐름

- 숙련의 탑 메인 화면에서 새 등반을 시작할 때 시작 위치 선택 영역을 표시한다.
- 선택지는 `1층부터`와 `최근 체크포인트 · N층부터` 두 개로 제한한다. 과거의 모든 체크포인트를 나열하지 않는다.
- 최근 체크포인트 선택지에는 해금 근거를 함께 표시한다. 예: `30층 체크포인트 돌파 · 31층부터 시작`.
- 진행 중인 등반에서는 기존 `다음 층 입장` 동작을 유지한다.
- 전투 화면과 재입장 안내의 `1층부터` 고정 문구는 선택 가능한 시작 위치를 반영하도록 바꾼다.

## 서버 검증과 호환성

- 시작 층은 클라이언트가 임의로 결정하지 않는다. 서버가 저장된 주간 최고층으로 허용 가능한 최근 체크포인트를 계산한다.
- 클라이언트가 요청한 시작 층이 1층도 아니고 서버가 계산한 최근 체크포인트도 아니면 요청을 거부한다.
- 진행 중인 등반에서는 시작 층 변경 요청을 거부해 층을 건너뛰거나 되돌리는 조작을 막는다.
- 기존 저장 데이터에 주간 필드가 없으면 현재 주의 주간 최고층을 0으로 간주한다. 따라서 배포 후 첫 주에는 모든 이용자가 1층부터 체크포인트를 다시 해금한다.

## 테스트

- 주간 최고층에 따른 최근 체크포인트 계산: 0~9층 없음, 10층은 11층, 37층은 31층, 50층은 41층.
- 같은 주에는 주간 최고층과 체크포인트가 유지되고 월요일 경계에서 초기화된다.
- 주간 초기화 뒤에도 역대 최고층과 최초 돌파 보상 기록은 유지된다.
- 새 등반에서 1층과 허용된 최근 체크포인트 시작을 받아들이고 임의 층 요청은 거부한다.
- 진행 중인 등반에서 시작 위치 변경을 거부한다.
- 체크포인트로 건너뛴 층이 당일 최고층이나 보상으로 기록되지 않는다.
- 첫 입장과 패배 후 재입장 모두 선택한 시작 위치를 적용한다.
- 기존 저장 상태를 읽을 때 안전하게 주간 필드를 채운다.

## 제외 범위

- 역대 최고층 랭킹 규칙은 바꾸지 않는다.
- 탑의 층 수, 수호자 난이도, 보상량, 스태미나 비용, 재입장 대기시간은 바꾸지 않는다.
- 운영 배포나 점검 모드 변경은 수행하지 않는다.
