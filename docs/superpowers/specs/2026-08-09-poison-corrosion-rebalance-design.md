# 독 맹독·부식 재조정 설계

## 목표

독이 회피 피해 경감을 무시하는 지속 피해라는 정체성은 유지하되, 중독 하나가 회피와 방어력을 동시에 과도하게 카운터하지 않게 한다. 독 피해와 방어 감소를 별도 패시브 투자로 나누고, 기존 독 빌드의 직접 피해 손실은 중독 중첩 보상으로 일부 보완한다.

## 확정 규칙

- 방어 감소는 퍼센트 방식과 남은 방어력 기준 곱연산을 유지한다.
- 독술사부터 역병 군주까지 각 직업은 기존 `부식 I~IV`와 별도인 `맹독 I~IV`를 제공한다.
- `부식`은 대상이 중독된 동안 물리 방어만 낮춘다.
- `맹독`은 중독 지속 피해만 높이며 대상 방어에는 영향을 주지 않는다.
- 6차 패시브 `만독지배`는 계보 정점이므로 맹독과 부식을 모두 제공한다.
- 부식과 일반 물리 방어 감소를 합친 최종 퍼센트 방어 감소는 60%에서 멈춘다.
- 관통, 고정 방어 감산, 방어 무시 피해는 60% 상한과 별도다.
- 새 중첩 폭발 액티브나 중독 스택 소모는 추가하지 않는다.

## 패시브 수치

| 직업 | 부식 | 맹독 | 각 패시브 SP |
| --- | ---: | ---: | ---: |
| 독술사 | 6% | 중독 피해 +24.4% | 4 |
| 맹독술사 | 7% | 중독 피해 +24.4% | 4 |
| 독왕 | 9% | 중독 피해 +24.4% | 4 |
| 역병 군주 | 12% | 중독 피해 +24.4% | 6 |
| 독황 (`만독지배`) | 14% | 중독 피해 +24.4% | 11 |

부식 다섯 단계를 모두 장착하면 `1 - 0.94 × 0.93 × 0.91 × 0.88 × 0.86 = 39.79489504%`다. 맹독 네 단계와 `만독지배`를 모두 장착하면 중독 피해가 `122%`, 즉 `2.22배`가 된다.

하위 단계에서 맹독과 부식은 같은 SP 비용의 선택지다. 양쪽을 모두 장착할 수도 있지만 그만큼 SP를 각각 지불한다. `만독지배`의 기존 LUK·최대 HP·회피·치명타 피해 효과와 SP 비용은 유지한다.

## 중첩 보상

- `역병 창궐`의 `stackPayoffDamage.perStackFlat`: `40 → 55`
- `만독개화`의 `stackPayoffDamage.perStackFlat`: `48 → 65`
- 보상 계수 변경으로 자동 SP 루브릭이 오르더라도 기존 비용 `8/12 SP`는 유지한다.

이는 방어를 무시하는 중첩당 고정 보상 부분만 높인다. 스킬 전체 직접 피해는 기존처럼 회피 피해 경감을 받으므로, 방어 대응력을 보완하면서 회피까지 동시에 강하게 카운터하지 않는다. 중독 적용 스택, 지속시간, 발동 확률, MP 비용과 중첩 소모 여부는 바꾸지 않는다.

## 기존 이용자 호환

기존 `부식 I~IV` 중 하나를 이미 학습한 저장에는 대응 `맹독 I~IV`를 학습 목록 끝에 한 번 추가한다.

- 현재 장착 목록에는 자동으로 넣지 않는다.
- 로드아웃 프리셋, 전투 패턴, 즐겨찾기, 강화 정보는 바꾸지 않는다.
- 이미 대응 맹독을 보유했다면 중복 추가하지 않는다.
- 마이그레이션을 다시 실행해도 저장 버전과 학습 목록이 다시 변하지 않는다.
- 마이그레이션 이후 새로 부식을 배우는 이용자는 맹독을 별도로 배워야 한다.

## 전투 적용

PvE와 PvP가 같은 규칙을 사용한다.

1. 중독 DoT를 만들 때 장착 맹독의 합산 수치로 `1 + poisonDamagePct / 100`을 곱한다.
2. 출혈과 다른 상태 피해에는 맹독 배율을 적용하지 않는다.
3. 물리 방어 계산 시 현재 적용되는 일반 방어 감소와, 대상이 중독됐을 때의 부식을 곱연산으로 합친다.
4. 합산 결과를 최대 60%로 제한한 뒤 관통 적용 후 남은 방어에 한 번 적용한다.

## 검증 기준

- 네 직업이 부식과 맹독을 별도 학습 선택지로 제공한다.
- 완성 부식은 약 `39.794895%`, 완성 맹독은 `+122%`다.
- 기존 독 패시브 SP 비용은 `4/4/4/6/11`이고 새 맹독은 `4/4/4/6`이다.
- 맹독은 PvE·PvP 중독 피해만 높이고 부식은 중독 피해를 높이지 않는다.
- 물리 방어 감소는 부식과 합쳐 60%에서 멈춘다.
- 기존 부식 보유자 백필은 장착을 바꾸지 않고 멱등이다.
- `역병 창궐`과 `만독개화`의 실제 중첩 보상 증가와 기존 `8/12 SP` 유지가 전투·카탈로그 테스트에서 확인된다.
- 배포하지 않는다.
