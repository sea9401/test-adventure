# 스킬 장착 능력치 피드백 설계

## 목적

스킬을 장착하거나 해제한 뒤 `내 정보` 화면으로 이동하지 않아도 실제 적용된 주요 전투 능력치와 직전 변경분을 스킬 화면에서 확인할 수 있게 한다.

## 범위

- `/api/v2/me/state`가 이미 반환하는 서버 계산 결과를 사용한다.
- 장착 저장이 성공한 뒤 상태를 다시 조회하고 직전 스냅샷과 비교한다.
- 공격력, 마법 공격력, 방어력, 마법 방어력, 속도, 적중도, 회피도, 치명타율, 최대 HP, 최대 MP, 전투력을 표시한다.
- 직접 표시 능력치를 바꾸지 않는 패시브는 기존 `SkillEffectChips` 설명을 유지하고, 최근 비교에는 `주요 능력치 변동 없음`으로 안내한다.
- 가상 장착 전 미리보기와 서버 전투 파생 로직의 클라이언트 복제는 이번 범위에서 제외한다.

## 반응형 UI

- 데스크톱(`lg` 이상): 스킬 목록 오른쪽에 불투명한 요약 카드를 배치하고 스크롤 시 상단에 고정한다.
- 모바일: 같은 요약을 목록 위의 접이식 카드로 제공한다. 플로팅 패널이나 화면 하단 오버레이를 사용하지 않는다.
- 최근 변경된 값은 이전 값, 현재 값, 증감치를 함께 표시하고 색상만으로 의미를 전달하지 않도록 `+`/`-` 기호를 병기한다.
- 변경이 없는 값은 현재 값만 표시한다.

## 데이터 흐름

1. 스킬 화면 최초 조회 시 현재 주요 능력치 스냅샷을 저장한다.
2. 장착 API 저장 성공 후 기존 `onChanged` 갱신을 완료할 때까지 장착 버튼을 잠근다.
3. 새 `/me/state` 응답에서 다음 스냅샷을 만들고 이전 스냅샷과 비교한다.
4. 새 스냅샷을 현재 값으로 표시하고, 직전 장착 변경에서 달라진 항목만 최근 변경 영역에 남긴다.
5. 갱신 실패 시 기존 스냅샷과 장착 UI를 유지하고 허위 증감치를 표시하지 않는다.

## 컴포넌트 경계

- 순수 유틸: 상태 응답을 표시 스냅샷으로 정규화하고 두 스냅샷의 차이를 계산한다.
- `LoadoutStatSummary`: 현재 수치와 최근 변경을 렌더하는 독립 컴포넌트다.
- `V2SkillLearnView`: 상태 조회, 스냅샷 보관, 장착 전후 비교를 담당한다.
- `V2LoadoutPanel`: 저장 성공 후 부모 갱신 Promise를 기다려 연속 조작으로 비교 기준이 섞이지 않게 한다.

## 오류와 접근성

- 숫자가 없거나 비유한 값이면 해당 항목을 제외한다.
- 모바일 접이식 버튼은 `aria-expanded`를 제공한다.
- 최근 변경 영역은 `aria-live="polite"`로 저장 완료 후 변화를 알린다.
- 모든 표면은 `SURFACE_CARD` 또는 `SURFACE_INSET`을 사용해 배경 이미지가 비치지 않게 한다.

## 테스트

- 스냅샷 정규화와 증감 계산 단위 테스트
- 증가, 감소, 무변동, 선택 능력치 누락 렌더 테스트
- 데스크톱 요약과 모바일 접이식 요약이 함께 렌더되는지 정적 마크업 테스트
- 장착 저장 성공 시 비동기 `onChanged` 완료를 기다리는 동작 테스트
- 관련 Vitest, TypeScript 검사, 이미지 참조 검사를 실행한다.
