# 천궁·검성 6차 패시브 재설계

## 목표

- 천궁의 속도 전환 패시브가 6차 진입 직후부터 작동하게 한다.
- SPD 1,024 행동 빈도 상한 이후에도 속도 투자의 가치가 완만하게 이어지게 한다.
- 검성의 6차 패시브를 방어 효과 없이 기존 공격 능력과 단일 일격 강화에 집중시킨다.
- 기존에 학습하거나 장착한 스킬 ID는 유지해 저장 데이터 마이그레이션을 만들지 않는다.

## 천궁: 성도 조준

`v2c_heavenlybow_starpath`의 기존 `SPD 1,024 초과분` 전환을 전체 SPD 기반 점감 전환으로 교체한다.

공격력 증가율은 다음 식으로 계산한다.

```text
공격력 증가율 = 30 × SPD / (SPD + 500) (%)
```

이 식은 하드캡 없이 30%를 향해 점근한다. SPD가 늘 때마다 공격력은 계속 증가하지만, 행동 빈도 증가와 공격력 증가가 함께 폭주하지 않도록 고속 구간의 효율은 점차 낮아진다.

| 최종 SPD | 공격력 증가 |
| ---: | ---: |
| 300 | 11.25% |
| 500 | 15.00% |
| 800 | 18.46% |
| 1,024 | 20.16% |
| 1,500 | 22.50% |
| 2,000 | 24.00% |

- 전환에는 직업 효과까지 반영된 최종 SPD를 사용한다.
- 공격력 증가는 물리 공격력에 한 번 적용한다.
- SPD 1,024까지는 행동 빈도와 공격력이 함께 성장하고, 1,024 이후에는 공격력만 완만하게 성장한다.
- `성도 조준`의 다른 효과와 SP 11은 유지한다.
- 표시 문구는 임계치나 초과분을 언급하지 않고, 속도에 비례해 공격력이 증가한다고 안내한다.

## 검성: 일검필살

`v2c_swordsaint_transcendence`의 ID는 유지하되 이름을 `일검필살`로 바꾸고 다음 공격 효과를 제공한다.

- 힘 +24%
- 치명타 피해 +35%
- 단일 타격 물리 공격 스킬 피해 +30%
- 명중도 +15%
- 받는 반사 피해 -20% 제거
- SP 11

단일 타격 물리 공격 스킬은 `category: "attack"`이면서, 효과 목록에 비마법 `kind: "damage"`가 정확히 하나 있고 다른 직접 피해 효과는 없는 스킬을 뜻한다. 무심검과 검격은 적용 대상이다.

다음 피해에는 적용하지 않는다.

- 일반 공격
- 직접 피해 판정이 둘 이상인 연타 스킬
- 마법 피해 스킬
- 체력 소모·처형·기습·중첩 폭발처럼 별도 피해 규칙을 사용하는 스킬
- 중독·출혈 등 지속 피해
- 반사·반격 피해
- 회복을 피해로 바꾸는 효과

다른 직업이 검성 계보를 익힌 뒤 조건을 충족하는 단일 타격 물리 스킬을 장착하면 효과를 사용할 수 있다. 현재의 직업 전용 장비 제한은 새로 추가하지 않는다.

## 구현 경계

- 천궁 전환은 기존 초과 속도 필드와 상수를 전체 속도 점감 전환 의미로 교체한다.
- 일검필살은 스킬 해석 단계에서 해당 스킬의 직접 피해 판정 수와 피해 유형을 확인해, 조건을 충족한 한 번의 피해 판정에만 배율을 적용한다.
- 전환·일검필살 모두 미장착 상태에서는 기존 전투 결과와 직렬화 형태를 바꾸지 않는다.
- 기존 스킬 ID를 재사용하므로 학습 데이터, 장착 데이터, SP 환불 마이그레이션은 만들지 않는다.

## 검증

- 천궁 전환 단위 테스트: SPD 0·300·500·1,024·2,000의 공격력 증가율과 단조 증가·점감을 확인한다.
- 천궁 회귀 테스트: SPD 500에서 공격력 +15%, SPD 1,024 이하에서도 효과가 적용됨을 확인한다.
- 검성 단위 테스트: 단일 타격 물리 스킬에는 +30%, 연타·마법·지속 피해·일반 공격에는 미적용됨을 확인한다.
- 데이터 테스트: 이름, 설명, 패시브 수치, SP 비용과 기존 스킬 ID 유지를 확인한다.
- 전투 시뮬레이션: 기존 검성, 새 일검필살 검성, 천궁의 천공 균열 사냥 성능을 비교해 의도치 않은 지배 빌드가 생기지 않았는지 확인한다.
- 전체 테스트와 TypeScript 타입 검사를 통과시킨다.
