# 숙련 증서 소모품 사용 모달 설계

## 배경

교역소의 `숙련 증서 묶음`을 구매하면 `inventory.v2.masteryCertificates`에
숙련 증서 10개가 적립된다. 그러나 사용 UI는 숙련의 탑 화면에만 있어, 교역소나
출석 보상으로 증서를 처음 얻은 이용자가 사용처를 찾기 어렵다.

숙련 증서는 이미 인벤토리에 수량형 아이템으로 저장되므로 저장 구조를 바꾸지
않고 소모품 탭에 노출한다. 인벤토리와 숙련의 탑은 동일한 사용 모달을 공유한다.

## 목표

- 인벤토리 소모품 탭에서 숙련 증서의 보유 수량과 용도를 바로 확인할 수 있다.
- 인벤토리와 숙련의 탑 어디에서든 같은 절차로 증서를 사용할 수 있다.
- 직업 숙련도 투자와 숙달 포인트 1:1 전환 기능을 모두 유지한다.
- 인벤토리에서 증서를 확인하거나 사용할 때 숙련의 탑 진행 상태와 일일 정산에
  불필요한 부수효과를 일으키지 않는다.
- 기존 서버 검증, 트랜잭션, 경제 기록을 유지한다.

## 제외 범위

- 숙련 증서의 획득량, 교역소 가격, 주간 구매 제한 변경
- 직업 숙련도 및 숙달 포인트 전환 비율 변경
- `inventory.v2.masteryCertificates` 저장 위치 변경이나 데이터 마이그레이션
- 숙련의 탑 보상 및 전투 규칙 변경

## 사용자 경험

### 인벤토리 소모품 탭

숙련 증서를 1개 이상 보유하면 소모품 목록에 `숙련 증서` 카드를 표시한다. 카드에는
아이콘, 보유 수량, `직업 숙련도 또는 숙달 포인트로 전환`한다는 설명과 `사용` 버튼을
제공한다. 교역소 상품명은 묶음 단위인 `숙련 증서 묶음`을 유지하되, 인벤토리에서는
개별 재화명인 `숙련 증서`로 표시한다.

`사용` 버튼을 누르면 공용 숙련 증서 사용 모달이 열린다. 보유량이 0이 되면 모달을
닫은 뒤 카드가 소모품 목록에서 사라진다.

### 숙련의 탑

기존의 긴 인라인 사용 폼은 보유 수량과 `사용` 버튼이 있는 간단한 카드로 바꾼다.
버튼은 인벤토리와 같은 공용 모달을 연다. 따라서 기존 이용자는 숙련의 탑에서도
계속 증서를 사용할 수 있다.

### 공용 사용 모달

모달은 열릴 때 최신 보유량과 사용 가능한 직업 목록을 불러온다. 두 가지 사용 모드를
제공한다.

1. `직업 숙련도`: 직업군 탭에서 해금된 대상 직업을 선택하고 수량을 입력한다.
2. `숙달 포인트`: 증서 1개를 공용 숙달 포인트 1점으로 전환할 수량을 입력한다.

수량 입력의 초기값은 현재 보유량 전체이며 1개 이상, 보유량 이하로 제한한다. 실행
버튼 주변에는 선택한 결과를 미리 표시한다. 직업 숙련도 모드에서는 대상 직업과 사용
후 예상 숙련도를, 숙달 포인트 모드에서는 획득할 숙달 포인트와 되돌릴 수 없다는
안내를 표시한다.

사용 중에는 중복 제출을 막는다. 성공하면 모달의 보유량을 응답값으로 갱신하고,
호출 화면의 인벤토리·숙련도 상태도 다시 불러온다. 남은 증서가 0개면 성공 알림 후
모달을 닫는다.

## 구조

### 공용 UI

기존 `V2MasteryTowerView`의 증서 사용 폼을 독립된
`MasteryCertificateUseModal` 컴포넌트로 분리한다. 모달은 열림 상태, 닫기 콜백,
사용 성공 콜백만 외부에서 받고 조회·선택·제출 상태는 내부에서 관리한다.

인벤토리와 숙련의 탑은 각각 모달의 진입 카드만 소유한다. 직업 필터링, 수량 검증,
결과 안내 문구는 공용 컴포넌트에 한 번만 둔다.

### 조회 경로

증서 전용 읽기 API를 추가해 다음 데이터만 반환한다.

- 현재 숙련 증서 보유량
- 증서를 사용할 수 있는 해금 직업의 ID, 이름, 차수, 직업군, 현재 숙련도

이 조회는 `character.v2`, `proficiency.v2`, `inventory.v2`만 읽는다. 기존
`GET /api/v2/mastery-tower`를 호출하지 않으므로 인벤토리에서 모달을 열 때 탑 날짜
롤오버, 전날 미수령 보상 자동 지급, 스태미나 갱신을 유발하지 않는다.

### 사용 경로

기존 `POST /api/v2/mastery-tower/use-certificate`를 두 화면에서 공통으로 사용한다.
이 경로가 보유량과 직업 해금 여부를 서버에서 다시 검증하고, 증서 차감과 숙련도 또는
숙달 포인트 지급을 하나의 트랜잭션으로 처리한다. 기존 경제 이벤트 기록도 유지한다.

UI가 보내는 값은 기존과 동일하다.

- 직업 숙련도: `{ mode: "mastery", jobId, amount }`
- 숙달 포인트: `{ mode: "proficiency", amount }`

## 오류 처리

- 보유량 없음: 모달 보유량을 다시 조회하고 `보유한 숙련 증서가 없습니다`를 표시한다.
- 잘못되거나 잠긴 직업: 목록을 다시 조회하고 대상 직업을 다시 선택하도록 안내한다.
- 낚시·농사 등 사용 불가 직업: 서버 검증을 유지하며 공용 목록에서는 처음부터 제외한다.
- 네트워크 오류: 모달 입력값을 보존하고 재시도할 수 있게 한다.
- 사용 중 다른 화면에서 수량이 바뀐 경우: 서버가 실제 보유량으로 사용량을 제한한
  응답을 기준으로 화면을 갱신한다.

모달을 닫는 행위는 어떤 저장 요청도 만들지 않는다.

## 접근성과 반응형

- 모달은 기존 공용 모달의 포커스 이동, ESC 닫기, 배경 스크롤 잠금 패턴을 따른다.
- 모드 선택은 버튼의 `aria-pressed`, 직업군은 탭 역할과 명확한 레이블을 유지한다.
- 모바일에서는 직업 목록과 수량 입력 영역만 모달 내부에서 스크롤되며 실행 버튼은
  접근하기 쉬운 하단에 둔다.
- 데스크톱에서도 최대 너비를 제한해 직업 카드와 수량 정보가 지나치게 넓어지지 않게 한다.

## 검증

- 증서 보유 시에만 인벤토리 소모품 카드가 나타나는지 확인한다.
- 인벤토리와 숙련의 탑 양쪽에서 동일한 모달이 열리는지 확인한다.
- 모달 조회가 숙련의 탑 롤오버 로직을 호출하지 않는지 API 테스트로 확인한다.
- 직업 숙련도 사용 시 선택한 직업의 숙련도와 잔여 증서가 갱신되는지 확인한다.
- 숙달 포인트 전환 시 1:1로 지급되고 잔여 증서가 갱신되는지 확인한다.
- 사용 성공 후 인벤토리 카드 수량과 숙련의 탑 보유량이 즉시 갱신되는지 확인한다.
- 0개, 초과 수량, 잠긴 직업, 중복 클릭, 네트워크 실패를 회귀 테스트한다.
- 모바일과 데스크톱에서 모달이 화면을 벗어나지 않고 키보드로 조작 가능한지 확인한다.

## 완료 기준

- 교역소에서 숙련 증서 묶음을 구매한 이용자가 다른 화면 안내 없이 인벤토리 소모품
  탭에서 사용처를 발견할 수 있다.
- 두 진입점은 동일한 서버 데이터와 공용 UI를 사용해 기능과 문구가 서로 어긋나지 않는다.
- 기존 숙련의 탑 사용자 동선과 숙련 증서 사용 원장이 유지된다.
