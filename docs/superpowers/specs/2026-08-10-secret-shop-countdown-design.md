# 비밀 상점 남은 시간 표시 설계

## 목적

비밀 상점 지도는 발견 후 30분 동안만 유효하지만 현재 화면에는 고정 안내만 있어 남은 시간을 알 수 없다. 비밀 상점 제목 아래의 기존 안내문에 실제 남은 시간을 표시한다.

## 화면 동작

- 기존 문구 `품목당 1회 구매 · 비밀 상점 지도는 발견 후 30분 동안 개방` 뒤에 `· 남은 시간 MM:SS`를 붙인다.
- 남은 시간은 1초마다 갱신하며 1시간 미만인 현재 지도 정책에 맞춰 분과 초를 두 자리로 표시한다.
- 시간이 끝나면 구매를 막고 `비밀 상점 이용 시간이 종료되었습니다`를 알린 뒤 사냥터 화면으로 돌아간다.
- 로딩 중이거나 유효하지 않은 지도에는 카운트다운을 표시하지 않는다.

## 데이터 흐름

- 비밀 상점 GET API가 권위 있는 지도 `foundAt`과 `RARE_MAP_TTL_MS`로 `expiresAt`을 계산해 응답한다.
- 응답에는 클라이언트 시계 오차를 보정할 수 있도록 `serverNow`도 포함한다.
- 클라이언트는 `expiresAt - serverNow`로 초기 남은 시간을 계산하고 로컬 경과 시간만 차감한다.
- 구매 후 새로고침에서도 같은 지도 만료 시각을 다시 받아 카운트다운을 보정한다.

## 오류 및 만료 처리

- 서버는 기존처럼 만료된 지도를 `no_map`으로 거절한다.
- 카운트다운이 먼저 0이 되면 구매 버튼을 비활성화하고 한 번만 만료 처리를 실행한다.
- 구매 요청과 만료가 겹쳐 서버가 `no_map`을 반환해도 같은 만료 안내와 이동 동작을 사용한다.

## 검증

- API 테스트: 유효한 지도 응답의 `expiresAt`과 `serverNow`가 서버 기준값과 일치한다.
- UI 테스트: 초기 남은 시간, 1초 감소, 0초 도달 시 구매 비활성화와 이동을 확인한다.
- 기존 비밀 상점 구매 및 유효하지 않은 지도 동작이 유지되는지 관련 테스트를 함께 실행한다.
