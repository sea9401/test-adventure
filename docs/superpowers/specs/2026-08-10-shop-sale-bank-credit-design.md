# Shop Sale Bank Credit Design

## Goal

NPC 상점에서 아이템을 판매해 얻는 골드를 소지금이 아니라 은행 잔액에 적립한다.

## Behavior

- 장비 단건 판매, 장비 일괄 판매, 재료 판매에 적용한다.
- 성공 시 `character.v2.gold`는 기존 값을 유지하고 `character.v2.bankedGold`에 판매액을 더한다.
- 손상되거나 누락된 잔액은 기존 판매 경로의 방어 수준과 같이 0 이상의 유한한 값으로 정규화한다.
- 성공 응답은 최신 `gold`와 `bankedGold`를 모두 반환한다.
- 판매 아이템 제거, 가격, 경제 로그와 거래소 판매·환불 정책은 바꾸지 않는다.
- 판매 결과 알림은 `은행 +N골드`라고 표시하고 전역 잔액을 즉시 동기화한다.

## Testing

- 세 판매 API 각각에서 소지금 불변과 은행 판매액 증가를 검증한다.
- 장비 일괄 판매의 기존 선택·잠금 보호 테스트를 유지한다.
- 관련 컴포넌트 테스트, TypeScript, lint, 전체 테스트와 production build를 검증한다.
