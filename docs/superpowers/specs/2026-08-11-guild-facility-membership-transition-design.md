# 길드 가입 시 주간 시설 승계 설계

## 목표

무소속 상태에서 모험가 협회 시설을 사용한 이용자가 주중에 길드에 가입해도 안전한 시설은 남은 이용량을 이어서 사용할 수 있게 한다. 협회와 길드의 보상 장부가 분리된 교역소는 중복 보상을 막고, 주중 가입자라는 이유만으로 사용 이력이 없는 시설까지 다음 주로 미루지 않는다.

## 현재 문제

`facility-weekly-source.v1`은 시설별로 `association` 또는 `guild`만 기록한다. 같은 주에 출처가 달라지면 길드 가입 여부와 관계없이 요청을 거절하며, 길드 출처가 어느 길드였는지는 구분하지 않는다.

식당과 교역소는 별도로 주간 시작 시점의 길드원 목록을 `eligibleUserIds`에 고정한다. 그 결과 주중 가입자는 협회 사용 이력이 없어도 길드 시설의 보상 행동을 할 수 없다.

## 시설별 정책

### 자동 승계 시설

- 훈련장: `guild-training.v1`의 일일 수령, 주간 수령, 주간 보너스 상태를 그대로 사용한다.
- 대장간: 개인 제작 재료, 장비, 장인 경험치와 주간 제작 통계를 그대로 사용한다. 길드 공동 제작 진척은 가입 후 제작부터 반영한다.
- 연금 공방: `inventory.v2.guildAlchemyWeekly.energyUsed`를 유지한다. 새 시설의 주간 에너지 한도가 더 크면 남은 차이만 사용할 수 있고, 더 작으면 다음 주까지 추가 제작할 수 없다.
- 식당: 사용 식권 수와 활성 효과뿐 아니라 협회에서 쌓은 개인 기여도도 유지한다. 길드 공동 식재료 진척에는 과거 협회 기여를 소급 반영하지 않는다.

자동 승계는 `association -> guild` 한 방향만 허용한다. 길드 탈퇴 후 `guild -> association` 전환은 같은 주 동안 계속 차단한다.

### 교역소

협회 교역소는 개인 토큰·개인 구매 횟수·협회 계약 완료 보상을 사용하고, 길드 교역소는 공동 토큰·공동 구매 횟수·길드 계약 보상을 사용한다. 따라서 협회에서 이번 주 보상 행동을 한 이용자는 길드 가입 후에도 다음 주까지 길드 교역 납품을 할 수 없다.

협회 교역소 사용 이력이 없는 주중 가입자는 길드의 주간 참여자 스냅샷에 없더라도 즉시 납품할 수 있다. 기존 길드 목표치는 주중에 다시 계산하지 않는다.

### 탐사 본부

협회 공공 이용 화면이 아직 구현되지 않아 승계 대상이 없다. 길드 가입 후에는 기존 길드 탐사 본부 규칙을 그대로 사용한다.

## 출처 상태 구조

신규 길드 선택에는 `guildId`를 함께 저장한다.

```ts
type WeeklyFacilitySourceSelection = {
  weekKey: string;
  source: "association" | "guild";
  guildId?: number;
};
```

기존 `guildId` 없는 길드 선택은 최초 이용 시 현재 길드에 귀속시켜 호환한다. 이미 다른 `guildId`에 귀속된 선택은 같은 주에 새 길드에서 사용할 수 없다. 이 규칙으로 길드 이동을 통한 식당 기여 한도와 교역 납품 한도 초기화를 막는다.

## 가입 처리와 지연 보정

가입 신청 승인과 길드 초대 수락은 동일한 가입 승계 함수를 호출한다. 이 함수는 자동 승계 시설의 협회 출처를 현재 길드 출처로 바꾸고 식당 개인 상태를 길드 소유 상태로 저장한다.

배포 전에 이미 가입했거나 가입 처리 도중 승계가 누락된 이용자를 위해 각 시설의 실제 보상 요청에서도 같은 정책을 적용한다. 따라서 가입 경로와 이용 경로 중 어느 한쪽만 거쳐도 상태가 안전하게 정규화된다.

## 식당·교역소 주간 명단

`eligibleUserIds`는 해당 주의 공동 목표 산정용 스냅샷으로만 유지한다. 현재 길드원인지 여부는 라우트의 멤버십 조회로 검증하므로, 개인 행동을 스냅샷 포함 여부로 거절하지 않는다.

- 식당은 현재 길드원이면 주문과 기부를 시도할 수 있고, 출처·길드 이동 검사는 실제 상태 변경 직전에 수행한다.
- 교역소는 현재 길드원이면 납품을 시도할 수 있지만, 협회 사용 또는 다른 길드 사용 이력이 있으면 출처 검사에서 거절한다.

## 오류와 원자성

출처 승계, 개인 상태 변경, 재료 소비와 보상 지급은 기존 데이터베이스 트랜잭션 안에서 처리한다. 출처 충돌 시 기존 `weekly_source_conflict` 응답을 유지하며 재료와 재화는 소비하지 않는다.

## 테스트

- 출처 정책: 협회에서 안전 시설의 길드 전환 허용, 교역소 전환 거절, 역방향 전환 거절, 다른 길드로 전환 거절, 레거시 길드 선택 귀속을 검증한다.
- 식당 상태: 협회에서 길드로 바뀔 때 기여도·식권 사용량·효과가 유지되고 길드 간 이동에서는 기여도가 초기화되는지 검증한다.
- 가입 경로: 신청 승인과 초대 수락 모두 승계 함수를 호출하는지 검증한다.
- 식당과 교역소 라우트: 주간 스냅샷에 없는 현재 길드원이 각각 식사·납품할 수 있는지 검증한다.
- 관련 단위 테스트, TypeScript 검사와 전체 테스트를 실행한다.

## 범위 제외

- 협회 교역소 개인 토큰을 길드 공동 토큰으로 바꾸지 않는다.
- 완료 전 협회 교역 계약이나 미수령 협회 보상을 길드 계약으로 옮기지 않는다.
- 길드 주간 공동 목표를 주중 가입 인원에 맞춰 재산정하지 않는다.
- 운영 배포와 점검 모드 변경은 수행하지 않는다.
