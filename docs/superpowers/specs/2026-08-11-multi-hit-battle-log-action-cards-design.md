# 연타 전투 로그 행동 카드 설계

## 목표

한 번 시전한 연타 기술의 개별 피해 로그를 행동 카드 하나로 묶는다. 카드 머리말에서 타수와 총피해를 빠르게 읽고, 카드 본문에서 각 타격 피해를 펼침 조작 없이 바로 확인할 수 있게 한다.

## 표시 방식

- 단일타 기술과 기본 공격은 현재 행동 카드 표시를 유지한다.
- 천궁궤적·천룡난무처럼 동일 기술이 한 시전에서 여러 피해 로그를 연속 생성하면 카드 하나로 표시한다.
- 카드 결과 영역은 `N타 · 총 X 피해`로 표시한다.
- 카드의 불투명 인셋 영역에 `1타 X · 2타 Y · …` 형식의 타격별 피해를 즉시 표시한다.
- 취약·회피·지연·회복·반사 같은 후속 효과는 타격별 피해 아래에서 같은 카드에 유지한다.
- 방어 계산은 현재처럼 카드 하나의 `계산 상세`에 둔다.

## 묶음 규칙과 호환성

전투 엔진과 `BattleLogEntry` 저장 형식은 변경하지 않는다. `BattleLogList`의 표시용 행동 묶음 단계에서 다음 조건을 모두 만족하는 연속 피해 로그만 합친다.

- 공격 진영이 같다.
- 파싱된 기술명이 같고 `기본 공격`이 아니다.
- 두 로그 모두 숫자 피해 결과다.
- 양쪽에 ATB 틱 `t`가 있으면 값이 같다.
- 첫 타격과 다음 타격 사이에 후속 효과나 행동 경계가 없다.

틱이 다른 동일 기술은 별도 시전으로 취급한다. 메타데이터가 없는 과거 리플레이는 같은 그룹 안의 연속 동일 기술 피해만 묶고, 다른 기술·효과·턴 경계가 나타나면 즉시 분리한다.

## 컴포넌트와 검증

`BattleLogDisplayItem`의 행동 항목이 첫 로그인 `main`과 시전의 모든 직접 피해 로그인 `hits`를 함께 가진다. `groupBattleLogActions`가 병합을 담당하고 `ActionCard`는 `hits`에서 총피해와 타격별 피해를 파생한다.

회귀 테스트는 연속 3타 병합, 다른 틱의 동일 기술 분리, 총피해와 타격별 피해의 실제 정적 렌더링을 검증한다. 기존 행동 묶음·좌우 반전·효과·계산 상세 테스트도 함께 통과해야 한다.

## 범위 제외

- 피해 공식, 치명타, 방어, 보호막 계산을 변경하지 않는다.
- 전투 로그 저장 스키마나 과거 리플레이를 마이그레이션하지 않는다.
- 연타 상세 접기 옵션이나 사용자 설정은 추가하지 않는다.
- 배포하지 않는다.
