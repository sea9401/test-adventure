# 인벤토리 티어 정렬 설계

## 목표

장비 인벤토리의 기존 순환 정렬 버튼에 `티어순`을 추가해 상위 티어 장비를 먼저 확인할 수 있게 한다. 기존 기본 정렬의 동작과 초기 선택값은 바꾸지 않는다.

## 동작

- 정렬 순환은 `기본 → 티어순 → 품질순 → 위력순 → 기본`이다.
- 티어순은 장비 카드에 표시되는 티어(`1T`~`6T`)가 높은 장비부터 정렬한다.
- 같은 표시 티어 안에서는 기존 기본 정렬인 내부 카탈로그 티어, 콘셉트, 이름, iid 순서를 유지한다.
- 정렬은 원본 장비 배열을 변경하지 않는다.

## 구현 범위

정렬 모드와 비교 함수는 인벤토리와 거래소 판매 목록이 함께 사용하는 공용 모듈에 유지한다. 따라서 두 화면의 정렬 버튼이 같은 순환 규칙을 사용하며, 인벤토리만을 위한 중복 정렬 구현은 만들지 않는다.

## 테스트

- 티어순이 표시 티어 내림차순으로 장비를 반환하는지 검증한다.
- 같은 표시 티어에서는 기존 기본 정렬 순서를 유지하는지 검증한다.
- 원본 배열이 변경되지 않는지 검증한다.
