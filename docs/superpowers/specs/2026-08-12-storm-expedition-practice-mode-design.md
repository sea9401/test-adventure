# 폭풍 원정 연습 모드 설계

## 목표

폭풍 원정을 해금한 이용자가 일일 입장 횟수와 보상을 걸지 않고 실제와 동일한 9노드 원정을 처음부터 끝까지 연습할 수 있게 한다.

## 진입과 동시 진행

- 연습 모드는 기존 폭풍 원정 해금 조건을 그대로 사용한다.
- 항로 카드마다 `실전 출발`과 `연습 시작`을 함께 제공한다.
- 일일 입장 횟수가 0이어도 연습은 시작할 수 있다.
- 실전 또는 연습이 진행 중이면 다른 원정을 새로 시작할 수 없다.
- 시작한 연습은 서버에 저장하고 재접속 시 같은 체크포인트에서 복원한다.

## 전투와 선택

- 연습은 실전과 같은 세 항로, 9노드, 7회 전투, 적 능력치, 자동 전투 규칙을 사용한다.
- HP·MP 계승, 보급·야영·제단·최종 정비, 원정 한정 회복기, 위험 이벤트와 페널티도 실전과 동일하게 처리한다.
- 진행 화면과 전투 결과에 `연습 모드`를 계속 표시한다.
- 이용자는 어느 체크포인트에서든 `연습 종료`를 눌러 보상 없이 즉시 나갈 수 있다. 적 처치 여부나 미해결 위험 페널티는 종료를 막지 않는다.

## 보상과 기록 차단

연습 모드는 다음 값을 생성하거나 변경하지 않는다.

- 일일 입장 횟수
- 골드, 재료, 장비, SP 열매
- 임시 전리품 가방
- 완주 횟수와 SP 열매 천장
- 퀘스트, 업적, 경제 로그 등 보상·완주로부터 파생되는 기록

서버는 연습 전투에서 전리품 추첨과 장비 생성 자체를 건너뛴다. 최종 보스를 처치해도 캐릭터, 장비, 누적 완주, 천장을 갱신하지 않고 연습 상태만 종료한다.

## 위험 이벤트

- 전투 페널티와 경로 변화는 실제처럼 적용해 체험할 수 있게 한다.
- `균열 상자`, `폭풍 계약`, `황금 나침반`처럼 경제적 이득이 있는 이벤트는 실전 효과 설명을 보여주되 연습에서는 재료·장비 확률·골드가 발생하지 않는다.
- `불안정한 축복`처럼 원정 안에서만 쓰이는 전투 효과는 실전과 동일하게 적용한다.

## 서버 상태와 API

`StormExpeditionActive`에 `mode: "normal" | "practice"`를 저장한다. 기존 저장 데이터는 `normal`로 복원한다.

기존 `start` 액션에 `mode`를 전달한다. `practice` 시작은 입장 횟수를 검사하거나 소비하지 않는다. 나머지 `fight`, `choose`, `risk_event`, `withdraw` 액션은 기존 경로를 공유하되 `mode`에 따라 경제·기록 처리를 차단한다. 연습에서 `withdraw`는 언제든 성공하며 `practiceEnded`를 반환한다. 최종 보스 처치 시 `practiceCompleted`를 반환한다.

모드 판정은 클라이언트 표시가 아니라 저장된 서버 상태를 권위로 삼는다. 클라이언트가 전투 요청마다 연습 여부를 보내 경제 처리를 결정하게 하지 않는다.

## UI와 가독성

- 항로 정보 카드는 기존 불투명 표면을 유지하고 카드 내부에 실전·연습 버튼을 둔다.
- 연습 시작 버튼 옆이나 입구 안내에 `입장 횟수 소모 없음 · 보상 없음`을 명시한다.
- 진행 중에는 지도 상단과 현재 체크포인트 카드에 연습 배지를 표시한다.
- 임시 전리품 카드는 연습 중 `연습 안내` 카드로 바꾸고 보상이 저장되지 않음을 표시한다.
- 전투 드롭 정보는 `실전 기준 미리보기`로 표시하고 연습에서는 지급되지 않는다고 함께 안내한다.
- 잠금·비활성 상태는 카드 전체 투명도가 아니라 버튼의 `disabled` 상태와 문구로 표현한다.

## 오류 처리

- 잠긴 이용자는 실전과 연습 모두 시작할 수 없다.
- 진행 중 원정이 있으면 새 실전·연습 시작을 모두 거절한다.
- 잘못된 모드는 `invalid_mode`로 거절한다.
- 오래된 위치에서 보낸 진행 요청은 기존 `stale_state` 규칙을 유지한다.
- 네트워크 오류는 패배나 연습 종료로 처리하지 않고 마지막 저장 체크포인트를 유지한다.

## 테스트

- 기존 저장의 모드가 `normal`로 복원되고 연습 저장은 `practice`로 유지되는지 확인한다.
- 연습 시작이 입장 횟수를 소비하지 않고, 0회 남은 상태에서도 허용되는지 확인한다.
- 연습 전투가 실전 적·자원 계승을 사용하면서 전리품 추첨과 임시 가방 적립을 하지 않는지 확인한다.
- 연습 종료가 적 처치 전과 위험 페널티 보유 중에도 가능하며 아무 보상도 지급하지 않는지 확인한다.
- 연습 완주가 캐릭터·장비·완주·천장 값을 변경하지 않는지 확인한다.
- 실전 시작, 전투, 귀환, 완주 동작이 기존과 동일한지 관련 전체 테스트로 회귀 검증한다.
