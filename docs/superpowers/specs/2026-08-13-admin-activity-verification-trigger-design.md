# 관리자 생활 활동 사람 확인 강제 표시 설계

## 목표

최고 관리자가 특정 유저의 다음 낚시·벌목·채광 행동에 사람 확인을 1회 표시하고, 일반 Turnstile 또는 Turnstile+hCaptcha 흐름을 실제 환경에서 관찰할 수 있게 한다.

## 선택한 방식

기존 `activity-guard.v1` 상태에 관리자 요청 표식을 별도 필드로 저장한다. 실제 위험 점수, 강한 신호 수, 행동 패턴 수와 확인 주기는 바꾸지 않는다. 별도 저장 키는 모든 보호 대상 라우트의 추가 조회를 요구하고, 기존 의심 카운터를 직접 조작하는 방식은 운영 통계를 오염시키므로 사용하지 않는다.

관리자 요청 표식은 활동별로 다음 값을 가진다.

- 모드: `standard` 또는 `captcha`
- 요청 시각
- 만료 시각

표식은 10분 동안 유효하다. 만료된 표식은 확인 대상으로 취급하지 않는다. 최고 관리자가 취소하거나 유저가 확인에 성공하면 제거한다.

## 서버 동작

### 관리자 API

`/api/admin/users/activity-verification`에 다음 동작을 둔다.

- `GET ?userId=...`: Turnstile/hCaptcha 설정 여부와 활동별 활성 요청을 조회한다.
- `POST`: `{ userId, activity, mode }`로 10분짜리 1회 요청을 설정한다.
- `DELETE`: `{ userId, activity }`로 활성 요청을 취소한다.

모든 변경 동작은 `super` 권한만 허용한다. 대상 유저와 입력값을 검증하고, 설정되지 않은 공급자의 모드는 거절한다. 이미 실제 활동 판정으로 확인 대기 중인 유저에게는 운영 테스트를 덮어쓰지 않는다. 설정과 취소는 관리자 감사 로그에 남긴다.

### 활동 게이트

실제 위험 판정이 대기 중이면 언제나 그것을 우선한다. 실제 판정이 없고 유효한 관리자 요청이 있으면 해당 활동의 다음 보호 API 호출에서 403 확인 응답을 반환한다.

- `standard`: Turnstile만 요구한다.
- `captcha`: Turnstile 통과 후 hCaptcha를 요구한다.

응답에는 `manualTest: true`를 포함한다. 클라이언트는 자동화 의심을 단정하지 않는 중립적인 안내 문구를 표시한다.

### 확인 완료와 기록

관리자 요청으로 시작된 확인이 성공하면 요청 표식만 제거한다. 위험 점수, 실제 확인 대기 상태, 일일 확인 수와 다음 체크포인트는 변경하지 않는다. 실패하면 요청은 만료 시각까지 유지되어 다시 시도할 수 있다.

요구·성공·실패 이벤트에는 `manualTest: true`를 넣는다. 이 이벤트는 생활 활동 확인 이력에는 표시하지만 매크로 의심 점수 계산에서는 제외한다.

## 관리자 UI

유저 상세에 `사람 확인 테스트` 섹션을 추가한다.

- 활동 선택: 낚시, 벌목, 채광
- 모드 선택: 일반 확인, 2단계 hCaptcha
- `다음 행동에 표시` 버튼
- 활성 요청의 활동·모드·만료 시각 표시
- `요청 취소` 버튼
- Turnstile 또는 hCaptcha가 설정되지 않았을 때의 안내

읽기 전용 모드에서는 변경 버튼을 비활성화한다. 최고 관리자가 아니면 섹션을 표시하지 않는다. 운영 이력 화면으로 이동하는 링크를 함께 제공한다.

## 오류 처리

- 인증/권한 없음: 401/403
- 잘못된 입력: 400
- 대상 유저 없음: 404
- 공급자 설정 없음: 409
- 실제 확인이 이미 대기 중: 409

클라이언트는 서버 오류 코드를 한국어 안내로 변환하고 요청 성공 후 상태를 다시 조회한다.

## 테스트

- 도메인: 관리자 표식 설정·만료·모드 판정·취소·성공 제거가 실제 위험 상태를 바꾸지 않는지 검증한다.
- 게이트 응답: 수동 여부와 2단계 site key가 정확히 포함되는지 검증한다.
- 관리자 API: 권한, 입력, 공급자 설정, 대상 조회, 저장, 취소와 감사 로그를 검증한다.
- 확인 API: 수동 성공·실패 이벤트가 표시되고 성공 시 위험 점수 변동 없이 표식만 제거되는지 검증한다.
- UI: 최고 관리자 노출, 요청/취소 흐름과 설정 오류 안내를 검증한다.

## 범위 밖

- 사냥이나 전투 등 생활 활동 외 콘텐츠에 사람 확인 추가
- 실제 의심 점수나 자동 제재 기준 변경
- 유저 응답을 실시간 푸시로 관리자 화면에 전송
- 일반 운영자에게 강제 표시 권한 부여
