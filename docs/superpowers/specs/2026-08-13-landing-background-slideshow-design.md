# 대문 게임 이미지 백그라운드 슬라이드 설계

## 목적

홍보 링크로 처음 방문한 사람이 대문을 카카오 정보 수집용 페이지로 오해하지 않도록,
로그인하기 전부터 실제 게임의 분위기와 콘텐츠 범위를 보여준다. 별도 소개 단계나 팝업은
추가하지 않고 기존 대문 안에서 바로 로그인할 수 있게 유지한다.

## 확정 방향

- 대문의 첫 화면 전체에 게임에서 실제 사용하는 이미지 자산을 배경 슬라이드로 표시한다.
- 실제 플레이 스크린샷처럼 보이게 가공하거나 AI로 게임 화면을 새로 만들지 않는다.
- 배경 이미지는 `GameChrome` 등 현재 게임 코드에서 사용하는 다음 자산으로 구성한다.
  1. `/images/ui/village.webp` — 시작 마을
  2. `/images/ui/battle.webp` — 전투
  3. `/images/ui/fishing.webp` — 낚시터
  4. `/images/ui/guild.webp` — 길드
  5. `/images/ui/hunt.webp` — 사냥터
- 첫 슬라이드는 밝고 친근한 시작 마을로 고정한다.
- 슬라이드 설명은 `실제 게임 화면`이 아니라 `게임에서 사용하는 지역 이미지`처럼
  사실과 일치하는 표현을 사용한다.

## 화면 구성

- 상단에는 게임명과 게임 소개·가이드·운영정책 링크를 둔다.
- 기존 게임명, 소개 문구, 카카오 로그인, 아이디·비밀번호 로그인 기능을 유지한다.
- 주요 문구와 로그인 컨트롤은 좌측의 불투명한 니어블랙 패널에 배치한다. 배경 그림이
  텍스트나 컨트롤 뒤로 비치지 않게 한다.
- 배경에는 어두운 그라데이션을 적용하되, 우측의 핵심 그림은 알아볼 수 있게 유지한다.
- 우측 하단에는 현재 이미지 이름과 5개의 진행 표시점을 둔다.
- 이용약관과 개인정보처리방침은 로그인 영역 가까이에 계속 노출한다.
- 현재 대문 아래의 게임 특징과 푸터 영역은 유지한다.

## 슬라이드 동작

- 약 6초마다 다음 이미지로 부드럽게 교차 전환하고 마지막 다음에는 첫 이미지로 돌아간다.
- 진행 표시점을 누르면 해당 이미지로 즉시 이동한다.
- 사용자가 표시점을 조작하면 자동 전환 시간을 처음부터 다시 센다.
- 브라우저 탭이 보이지 않을 때는 전환 타이머를 멈춘다.
- `prefers-reduced-motion: reduce` 환경에서는 자동 전환과 전환 애니메이션을 끄고 첫
  이미지만 안정적으로 표시한다.
- 이미지 로딩에 실패해도 니어블랙 배경과 로그인 패널은 그대로 남아 로그인을 방해하지
  않는다.

## 반응형·접근성

- 데스크톱에서는 로그인 패널을 좌측에 두고 배경의 주요 피사체가 우측에 보이게 한다.
- 모바일에서는 상단 내비게이션을 간소화하고 로그인 패널을 화면 폭에 맞춘다. 이미지별
  초점 위치를 지정해 주요 부분이 과도하게 잘리지 않게 한다.
- 배경 이미지는 장식 요소로 처리하며 화면 읽기 도구가 불필요하게 읽지 않게 한다.
- 진행 표시점에는 이미지 이름을 포함한 접근 가능한 레이블과 현재 상태를 제공한다.
- 라이트·다크 설정과 무관하게 로그인 패널은 불투명한 어두운 표면을 사용한다.

## 구현 경계

- 로그인·인증 처리, 추천 링크 처리, 이용약관 동의 방식은 변경하지 않는다.
- 신규 이미지 생성이나 외부 이미지 도입은 하지 않는다.
- 기존 게임 이미지 파일을 복제하거나 편집하지 않고 그대로 재사용한다.
- 이번 작업에서 별도의 게임 소개 페이지, 온보딩 단계, 팝업은 만들지 않는다.

## 검증

- 랜딩 표현 테스트에서 다섯 이미지와 진행 표시, 기존 로그인 UI가 렌더링되는지 확인한다.
- 가짜 타이머로 자동 순환, 직접 선택, 모션 감소 동작을 검증한다.
- 이미지 로딩 실패 시 로그인 영역이 유지되는지 확인한다.
- 데스크톱과 모바일 브라우저에서 가로 넘침, 텍스트 대비, 정책 링크, 카카오 로그인 진입을
  확인한다.
- `npm run check-images`, 관련 단위 테스트, 타입 검사와 빌드를 실행한다.

## 목업

승인된 배치 목업은 로컬 바탕 화면의
`무슨무슨게임-랜딩-게임이미지-목업.png`이며, 실제 구현의 간격과 크기는 반응형 화면에
맞춰 조정할 수 있다.
