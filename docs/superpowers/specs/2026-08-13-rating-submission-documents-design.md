# 등급분류 첨부문서 제작 설계

## 목표

게임콘텐츠등급분류위원회 첨부문서 화면에 바로 제출할 수 있도록 공개용 게임
사용설명서, 비공개 자료 묶음, 게임파일 전달방법 안내문을 제작한다. 결과물은 사용자
PC 바탕화면의 별도 폴더에 저장한다.

## 결과물

1. `01_무슨무슨게임_게임사용설명서.pdf`
   - 공개 가능 정보만 포함한다.
   - 게임 개요, 줄거리, 캐릭터와 직업, 주요 아이템·재화·제작·강화, 조작법,
     전투과정, 커뮤니티, 가격과 결제 상태를 설명한다.
   - 사용자가 촬영한 등급분류 영상에서 주요 화면을 추출해 설명과 함께 수록한다.
   - 무슨 코인 상점은 화면만 공개된 비활성 기능이며 실제 구매·충전·결제가 되지
     않는다는 사실을 명확하게 적는다.
2. `02_무슨무슨게임_비공개자료.zip`
   - 심의용 접속방법, 계정 관련 안내, 치트 코드 여부, 주요 대사·스크립트 안내를
     포함한다.
   - 심의용 계정은 신청서에 입력한 일반 심의용 계정과 동일하다고 기재한다.
   - 실제 아이디·비밀번호·개인정보·운영 비밀값은 새로 복제하지 않는다.
3. `03_게임파일_전달방법.txt`
   - 브라우저 접속형 온라인 게임이라 별도 설치 클라이언트가 없다는 점과 접속 URL,
     계정 확인 위치를 사이트 입력란에 붙여 넣을 수 있는 문장으로 제공한다.

## 공개·비공개 경계

- 공개 설명서에는 계정 정보, 관리자 정보, 소스 코드, 세션 값, 다른 이용자의 식별
  정보를 넣지 않는다.
- 비공개 자료에도 불필요한 개인정보와 소스 코드를 넣지 않는다.
- 영상 프레임에 식별 가능한 개인정보나 비밀값이 보이면 해당 프레임을 제외한다.
- 이미 신청서에 안전하게 제출된 심의 계정 자격 증명은 문서에 중복 기록하지 않는다.

## 제작 방식

- 기존 프로젝트의 게임 설명과 실제 촬영 영상을 함께 근거로 사용한다.
- 영상 프레임 추출과 PDF 렌더링은 임시 작업 디렉터리에서 수행한다.
- 최종 파일만 바탕화면 제출 폴더에 복사한다.
- 비공개 ZIP은 압축을 풀어 내부 문서가 정상적으로 읽히는지 재검증한다.

## 검증 기준

- 공개 PDF가 열리고 모든 페이지와 한글 글자가 정상 출력된다.
- 주요 장면 이미지가 잘리지 않고 설명과 대응한다.
- 공개 PDF에 계정·비밀번호·전화번호·이메일이 없다.
- 비공개 ZIP에 접속방법, 계정 안내, 치트 코드 없음, 스크립트 안내가 모두 있다.
- 전달방법 TXT가 UTF-8로 열리고 사이트에 그대로 붙여 넣을 수 있다.
- 최종 파일명은 한글과 허용 확장자만 사용하며 업로드 대상이 명확하다.
