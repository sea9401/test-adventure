# 심의용 관리자 OP 세팅 설계

## 목적

게임 등급 심의 중 별도 성장 없이 사냥터와 전투 콘텐츠를 확인할 수 있도록,
등록된 최고 관리자 계정의 기존 캐릭터에 일회성 OP 프리셋을 적용한다.

## 적용 방식

관리자 사용자 상세 화면에 `심의용 OP 세팅 적용` 버튼을 둔다. 요청자와 대상
계정 모두 `ADMIN_EMAILS`에 등록된 최고 관리자여야 한다. 저장 데이터를 교체하지
않고 필요한 값만 상향 병합하며, 여러 번 실행해도 값이 누적되거나 기존의 더 높은
값이 낮아지지 않는다.

## 적용 값

- 캐릭터 레벨 최소 100
- 여섯 기본 능력치 성장값과 성장 한도 증가량 각각 최소 3,000
- 숙련 포인트 최소 1,000,000
- 현재 직업 및 직업군 누적 숙련도 최소 1,000,000
- 현재 직업군 단계 최소 5, 환생 횟수 최소 100
- `MAX_FRONTIER_DEPTH`까지 사냥터 개방
- 골드·은행 골드 각각 최소 1,000,000,000, 명성 최소 1,000,000
- HP·MP 회복약 각각 최소 100,000개
- 현재 HP·MP·행동력을 적용 시점의 최대치로 회복

최초 설계의 능력치 목표 1,000은 장비와 스킬이 없는 기본 직업에서 최종 사냥터
권장 전투력에 못 미쳤다. 실제 공식 전투력 계산 결과를 기준으로 3,000으로 조정해,
가장 불리한 기본 직업도 최종 권장 전투력의 1.5배 이상이 되게 한다.

## 보존 범위

- 캐릭터 이름과 현재 직업
- 장착·보유 장비
- 장착·습득 스킬
- 퀘스트 및 스토리 완료 플래그
- 일반 재료와 특수 아이템
- 프리셋 기준보다 높은 기존 수치

스토리 플래그를 건드리지 않아 심의 중 퀘스트 흐름을 직접 확인할 수 있다.
사냥터 개방은 `frontierDepth`만 상향한다.

## 서버와 UI

최고 관리자 전용 POST Route Handler가 대상 이메일을 다시 검증하고,
`character.v2 → proficiency.v2 → inventory.v2` 순서로 잠근 뒤 한 트랜잭션에서
저장한다. 기존 장비와 스킬을 포함해 전투 능력치를 다시 계산한 후 HP·MP를 최대치로
맞춘다. 성공 시 `review-op-preset.apply` 감사 로그에 전체 저장본이 아닌 적용 전후
핵심 수치만 기록한다.

사용자 검색 응답은 대상의 최고 관리자 여부를 포함한다. 현재 요청자도 최고 관리자이고
선택 대상도 최고 관리자일 때만 사용자 상세 화면에 프리셋 카드를 표시한다. 실행 전에는
진행도와 성장 수치가 자동으로 되돌아가지 않는다는 확인창을 보여준다.

## 오류 처리

- 인증 없음 401, 최고 관리자 권한 없음 403
- 대상 사용자 없음 404
- 대상이 최고 관리자가 아님 400
- 캐릭터 또는 직업 정보 없음 409

## 제외 범위

- 배포와 점검 모드 변경
- 관리자 계정의 아레나 참여 허용
- 모든 장비·재료·아이템 일괄 지급
- 퀘스트 및 스토리 자동 완료
- 프리셋 전용 되돌리기 기능
