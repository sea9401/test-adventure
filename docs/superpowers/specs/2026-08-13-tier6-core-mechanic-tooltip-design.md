# 6티어 핵심 기믹 툴팁 개선 설계

## 문제

`합일의 망토`는 "서로 다른 핵심 기믹 3종"과 "합일 강화"라는 내부 용어만 보여 준다. 현재 툴팁만으로는 어떤 효과가 핵심 기믹으로 집계되는지, 합일 강화가 무엇을 올리는지 알 수 없다.

## 확정안

- 기존 효과 문장은 유지하되 `핵심 기믹이란?` 펼침 버튼을 효과 바로 아래에 추가한다.
- 버튼은 별도 팝업을 열지 않고 현재 아이템 툴팁 안에서 인라인 설명을 펼친다. 다시 누르면 접힌다.
- 펼친 설명에는 집계 대상 7종을 모두 표시한다.
  - 중력 반발
  - 상처 파열
  - 추적 사격
  - 그림자 잔상
  - 맹독 폭발
  - 과부하 낙뢰
  - 성역 소비
- 서로 다른 3종이 한 전투에서 발동하면 조건을 충족한다는 점을 명시한다.
- 보상 효과를 `합일 강화: 공격·회복 +18% (3행동)`으로 명시한다.

## UI 및 접근성

- 모바일에서 중첩 팝업이 화면을 가리지 않도록 인라인 펼침을 사용한다.
- 네이티브 `details`/`summary`를 사용해 펼침 상태와 키보드 조작을 브라우저 접근성 트리에 전달한다.
- 펼침 영역은 기존 불투명 인셋 표면 스타일을 사용해 장면 배경이 비치지 않게 한다.
- 상세 설명은 합일의 망토에만 표시하며, 다른 시그니처 효과 툴팁은 바꾸지 않는다.

## 검증

- 접힌 상태에서는 기존 툴팁 크기와 정보 흐름을 유지하는지 확인한다.
- 버튼을 눌렀을 때 7종 목록, 발동 기준, +18%/3행동 수치가 모두 표시되는지 컴포넌트 테스트로 검증한다.
- `details`/`summary` 연결을 검증하고, 브라우저의 네이티브 펼침·접힘 동작을 사용한다.
- 관련 단위 테스트와 타입 검사를 실행한다.
