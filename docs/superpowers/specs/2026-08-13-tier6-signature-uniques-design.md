# 6티어 시그니처 유니크 확장 설계

## 목표

천공 균열과 폭풍 원정에 6티어 유니크 18종을 추가한다. 기존 6티어 세트의 일곱 빌드 축을
확장하되 직업, 세트, 특정 장비 조합을 강제하지 않는다. 여러 유니크가 서로 맞물려 예상하지 못한
조합이 나오는 것을 허용하고, 실제 플레이에서 지나치게 강한 조합이 확인되면 수치를 사후 조정한다.

핵심 원칙은 다음과 같다.

- 총 18종: 천공 균열 사냥 12종, 폭풍 원정 6종
- 클래스 제한, 세트 착용 조건, 유니크 장착 개수 제한 없음
- 모든 아이템은 기존 장비와 같은 방식으로 거래·해체·강화 가능
- 새 아이템은 어느 기존 세트에도 속하지 않으며, 무기는 직업 제한 대신 기존 무기 종류별 스킬 호환
  규칙만 따른다.
- 천장, 조각 교환, 미보유 우선 보정 없음. 중복 드랍 허용
- 효과 발동 과정과 전투 자원은 툴팁, 상태 표시, 전투 로그에서 확인 가능
- 밸런스용 인위적 조합 차단은 두지 않고 무한 재귀와 수치 오버플로만 구조적으로 차단

## 채택한 접근

### 선택안: 독립 시그니처와 공유 전투 자원

각 유니크는 독립적인 시그니처 효과를 가지되 `보호막 파열`, `출혈 소비`, `추적 표식`, `잔상`,
`중독 폭발`, `과부하`, `성역 축적` 같은 공용 전투 자원을 통해 다른 유니크와 상호작용한다.
기존 `SignatureEffect`를 확장하고 엔진이 공통 런타임 상태를 관리한다.

이 방식은 단일 아이템도 작동하면서 두세 아이템을 조합했을 때 새로운 순환이 생긴다. 효과별 전용
코드를 장비 ID에 직접 연결하는 방식보다 테스트와 툴팁 생성이 쉽고, 기존 세트 효과와도 같은 경로를
사용할 수 있다.

검토한 다른 방식은 다음과 같다.

- 기존 트리거만 조합: 구현은 작지만 이미 보유한 유니크와 체감 차이가 작아 이번 확장의 목적에 맞지 않는다.
- 아이템 ID별 전용 전투 코드: 개성은 가장 강하지만 전투 엔진이 장비 목록에 종속되고 조합 검증이 어렵다.

## 획득 구조와 확률

### 천공 균열 사냥 12종

73~78 깊이에 깊이별 2종을 배치한다. 해당 깊이의 두 아이템만 같은 풀을 공유하므로 특정 아이템을
노리려면 원하는 깊이를 선택할 수 있다.

| 깊이 | 풀 전체 확률 | 개별 아이템 확률 | 풀 구성 |
|---:|---:|---:|---|
| 73 | 0.005% | 0.0025% | 2종 |
| 74 | 0.005% | 0.0025% | 2종 |
| 75 | 0.0075% | 0.00375% | 2종 |
| 76 | 0.0075% | 0.00375% | 2종 |
| 77 | 0.01% | 0.005% | 2종 |
| 78 | 0.01% | 0.005% | 2종 |

표의 확률은 기본 사냥 1회 기준이다. 기존 사냥 드랍 배율은 다른 시그니처 유니크와 동일하게 최종
확률에 적용한다. 일반 6티어 방어구와 78단계 무기 굴림은 그대로 유지하고, 새 유니크는 별도 굴림을
사용한다. 따라서 일반 장비 드랍률을 낮추거나 기존 풀을 희석하지 않는다.

### 폭풍 원정 6종

원정 유니크는 기존 항로 장비 굴림과 분리된 독립 굴림이다. 한 전투에서 기존 장비와 유니크가 함께
나올 수 있고, 최종전에서는 서로 다른 유니크 범주의 동시 드랍도 허용한다.

| 범주 | 획득 지점 | 기본 확률 | 후보 |
|---|---|---:|---|
| 항로 전용 | 해당 항로 수호자 | 0.15% | 항로별 고정 1종 |
| 항로 전용 | 폭풍의 심장 | 0.4% | 선택 항로의 고정 1종 |
| 복합 기믹 | 폭풍의 심장 | 통합 0.2% | 2종 균등 |
| 심장 유니크 | 폭풍의 심장 | 0.05% | 고정 1종 |

`폭풍의 계약`은 항로 전용과 복합 기믹 확률을 2배로 만든다. 심장 유니크 0.05%에는 적용하지
않는다. 유니크에는 확정 천장이나 별도 교환식을 두지 않는다.

## 사냥 유니크 12종

아래 수치는 최초 밸런스 값이다. 이름, 슬롯, 작동 조건은 출시 계약으로 고정하고 계수는 시뮬레이션과
라이브 데이터에 따라 조정 가능한 상수로 둔다.

기본 공격력·방어력·옵션·무게·굴림 범위는 아래 표의 같은 슬롯 6티어 장비를 복사한다. `setTags`는
복사하지 않는다. 따라서 유니크 효과를 얻는 대신 기존 세트 부위 수를 포기하는 선택이 생기며,
시그니처 효과와 무관한 기본 능력치 예산은 현재 6티어 범위를 벗어나지 않는다.

| 신규 아이템 | 기본 능력치 기준 장비 |
|---|---|
| 붕괴성의 흉갑 | `v2_storm_wreckage_armor` |
| 반중력 인장 | `v2_storm_wreckage_ring` |
| 혈맥 절단검 | `v2_storm_breaker_greatsword` |
| 상흔의 계수기 | `v2_storm_breaker_gloves` |
| 지평선 추적궁 | `v2_storm_gale_bow` |
| 무풍의 잔영화 | `v2_storm_shadow_boots` |
| 독왕의 양면침 | `v2_storm_venom_dagger` |
| 부식의 저울 | `v2_storm_venom_ring` |
| 뇌정 과부하핵 | `v2_storm_thunder_staff` |
| 역류 도체장갑 | `v2_storm_thunder_gloves` |
| 새벽 저장성배 | `v2_storm_sanctuary_necklace` |
| 합일의 망토 | `v2_storm_sanctuary_armor` |

### 깊이 73: 중력성채

1. **붕괴성의 흉갑** (`armor`)
   - 보호막이 적의 공격으로 완전히 소진되면 소진 직전 남아 있던 보호막과 초과 피해의 합계 중 35%를
     `중력 반발`로 저장한다.
   - 다음 직접 공격이 적중하면 저장량만큼 추가 고정 피해를 주고 저장량을 비운다.
   - 한 번에 저장할 수 있는 값은 최대 HP와 같은 수치까지만 제한한다. 이는 오버플로 방지용이다.
2. **반중력 인장** (`ring`)
   - 자신이 새 보호막을 얻을 때 그 보호막의 20%를 `중력 반발`에 더한다.
   - 반발 피해가 발동하면 최대 HP의 5%만큼 보호막을 얻는다.
   - 이 아이템이 만든 보호막은 같은 원인 행동 안에서 다시 반발 저장을 만들지 않는다.

### 깊이 74: 붕괴의 선봉

3. **혈맥 절단검** (`weapon`, `greatsword`)
   - 기본 공격이 출혈 중인 적에게 적중하면 출혈을 전부 소비해 남은 출혈 피해의 70%를 즉시 준다.
   - 스킬 공격은 출혈을 소비하지 않으므로, 계속 쌓을지 기본 공격으로 터뜨릴지 플레이가 결정한다.
4. **상흔의 계수기** (`gloves`)
   - 한 번에 소비한 출혈 스택마다 2행동 동안 적의 방어를 3% 낮춘다.
   - 같은 폭발에서 얻는 방어 감소는 합산되며 기존 방어 감소 규칙의 전역 상한만 따른다.
   - 출혈 폭발 뒤 스택 하나를 다시 남겨 출혈 연계가 완전히 끊기지 않게 한다.

### 깊이 75: 천공추적과 무풍암영

5. **지평선 추적궁** (`weapon`, `bow`)
   - 같은 적에게 직접 공격을 연속 적중할 때마다 `추적 표식` 1중첩을 남긴다.
   - 5중첩에 도달하면 표식을 모두 소비하고 직전 공격 피해의 60%인 추적 사격을 발사한다.
   - 빗나감은 표식을 초기화하며 다단 공격은 실제 적중한 타수만 센다.
6. **무풍의 잔영화** (`boots`)
   - 회피에 성공할 때 `그림자 잔상` 1개를 얻는다.
   - 다음 치명타가 잔상 하나를 소비해 직전 치명타 피해의 45%를 복제한다.
   - 잔상은 최대 3개까지 보관하며 복제 피해는 치명타나 추가 복제를 일으키지 않는다.

### 깊이 76: 만독침식

7. **독왕의 양면침** (`weapon`, `dagger`)
   - 스킬 공격은 적중할 때마다 중독 1스택을 추가한다.
   - 기본 공격은 대상의 중독이 5스택 이상이면 모든 중독을 소비해 남은 중독 피해의 75%를 즉시 준다.
   - 자동 전투에서도 스킬은 축적, 기본 공격은 폭발이라는 동일한 규칙을 사용한다.
8. **부식의 저울** (`ring`)
   - 중독 폭발이 발동하면 소비한 스택의 절반을 올림해 다시 부여한다.
   - 폭발로 소비한 스택마다 2행동 동안 적의 마법방어를 2% 낮춘다.
   - 재부여된 중독은 같은 공격 안에서 다시 폭발하지 않는다.

### 깊이 77: 뇌정술식

9. **뇌정 과부하핵** (`weapon`, `staff`)
   - 실제로 소비한 MP 1마다 `마력 과부하` 1을 얻는다.
   - 과부하가 100에 도달하면 100을 소비하고 마법공격력의 140%인 낙뢰를 발동한다.
   - 한 스킬이 200 이상을 소비하면 임계값을 넘긴 횟수만큼 발동할 수 있다.
10. **역류 도체장갑** (`gloves`)
    - 과부하 낙뢰가 발동할 때 직전에 소비한 MP의 20%를 돌려받는다.
    - 낙뢰가 상태이상에 걸린 적을 맞히면 과부하 25를 다시 얻는다.
    - 환급된 MP는 과부하를 생성하지 않는다.

### 깊이 78: 성역공명과 교차 연계

11. **새벽 저장성배** (`necklace`)
    - 실제 회복과 초과 회복을 합친 산출 회복량의 30%를 `성역 축적`으로 저장한다.
    - 현재 HP가 35% 이하가 되면 저장량을 모두 소비해 같은 양을 회복한다.
    - 저장량은 최대 HP의 60%까지만 보관하며 전투가 끝나면 사라진다.
12. **합일의 망토** (`armor`)
    - 중력 반발, 출혈 폭발, 추적 사격, 잔상 복제, 중독 폭발, 과부하 낙뢰, 성역 소비 중 서로 다른
      효과가 연속으로 발동할 때마다 `합일` 1중첩을 얻는다.
    - 같은 효과를 반복하면 중첩은 늘지 않지만 초기화되지도 않는다.
    - 3중첩에서 합일을 소비해 3행동 동안 공격력과 마법공격력 18%, 회복 효율 18%를 얻는다.

## 원정 유니크 6종

원정 6종도 세트 태그 없이 같은 슬롯의 기존 항로 장비 능력치를 사용한다. 부유성채의 동력갑은
`v2_storm_wreckage_armor`, 칼바람의 무한궤도는 `v2_storm_gale_boots`, 귀환뇌명의 반지는
`v2_storm_thunder_ring`, 삼상 접속장갑은 `v2_storm_shadow_gloves`, 폭풍 합류의 목걸이와
맥동하는 폭풍심장은 `v2_storm_sanctuary_necklace`를 기준으로 한다.

### 항로 전용 3종

1. **부유성채의 동력갑** (`armor`, 부유 잔해지)
   - 행동 시작 시 보호막이 있으면 현재 보호막의 10%를 소비하고, 그 행동의 다음 직접 공격에 소비한
     보호막과 같은 양의 추가 고정 피해를 더한다.
   - 소비 직전 보호막이 최대 HP의 20% 이상이면 추가 피해가 소비량의 두 배가 된다.
2. **칼바람의 무한궤도** (`boots`, 칼바람 항로)
   - 직접 적중, 치명타, 회피 중 서로 다른 사건이 발생할 때 `질풍 연계`를 하나씩 채운다.
   - 3종이 모두 채워지면 모두 소비하고 추가 행동 1회를 얻는다.
   - 순서는 자유이며 같은 종류의 반복은 이미 채운 칸을 중복 충전하지 않는다.
3. **귀환뇌명의 반지** (`ring`, 뇌운 항로)
   - 출혈, 중독, 감전, 한기, 방어 감소 중 하나가 있는 적을 직접 공격하면 실제 MP 비용의 8%를 회복한다.
   - 서로 다른 상태이상 두 종류 이상이 있으면 회복량이 16%가 된다.
   - 비용이 없는 행동은 MP를 만들지 않는다.

### 복합 기믹 2종

4. **삼상 접속장갑** (`gloves`)
   - 중력 반발·출혈 폭발·중독 폭발 피해는 추적 표식 1중첩을 만든다.
   - 추적 사격·잔상 복제·과부하 낙뢰가 발동하면 성역 축적에 해당 피해의 10%를 저장한다.
   - 이 효과로 생긴 자원은 같은 원인 행동에서 삼상 접속을 다시 발동하지 않는다.
5. **폭풍 합류의 목걸이** (`necklace`)
   - 장비 시그니처로 추가 피해가 발생할 때마다 다음 직접 회복량과 다음 보호막 획득량이 각각 12%씩
     증가한다. 회복 또는 보호막을 얻으면 해당 보너스만 소비한다.
   - 장비 시그니처로 회복이나 보호막을 얻으면 다음 직접 공격 피해가 12% 증가한다.
   - 각 방향은 최대 5회분을 보관하며 서로를 같은 원인 행동에서 재발동시키지 않는다.

### 심장 유니크 1종

6. **맥동하는 폭풍심장** (`necklace`)
   - 전투 중 일곱 핵심 기믹의 실제 발동 횟수를 각각 기록한다.
   - 어느 기믹이 처음 3회 발동하면 그 기믹을 해당 전투의 `지배 기믹`으로 고정한다.
   - 이후 지배 기믹은 계수와 자원 생성량이 35% 증가한다. 정수 자원은 발동할 때 누적 소수점을
     보존해 장기 기대값이 35% 증가하도록 처리한다.
   - 전투마다 다시 판정하므로 장비 조합이나 전투 양상에 따라 강화 대상이 바뀐다.

## 전투 엔진 구조

### 데이터 모델

기존 `SignatureEffect`에 새 트리거와 파라미터를 추가하되 장비 ID를 엔진에서 직접 비교하지 않는다.
새 효과는 데이터가 설명하고, 툴팁도 같은 데이터에서 생성한다.

전투 중 상태에는 다음 값이 필요하다.

- 중력 반발 저장량
- 출혈·중독 폭발 여부와 소비 스택
- 추적 표식과 직전 직접 피해
- 그림자 잔상 수
- 마력 과부하와 MP 환급 제외 표식
- 성역 축적량
- 합일과 질풍 연계의 서로 다른 사건 집합
- 폭풍심장의 기믹별 발동 횟수와 지배 기믹
- 원인 행동 ID, 발생 효과 ID, 재발동 금지 표식

런타임 상태는 PvE와 PvP가 공유할 수 있는 순수 전투 상태 모듈에 둔다. 각 엔진 단계는 사건을
발행하고 시그니처 해석기가 효과를 계산해 피해, 회복, 보호막, 자원 변화 명령을 반환한다. 실제 HP,
MP, 상태이상 변경은 기존 전투 적용 함수가 담당한다.

### 재귀 안전 규칙

- 복제 공격과 추가 피해는 자신을 만든 동일 효과를 다시 발동하지 않는다.
- 추가 행동은 추가 행동을 직접 생성할 수 없다. 이후 플레이어가 수행한 실제 행동은 정상적으로
  다른 기믹을 발동할 수 있다.
- 동일한 시그니처 효과와 원인 사건의 조합은 한 번만 처리한다. 다단 공격의 각 직접 적중은 서로
  다른 사건이므로 정상적으로 자원을 만들고, 한 행동에서 여러 임계값을 넘으면 한 번의 평가에서
  발동 횟수를 일괄 계산한다.
- 환급 MP는 MP 소비 사건으로 취급하지 않는다.
- 폭발 뒤 재부여한 DoT는 같은 원인 행동에서 다시 폭발하지 않는다.
- 자원 수치는 유한한 안전 상한과 유한수 검사를 거치며 `NaN`, 음수, 무한대를 저장하지 않는다.

이 규칙은 무한 루프만 막는다. 서로 다른 유니크 사이의 정상 연쇄, 여러 임계값을 한 번에 넘기는
발동, 강한 시너지는 허용한다.

## UI와 전투 로그

- 아이템 툴팁은 발동 조건, 소비 자원, 계수, 지속 행동 수를 축약 없이 표시한다.
- 장비 화면에서 별도의 조합 금지나 직업 경고는 표시하지 않는다.
- 전투 화면에는 현재 의미가 있는 자원만 작은 상태 칩으로 표시한다. 값이 0이고 발동 가능 효과도
  없으면 숨긴다.
- 중력 반발, 추적 표식, 잔상, 과부하, 성역 축적, 합일, 질풍 연계, 지배 기믹을 구분해 표시한다.
- 발동 로그는 원인과 결과를 한 줄에 남긴다. 복합 연쇄는 같은 행동 카드 아래 발생 순서대로 묶는다.
- 사냥터 도감과 원정 보상 화면에는 실제 기본 확률과 폭풍의 계약 적용 후 확률을 표시한다.
- 기존 불투명 표면 토큰을 사용하며 새 전용 이미지 제작은 이번 범위에 포함하지 않는다.

## 드랍 및 저장 흐름

### 사냥

전투 승리 후 기존 일반 장비와 78단계 무기를 굴린 다음, 깊이 전용 시그니처 풀을 독립적으로
굴린다. 성공 시 기존 `droppedUnique` 경로를 사용해 유니크 배너와 전광판 방송을 유지한다.

### 원정

기존 재료와 장비 굴림을 마친 뒤 유니크 범주를 독립적으로 굴린다. 수호자는 항로 유니크만,
최종전은 항로·복합·심장 유니크를 각각 굴린다. 굴림 결과의 `equipmentId`는 기존 일반 장비용으로
유지하고, 새 유니크 ID 배열을 함께 반환한다. 생성한 일반 장비와 유니크 인스턴스는 모두 기존
`pendingEquipment: V2EquipInstance[]`에 추가한다. 귀환하면 전부 확정하고 패배하면 기존 규칙대로
임시 전리품과 함께 소실한다. 체크포인트 저장은 굴림 결과를 포함한 전체 임시 전리품을 원자적으로
기록하므로 재접속 시 이미 완료한 굴림을 다시 수행하지 않는다. 알 수 없는 유니크 ID나 유효하지 않은
확률 값은 드랍 없음으로 처리하고 서버 로그에 남기며, 전투나 원정 복구 자체를 실패시키지 않는다.

### 전투 오류 처리

시그니처 파라미터는 카탈로그 로딩 시 유한수와 허용 범위를 검증한다. 런타임에서 잘못된 효과를
만나면 해당 효과만 비활성화하고 기존 행동을 계속 처리한다. 사건 처리에는 원인 행동 ID, 하위 사건
ID, 발생 효과 ID를 함께 전달해 순환을 탐지하며, 순환이 감지되면 뒤쪽 재발동만 버리고 최초의 정상
효과는 유지한다.

## 검증

### 데이터와 드랍

- 18종 모두 화면상 6티어, 유니크 등급, 유효 슬롯과 설명을 가진다.
- 각 깊이는 정확히 2종만 노출하고 경계 깊이와 확률을 검증한다.
- 원정의 수호자·최종전·항로별 풀이 정확하고 세 유니크 굴림이 독립적임을 검증한다.
- 폭풍의 계약은 항로·복합만 2배이며 심장 0.05%는 변하지 않음을 검증한다.
- 천장, 미보유 우선, 중복 방지가 없음을 결정적 RNG 테스트로 검증한다.

### 전투

- 일곱 핵심 기믹을 단독으로 테스트한 뒤 모든 지원 유니크와의 연계를 테스트한다.
- 기본 공격과 스킬, 단타와 다단, 치명타와 회피, 보호막 파괴, 실제·초과 회복을 각각 검증한다.
- PvE와 PvP가 같은 규칙과 계수를 사용하는지 대칭 테스트를 둔다.
- 추가 피해·복제·추가 행동·MP 환급·DoT 재부여가 자기 자신을 재귀 호출하지 않는지 검증한다.
- 시그니처를 장착하지 않은 기존 전투 골든 결과가 변하지 않는지 확인한다.

### 시뮬레이션과 UI

- 기존 7개 6티어 완성 세트, 4+2 혼합, 신규 유니크 1~3개 혼합 조합을 비교한다.
- 시뮬레이션은 강한 조합을 자동으로 약화하지 않고 무한 행동, 전투 미종료, `NaN`, 자원 폭증처럼
  구조적으로 잘못된 결과만 출시 차단 조건으로 삼는다.
- 툴팁과 상태 칩이 실제 계수와 일치하며 모바일 폭에서 전투 버튼이나 로그를 가리지 않는지 검증한다.
