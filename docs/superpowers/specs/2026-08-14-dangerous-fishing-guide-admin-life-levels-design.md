# 위험 해역 안내와 어드민 생활 만렙 설계

## 목표

- 위험 해역 화면만 보고도 첫 출항부터 안전 귀환까지 진행할 수 있게 한다.
- 게임 매뉴얼에서 위험 해역의 규칙, 조작, 화물 손실 구조를 다시 확인할 수 있게 한다.
- 기존 심의용 OP 세팅을 최고 관리자 계정에 적용하면 농사·벌목·채광·낚시·요리도 각각 Lv.50이 되게 한다.

## 위험 해역 안내

출항 준비 화면 위에 기본적으로 닫혀 있는 `처음 이용하시나요?` 가이드를 둔다. 가이드에는 해역·수심 선택, 행동 대응표, 승리 조건, 장력 실패 조건, 안전 귀환과 사고 위험을 한 흐름으로 표시한다. 상세 수치와 전용 장비·거대어 설명은 생활 콘텐츠 매뉴얼의 `위험 해역 낚시` 절에서 제공한다.

안내는 기존 불투명 표면 토큰을 사용한다. 별도의 튜토리얼 진행 상태나 보상은 만들지 않는다.

## 어드민 생활 레벨

기존 `심의용 OP 세팅` API를 확장한다. 이 API는 최고 관리자 권한과 대상 계정의 `ADMIN_EMAILS` 포함 여부를 이미 검증하므로 별도의 자동 로그인 보정은 만들지 않는다.

농장, 벌목 로그, 채광 로그, 낚시 성장, 요리 상태를 각 파서로 정규화하고, 각 Lv.50 시작 경험치와 현재 경험치 중 큰 값을 저장한다. 그 밖의 기록·보유품·일일 진행은 보존한다. 따라서 한 번 적용하면 실제 콘텐츠 잠금이 해제되고, 재적용해도 경험치가 추가로 누적되지 않는다.

## 검증

- 위험 해역 화면 렌더 테스트에서 초보 가이드와 핵심 규칙을 확인한다.
- 매뉴얼 렌더 테스트에서 위험 해역 상세 안내를 확인한다.
- 심의용 프리셋 단위 테스트에서 5종 생활 경험치가 Lv.50이고 기존 필드가 보존되는지 확인한다.
- API 테스트에서 다섯 저장 키의 잠금·저장과 응답의 생활 레벨을 확인한다.
