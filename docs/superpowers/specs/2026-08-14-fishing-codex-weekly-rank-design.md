# 어보 주간 순위 표시 개선 설계

작성일: 2026-08-14

## 목표

사용자가 별도의 주간 낚시 대회 화면에서 어종을 하나씩 확인하지 않아도 모험의 서 `어보` 탭에서 이번 주에 기록이 없는 어종을 바로 찾을 수 있게 한다.

## 사용자 경험

### 어종 이름과 발견 상태

- 미발견 어종도 `???` 대신 실제 이름을 표시한다.
- 상태 배지는 기존 세 상태를 유지한다.
  - 한 번도 잡지 않고 표본도 등록하지 않은 어종: `미발견`
  - 잡은 적은 있지만 현재 표본이 등록되지 않은 어종: `미등록`
  - 표본이 등록된 어종: `등재`
- 미발견 어종의 설명은 발견 전까지 계속 숨긴다.
- 미발견 어종의 아이콘은 기존처럼 비활성된 모습으로 표시한다.

예시:

```text
붕어 [미발견]
잉어 [등재]
```

### 주간 순위와 최대어

- 각 어종 행 오른쪽에 `주간 순위`, `최대어` 순서로 정보를 표시한다.
- 이번 시즌에 본인 기록이 있으면 실제 순위를 `주간 7위`처럼 표시한다. 상위 10위 밖의 본인 순위도 실제 순위를 사용한다.
- 이번 시즌에 본인 기록이 없으면 `주간 미등록`으로 표시한다.
- 직접 잡은 기록이 없어 역대 최대어가 없으면 최대어 값은 `최대어 —`로 표시한다.
- 좁은 화면에서는 이름·상태와 기록 정보가 서로 겹치지 않도록 자연스럽게 줄바꿈한다.

예시:

```text
붕어 [미발견]                 주간 미등록 · 최대어 —
잉어 [등재]                   주간 7위 · 최대어 92cm
```

### 주간 미등록 필터

- 어보 진행도 카드 아래, 등급별 어종 목록 위에 `주간 미등록만 N` 토글을 둔다.
- `N`은 이번 시즌에 본인 기록이 없는 전체 어종 수다.
- 토글을 켜면 각 등급 카드에서 주간 기록이 없는 어종만 남긴다.
- 토글을 꺼도 기존 등급별 어종 순서와 카드 구성은 유지한다.
- 필터 결과가 없는 등급 카드는 숨긴다.
- 모든 어종에 주간 기록이 있으면 빈 상태로 `이번 주 모든 어종에 기록을 등록했습니다.`를 표시한다.
- 필터 상태는 화면을 벗어나면 초기화하며 별도로 저장하지 않는다.

## 데이터 흐름

- 기존 `/api/v2/fishing/leaderboard` 응답을 재사용한다.
- 새 API, 데이터베이스 테이블, 저장 키는 추가하지 않는다.
- 어보 탭이 활성화됐을 때만 주간 리더보드를 조회한다.
- `byFish[fishId]`에서 `isMe === true`인 항목을 찾아 본인의 이번 시즌 순위를 만든다.
- 해당 항목이 없으면 조회가 성공한 뒤에만 그 어종을 `주간 미등록`으로 판단한다.
- 기존 리더보드 응답은 상위 10위 밖이어도 본인 행을 포함하므로 별도의 순위 계산은 하지 않는다.
- 주간 리더보드와 어보의 역대 최대어는 서로 다른 값이다. 주간 순위는 리더보드 응답, 최대어는 기존 `/api/v2/me/state`의 `fishingCodex.best`를 각각 권위 데이터로 사용한다.

## 로딩과 오류 처리

- 순위 조회 중에는 각 어종에 `주간 확인 중`을 표시한다.
- 조회 중에는 `주간 미등록만` 토글을 비활성화한다.
- 순위 조회가 실패하면 각 어종에 `주간 순위 확인 불가`를 표시하고 토글을 비활성화한다.
- 로딩이나 오류 상태를 `주간 미등록`으로 간주하지 않는다.
- 주간 순위 조회가 실패해도 어보 상태, 설명, 최대어, 표본 추출 기능은 정상적으로 사용할 수 있어야 한다.

## 화면 표면과 접근성

- 기존 어보 카드의 불투명 표면을 유지하고 새 반투명 패널을 추가하지 않는다.
- 라이트·다크 모드에서 텍스트와 상태 배지의 대비를 유지한다.
- 토글은 버튼의 시각 상태뿐 아니라 `aria-pressed`로 선택 상태를 전달한다.
- 비활성 토글은 로딩 또는 오류 사유를 인접 문구로 알 수 있게 한다.

## 테스트

### 표시 규칙

- 미발견 어종이 실제 이름과 `미발견` 배지를 함께 표시한다.
- 미발견 어종의 설명은 표시하지 않는다.
- 등재, 미등록, 미발견 상태와 표본 추출 가능 여부가 기존 규칙을 유지한다.
- 본인 주간 기록이 있으면 상위 10위 밖을 포함해 `주간 N위`를 표시한다.
- 본인 주간 기록이 없으면 조회 성공 후 `주간 미등록`을 표시한다.
- 최대어가 있으면 기존 단위 포맷으로 표시하고 없으면 `최대어 —`를 표시한다.

### 필터 규칙

- `주간 미등록만 N`의 수가 실제 미등록 어종 수와 일치한다.
- 필터를 켜면 주간 기록이 있는 어종을 제외한다.
- 결과가 없는 등급 카드를 숨기고 전체 결과가 없으면 완료 빈 상태를 표시한다.
- 필터를 껐을 때 기존 등급과 어종 순서를 복원한다.

### 비정상 상태와 회귀

- 로딩 및 오류 중에는 토글이 비활성화되고 어종이 미등록으로 오분류되지 않는다.
- 순위 조회 실패가 기존 어보와 표본 추출 기능을 막지 않는다.
- 모바일 폭에서 이름, 상태 배지, 주간 순위, 최대어가 겹치지 않는다.
- 라이트·다크 모드 모두 기존 불투명 카드 표면을 유지한다.

## 범위 제외

- 주간 낚시 대회 화면의 구조 변경
- 어종 행에서 낚시터로 바로 이동하는 기능
- 주간 순위 계산, 정산, 보상 규칙 변경
- 어보의 등재·표본 추출 규칙 변경
- 미발견 어종 설명 공개
- 필터 상태의 영구 저장
