# 사냥터별 배경 일러스트 설계

## 목표

현재 별의 무덤만 전용 배경을 사용하고 나머지 사냥터는 모두 `hunt.webp`를 공유한다. 1~84단계의 14개 사냥터 테마가 각 지역의 분위기에 맞는 서로 다른 배경을 사용하도록 바꾸고, 기존 게임 그림체와 이질적인 별의 무덤 배경은 수채화·색연필풍 일러스트로 교체한다.

## 범위

- 6단계 단위의 14개 사냥터 테마에 전용 배경 경로를 매핑한다.
- 이미 게임에 포함된 지역 일러스트 13장을 재사용한다.
- 별의 무덤은 기존 주제와 구도를 유지하되 게임의 기존 그림체에 맞춰 새로 제작한다.
- `/battle/dungeon` 목록 경로, 잘못된 깊이, 프론티어 범위 밖 깊이는 기존 `hunt.webp`를 유지한다.
- 배경 전환, 딤 처리, 카드 표면 및 전투 로직은 변경하지 않는다.
- 배포는 포함하지 않는다.

## 접근 방식

### 선택: 기존 지역 자산 재사용 + 별의 무덤만 신규 제작

기존 UI 배경 중 각 사냥터 주제와 가까운 일러스트를 골라 매핑하고, 스타일이 맞지 않는 별의 무덤만 새로 제작한다. 새 자산 수를 최소화하면서도 모든 사냥터가 구분되고 전체 그림체가 일관된다.

### 검토한 대안

- 14장 모두 신규 제작: 지역 일치도는 높일 수 있지만 제작량과 스타일 편차가 크게 늘어난다.
- 공용 사냥 배경 유지: 구현은 단순하지만 사용자가 요청한 지역 구분을 해결하지 못한다.

## 별의 무덤 아트 방향

- 기존 별의 무덤의 핵심 소재인 부서진 천체 관측 유적, 원형 구조물, 떠다니는 잔해와 별하늘은 유지한다.
- `plains.webp`, `starlit_canyon.webp`, `star_corridor.webp`의 손으로 그린 수채화·색연필 질감, 부드러운 윤곽선, 밝은 남보라·크림·금색 팔레트와 가장자리 번짐을 따른다.
- 인물, 몬스터, 문자, 로고, 워터마크는 넣지 않는다.
- 화면에 80% 딤이 올라가도 큰 형태가 읽히도록 중앙 통로와 원형 유적의 실루엣을 분명히 한다.
- `public/images/ui/star_grave.webp`를 교체하고 기존 `ui` 프로필로 WebP 최적화한다.

## 구현

`gameSceneBackgroundForPath`에 테마 순서와 같은 14개 배경 배열을 둔다. 숫자 깊이가 1~84 범위에 있을 때 `Math.floor((depth - 1) / 6)`으로 배경을 선택한다. 목록 경로, 숫자가 아닌 경로, 0 이하 및 85 이상은 공용 사냥 배경으로 되돌린다.

테마 시작·끝 경계와 예외 경로를 단위 테스트로 고정해 데이터가 한 칸씩 밀리거나 프론티어 밖 경로가 마지막 지역으로 잘못 연결되는 회귀를 막는다.

## 검증

- 14개 테마의 시작·끝 깊이가 올바른 배경을 반환한다.
- 목록·비정상·범위 밖 경로가 `hunt.webp`를 반환한다.
- 새 별의 무덤 이미지가 코드 참조와 일치하고 이미지/권리 원장 검사를 통과한다.
- 집중 테스트, 린트, 타입 검사와 프로덕션 빌드를 통과한다.
- 배포 및 점검 모드 변경은 수행하지 않는다.
