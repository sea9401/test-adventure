# 위험 해역 배경 화풍 통일 디자인

## 목표

위험 해역 배경 3장의 해역별 구도와 식별 요소는 유지하면서, 기존 게임 지역 배경과 같은 연필선·옅은 수채화·종이 질감의 일러스트로 교체한다.

## 범위

다음 세 파일만 이미지 편집 대상으로 삼는다.

- `public/images/ui/dangerous-fishing-shattered-reef.webp`
- `public/images/ui/dangerous-fishing-storm-trench.webp`
- `public/images/ui/dangerous-fishing-abyssal-rift.webp`

어종, 거대어, 장비, 미끼 이미지와 화면 코드, 게임 규칙, 수치, 텍스트는 변경하지 않는다.

## 시각 기준

`public/images/ui/star_grave.webp`를 주 화풍 기준으로 사용하고, `public/images/ui/reef_isle.webp`와 `public/images/ui/fishing.webp`를 보조 기준으로 사용한다.

세 배경에 공통으로 적용할 기준은 다음과 같다.

- 손으로 그린 듯한 가는 연필선과 색연필 윤곽
- 물감이 종이에 스민 듯한 옅은 수채화 채색
- 따뜻한 미색 종이 바탕과 가장자리의 자연스러운 번짐
- 낮거나 중간 정도의 채도와 부드러운 명암
- 글자, 로고, 워터마크 없음
- 사진, 3D 렌더, 광택 강한 디지털 콘셉트 아트, 애니메이션 배경 스타일 배제

## 이미지별 불변 요소

### 부서진 암초

맑은 바다, 여러 방향으로 솟은 날카로운 암초, 가까운 목조 부두 또는 배의 일부를 유지한다. 현재의 과도하게 선명한 청록색과 매끈한 디지털 표면은 제거한다.

### 폭풍 해구

거센 파도, 먹구름, 번개, 낚싯대 또는 배 가장자리를 유지한다. 파도와 하늘은 위협적이어야 하지만 검푸른 사진풍이나 고대비 디지털 렌더가 되지 않게 한다.

### 심연 균열

바다 중앙의 거대한 균열, 어두운 수면, 부두와 낚싯대를 유지한다. 균열의 청색 발광은 식별 가능한 수준으로 남기되 네온처럼 강하게 빛나지 않게 한다.

## 제작 방식

각 기존 배경을 편집 대상으로 사용하고 참조 이미지의 화풍만 적용한다. 세 이미지는 각각 별도 작업해 해역별 불변 요소를 명시하며, 한 번에 여러 장을 합성하거나 동일한 결과를 단순 색상 변형해 재사용하지 않는다.

결과는 기존 파일명으로 교체한다. Git 이 이전 이미지를 보존하므로 별도 백업 파일은 만들지 않는다. 생성 결과에 필요한 경우 프로젝트의 기존 이미지 최적화 절차를 적용한다.

## 검수 기준

- 세 배경이 한 화가가 같은 매체로 그린 연작처럼 보인다.
- 축소된 해역 카드에서도 암초, 폭풍, 심연을 즉시 구분할 수 있다.
- 기존 화면의 가로형 크롭에서 핵심 피사체가 잘리지 않는다.
- 이미지에 텍스트, 로고, 워터마크, 깨진 낚싯대나 부자연스러운 구조물이 없다.
- `npm run optimize-images`와 `npm run check-images`가 성공한다.
- 변경 범위가 세 이미지와 필요한 자산 권리 메타데이터에 한정된다.

## 제외 사항

UI 레이아웃 변경, 새 이미지 경로 추가, 카탈로그 수정, 전용 어종·장비 이미지 재작업, 배포와 점검 모드 변경은 수행하지 않는다.
