# 돼지 출하 목장 설계

## 목표

기존 닭·소의 반복 생산과 다른 일회성 출하 흐름을 목장에 추가한다. 플레이어는 돼지우리와 함께 받은 첫 돼지를 비육한 뒤 출하해 돼지고기를 얻고, 이후 배합 사료로 새 돼지를 데려온다. 생산된 고기는 즉시 요리에 사용할 수 있어야 한다.

## 선택한 방식

돼지를 고기 전용 가축으로 추가한다. 기존 닭이나 소를 출하 대상으로 바꾸지 않는다. 기존 가축을 없애는 선택은 실수 위험이 크고, 이미 저장된 축사 상태와의 호환도 복잡해지기 때문이다.

돼지우리는 농사 Lv.50, 농장 증표 180개로 한 칸만 개방하며 첫 돼지 한 마리가 포함된다. 개방 즉시 16시간 비육이 시작된다. 완료된 돼지를 출하하면 돼지고기 8개와 농사 경험치 16을 받고 우리 상태는 비게 된다. 이때 배합 사료 4개를 한 번에 사용하면 새 돼지를 데려와 다음 16시간 비육을 시작한다. 출하 전에는 다음 돼지를 들일 수 없다.

## 상태 모델

저장 버전은 1을 유지한다. 기존 `RanchPenState`의 조합으로 돼지우리 상태를 표현할 수 있고, 새 `pigsty-1` 키는 파싱 시 기본값으로 안전하게 보충된다.

- 개방 직후 또는 재입식 후: `feed = 4`, `readyItems = 0`
- 비육 중: `feed = 4`, `progressMs < 16시간`
- 출하 대기: `feed = 0`, `readyItems = 8`, `readyCycles = 1`
- 출하 후: 다시 빈 우리

축사 정의에 `feedPerCycle`과 생산 방식(`recurring` 또는 `shipment`)을 둔다. 닭·소는 사료 1개당 한 생산 주기다. 돼지우리의 `feed = 4`는 돼지 한 마리가 들어와 비육 중임을 나타내는 내부 주기 토큰으로 사용하며, 최초 개방 때는 자동 부여되고 이후에는 출하 후 배합 사료 4개를 지불했을 때만 다시 부여된다. 부분 재입식과 출하 대기 중 추가 입식은 서버 로직에서 거부한다.

## 데이터와 경제

- 가축: `pig` / 표시명 `돼지`
- 축사: `pigsty-1` / 표시명 `돼지우리`
- 생산물: `pork` / 표시명 `돼지고기`
- 개방: 농사 Lv.50, 농장 증표 180개
- 최초 비육: 돼지우리 개방에 포함, 16시간
- 재입식: 출하 후 배합 사료 4개, 이후 16시간
- 출하: 돼지고기 8개, 농사 경험치 16

새끼돼지 가격을 별도 반복 화폐로 만들지 않는다. 현재 농장 증표는 밭·축사·씨앗 상자와 경쟁하므로, 반복 입식 비용까지 붙이면 후반 성장 동선을 과도하게 압박한다. 첫 돼지는 축사 개방 비용에 포함하고, 이후 새 돼지의 입식 비용은 배합 사료 4개로 표현한다.

## UI와 문구

목장 상단 설명은 달걀·우유 생산과 돼지 출하를 함께 안내한다. 돼지우리 카드는 상태별로 다음을 보여 준다.

- 개방 직후: `비육 중`, 출하까지 16시간
- 출하 후 빈 우리: `비어 있음`, `사료 4개로 새 돼지 데려오기`
- 비육 중: `비육 중`, 출하까지 남은 시간
- 출하 대기: `돼지고기 8개`, `출하 대기`

상단 일괄 버튼은 준비된 품목에 돼지고기가 포함될 수 있으므로 `모두 수확·출하`로 바꾼다. 잠긴 카드와 열린 카드는 기존 `SURFACE_INSET`, 내부 상태 카드는 `SURFACE_CARD`를 그대로 사용한다.

## 요리와 자산

Lv.50 요리 `허브 돼지고기 구이`를 추가한다. 재료는 돼지고기 8개, 양파 8개, 허브 6개이며 힘 15%, 활력 8% 효과와 요리 경험치 130을 제공한다. 한 번의 출하가 한 번의 요리로 이어지는 단순한 소비 고리를 만든다.

새 자산은 식별자와 동일한 이름을 쓴다.

- `public/images/items/farm/pig.webp`
- `public/images/items/farm/pork.webp`
- `public/images/items/cooking/herb_roasted_pork.webp`

## 오류 처리와 호환성

- 잠김, 레벨, 증표 검사는 기존 축사 개방 경로를 그대로 사용한다.
- 돼지우리를 개방하면 첫 돼지가 자동으로 비육을 시작한다.
- 출하 후 빈 돼지우리에는 정확히 사료 4개만 한 번에 사용해 새 돼지를 데려올 수 있다.
- 비육 중이거나 출하 대기 중이면 새 입식을 거부한다.
- 예전 저장에는 돼지우리 상태가 없으므로 파서가 잠긴 빈 우리로 보충한다.
- 손상된 저장의 돼지 사료·진행도·출하 수량은 정의된 용량과 주기 단위로 정규화한다.
