# 아레나 제재 계정 상대 제외 설계

## 문제

아레나 매치 후보 조회는 `users`를 조인하지만 이메일만 읽고 운영 계정만 제외한다.
`users.bannedUntil`이 현재보다 미래인 계정도 캐릭터 세이브가 남아 있으면 실유저 상대
후보가 된다. 제재 계정 본인은 `ensureUser`에서 차단되지만 다른 이용자의 상대 스냅샷으로
사용되는 경로에는 이 검사가 적용되지 않는다.

## 설계

- 아레나 실유저 상대 후보 전용 `filterArenaOpponentEligibleRows`를 만든다.
- 이 함수는 순위표·토너먼트·시즌 보상에서 쓰는 `filterRankingEligibleRows`의 제재 만료
  판정과 기존 `excludeArenaOperatorAccounts`를 조합한다.
- 매치 후보 조회에 `users.bannedUntil`을 포함하고, 점수 조회와 추첨 전에 전용 필터를
  적용한다.
- `bannedUntil`이 현재보다 미래인 기간 정지와 영구 밴은 제외한다. `null`, 만료 시각이
  현재와 같거나 과거인 계정은 다시 후보가 될 수 있다.
- 봇 폴백, Elo, 전적, 스태미나와 일요일 연습전 로직은 변경하지 않는다.

## 테스트

- 정상 계정과 만료된 정지는 후보에 남는지 확인한다.
- 현재 기간 정지와 영구 밴은 후보에서 제외되는지 확인한다.
- 운영 계정도 동일한 후보 경계에서 제외되는지 확인한다.
