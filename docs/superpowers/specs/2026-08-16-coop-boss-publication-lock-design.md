# 협동 보스 전체 공개 잠금 설계

## 목표

심연어룡을 포함한 모든 협동 보스는 처음 등장할 때 소환자만 볼 수 있게 한다. 소환자는 필요하면 길드원에게 먼저 열거나 전체 공개로 전환할 수 있다. 전체 공개된 보스는 전투 도중 다시 개인·길드 범위로 숨길 수 없으며, 전체 공개 직전에 되돌릴 수 없다는 확인을 한 번 받는다.

## 공개 범위 규칙

- 낚시에서 출현하는 심연어룡과 소환서로 부르는 모든 협동 보스의 최초 `visibility`는 `summoner_only`다.
- 전체 공개 전에는 `summoner_only`와 `guild_only` 사이를 오갈 수 있다.
- `public` 전환은 단방향이다. 현재 상태가 `public`이면 `summoner_only` 또는 `guild_only` 요청을 서버가 `visibility_locked`로 거부한다.
- 이미 `public`인 세션에 다시 `public`을 요청하는 경우에는 성공한 무변경 요청으로 처리하고 알림을 다시 발송하지 않는다.
- 소환자만 활성 세션의 공개 범위를 바꿀 수 있다는 기존 권한은 유지한다.
- 공개 범위는 모든 협동 보스의 안전 규칙이므로 `V2_CORE_LOOP_V2` 기능 플래그와 무관하게 목록·상세·공격·공격 로그에서 항상 적용한다. 생성만 개인으로 바뀌고 접근 검사가 꺼지는 모순을 허용하지 않는다.

## 생성과 알림

- 소환서 API는 클라이언트가 보낸 최초 공개 범위를 신뢰하지 않고 항상 `summoner_only`로 저장한다.
- 낚시 출현 경로도 심연어룡을 `summoner_only`로 저장한다.
- 보스 생성 직후에는 전체 소식 피드와 협동 보스 채팅 알림을 발송하지 않는다.
- 공개 범위 API가 행 잠금 안에서 비공개 상태를 `public`로 바꾼 경우에만 트랜잭션 이후 전체 소식 피드와 협동 보스 채팅 알림을 각각 한 번 발송한다.
- 메시지는 소환자와 보스 이름을 포함해 `○○ 님이 「보스명」 토벌을 전체 공개했다` 형식으로 표시한다.

## 화면

- 소환 목록에서 사전 공개 범위 선택기를 제거하고, 모든 보스가 먼저 개인 상태로 시작한다는 안내를 표시한다.
- 소환자 상세 화면에서 비공개·길드 공개 상태일 때만 범위 변경 조작을 표시한다.
- 전체 공개 버튼을 누르면 `전체 공개 후에는 나만 또는 길드원만으로 되돌릴 수 없다`는 확인창을 한 번 표시한다. 취소하면 API를 호출하지 않는다.
- 전체 공개가 끝나면 변경 조작을 숨기고 `공개 범위 · 공개` 읽기 전용 배지만 표시한다.
- 서버가 오래된 화면이나 직접 요청에서 범위 축소를 거부하면 사용자가 이해할 수 있는 잠금 안내를 표시한다.
- 공개 범위 선택과 현재 범위 표시는 `V2_CORE_LOOP_V2` 플래그와 무관하게 항상 노출한다.

## 동시성과 오류 처리

공개 범위 API는 기존처럼 세션 행을 `FOR UPDATE`로 잠근 뒤 소유자·활성 상태·현재 공개 상태를 검사한다. 따라서 동시에 여러 공개 요청이 와도 실제 상태 전환과 전체 알림은 한 요청에만 귀속된다. 알림은 게임 상태 변경의 부수 효과이며, 기존 전체 소식·협동 보스 알림 함수의 실패 격리 정책을 따른다.

## 검증

- 순수 공개 범위 전환 규칙: 비공개 간 전환 허용, 전체 공개 후 축소 거부, 동일 공개 재요청 허용
- 심연어룡 생성: 최초 개인 상태 및 생성 즉시 전체 알림 없음
- 소환서 생성: 요청 본문과 무관하게 최초 개인 상태
- 공개 API: 최초 전체 공개만 상태를 바꾸고 알림을 한 번 발송하며, 이후 축소와 중복 알림을 차단
- UI: 전체 공개 확인을 취소하면 콜백이 실행되지 않고, 확인하면 한 번만 실행
- 관련 집중 테스트, 타입 검사, 린트, 전체 테스트

## 범위 밖

- 이미 운영 DB에 `public`으로 저장된 활성 보스를 개인 상태로 되돌리는 데이터 마이그레이션
- 전체 공개 이후 별도의 초대 목록이나 길드 변경 정책
- 배포와 점검 모드 변경
