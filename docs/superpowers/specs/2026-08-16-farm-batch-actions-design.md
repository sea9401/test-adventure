# 농장 일괄 작업 설계

## 문제

모험가 농장의 밭은 최대 6칸이지만 심기, 수확, 비료 사용은 각 밭 카드에서 한 번씩
눌러야 한다. 같은 작물을 여러 빈 밭에 심거나 동시에 준비된 작물을 수확할 때 반복
조작이 많고, 비료 보유량을 확인하며 밭마다 적용해야 한다.

## 선택한 접근

클라이언트가 현재 농장 상태에서 대상 밭을 확정한 뒤 기존 개별 API를 순서대로
호출한다. 밭이 최대 6칸이고 농장 요청 제한이 분당 30회이므로 한 동작은 최대 6회로
끝난다. 기존 API를 그대로 사용하면 수확마다 적용되는 희귀 수확 보정, 농사 XP,
직업 숙련도, 길드 탐사 진행도, 숨겨진 도안, 생활 텔레메트리를 바꾸지 않고 보존할
수 있다.

별도 일괄 API는 한 번의 요청으로 원자성을 얻을 수 있지만 복잡한 수확 후속 처리를
재구현하거나 크게 추출해야 한다. 병렬 호출은 같은 저장 키를 동시에 갱신해 결과가
덮일 수 있으므로 사용하지 않는다.

## 일괄 작업 규칙

- `모두 수확`: 현재 시각에 수확 가능한 밭만 밭 순서대로 수확한다.
- `모두 심기`: 선택한 작물을 빈 밭에 밭 순서대로 심는다. 대상 수는 빈 밭 수와
  선택 작물 씨앗 보유량 중 작은 값이다. 잠긴 작물은 실행할 수 없다.
- `모두 비료 뿌리기`: 작물이 자라는 중이고 아직 비료를 쓰지 않은 밭에 밭 순서대로
  적용한다. 이미 수확 가능한 밭은 제외하며, 대상 수는 적용 가능한 밭 수와 유기질
  거름 보유량 중 작은 값이다.
- 대상이 없는 버튼은 비활성화하고 버튼 문구에 대상 칸 수를 표시한다.
- 일괄 실행 중에는 개별 밭 작업과 다른 일괄 작업을 모두 비활성화한다.
- 각 요청 성공 후 서버 응답 상태를 즉시 적용한다. 네트워크 또는 서버 오류로 중간에
  멈추면 이미 성공한 밭은 유지하고, 일부 처리 후 중단됐다는 오류 문구를 표시한다.

## UI

재배 탭의 작물 선택기와 밭 카드 목록 사이에 `SURFACE_INSET` 기반의 불투명 일괄 작업
패널을 둔다. 모바일에서는 세 버튼을 세로로, 넓은 화면에서는 3열로 배치한다.
버튼은 각각 `모두 수확 · N칸`, `<작물명> 모두 심기 · N칸`,
`모두 비료 뿌리기 · N칸`으로 현재 범위를 보여 준다. 실행 중인 버튼은 작업 종류에
맞는 진행 문구를 표시한다.

## 상태와 결과

`useFarm`은 `busyPlotAction`과 `harvestAll`, `plantAll`, `fertilizeAll`을 제공한다.
기존 응답 적용 함수는 일괄 처리 중 개별 토스트를 생략할 수 있게 하되 농장 상태,
잔액, 마지막 수확 결과와 알림 읽음 처리는 그대로 갱신한다. 완료 후에는 작업 종류와
처리한 칸 수를 하나의 토스트로 요약한다.

## 테스트

- 순차 일괄 요청 도우미가 입력 순서를 지키고 각 성공 응답을 적용하는지 검증한다.
- 중간 실패 시 이후 요청을 보내지 않고 완료 수를 포함한 실패 결과를 반환하는지
  검증한다.
- 재배 탭에 세 일괄 버튼과 대상 칸 수가 렌더링되고 실행 중 비활성 상태가 유지되는지
  정적 렌더링으로 검증한다.
- 기존 농장 도메인, 수확 라우트, 요청 제한 테스트를 함께 실행한다.
