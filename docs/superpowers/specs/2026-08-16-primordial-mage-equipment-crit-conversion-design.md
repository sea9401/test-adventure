# 태초술사 장비 치명타 전환 패시브 설계

## 목표

일반 치명타 확률은 평타와 직접 피해 스킬이 이미 공유하지만, 장비의 치명타 피해는 평타 치명타 배율에만 반영된다. 이 때문에 직접 마법 스킬을 주력으로 쓰는 캐릭터는 장비의 치명타 피해 옵션에서 충분한 가치를 얻지 못한다.

태초술사에 신규 장착 패시브를 추가해 장비 치명타 피해를 마법 스킬 치명타 피해로 점감 전환한다. 물리 치명 빌드에는 보너스가 새지 않게 하고, 치명 장비를 모은 마법 빌드는 고정 스킬 치명타 피해 패시브보다 높은 잠재력을 얻도록 한다.

## 신규 패시브

- 이름: `원초 증폭`
- 획득 직업: 6차 `태초술사`
- 분류: 장착형 패시브
- 학습 비용: 숙달 12,000
- 장착 비용: 12 SP
- 기존 `태초회귀`, `근원공명`과 별도의 세 번째 태초술사 스킬로 추가한다.
- 다른 직업 패시브와 마찬가지로 학습 후에는 현재 직업과 무관하게 장착할 수 있다.

설명은 장비 치명타 피해를 마법 스킬 치명타 피해로 점감 전환하며 최대 전환량이 `+0.75×`임을 명시한다. 효과 칩에는 `장비 치명타 피해 → 마법 스킬 치명타 피해`를 표시한다.

## 전환식

장착 중인 장비에서 얻은 치명타 피해 합을 배수 단위 `E`로 둔다. 예를 들어 장비 옵션과 활성 세트 보너스의 `critMult` 합이 100이면 `E = 1.00`이다.

전환 보너스 `B`는 다음과 같다.

```text
B = 0.75 × (1 − exp(−E ÷ 2))
```

대표 기준값은 다음과 같다.

| 장비 치명타 피해 E | 마법 스킬 치명타 보너스 B |
|---:|---:|
| +0.50× | 약 +0.17× |
| +1.00× | 약 +0.30× |
| +1.50× | 약 +0.40× |
| +2.00× | 약 +0.47× |
| +3.00× | 약 +0.58× |
| +5.00× | 약 +0.69× |
| 이론상 최대 | +0.75× |

`E = 1.00` 부근에서는 천궁의 `성도 조준`이 주는 고정 스킬 치명타 피해 `+0.30×`와 비슷하다. 이후에는 장비 투자가 많을수록 더 강해지지만, 점감 때문에 최대치에는 사실상 도달하지 못한다.

## 전환 대상

전환에 포함하는 값은 현재 장착 장비 집계의 `critMult`뿐이다.

- 개별 장비의 고정 옵션과 개체 굴림
- 완성된 일반 장비 세트 보너스
- 충족한 태그 세트 단계 보너스

다음 값은 전환하지 않는다.

- 행운과 힘에서 파생된 일반 치명타 피해
- 장착 스킬과 직업 효과가 직접 주는 일반 치명타 피해
- 치명타 확률 75% 초과분이 주는 오버플로 보너스
- 기존 `skillCritDmgPct` 계열 패시브

이 경계는 장비 옵션을 살린다는 목표를 보존하고, 일반 치명 빌드의 다른 투자원이 마법 보너스로 이중 전환되는 것을 막는다.

## 전투 적용

신규 보너스는 치명타가 발생한 직접 마법 스킬 피해에만 가산한다.

- `scaling="magic"` 또는 `scaling="spi"`인 직접 피해가 대상이다.
- 순수 마법 스킬은 직접 피해 전체에 적용한다.
- 물리와 마법 피해가 섞인 스킬은 `magicEnemyDamage`로 추적되는 마법 피해 부분에만 적용한다.
- 기존 `magicSkillDamagePct`가 마법 피해를 바탕으로 더한 보너스 피해도 마법 피해 부분에 포함한다.
- 물리 직접 피해, 중독·출혈 등 지속 피해, 회복, 보호막에는 적용하지 않는다.
- 마법 기본 공격은 이미 일반 장비 치명타 피해 배율을 사용하므로 신규 보너스를 중복 적용하지 않는다.

기존 스킬 치명타 배율은 유지한다. 공통 `SKILL_CRIT_MULT`, 기존 `skillCritDmgPct`, 광전사 필살기 보너스와 조건부 치명 오버플로는 지금처럼 해당 스킬 전체의 치명타 배율을 구성한다. `원초 증폭`의 장비 전환분만 마법 피해 부분에 별도로 더한다.

개념적인 치명타 계산은 다음과 같다.

```text
최종 치명 스킬 피해
= 기존 방식으로 계산한 전체 스킬 치명 피해
+ 같은 공격 배율을 적용한 마법 피해 부분 × 장비 전환 보너스 B
```

PvE와 PvP가 같은 순수 계산 함수를 사용해 점감식과 혼합 피해 분배가 달라지지 않게 한다. 패시브를 장착하지 않았거나 `E = 0`이면 신규 필드를 생략하거나 0으로 두고 기존 피해 결과와 RNG 소비 순서를 유지한다.

## 데이터 흐름

1. 신규 패시브 효과에 장비 치명타 전환 활성 여부를 나타내는 명시적 필드를 추가한다.
2. 장착 패시브 집계는 해당 필드를 불리언으로 합친다. 같은 효과가 중복되어도 전환 곡선을 여러 번 적용하지 않는다.
3. 플레이어 전투 파생 단계는 `equipAcc.critMult`를 배수 단위로 변환하고 점감식을 한 번 적용한다.
4. 계산된 보너스를 일반 `skillCritDmgPct`와 구분되는 전용 전투 필드로 전달한다.
5. PvE와 PvP 스킬 치명타 계산은 전용 필드를 마법 직접 피해 부분에만 소비한다.

잘못된 장비 데이터나 음수 값은 `E = max(0, E)`로 정규화한다. 지수 함수 결과도 `0` 이상 `0.75` 미만으로 제한해 비정상 입력이 피해 배율을 낮추거나 상한을 넘지 못하게 한다.

## 표시

- `원초 증폭`의 설명과 효과 칩에 장비 기반 점감 전환과 최대 `+0.75×`를 표시한다.
- 캐릭터 상세 능력치에서 패시브가 장착된 경우 `마법 스킬 치명타 배율`을 별도 행으로 표시한다.
- 이 값은 기본 스킬 치명타 배율, 기존 스킬 치명타 피해 보너스, 적용 가능한 오버플로와 현재 장비 전환 보너스를 합친 실제 배율이다.
- 기존 `스킬 치명타 배율` 행은 일반 직접 피해 스킬의 배율로 유지해 두 값의 차이를 확인할 수 있게 한다.
- 장비 옵션 이름 `치명타 피해`와 저장 형식은 바꾸지 않는다.

## 테스트와 검증

1. 점감 순수 함수에 대해 `E = 0`, `0.5`, `1`, `1.5`, `2`, `3`, `5` 기준값과 음수 입력을 검증한다.
2. 매우 큰 입력에서도 보너스가 `+0.75×`를 넘지 않고 상한에 가까워지는지 검증한다.
3. 개별 장비 옵션, 굴림, 일반 세트와 태그 세트의 `critMult`가 전환 입력에 포함되는지 검증한다.
4. 행운·힘·일반 치명타 피해 패시브·오버플로·기존 스킬 치명타 피해는 전환 입력에서 제외되는지 검증한다.
5. 순수 `magic` 피해와 `spi` 피해가 전환 보너스를 받고, 순수 물리 피해는 받지 않는지 검증한다.
6. 물리·마법 혼합 스킬에서는 마법 피해 부분에만 추가 배율이 적용되는지 손계산 값으로 검증한다.
7. 지속 피해, 회복, 보호막과 마법 기본 공격이 신규 보너스를 받지 않는지 검증한다.
8. 같은 고정 RNG 조건에서 PvE와 PvP가 같은 전환 보너스와 피해 비율을 사용하는지 검증한다.
9. 패시브 미장착 및 장비 치명타 피해 0인 기존 캐릭터의 전투 결과와 RNG 호출 수가 변하지 않는지 검증한다.
10. 스킬 학습 목록, 학습 비용, 12 SP 장착 비용, 효과 칩과 캐릭터 상세 배율 표시를 검증한다.

집중 Vitest와 타입 검사를 실행하고, 마법 빌드 대표 장비 조합으로 기존 진행 시뮬레이션을 비교한다. 시뮬레이션에서는 패시브 미장착 빌드가 변하지 않아야 하며, 장착 빌드는 치명타 장비 투자량에 따라 단조롭게 강해지되 상한을 넘지 않아야 한다.

## 범위 제외

- 일반 치명타 확률과 75% 적용 상한은 바꾸지 않는다.
- 공통 스킬 치명타 기본 배율 `1.70×`은 바꾸지 않는다.
- 기존 장비와 세트의 치명타 수치는 재조정하지 않는다.
- 천궁·암살자 등 물리 치명 직업의 패시브와 피해 계산은 바꾸지 않는다.
- 지속 피해에 치명타 시스템을 새로 추가하지 않는다.
- 배포하지 않는다.
