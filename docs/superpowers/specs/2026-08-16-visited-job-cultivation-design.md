# 방문 직업 수행 선택 설계

## 목표

플레이어가 현재 직업을 유지한 채, 한 번이라도 직접 전직해 본 전투직의 수행 성장 프로필을 선택하여 수행할 수 있게 한다. 특정 능력치를 올리기 위해 반복 재전직하며 골드를 소모하는 불편을 없애되, 방문하지 않은 직업의 성장 프로필을 미리 사용하는 우회는 허용하지 않는다.

## 검토한 접근

1. 수행 요청마다 `targetJobId`를 보내고 서버가 현재 직업·전직 이력을 검증한다. 별도 저장값이 없고 서버가 권위 있는 검증을 수행하므로 이 방식을 채택한다.
2. 선택한 수행 직업을 `proficiency.v2`에 영구 저장한다. 다음 방문 때 선택이 유지되는 장점은 있지만 마이그레이션과 상태 동기화가 추가되고, 이번 요구에는 불필요하다.
3. 수행 전에 임시 재전직을 적용했다 되돌린다. 전직 비용, 레벨 초기화, 스킬 정리 같은 부작용을 일으킬 수 있어 제외한다.

## 서버 규칙

- `POST /api/v2/me/cultivate`는 기존 `mode`와 함께 선택적인 `targetJobId`를 받는다.
- `targetJobId`가 없으면 현재 직업으로 수행하는 기존 동작을 그대로 유지한다.
- 선택 가능한 직업은 다음 중 하나를 만족해야 한다.
  - 현재 직업이다.
  - `proficiency.v2.jobHistory`에 기록되어 있다.
  - 전직 이력 필드 도입 전 저장과의 호환을 위해 해당 직업 숙련도가 1 이상이다.
- 직업 카탈로그에 없거나 전직 대상으로 선택할 수 없는 ID, 방문하지 않은 직업은 `unvisited_job`으로 거부한다.
- 선택한 직업이 생활직이면 `lifestyle_job`으로 거부한다. 현재 직업이 생활직이더라도 과거 방문한 전투직을 선택한 경우에는 수행할 수 있다.
- 선택 직업의 레거시 저장 매핑에서 수행 회계 직군을 구하고, 기존 `applyCultivationBatch`에 그 직군과 선택 직업 ID를 전달한다.
- 수행 비용, 특별 수행 확률, 한계 증가량, 초기화 환급 원장은 기존 규칙을 그대로 사용한다.
- 성공 응답에는 실제 적용한 `targetJobId`, `targetJobName`, `group`을 포함한다.

## 클라이언트와 UI

- 성장의 신전 수행 탭에서 `jobsV2.jobs` 중 `visited`가 참이고 수행 가능한 전투직만 선택지로 노출한다.
- 현재 직업을 초기 선택값으로 사용한다. 현재 직업이 생활직이면 방문한 전투직 중 첫 번째 항목을 선택하며, 항목이 없으면 기존 수행 불가 안내를 유지한다.
- 선택기는 불투명한 `SURFACE_INSET` 영역에 배치하고, 직업명과 1회 수행 시 오르는 능력치를 함께 표시한다.
- 선택이 바뀌면 제목, 능력치별 `한계 +N`, 수행 가능 여부가 즉시 바뀐다.
- 1회 수행과 가능한 만큼 수행 요청 모두 동일한 `targetJobId`를 JSON 본문으로 전송한다.
- 서버가 `unvisited_job`을 반환하면 "전직한 적이 있는 직업만 선택할 수 있습니다"라고 안내한다.
- 수행 완료 문구에는 선택 직업명을 붙여 어떤 성장 프로필이 적용됐는지 명확히 한다.

## 오류와 동시성

- 전직 이력 검증은 `character.v2`와 `proficiency.v2`를 잠근 기존 트랜잭션 안에서 수행한다.
- 클라이언트 선택지는 편의 기능일 뿐이며 서버 검증을 우회할 수 없다.
- 수행 중에는 선택기와 기존 수행 버튼을 모두 비활성화하여 중복 요청과 표시 불일치를 막는다.
- 요청 실패 시 선택값과 기존 상태는 유지하고 오류만 표시한다.

## 테스트

- 요청 생성기가 `once`와 `max` 모두 `targetJobId`를 JSON으로 보낸다.
- 서버 라우트가 과거 방문한 성채기사 프로필을 현재 직업과 무관하게 적용한다.
- 방문하지 않은 직업과 생활직 선택을 거부하고 포인트를 소모하지 않는다.
- 이력 필드 도입 전 숙련도가 남은 직업도 방문 직업으로 인정한다.
- 선택 UI가 방문한 전투직만 표시하고 선택한 프로필의 능력치 증가량을 보여준다.
- 기존 본문 없는 1회 수행 요청은 현재 직업 수행으로 계속 동작한다.

## 범위 밖

- 마지막 선택 직업의 영구 저장
- 생활직 수행 허용
- 수행 비용·확률·성장량 조정
- 전직 비용 또는 전직 규칙 변경
- 운영 배포
