# 약세 스탯 효율 재조정 설계

## 목표

민첩과 행운을 약화하지 않고, 동일한 투자량에서 활력·지능·정신이 주는 전투 기여를 더 분명하게 만든다. 힘은 현재 사냥 시뮬레이션에서 이미 강하므로 수치를 유지한다.

## 진단

현재 파생식은 민첩이 속도·회피·적중을, 행운이 치명타 확률·치명타 피해·회피를 동시에 제공한다. 반면 활력은 생존력이 처치 시간 제한으로 전환되지 못하고, 지능은 높은 적 방어 앞에서 마법 스킬 피해 하한이 부족하며, 정신은 지능을 추월하기 전까지 공격 기여가 전혀 없는 문턱을 가진다.

현재 `sim-v2-progression --skills --depths=8,20,50` 결과에서 힘은 97~100% 승률을 유지하므로 직접 상향 대상이 아니다. 활력은 깊이 50에서 0%, 지능은 49%, 정신 보조 빌드는 전 구간 0%로 떨어진다. 행운 역시 깊이 50에서 0%이므로 민첩·행운을 일괄 하향하는 방식은 사용하지 않는다.

## 변경 설계

### 활력

- `VIT_ATK_COEF`를 `0.07`에서 `0.10`으로 올린다.
- `DEF_PER_VIT`를 `0.30`에서 `0.35`로 올린다.
- 최대 HP와 회복 배율은 그대로 둔다.

활력 100당 물리 공격력은 7에서 10, 방어력은 30에서 35로 오른다. 힘의 공격 계수 `0.35`보다 충분히 낮게 유지해 활력이 힘을 대체하지 않게 한다. 방어력 40은 동일 레벨 아레나에서 활력이 힘과의 상성을 과도하게 뒤집어 시뮬레이션 후 35로 완화했다.

### 지능

- `MIN_DMG_PER_INT`를 `0.10`에서 `0.15`로 올린다.
- `MAGIC_ATK_PER_INT`와 최대 MP 계수는 그대로 둔다.

마법 공격력 자체를 전 구간에서 키우지 않고, 마법 방어력이 높은 후반 적을 상대로 마법 스킬 피해 하한만 힘과 같은 비율로 보강한다.

### 정신

- `MAGIC_ATK_PER_SPI = 0.10`을 새로 추가해 모든 정신이 소량의 마법 공격력에 기여하게 한다.
- `MAGIC_ATK_PER_EXCESS_SPI`를 `0.70`에서 `0.60`으로 바꾼다.
- 마법 공격력 공식을 `INT×0.35 + SPI×0.10 + max(0, SPI−INT)×0.60`으로 바꾼다.
- `MIN_DMG_PER_SPI = 0.08`을 추가한다.

정신이 지능보다 높은 구간의 정신 1당 총 한계 계수는 기존과 같은 `0.70`을 유지한다. 대신 정신이 지능 이하인 구간에도 `0.10`의 공격 기여를 주어 문턱을 없앤다. 정신은 마법 방어·치명타 저항·회복도 함께 제공하므로 지능의 마법 공격 계수 `0.35`보다 낮게 둔다.

### 유지 대상

- 힘·민첩·행운의 파생 계수와 점감 곡선은 바꾸지 않는다.
- 직업 스킬, 장비, 몬스터, 전투 시간 제한은 이번 변경에서 건드리지 않는다.
- 배포하지 않는다.

### 물리·마법 스킬 최소 피해 분리

- 평타는 기존처럼 유효 공격력의 15%를 하한으로 사용한다.
- 물리 스킬 최소 피해는 `floor(STR×0.15 + VIT×0.05)`로 계산한다.
- 마법 스킬 최소 피해는 `floor(INT×0.15 + SPI×0.08)`로 계산한다.
- `scaling="magic"`과 `scaling="spi"`인 직접 피해 스킬은 마법 스킬 최소 피해를 사용하고, 나머지 직접 피해 스킬은 물리 스킬 최소 피해를 사용한다.
- 지속 피해·반사·회복·HP 비용에는 두 스킬 최소 피해를 적용하지 않는다.
- 기존 호출자가 마법 스킬 최소 피해를 전달하지 않으면 물리 스킬 최소 피해로 폴백해 호환성을 유지한다.

이 분리로 지능과 정신이 물리 스킬의 피해 하한까지 올리던 교차 효율을 제거하고, 각 스탯이 담당하는 공격 계열을 분명히 한다.

## 테스트와 검증

1. 같은 레벨·장비·직업 조건에서 한 스탯만 100 올린 파생값을 비교하는 회귀 테스트를 먼저 작성한다.
2. 활력의 공격력·방어력·물리 최소 피해, 지능의 마법 최소 피해, 정신의 마법 공격력·마법 최소 피해가 설계값만큼 오르는지 정확히 검증한다.
3. 지능·정신 투자가 물리 최소 피해를 바꾸지 않고, 힘·활력 투자가 마법 최소 피해를 바꾸지 않는지 검증한다.
4. 물리·마법 직접 피해 스킬이 높은 방어력 앞에서 서로 다른 하한을 선택하고, 평타의 15% 하한은 변하지 않는지 검증한다.
5. 정신이 지능을 추월한 뒤의 정신 1당 마법 공격 한계 계수가 기존 `0.70`으로 유지되는지 경계 테스트로 검증한다.
6. 기존 힘·민첩·행운 파생값이 변하지 않는 회귀 테스트를 유지한다.
7. 집중 Vitest, 타입 검사, 전체 테스트와 현재 진행 시뮬레이션을 실행한다.

## 문서와 표시

캐릭터 능력치 도움말과 매뉴얼의 정신 설명을 새 공식에 맞춘다. 정신이 지능보다 높을 때만 마법 공격에 기여한다는 기존 문구는, 정신 전체가 소량 기여하고 초과 정신이 추가 기여한다는 설명으로 바꾼다.
