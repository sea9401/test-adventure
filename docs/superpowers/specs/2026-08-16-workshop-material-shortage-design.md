# 제작소 부족 재료 강조 설계

## 문제

길드 제작소 레시피는 일반·명장 제작 가능 여부를 계산하지만, 재료 목록은 하나의
문자열로 표시한다. 재료가 하나라도 모자라면 버튼에는 `부족`만 보여서 사용자가 어떤
재료를 더 모아야 하는지 직접 보유 재료 목록과 대조해야 한다.

## 설계

- 기존 `WorkshopRecipeView.materialCost`와 `WorkshopState.materials`를 비교해 각 재료의
  충족 여부를 클라이언트에서 표시한다. 서버 판정과 비용 계산은 변경하지 않는다.
- 일반 제작에는 `recipe.materialCost`, 명장 제작에는 `recipe.masterwork.materialCost`를
  사용한다. 두 모드가 서로 다른 필요량을 그대로 보여 준다.
- 충족한 재료는 기존처럼 `재료명 필요량`으로 표시한다.
- 부족한 재료는 장미색의 굵은 글자로 강조하고
  `재료명 필요량 (필요 N · 보유 M · 부족)`을 표시한다. 색에만 의존하지 않도록
  `부족` 문구와 수량을 함께 노출한다.
- 재료 항목 사이는 기존과 같은 가운데점으로 구분해 모바일 카드의 현재 밀도를
  유지한다.
- 과거 또는 부분 응답에 `materialCost`가 없으면 기존 `costText`를 그대로 표시한다.
- 골드, 레시피 레벨, 제작소 레벨, 개량 장비, 상위 재료 대체 판정과 버튼 문구는
  변경하지 않는다.

## 구성

`WorkshopCraftPanel.tsx` 안에 재료 비용 표시 전용 컴포넌트를 두고, 재료 이름은 기존
`guildWorkshopMaterialName`을 재사용한다. 별도 API 필드나 저장 데이터는 추가하지
않는다.

## 테스트

- 일반 제작에서 충족 재료는 기존 형태를 유지하고 부족 재료만 필요량·보유량·부족
  문구와 강조 클래스를 갖는지 정적 렌더링으로 검증한다.
- 명장 제작의 배수 비용을 기준으로 독립적으로 부족 여부를 계산하는지 검증한다.
- 기존 제작 수수료, 상위 재료 대체, 도감 상태 테스트를 함께 실행한다.
