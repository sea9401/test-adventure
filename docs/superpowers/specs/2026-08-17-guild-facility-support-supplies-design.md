# 길드 시설 지원 물자 개편 설계

작성일: 2026-08-17

## 배경

길드 교역소의 `정착 보급품`은 현재 구매 시 길드의 구형 정착지 공용 재화 풀에 통나무와 철광석을 각각 100개씩 적립한다. 이 공용 풀은 중앙 길드 시설 업그레이드가 건물별 공동 기부 방식으로 개편된 뒤 길드 시설 화면에서 더 이상 표시하거나 소비하지 않는다. 점령 영지의 마을과 영지 건축물에는 여전히 사용되지만, 영지를 보유하지 않은 길드는 구매 결과를 확인하거나 이용할 수 없다.

상품을 현재 길드 시설 성장 구조에 맞는 즉시 적용형 공동 보상으로 바꾼다. 별도의 개인 아이템이나 길드 공용 지갑을 새로 만들지 않는다.

## 목표

- 모든 길드가 영지 보유 여부와 관계없이 상품을 이용할 수 있게 한다.
- 구매 보상이 선택한 길드 시설의 기존 공동 기부 진행도에 직접 반영되게 한다.
- 통나무와 철광석만 지원하며 고급 목재·광석은 지원하지 않는다.
- 상품의 총 지원 가치를 구매 1회당 200개로 고정한다.
- 기존 상품 ID, 교역 토큰 가격과 주간 구매 기록을 유지한다.
- 구매 전후 결과와 실제 반영 위치를 화면에서 명확히 보여 준다.

## 범위 밖

- 개인 인벤토리에 지원 물자 아이템을 지급하지 않는다.
- 별도의 길드 시설 물자 지갑이나 공용 재화 풀을 만들지 않는다.
- 고급 목재와 고급 광석의 기부 진행도에는 적용하지 않는다.
- 구매로 반영된 지원량은 개인 길드 기여 점수로 계산하지 않는다.
- 과거 구매로 구형 정착지 공용 풀에 이미 적립된 재화를 자동 이전하거나 다시 지급하지 않는다.

## 상품 정의

- 기존 내부 ID `settlement_supplies`는 유지한다.
- 표시 이름을 `정착 보급품`에서 `길드 시설 지원 물자`로 변경한다.
- 교역 토큰 가격 120개, 주간 구매 한도 3회, 교역소 최소 레벨 1은 유지한다.
- 길드 관리자만 구매할 수 있는 공용 보상이라는 기존 권한 규칙을 유지한다.
- 설명은 `선택한 길드 시설의 통나무·철광석 기부 진행도에 총 200개를 즉시 지원합니다.`로 변경한다.
- 상품 카드에 `길드 공용 · 구매 즉시 시설에 적용` 문구를 표시한다.

## 대상 시설

구매 시 다음 조건을 모두 만족하는 시설만 선택할 수 있다.

1. 길드에 실제로 개방되어 있는 배치형 길드 시설이다.
2. 최대 레벨이 아니며 다음 업그레이드가 존재한다.
3. 다음 업그레이드 비용에 통나무 또는 철광석이 포함되어 있다.
4. 두 재료의 남은 기부 필요량 합계가 200개 이상이다.

통나무와 철광석을 요구하지 않는 고단계 업그레이드는 지원 대상이 아니다. 선택 가능한 시설이 없으면 구매 버튼을 비활성화하고 `통나무·철광석 지원을 받을 수 있는 시설이 없습니다.`라고 안내한다.

## 지원량 배분

구매 1회당 총 200개를 선택한 시설의 통나무와 철광석 기부 진행도에 반영한다.

1. 통나무와 철광석에 각각 최대 100개를 먼저 배정한다.
2. 한쪽의 남은 필요량이 100개보다 적으면 그 재료에는 필요한 만큼만 배정한다.
3. 2단계에서 남은 지원량은 다른 재료의 남은 필요량에 추가 배정한다.
4. 어느 재료도 해당 시설의 남은 필요량을 초과할 수 없다.
5. 대상 시설은 합산 부족량이 200개 이상이어야 하므로 구매가 성공하면 항상 총 200개가 모두 반영된다.

예시:

- 통나무 300개, 철광석 400개 부족: 통나무 100개, 철광석 100개 지원
- 통나무 40개, 철광석 300개 부족: 통나무 40개, 철광석 160개 지원
- 통나무 0개, 철광석 250개 부족: 철광석 200개 지원
- 통나무 80개, 철광석 100개 부족: 합산 부족량이 180개이므로 선택 불가

## 구매 화면

길드 교역소에서 구매 버튼을 누르면 즉시 처리하지 않고 시설 선택 확인창을 연다.

각 시설 선택 항목에는 다음 정보를 표시한다.

- 시설 이름과 다음 목표 레벨
- 현재 통나무·철광석 기부량과 요구량
- 이번 구매로 추가될 통나무·철광석 수량
- 적용 후 기부량

선택 불가능한 시설은 목록에서 숨기지 않고 비활성 상태로 표시하며, 최대 레벨·대상 재료 없음·남은 필요량 부족 중 해당 사유를 안내한다. 최종 확인 버튼에는 소모될 교역 토큰 120개와 대상 시설을 다시 표시한다.

## 반영 위치와 안내

구매가 완료되면 지원량은 선택한 시설과 다음 목표 레벨에 대응하는 기존 `guild_facility_upgrade_donations` 진행도에 직접 합산한다.

- 개인 인벤토리에는 아무 아이템도 생성하지 않는다.
- 길드 공용 재화 화면이나 별도 보관함에는 표시하지 않는다.
- 길드 시설 화면의 기존 `Lv.N 재료 기부` 진행 막대가 즉시 갱신된다.
- 구매 완료 안내에 시설 이름과 실제 반영된 통나무·철광석 수량을 표시한다.
- 길드 활동 기록에는 구매자, 대상 시설, 목표 레벨, 지원량과 소모 토큰을 기록한다.
- 공동 구매 보상이므로 구매자 개인의 시설 재료 기부량이나 길드 기여 점수는 증가하지 않는다.

## 서버 처리와 동시성

구매는 하나의 데이터베이스 트랜잭션에서 처리한다.

1. 구매자의 길드 관리자 권한을 확인한다.
2. 길드 교역소 주간 상태와 교역 토큰을 잠근다.
3. 요청한 시설의 현재 배치 위치와 레벨을 다시 확인한다.
4. 해당 목표 레벨의 공동 기부 진행도를 잠근다.
5. 최신 진행도를 기준으로 대상 적격성과 200개 배분량을 다시 계산한다.
6. 기부 진행도 반영, 토큰 차감, 주간 구매 횟수 증가와 활동 기록을 함께 저장한다.

확인창을 연 뒤 다른 길드원이 재료를 기부해 대상이 부적격해졌거나 목표 레벨이 바뀌면 구매를 실패 처리한다. 이 경우 토큰과 주간 구매 횟수는 차감하지 않고 최신 상태를 다시 불러온다.

## 기존 데이터 호환

- 내부 상품 ID를 유지하므로 기존 주간 구매 횟수와 한도가 그대로 이어진다.
- 개편 전에 구매한 횟수는 같은 주의 3회 한도에 포함한다.
- 이미 구형 정착지 공용 풀에 지급된 통나무·철광석은 과거 지급 결과로 유지한다.
- 과거 구매에 대해 토큰을 환불하거나 새 시설 지원을 중복 지급하지 않는다.
- 개편 이후의 신규 구매부터 시설 공동 기부 진행도로 지급한다.

## 테스트 범위

### 순수 배분 규칙

- 두 재료가 각각 100개 이상 부족하면 100개씩 배분한다.
- 한 재료가 100개보다 적게 부족하면 잔여량을 다른 재료로 넘긴다.
- 한 재료만 필요하면 200개를 모두 해당 재료에 배분한다.
- 합산 부족량이 200개보다 적으면 부적격으로 판정한다.
- 고급 재료의 부족량은 배분 계산에 포함하지 않는다.

### API

- 적격 시설 구매 시 토큰과 구매 횟수, 공동 기부 진행도와 활동 기록이 한 번만 변경된다.
- 개인 인벤토리와 구형 정착지 공용 풀은 변경되지 않는다.
- 일반 길드원, 토큰 부족, 주간 한도 초과, 존재하지 않는 시설과 최대 레벨 시설을 거부한다.
- 확인 이후 동시 기부나 시설 레벨 변경이 발생하면 전체 구매를 롤백한다.
- 구매로 개인 기여 점수가 증가하지 않는다.

### UI

- 상품 카드에 즉시 적용형 공용 보상임을 표시한다.
- 시설별 현재값·지원량·적용 후 값을 확인할 수 있다.
- 부적격 시설의 사유와 선택 가능한 시설이 없는 상태를 표시한다.
- 구매 성공 후 교역소 잔액과 시설 기부 진행도가 최신 상태로 갱신된다.
