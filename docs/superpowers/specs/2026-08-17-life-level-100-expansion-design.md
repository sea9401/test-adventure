# 생활 레벨 100 확장 설계

## 1. 목표

농사·벌목·채광·낚시·요리의 최종 레벨을 50에서 100으로 확장한다. 기존
Lv.1~50 성장 속도와 보상은 유지하고, Lv.51~100은 장기 목표가 되는 후반 성장
구간으로 만든다.

이번 확장의 핵심 목표는 다음과 같다.

- 다섯 생활 모두 같은 원칙으로 Lv.100까지 성장한다.
- Lv.50까지 투자한 시간과 기존 달성 기록은 훼손하지 않는다.
- Lv.50 이후 쌓인 경험치는 일부 인정하되 신규 구간 전체를 건너뛰지 못한다.
- Lv.51~100은 기존 Lv.1~50보다 네 배 긴 장기 성장 구간이다.
- 직종별 성장 효과와 Lv.60·75·90·100 마일스톤으로 레벨을 올릴 이유를 만든다.
- 생산 경제가 급격히 팽창하지 않도록 신규 효율은 작고 명확한 상한을 가진다.

신규 작물·요리법·어종·벌목지·광맥·생활 화폐는 이번 범위에 포함하지 않는다.

## 2. 대상과 상한

대상 생활은 다음 다섯 가지다.

1. 농사
2. 벌목
3. 채광
4. 낚시
5. 요리

각 직종의 최종 레벨은 Lv.100이다. 다섯 직종을 합산하는 생활 숙련도 상한은
250에서 500으로 변경한다. 기존 생산직 전직 조건은 최대 Lv.35이므로 변경하지
않는다.

Lv.100 도달 뒤에도 재료, 기록, 도감, 직업 숙련도와 그 밖의 기존 활동 보상은
계속 얻는다. 생활 경험치만 Lv.100 기준치에서 멈춘다.

## 3. 경험치 곡선

### 3.1 Lv.1~50 보존

각 직종의 기존 Lv.1~50 누적 경험치 기준을 그대로 사용한다. 현재 직종별 경험치
단위와 활동당 지급량도 바꾸지 않는다. 따라서 배포 전후 같은 경험치의 Lv.1~50
이용자는 같은 레벨을 가진다.

### 3.2 Lv.51~100 공통 후반 곡선

직종별 기존 Lv.50 누적 경험치 기준을 `T50`이라 한다. 목표 레벨 `L`이 51~100일
때 다음 값을 사용한다.

```text
x = (L - 50) / 50
후반 진행 함수 F(x) = 0.5x + 0.5x³
T(L) = T50 + round(4 × T50 × F(x))
```

이 수식은 다음 성질을 보장한다.

- `T(50) = T50`
- `T(100) = 5 × T50`
- Lv.50→100에 필요한 경험치는 정확히 `4 × T50`, 즉 Lv.1→50의 네 배다.
- Lv.50 직후의 레벨당 요구량은 기존 40~50 구간과 자연스럽게 이어진다.
- 요구량은 단조 증가하며 Lv.80 이후 증가 폭이 더 커진다.
- Lv.90→100이 가장 긴 최종 성장 구간이다.

누적 기준치는 정수로 반올림한다. 모든 직종은 같은 후반 진행 함수를 사용하되
`T50`이 서로 달라 현재 경험치 단위의 상대적 차이는 유지한다.

## 4. 기존 초과 경험치 전환

### 4.1 전환 규칙

구 곡선에서 Lv.50 이후에도 저장된 경험치는 최초 한 번만 다음과 같이 전환한다.

```text
초과 경험치 = max(0, 구 경험치 - T50)
인정 경험치 = floor(초과 경험치 × 0.25)
인정 상한 = 새 곡선 T(60) - T50
새 경험치 = T50 + min(인정 경험치, 인정 상한)
```

- 구 경험치가 `T50` 미만이면 경험치를 그대로 유지한다.
- Lv.50 초과분의 25%만 인정한다.
- 아무리 많은 경험치를 보유해도 최초 시작점은 Lv.60을 넘지 않는다.
- Lv.60 이후는 확장 적용 뒤 새로 활동해 성장해야 한다.

### 4.2 버전과 멱등성

공통 상수 `LIFE_LEVEL_CURVE_VERSION = 2`를 두고 각 생활 저장값에
`levelCurveVersion`을 기록한다.

- 버전이 없거나 2보다 작으면 전환 대상이다.
- 버전이 2 이상이면 다시 전환하지 않는다.
- 신규 저장값은 처음부터 버전 2로 생성한다.
- 음수·NaN·무한대·비정수 경험치는 기존 정규화 원칙에 따라 0 이상의 안전한
  정수로 바꾼 뒤 처리한다.
- 알 수 없는 미래 버전은 구버전으로 되돌리지 않는다.

읽기 경로는 저장을 변경하지 않고도 전환 후 유효 경험치를 계산해 화면과 랭킹에
표시한다. 쓰기 경로는 기존 생활 저장값을 잠근 뒤 전환, 신규 경험치 가산,
버전 기록을 같은 트랜잭션에서 처리한다.

마이그레이션으로 오른 레벨은 낚시 레벨업 코인처럼 행동 1회에 붙는 레벨업 보상을
발생시키지 않는다. 쓰기 경로는 먼저 전환된 레벨을 기준 레벨로 잡고, 그 뒤 실제로
얻은 신규 경험치가 넘긴 레벨만 레벨업으로 판정한다. 레벨 조건 업적은 전환 후 현재
레벨을 기준으로 정상 수령할 수 있다.

최초 쓰기 전환 응답에는 일회성 `levelCurveMigrated` 신호를 포함한다. 클라이언트는
이를 받으면 다음 안내를 표시한다.

> 기존 초과 숙련 경험치의 일부가 신규 성장 구간에 반영되었습니다.

## 5. Lv.51~100 직종별 효과

기존 Lv.1~50 효과와 속도·실패율 상한은 변경하지 않는다. 신규 효과는 Lv.51부터
시작하며 Lv.100에서 아래 상한에 도달한다. 소수 레벨의 효과는 선형 보간하고 실제
확률 판정 직전에 사용 중인 정밀도로 반올림한다.

### 5.1 농사

- Lv.51~100: 추가 수확 확률을 레벨당 `+0.1%p`, 최대 `+5%p` 제공
- Lv.60: 희귀 수확 확률 `+0.25%p`
- Lv.75: 희귀 수확 확률 누적 `+0.5%p`
- Lv.90: 희귀 수확 확률 누적 `+0.75%p`
- Lv.100: 희귀 수확 확률 누적 `+1%p`, 최종 업적과 전용 칭호 해금

### 5.2 벌목

- Lv.51~100: 추가 원목 확률을 레벨당 `+0.1%p`, 최대 `+5%p` 제공
- Lv.60: 묘목 발견 확률 `+0.5%p`
- Lv.75: 추가 원목 확률이 자연 성장으로 `+2.5%p`에 도달
- Lv.90: 희귀 부산물 확률 `+1%p`
- Lv.100: 추가 원목 확률 `+5%p`, 최종 업적과 전용 칭호 해금

### 5.3 채광

- Lv.51~100: 추가 광석 확률을 레벨당 `+0.1%p`, 최대 `+5%p` 제공
- Lv.60: 부산물 발견 확률 `+0.5%p`
- Lv.75: 추가 광석 확률이 자연 성장으로 `+2.5%p`에 도달
- Lv.90: 희귀 부산물 확률 `+1%p`
- Lv.100: 추가 광석 확률 `+5%p`, 최종 업적과 전용 칭호 해금

### 5.4 낚시

- Lv.51~100: 물고기 크기 보너스 최대 `+3%`, 특별 어종 가중치 최대 `+5%`
- Lv.60: 물고기 크기 보너스가 `+1%`에 도달
- Lv.75: 특별 어종 가중치가 `+3%`에 도달
- Lv.90: 희귀 이상 어종 크기 `+1%`
- Lv.100: 대물권 크기 `+1%`, 연속 보너스는 각각 `+3%`·`+5%`에 도달,
  최종 업적과 전용 칭호 해금

크기 보너스는 Lv.50의 `0%`에서 Lv.60의 `+1%`, Lv.100의 `+3%`를 잇는 두
선형 구간으로 계산한다. 특별 어종 가중치는 Lv.50의 `0%`에서 Lv.75의 `+3%`,
Lv.100의 `+5%`를 잇는 두 선형 구간으로 계산한다. 기존 Lv.50 이하 낚시 보너스
계산은 그대로 둔 뒤 후반 보너스를 별도 가산한다.

### 5.5 요리

- Lv.51~100: 걸작 확률을 레벨당 `+0.1%p`, 최대 `+5%p` 제공
- Lv.60: 걸작 확률이 자연 성장으로 `+1%p`에 도달
- Lv.75: 희귀 재료를 제외한 묶음 조리 재료 소모 `-2%`
- Lv.90: 희귀 재료 보존 확률 `+2%p`
- Lv.100: 걸작 확률 `+5%p`, 최종 업적과 전용 칭호 해금

### 5.6 중첩과 경제 안전

후반 레벨 보너스는 별도 기여분으로 계산한 뒤 기존 생활 패시브·길드 버프·환경
효과와 같은 최종 판정에 합산한다. 기존 효과의 중첩 순서와 상한은 변경하지 않는다.
마지막 확률 판정은 기존처럼 0~100% 범위를 벗어나지 않게 제한한다.

이번 확장으로 추가되는 주 생산물 기대 공급량은 직종별 Lv.100에서도 기본 활동량
대비 약 5%를 넘지 않는다. 희귀 결과 보너스는 위에 명시한 1~2%p 범위를 넘지
않는다.

## 6. 마일스톤 업적과 칭호

각 직종에 Lv.60·75·90·100 업적을 추가한다.

| 레벨 | 업적 점수 | 공통 성격 |
|---|---:|---|
| 60 | 20 | 후반 숙련 입문 |
| 75 | 30 | 직종별 거장 단계 |
| 90 | 40 | 최종 구간 진입 |
| 100 | 60 | 최종 숙련 달성 및 전용 칭호 |

기존 Lv.50 전설 업적과 이미 받은 보상은 그대로 유지한다. Lv.100 칭호는 다음과
같다.

- 농사: `대지의 초월자`
- 벌목: `세계수의 손길`
- 채광: `심층의 지배자`
- 낚시: `만경창파의 강태공`
- 요리: `천상의 대연회`

칭호는 해당 Lv.100 업적 보상을 수령했을 때 기존 칭호 해금 경로로 지급한다.

## 7. 공통 성장 코어

Lv.51~100 곡선과 구 경험치 전환을 담당하는 작은 공통 모듈을 둔다. 이 모듈은
다음 입력만 받는다.

- 현재 저장 경험치
- 저장된 곡선 버전
- 직종의 기존 Lv.50 누적 경험치 `T50`
- 목표 레벨 또는 신규 획득 경험치

공통 모듈은 다음 결과를 제공한다.

- 안전하게 정규화된 경험치와 버전
- 전환 여부
- 현재 레벨
- 현재 레벨 진척과 다음 레벨 요구량
- Lv.100 도달 여부
- 신규 경험치 적용 뒤 저장할 경험치

농사·벌목·채광·낚시·요리 모듈은 기존 Lv.1~50 기준 함수를 유지하고, 공통 모듈에
자기 직종의 `T50`을 전달한다. 이를 통해 기존 데이터 구조를 대규모로 합치지 않고도
후반 곡선과 마이그레이션 규칙만 단일화한다.

## 8. 읽기·쓰기 데이터 흐름

### 8.1 읽기

1. 기존 생활 저장값을 파싱한다.
2. 공통 성장 코어로 유효 경험치와 레벨을 계산한다.
3. 저장 버전이 오래됐어도 변환된 미리보기 값을 반환한다.
4. 읽기 요청만으로 DB 저장값은 변경하지 않는다.

생활 요약, 개별 생활 화면, 랭킹, 퀘스트 문맥은 모두 같은 유효 레벨 계산을
사용한다. 서로 다른 화면에서 레벨이 다르게 보이지 않아야 한다.

### 8.2 쓰기

1. 기존 라우트의 잠금 순서대로 생활 저장값을 잠근다.
2. 구버전 저장이면 경험치를 한 번 전환한다.
3. 전환된 레벨을 이번 행동의 시작 레벨로 기록한다.
4. 활동 성공으로 얻은 경험치와 기존 보상을 적용한다.
5. 경험치를 `T(100)` 이하로 제한한다.
6. 버전 2와 결과를 같은 트랜잭션에서 저장한다.
7. 실제 신규 경험치로 오른 레벨과 전환 안내 여부를 응답한다.

자동 벌목·자동 채광 정산, 농장 일괄 수확, 낚시 릴 결과와 묶음 요리도 같은 쓰기
규칙을 사용한다. 정상 완료되지 않은 행동은 경험치와 마이그레이션 버전을 임의로
저장하지 않는다.

## 9. 화면과 연동

기존 생활 화면 구조는 유지한다.

- 각 생활 화면: `현재 레벨 / 100`, 현재 경험치 진행도 표시
- Lv.50 이상: 다음 Lv.60·75·90·100 마일스톤과 효과 표시
- Lv.100: 경험치 막대 대신 `최종 숙련 달성 · MAX` 표시
- 생활 요약: 다섯 직종 합산 `생활 숙련도 / 500` 표시
- 랭킹 도움말: 각 생활은 Lv.100까지 반영된다고 안내
- 관리자 심의용 OP 세팅: 다섯 생활을 Lv.100 기준 경험치로 설정하고 관련 문구 수정

개별 직종 화면에 새 탭이나 별도 화폐 UI는 만들지 않는다. 기존 진행 카드와 다음
목표 영역을 확장해 사용한다.

## 10. 오류 처리와 호환성

- 기존 저장값에 `levelCurveVersion`이 없어도 정상 파싱한다.
- 손상된 경험치와 버전은 안전한 정수로 정규화한다.
- 읽기 미리보기와 최초 쓰기 전환 결과는 같은 값이어야 한다.
- 최초 쓰기가 재시도돼도 버전 확인으로 초과 경험치를 두 번 환산하지 않는다.
- Lv.100에서 경험치가 추가돼도 저장값은 `T(100)`을 넘지 않는다.
- Lv.50 이하의 보상, 생산량, 해금, 레벨업 알림은 기존과 같아야 한다.
- 기존 Lv.50 업적 ID와 수령 기록은 변경하지 않는다.

별도의 전체 DB 일괄 마이그레이션은 하지 않는다. 읽기 미리보기와 쓰기 시 지연
전환으로 운영 부하와 롤백 위험을 줄인다.

## 11. 테스트 전략

### 11.1 공통 곡선

- 각 직종의 Lv.1·10·25·50 기준치가 기존과 동일하다.
- Lv.50→100 총 요구량이 Lv.1→50의 정확히 네 배다.
- Lv.51~100 기준치와 레벨당 요구량이 단조 증가한다.
- Lv.80 이후 증가 폭이 앞 구간보다 커진다.
- Lv.100 초과 레벨과 경험치는 상한 처리된다.

### 11.2 전환

- 초과 경험치가 없으면 경험치를 그대로 유지한다.
- 초과분의 25%만 인정한다.
- 매우 큰 구 경험치는 Lv.60 기준치에서 제한된다.
- 버전 2 저장값은 재전환하지 않는다.
- 읽기 미리보기와 쓰기 결과가 일치한다.
- 마이그레이션 레벨은 행동형 레벨업 보상을 발생시키지 않는다.

### 11.3 직종별 경로

- 농사 수동·일괄 수확
- 벌목 수동·자동 정산
- 채광 수동·자동 정산
- 낚시 릴·레벨업 코인
- 요리 단건·묶음 조리
- 각 직종의 Lv.51~100 효과와 마일스톤 효과
- Lv.100에서 경험치는 멈추지만 기존 재료와 기록 보상은 계속 지급

### 11.4 통합 표면

- 생활 숙련도 합계 상한 500
- 랭킹 계산과 안내 문구
- 생활 요약과 개별 진행 카드
- Lv.60·75·90·100 업적 및 Lv.100 칭호
- 관리자 심의용 OP 세팅
- 기존 Lv.50 이하 골든·회귀 테스트
