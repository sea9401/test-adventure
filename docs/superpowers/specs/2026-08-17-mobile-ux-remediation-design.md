# 모바일 사용성 개선 설계

## 목표

320px부터 430px까지의 세로형 모바일 화면에서 게임의 주요 화면이 가로로 축소되거나 잘리지 않게 하고, 반복 조작을 오탭 없이 수행하며, 긴 정보 화면을 과도한 스크롤 없이 탐색할 수 있게 한다. 데스크톱 레이아웃과 게임 규칙, API, 저장 데이터는 변경하지 않는다.

## 범위와 순서

1. 상점·거래소·스킬 장착 화면의 가로 넘침 제거
2. 공통 버튼·탭·아이콘 조작부의 모바일 터치 영역 확대
3. 숙소 배치 화면의 모바일 정밀 조작 개선
4. 직업 도감의 긴 목록 탐색 개선
5. 전투 로그와 반복 보조 정보의 모바일 글자 가독성 개선

## 반응형 폭

- 320px와 390px에서 문서 폭이 시각 뷰포트 폭을 넘지 않아야 한다.
- `html { overflow-x: clip }`은 최후의 안전장치로만 유지하며 자식의 실제 넘침을 숨기는 해결책으로 사용하지 않는다.
- 상점은 `sm` 미만에서 표 머리글을 숨기고 각 상품을 이름·종류·가격·위력·구매 동작이 들어간 카드형 행으로 표시한다. `sm` 이상에서는 기존 표를 유지한다.
- 거래소 매물 카드는 좁은 화면에서 가격 정보와 구매·입찰 동작을 세로로 쌓고, 긴 가격·상태 문자열은 줄바꿈한다.
- 스킬 장착 화면은 검색과 보기 설정, 스킬 설명과 장착 동작을 좁은 화면에서 줄바꿈하거나 세로로 쌓는다. 고정 폭과 모바일 최소 너비를 제거하되 데스크톱의 빠른 조작 구조는 유지한다.

## 터치 영역

- 모바일의 일반 버튼·탭은 최소 높이 40px을 사용한다.
- 뒤로 가기, 알림, 검색 지우기, 즐겨찾기, 순서 이동처럼 독립된 아이콘 조작은 최소 44×44px을 사용한다.
- 공통 `Button`과 `TabBar`에서 기본값을 보장하고, 조밀한 데이터 표처럼 예외가 필요한 곳은 개별적으로 데스크톱 크기를 복원한다.
- 터치 영역 확장은 시각 아이콘 크기를 키우기보다 패딩과 최소 크기로 제공한다.

## 숙소 편집

- 방문·열람 상태의 기존 방 카드는 유지한다.
- 모바일에서 편집을 시작하면 방 캔버스를 화면 폭에 맞는 전용 편집 표면으로 제공하고, 확대 상태를 전환할 수 있게 한다.
- 확대 상태에서는 캔버스를 2배 너비로 표시하고 양방향 스크롤과 관성 스크롤을 허용한다. 8×6 바닥 칸은 확대된 캔버스에서 최소 약 40px에 가까운 조작 폭을 확보한다.
- 확대·축소 버튼은 현재 상태와 동작을 접근성 라벨로 알린다. 선택한 가구와 선택한 바닥 칸의 기존 시각 상태 및 배치 규칙은 유지한다.

## 직업 도감

- 목표·현재 직업은 기본으로 펼치고, 해금된 직업과 조건 부족 직업은 직군 또는 상태 섹션별로 접고 펼칠 수 있게 한다.
- 검색어 또는 태그 필터가 활성화되면 결과가 있는 섹션을 자동으로 펼쳐 결과를 숨기지 않는다.
- 각 섹션 머리글은 버튼이며 항목 수와 펼침 상태를 접근성 속성으로 제공한다.
- 직업 데이터와 해금·목표 지정 동작은 변경하지 않는다.

## 글자 가독성

- 전투 로그의 행동 보조 정보, 라벨, HP 표기는 모바일에서 최소 12px로 올린다. `sm` 이상은 기존 밀도를 유지할 수 있다.
- 상점·거래소·스킬·직업 화면에서 판단에 필요한 10~11px 정보는 12px로 올린다.
- 장식 배지처럼 의미가 반복되며 주변 문맥으로 보완되는 항목까지 전역 일괄 확대하지 않고, 이번에 손대는 핵심 동선부터 선별적으로 정리한다.

## 테스트

- 정적 렌더링 테스트로 상점의 모바일 카드/데스크톱 표, 거래소와 스킬의 적층 클래스, 공통 터치 최소 크기, 숙소 확대 제어, 직업 도감 접기, 전투 로그 글자 크기를 검증한다.
- Playwright 모바일 회귀 테스트로 320×568과 390×844에서 대표 프리뷰 화면의 `scrollWidth <= visualViewport.width`를 검증한다.
- 상점·거래소·스킬·숙소·직업 도감에서 40px 미만의 주요 조작부가 남지 않았는지 확인한다. 숙소 격자 셀은 확대 편집 상태에서 별도로 확인한다.
- 기존 단위 테스트, 타입 검사, 린트, 프로덕션 빌드를 실행한다.

## 완료 기준

- 상점·거래소·스킬 장착 화면이 320px와 390px에서 가로로 넘치지 않는다.
- 반복 조작 버튼과 아이콘 조작부가 모바일 터치 기준을 충족한다.
- 숙소에서 확대 상태로 바닥 칸과 가구를 안정적으로 선택할 수 있다.
- 직업 도감의 긴 섹션을 접어서 원하는 범주로 이동할 수 있다.
- 전투 로그의 핵심 보조 정보가 확대 없이 읽을 수 있는 크기로 표시된다.
- 데스크톱 화면과 게임 로직, API, 저장 데이터에는 동작 변화가 없다.
