# 희귀 탐사 만료 시간 표시 설계

## 목표

희귀 탐사가 발견 후 30분에 만료된다는 사실과 실제 남은 시간을 발견 알림, 열린 레어맵 목록, 희귀 탐사 진행 화면에서 즉시 확인할 수 있게 한다. 만료된 지도는 열린 목록에서 자동으로 사라지며, 진행 중 만료되면 일반 사냥으로 안전하게 돌아간다.

## 범위

- 희귀 탐사 발견 알림에 `30분 동안 개방` 안내와 남은 시간 표시
- 열린 레어맵 카드에 남은 판수와 `남은 시간 MM:SS` 동시 표시
- 희귀 탐사 진행 배너에 남은 판수와 `남은 시간 MM:SS` 동시 표시
- 서버와 클라이언트 시계가 달라도 서버 기준 남은 시간이 보이도록 보정
- 만료 시 열린 목록에서 해당 지도를 제거하고, 진행 화면에서는 안내 후 일반 사냥으로 복귀
- 희귀 장소와 비밀 상점의 기존 표시 및 만료 규칙은 유지

## 설계

`GET /api/v2/me/rare-maps`는 `rareMaps`와 함께 응답 생성 시점의 `serverNow`를 반환한다. 각 지도에는 이미 `foundAt`이 있으므로 별도 저장 필드를 추가하지 않고 `foundAt + RARE_MAP_TTL_MS`로 만료 시각을 계산한다.

클라이언트에는 희귀 지도용 순수 시간 유틸리티를 둔다. 이 유틸리티는 서버 기준 만료 시각을 클라이언트 시계에 맞춰 보정하고, 남은 밀리초를 `MM:SS`로 표시한다. 표시 중 유효 시간이 남아 있는데 `00:00`이 먼저 보이지 않도록 초 단위는 올림한다.

열린 레어맵 목록과 희귀 탐사 진행 화면은 API 응답의 `serverNow`로 보정한 만료 시각을 저장하고 1초마다 화면을 갱신한다. 목록에서는 만료된 항목만 제거한다. 진행 화면에서는 만료를 한 번만 처리해 시스템 안내를 표시하고 기존 일반 사냥 복귀 콜백을 호출한다.

발견 알림은 막 생성된 `RareMapInstance`를 받으므로 전체 TTL을 기준으로 즉시 카운트다운을 시작한다. 단건 및 일괄 사냥 알림 모두 같은 표시 컴포넌트를 사용해 문구 차이를 막는다.

## 오류 처리

- 희귀 지도 API 조회가 실패하면 기존 화면은 유지하되 계산 근거가 없는 카운트다운은 표시하지 않는다.
- 응답의 `serverNow`나 지도 시각이 유효하지 않으면 해당 항목의 카운트다운을 숨긴다.
- 만료 복귀는 중복 실행되지 않게 보호한다.
- 서버의 실제 소유권·만료 검증은 계속 최종 권위로 둔다.

## 테스트

- 남은 시간 포맷과 서버 시각 보정의 경계값을 순수 함수 테스트로 검증한다.
- 희귀 지도 API가 같은 시점으로 만료 필터링하고 `serverNow`를 반환하는지 검증한다.
- 열린 레어맵 카드가 남은 판수와 시간을 함께 표시하는지 검증한다.
- 발견 알림과 진행 배너가 30분 제한 및 남은 시간을 표시하는지 렌더링 테스트로 검증한다.
- 만료된 목록 항목 제거와 진행 화면 복귀 동작을 fake timer 기반으로 검증한다.

## 비범위

- 30분 만료 시간 자체의 변경
- 만료된 희귀 탐사의 복구나 보상
- 희귀 장소 및 비밀 상점 UI 재설계
