# 폭풍 원정 모바일 구간 지도 설계

## 목표

모바일 폭풍 원정 지도에서 1120px 전체 그래프를 가로로 스크롤해야 하는 불편을 없앤다. 데스크톱의 전체 지도와 원정 규칙은 유지하고, 모바일에서만 현재 진행 구간을 화면 폭 안에 크게 표시한다.

## 범위

### 포함

- 모바일 전용 3구간 지도
- 현재 노드에 따른 자동 구간 전환
- 화면 폭 안에서 유지되는 노드 크기와 터치 영역
- 구간 번호와 구간 이름 표시
- 기존 노드 미리보기 후 확정하는 2단계 선택 방식
- 모바일·데스크톱 지도 회귀 테스트

### 제외

- 원정 그래프, 전투, 보상, 저장 상태 또는 API 변경
- 데스크톱 전체 지도 레이아웃 변경
- 사용자가 임의로 미래 구간을 탐색하는 기능
- 확대·축소와 드래그 제스처

## 모바일 구간

각 구간은 앞 구간의 합류 노드를 다음 구간의 시작 기준으로 함께 사용한다.

1. `항로 입구`: 세 외곽 노드 → 표류 보급품
2. `중층 항로`: 표류 보급품 → 세 항로의 중층·야영지·정예 → 폭풍 제단
3. `폭풍 심장`: 폭풍 제단 → 세 수호자 → 최종 정비 → 폭풍의 심장

현재 노드가 외곽이면 1구간, 보급·중층·야영지·정예면 2구간, 제단·수호자·최종 정비·폭풍의 심장이면 3구간을 표시한다. 원정 시작 전에는 1구간을 표시한다. 선택한 미리보기만으로 구간이 바뀌지 않으며 서버 이동 성공으로 현재 노드가 바뀔 때만 다음 구간으로 전환한다.

## 화면 설계

- `sm` 미만에서는 모바일 구간 지도를, `sm` 이상에서는 기존 1120px 전체 지도를 표시한다.
- 모바일 지도 상단에 `1/3 항로 입구`처럼 현재 구간을 표시한다.
- 모바일 캔버스는 부모 폭을 사용하며 가로 스크롤과 최소 너비를 두지 않는다.
- 각 구간은 독립적인 SVG `viewBox` 좌표를 사용한다. 노드 버튼은 기존과 같은 76px 크기와 글자 크기를 유지한다.
- 진행 방향은 위에서 아래로 두고 세 항로는 왼쪽·가운데·오른쪽 열로 구분한다. 공용 노드는 상단 또는 하단 중앙에 둔다. 2구간은 보급 아래에 세 항로의 중층·야영지·정예를 세로로 배치하고 마지막에 제단으로 합친다.
- 완료·현재·이동 가능·선택·잠김 상태, 접근성 문구와 항로별 색은 기존 지도와 동일하게 유지한다.
- 노드를 누르면 기존 상세 미리보기만 바뀐다. 실제 시작 또는 이동은 지도 아래 확정 버튼으로 수행한다.

## 구성 요소

- 기존 `StormExpeditionRouteMap`이 반응형 컨테이너를 제공한다.
- 순수 헬퍼가 현재 노드에서 모바일 구간 ID를 계산한다.
- 모바일 구간 정의는 포함 노드와 모바일 좌표만 가진다. 원정 연결 관계와 노드 내용은 기존 `STORM_EXPEDITION_MAP_NODES`를 권위 데이터로 사용한다.
- 노드 버튼 렌더링은 모바일과 데스크톱이 같은 상태 판정과 접근성 라벨 생성 규칙을 공유한다.

## 상태 및 오류 처리

새 저장 상태는 추가하지 않는다. 서버 응답의 `currentNodeId`, `availableNodeIds`, `previewableNodeIds`, `selectedNodeId`만 사용한다. 이동 오류가 발생하면 기존처럼 최신 서버 상태를 반영하며, 표시 구간도 최신 현재 노드에서 다시 계산한다.

## 테스트

- 원정 시작 전과 외곽 노드는 1구간으로 계산한다.
- 보급·중층·야영지·정예는 2구간으로 계산한다.
- 제단·수호자·최종 정비·최종 보스는 3구간으로 계산한다.
- 모바일 지도에는 가로 스크롤과 1120px 최소 너비가 없고 구간 표시가 있다.
- 데스크톱 지도에는 기존 전체 그래프와 가로 오버플로 안전장치가 유지된다.
- 모바일에서도 활성·잠김·선택 상태와 접근성 라벨이 유지된다.
- 기존 지도 및 원정 API 테스트가 모두 통과한다.

## 완료 기준

- 모바일에서 가로 스크롤 없이 현재 구간의 모든 노드를 확인하고 선택할 수 있다.
- 이동 성공 후 현재 위치가 속한 다음 구간으로 자동 전환된다.
- 노드 터치 영역과 글자 가독성이 기존보다 작아지지 않는다.
- 기존 2단계 선택, 데스크톱 전체 지도, 원정 진행과 보상 동작이 바뀌지 않는다.
