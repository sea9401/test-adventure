# 치료소 보유 골드 기준 `가득` 충전 설계

## 배경

치료소의 HP·MP 충전약은 1G당 1만큼 충전되며 종류별 최대 보유량은 10,000,000이다. 현재 `가득` 버튼은 충전약의 남은 보관 용량 전체를 구매 금액으로 표시하고, 그 금액보다 결제 가능 골드가 적으면 버튼을 비활성화한다. 신규 이용자는 가진 골드를 직접 입력해야 한다.

## 목표

`가득` 버튼 한 번으로 남은 보관 용량과 실제 결제 가능 골드 중 더 작은 수량을 충전한다. 직접 입력 구매와 서버의 기존 한도·잔액 검증은 유지한다.

## 결정

- `가득` 충전량은 `min(MAX_CHARGE - current, spendableGold)`로 계산한다.
- `spendableGold`는 현재 치료소 결제 규칙과 동일하게 코어루프가 꺼져 있으면 지갑 골드, 켜져 있으면 지갑과 은행 골드의 합이다.
- 버튼 문구의 가격과 클릭 시 서버로 보내는 수량은 같은 계산값을 사용한다.
- 충전약이 이미 최대치이거나 실제 결제 가능 골드가 0이면 버튼을 비활성화한다.
- 직접 입력 수량, 입력 구매 버튼, 서버 API 계약은 변경하지 않는다.

## 구현 경계

순수 계산 함수를 `src/lib/v2-charge-config.ts`에 두고 치료소의 HP·MP 행에서 공통으로 사용한다. 이 함수는 음수·소수·비정상 숫자를 0 이상의 정수로 정규화해 UI 계산이 손상된 상태값에도 안전하도록 한다. 서버는 이미 트랜잭션 안에서 저장 한도와 실제 골드 잔액을 재검증하므로 변경하지 않는다.

## 검증

- 남은 용량보다 골드가 적으면 골드만큼 반환한다.
- 골드가 충분하면 남은 용량 전체를 반환한다.
- 최대치 또는 골드 0이면 0을 반환한다.
- 소수·음수·비정상 입력은 안전하게 정규화한다.
- 집중 단위 테스트, TypeScript 검사, 대상 ESLint를 실행한다.
