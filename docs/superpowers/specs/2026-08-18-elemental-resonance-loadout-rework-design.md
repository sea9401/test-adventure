# 원소군주·태초술사 공명 로드아웃 개편 설계

## 배경

`오원소 폭주`와 `태초회귀`의 강한 주문식은 하위 원소 공격기를 함께 장착해야 한다. 현재 최대 주문식은 본체 16 SP와 하위 원소기 34 SP를 합쳐 액티브 구성만 50 SP를 사용한다. 공명 패시브까지 포함하면 원소군주는 52 SP, 태초술사는 59 SP가 필요하다. 천궁의 주력기와 핵심 패시브는 24 SP, 흑월은 핵심 두 스킬 29 SP와 세 스킬 36 SP이므로 조합형 계보가 효과에 비해 지나치게 큰 장착 비용을 부담한다.

6차 패시브도 같은 문제가 있다. 현재 성능 점수는 근원공명 3.82, 성도 조준 5.83, 흑월지배 7.27이다. 원초 증폭은 일반 SP 산식상 9 SP지만 명시 하한으로 12 SP를 사용하며, 장비 치명타 피해·마법 직접 피해·치명타 발생 조건을 모두 충족해야 작동한다.

## 목표

- 원소 조합을 장착으로 선택하는 현재 정체성을 유지한다.
- 주문식 재료와 독립 공격기의 SP를 이중으로 지불하는 문제를 없앤다.
- 원소군주 최대 공명 구성을 28 SP, 태초술사를 35 SP로 낮춘다.
- 오원소 폭주를 태초회귀의 선택형 상위 촉매로 계승한다.
- 근원공명을 다른 6차 핵심 패시브와 비슷한 급으로 높인다.
- 원초 증폭의 조건부 가치를 반영해 장착 비용을 9 SP로 낮춘다.
- 기존 스킬 ID와 저장된 장착 목록을 유지한다.

## 용어

- **공명 회로**: 주력 조합기와 대응 공명 패시브를 함께 장착한 상태.
- **공명 재료**: 현재 선택된 주문식의 `requiredEquippedSkillIds`에 포함된 하위 원소기.
- **근원 촉매**: 태초회귀 공명 회로에서 추가로 장착한 오원소 폭주.
- **흡수**: 재료의 SP를 2로 낮추는 대신 독립 발동 후보에서 제외하는 처리.

하위 원소기는 다음 다섯 스킬만 뜻한다.

- 홍련술 (`v2c_firemage_inferno`)
- 빙하진 (`v2c_frostmage_glacier`)
- 천뢰격 (`v2c_lightningmage_thunderbolt`)
- 질풍술 (`v2c_windmage_tempest`)
- 지각진 (`v2c_earthmage_tectonic`)

## 공명 회로 활성 조건

원소군주 회로는 `오원소 폭주 + 원소 공명`을 함께 장착하면 활성화한다. 태초술사 회로는 `태초회귀 + 근원공명`을 함께 장착하면 활성화한다.

두 회로의 주력기와 패시브를 모두 장착한 경우에는 태초술사 회로만 활성화한다. 이때 오원소 폭주는 근원 촉매로 흡수되며 원소군주 회로를 별도로 만들지 않는다. 같은 하위 원소기 묶음으로 할인된 두 주력기를 동시에 운용하는 이중 이득을 막기 위한 우선순위다.

태초술사 회로가 완성되지 않고 원소군주 회로만 완성되면 원소군주 회로를 정상 적용한다. 어느 회로도 완성되지 않으면 모든 스킬은 현재 기본 SP와 독립 발동을 유지한다.

## 주문식 선택과 재료 흡수

현재 `castVariants` 순서와 요구 조건을 유지한다. 공명 비용 계산과 실제 시전은 반드시 같은 공용 주문식 선택 함수를 사용한다. 현재 장착 목록에서 가장 먼저 성립하는 변형을 선택하고, 그 변형의 `requiredEquippedSkillIds`에 포함된 하위 원소기만 공명 재료로 흡수한다.

- 공명 재료의 유효 비용은 각각 2 SP다.
- 공명 재료는 장착 상태와 주문식 조건에는 남아 있지만 독립 행동 후보에서는 제외한다.
- 장착되어 있어도 선택된 주문식에 쓰이지 않은 원소기는 기본 SP를 지불하고 독립적으로 발동한다.
- `requiredLearnedSkillIds`만 사용하는 기본형·오원소 대폭주·태초 오원소 회귀는 하위 원소기를 흡수하지 않는다.
- 공명 패시브나 대응 주력기를 해제하면 할인과 흡수가 즉시 사라지고 기본 비용과 독립 발동이 복원된다.

기본 스킬 가격을 반환하는 `spCostOf`는 전역 의미를 바꾸지 않는다. 공명 회로를 반영한 유효 비용은 장착 목록 전체를 받는 별도의 공용 계산 결과로 제공한다.

## 오원소 폭주 근원 촉매

태초술사 회로에서 오원소 폭주를 함께 장착하면 오원소 폭주를 근원 촉매로 흡수한다.

- 유효 비용: 2 SP
- 독립 발동: 하지 않음
- 태초회귀 추가 효과: 직접 마법 피해 `statCoef +0.28`, `baseFlat +110`
- 적용 범위: 기본 태초회귀와 모든 태초회귀 주문식
- 상태이상·보호막·행동 지연 수치는 추가로 높이지 않음

촉매는 하위 원소기 묶음을 대신하지 않는다. 하위 원소기는 주문식의 형태를 결정하고, 오원소 폭주는 선택된 주문식의 직접 피해를 한 단계 높인다.

## 목표 SP 구성

| 구성 | 유효 SP |
|---|---:|
| 오원소 폭주 + 원소 공명 + 하위 원소기 5개 | 16 + 2 + 10 = 28 |
| 태초회귀 + 근원공명 + 하위 원소기 5개 | 16 + 9 + 10 = 35 |
| 위 태초술사 구성 + 오원소 폭주 촉매 | 35 + 2 = 37 |
| 위 촉매 구성 + 원초 증폭 | 37 + 9 = 46 |

선택된 주문식에 원소기 한 개 또는 두 개만 필요하면 실제로 쓰인 원소기만 각각 2 SP로 계산한다. 쓰이지 않은 원소기는 표에 포함하지 않는다.

## 패시브 조정

### 원소 공명

기존 수치와 2 SP를 유지한다. 주문식 추가 피해·마나 환류에 더해 공명 재료 할인과 흡수를 활성화하므로 역할이 충분히 명확해진다.

### 근원공명

다음 수치로 상향한다.

| 효과 | 현재 | 변경 |
|---|---:|---:|
| 지능 | +20% | +24% |
| 정신 | +8% | +12% |
| 마법 스킬 피해 | +10% | +16% |
| 최대 MP | +14% | +20% |
| SP | 9 | 9 |

기존 태초회귀 추가 피해와 최대 MP 8% 회복 시너지를 유지한다. 강화된 순수 패시브 성능 점수는 약 5.47로 성도 조준 5.83에 근접한다. 일반 루브릭 비용이 9 SP보다 높아지면 명시 할인으로 최종 9 SP를 유지한다. 어려운 계보 해금 조건과 공명 회로 전용성을 반영한 보상이다.

### 원초 증폭

장비 치명타 피해를 마법 스킬 치명타 피해로 전환하는 공식과 최대 `+0.75배`는 유지한다. 명시된 12 SP 하한을 제거해 일반 산식 결과인 9 SP를 사용한다.

장비 치명타 피해가 없거나, 직접 마법 피해가 아니거나, 공격이 치명타로 적중하지 않으면 효과가 없다는 기존 제한도 유지한다. 효과 범위를 넓히지 않고 조건부 기회비용만 바로잡는다.

## 공용 계산과 데이터 흐름

공명 판정은 서버와 UI가 함께 쓰는 순수 계산 경계로 둔다. 입력은 장착 스킬 ID 목록과 스킬 정의이며, 출력은 다음 정보를 포함한다.

- 활성 회로: 없음, 원소군주, 태초술사
- 선택된 주문식
- 흡수된 공명 재료 ID 집합
- 근원 촉매 활성 여부
- 스킬별 기본 SP와 유효 SP
- 전체 유효 SP 합계

서버의 로드아웃 저장 검증은 이 결과를 권위값으로 사용한다. 클라이언트가 보낸 SP 합계나 할인 표시는 신뢰하지 않는다. 스킬 UI와 프리셋 요약도 같은 계산을 사용해 표시와 저장 판정이 어긋나지 않게 한다.

전투에서는 원래 장착 목록을 주문식 판정에 전달하되, 독립 행동 후보를 만들 때 흡수된 ID를 제외한다. PvE와 PvP가 같은 흡수 결과를 사용해야 한다. 촉매 피해도 공용 스킬 시전 계산에서 한 번만 더해 PvE와 PvP의 계수와 RNG 소비 순서를 맞춘다.

## UI 표시

- 흡수된 하위 원소기 카드: `공명 재료 · 2 SP`
- 흡수된 오원소 폭주 카드: `근원 촉매 · 2 SP · 태초회귀 강화`
- 원래 비용과 유효 비용을 함께 표시해 할인 이유를 알 수 있게 한다.
- 장착 목록 합계는 유효 SP를 사용한다.
- 선택되지 않은 원소기는 기본 비용과 일반 상태로 표시한다.
- 두 회로를 모두 구성한 경우 원소 공명에는 `근원공명 우선 · 원소군주 회로 비활성` 안내를 표시한다.
- 스킬 설명과 효과 칩에는 근원공명 수치, 원초 증폭 9 SP, 촉매 추가 피해를 반영한다.

새로운 설정 화면이나 주문식 선택 UI는 만들지 않는다. 기존 장착 목록이 곧 주문식 선택 수단으로 남는다.

## 기존 저장과 오류 처리

- 스킬 ID와 장착 목록 저장 형식은 바꾸지 않는다.
- 기존 조합은 다음 조회부터 낮아진 유효 SP를 자동 적용받는다.
- 할인이 사라져 SP 한도를 넘으면 기존 서버의 초과 장착 검증·조정 정책을 그대로 사용한다.
- 공명 계산이 알 수 없는 스킬 ID를 받으면 해당 ID에는 할인이나 흡수를 적용하지 않는다.
- 변형 데이터에 하위 원소기가 아닌 요구 ID가 추가되더라도 자동 할인하지 않는다.
- 계산 오류 시 할인된 값을 추정하지 않고 기본 SP 합계로 안전하게 실패한다.

## 검증

### 순수 계산

- 회로 없음, 원소군주 회로, 태초술사 회로를 구분한다.
- 단일·2원소·5원소 주문식에서 실제 요구 재료만 2 SP가 된다.
- 장착했지만 선택된 주문식에 쓰이지 않은 원소기는 기본 비용을 유지한다.
- 두 회로가 모두 완성되면 태초술사만 우선하고 오원소 폭주를 촉매로 흡수한다.
- 최대 구성의 유효 SP가 28, 35, 37, 46인지 각각 검증한다.
- 회로가 깨지면 기본 SP와 독립 발동 상태가 복원된다.

### 전투

- 흡수된 원소기는 주문식 조건을 충족하지만 독립 공격으로 발동하지 않는다.
- 흡수되지 않은 원소기는 기존처럼 발동한다.
- 오원소 폭주 촉매가 모든 태초회귀 변형에 `+0.28/+110` 직접 마법 피해를 정확히 한 번 추가한다.
- 촉매가 없을 때 기존 주문식 피해와 RNG 소비 순서를 유지한다.
- PvE와 PvP가 같은 회로, 변형, 흡수 목록과 촉매 피해를 사용한다.

### 패시브와 UI

- 근원공명의 네 수치와 최종 9 SP를 검증한다.
- 원초 증폭의 공식과 상한은 유지되고 최종 비용만 9 SP인지 검증한다.
- 카드의 기본·유효 SP, 공명 재료, 근원 촉매, 우선순위 안내가 공용 계산과 일치한다.
- 클라이언트 표시와 서버 로드아웃 검증의 전체 SP가 일치한다.

### 밸런스

동일한 총 SP와 대표 장비 구간에서 태초술사, 천궁, 흑월을 결정적 전투 시뮬레이션으로 비교한다. 태초술사는 다양한 상태 효과와 보호막을 함께 제공하므로 순수 지속 피해가 비교 두 직업의 중앙값 기준 `±10%` 범위면 유지한다. 범위를 벗어나면 다른 패시브나 상태 효과를 다시 건드리지 않고 오원소 폭주 촉매의 `+0.28/+110`만 조정한다.

## 범위 제외

- 원소 공명의 기존 전투 수치 상향
- 태초회귀 기존 주문식의 상태이상·보호막·지연 수치 변경
- 원초 증폭의 전환 공식·대상·상한 변경
- 별도 주문식 선택 UI
- 스킬 ID 변경 또는 저장 데이터 마이그레이션
- 다른 직업 스킬과 SP 공식의 전역 재조정
- 배포
