# 낚시 중 좌상단 활동 상태 설계

## 배경

게임 좌상단 활동 상태는 자동 벌목·채광만 전역으로 추적한다. 수동 낚시 미니게임을 진행하는 동안에는 이 값이 비어 있어 `휴식 중`으로 표시된다.

## 목표

낚시 미니게임을 실제로 진행하는 동안 좌상단에 `낚시 중`을 표시한다. 낚시 화면에 머무는 것만으로는 활성 상태로 보지 않는다.

## 결정

- 낚시의 `casting`, `waiting`, `biting`, `resolving` 단계를 낚시 중으로 본다.
- `idle`과 `result` 단계에서는 낚시 중 표시를 해제한다.
- 낚시 화면이 진행 중에 언마운트되면 상태를 해제해 좌상단에 남지 않게 한다.
- 자동 벌목·채광 상태와 낚시 상태가 동시에 전달되면 서버 권위 장기 작업인 자동 벌목·채광을 우선한다.
- 낚시 중 상태는 `/town/fishing`으로 이동하는 링크로 표시한다.
- 낚시 서버 세션 조회나 폴링은 추가하지 않는다. 현재 화면에서 실제로 진행 중인 미니게임 상태만 반영한다.

## 구현 경계

`FishingView`가 소유한 단계에서 낚시 활성 여부를 계산해 `FishingPanel`을 통해 `GameStateProvider`의 전역 불리언 상태를 갱신한다. `GameChrome`은 이 상태를 `V2TopBar`에 전달하고, 상단바는 자동 생활 작업·낚시·휴식 순서로 표시를 선택한다.

## 검증

- 진행 단계 네 종류는 낚시 중으로, 유휴·결과 단계는 비활성으로 판정한다.
- 낚시 중이면 좌상단에 `낚시 중`과 낚시터 링크가 렌더링된다.
- 자동 벌목·채광 상태가 있으면 기존 표시와 링크가 유지된다.
- 집중 테스트, TypeScript 검사, 대상 ESLint, 전체 테스트를 실행한다.
- 배포하지 않는다.
