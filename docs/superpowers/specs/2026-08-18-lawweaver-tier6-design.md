# 법칙술사 6차 직업 설계

## 배경

문장술사는 저차 패시브를 문장 재료로 다시 장착해 `대문장 해방`에 추가 효과를 붙이는 4차 마법 직업이다. 각인술사는 이 구조를 `각인 해방`과 `각인 증폭`으로 확장해 더 많은 문장 재료와 복수 장착 시너지를 사용하는 5차 직업이다.

현재 계보의 실제 전투 정체성은 전투 중 각인을 쌓는 방식이 아니라, 장착한 과거 스킬 조합에 따라 하나의 액티브 효과가 달라지는 로드아웃 퍼즐이다. 6차는 이 로드아웃 조합을 유지하면서 문장 재료를 전투 중 임시 자원으로 축적하고, 전투 패턴으로 선택한 시점에 해방하는 단계로 발전시킨다.

## 목표

- 각인술사 다음의 6차 마법 직업 `법칙술사`를 추가한다.
- `대문장 해방`과 `각인 해방`을 각인 생성기로 재사용해 계보 전체를 보존한다.
- 공격·환류·침식·수호 각인을 전투 중 축적하고 원하는 기준에서 직접 소비한다.
- 같은 각인을 중첩하는 특화 빌드와 여러 종류를 조합하는 완성 빌드를 모두 지원한다.
- 기존 문장술사·각인술사 결과는 새 패시브를 장착하지 않았을 때 완전히 보존한다.

## 비목표

- 전직 퀘스트, 전용 아이템, 이미지 또는 전투 이펙트를 추가하지 않는다.
- 각인을 캐릭터 저장 데이터나 데이터베이스에 영구 저장하지 않는다.
- 첫 구현에서 전투 패턴에 개별 각인 종류 조건을 추가하지 않는다.
- 기존 `대문장 해방`, `각인 해방`, `각인 증폭`의 현재 효과와 수치를 변경하지 않는다.

## 직업 정의

- 표시 이름: `법칙술사`
- 내부 ID: `lawweaver`
- 직업 차수: 6차
- 선행 직업: `inscriber`
- 해금 조건: 각인술사 누적 직업 숙련도 `TIER6_UNLOCK_CUMLEVEL`
- 수행 성장: 지능 3, 정신 3
- 직업 보너스: 지능 28, 정신 12
- 역할: 문장 조합을 준비하고 완성된 각인을 원하는 시점에 해방하는 누적형 마법 딜러

법칙술사는 문장을 쓰고 각인을 새기는 단계를 넘어, 완성된 각인으로 전장의 법칙을 바꾼다는 계보상의 의미를 갖는다.

## 스킬 구성

법칙술사는 대표 액티브 하나와 핵심 패시브 하나를 배운다. 기존 6차 전투 직업의 일반적인 2스킬 구조를 따르며, 별도의 생성 액티브는 만들지 않는다.

### 법칙 각인

- 분류: 패시브
- 주 능력치: 지능
- 학습 비용: 숙달 포인트 12,000
- 장착 SP: 13
- 능력치 효과:
  - 지능 18%
  - 정신 8%
  - 최대 MP 16%
- 시스템 효과:
  - `대문장 해방` 또는 `각인 해방`이 정상적으로 시전된 뒤 각인을 생성한다.
  - `법칙 각인`을 장착하지 않았다면 어떤 각인도 생성하지 않는다.
  - 공격 적중 여부가 아니라 정상 시전을 기준으로 생성한다.

스킬 데이터의 패시브 마커 이름은 `lawInscription: true`로 고정한다. 전투 파생 능력치에도 같은 의미의 `lawInscription` 불리언을 전달해 엔진이 스킬 ID를 역으로 추론하지 않게 한다.

### 만상각인 해방

- 분류: 공격 액티브
- 주 능력치: 지능
- 학습 비용: 숙달 포인트 12,000
- 장착 SP: 13
- MP 비용: 기본 86, 고정 MP 비용 200
- 재사용 대기시간: 0
- 발동 확률: 100%
- 사용 조건: 보유 각인 총합 3개 이상
- 사용 결과: 보유 각인을 모두 소비하고 개수·종류에 따른 효과를 적용한다.

스킬 데이터의 소비 마커 이름은 `consumesLawInscriptions: true`로 고정한다. 해방 여부는 표시 이름이나 직업 ID가 아니라 이 마커로 판정한다.

MP 부족, 자원 부족 또는 다른 이유로 시전이 성립하지 않으면 각인을 소비하지 않는다. 정상 발동이 확정된 뒤 소비 스냅샷을 만들고 자원을 제거한다.

## 각인 자원

각인은 한 전투 안에서만 존재하는 임시 전투 자원이다. 전투 시작 시 모두 0이며 전투 종료 시 폐기한다.

순수 모듈과 전투 상태에서 사용할 타입 이름은 `LawInscriptionState`로 고정하고, 필드는 `assault`, `reflux`, `erosion`, `ward`를 사용한다.

```text
공격 각인: 0~2
환류 각인: 0~2
침식 각인: 0~2
수호 각인: 0~2
전체 각인: 0~8
```

누락되거나 손상된 값은 0으로 정규화한다. 각 종류의 값은 0~2로 제한하고 전체 합은 8을 넘지 않는다. 상한에 막힌 각인은 추가되지 않는다.

### 문장 재료 매핑

`대문장 해방` 또는 `각인 해방`을 시전할 때 다음 스킬이 함께 장착되어 있으면 대응하는 각인을 1개 생성한다.

| 장착 스킬 | 스킬 ID | 생성 각인 |
|---|---|---|
| 총명 | `v2c_mage_acumen` | 공격 각인 |
| 마나 실드 | `v2c_caster_acumen` | 환류 각인 |
| 총명 III | `v2c_magus_acumen3` | 침식 각인 |
| 문장 회로 | `v2c_runecaster_circuit` | 수호 각인 |

한 번의 정상 시전에서 장착 조건을 만족한 각인을 각각 1개씩 동시에 생성할 수 있다. `각인 증폭`은 기존처럼 `각인 해방`의 장착 시너지만 강화하며 각인 생성량을 늘리지 않는다.

각 종류가 최대 2개이고 해방 최소치가 총 3개이므로 문장 재료를 최소 두 종류 장착해야 해방할 수 있다. 단일 계열 특화는 `공격 2 + 보조 1`처럼 주력 각인 두 개와 보조 각인을 조합한다. 이는 순수 단일 재료 반복보다 조합 계보를 유지하기 위한 의도적인 제한이다.

## 해방 효과

### 기본 피해

`만상각인 해방`의 카탈로그 기준 기본 피해는 다음과 같다.

- 기본: 지능 계수 1.40 + 고정 마법 피해 320
- 소비한 각인 1개당: 지능 계수 +0.25, 고정 피해 +60

예시는 다음과 같다.

| 소비 총합 | 지능 계수 | 고정 피해 |
|---:|---:|---:|
| 3 | 2.15 | 500 |
| 4 | 2.40 | 560 |
| 6 | 2.90 | 680 |
| 8 | 3.40 | 800 |

이 수치는 카탈로그 원본값이다. 기존 차수별 액티브 보정, 치명타, 방어, 피해 배율과 PvP 보정은 정확히 한 번만 기존 경로에서 적용한다.

### 종류별 효과

- 공격 각인: 소비한 1개당 지능 계수 0.30 + 고정 마법 피해 80의 별도 추가타
- 환류 각인: 소비한 1개당 최대 MP의 4% 회복
- 침식 각인: 소비한 1개당 3턴간 마법 취약 7%
- 수호 각인: 소비한 1개당 3턴간 최대 MP 기반 보호막 7%

같은 종류를 2개 소비하면 해당 효과도 두 배로 합산한다. 침식 2개는 마법 취약 14%, 수호 2개는 최대 MP 기반 보호막 14%가 된다.

### 종류 다양성 보너스

- 서로 다른 각인 2종: 모든 직접 피해 6% 증가
- 서로 다른 각인 3종: 모든 직접 피해 12% 증가
- 서로 다른 각인 4종: 모든 직접 피해 18% 증가

네 종류가 모두 하나 이상 있으면 `완성 각인`을 추가로 발동한다.

- 지능 계수 0.55 + 고정 마법 피해 160의 추가 마법 타격
- 행동 속도 35% 증가

다양성 피해 보너스는 `만상각인 해방`이 이번 시전에 만드는 기본 피해, 공격 각인 추가타와 완성 각인 추가타에만 적용한다. DoT, 반사, 반격 또는 이후 다른 스킬에는 적용하지 않는다.

## 전투 순서와 데이터 흐름

### 각인 생성

1. 시전자가 `법칙 각인`을 장착했는지 확인한다.
2. 시전 스킬이 `대문장 해방` 또는 `각인 해방`인지 확인한다.
3. 기존 스킬의 피해와 장착 시너지를 현재 규칙대로 처리한다.
4. 시전이 정상적으로 성립했으면 장착 문장 재료를 각인 종류로 변환한다.
5. 종류별 상한 2와 전체 상한 8 안에서 각인을 추가한다.
6. 실제로 하나 이상 늘었을 때만 생성 로그를 남긴다.

### 각인 해방

1. 전투 패턴과 MP 조건을 포함한 일반 시전 가능 여부를 확인한다.
2. 각인 총합이 3 이상인지 확인한다.
3. 현재 네 종류의 각인 상태를 소비 스냅샷으로 복사한다.
4. 스냅샷으로 기본 피해, 종류별 효과와 다양성 보너스를 계산한다.
5. 정상 발동이 확정되면 실제 각인을 모두 0으로 만든다.
6. 계산된 효과를 기존 마법 피해·치명타·방어·PvP 처리 경로에 전달한다.

소비와 효과 계산은 하나의 시전 안에서 원자적으로 처리한다. 시전 확정 이전의 실패는 자원을 바꾸지 않는다.

## 전투 패턴

전투 패턴의 `self_resource` 조건에 내부 값 `inscription`, 표시 이름 `각인 총합` 자원을 추가한다. 첫 구현에서는 개별 공격·환류·침식·수호 개수를 조건으로 노출하지 않는다.

`만상각인 해방`의 기본 패턴은 다음과 같다.

- 우선순위: 600
- 조건: 자신의 각인 총합 4 이상
- 발동 확률: 100%

플레이어는 같은 조건의 값을 3, 4, 6 또는 8 등으로 바꿔 빠른 순환과 최대 해방 사이를 선택할 수 있다.

- 3 이상: 빠른 순환
- 4 이상: 기본 설정
- 6 이상: 고효율 해방
- 8 이상: 최대 해방

문장 재료 2종은 두 번의 생성 시전 뒤 총 4개, 3종은 첫 시전 3개와 두 번째 시전 최대 6개, 4종은 첫 시전 4개로 기본 해방 조건을 만족한다.

## 사용자 표시와 전투 로그

전투 재생 화면의 플레이어 상태 카드에는 각인이 하나 이상일 때 총합과 종류별 개수를 한 줄로 표시한다. 재생 이벤트가 생성·소비 시점의 `LawInscriptionState` 스냅샷을 선택적으로 전달하며, 스냅샷이 없는 과거 리플레이에서는 이 줄을 표시하지 않는다.

```text
각인 4/8 · 공격 2 · 환류 2
```

각인 생성 로그:

```text
법칙 각인: 공격 +1 · 환류 +1 (총 4/8)
```

해방 로그:

```text
만상각인 해방: 공격 2 · 환류 2 소비
```

완성 각인 로그:

```text
공격·환류·침식·수호가 하나로 이어져 완성 각인이 발동했다.
```

상한 때문에 실제 증가량이 0이면 생성 로그를 남기지 않는다. 해방 시전이 성립하지 않으면 소비 로그도 남기지 않는다.

## 구현 경계

각인 계산은 전투 엔진 내부에 중복 구현하지 않고 별도의 순수 모듈로 분리한다. 모듈은 다음 책임만 갖는다.

- 각인 상태 타입과 빈 상태 생성
- 손상된 상태 정규화
- 장착 문장 재료에서 생성할 각인 계산
- 종류별·전체 상한을 적용한 각인 추가
- 총합과 서로 다른 종류 수 계산
- 해방 가능 여부 계산
- 소비 스냅샷에서 동적 효과 계산

순수 모듈의 파일 경계는 `src/adventure/v2/combat/lawInscription.ts`로 고정한다. 카탈로그는 `lawInscription`과 `consumesLawInscriptions` 마커만 선언하고, 개수 제한과 해방 공식은 이 모듈만 소유한다.

직업·스킬 카탈로그는 법칙술사와 두 스킬의 정적 정의만 소유한다. 전투 엔진은 순수 모듈을 호출해 임시 자원을 갱신하고, 패턴 엔진은 각인 총합만 읽는다. PvE와 PvP는 같은 순수 계산을 공유한다.

전투 자원은 런타임 상태에만 추가한다. 저장 데이터와 API 저장 형식은 바꾸지 않으며 DB 마이그레이션은 없다.

## 오류와 호환성

- 각인 상태가 누락된 기존 전투 상태는 네 종류 모두 0으로 해석한다.
- 음수, 소수, 숫자가 아닌 값과 종류별 2를 넘는 값은 정규화한다.
- 전체 합이 8을 넘는 손상 상태는 정해진 종류 순서 안에서 총합 8로 제한한다.
- `법칙 각인` 미장착 시 기존 `대문장 해방`과 `각인 해방`은 바이트 수준으로 같은 효과를 낸다.
- 기존 저장 스킬, 로드아웃과 전투 패턴은 새 자원을 사용하지 않는 한 그대로 유효하다.
- PvP는 생성량과 부가 효과를 PvE와 동일하게 계산하고 최종 직접 피해에만 기존 PvP 보정을 적용한다.

## 검증 계획

### 카탈로그와 전직

- `lawweaver`가 6차이며 각인술사 숙련도를 선행 조건으로 요구한다.
- 수행 성장 지능 3·정신 3과 직업 보너스 지능 28·정신 12를 검증한다.
- 법칙술사가 두 스킬만 배우며 학습 비용·SP·MP·기본 패턴이 설계와 일치한다.
- 레거시 표시와 직업 ID 매핑, 직업 목록 완전성 검증을 갱신한다.

### 순수 각인 계산

- 네 문장 재료가 각각 올바른 각인을 만든다.
- 한 시전에 여러 문장 재료가 있으면 각 종류를 동시에 1개씩 만든다.
- 종류별 2개와 전체 8개 상한을 지킨다.
- 손상된 상태를 안전하게 정규화한다.
- 각인 3개 미만은 해방할 수 없다.
- 3, 4, 6, 8개에서 기본 피해 공식이 정확하다.
- 같은 종류 2개가 종류별 효과를 정확히 두 배로 만든다.
- 2, 3, 4종 다양성 보너스가 각각 6%, 12%, 18%다.
- 네 종류가 있을 때만 완성 각인이 생긴다.

### 전투 통합

- `법칙 각인`과 생성 스킬을 장착한 정상 시전 뒤 각인이 쌓인다.
- 생성 스킬이 장착되어도 `법칙 각인`이 없으면 각인이 쌓이지 않는다.
- 정상 해방 뒤 네 종류가 모두 0이 된다.
- 각인 부족과 MP 부족에서는 해방되지 않고 기존 각인을 보존한다.
- 공격 추가타, MP 회복, 마법 취약, MP 보호막과 행동 속도가 기존 처리 순서로 적용된다.
- 다양성 보너스가 이번 직접 피해에만 적용된다.
- PvE와 PvP 양쪽에서 같은 생성·소비 규칙을 사용한다.
- 새 패시브 미장착 시 기존 문장술사·각인술사 픽스처 결과가 그대로다.

### 패턴과 표시

- 전투 패턴이 자신의 각인 총합 조건을 파싱·저장·평가한다.
- 기본 패턴이 총합 4 이상과 우선순위 600을 사용한다.
- 전투 상태가 총합과 종류별 개수를 표시한다.
- 실제 증가·소비·완성 각인에만 대응 로그가 생성된다.

### 전체 균형 검증

- 전체 타입 검사와 린트, 관련 집중 테스트와 전체 테스트를 통과한다.
- 고정 시드 전투 시뮬레이션으로 대마도사·태초술사 등 기존 6차 마법 직업과 평균 화력·MP 유지력·생존력을 비교한다.
- 3개 빠른 해방, 4개 기본 해방, 6개 고효율 해방과 8개 최대 해방이 하나의 설정만 압도하지 않는지 확인한다.

## 완료 기준

- 각인술사 숙련도로 법칙술사를 해금하고 두 스킬을 배울 수 있다.
- 기존 두 생성 스킬과 문장 재료 조합이 네 종류의 임시 각인을 만든다.
- 플레이어가 전투 패턴에서 각인 총합 기준을 정해 `만상각인 해방` 시점을 조절한다.
- 해방 결과가 개수·종류·다양성에 따라 설계된 피해와 부가 효과를 적용한다.
- 실패 시 자원을 보존하고 성공 시 전부 소비한다.
- 기존 문장술사·각인술사와 다른 전투 직업의 회귀가 없다.
