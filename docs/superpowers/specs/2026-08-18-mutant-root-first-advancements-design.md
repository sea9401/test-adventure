# 변이자 기본 루트와 1차 변이 직업 설계

## 결정

모험가·생존자와 나란히 선택할 수 있는 세 번째 Tier 0 기본 루트 `변이자`를 추가한다.

- 루트 ID: `mutant`
- 표시명: `변이자`
- 처음부터 해금돼 있으며 별도 퀘스트·아이템·스토리 조건을 요구하지 않는다.
- 변이자 숙련도 `1,000`을 달성하면 Tier 1 직업 `수인·골렘·점액체`가 동시에 해금된다.
- 1차 해금에는 아이템 획득 기록을 사용하지 않는다. 아이템 해금은 각 계열의 2차 이후 직업을 설계할 때 다시 검토한다.

계보는 다음과 같다.

```text
변이자
├─ 수인     — 출혈 누적
├─ 골렘     — 중량 축적과 지각 붕괴
└─ 점액체   — 분열과 융합
```

## 수집형 원칙

직업은 스킬을 얻는 경로이지 스킬 사용을 제한하는 전투 태세가 아니다.

- 변이 계열에서 한 번 학습한 스킬은 다른 직업으로 전직한 뒤에도 기존 로드아웃 규칙에 따라 장착할 수 있다.
- 신규 스킬과 전투 자원은 `currentJobId`가 `mutant`, `beastkin`, `golem`, `slime`인지 검사하지 않는다.
- 이번에 추가하는 변이 계열에서는 현재 직업이 수련 성향과 직업 보너스에만 관여한다. 기존 계보의 현재 직업 전용 태세 규칙은 변경하지 않는다.
- 완성형 세트를 장착하면 계열의 대표 기믹이 선명해지지만, 공격·소모 스킬은 관련 자원이 0이어도 기본 효과를 낸다.
- 수인 스킬은 다른 출혈 공급원과 상호작용하고, 골렘·점액체 스킬은 어느 직업이 장착해도 각각 중량과 분열체를 생성·사용할 수 있다.

이 원칙으로 기존 직업·장비·스킬과 변이 기술을 섞는 수집형 빌드를 보장한다.

## 직업 성장

### 변이자

- Tier: 0
- ID: `mutant`
- 수련 성향: `VIT 2 / STR 1 / INT 1`
- 직업 보너스: 없음
- 해금: 항상 해금

변이자는 세 갈래로 갈라지기 전의 불완전한 신체 변화를 표현한다. 어느 한 공격 계열을 미리 강요하지 않도록 활력을 중심에 두고 힘과 지능을 함께 수련한다.

### 수인

- Tier: 1
- ID: `beastkin`
- 수련 성향: `STR 2 / DEX 1 / VIT 1`
- 직업 보너스: `STR +5`
- 해금: 변이자 숙련도 `1,000`

빠른 신체 공격으로 짧고 강한 출혈을 유지하는 물리 공격 계열이다.

### 골렘

- Tier: 1
- ID: `golem`
- 수련 성향: `VIT 2 / STR 1 / SPI 1`
- 직업 보너스: `VIT +5`
- 해금: 변이자 숙련도 `1,000`

공격할수록 몸이 무거워지고 단단해진 뒤 축적한 중량을 한 번에 해소하는 물리 전투 계열이다.

### 점액체

- Tier: 1
- ID: `slime`
- 수련 성향: `INT 2 / VIT 1 / SPI 1`
- 직업 보너스: `INT +5`
- 해금: 변이자 숙련도 `1,000`

분열체를 늘려 지속 화력을 얻거나 한꺼번에 융합해 단일 피해를 내는 마법 전투 계열이다.

## 변이자 기본 스킬

변이자 숙련도 1,000까지 기본 공격만 반복하지 않도록 최소 스킬 두 개를 제공한다. 다른 루트와 마찬가지로 자동 지급하지 않으며 기존 학습·SP 장착 규칙을 따른다.

### 불완전 변형

- 스킬 ID: `v2c_mutant_morphstrike`
- 분류: Tier 1 직접 물리 공격
- 주 능력치: VIT
- 성능 기준: 기존 Tier 1 단일 공격기와 같은 예산
- 효과: 변형한 신체로 직접 피해를 준다.

현재 직업과 관계없이 사용할 수 있는 단순 공격기다. 별도 변이 자원을 생성하지 않는다.

### 변이 적응

- 스킬 ID: `v2c_mutant_adaptation`
- 분류: Tier 1 패시브
- 주 능력치: VIT
- 효과: 받는 상태 피해 8% 감소

중독·출혈·연소처럼 기존 상태 피해 경감 경로를 사용하는 피해에만 적용한다. 직접 피해 감소나 상태이상 면역은 제공하지 않는다.

## 수인 스킬 — 출혈 누적

수인은 기존 출혈 상태와 최대 10스택 규칙을 그대로 사용하며 전용 전투 자원을 추가하지 않는다. 출혈을 소모하거나 폭발시키지 않고 유지할수록 직접 공격이 강해지는 계열로, 중독을 쌓아 추가 피해로 회수하는 독술 계보와 구분한다.

### 찢어발기기

- 스킬 ID: `v2c_beastkin_rend`
- 분류: Tier 1 STR 직접 물리 공격
- 효과: 직접 피해와 출혈 2스택을 부여한다.
- 출혈 지속 시간과 스택당 피해는 기존 출혈 프리셋을 따른다.

### 연속 할퀴기

- 스킬 ID: `v2c_beastkin_clawflurry`
- 분류: Tier 1 STR 다단 물리 공격
- 효과: 세 번 공격하고 시전당 출혈 3스택을 부여한다.
- 다단 각 타격이 출혈을 별도로 중첩하지 않는다. 출혈은 시전당 한 번만 적용해 다단 온힛 증폭을 제한한다.

### 피 냄새

- 스킬 ID: `v2c_beastkin_bloodscent`
- 분류: Tier 1 패시브
- 효과: 적의 활성 출혈 1스택당 자신이 가하는 직접 물리 스킬 피해가 2% 증가한다.
- 최대 출혈 10스택에서 최대 20% 증가한다.
- 수인 스킬뿐 아니라 장비·다른 직업 스킬이 만든 출혈도 읽는다.
- 평타 추가 횟수는 제공하지 않아 기존 검투사 `혈광`과 역할을 겹치지 않는다.

## 골렘 스킬 — 중량 축적

초기의 `피격 시 핵 충전 → 강타로 소모` 안은 기존 수호자·성채기사의 `충격 방벽 → 충격 소모`와 동일해 폐기한다. 골렘은 자신의 공격으로 몸의 중량을 늘리는 별도 자원 `중량`을 사용한다.

### 중량 규칙

- 중량 범위: 0~3
- 전투 시작 시 0이며 전투가 끝나면 사라진다.
- 중량 1스택당 모든 직접 물리 스킬 피해가 5% 증가하고 현재 SPD가 5% 감소한다.
- 중량은 직접 물리 스킬 피해에만 적용하며 평타·마법·지속 피해·반사 피해는 강화하지 않는다.
- SPD 감소는 기존 속도 하한을 우회하지 않는다.
- 중량은 저장된 기본 SPD를 변경하지 않고 전투 중 유효 SPD를 계산할 때만 적용한다. 자원을 소모하면 다음 속도 계산부터 즉시 원래 값으로 돌아간다.
- 중량을 만드는 스킬의 이번 피해는 새 중량의 보너스를 받지 않는다. 피해를 계산한 뒤 중량을 올린다.
- 중량을 소모하는 스킬은 시전 시점의 중량을 스냅샷으로 계산하고, 시전이 성립하면 회피나 피해 무효 여부와 관계없이 소모한다.

### 암석 강타

- 스킬 ID: `v2c_golem_rocksmash`
- 분류: Tier 1 VIT/DEF 기반 직접 물리 공격
- 효과: 기본 피해를 준 뒤 중량 1스택을 얻는다.
- 중량이 최대라면 피해만 주고 3스택을 유지한다.

단독 장착 시에도 일반 공격기로 기능하며, 축적한 중량은 다른 직업의 직접 물리 스킬도 강화한다.

### 지각 붕괴

- 스킬 ID: `v2c_golem_tectoniccollapse`
- 분류: Tier 1 VIT/DEF 기반 직접 물리 공격
- 효과: 자원이 없어도 기본 피해를 준다.
- 중량 1스택당 이 스킬의 최종 피해가 추가로 20% 증가한다.
- 시전이 성립하면 중량을 모두 소모한다.
- 스마트 기본 조건은 중량 3 이상에서 우선 사용한다.

### 돌가죽

- 스킬 ID: `v2c_golem_stoneskin`
- 분류: Tier 1 패시브
- 효과: 중량 1스택당 DEF가 6% 증가한다. 최대 3스택에서 18%다.
- 중량이 없을 때는 DEF를 올리지 않는다.

돌가죽은 중량의 방어 측면만 강화한다. 다른 직업도 암석 강타와 함께 장착하면 같은 효과를 얻는다.

## 점액체 스킬 — 분열과 융합

점액체는 전투 자원 `분열체`를 사용한다. 기존 그림자 분신이 즉시 추가타를 제공하는 것과 달리 분열체는 명시적으로 쌓고 유지하거나 융합 공격으로 소모하는 자원이다.

### 분열체 규칙

- 분열체 범위: 0~3
- 전투 시작 시 0이며 전투가 끝나면 사라진다.
- 분열체 자체는 능력치를 바꾸지 않는다.
- 관련 스킬이 분열체 수를 읽어 추가타 또는 융합 보너스를 계산한다.
- 소모 스킬은 시전 시점의 분열체 수를 스냅샷으로 계산하고, 시전이 성립하면 회피나 피해 무효 여부와 관계없이 모두 소모한다.

### 분열

- 스킬 ID: `v2c_slime_split`
- 분류: Tier 1 버프
- 주 능력치: INT
- 효과: 분열체 1개를 만든다.
- 최대치에서는 시전 후보에서 제외한다.
- 스마트 기본 조건은 분열체 1 이하에서 사용한다.

### 점액 난타

- 스킬 ID: `v2c_slime_barrage`
- 분류: Tier 1 INT 기반 직접 마법 공격
- 효과: 분열체가 없어도 기본 1회 피해를 준다.
- 현재 분열체 1개당 기본타의 25% 위력을 가진 보조타 1회를 추가한다.
- 보조타는 추가 분열·스킬 발동·상태이상 부여를 재귀적으로 일으키지 않는다.
- 분열체를 소모하지 않는다.

### 융합 충돌

- 스킬 ID: `v2c_slime_fusioncrash`
- 분류: Tier 1 INT 기반 직접 마법 공격
- 효과: 분열체가 없어도 기본 피해를 준다.
- 분열체 1개당 이 스킬의 최종 피해가 25% 증가한다.
- 시전이 성립하면 분열체를 모두 소모한다.
- 스마트 기본 조건은 분열체 3 이상에서 우선 사용한다.

세 스킬은 현재 직업과 무관하게 작동한다. 마법사나 생존 계열이 분열과 융합만 가져가는 혼합 빌드도 허용한다.

## 데이터와 전투 흐름

### 직업·스킬 데이터

- 직업 카탈로그에 `mutant`, `beastkin`, `golem`, `slime`을 추가한다.
- `MUTANT_TIER1_UNLOCK_CUMLEVEL = 1_000`을 별도 상수로 두고 세 Tier 1 직업이 공유한다.
- 기본 루트 판별, 직업 계보, 숙련도 그룹, 구형 class/spec 호환 매핑, 직업 탐색기·로드맵·도감에서 새 루트를 명시적으로 인식한다.
- 직업별 스킬 매핑과 공용 스킬 ID 유니온에 위 11개 스킬을 추가한다.
- 학습 비용과 SP 비용은 기존 Tier 1 정책을 사용하며 변이 계열만의 할인이나 자동 지급을 만들지 않는다.

### 전투 자원

- PvE와 PvP 전투 상태에 `weight`와 `split`을 전투 한정 숫자 자원으로 추가한다.
- 자원 생성·증폭·소모 계산은 순수 함수로 분리하고 PvE/PvP 어댑터가 같은 함수를 사용한다.
- 모든 입력은 정수로 내리고 `weight`와 `split`을 각각 0~3으로 보정한다.
- 저장 캐릭터 데이터에는 두 자원을 기록하지 않는다.
- 스킬 장착 여부가 자원을 생성하는 유일한 진입점이며 현재 직업은 판정에 포함하지 않는다.

### 자동 전투

- `self_resource` 조건의 허용 자원에 `weight`와 `split`을 추가한다.
- 패턴 편집기에서 `중량`, `분열체`를 선택할 수 있게 한다.
- 두 자원의 입력 상한은 3이다.
- 구형 또는 알 수 없는 자원 키는 기존 파서처럼 해당 조건을 제거하고 안전한 기본 패턴으로 정리한다.
- 지각 붕괴와 융합 충돌은 자원이 0이어도 수동 패턴이나 사용자 지정 패턴에서 정상 시전할 수 있다.

## UI와 전투 로그

- 직업 탐색기에서 변이자를 세 번째 기본 루트로 표시하고 세 Tier 1 갈래를 연결한다.
- 잠긴 수인·골렘·점액체 카드에는 `변이자 숙련도 1,000`을 동일하게 표시한다.
- 전투 상태 영역에 중량과 분열체의 현재 수치를 0~3으로 표시한다. 해당 자원을 만드는 스킬이 장착되지 않았다면 숨긴다.
- 전투 로그는 다음 형식을 사용한다.
  - `[중량] +1 (2/3)`
  - `[지각 붕괴] 중량 3 소모`
  - `[분열] 분열체 +1 (2/3)`
  - `[융합 충돌] 분열체 3 융합`
- 스킬 상세 설명에는 자원 상한, 중첩당 효과, 소모 여부를 수치 칩으로 표시한다.
- 새 카드나 패널이 필요하면 기존 불투명 표면 컴포넌트와 `SURFACE_CARD`·`SURFACE_INSET`을 재사용한다. 배경 이미지가 본문 뒤로 비치는 새 반투명 표면은 만들지 않는다.

## 수치 조정 범위

문서에 명시한 해금 숙련도, 자원 상한, 중첩당 증감률, 출혈 스택, 타격 수와 자원 판정 순서는 기능 규칙으로 고정한다. 각 공격기의 기본 피해 계수·고정 피해·MP 비용·발동률·학습 비용·SP 비용은 기존 Tier 1 공격기 예산에서 시작해 구현 단계의 PvE/PvP 시뮬레이션으로 정한다.

- 자원이 0인 지각 붕괴와 융합 충돌은 동급 Tier 1 단일 공격기보다 강하지 않게 한다.
- 최대 자원 보너스를 포함한 평균 피해는 자원 생성에 사용한 행동 수까지 합산해 동급 Tier 1 완성 빌드와 비교한다.
- 수인의 출혈은 기존 최대 10스택과 상태 피해 상한을 우회하지 않는다.
- 중량의 SPD 감소와 돌가죽의 DEF 증가는 기존 속도·방어 계산 상한을 우회하지 않는다.
- 점액 난타 보조타는 기본타의 치명타나 온힛 결과를 복제하지 않는다.

## 기존 데이터 호환

- 기존 캐릭터의 현재 직업과 숙련도 그룹을 변경하지 않는다.
- `mutant` 숙련도 그룹이 없는 저장 데이터는 기존 숙련도 정규화 경로에서 0으로 채운다.
- 변이자 루트는 항상 해금으로 계산하지만 기존 캐릭터에게 변이자 스킬을 자동 학습시키지 않는다.
- 기존 로드아웃, SP 사용량, 전투 패턴을 다시 계산하거나 초기화하지 않는다.
- 이번 범위에는 영구 아이템 획득 기록이나 재료 마이그레이션이 없다.

## 테스트

### 직업과 해금

- 변이자가 신규·기존 캐릭터 모두에게 기본 해금된다.
- 변이자 숙련도 999에서는 세 Tier 1 직업이 잠기고 1,000에서는 모두 해금된다.
- 모험가·생존자 루트의 기존 해금과 루트 선택이 변하지 않는다.
- 계보·직업 탐색기·로드맵·도감에 세 번째 루트가 누락되지 않는다.

### 수집형 스킬

- 현재 직업이 수인·골렘·점액체가 아니어도 학습한 변이 스킬을 장착하고 발동할 수 있다.
- 수인 피 냄새가 장비와 다른 직업 스킬이 만든 출혈도 읽는다.
- 암석 강타로 만든 중량이 다른 직업의 직접 물리 스킬 피해에도 적용된다.
- 분열·점액 난타·융합 충돌이 다른 직업에서도 같은 자원을 공유한다.
- 관련 자원이 0인 상태에서 암석 강타·지각 붕괴·점액 난타·융합 충돌의 기본 피해가 발생한다.

### 자원과 전투

- 중량과 분열체가 0~3으로 보정되고 전투마다 0에서 시작한다.
- 암석 강타의 현재 피해 계산 후 중량이 증가한다.
- 중량이 직접 물리 스킬 피해와 SPD에만 적용되고 평타·마법·지속·반사 피해에는 적용되지 않는다.
- 돌가죽의 DEF 증가가 중량 수에 맞게 적용되고 0중첩에서는 비활성이다.
- 지각 붕괴와 융합 충돌이 시전 시점 자원을 읽은 뒤 모두 소모한다.
- 점액 난타 보조타가 재귀적으로 온힛이나 추가 보조타를 만들지 않는다.
- 같은 판정이 PvE와 PvP에서 성립한다.

### 자동 전투와 호환

- 자동 전투가 중량·분열체의 `none`, `atLeast`, `atMost` 조건을 평가한다.
- 패턴 파서가 두 자원을 보존하고 잘못된 키와 범위를 안전하게 정리한다.
- 기본 패턴이 최대 중량에서 지각 붕괴, 최대 분열체에서 융합 충돌을 우선한다.
- 기존 저장 데이터 정규화가 새 숙련도 그룹을 0으로 채우면서 기존 값을 보존한다.
- 기존 스킬 로드아웃과 직업 계보 회귀 테스트가 계속 통과한다.

## 구현 범위 밖

- 수인·골렘·점액체의 2차 이후 직업
- 아이템 최초 획득 또는 현재 보유 기반 해금
- 변신 외형, 전용 캐릭터 일러스트, 신규 몬스터와 신규 재료
- 스토리·퀘스트·NPC 대화
- 운영 배포와 점검 모드 변경

이 문서는 세 번째 기본 루트, 세 Tier 1 직업, 첫 스킬 세트, 전투 자원과 수집형 상호 운용까지를 하나의 구현 단위로 확정한다.
