# 폭풍 원정 조작 동선 개선 설계

## 문제

분기형 원정 지도 도입 후 진행 화면이 `지도 → 선택 미리보기 → 현재 체크포인트 행동 → 전리품` 순서로 세로 배치됐다. 모바일 중층 지도는 높이가 550px이고, PC에서도 420px 지도 아래에 행동 영역이 놓여 전투·정비와 다음 경로 선택 사이에 스크롤 왕복이 발생한다.

## 목표

- 모바일에서는 현재 체크포인트 행동을 가장 먼저 보여준다.
- 모바일 지도는 현재 노드와 바로 다음 후보만 보여 한 화면 안에서 선택할 수 있게 한다.
- PC에서는 지도와 현재 행동을 좌우에 동시에 배치한다.
- 선택한 다음 노드의 설명과 이동 버튼은 지도 바로 아래에 둔다.
- 분기 규칙, 전투, 보상, API 요청 형식은 바꾸지 않는다.

## 화면 구조

진행 중 화면은 세 영역으로 나눈다.

1. `현재 행동`: 현재 체크포인트 정보, HP/MP, 전투·정비·위험 이벤트 조작
2. `경로 선택`: 진행 헤더, 반응형 지도, 선택 노드 미리보기와 이동 버튼
3. `원정 지원`: 임시 전리품 가방 또는 연습 종료 안내

모바일 DOM 순서는 `현재 행동 → 경로 선택 → 원정 지원`이다. PC에서는 CSS Grid로 경로 선택을 왼쪽, 현재 행동과 원정 지원을 오른쪽에 배치한다. 따라서 모바일 접근 순서와 PC 동시 가시성을 모두 만족한다.

모바일 지도는 입장 전에는 세 입구만, 진행 중에는 현재 노드와 `previewableNodeIds`만 표시한다. 진행 구간 전체를 보여주는 300~550px 캔버스는 제거하고 180~260px의 축약 캔버스를 사용한다. 전체 원정 지도는 PC에서 계속 제공한다.

## 테스트

- 레이아웃 셸을 정적 렌더링해 모바일 DOM 순서가 현재 행동, 경로 선택, 원정 지원 순인지 확인한다.
- 레이아웃 셸이 PC 2열 배치 클래스를 제공하는지 확인한다.
- 모바일 지도 모델이 입장 노드만 또는 현재 노드와 다음 후보만 반환하는지 확인한다.
- 원정 지도 컴포넌트가 축약 캔버스와 전체 PC 지도를 함께 렌더링하는지 확인한다.

## 범위 제외

- 원정 난이도, 입장 횟수, 보상 및 확률 변경
- 서버 상태와 저장 형식 변경
- 전투 리플레이 화면 변경
- 운영 배포
