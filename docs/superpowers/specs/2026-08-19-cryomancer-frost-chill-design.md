# 빙결술사 5차 및 한기·빙결 전투 설계

## 배경

냉기 마법사는 4차 마법 직업이며 `빙하진`과 `얼어붙은 심장`을 사용한다. 현재 빙하진은 마법 피해, 보호막, 적 행동 지연을 한 번에 제공한다. 대지 마법사의 `지각진`도 마법 피해, 보호막, 적 행동 지연을 제공하므로 두 원소의 실제 운용이 지나치게 비슷하다.

기존 냉기 마법사의 후속은 화염·냉기·전격·바람·대지 마법사를 모두 요구하는 5차 `원소군주`다. 냉기 하나를 깊게 파는 단일 계보는 없다. 냉기는 여러 번 적중해 한기를 축적하고 임계점에서 빙결 피해를 일으키는 누적형 원소로 재정의하고, 대지는 즉시 행동 지연과 보호막을 제공하는 안정형 원소로 유지한다.

## 목표

- 냉기 마법사에서 직접 이어지는 5차 직업 `빙결술사`를 추가한다.
- 냉기 마법사 단계부터 적에게 한기를 쌓아 5스택에서 자동 빙결시키는 전투 순환을 제공한다.
- 빙결은 행동을 완전히 막지 않고 추가 마법 피해와 1회성 ATB 지연을 적용한다.
- 빙하진에서 보호막과 즉시 지연을 제거해 지각진과 역할을 분리한다.
- 다른 직업이 배운 냉기 스킬을 장착하는 기존 공용 로드아웃 원칙을 유지한다.
- PvE, PvP, 전투 패턴, 전투 로그와 리플레이에서 같은 한기 규칙을 사용한다.

## 비목표

- 적의 다음 행동을 건너뛰게 하는 기절·행동 불가형 빙결은 추가하지 않는다.
- 대지 마법사의 `지각진` 수치나 효과는 변경하지 않는다.
- 원소군주의 `빙하 폭주`, `영구빙벽`, `빙뢰결계`에 한기 생성을 자동으로 추가하지 않는다.
- 전직 퀘스트, 전용 장비, 이미지 또는 별도 전투 연출은 추가하지 않는다.
- 한기를 캐릭터 저장 데이터나 데이터베이스에 영구 저장하지 않는다.
- 현재 직업이 빙결술사인지 검사하는 숨은 직업 전용 보정은 만들지 않는다.

## 직업 정의

- 표시 이름: `빙결술사`
- 내부 ID: `cryomancer`
- 직업 차수: 5차
- 선행 직업: `frostmage`
- 해금 조건: 냉기 마법사 누적 직업 숙련도 `TIER5_UNLOCK_CUMLEVEL`
- 수행 성장: 지능 3, 정신 2
- 직업 보너스: 지능 18, 정신 8
- 역할: 한기를 빠르게 축적해 반복적인 빙결 추가타와 소프트 제어를 일으키는 마법 공격수

원소군주는 다섯 원소를 조합하는 별도 5차 경로로 그대로 유지한다. 냉기 마법사 숙련자는 원소군주와 빙결술사를 각각 해금할 수 있다.

## 한기 자원

플레이어 냉기 스킬이 적에게 쌓는 한기는 한 전투 안에서만 존재하는 대상별 임시 자원이다.

- 시작값: 0
- 빙결 임계점: 5
- 표시 범위: 0~4
- 자연 감소: 없음
- 전투 종료: 전량 폐기
- 한기 생성: 명시적인 생성 스킬이 정상 적중하고 상태이상 차단을 통과했을 때만 적용
- 다단 공격: 타격 수와 무관하게 한 번의 스킬 시전당 한 번만 생성

한기 증가로 합계가 5 이상이 되면 5스택을 즉시 소비해 빙결을 한 번 발동하고 상태를 0으로 만든다. 초과분은 이월하지 않는다. 예를 들어 한기 4에서 빙하진으로 2를 추가하면 빙결 1회가 발동하고 한기는 0이 된다.

한 번의 시전에서 한기 증가량이 10 이상이더라도 빙결은 최대 한 번만 발동한다. 빙결 추가타는 한기를 생성하지 않으며 재귀적으로 다른 빙결을 일으키지 않는다.

### 기존 몬스터 한기와 분리

현재 전투 상태의 `chillStacks`는 몬스터가 플레이어에게 부여하는 한기 상태다. 새 자원은 이를 재사용하지 않는다.

- PvE: 플레이어가 적에게 쌓은 값을 별도 `enemyFrostChillStacks` 상태로 관리한다.
- PvP: 각 진영 스택에 자신이 받은 `frostChillStacks`를 별도로 관리한다.
- 순수 계산 타입과 함수도 몬스터 한기 로직과 다른 모듈에 둔다.

누락되거나 손상된 값은 0으로 정규화한다. 이를 통해 한기 필드가 없는 과거 전투 상태와 리플레이를 그대로 읽을 수 있다.

## 기본 빙결

빙결은 4차 냉기 마법사부터 사용할 수 있다. 별도 패시브를 장착해야만 열리는 기능이 아니라, 한기 생성 스킬 자체의 공통 임계 효과다.

### 기본 효과

- 원시 추가 마법 피해: `지능 × 0.70 + 최대 MP × 4% + 180`
- 적 다음 행동 지연: 대상 기준 행동 간격의 30%
- 한기 소비: 5

추가 피해 수치는 차수별 액티브 리밸런싱 전 원시값이다. 빙결을 발생시킨 스킬의 차수 보정을 정확히 한 번 적용하고, 이후 기존 직접 마법 피해 경로에서 마법 방어, 치명타, 장비 효과와 PvP 보정을 처리한다.

빙결 추가 피해는 원래 스킬과 같은 시전의 별도 마법 타격으로 기록하며 같은 명중 및 치명타 결과를 공유한다. 원래 직접 피해와 빙결 추가 피해 중 하나라도 적을 처치할 수 있다. 대상이 살아 있을 때만 행동 지연이 의미를 갖는다.

### 소프트 제어 원칙

빙결은 적의 행동을 취소하거나 다음 행동을 건너뛰지 않는다. ATB 타임라인에 이미 예약된 다음 행동을 대상 행동 간격의 일정 비율만큼 뒤로 민다.

- 기본 빙결: 30%
- `빙점 지배` 장착 빙결: 40%
- 지각진: 기존처럼 매 적중 35% 즉시 지연

빙하진은 약 세 번의 적중마다 기본 빙결을 일으켜 적중당 평균 지연이 약 10%다. 절대영도와 빙점 지배 조합은 약 두 번의 적중마다 40% 지연을 일으켜 적중당 평균이 약 20%다. 추가 빙결 피해가 함께 있으므로, 지연만 제공하는 빈도와 강도는 지각진보다 낮게 유지한다.

## 냉기 마법사 스킬 개편

### 빙하진

- 스킬 ID: 기존 `v2c_frostmage_glacier` 유지
- 분류: 공격 액티브
- 주 능력치: 지능
- 마법 피해: 지능 계수 1.50 + 고정 피해 290
- MP 비용, 발동 확률과 재사용 대기시간: 현재 값 유지
- 신규 효과: 정상 적중 시 한기 2
- 제거 효과: 최대 HP·MP 기반 보호막
- 제거 효과: 25% 즉시 적 행동 지연
- 장착 SP: 기존 7 유지

빙하진의 저장 ID는 바꾸지 않는다. 기존에 배우거나 장착한 빙하진은 자동으로 새 효과를 사용한다.

### 얼어붙은 심장

- 스킬 ID: 기존 `v2c_frostmage_frozenheart` 유지
- 최대 MP 12%와 마법 방어 12% 유지
- 장착 SP: 기존 5 유지

얼어붙은 심장은 한기 생성량을 직접 늘리지 않는다. 최대 MP 증가가 기본 빙결 피해의 최대 MP 계수를 높이는 방식으로 계보에 기여한다.

## 빙결술사 스킬

### 절대영도

- 스킬 ID: `v2c_cryomancer_absolutezero`
- 분류: 공격 액티브
- 주 능력치: 지능
- 학습 비용: 8,000
- 장착 SP: 7
- 고정 MP 비용: 155
- 발동 확률: 30%
- 재사용 대기시간: 0
- 마법 피해: 지능 계수 2.20 + 고정 피해 540
- 정상 적중 시 한기 3

절대영도는 빙하진보다 직접 피해와 생성량이 높은 5차 주력기다. 대상의 한기가 2 이상이면 한 번의 적중으로 빙결까지 연결한다.

### 빙점 지배

- 스킬 ID: `v2c_cryomancer_freezingpoint`
- 분류: 패시브
- 주 능력치: 지능
- 학습 비용: 8,000
- 장착 SP: 6
- 능력치 효과: 최대 MP 12%
- 시스템 효과: 빙결 추가 피해 50% 증가
- 시스템 효과: 빙결 행동 지연을 30%에서 40%로 증가

빙점 지배의 50% 피해 증가는 빙결 추가타에만 적용한다. 빙하진, 절대영도 또는 다른 직접 피해에는 적용하지 않는다.

## 공용 장착 규칙

배운 스킬은 현재 직업과 무관하게 장착할 수 있는 기존 규칙을 그대로 따른다.

- 빙하진만 장착해도 한기와 기본 빙결을 사용할 수 있다.
- 절대영도만 장착해도 한기와 기본 빙결을 사용할 수 있다.
- 빙점 지배를 함께 장착하면 어느 직업이든 빙결 피해와 지연이 강화된다.
- 빙점 지배의 효과를 적용할 때 현재 직업 ID를 검사하지 않는다.

절대영도와 빙점 지배를 함께 가져가려면 13 SP가 필요하다. 빙하진과 얼어붙은 심장까지 포함한 전체 냉기 구성은 25 SP가 필요하다. 다른 직업이 냉기 순환을 채용할 수는 있지만 주력 액티브와 패시브 예산을 상당 부분 사용하도록 한다.

## 한기 생성 대상

스킬 정의에 전용 메타데이터 `frostChillGain`을 추가하고, 값이 있는 스킬만 한기를 생성한다.

첫 구현에서 생성량을 갖는 스킬은 다음 두 개다.

| 스킬 | 스킬 ID | 한기 생성량 |
|---|---|---:|
| 빙하진 | `v2c_frostmage_glacier` | 2 |
| 절대영도 | `v2c_cryomancer_absolutezero` | 3 |

이름, 설명, 속성 또는 직업 계보로 한기 스킬을 추론하지 않는다. 원소군주의 빙하 계열 주문식과 향후 추가되는 냉기풍 스킬은 `frostChillGain`을 명시하기 전까지 한기를 만들지 않는다.

빙점 지배는 패시브 메타데이터에 최대 MP 증가와 빙결 강화 값을 명시한다. 엔진이 스킬 ID나 현재 직업을 역으로 추론하지 않게 한다.

## 명중과 상태이상 차단

한기는 적에게 부착하는 전투 상태로 취급한다.

- 스킬이 빗나가면 직접 피해 연동 효과와 함께 한기 생성 요청을 제거한다.
- 보장 회피로 공격이 무효화되면 한기를 생성하지 않는다.
- 정화 결계나 상태이상 1회 차단이 발동하면 해당 시전의 한기 생성만 막는다.
- 상태이상 차단은 빙하진과 절대영도의 직접 피해를 막지 않는다.
- 차단된 한기 증가로는 빙결 피해나 행동 지연이 발생하지 않는다.
- 한기 자체에는 첫 구현에서 별도의 해제나 자연 감소를 두지 않는다.

한기 증가와 빙결 여부는 상태이상 차단 결과가 확정된 뒤 하나의 전이로 계산한다. 빙결 피해를 먼저 계산한 뒤 차단 상황에서 되돌리는 구조는 사용하지 않는다.

## 전투 데이터 흐름

한기 상태와 임계 계산은 별도의 순수 모듈로 분리한다. 이 모듈은 다음 책임만 갖는다.

- 한기 값을 안전한 범위로 정규화
- 현재 한기와 시전당 생성량으로 다음 상태 계산
- 빙결 발동 여부, 소비량과 초과분 소멸 계산
- 빙점 지배 유무에 따른 피해 배율과 지연 비율 선택
- 전투 표시와 로그 문자열에 필요한 스냅샷 생성

전투 처리 순서는 다음과 같다.

1. 공용 시전 해석기가 스킬의 직접 효과와 `frostChillGain` 요청을 만든다.
2. 전투 엔진이 명중, 보장 회피와 상태이상 차단 여부를 판정한다.
3. 한기 요청이 허용되면 순수 모듈로 현재 상태를 전이한다.
4. 임계점에 도달하지 않으면 새 한기 값만 저장한다.
5. 임계점에 도달하면 한기를 0으로 저장하고 빙결 추가타를 기존 직접 마법 피해 경로에 합성한다.
6. 대상이 생존하고 ATB 전투라면 예약된 다음 행동을 30% 또는 40% 뒤로 민다.
7. 한기 증가, 차단 또는 빙결 로그와 자원 스냅샷을 남긴다.

PvE와 PvP 엔진은 같은 순수 전이를 사용한다. 각 엔진에 임계 계산이나 초과분 처리 규칙을 중복 구현하지 않는다.

## 전투 패턴

전투 패턴의 적 상태 조건에 내부 값 `frostChill`, 표시 이름 `한기`를 추가한다. 기존 `atLeast`, `atMost`, `none` 비교를 그대로 사용한다.

예시:

- 적 한기 2 이상일 때 절대영도 사용
- 적 한기 4 이하일 때 빙하진 사용
- 적에게 한기가 없을 때 다른 준비 스킬 사용

한기 조건이 없는 기존 패턴은 변하지 않는다. 저장된 조건에서 알 수 없는 값이나 손상된 수치는 기존 파서 규칙에 따라 안전하게 버리거나 정규화한다.

## 사용자 표시와 전투 로그

전투 기록의 대상 자원 영역에 한기가 1 이상일 때 다음처럼 표시한다.

```text
한기 3/5
```

한기 획득 로그:

```text
한기 +2 (4/5)
```

상태이상 차단 로그는 기존 정화·차단 로그를 재사용하며, 차단된 경우 별도 한기 증가 로그를 남기지 않는다.

빙결 로그:

```text
한기 5스택을 소비해 빙결이 발생했다.
```

빙점 지배가 적용된 경우에도 로그 문장은 같게 유지하고, 피해 및 지연 수치는 스킬 설명과 상세 전투 결과에서 확인하게 한다. 로그 문구를 패시브 유무마다 분기하지 않는다.

HP/MP 바 이벤트와 리플레이에는 한기 값을 선택적 대상 자원 스냅샷으로 전달한다. 스냅샷이 없는 과거 리플레이에서는 한기 줄을 표시하지 않는다.

## 전투 모드 규칙

- PvE ATB: 빙결 피해와 30% 또는 40% 적 행동 지연 적용
- PvP ATB: PvE와 같은 임계점과 지연 비율을 사용하고 기존 PvP 피해 보정을 적용
- 구형 턴 전투: 빙결 추가 피해는 적용하지만 ATB 행동 지연은 적용하지 않음
- 보스: 일반 적과 같은 5스택, 피해와 지연 비율 사용

빙결은 행동 불가가 아니며 기본 지연도 누적 발동 주기를 전제로 낮게 설정했으므로, 첫 구현에서는 보스나 PvP 전용 지연 배율을 추가하지 않는다. 실전 지표에서 문제가 확인되면 모드별 상수를 추가하되 직업 ID 조건으로 조정하지 않는다.

## 호환성과 마이그레이션

- 빙하진과 얼어붙은 심장의 기존 스킬 ID를 유지한다.
- 빙하진의 효과 변경은 모든 기존 장착자에게 적용되는 의도적인 밸런스 변경이다.
- 한기는 전투 중 임시 상태이므로 DB 마이그레이션이 필요하지 않다.
- 한기 필드가 없는 기존 상태는 0으로 처리한다.
- 기존 리플레이는 한기 표시 없이 정상 재생한다.
- 몬스터가 플레이어에게 부여하는 기존 `chillStacks` 동작과 저장 형식은 변경하지 않는다.
- 지각진과 원소군주 주문식의 기존 결과는 바이트 수준 회귀 테스트로 보호한다.

## 테스트 전략

### 카탈로그와 계보

- 빙결술사가 냉기 마법사 숙련도 조건으로 해금되는지 확인한다.
- 직업 차수, 성장 능력치, 직업 보너스와 레거시 매핑을 검증한다.
- 절대영도와 빙점 지배의 수치, 비용, SP와 직업 스킬 매핑을 검증한다.
- 빙하진에서 보호막과 즉시 지연이 제거되고 한기 2가 추가됐는지 확인한다.
- 지각진과 원소군주 주문식 정의가 변하지 않았는지 확인한다.

### 순수 한기 전이

- 빙하진 기준 `0 → 2 → 4 → 빙결 → 0` 순환을 검증한다.
- 절대영도 기준 `0 → 3 → 빙결 → 0` 순환을 검증한다.
- 4에서 2를 더했을 때 초과 1이 이월되지 않는지 확인한다.
- 한 번의 시전에서 빙결이 최대 한 번만 발동하는지 확인한다.
- 누락, 음수, `NaN`과 과도한 값이 안전하게 정규화되는지 확인한다.
- 빙결 피해와 추가 지연 선택이 빙점 지배 유무에 따라 정확한지 확인한다.

### 공용 시전과 방어

- 다단 스킬이어도 시전당 한기가 한 번만 생성되는지 확인한다.
- 빗나감과 보장 회피에서는 한기를 생성하지 않는지 확인한다.
- 정화 결계와 상태이상 1회 차단이 한기만 차단하고 직접 피해는 유지하는지 확인한다.
- 차단된 증가로 임계점에 도달하지 않는지 확인한다.
- 빙결 추가타가 마법 방어, 치명타와 차수 보정을 정확히 한 번씩 적용받는지 확인한다.
- 빙결 추가타가 한기나 추가 빙결을 재귀적으로 만들지 않는지 확인한다.

### PvE·PvP와 공용 장착

- 현재 직업이 빙결술사가 아니어도 장착한 빙하진과 절대영도가 동일하게 작동하는지 확인한다.
- 기본 빙결은 30%, 빙점 지배 장착 시 40%만큼 다음 행동을 미루는지 확인한다.
- PvE와 PvP가 같은 임계 전이 결과를 사용하는지 확인한다.
- 구형 턴 전투에서는 빙결 피해만 적용되고 지연이 무시되는지 확인한다.
- 한기와 기존 몬스터 `chillStacks`가 서로 읽거나 덮어쓰지 않는지 확인한다.

### 패턴·로그·리플레이

- 적 한기 `none`, `atLeast`, `atMost` 패턴 조건을 파싱하고 평가하는지 확인한다.
- 한기 획득, 상태 차단과 빙결 로그가 실제 전이와 일치하는지 확인한다.
- HP/MP 바와 리플레이 스냅샷이 한기 값을 보존하는지 확인한다.
- 한기 스냅샷이 없는 과거 리플레이가 동일하게 재생되는지 확인한다.

## 완료 기준

- 냉기 마법사부터 한기를 쌓아 5스택 자동 빙결을 사용할 수 있다.
- 빙하진은 한기 생성기로, 지각진은 즉시 지연·보호막기로 구분된다.
- 빙결술사는 절대영도와 빙점 지배로 더 빠르고 강한 빙결 순환을 만든다.
- 다른 직업이 냉기 스킬을 장착해도 같은 규칙과 SP 비용으로 작동한다.
- 상태이상 차단, PvE, PvP, 패턴, 로그와 리플레이가 한기 전이를 일관되게 처리한다.
- 기존 몬스터 한기, 지각진, 원소군주와 과거 저장·리플레이에 회귀가 없다.
