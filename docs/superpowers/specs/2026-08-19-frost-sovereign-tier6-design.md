# 빙천제 6차 및 영구동토 설계

## 배경

냉기 단일 계보는 4차 `냉기 마법사`와 5차 `빙결술사`까지 구현되어 있다. `빙하진`은 한기 2, `절대영도`는 한기 3을 쌓고, 한기 5에서 추가 마법 피해와 행동 지연을 주는 빙결이 발동한다. 그러나 빙결술사에서 직접 이어지는 6차 직업은 없어 냉기 누적형 운용을 끝까지 성장시킬 수 없다.

다섯 원소를 모두 다루는 `원소군주 → 태초술사`는 별도 조합 계보로 유지한다. 새 6차는 냉기 하나를 깊게 파며, 새 전장 상태를 추가하기보다 기존 한기 순환을 더 빠르고 강하게 완성한다.

## 목표

- 빙결술사에서 직접 이어지는 6차 직업 `빙천제`를 추가한다.
- 4차 빙하진과 5차 절대영도를 교체하지 않고 계속 장착할 이유를 만든다.
- 6차 공격기는 높은 직접 피해와 한기 4를 제공해 빙결 직전 상태를 만든다.
- 6차 패시브는 빙결 뒤 한기 1을 남겨 순환의 저점을 높이고, 최대 MP·빙결 피해·지연을 강화한다.
- 현재 직업을 검사하지 않는 기존 공용 스킬 장착 원칙을 유지한다.
- PvE와 PvP가 같은 잔류 한기 전이를 사용한다.

## 비목표

- 행동 불가, 기절 또는 행동 건너뛰기형 빙결을 추가하지 않는다.
- 영구 빙판, 지속 피해 장판 또는 별도의 냉기 상태를 추가하지 않는다.
- 냉기 마법사·빙결술사의 기존 수치나 스킬 ID를 다시 변경하지 않는다.
- 원소군주·태초술사 계보 또는 원소 주문식에 한기를 추가하지 않는다.
- 전용 장비, 이미지, 전직 퀘스트 또는 데이터베이스 마이그레이션을 추가하지 않는다.

## 검토한 방향

### 직선 강화형

6차 공격기의 직접 피해와 한기 생성량만 높이고 패시브에는 일반 능력치만 둔다. 구현은 단순하지만 절대영도를 그대로 대체하여 4·5차 계승감이 약하다.

### 순환 완성형

6차 공격기는 한기 4를 만들고, 패시브는 빙결 후 한기 1을 남긴다. 기존 생성기와 같은 자원을 사용하면서도 6차 공격기는 잔류 한기에서 즉시 재빙결할 수 있다. 기존 계보를 가장 직접적으로 강화하므로 이 방향을 채택한다.

### 전장 제어형

지속 빙판이나 반복 지연을 추가한다. 냉기 분위기는 강하지만 새 상태와 엔진 분기를 크게 늘리고, 즉시 지연·방어를 담당하는 대지 계열과 다시 역할이 겹치므로 채택하지 않는다.

## 직업 정의

- 표시 이름: `빙천제`
- 내부 ID: `frostsovereign`
- 직업 차수: 6차
- 선행 직업: `cryomancer`
- 해금 조건: 빙결술사 누적 직업 숙련도 `TIER6_UNLOCK_CUMLEVEL`
- 수행 성장: 지능 3, 정신 3
- 직업 보너스: 지능 28, 정신 12
- 역할: 잔류 한기를 이용해 빙결 간격을 줄이고 강한 빙결 추가타를 반복하는 냉기 마법 공격수

직업 보너스는 같은 마법 6차인 대마도사·법칙술사의 기준값과 맞춘다. 다섯 원소 숙련을 요구하는 태초술사의 더 높은 직업 보너스는 그대로 유지한다.

## 스킬 정의

### 영겁빙옥

- 스킬 ID: `v2c_frostsovereign_eternalprison`
- 분류: 공격 액티브
- 주 능력치: 지능
- 학습 비용: 12,000
- 장착 SP: 10
- 고정 MP 비용: 195
- 원시 발동 확률: 32%
- 재사용 대기시간: 0
- 원시 마법 피해: 지능 계수 3.00 + 고정 피해 760
- 정상 적중 시 한기 4

공용 차수 리밸런싱 뒤 피해는 지능 계수 2.85 + 고정 피해 722, 발동 확률은 45%가 된다. 별도의 즉시 행동 지연은 넣지 않는다. 제어 효과는 한기 5에서 발동하는 빙결로만 얻어 냉기 순환의 조건과 보상을 일치시킨다.

한기 0에서는 4까지만 쌓이고, `영구동토`로 빙결 뒤 한기 1이 남은 상태에서는 다음 정상 적중이 곧바로 빙결로 이어진다. 높은 직접 피해와 빠른 빙결 가능성을 함께 가지므로, 성능 루브릭보다 높은 10 SP를 명시한다.

### 영구동토

- 스킬 ID: `v2c_frostsovereign_permafrost`
- 분류: 패시브
- 주 능력치: 지능
- 학습 비용: 12,000
- 장착 SP: 11
- 최대 MP 16% 증가
- 빙결 추가 피해 35% 증가
- 빙결 행동 지연을 50%로 강화
- 빙결 발동 후 한기 1 잔류

빙결 피해 증가는 빙점 지배의 50%와 가산되어 둘을 함께 장착하면 총 85%가 된다. 행동 지연은 합산하지 않고 가장 높은 값만 적용하므로 빙점 지배의 40% 대신 영구동토의 50%가 적용된다. 잔류 한기도 여러 패시브에서 합산하지 않고 가장 높은 값을 사용한다.

## 잔류 한기 규칙

기존 한기 임계점과 발동 횟수 규칙은 그대로 유지한다.

- 임계점: 5
- 한 시전당 빙결: 최대 1회
- 초과 생성량: 폐기
- 잔류 한기 미장착: 빙결 뒤 0
- 영구동토 장착: 빙결 뒤 1
- 잔류 값 정규화: 0~4의 정수

예시 순환:

| 구성 | 전이 |
|---|---|
| 빙하진만 | `0 → 2 → 4 → 빙결 후 0` |
| 빙하진 + 영구동토 | 첫 순환 `0 → 2 → 4 → 빙결 후 1`, 이후 `1 → 3 → 빙결 후 1` |
| 절대영도 + 영구동토 | `0 → 3 → 빙결 후 1 → 4 → 빙결 후 1` |
| 영겁빙옥 + 영구동토 | `0 → 4 → 빙결 후 1`, 이후 정상 적중마다 `빙결 후 1` |

잔류량을 1로 제한해 절대영도가 빙결 직후 매번 즉시 다시 빙결하는 구조는 피한다. 대신 기존 빙하진은 첫 빙결 이후 3회 적중 주기에서 2회 적중 주기로 개선되고, 6차 공격기는 가장 빠른 순환이라는 명확한 상위 역할을 갖는다.

## 데이터 흐름

패시브 정의에 `freezeRetainStacks`를 추가한다. 장착 패시브 집계에서는 최대값을 취하고 다음 경로로 전달한다.

```text
V2PassiveSkillEffect
  → aggregateEquippedPassives
  → derivePlayerCombatV2PureInput.passiveFreezeRetainStacks
  → PlayerCombat.freezeRetainStacks
  → resolveFrostChillGain(..., { retainStacks })
```

`resolveFrostChillGain`은 임계점 미만에서는 잔류 값을 읽지 않는다. 빙결이 발동했을 때만 정규화한 잔류 값을 다음 한기로 반환한다. PvE·PvP 엔진은 각각 플레이어 전투 수치의 값을 같은 순수 함수에 전달한다.

현재 직업 ID나 스킬 ID를 전투 엔진에서 검사하지 않는다. 영구동토를 배워 장착한 캐릭터라면 어느 직업에 있든 동일한 결과를 얻는다.

## 사용자 표시

- 영겁빙옥 설명: 직접 마법 피해, 발동 확률, MP와 함께 `적중 시 한기 +4` 표시
- 영구동토 설명: 최대 MP, 빙결 피해, 빙결 행동 지연과 함께 `빙결 후 한기 1 잔류` 표시
- 빙결 발동 로그: 기존 문장 유지
- 발동 뒤 자원 스냅샷: 잔류 한기가 있으므로 `한기 1/5` 표시

기존 빙결 로그 문구는 잔류 여부와 무관하게 유지한다. 전투 자원 스냅샷이 실제 다음 상태를 표시하므로 별도 로그 분기는 만들지 않는다.

## 호환성

- 잔류 필드가 없는 과거 캐릭터와 전투 상태는 0으로 처리한다.
- 기존 빙하진·절대영도·빙점 지배의 ID와 동작은 영구동토 미장착 시 그대로다.
- 한기는 전투 중 임시 상태이므로 저장 스키마나 DB 마이그레이션이 필요 없다.
- 기존 리플레이는 새 선택 필드가 없어도 정상 재생된다.
- 원소군주와 태초술사는 별도 진로로 유지되며 해금 조건이나 스킬이 변하지 않는다.

## 테스트 전략

### 카탈로그

- 빙천제가 빙결술사 숙련도 35,000으로 해금되는지 검증한다.
- 수행 성장, 직업 보너스와 레거시 왕복 매핑을 검증한다.
- 두 스킬의 학습 비용, SP, MP, 발동률, 피해와 한기 수치를 검증한다.
- 스킬 설명에 한기 +4와 빙결 후 한기 1 잔류가 표시되는지 검증한다.
- 영구동토 단독 및 빙점 지배 조합의 패시브 집계를 검증한다.

### 순수 전이

- 잔류 미지정은 기존처럼 빙결 뒤 0인지 검증한다.
- 잔류 1은 빙결 뒤 1을 반환하는지 검증한다.
- 음수, 소수, `NaN`과 5 이상의 손상된 잔류 값을 0~4 정수로 정규화하는지 검증한다.
- 큰 한기 생성량도 한 번만 빙결시키고 초과분 대신 잔류 값만 남기는지 검증한다.

### 파생 및 전투

- 영구동토 장착값이 저장 집계에서 `PlayerCombat`까지 전달되는지 검증한다.
- 미장착 또는 0은 선택 필드를 만들지 않는지 검증한다.
- PvE에서 빙결 뒤 한기 1과 자원 스냅샷이 남는지 검증한다.
- PvP에서 동일한 잔류 전이와 50% 행동 지연이 적용되는지 검증한다.
- 영구동토 미장착 PvE·PvP 회귀 테스트가 기존 0 초기화를 계속 보장하는지 확인한다.
