# 길드 토벌전 드롭다운 노출 설계

## 목표

길드 가입자가 메인 내비게이션의 길드 드롭다운에서 길드 토벌전으로 바로 이동할 수 있게 한다.

## 설계

- 길드 토벌전은 시설 해금과 무관한 고정 길드 콘텐츠로 취급한다.
- 길드 가입자에게만 `토벌전` 항목을 노출하며 경로는 `/guild?tab=raid`로 고정한다.
- 메뉴 순서는 `길드`, `토벌전`, 해금된 길드 시설 순으로 유지한다.
- 시설 API 조회가 실패하거나 아직 끝나지 않아도 토벌전 항목은 표시한다.
- 무소속 사용자는 참여할 수 없으므로 기존처럼 `길드` 항목만 표시한다.

## 구현 경계

- `MainTabNav`에 토벌전 전용 메뉴 정의를 추가한다.
- 길드 가입 여부와 해금 시설을 입력받는 순수 메뉴 생성 함수를 만들고 렌더링에서 사용한다.
- 기존 길드 홈의 `raid` 탭, 토벌전 패널, API는 변경하지 않는다.

## 검증

- 길드 가입자의 메뉴에 `{ label: "토벌전", href: "/guild?tab=raid" }`가 포함된다.
- 무소속 사용자의 메뉴에는 토벌전이 포함되지 않는다.
- 해금된 시설이 없어도 길드 가입자는 토벌전을 볼 수 있다.
- 기존 마을·캐릭터 메뉴 테스트와 타입·린트 검사를 통과한다.

## 범위 제외

- 토벌전 규칙, 보상, 공격 횟수 및 서버 API 변경
- 토벌전 알림 배지나 진행 상태 표시
- 길드 드롭다운의 전반적인 시각 개편
