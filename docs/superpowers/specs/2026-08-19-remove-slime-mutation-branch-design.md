# 점액체 변이 계보 제거 설계

## 목표

변이자 1차 계보에서 애매한 콘셉트의 `점액체`를 제거하고 `수인·골렘` 두 갈래만 유지한다.

## 삭제 범위

- 직업 `slime`과 변이자 숙련도 1,000 해금·로드맵·탐색기 연결
- 스킬 `v2c_slime_split`, `v2c_slime_barrage`, `v2c_slime_fusioncrash`
- 스킬 정의의 `splitGain`, `splitAuxHitPctPerStack`, `splitConsumePctPerStack`
- PvE/PvP 전투 상태의 `splitBodies`와 생성·보조타·융합·로그 처리
- 전투 패턴 자원 `split`, 패턴 편집기와 아레나 라벨
- 전투 화면의 분열체 표시와 관련 회귀 테스트

## 유지 범위

- `slime_chunk`, `slime_core` 재료
- 슬라임 계열 몬스터와 몬스터 태그·이미지
- 변이자, 수인, 골렘 및 중량 자원
- 기존 직업과 무관하게 획득한 변이 스킬을 장착하는 수집형 원칙

## 데이터 호환성

점액체 기능은 운영에 배포되지 않았으므로 과거 점액체 직업·스킬 저장값을 위한 별도 마이그레이션이나 폐기 ID는 두지 않는다. 기존 범용 파서는 알 수 없는 직업·스킬·패턴 값을 현재 방식대로 거부하거나 걸러낸다.

## 검증

- 직업 카탈로그와 로드맵에 수인·골렘만 남는지 검증한다.
- 스킬 카탈로그와 설명에서 점액체 스킬·분열체 필드가 사라지는지 검증한다.
- PvE/PvP 상태와 패턴/UI에서 분열체가 사라지고 중량은 그대로 동작하는지 검증한다.
- 전체 테스트, 타입 검사, 린트, 빌드를 실행한다.

## 비범위

- 점액체를 대체할 세 번째 변이 계보 설계
- 수인·골렘 밸런스 변경
- 배포 또는 점검 모드 변경
