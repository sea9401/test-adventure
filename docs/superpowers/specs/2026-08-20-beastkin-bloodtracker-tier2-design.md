# 대체된 설계 — 수인 2차 직업 `혈흔추적자`

> **상태: 대체됨. 구현하지 않는다.** 2026-08-20 합의로 `혈흔추적자`는 4차로 이동했고,
> 수인 계보를 6차까지 다시 설계했다. 최신 명세는
> `docs/superpowers/specs/2026-08-20-beastkin-tier2-tier6-design.md`다.

## 결정

수인의 다음 차수는 두 갈래로 나누지 않고 단일 Tier 2 직업 `혈흔추적자`로 확장한다.

- 직업 ID: `bloodtracker`
- 표시명: `혈흔추적자`
- 선행 직업: `beastkin` (`수인`)
- 핵심 역할: 출혈을 소비하지 않고 5·10중첩 구간을 오래 유지하는 지속 물리 공격수
- 신규 스킬: 직접 물리 공격 `상처 덧내기`, 패시브 `집요한 추적`

수집형 스킬 구조에서는 같은 출혈을 쓰는 두 분기가 서로의 좋은 스킬만 가져가며 경계가
흐려질 가능성이 크다. 따라서 수인 계보는 단일 갈래로 두고, 다음 차수도 `출혈 누적 → 유지 →
고중첩 보상`이라는 한 전투 흐름을 깊게 만든다.

## 목표

- 기존 수인의 출혈 누적과 `피 냄새`를 자연스럽게 이어받는다.
- 출혈 5중첩에서 추적이 시작되고 10중첩에서 사냥이 최고조에 이르는 두 단계 체감을 만든다.
- 최대 중첩에 도달한 뒤에도 출혈 스킬을 계속 사용할 이유를 제공한다.
- 배운 스킬을 다른 직업에서도 장착하는 변이 계열의 수집형 원칙을 유지한다.
- PvE와 PvP가 같은 핵심 규칙과 계산 헬퍼를 사용한다.

## 선택하지 않은 방향

### 출혈 소비·폭발

출혈을 쌓은 뒤 소비해 큰 피해를 주는 방식은 독술 계보의 회수 구조와 겹친다. Tier 6 장비에도
출혈을 폭발시키고 일부 중첩을 남기는 효과가 이미 있으므로 기본 수인 계보에는 넣지 않는다.

### 저체력 야수화

자신의 HP가 낮을수록 강해지는 변신·광폭화는 광전사 계보와 역할이 겹친다. 혈흔추적자는 자신의
체력보다 대상에게 남긴 출혈을 읽는다.

### 최대 중첩 추가타

10중첩에서 별도 추가타를 발생시키는 안은 다단 스킬과 온힛 효과를 결합했을 때 발동 횟수와
피해 예산이 불안정해진다. 최고조 보상은 추가타 대신 직접 물리 스킬의 방어 관통으로 정한다.

## 직업 성장

- Tier: 2
- 수련 성향: `STR 2 / DEX 2`
- 직업 보너스: `STR +12 / DEX +6`
- 해금: 수인 숙련도 `1,000`

해금 임계는 일반 2차 직업과 같은 `TIER2_UNLOCK_CUMLEVEL`을 사용한다. 직업 보너스는 같은
차수의 물리 공격 직업 예산 안에서 힘을 주축으로 두고, 추적자의 속도·명중 성격을 민첩으로
보조한다. 별도 아이템이나 퀘스트 조건은 추가하지 않는다.

계보는 다음과 같다.

```text
변이자
└─ 수인
   └─ 혈흔추적자
```

## 핵심 전투 흐름

1. `찢어발기기`와 `연속 할퀴기` 등으로 출혈을 쌓는다.
2. 5중첩부터 `추적` 보상으로 직접 물리 스킬의 명중과 행동 템포가 좋아진다.
3. `상처 덧내기`로 출혈을 한 겹 더 쌓고 남은 지속 횟수를 늘려 추적 구간을 유지한다.
4. 10중첩에서는 기존 `피 냄새`의 최대 피해 보너스에 `사냥의 절정` 방어 관통이 더해진다.
5. 출혈이 끝나면 두 단계 보상도 즉시 사라지므로 계속 공격해 흔적을 놓치지 않아야 한다.

혈흔추적자는 출혈을 빨리 폭발시키는 직업이 아니라, 완성한 출혈을 끊기지 않게 붙들고 긴
전투에서 안정적인 직접 피해를 내는 직업이다.

## 액티브 — 상처 덧내기

- 스킬 ID: `v2c_bloodtracker_reopen`
- 분류: Tier 2 STR 단일 직접 물리 공격
- 실제 MP 비용: 59 (현행 Tier 2 비캐스터 공격기 루브릭)
- 재사용 대기시간: 0
- 자동 발동 확률: 30%
- 카탈로그 피해 기준: `STR 계수 1.10 / 레거시 flat 150`
- 상태 효과: 플레이어 출혈 1중첩

MP는 `fixedMpCost` 예외를 두지 않고 현행 `v2SkillMpCostValue` 계산을 따른다. 카탈로그의
`baseFlat`은 기존 플레이어 직접 피해 공식에서 사용하지 않는 호환용 값이며, 실제 피해는 Tier 2
순수 물리 스킬 공식과 STR 계수로 계산한다.

명중하면 기존 플레이어 출혈 병합 규칙에 따라 출혈 1중첩을 더한다. 병합 뒤 출혈이 5중첩
이상이면 남은 지속 횟수를 4회로 갱신한다.

- 출혈이 없던 대상에게는 1중첩과 기본 지속 3회를 적용한다.
- 병합 결과가 1~4중첩이면 기존과 같이 지속 3회로 갱신한다.
- 병합 결과가 5~10중첩이면 지속 4회로 갱신한다.
- 10중첩에서는 추가 중첩이 상한에 막혀도 지속 4회 갱신은 적용한다.
- 빗나가거나 상태이상 적용이 차단되면 중첩과 지속 횟수 모두 바뀌지 않는다.
- 출혈을 소비하거나 즉시 피해로 바꾸지 않는다.

일반 출혈의 최대 지속은 계속 3회다. 4회 유지는 `상처 덧내기`가 정상적으로 출혈을 적용한
경우에만 허용하며, 전역 출혈 프리셋은 변경하지 않는다. 현재 DoT 병합 규칙은 같은 태그를
재부여하면 새 효과의 지속 횟수로 갱신하므로, 다른 일반 출혈 스킬을 사용하면 남아 있던 4회가
다시 3회가 된다. 이후 `상처 덧내기`를 적중시켜야 4회로 되돌릴 수 있다.

## 패시브 — 집요한 추적

- 스킬 ID: `v2c_bloodtracker_relentless`
- 분류: Tier 2 패시브
- 판정 대상: 현재 공격 대상에게 활성화된 출혈 중첩

패시브를 장착하면 출혈 중첩에 따라 다음 두 단계 효과를 얻는다.

### 출혈 5중첩 이상 — 추적

- 직접 물리 스킬 적중도 `+12%`
- 직접 물리 스킬을 정상 시전한 뒤 다음 행동까지의 대기시간 `8%` 단축

행동 가속은 스킬 발동과 MP 지불이 성립하면 적용하며, 해당 공격의 명중 여부에는 의존하지
않는다. 기본 공격, 마법·회복·버프 스킬, 지속 피해, 반사와 장비 추가타는 적중 보정과 행동
가속의 대상이 아니다.

### 출혈 10중첩 — 사냥의 절정

- `추적` 효과를 계속 유지한다.
- 직접 물리 스킬이 대상의 물리 방어를 `15%p` 추가 관통한다.

관통은 기존 스킬·장비 관통과 합산한 뒤 현재 전투의 관통 상한을 적용한다. 기본 공격, 출혈
틱, 반사, 고정 피해와 마법 피해에는 적용하지 않는다. PvE와 PvP의 기본 수치는 동일하게 둔다.

## 중첩 판정과 계산 순서

`집요한 추적`은 새 전투 자원이나 저장형 버프를 만들지 않고 대상의 활성 출혈에서 매번 파생한다.

1. 행동 시작 시 대상의 활성 출혈 중첩과 남은 횟수를 읽는다.
2. 출혈이 없거나 남은 횟수가 0이면 모든 단계 보너스는 0이다.
3. 시전 전 중첩이 5 이상이면 이번 직접 물리 스킬에 적중 보정을 적용한다.
4. 시전 전 중첩이 10이면 이번 직접 물리 스킬에 추가 관통을 적용한다.
5. 명중과 직접 피해를 계산한다. `피 냄새`도 이 시점의 시전 전 중첩을 사용한다.
6. 명중했다면 출혈 중첩과 지속 횟수 변경을 적용한다.
7. 시전 전 중첩이 5 이상이고 직접 물리 스킬 시전이 성립했다면 다음 행동 대기시간을 8%
   줄인다.

따라서 9중첩 대상에게 `상처 덧내기`를 사용해 10중첩을 만든 그 타격은 최고조 관통을 받지
않는다. 이후 직접 물리 스킬부터 관통이 적용된다. 반대로 행동 시작 전에 출혈이 만료되면
직전 행동에서 최고조였더라도 보너스를 받지 않는다.

## 수집형 상호작용

- 두 신규 스킬은 현재 직업이 `bloodtracker`인지 검사하지 않는다.
- 다른 직업과 장비가 만든 플레이어 출혈도 중첩 판정에 포함한다.
- 다른 직업도 `집요한 추적`을 장착하고 출혈을 준비하면 두 단계 보상을 받을 수 있다.
- 보상 범위를 직접 물리 스킬로 제한해 출혈 장비 하나만 사용한 마법·회복 빌드가 행동 가속을
  가져가는 상황은 막는다.
- `피 냄새`와 `집요한 추적`은 함께 장착할 수 있다. 전자는 중첩마다 직접 피해를 높이고,
  후자는 5·10중첩의 템포와 관통을 담당한다.
- Tier 6 출혈 폭발 장비가 중첩을 낮추면 낮아진 중첩을 즉시 기준으로 단계를 다시 판정한다.

## 데이터와 전투 구현 경계

- 직업 카탈로그와 직업 ID 유니온에 `bloodtracker`를 추가한다.
- 선행 숙련도 판정은 표시용 숙련도와 같은 `cumLevelForJob` 규칙을 사용한다. 수인은 Tier 1이지만
  변이자 직군 아래의 전문 직업이므로 `groups.mutant`가 아니라 `jobCumLevel.beastkin` 1,000을
  요구한다. 변이자나 골렘만 수련해서 혈흔추적자가 열려서는 안 된다.
- 직업 계보, 직업 숙련도·해금 판정, 구형 class/spec 호환 매핑, 직업 탐색기와 로드맵이
  `beastkin → bloodtracker` 연결을 인식한다.
- 공용 스킬 ID와 직업별 스킬 매핑에 신규 스킬 두 개를 추가한다.
- `상처 덧내기`에는 일반 출혈 프리셋을 전역 수정하지 않는 전용 지속 갱신 메타데이터를 둔다.
- `집요한 추적`의 중첩별 적중·행동 가속·관통 계산은 순수 함수로 만들고 PvE·PvP 어댑터가
  공유한다.
- 전투 저장 데이터와 DB 스키마에는 새 필드를 저장하지 않는다. 장착 패시브의 고정 수치와
  현재 대상 출혈로 매 행동 파생한다.
- 대상 출혈이 없거나 패시브를 장착하지 않은 기존 전투 경로는 수치와 행동 간격이 바뀌지
  않아야 한다.

## UI와 전투 로그

- 직업 탐색기에서 수인 아래에 혈흔추적자 카드와 연결선을 표시한다.
- 잠긴 카드에는 `수인 숙련도 1,000`을 표시한다.
- 스킬 상세 칩은 다음 핵심 수치를 그대로 노출한다.
  - `출혈 +1 (최대 10)`
  - `출혈 5중첩 이상: 지속 4회로 갱신`
  - `출혈 5+: 물리 스킬 적중 +12% · 다음 행동 8% 가속`
  - `출혈 10: 물리 스킬 방어 관통 +15%p`
- 적 출혈 표시에 현재 단계 라벨을 파생해 보여준다.
  - 0~4중첩: 별도 라벨 없음
  - 5~9중첩: `추적`
  - 10중첩: `사냥의 절정`
- `상처 덧내기`가 4회 지속을 만들면 기존 출혈 적용 로그에 남은 지속 횟수를 포함한다. 단계
  라벨은 화면에서 파생하므로 매 행동마다 별도 전투 로그를 반복하지 않는다.
- 새 카드나 패널이 필요하면 기존 불투명 표면과 `SURFACE_CARD`·`SURFACE_INSET`을 재사용한다.

## 밸런스 안전장치

- 한 번에 부여하는 출혈은 기존 상위 수인 원칙대로 1중첩이며 2중첩을 넘지 않는다.
- 4회 지속은 5중첩 이상에서만 열리고 출혈 피해 계수나 10중첩 상한은 올리지 않는다.
- `피 냄새`의 중첩당 2%, 최대 20%는 변경하지 않는다.
- 단계 보너스는 직접 물리 스킬에만 적용해 평타·마법·지속 피해와의 범용 중첩을 제한한다.
- 행동 가속은 여러 `집요한 추적`을 중복 장착해 합산할 수 없으며 기존 행동 간격 하한을
  우회하지 않는다.
- 관통은 기존 관통 상한을 우회하지 않고 방어 감소·고정 방어 감산과 별도 순서를 만들지 않는다.
- PvP에서 10중첩 도달 후 유지 시간이 과도한지는 구현 단계의 장기전 시뮬레이션으로 확인하되,
  PvP 전용 수치를 먼저 만들지는 않는다.

## 검증

- 수인 숙련도 999에서는 잠기고 1,000에서 혈흔추적자가 해금되는지 검사한다.
- 변이자 직군 누적 숙련도만 높거나 골렘 직업 숙련도만 높을 때는 해금되지 않는지 검사한다.
- 직업 탐색기와 로드맵이 `변이자 → 수인 → 혈흔추적자` 단일 계보를 표시하는지 검사한다.
- `상처 덧내기`가 출혈 없음에서 1중첩·3회, 병합 결과 4중첩에서 3회, 5중첩에서 4회,
  10중첩에서 10중첩·4회를 만드는지 검사한다.
- 빗나감과 상태이상 차단 시 중첩·지속 횟수가 변하지 않는지 검사한다.
- 시전 전 4·5·9·10중첩에서 적중, 행동 가속과 관통 단계가 정확히 갈리는지 검사한다.
- 9→10중첩을 만든 현재 타격에는 최고조 관통이 없고 다음 물리 스킬부터 적용되는지 검사한다.
- 기본 공격, 마법·회복·버프, 출혈 틱, 반사와 장비 추가타에는 단계 보너스가 적용되지 않는지
  검사한다.
- `피 냄새`와 함께 장착했을 때 시전 전 중첩 기준 직접 피해 보너스와 단계 보너스가 각각 한 번만
  적용되는지 검사한다.
- PvE와 PvP에서 같은 중첩 판정 헬퍼를 사용하고 패시브 미장착 경로가 회귀하지 않는지 검사한다.
- 출혈 10중첩 상한, 일반 출혈 3회 지속, 플레이어 출혈 계수 0.45와 몬스터 출혈 계수 0.12가
  유지되는지 검사한다.
