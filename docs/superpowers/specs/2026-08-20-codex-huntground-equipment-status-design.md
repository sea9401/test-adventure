# 모험의 서 사냥터 장비 도감 상태 표시 설계

## 배경

모험의 서의 사냥터 탭은 지역별 일반·세트·유니크 장비 드랍 목록을 보여 주지만,
각 장비가 장비 도감에 등록됐는지는 표시하지 않는다. 이용자는 장비 탭과 사냥터 탭을
오가며 남은 장비를 직접 대조해야 한다.

## 목표

- 각 사냥터에서 장비 도감 등록 진행률을 바로 확인할 수 있다.
- 장비마다 등록 여부를 텍스트와 아이콘으로 구분할 수 있다.
- 기존 장비 상세 보기와 드랍 정보는 그대로 유지한다.
- 별도 API나 DB 변경 없이 현재 게임 상태 응답을 재사용한다.

## 범위

### 포함

- 모험의 서 `사냥터` 탭의 일반·세트·유니크 장비
- 사냥터별 `도감 등록 N/M` 요약
- 장비 칩의 `등록` 또는 `미등록` 상태
- 모바일, 라이트 모드, 다크 모드 표시
- 등록 ID 파싱과 사냥터별 집계에 대한 회귀 테스트

### 제외

- 사냥터 목록 필터 또는 미등록 장비만 보기
- 장비 도감 등록 행동
- 재료, 어보, 제작 장비 등 다른 도감의 상태 표시 변경
- API, DB 스키마, 도감 등록 규칙 변경

## 데이터 흐름

`GameStateProvider`가 `GET /api/v2/me/state` 응답의
`equipmentCodex.registeredIds`로 채우는 장비 도감 전용 컨텍스트를 사용한다. 장비 탭에서
등록이 완료될 때도 같은 컨텍스트가 갱신되므로 사냥터 탭으로 돌아오면 최신 상태가 즉시
반영된다.

1. 컨텍스트의 `loaded`가 참이면 정규화된 `registeredIds` 집합을 사용한다.
2. 컨텍스트가 없거나 `loaded`가 거짓이면 상태를 `unavailable`로 둔다.
3. 사냥터의 일반·세트·유니크 ID를 합쳐 중복을 제거한다.
4. 고유 ID 중 등록 ID 집합에 포함된 수를 `N`, 전체 고유 ID 수를 `M`으로 계산한다.

장비 도감 상태를 알 수 없는 경우 모든 장비를 미등록으로 간주하지 않는다. 기존 장비
목록과 상세 보기는 유지하고 도감 상태 및 진행률만 숨긴다.

## UI

### 사냥터 요약

장비 드랍 제목 영역에 `도감 등록 N/M` 배지를 표시한다. `N === M`이고 `M > 0`이면
완료 상태가 드러나는 체크 아이콘과 `도감 완료 N/M` 문구를 사용한다. 장비가 없는
사냥터에는 배지를 표시하지 않는다.

### 장비 칩

- 등록 장비: 체크 아이콘과 `등록` 문구를 표시한다.
- 미등록 장비: `미등록` 문구를 표시한다.
- 일반·세트·유니크의 기존 색상 체계는 유지한다.
- 색상에만 의존하지 않고 보이는 문구와 접근 가능한 이름에 상태를 포함한다.
- 상태 영역은 장비 상세 열기 버튼 안에 포함하며 기존 클릭 동작을 바꾸지 않는다.

카드와 중첩 표면은 기존 `Card`와 `SURFACE_INSET`을 유지한다. 배경 이미지가 비치거나
잠긴 상태처럼 카드 전체 투명도를 낮추는 표현은 사용하지 않는다.

## 코드 경계

- 순수 집계 함수는 장비 ID 목록과 등록 ID 집합을 받아 고유 전체 수와 등록 수를
  반환한다.
- `DropChip`은 등록 상태를 선택적으로 받는다. 상태를 알 수 없을 때는 현재 UI와 같은
  장비명만 렌더링한다.
- `V2CodexView`는 장비 도감 컨텍스트 구독과 사냥터별 집계를 담당한다.

이 경계로 집계 규칙을 React 렌더링과 분리해 중복 제거 및 완료 판정을 독립적으로
검증할 수 있게 한다.

## 오류 처리

- `/api/v2/me/state` 요청 실패 또는 도감 컨텍스트 미로딩: 현재처럼 화면을 유지하고 도감
  상태 표시만 생략한다.
- 카탈로그에 없는 장비 ID: 기존 방어 동작을 유지하고 집계에서는 ID 하나로 센다.
- 중복 ID: 같은 사냥터의 진행률 분모와 분자에서 한 번만 센다.

## 테스트

- 일반·세트·유니크를 합친 고유 장비 집계
- 중복 장비 ID 제거
- 일부 등록, 전체 등록, 등록 0개 판정
- 등록 상태가 준비된 장비 칩의 `등록`·`미등록` 문구
- 상태를 알 수 없을 때 잘못된 `미등록` 문구를 표시하지 않음
- 기존 장비 분류, 드랍 설명, 상세 보기 동작의 회귀 없음

## 완료 기준

- 이용자가 사냥터 카드만 보고 해당 지역의 장비 도감 완성 여부와 남은 장비를 구분한다.
- 장비 도감 상태를 불러오지 못한 경우 오정보가 표시되지 않는다.
- API와 DB 변경 없이 기존 상태 응답으로 동작한다.
- 관련 회귀 테스트, 타입 검사, 린트, 프로덕션 빌드가 통과한다.
