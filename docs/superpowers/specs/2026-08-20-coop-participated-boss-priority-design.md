# 협동 보스 참여 목록 우선 표시 설계

## 목표

다른 모험가가 소환한 진행 중 협동 보스 가운데 현재 사용자가 피해를 기록한 보스를 일반 길드·전체 공개 보스보다 위에서 바로 찾을 수 있게 한다.

## 설계

- 기존 `내가 소환한 보스` 구역은 첫 번째로 유지한다. 본인 소환은 공개 범위 관리 책임이 있어 기존 우선순위를 보존한다.
- 다른 사람의 세션 중 `myDamage > 0`인 항목을 조건부 `내가 참여한 보스` 구역으로 모은다.
- 참여 구역은 본인 소환 구역 다음, 길드·전체 공개 구역보다 앞에 둔다.
- 참여 구역에 들어간 세션은 길드·전체 공개 구역에서 제외해 한 번만 표시한다.
- 참여 세션이 없으면 참여 구역 자체를 만들지 않아 빈 카드가 늘어나지 않게 한다.
- 각 구역 안에서는 API가 제공하는 기존 순서를 유지한다.

## 데이터와 범위

목록 API가 이미 각 세션의 `myDamage`를 제공하므로 서버 쿼리, 응답 타입, DB 스키마는 바꾸지 않는다. API의 기존 공개 범위 필터를 통과한 세션만 클라이언트 분류 함수에 들어오므로 접근 권한에도 변화가 없다.

## 검증

- 길드 공개와 전체 공개 참여 세션이 모두 참여 구역으로 이동하는지 확인한다.
- 참여 세션이 기존 공개 구역에 중복되지 않는지 확인한다.
- 참여 기록이 없을 때 기존 세 구역 구조가 유지되는지 확인한다.
