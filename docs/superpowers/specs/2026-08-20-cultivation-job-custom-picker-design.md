# 수행 직업 커스텀 선택기 설계

## 목표

iPhone 네이티브 선택 화면에서 직업명만 보여 수행 상승치를 비교할 수 없는 문제를 해결한다. 모든 플랫폼에서 직업명과 실제 수행 상승치를 함께 보여 주는 게임 내부 선택기를 제공한다.

## 화면과 동작

- 기존 `<select>`를 선택 직업명과 수행 상승치를 두 줄로 보여 주는 버튼으로 교체한다.
- 버튼을 누르면 모바일에서는 하단 시트, 넓은 화면에서는 중앙 대화상자로 직업 목록을 연다.
- 목록의 각 항목은 직업명과 `summary` 수행 상승치를 함께 표시하고 현재 임시 선택을 강조한다.
- 항목을 누르면 임시 선택만 바뀌며 `선택 완료`를 눌러야 실제 수행 대상이 변경된다.
- 닫기, 바깥 영역 클릭, Esc는 실제 선택을 바꾸지 않는다.
- 수행 중이거나 선택 가능한 직업이 없으면 선택기 진입을 비활성화한다.

## 접근성과 표면

- 여는 버튼은 `aria-haspopup="dialog"`와 `aria-expanded`를 제공한다.
- 대화상자는 제목이 연결된 `role="dialog"`, 목록은 `radiogroup`, 항목은 `radio` 의미를 제공한다.
- 기존 `useModalA11y`와 `useEscapeKey`를 사용해 포커스와 키보드 닫기를 처리한다.
- 최상위 패널과 항목은 `SURFACE_CARD`, `SURFACE_INSET`, `SURFACE_ACCENT`를 사용해 라이트·다크 모드 모두 불투명하게 유지한다.
- 모바일 하단에는 `safe-area-inset-bottom`을 반영한다.

## 데이터와 범위

`visitedCultivationJobOptions`가 이미 산출하는 `{ id, name, summary }`만 사용한다. 수행 계산, API, 저장 데이터, 밸런스는 변경하지 않는다.

## 검증

- 닫힌 선택기가 선택 직업명과 상승치를 함께 표시하고 네이티브 `<select>`를 렌더하지 않는지 확인한다.
- 열린 목록이 모든 직업명·상승치, 현재 선택 상태, 취소·확정 동작 요소와 대화상자 의미를 제공하는지 확인한다.
- 기존 방문 직업 필터와 수행 요청 테스트가 계속 통과하는지 확인한다.
