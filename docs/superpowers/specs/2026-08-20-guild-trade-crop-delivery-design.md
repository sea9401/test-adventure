# 길드 교역소 농작물 납품 개선 설계

## 배경

길드 교역소 계약 목표는 길드원 수에 따라 모든 품목에 같은 점수로 적용된다. 그러나 현재 농작물은 성장 시간과 해금 단계에 관계없이 모두 5개당 1점이다. 8인 길드의 110점 계약은 밀과 16시간 작물인 카카오에 똑같이 550개를 요구하므로 후반 농작물 계약이 다른 채집 계약보다 지나치게 어렵다.

납품 UI도 1묶음과 가능한 최대 묶음만 제공한다. 최대 납품을 원하지 않는 이용자가 여러 번 반복해서 눌러야 하는 불편이 있다.

## 목표

- 초반 농작물 계약의 현재 난이도는 대체로 유지한다.
- 성장 시간이 긴 후반 농작물일수록 필요한 실물 수량을 크게 줄인다.
- 한 번에 최대 10점을 안전하게 납품하는 빠른 동작을 추가한다.
- 기존 계약 점수, 보상, 개인 납품 한도와 서버 검증 규칙은 유지한다.

## 농작물 환산율

목재와 광석의 등급별 묶음 규칙과 같은 방식으로 농작물에 명시적인 환산표를 둔다.

| 작물 | 기존 | 변경 | 110점에 필요한 수량 |
| --- | ---: | ---: | ---: |
| 밀 | 5개당 1점 | 5개당 1점 | 550개 |
| 허브 | 5개당 1점 | 4개당 1점 | 440개 |
| 옥수수 | 5개당 1점 | 3개당 1점 | 330개 |
| 토마토 | 5개당 1점 | 3개당 1점 | 330개 |
| 딸기 | 5개당 1점 | 2개당 1점 | 220개 |
| 감자 | 5개당 1점 | 2개당 1점 | 220개 |
| 양파 | 5개당 1점 | 1개당 1점 | 110개 |
| 쌀 | 5개당 1점 | 1개당 1점 | 110개 |
| 콩 | 5개당 1점 | 1개당 1점 | 110개 |
| 사탕수수 | 5개당 1점 | 1개당 2점 | 55개 |
| 카카오 | 5개당 1점 | 1개당 2점 | 55개 |

환산율은 작물 정의에서 자동 계산하지 않고 교역 데이터에 명시한다. 성장 시간이나 수확량을 다른 목적으로 조정해도 교역 경제가 의도치 않게 함께 변하지 않게 하기 위해서다. 이미 생성된 주간 계약도 품목 ID로 현재 교역 데이터를 조회하므로 배포 후 같은 환산율을 적용받는다.

## 최대 10점 납품

계약 카드의 기존 두 버튼 사이에 빠른 납품 버튼을 추가한다. 버튼이 보내는 묶음 수는 다음 값을 넘지 않는다.

- 10점을 넘지 않는 완전한 묶음 수
- 현재 보유량, 계약 잔여 점수, 개인 주간 한도를 반영한 `maxBatches`

계산식은 `min(maxBatches, max(1, floor(10 / pointValue)))`이다. 실제 점수는 `묶음 수 × 묶음당 점수`로 표시한다. 따라서 1점·2점 품목은 10점, 3점 품목은 9점, 8점 품목은 8점으로 표시된다. 남은 납품 가능량이 더 적다면 그 값에 맞춰 버튼 문구도 줄어든다.

클라이언트는 기존 `batches` 요청 형식을 그대로 사용한다. 서버는 현재처럼 계약 존재 여부, 완결 여부, 보유량, 남은 목표, 개인 한도와 요청 상한을 다시 검증하므로 클라이언트 계산을 신뢰하지 않는다.

## UI와 접근성

- 버튼은 `1묶음 납품`, 계산된 `N점 납품`, `최대 N묶음` 순서로 배치한다.
- 기존 불투명 카드 표면과 비활성 버튼 표현을 유지한다.
- 요청 처리 중이거나 납품할 수 없을 때 세 버튼 모두 비활성화한다.
- 빠른 납품량이 최대 납품량과 같아도 동작을 숨기지 않는다. 이용자가 예상 가능한 고정 위치에서 10점 단위 동작을 찾을 수 있게 한다.

## 테스트

- 교역 데이터 테스트에서 모든 농작물의 묶음 크기와 점수가 위 표와 일치하는지 검증한다.
- 빠른 납품 계산 테스트에서 일반 1점 품목, 나누어떨어지지 않는 3점·8점 품목, 10점보다 작은 `maxBatches`를 검증한다.
- 기존 API 테스트로 납품 요청의 서버 측 보유량·목표·한도 검증이 유지되는지 확인한다.
- 관련 단위 테스트, 타입 검사와 린트를 실행한다.

## 제외 범위

- 길드원의 농업 스킬이나 씨앗 보유량에 따라 계약 후보를 동적으로 제한하지 않는다.
- 계약 목표 및 완료 보상, 개인 한도, 씨앗 공급량은 변경하지 않는다.
- 배포와 점검 모드 변경은 수행하지 않는다.
