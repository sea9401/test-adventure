# 도감 숙련도 점수 호환성 수정 설계

## 문제

도감 숙련도 v1은 카테고리별 항목 수로 `scoreWeightMilli`를 계산한다. 7차 직업 4종이 추가되면서 직업 수가 134개에서 138개로 늘었고, 이미 저장된 직업 점수의 가중치 3,392가 런타임에서 3,294로 재해석됐다. 잠긴 진행 행의 점수 검사가 실패해 해당 사용자의 사냥 트랜잭션이 500으로 롤백된다.

## 결정

- v1의 카테고리별 점수 기준 항목 수를 출시 당시 값으로 고정한다.
- 직업 도감의 권위 가중치는 기존 사용자 점수를 보존하는 3,392로 유지한다.
- 7차 배포 직후 잠깐 생성될 수 있었던 3,294 점수는 명시적인 호환 가중치로만 인정한다.
- 호환 점수를 읽으면 진행 행과 사용자 요약 점수를 같은 트랜잭션에서 권위 가중치로 정규화한 뒤 원래 게임 기록을 적용한다.
- 정의에 등록되지 않은 임의 점수, 잘못된 등급, 인장, 항목 식별자는 계속 실패 처리한다.

## 테스트

- 운영에서 실패한 직업 전설 점수 74,624가 정상적으로 다음 기록을 처리하는지 검증한다.
- 호환 가중치 행이 진행 점수와 요약 점수를 함께 정규화하는지 검증한다.
- 임의 점수 불일치는 기존처럼 저장 없이 차단되는지 유지한다.
- 직업 항목 증가 뒤에도 v1 직업 점수 가중치와 기존 행 점수가 유지되는지 검증한다.

## 운영 경계

이 변경은 코드와 자동 복구 경로만 제공한다. 운영 배포, 기능 플래그 변경, 직접 DB 수정은 별도 승인 없이는 수행하지 않는다.
