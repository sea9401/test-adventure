# 위험 해역 낚시 목표·피드백·거대어 화면 개선 설계

## 배경

위험 해역 낚시는 행동 대응, 누적 위험도, 안전 귀환, 교환 가능한 어획물, 공용 거대어
기여와 증표 보상까지 갖추고 있다. 그러나 현재 화면은 조작 뒤 API 응답을 버리고 최신
상태만 다시 불러온다. 조우가 끝나면 전투 화면이 즉시 사라져 성공·실패와 획득 내용을
알기 어렵고, 출항 전에도 어획물과 거대어가 어디에 쓰이는지 한눈에 보이지 않는다.

거대어 개인 시도에서는 공용 거대어 이미지와 현황 아래에 동일한 장면과 거대어를 포함한
개인 조우 패널을 다시 렌더한다. 사용자는 화면이 전환되거나 분할된 것이 아니라 같은 화면이
아래로 복제됐다고 느끼게 된다.

## 목표

- 출항 전에 `어획 → 화물 → 안전 귀환 → 교환·거래` 보상 흐름을 바로 이해하게 한다.
- 위험도 높은 영웅·전설 어획이 거대어 발견으로 이어지고, 거대어 개인 성공이 보상 자격과
  기여를 만든다는 목적을 설명한다.
- 모든 개인 조작 뒤 대응 판정과 장력·어체력·거리 변화를 즉시 표시한다.
- 어획 성공, 줄 끊김, 바늘 빠짐, 시간 초과 결과를 다음 투척 전까지 유지한다.
- 안전 귀환과 사고 귀환, 거대어 개인 시도 성공·실패, 거대어 보상 수령 결과를 유지한다.
- 거대어 개인 시도 중에는 이미지가 하나뿐인 단일 전투 화면을 제공한다.

## 비목표

- 어종 확률, 조작 수치, 위험도, 사고 확률, 보상 수량을 변경하지 않는다.
- 새 화폐, 장비 강화, 일일 과제나 별도 성장 트리를 추가하지 않는다.
- 신규 이미지나 사운드 자산을 추가하지 않는다.
- 배포와 점검 모드 변경은 포함하지 않는다.

## 화면 구조

### 목표와 보상

개인 조우가 진행 중이지 않을 때 위험 해역 상단에 세 단계 보상 흐름을 표시한다.

1. 어획 성공: 낚시 경험치·코인·도감은 즉시 획득한다.
2. 안전 귀환: 화물이 거래 가능한 어획물로 확정되며 위험 해역 교환이나 거래소에 쓴다.
3. 거대어: 위험도 4 이상의 영웅·전설 어획에서 발견할 수 있고, 개인 시도 성공으로
   보상 자격을 얻어 처치 후 낚시 코인과 증표를 받는다.

상점 이동이 가능한 화면에서는 `위험 해역 교환 보기` 동선을 함께 제공한다. 귀환 전 화물은
내부 손실 계산용 `가치`보다 실제로 확보할 어획물 개수를 우선 표시한다.

### 개인 조우 피드백

현재 행동의 정답 조작을 버튼에서 `추천`으로 강조한다. 장력·어체력·거리 막대에는 짧은
전환 효과를 적용한다. 조작 응답의 이전·다음 조우 상태를 비교해 다음 내용을 표시한다.

- 정확한 대응 또는 일반 조작
- 사용한 조작 이름
- 장력·어체력·거리 증감
- 줄 끊김 위험, 바늘 빠짐 위험, 어체력 소진 뒤 인양 같은 현재 국면

종료 결과는 불투명한 결과 카드로 유지한다.

- 일반 성공: 어종, 크기, 낚시 경험치, 코인, 화물 추가
- 일반 실패: 줄 끊김, 바늘 빠짐, 시간 초과의 구체적인 원인
- 귀환: 확정 어획물 개수와 상점 교환·거래소 사용처
- 사고 귀환: 손실 가치와 확정된 나머지 화물
- 거대어 성공: 이번 기여와 누적 기여, 제압 여부
- 거대어 실패: 구체적인 실패 원인과 기존 기여 보존 안내
- 보상 수령: 코인·증표 수량과 증표 사용처

새 투척이나 새 개인 시도를 시작하면 직전 결과를 지운다. 진행 중 조작 피드백은 매 조작마다
교체하고, 종료 결과는 다음 시작 전까지 유지한다.

### 거대어 단일 전투 화면

개인 시도가 없을 때는 기존 공용 거대어 화면을 유지하되 다음 목적을 추가한다.

- 개인 시도 1회 성공 시 기본 보상 자격
- 누적 기여가 커질수록 보상 등급 상승
- 공용 어체력 0 이후 코인·증표 수령
- 증표는 전용 장비·미끼·칭호·꾸미기 교환에 사용

개인 시도가 시작되면 공용 대형 이미지와 상세 카드 대신 압축 헤더를 표시한다. 헤더에는
거대어 이름, 남은 시간, 공용 어체력, 내 누적 기여, 이번 성공 시 예상 기여를 둔다. 그 아래
개인 장력 조우를 이미지 하나로 렌더한다. 공용 현황과 개인 어체력은 명확히 다른 이름으로
표시한다.

## 데이터 흐름

서버 API 응답 형식과 저장 상태는 바꾸지 않는다. `useDangerousFishing`의 mutation 계층이
현재 버리던 성공 JSON을 보존해 순수 피드백 변환 함수에 전달한다. 변환 함수는 조작 전
조우 상태, 요청한 행동, 응답의 이벤트와 다음 조우 상태로 표시 모델을 만든다.

화면은 피드백 표시 모델만 받아 렌더하며 서버 응답을 직접 해석하지 않는다. 일반 출항과
거대어 피드백은 scope를 분리해 탭을 바꿨을 때 다른 콘텐츠의 결과가 노출되지 않게 한다.

## 오류와 호환성

- 네트워크·검증·stale·too-fast 오류는 기존 오류 표면을 유지한다.
- 알 수 없는 성공 응답은 결과 카드를 만들지 않고 정상 새로고침만 수행한다.
- 옛 저장 데이터와 API 클라이언트는 변경하지 않는다.
- 모든 신규 콘텐츠 패널은 기존 불투명 표면 상수를 사용한다.

## 테스트

- 순수 피드백 변환 테스트로 진행, 일반 성공·실패, 귀환, 거대어 성공·실패·보상 문구를
  검증한다.
- 위험 해역 렌더 테스트로 목표·보상 흐름과 결과 카드 노출을 검증한다.
- 거대어 렌더 테스트로 개인 시도 중 거대어·해역 이미지가 각각 한 번만 나타나고 압축된
  공용 현황과 개인 조우가 함께 표시되는지 검증한다.
- 관련 위험 해역 UI·도메인·라우트 테스트, ESLint와 TypeScript 검사를 실행한다.
