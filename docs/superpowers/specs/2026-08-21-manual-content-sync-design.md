# 8월 20~21일 게임 안내서 동기화 설계

## 목표

2026년 8월 20~21일 운영 `main`에 반영된 플레이어 노출 변경을 게임 안내서와 패치 노트에 동기화한다. 실제 규칙과 반대인 설명을 먼저 바로잡고, 대형 신규 기능과 발견성 개선을 이어서 설명한다.

## 범위

- 협동 보스의 공격 비용·재공격 대기·공개 범위 규칙 교정
- 공개된 7차 전직 4종과 최초 해금 조건, 영구 해금 규칙 추가
- 전직 이력이 있는 전투 직업을 선택하는 수행 방식으로 교정
- 도감 숙련 6분야·7단계·랭킹·월간 연구·트로피 전시대 설명 추가
- 폭풍 원정 직접 진행과 일괄 진행의 차이·위험 설명 추가
- 게시판 활동 Lv.20·칭호, 도감 및 월간 연구 랭킹 설명 추가
- 사냥터 장비 등록 상태, 공용 스킬 상세, 전투 기록 틱 표시, 거래 이용 제한 설명 보강
- 안내서 목록 요약과 게임 개요의 장기 목표 동기화
- 8월 20~21일 플레이어용 패치 노트 작성

## 작성 원칙

1. 변하기 쉬운 수치는 가능한 한 기존 게임 데이터 상수를 가져와 출력한다.
2. 안내서는 사용자가 행동을 결정하는 데 필요한 규칙과 위험을 우선한다. 내부 보안·DB·CI 구현은 포함하지 않는다.
3. 도감 숙련과 트로피는 SP·스탯·경제 보상을 추가하지 않는 장기 수집 목표임을 분명히 한다.
4. 현재 공개된 7차 직업 네 종만 안내하며 미공개 직업은 언급하지 않는다.
5. 숙소는 페이지와 API가 비공개이므로 안내서와 패치 노트에서 제외한다.
6. 운영정책은 이미 거래 등 일부 기능 제한을 포괄하므로 법적 문구를 바꾸지 않고, 플레이어 안내서에서 이용 범위만 설명한다.

## 문서 구조

- `coop.tsx`, `jobs.tsx`, `hunting.tsx`: 현재 동작과 모순되는 규칙을 즉시 교정한다.
- `compendium.tsx`, `quests.tsx`, `plaza.tsx`: 도감 숙련·월간 연구·트로피·랭킹의 연결 관계를 나누어 설명한다.
- `skills.tsx`, `combat.tsx`, `overview.tsx`, `sections.ts`: 발견성 문구와 안내서 메타데이터를 짧게 보강한다.
- `current-content.test.tsx`, `sections.test.ts`: 핵심 규칙이 다시 누락되거나 과거 문구로 돌아가는 회귀를 막는다.
- `docs/patch-notes/2026-08-21-content-and-collection-update.md`: 최근 이틀의 플레이어 노출 변경을 한 공지 초안으로 정리한다.

## 검증

- 안내서 회귀 테스트에서 변경 전 RED, 변경 후 GREEN을 확인한다.
- 안내서 테스트 전체, TypeScript 검사, 수정 파일 ESLint, 프로덕션 빌드를 실행한다.
- `git diff --check`와 숙소 문구 검색으로 서식 오류와 비공개 기능 노출이 없는지 확인한다.
