# 누락 대형 기능 복구 설계

## 목적

운영과 동일한 `origin/main`을 기준으로, 후속 통합에서 빠진 두 기능만 복원한다.

- 냉기 단일 계보 `빙결술사 → 빙천제`와 한기·빙결·영구동토 전투 규칙
- 위험 해역 어획물·거대어 증표 교환소와 칭호·영구 프로필 테두리

도감 숙련도·월간 연구, 공용 스킬 상세창 등 다른 미배포 작업은 포함하지 않는다. 배포와
점검 모드 변경도 범위 밖이다.

## 선택한 복구 방식

원본 기능 브랜치를 통째로 병합하지 않는다. 두 브랜치에는 기능과 무관한 당시 미배포
작업이 함께 있으므로, 기능 전용 커밋만 원래 순서대로 최신 `main`에 재적용한다. 충돌은
원본 기능 의도와 현재 코드 양쪽을 대조해 최소 범위로 해소한다.

수동 재작성보다 원본 커밋 재적용을 우선한다. 원본에는 도메인·서버·UI 회귀 테스트가
기능 코드와 함께 남아 있어, 구현과 테스트의 대응 관계를 보존할 수 있기 때문이다.

## 복구선 1: 빙결술사·빙천제

`docs/superpowers/specs/2026-08-19-cryomancer-frost-chill-design.md`의 기존 설계를 기준으로
빙결술사를 복원하고, 원본 브랜치의 빙천제 설계와 구현을 이어 붙인다.

- `frostmage → cryomancer → frostsovereign` 계보와 스킬 카탈로그를 복원한다.
- 플레이어가 적에게 쌓는 한기는 몬스터가 플레이어에게 주는 기존 한기와 분리한다.
- 한기 5스택에서 추가 마법 피해와 ATB 지연을 주는 빙결을 PvE와 PvP에 동일하게 적용한다.
- 영구동토는 현재 직업 ID가 아니라 장착 패시브 집계값으로 빙결 피해·지연·잔류 한기를
  전달한다.
- 기존 저장·리플레이에 없는 선택 필드는 0 또는 미지정으로 해석한다.
- DB 스키마와 이미지 자산은 변경하지 않는다.

복원 대상 구현 커밋은 `37d83eeaa`, `ea5cff0e5`, `9bb7d1807`, `906dc041c`, `2b03722e5`,
`ab2db469c`, `e36ad66fa`, `3ca848266`, `ecf9540d7`, `3a5fb4f40`, `32684d542`,
`29e43d155`, `461f398cb`, `9a76f05e9`다. 빙천제 설계·계획 커밋 `c98b80245`,
`67afd4024`도 함께 복원한다.

## 복구선 2: 위험 해역 교환소

`docs/superpowers/specs/2026-08-16-dangerous-fishing-reward-sinks-design.md`의 기존 설계를
그대로 구현 기준으로 사용한다.

- 모든 등급의 안전 귀환 어획물을 등급별 특수 미끼로 반복 교환한다.
- 거대어 증표를 최상급 장비의 할인 경로, 전용 칭호, 영구 프로필 테두리, 반복 미끼로
  교환한다.
- 비용과 보상은 공용 선언형 카탈로그에서만 계산한다.
- 서버는 인증·해금·선택 재료·잔액·중복 보유를 검증하고 모든 차감과 지급을 한
  트랜잭션에서 처리한다.
- `operationId` 멱등성 기록으로 재전송과 동시 요청의 중복 지급을 막는다.
- `museunCosmetics.permanentOwned`는 선택 필드로 추가하고 옛 데이터는 빈 배열로 해석한다.
- 상점과 교환 카드는 `SURFACE_CARD`, `SURFACE_INSET`, `SURFACE_ACCENT`를 사용해 배경이
  비치지 않게 한다.
- 기존 거래소 거래, 코인 단독 장비 구매, 기간제 꾸미기 동작은 유지한다.

복원 대상 구현 커밋은 `a4218e459`, `d94c29ec1`, `400630e87`, `f055efaae`,
`a3af9a062`다.

## 오류 처리와 호환성

두 기능 모두 기존 ID를 유지한다. 손상되거나 누락된 새 선택 필드는 안전한 기본값으로
정규화한다. 교환 실패는 어떤 저장값도 바꾸지 않고 정해진 오류 코드를 반환한다. 이미
장비·칭호·꾸미기를 가진 사용자는 다시 차감되지 않는다. 영구 테두리는 획득 직후 자동
장착하지 않는다.

## 검증

각 원본 커밋에 포함된 회귀 테스트를 복원해 기능별로 먼저 실행한다. 이후 관련 전투,
카탈로그, 저장 파생, API, 꾸미기, 낚시 상점과 매뉴얼 테스트를 함께 실행한다. 마지막으로
전체 TypeScript 검사, 이미지 참조 검사, 린트와 프로덕션 빌드를 수행한다. 원본 테스트가
최신 코드 구조와 충돌하면 기대 동작은 바꾸지 않고 테스트 연결부와 구현 연결부만 함께
갱신한다.

## 완료 기준

- 빙결술사와 빙천제가 해금·학습·장착되며 PvE/PvP에서 한기·빙결·영구동토가 동작한다.
- 위험 해역 교환소의 모든 교환 유형이 원자적이고 멱등하게 처리되며 UI와 사용처 안내가
  노출된다.
- 기존 저장 데이터, 거래소, 기간제 꾸미기, 원소 계보와 몬스터 한기에 회귀가 없다.
- 범위 밖 미배포 기능이 diff에 섞이지 않는다.
