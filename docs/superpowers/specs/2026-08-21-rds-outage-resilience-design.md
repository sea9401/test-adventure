# RDS Outage Resilience Design

## Goal

RDS가 짧게 연결을 거부하거나 재시작하더라도 오래된 연결, 전역 계정 확인, 정기 작업,
오류 로그가 장애를 증폭시키지 않게 한다. 운영 DB 원인을 판별할 수 있도록 기존 RDS
메모리 감시 권한도 실제 요구 범위와 일치시킨다.

## Evidence

- 2026-08-20 23:45 KST부터 운영 DB 연결 대기가 증가했고 최대 78개까지 쌓였다.
- 같은 장애 구간에 연결 획득 시간 초과 1,904회, `ECONNREFUSED` 96회, 기존 연결 종료
  62회가 기록됐다.
- RDS `pg_postmaster_start_time()`은 2026-08-21 00:11:05 KST 재시작을 확인했다.
- EC2 CPU와 메모리는 정상 범위였고, RDS 재시작 후 내부 헬스와 로그인 응답은 각각
  약 5ms와 15ms로 회복됐다.
- RDS 메모리 감시는 EC2 역할에 `cloudwatch:GetMetricStatistics`가 적용되지 않아
  실제 DB 메모리를 읽지 못했다.

## Chosen Approach

DB 작업 전체를 자동 재시도하지 않는다. 쓰기 트랜잭션은 응답 유실 시 중복 실행될 수 있기
때문이다. 대신 다음의 좁고 독립적인 보호 장치를 둔다.

1. PostgreSQL 풀이 유휴 연결 오류를 방출하면 안전한 오류 메타데이터만 기록하고 현재 풀을
   회수한다. 다음 요청이 새 풀을 만든다.
2. 계정 제재 상태는 사용자와 경고를 먼저 병렬 조회하고, 사용자에게 활성 거래 제한 시각이
   있을 때만 거래 제재 이력을 추가 조회한다. 대부분의 최초 진입은 기존 두 쿼리를 유지한다.
3. 최초 계정 상태 확인 실패 화면은 짧은 지수 백오프로 자동 재시도한다. 사용자의 수동
   재시도 버튼은 유지하며, 정상 상태에 도달하면 예약된 재시도를 취소한다.
4. 전투 리플레이 만료 정리는 PostgreSQL 트랜잭션 advisory lock을 같은 SQL 문 안에서
   획득한 실행만 삭제한다. 앞선 실행이 남아 있으면 새 실행은 성공적으로 건너뛴다.
5. 리플레이 임시 저장 실패 로그에는 오류 객체나 메시지를 넣지 않고 오류 이름과 안전한
   코드만 남긴다. 전투 payload와 SQL params는 절대 기록하지 않는다.
6. EC2 역할 정책에는 RDS 메모리 지표 조회와 장애 이벤트·인스턴스 메타데이터 읽기만
   허용한다. 앱 배포와 RDS 변경 권한은 추가하지 않는다.

## Error Handling

- 풀 회수에는 30초 쿨다운을 유지해 오류 폭주 중 반복 종료를 막는다.
- 자동 재시도는 최초 실패 후 2초, 5초, 이후 10초 간격으로 제한한다. 컴포넌트가
  언마운트되거나 정상 응답을 받으면 타이머를 정리한다.
- 예상 가능한 DB 단절은 사용자에게 재시도 가능한 오류 상태로 표시한다. 제재 확인은
  보안 경계이므로 실패 시 게임을 열어 주지 않는다.
- 크론 잠금 미획득은 오류가 아니라 `{ skipped: true }` 결과다.
- 쓰기 API의 자동 재시도는 이번 범위에 포함하지 않는다.

## Testing

- 풀 오류 한 번이 풀 회수를 요청하고 쿨다운이 중복 회수를 막는지 단위 테스트한다.
- 거래 제한이 없는 사용자는 거래 제재 쿼리를 실행하지 않고, 있는 사용자만 실행하는지
  서버 테스트로 검증한다.
- 계정 상태 확인 실패 뒤 자동 재시도가 예약되고 성공 후 중단되는지 가짜 타이머로 검증한다.
- 리플레이 정리 SQL이 advisory lock을 사용하고 잠금 실패를 `skipped`로 반환하는지
  테스트한다.
- 리플레이 저장 실패 로그에 payload, SQL, params, 원본 오류 메시지가 포함되지 않는지
  검증한다.

## Operations

로컬 변경은 테스트·타입 검사·린트·빌드 후 현재 브랜치에 커밋한다. 사용자가 별도로
요청하기 전까지 애플리케이션은 배포하지 않는다. IAM 정책 적용은 운영 코드 배포와 별개로
실행하며, 적용 후 RDS 이벤트와 `FreeableMemory`, `DatabaseConnections`, CPU,
`FreeStorageSpace`, 읽기·쓰기 지연을 장애 시간대와 대조한다.
