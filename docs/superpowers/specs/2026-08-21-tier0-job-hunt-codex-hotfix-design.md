# 0단계 직업 사냥 도감 기록 핫픽스 설계

## 문제

사냥 승리 시 현재 직업의 숙련도 이벤트를 도감 숙련도 기록기로 전달한다. 생존자(`survivor`)와 변이자(`mutant`)는 직업 숙련도는 적립되지만 도감 숙련도 카탈로그에는 포함되지 않는 0단계 직업이다. 이 두 직업의 승리 이벤트가 기록기로 전달되면 `unknown_entry` 예외가 발생하고 사냥 트랜잭션 전체가 롤백된다.

## 설계

- 사냥의 직업 숙련도 계산과 저장은 그대로 유지한다.
- 도감 숙련도 `job.victory` 이벤트는 직업 카탈로그에서 `tier > 0`인 직업에만 생성한다.
- 몬스터 처치와 장비 획득 도감 이벤트는 변경하지 않는다.
- 알 수 없는 일반 도감 항목을 조용히 무시하도록 기록기 전체를 완화하지 않는다. 잘못된 서버 이벤트는 계속 예외로 탐지한다.

## 검증

- 생존자와 변이자 각각으로 확정 승리 사냥을 실행한다.
- 실제 도감 기록기처럼 카탈로그에 없는 직업 이벤트를 거부하는 테스트 경계를 사용한다.
- 응답이 200이고 직업 숙련도는 1 증가하며, 전달 이벤트에는 0단계 직업이 없음을 확인한다.
- 기존 전사 사냥은 `job.victory` 이벤트를 계속 생성함을 기존 통합 테스트로 확인한다.

## 운영 영향

DB 스키마나 기존 데이터 변경은 없다. 실패 요청은 기존에도 트랜잭션 롤백되었으므로 별도 데이터 복구가 필요하지 않다.
