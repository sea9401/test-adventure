# 협회 식당 개인 식권 설계

## 목적

모험가 협회 식당을 서버 공동 준비형에서 개인 기여형으로 바꾼다. 길드에 속하지 않은 이용자는 다른 이용자의 기여를 기다리지 않고, 자신이 납품한 식재료 점수 20점마다 식권 1장을 즉시 얻는다.

## 규칙

- 협회 식당은 기본 식권을 지급하지 않는다.
- 개인의 해당 주 누적 기여 점수 20점마다 식권 1장을 얻는다.
- 주간 개인 기여 점수와 획득 가능한 식권 수에는 상한을 두지 않는다.
- 식권을 사용해도 누적 기여 점수는 차감하지 않고, 기존 `mealsUsed`로 사용량을 계산한다.
- 개인 기여 점수, 사용 식권과 음식 효과는 기존처럼 매주 월요일 00:00 KST에 초기화한다.
- 길드 식당의 공동 준비 목표, 기본 식권, 기여 식권과 기여 상한은 변경하지 않는다.
- 같은 주에 길드 식당과 협회 식당 중 먼저 이용한 한쪽으로 고정되는 규칙은 유지한다.

## 서버와 저장 구조

협회 식당은 기존 `guild-dining-user.v1` 개인 주간 상태의 `contributionPoints`와 `mealsUsed`를 계속 사용한다. 협회 전용 계산 함수는 `base = 0`, `earned = floor(contributionPoints / 20)`, `available = max(0, earned - mealsUsed)`를 반환한다.

협회 식당 GET과 POST는 더 이상 `adventurer_association_dining_weekly`의 400점 공동 진행도를 읽거나 갱신하지 않는다. 기존 테이블과 필드는 과거 데이터 및 배포 호환성을 위해 삭제하지 않는다. 기부 요청 한 번의 수량 검증 상한 999개와 속도 제한은 보안 경계로 유지하며, 이는 주간 개인 납품 제한으로 취급하지 않는다.

## 화면

공유 식당 패널은 `source="association"`일 때 협회 전용 표시를 사용한다.

- 공동 식재료 400점 진행 막대를 숨긴다.
- `개인 식재료 기여`에 이번 주 누적 점수와 다음 식권까지 남은 점수를 표시한다.
- `20점마다 식권 1장 · 주간 납품 제한 없음`을 안내한다.
- 기부 입력의 최대치는 개인 기여나 공동 목표가 아니라 보유 수량과 요청당 999개 제한으로 계산한다.
- 식권이 없을 때는 개인 기여로 식권을 얻어야 한다는 협회 전용 안내를 표시한다.
- 길드 식당 화면과 안내는 기존 공동 준비형 표현을 유지한다.

## 오류와 경계 조건

- 20점 미만 기여한 이용자는 식권이 0장이므로 주문 시 `no_meal_ticket`을 받는다.
- 20점 경계를 넘기는 한 번의 기부는 누적 점수에 따라 여러 장을 한꺼번에 획득할 수 있다.
- 높은 기여 점수에서도 개인 상한 오류를 반환하지 않는다.
- 보유 재료 부족, 잘못된 기부 단위, 메뉴 레벨, 회복량 포화와 주간 이용처 충돌 검사는 유지한다.

## 검증

- 순수 계산 함수에서 0점, 19점, 20점, 40점과 사용 식권을 검증한다.
- 협회 라우트에서 공동 400점 상태 없이 20점 기여 후 식권이 생기는지 검증한다.
- 기존 개인 한도를 넘긴 기부가 성공하고 공용 주간 상태를 갱신하지 않는지 검증한다.
- 기여가 부족하면 공동 목표가 아니라 식권 부족으로 주문이 거부되는지 검증한다.
- 공유 패널의 협회 표시와 길드 표시가 서로 섞이지 않는지 렌더링 테스트로 검증한다.

## 범위 제외

- 식재료별 점수와 기부 단위는 변경하지 않는다.
- 메뉴 효과, 지속 시간과 시설 레벨별 메뉴 해금은 변경하지 않는다.
- 길드 식당 규칙과 협회 시설 승급 규칙은 변경하지 않는다.
- 기존 협회 공용 주간 테이블을 삭제하는 DB 마이그레이션은 하지 않는다.
