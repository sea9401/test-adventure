# 대장장이 영구 전문화 및 장기 성장 설계

## 목적

길드 제작소를 중심으로 형성된 기존 제작·거래·납품 생태계는 유지하면서, 개인 대장장이에게 장기 성장 목표와 실제 제작 판단을 추가한다. 단순히 완성품의 총 능력치를 올리는 전문화가 아니라, 기존 장비가 가진 능력치와 부가 옵션의 분배를 통제하는 전문 기술을 제공한다.

현재 장비의 유효 무게는 항상 `0`으로 처리되므로 중량·경량 제작은 도입하지 않는다. 또한 제작 장비는 카탈로그에 정의된 옵션 종류의 수치만 굴리며 새 옵션을 임의로 붙이지 않는다. 이번 개편도 이 원칙을 유지해 장비별 정체성과 사냥·고유 장비의 가치를 보존한다.

## 유지 범위

- 장비 제작은 계속 길드 제작소에서 진행한다.
- 기존 제작법 75종, 제작 요구 레벨, 제작 시설, 재료, 골드 비용과 명장 제작 비용 구조를 유지한다.
- 기존 제작품과 제작자 각인, 거래, 해체, 납품, 주간 활동, 랭킹 기록은 그대로 인정한다.
- 일반 품질 및 명장 제작의 별 등급 확률과 별 등급 성능 보너스는 이번 개편에서 직접 상향하지 않는다.
- 제작 의뢰나 개인 제작소는 추가하지 않는다.
- 재련은 현재 비활성 상태를 유지하며 이번 개편 범위에 포함하지 않는다.

## 영구 전문 분야

대장장이 Lv.13에 다음 세 분야 중 하나를 선택한다.

- 무기 단조: 모든 무기
- 방어구 단조: 갑옷, 장갑, 신발
- 장신구 세공: 반지, 목걸이

전문 분야는 이중 확인을 거쳐 계정에 영구 저장하며 변경하거나 초기화할 수 없다. 이미 Lv.13 이상인 이용자도 자동 배정하지 않고 직접 선택한다. 선택 전에도 기존 방식의 일반 제작과 명장 제작은 가능하지만, Lv.13 이후의 전문 제작 기술은 사용할 수 없다.

전문 기술은 선택한 분야의 장비에만 적용된다. 다른 분야의 장비도 기존과 똑같이 제작할 수 있으며 별 등급 확률이나 기본 성능에 불이익을 받지 않는다.

## 옵션 성향

Lv.15부터 전문 분야 장비를 제작할 때 옵션 성향 하나를 선택할 수 있다. 성향은 제작마다 바꿀 수 있으며 장비에 이미 정의된 옵션만 대상으로 한다.

- 무기: 화력, 정밀, 기교
- 방어구: 방호, 기동, 저항
- 장신구: 공격 보조, 생존 보조, 회복 보조

옵션 키는 다음과 같이 분류한다.

- 화력·공격 보조: `crit`, `critMult`
- 정밀: `accuracy`
- 기교: `spd`, `mp`
- 방호·생존 보조: `hp`, `def`, `magicDef`
- 기동: `eva`, `spd`
- 저항: `critResist`, `statusDamageReductionPct`, `magicDef`
- 회복 보조: `healPowerPct`, `mp`, `spd`

분류가 겹치는 옵션은 선택한 성향에서 정상적으로 사용할 수 있다. 해당 장비에 대상 옵션이 하나도 없거나 대상·비대상 부가 옵션 사이에 재배분할 여지가 없으면 그 성향은 선택 목록에서 숨긴다. 새로운 옵션 키를 완성품에 주입하지 않는다.

기본 성향 성공률은 75%다. 기존 방식으로 굴린 부가 옵션 배율의 집합은 그대로 두고, 성공하면 높은 배율부터 선택 성향의 기존 옵션에 우선 배치한다. 실패하면 원래의 무작위 배치를 사용한다. 배율의 총합과 품질 계산 예산을 새로 만들지 않으므로 전문화 자체가 순수 능력치 상승으로 이어지지 않는다.

## 촉매

Lv.17부터 제작마다 선택적으로 촉매를 넣을 수 있다. 별도 화폐나 전용 토큰은 만들지 않고 기존 광석, 목재, 몬스터 재료 중 레시피와 티어에 맞는 재료를 추가 소모한다.

- 성향 성공률을 75%에서 90%로 높인다.
- 선택 성향 옵션의 낮은 배율을 보정한다.
- 보정에 필요한 값은 비대상 부가 옵션의 배율에서 같은 품질 가중치만큼 이동한다.
- 비대상 옵션의 현재 하한까지 이동해도 부족하면 가능한 범위까지만 보정한다.
- 따라서 전체 가중 능력치 예산과 별 등급은 촉매 때문에 증가하지 않는다.

촉매는 제작 시작과 함께 소모되며 결과가 기대와 달라도 반환하지 않는다. Lv.24부터는 제작 완료 시 20% 확률로 사용한 촉매를 돌려받는다. 반환 판정과 인벤토리 반영은 제작 트랜잭션 안에서 한 번만 처리한다.

## 구조 제작술

Lv.20부터 전문 분야 장비의 능력치 분배 방식을 제작마다 선택한다. 모든 방식은 먼저 기존 난수로 만든 가중 총량을 고정한 뒤 배분만 바꾸며, 반올림을 제외한 총 품질 예산을 늘리지 않는다.

- 균형 제작: 기존 능력치 배분을 그대로 사용한다.
- 주력 강화: 부가 옵션 예산 일부를 장비의 주 능력치로 옮긴다.
- 옵션 정밀: 주 능력치 예산 일부를 선택한 옵션 성향으로 옮긴다.
- 극한 제작: 평균 총량은 유지하면서 각 능력치의 고저 차이를 넓힌다.
- 안정 제작: Lv.22에 해금한다. 낮은 결과를 평균 쪽으로 끌어올리는 대신 높은 결과도 평균 쪽으로 낮춘다.

재배분 비율, 배율 하한·상한과 반올림 규칙은 서버 공용 설정으로 한곳에서 관리한다. 최종 값은 기존 장비 타입이 허용하는 범위를 넘지 않는다. 성향이나 구조 제작술을 적용할 수 없는 레시피에는 선택지를 노출하지 않는다.

Lv.26 전에는 무작위로 명장품이 나오거나 명장 제작 모드를 사용한 경우 기존 명장품 분배 규칙을 우선한다. Lv.26부터는 옵션 성향, 촉매와 구조 제작술을 명장품에도 적용한다. 별 등급은 기존 방식대로 먼저 한 번만 결정한다.

## Lv.28 대표작과 전문 각인

Lv.28부터 선택한 분야의 완성품 제작자 정보에 전문 분야 각인을 추가한다. 각인은 거래 후에도 유지되지만 별도의 성능, 납품 점수, 해체 보너스를 주지 않는다.

전문 분야에서 직접 만든 장비 하나를 대표작으로 지정할 수 있다. 대표작은 프로필과 길드 제작소 기록에 전시하는 명예 기능이며 장비 성능을 바꾸지 않는다. 새 대표작을 지정하면 이전 대표작 표시는 해제하되 장비 자체와 제작자 기록은 유지한다.

## Lv.30 최종 검수

Lv.30부터 전문 분야의 명장품을 만들면 같은 완성품에 대한 능력치 분배 후보 두 개를 생성하고 하나를 선택한다.

- 재료, 촉매와 골드는 제작 시작 시 한 번만 소모한다.
- 별 등급은 한 번만 굴려 두 후보가 같은 등급을 공유한다.
- 두 후보는 같은 기본 장비, 구조 제작술, 성향과 가중 총량을 공유하고 배분 결과만 다르다.
- 제작 경험치, 제작 횟수, 주간 진행도와 랭킹 기여는 후보 생성 시 한 번만 반영한다.
- 후보는 서버 저장 상태에 보관하고 확정 전에는 인벤토리에 넣지 않는다.
- 미확정 후보가 있으면 다른 제작을 시작할 수 없다.
- 새로고침·재접속 후에도 같은 두 후보를 보여주며 다시 굴리지 않는다.
- 후보 하나를 확정하는 요청은 멱등적으로 처리해 중복 장비 지급을 막는다.

후보 생성과 확정을 별도 서버 동작으로 나누되, 각 동작 안의 저장 변경은 하나의 DB 트랜잭션으로 처리한다. 확정되지 않은 후보는 거래, 장착, 해체 또는 납품할 수 없다.

## 상태와 서버 권한

기존 `crafting.v2`의 대장장이 상태에 영구 전문 분야, 대표작, 미확정 최종 검수 상태를 확장 저장한다. 기존 `xp`와 `crafts`는 그대로 보존한다. 누락된 새 필드는 미선택·미지정·미확정 상태로 해석해 기존 저장과 호환한다.

전문화 선택 가능 여부, 레시피 슬롯, 옵션 성향 적용 가능 여부, 촉매 종류와 수량, 구조 제작술, 명장품 적용 여부는 모두 서버에서 다시 검증한다. 클라이언트가 보낸 완성 능력치나 후보 값은 신뢰하지 않는다. 전문 분야 선택은 조건부 저장 또는 잠금 트랜잭션으로 최초 한 번만 허용한다.

최종 검수 후보에는 원본 레시피, 비용 지불 표식, 별 등급, 두 분배 결과, 제작자 스냅샷과 생성 시각을 저장한다. 확정 API는 저장된 후보만 장비 인스턴스로 발행하며 새 난수를 사용하지 않는다.

## UI

- 길드 제작소 성장 패널에 Lv.30까지의 해금과 Lv.31 이후 명예 레벨을 표시한다.
- Lv.13 이상 미선택 이용자에게 영구 선택 경고와 이중 확인을 제공한다.
- 제작 화면은 해당 레시피에 실제 적용 가능한 옵션 성향, 구조 제작술과 촉매만 보여준다.
- 선택 변경 시 예상되는 방향과 대가를 보여주되 완성 수치나 결과를 미리 공개하지 않는다.
- 최종 검수 대기 중에는 제작 화면 진입 시 후보 선택을 우선 표시하고 다른 제작 버튼을 비활성화한다.
- 두 후보 비교에는 총점만 강조하지 않고 주 능력치와 각 기존 옵션의 차이를 나란히 표시한다.
- 모든 패널과 중첩 카드는 `SURFACE_CARD`, `SURFACE_INSET`, `SURFACE_ACCENT`를 사용해 라이트·다크 모드에서 배경 이미지가 비치지 않게 한다.

## 검증

- 기존 누적 XP 경계부터 Lv.31 이상까지 레벨 계산과 다음 레벨 XP를 단위 테스트한다.
- Lv.13 전문 분야 선택의 영구성, 동시 요청 경쟁, 미선택 상태의 기존 제작 허용을 테스트한다.
- 모든 제작법에 대해 슬롯별 전문 분야와 실제 선택 가능한 옵션 성향이 올바른지 검사한다.
- 성향 적용 전후의 배율 다중집합과 가중 총량이 같고, 성공 시 선택 성향에 높은 배율이 우선 배치되는지 통계·결정적 난수 테스트를 둔다.
- 촉매의 90% 성공, 하위 보정, 총량 보존, 20% 반환을 경계 난수로 검증한다.
- 모든 구조 제작술이 가중 총량과 기존 하한·상한을 지키는지 검증한다.
- Lv.26 전후 명장품의 전문 기술 적용 차이와 별 등급 단일 판정을 검증한다.
- 최종 검수의 비용·XP·주간 기록 단일 반영, 제작 잠금, 재접속 복구, 중복 확정 방지를 라우트 및 DB 통합 테스트로 검증한다.
- 기존 제작품 파싱, 거래, 장착, 해체, 납품, 제작 기록과 랭킹 회귀 테스트를 실행한다.
- 관련 단위·라우트·컴포넌트 테스트, 타입 검사, ESLint와 프로덕션 빌드를 완료한다.

## 제외 범위

- 제작 의뢰 또는 개인 제작소
