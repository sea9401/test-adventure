# 격자 던전 다단타 로그 묶음 설계

## 문제

일반 전투 화면은 구조화된 `BattleLogEntry`를 행동 단위로 묶지만, 격자 던전 전투 요약은 엔진 로그를 문자열로 변환한 뒤 최근 네 줄만 저장한다. 이 과정에서 같은 시전이라는 경계가 사라져 월식의 두 타격이 별도 행동처럼 표시된다. 실제 피해 계산은 정상이다.

## 선택한 방식

격자 던전 서버가 구조화된 로그를 문자열로 바꾸기 전에 다단타를 요약한다. 같은 공격자·기술명·틱에 연속된 직접 피해만 하나의 문자열로 합치고, 기본 공격과 경계가 다른 동일 기술 시전은 합치지 않는다. 출력은 `월식! 2타 · 총 N 피해 (1타 A / 2타 B)` 형식으로 한다.

문자열만 받은 클라이언트에서 이름이 같은 줄을 합치는 방식은 서로 다른 연속 시전을 오인할 수 있어 사용하지 않는다. 전체 전투 로그 스키마를 구조화된 항목으로 마이그레이션하는 방식도 이번 표시 오류에 비해 범위가 크므로 제외한다.

## 범위

- 솔로 격자 던전 전투 요약의 문자열 변환 전에 적용한다.
- 파티 전투는 이미 한 스킬을 한 줄로 집계하므로 그대로 유지한다.
- 일반 전투·PvP·협동 보스의 `BattleLogList`와 엔진 피해 계산은 변경하지 않는다.
- 저장된 기존 `log: string[]` 응답 형식은 유지한다.

## 검증

- 같은 틱의 월식 두 타가 한 줄과 정확한 총합으로 변환되는 회귀 테스트
- 서로 다른 틱의 연속 월식은 두 줄로 유지되는 경계 테스트
- 기본 공격과 단일타 로그가 기존 문자열을 유지하는 테스트
- 격자 던전 라우트가 요약 후 최근 네 행동을 저장하는 통합 테스트
