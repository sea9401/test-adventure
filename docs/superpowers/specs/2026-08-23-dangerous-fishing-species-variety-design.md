# 위험 해역 어종 다양화 설계

## 목표

위험 해역의 해역·수심 조합마다 한 어종만 고정 출현하는 구조를 없애고, 수심과 미끼가
서로 다른 방식으로 출현 가중치를 바꾸게 한다. 특수 미끼는 기존 실시간 조우 보조 효과를
유지하면서 실제 어종 선택에도 체감 가능한 영향을 줘야 한다.

## 콘텐츠 규모

- 기존 9종에 신규 9종을 더해 총 18종을 제공한다.
- 각 해역은 표층 선호 2종, 중층 선호 2종, 심층 선호 2종으로 총 6종을 가진다.
- 선택한 수심과 다른 선호 수심의 어종도 낮은 확률로 출현하므로, 실제 후보군은 해역당
  6종이다.
- 신규 어종과 이미지 파일명은 같은 영문 ID를 사용한다.

| 해역 | 표층 선호 신규 어종 | 중층 선호 신규 어종 | 심층 선호 신규 어종 |
| --- | --- | --- | --- |
| 파쇄 암초 | 유리비늘 청어 (`glassscale_herring`) | 산호뿔 도미 (`coralhorn_snapper`) | 해구갑 철갑상어 (`trenchshell_sturgeon`) |
| 폭풍 해구 | 질풍 침치 (`gale_needlefish`) | 폭뢰 개복치 (`stormbell_sunfish`) | 회오리 청새치 (`cyclone_marlin`) |
| 심연 균열 | 유령빛 해파리 (`ghostlight_jellyfish`) | 밤유리 상어 (`nightglass_shark`) | 무광 리바이어던 (`starless_leviathan`) |

## 출현 선택

서버는 선택한 해역의 6종을 모두 후보로 삼는다. 각 후보의 최종 가중치는 다음 세 값을
곱해 계산한다.

1. 어종의 기본 `spawnWeight`
2. 수심 친화도: 선호 수심 100%, 한 단계 차이 22%, 두 단계 차이 5%
3. 미끼 보정: 행동 유형 일치 시 150%, 목표 희귀도면 아래 가중치 추가

| 미끼 | 목표 희귀도 | 희귀도 가중치 |
| --- | --- | --- |
| 해역용 기본 미끼 | 없음 | 없음 |
| 암초 향 미끼 | 일반·희귀 | +25% |
| 핏빛 미끼 | 희귀·영웅 | +40% |
| 발광 미끼 | 영웅·전설 | +65% |
| 심연 응축 미끼 | 전설 | +100% |

`+100%`는 전설 어종의 최종 확률을 100%로 만든다는 뜻이 아니라 해당 후보의 가중치를
두 배로 만든다는 뜻이다. 따라서 심연 균열 심층에서도 심연 왕관어와 무광 리바이어던이
주로 나오지만 다른 심연 어종이 함께 출현한다.

기존 v1 조우와 v2 실시간 조우는 같은 선택 함수를 사용해 규칙이 갈라지지 않게 한다.
서버가 확정한 어종을 세션에 저장하는 기존 재현·정산 방식은 유지한다.

## 미끼와 UI

- 특수 미끼의 기존 실시간 조우 효과는 모두 유지한다.
- 출항 후 미끼 선택 카드에 어종 출현 가중치와 실시간 조우 효과를 함께 표시한다.
- “미끼마다 노리기 쉬운 행동과 희귀 어종 보정이 다릅니다”라는 모호한 문구는 수심과
  미끼가 후보 가중치를 어떻게 바꾸는지 설명하는 문구로 교체한다.
- 상점과 게임 매뉴얼에서도 퍼센트를 “확률”이 아니라 “출현 가중치”로 표기한다.

## 이미지

- 신규 9종은 기존 위험 해역 어종과 어울리는 고대비 판타지 해양 생물 일러스트로 만든다.
- 단일 어종의 전신 측면 실루엣, 투명 배경, 글자·테두리·워터마크 없음이 공통 조건이다.
- 생성 PNG는 `public/images/fish/<fish-id>.png`로 옮긴 뒤 기존 `optimize-images`를 실행해
  최대 1024px, 품질 86의 WebP로 변환하고 PNG를 제거한다.

## 호환성과 정산

- 기존 어종 ID, 저장된 화물, 도감, 거래 재료와 가격은 변경하지 않는다.
- 신규 어종은 기존 `danger_catch_<fish-id>` 규칙으로 재료 ID를 자동 생성한다.
- 화물 가치의 10배라는 기존 NPC 판매 가격 규칙과 희귀도 기반 교환·강화 규칙을 그대로
  적용한다.
- 배포나 점검 모드 변경은 이 작업 범위에 포함하지 않는다.

## 검증

- 카탈로그가 해역당 정확히 6종, 선호 수심당 정확히 2종인지 검증한다.
- 수심 친화도 경계값과 미끼 희귀도·행동 가중치를 고정 난수로 검증한다.
- v2 시작 경로가 선택한 미끼를 어종 선택 함수에 전달하는지 실제 서비스 테스트로 검증한다.
- 준비 화면과 상점이 출현 가중치와 실시간 효과를 함께 표시하는지 렌더링 테스트로 검증한다.
- 전체 관련 Vitest, TypeScript 검사, `npm run check-images -- --strict`를 통과시킨다.
