# 실패 음식 퇴비 제작 설계

## 목표

요리 연구 실패로 누적되는 `failedCookingDishes`에 생활 콘텐츠 안의 실제 소비처를 제공한다.

## 제작식

- 이름: 실패 음식 퇴비
- 분류: 생활 보조품
- 요구 레벨: 생활 제작 Lv.1
- 비용: 실패 음식 3개
- 결과: 기존 `organic_fertilizer` 1개
- 설명: 실패한 요리를 발효해 유기질 거름으로 되살린다.

기존 유기질 거름 제작식은 유지한다. 새 제작식은 실패 음식을 처리하는 낮은 효율의 대체 경로이며, 의도적으로 요리 연구에 실패하는 것이 일반 재료 제작보다 유리하지 않게 한다.

## 데이터와 처리 흐름

`LifeCraftingRecipe`에 선택적 `failedDishCost`를 추가한다. 생활 작업장 조회 응답은 `inventory.v2.failedCookingDishes`의 정규화된 수량을 포함하고, 일반 재료와 실패 음식 중 실제로 필요한 모든 비용을 기준으로 최대 제작 가능 수량을 계산한다.

제작 요청은 생활 작업장 트랜잭션 안에서 `inventory.v2`를 잠근다. 실패 음식이 부족하면 아무 상태도 변경하지 않고 `not_enough_failed_dishes`를 반환한다. 성공하면 실패 음식 3개를 차감하고 기존 생활 제작 상태에 유기질 거름 1개를 더한 뒤 두 저장값을 같은 트랜잭션에서 기록한다.

## UI

생활 제작의 생활 보조품 목록에 기존 카드 형태로 노출한다. 비용 문구에는 `실패 음식 3개 (보유 N개)`를 표시하고, 최대 제작 가능 수량과 수량 선택은 기존 공용 컨트롤을 사용한다. 새 이미지 자산은 만들지 않고 기존 유기질 거름 이미지를 재사용한다.

## 오류와 검증

- 실패 음식 부족은 `실패 음식이 부족합니다.`로 안내한다.
- API 테스트는 성공 시 실패 음식 차감과 거름 지급을 함께 확인한다.
- API 테스트는 부족 시 두 저장 상태가 보존되는지 확인한다.
- 조회 테스트는 실패 음식 보유량이 최대 제작 가능 수량에 반영되는지 확인한다.
- 기존 생활 제작, 요리, 타입, 린트, 이미지 검사를 회귀 검증한다.
