# 농장 재료 수급 확장 설계

## 목표

요리 연구와 제작에 쓰이는 농장 재료의 수급량을 늘리되, 기존 작물별 재배 시간과 씨앗·납품 경제를 한 번에 뒤집지 않는다. 농장 확장과 비료 사용이 눈에 보이는 생산량 증가로 이어지게 해 요리 실패 음식 재활용과 농장 성장의 연결도 강화한다.

## 밭 확장

- 최대 밭 수를 6칸에서 8칸으로 늘린다.
- 기존 확장 단계 뒤에 7칸 `마을 공동 농장`을 농장 증표 300개, 8칸 `풍요의 대농장`을 농장 증표 500개로 추가한다.
- 기존 2~6칸 저장은 현재 밭과 작물을 그대로 보존한다. 새 밭은 사용자가 증표를 지불해 한 칸씩 열며 자동 지급하지 않는다.
- 8칸도 기존 일괄 심기·수확·비료 흐름이 밭 ID 순서대로 처리한다. 한 번의 일괄 작업은 최대 8회 요청이므로 현재 분당 30회 제한 안에 유지된다.
- 농장 화면은 기존 `FARM_MAX_PLOT_COUNT` 기반 진행 표시와 카드 목록을 그대로 사용한다. 별도 레이아웃이나 신규 이미지 자산은 추가하지 않는다.

## 비료 수확 보너스

- 유기질 거름을 사용한 밭은 기존 남은 재배 시간 20%, 최대 2시간 단축 효과를 유지한다.
- 해당 밭을 수확할 때 일반 작물을 정확히 1개 더 지급한다.
- 추가 1개는 무작위 기본 수확량과 퍼센트 수확량 보너스를 계산한 뒤 더한다. 따라서 직업·생활 레벨의 퍼센트 보너스 누적값, 희귀 작물 확률과 천장, 농사 경험치는 바뀌지 않는다.
- 수확이 끝나면 기존과 같이 밭이 비워지므로 비료 상태도 함께 제거된다.
- 생활 제작과 농장주의 교환소의 유기질 거름 설명에는 시간 단축과 수확량 +1을 함께 안내한다.

완전히 확장한 8칸 농장에서 모든 밭에 비료를 쓰면 현재 6칸 대비 작물별 한 주기 평균 공급량은 약 54~78% 증가한다. 작물 기본 수확량 자체는 유지하므로 비료를 사용하지 않는 6칸 이용자의 기존 생산량과 납품·교역 환산은 변하지 않는다.

## 농장주의 교환소 연동

- 교환소의 완전 확장 조건을 밭 6칸에서 8칸으로 변경한다.
- 유료 축사 4칸 조건은 유지한다.
- 기존 6칸 이용자는 7·8칸을 열기 전까지 교환소가 잠긴다. 이미 구매한 반복 상품이나 칭호는 회수하지 않는다.
- API와 UI는 `requiredPlots: 8`을 표시해 실제 최대 밭 수와 해금 조건을 일치시킨다.

## 오류와 호환성

- 증표가 부족할 때의 `not_enough_reputation`, 최대 확장 뒤의 `plot_upgrade_maxed` 등 기존 오류 계약은 유지한다.
- 저장 파서는 8칸까지만 받아들이고 그보다 많은 잘못된 밭 데이터는 8칸으로 제한한다.
- 기존 수확 API 응답 형태는 바꾸지 않는다. `quantity`에 비료 추가 수확량이 포함되므로 클라이언트와 후속 숙련도·도안·길드 진행 처리는 기존 경로를 그대로 사용한다.

## 테스트와 검증

- 농장 도메인 테스트에서 7·8칸 확장 비용, 누적 증표 사용량, 8칸 최대 제한을 검증한다.
- 비료를 사용한 밭의 수확량이 동일한 난수 조건의 일반 밭보다 정확히 1개 많은지 검증한다.
- 퍼센트 수확량 보너스 누적값과 비료 보너스가 서로 간섭하지 않는지 검증한다.
- 저장 파서가 8칸을 보존하고 9칸 이상은 8칸으로 제한하는지 검증한다.
- 농장주의 교환소가 밭 7칸에서는 잠기고 8칸과 유료 축사 4칸에서만 열리는지 검증한다.
- 관련 농장·생활 제작·교환소 UI 테스트와 전체 타입 검사, 린트, 빌드, 이미지 검사를 수행한다.
