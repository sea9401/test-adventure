# 수행 초기화 레벨 1 전환 설계

## 목표

수행 초기화로 현재 직업에서 얻은 레벨 성장 능력치를 다른 직업에 자유롭게 옮길 수 없도록 한다. 초기화가 성공하면 수행 한계치와 해당 생애의 레벨 성장을 비우고 캐릭터를 레벨 1부터 다시 육성하게 한다.

## 동작

- 신전의 골드 수행 초기화와 수행 초기화 물약에 같은 규칙을 적용한다.
- 성공 시 캐릭터 레벨은 1, 경험치는 0이 된다.
- 수행으로 올린 한계치는 비우고 사용한 숙달 포인트는 기존처럼 환급한다.
- `grown`과 기존 `growthRespecPoints`는 모두 0으로 비운다. 새 재분배 대기 포인트는 만들지 않는다.
- 수행 횟수, 수행 초기화 횟수, 직업 숙련도와 직업 이력은 유지한다.
- 실패 시에는 레벨, 경험치, 아이템, 골드, 수행 상태를 변경하지 않는다.

## 안내

- 신전 확인창은 레벨 1·경험치 0·레벨 성장값 소멸을 실행 전에 명시한다.
- 수행 초기화 물약은 사용 버튼을 누른 뒤 별도 확인창에서 같은 내용을 안내한다.
- 성공 메시지는 레벨 1 초기화를 포함하고 재분배 대기 포인트 문구를 제거한다.
- 물약 설명과 간단 효과 설명도 새 규칙에 맞춘다.

## 호환성

저장 스키마 호환을 위해 `growthRespecPoints` 필드는 당장 삭제하지 않되 항상 0으로 정규화한다. 과거 저장 데이터에 남은 대기값도 로드 시 폐기하며, 수행 적용과 UI에서는 재분배 기능을 제거한다.

## 검증

- 공통 로직이 성장값과 대기값을 삭제하는 단위 테스트
- 과거 저장값의 재분배 대기값도 0으로 정규화하고 수행에 적용하지 않는 단위 테스트
- 신전 및 물약 API가 `level: 1`, `exp: 0`을 저장하고 응답하는 경로 테스트
- 인벤토리 확인창이 실제 사용 콜백을 확인 전에는 호출하지 않는 컴포넌트 테스트
- 관련 테스트, 타입 검사, 린트, 전체 테스트와 프로덕션 빌드
