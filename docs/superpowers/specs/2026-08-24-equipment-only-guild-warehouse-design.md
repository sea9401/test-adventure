# 장비 전용 길드 창고 설계

## 목표

길드 창고의 신규 입고 품목을 장비로 제한한다. 기존에 창고에 보관된 재료는 자산 손실 없이 개인 인벤토리로 회수할 수 있어야 한다.

## 정책

- 장비는 기존과 같이 거래 가능·미착용·미강화·잠금 해제 상태일 때 입고할 수 있다.
- 재료 신규 입고는 UI와 서버 양쪽에서 차단한다.
- 기존 창고 재료는 출고만 허용한다. 출고가 끝난 재료 종류는 창고에서 제거된다.
- 기존 재료는 회수 전까지 현재와 같이 슬롯을 사용한다.
- 거래 정지, 창고 권한, 창고 개방 여부 등 기존 공통 검증은 그대로 적용한다.

## UI

- 창고 입고 화면은 장비만 표시하며 장비 입고가 기본 상태다.
- 출고 화면은 장비를 기본으로 표시한다.
- 창고에 기존 재료가 남아 있을 때만 출고 화면에 `기존 재료 회수` 선택지를 추가한다.
- 창고 설명은 장비 전용 정책과 기존 재료 회수 정책을 함께 안내한다.
- 보관 목록의 기존 재료 제목은 `기존 재료 · 출고 전용`으로 표시한다.

## 서버

- 권한 검증을 통과한 `deposit + material` 요청은 `warehouse_equipment_only` 오류로 거부한다.
- `withdraw + material` 경로는 기존 구현을 유지한다.
- 장비 입출고 경로와 기존 저장 형식은 변경하지 않는다.

## 테스트

- 재료 입고가 개인·창고 저장소를 변경하지 않고 거부되는지 검증한다.
- 기존 재료 출고가 계속 가능한지 검증한다.
- UI가 입고 화면에서 재료 선택지를 노출하지 않는지 검증한다.
- 기존 재료가 있을 때 출고 화면에서만 회수 선택지가 나타나는지 검증한다.
