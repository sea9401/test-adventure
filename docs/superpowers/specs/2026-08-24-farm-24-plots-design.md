# 농장 밭 24칸 확장 설계

## 목표

요리 레시피 증가와 목장 사료 소비에 맞춰 농장의 최대 밭 수를 8칸에서 24칸으로 늘린다. 기존 8칸까지의 성장 경험은 유지하고, 이후에는 증표를 많이 모은 이용자가 4칸씩 확장하는 장기 목표를 제공한다.

## 확장 단계와 비용

기존 2칸 시작과 3~8칸의 한 칸 단위 확장 비용은 변경하지 않는다. 8칸 이후에는 다음 단계를 추가한다.

| 보유 밭 | 단계 이름 | 소모 증표 |
| ---: | --- | ---: |
| 12칸 | 비옥한 경작지 | 1,000개 |
| 16칸 | 풍요의 들판 | 2,000개 |
| 20칸 | 대지주의 농장 | 4,000개 |
| 24칸 | 왕국의 곡창지대 | 8,000개 |

8칸 이후 추가 비용은 총 15,000증표이며, 처음부터 24칸까지의 누적 비용은 16,150증표다. 각 구매는 현재 단계에서 다음 단계로만 진행되며 중간 단계를 건너뛸 수 없다.

## 데이터와 저장 호환성

- `FARM_MAX_PLOT_COUNT`를 24로 올리고 기존 확장 정의 뒤에 12·16·20·24칸 단계를 추가한다.
- 기존 확장 함수와 API의 다음 단계 탐색 및 증표 차감 흐름을 그대로 사용한다.
- 확장 시 기존 밭 객체를 보존하고 새 번호의 빈 밭만 추가한다. 8→12칸 확장은 빈 밭 4칸을 추가하며 이후 단계도 동일하다.
- 저장 형식은 바꾸지 않는다. 기존 2~8칸 저장은 그대로 복원되고, 신규 12~24칸 저장도 최대 24칸까지 손실 없이 복원한다.
- 24칸 상태에서는 다음 확장이 없으며 기존 `plot_upgrade_not_available` 오류를 반환한다.

## 후반 교환소 호환성

현재 후반 교환소는 최대 밭 수와 해금 조건이 결합되어 있다. 최대치를 24로 올리면서 기존 이용자의 교환소가 다시 잠기지 않도록 교환소 요구 밭 수를 별도 상수로 분리하고 8칸으로 고정한다.

- 밭 8칸과 기존 유료 축사 조건을 만족하면 교환소가 열린다.
- 12~24칸 추가 확장은 교환소 해금 여부에 영향을 주지 않는다.
- 교환소 안내의 진행 수치도 8칸을 기준으로 표시한다.

## 화면 구성

- 재배 화면에는 보유한 밭을 페이지 구분이나 접기 없이 모두 표시한다.
- 모바일은 기존 1열, 중간 화면은 3열을 유지하고 큰 화면에서는 4열로 확장한다. 최대 24칸은 큰 화면에서 6줄로 표시된다.
- 작물 선택과 일괄 심기·수확·비료 사용은 화면 상단의 기존 위치를 유지하며 보유한 밭 전체를 대상으로 동작한다.
- 개별 밭 카드의 심기·수확·비료 기능과 상태 표시는 변경하지 않는다.
- 농장 성장 영역에는 현재 보유 밭 수와 최대 24칸을 표시하고, 다음 확장 단계의 이름·도달 밭 수·비용·보유 증표를 기존 형식으로 안내한다.
- 농장 도움말의 최대 밭 수를 24칸으로 갱신한다.

## 오류 처리

- 증표가 부족하면 기존 `insufficient_reputation` 흐름을 유지하고 상태를 변경하지 않는다.
- 최대 24칸이거나 저장 상태에 맞는 다음 단계가 없으면 확장을 거부한다.
- 같은 요청이 중복되거나 오래된 상태에서 요청되더라도 서버가 현재 저장된 밭 수를 기준으로 다음 단계와 비용을 다시 계산한다.
- 예상하지 못한 밭 수의 저장 데이터는 기존 파싱 규칙에 따라 최소 시작 칸 수와 최대 24칸 사이로 제한한다.

## 검증

- 기존 2→3→4→5→6→7→8칸 단계와 비용이 변하지 않았는지 확인한다.
- 8→12→16→20→24칸 단계와 1,000→2,000→4,000→8,000증표 비용을 검증한다.
- 각 신규 확장에서 기존 밭과 작물 상태는 유지되고 빈 밭 4칸만 추가되는지 검증한다.
- 증표 부족 시 차감과 밭 추가가 모두 일어나지 않는지 검증한다.
- 24칸 저장 데이터가 복원 후에도 24칸이며, 다음 확장이 거부되는지 검증한다.
- 최대 밭 수가 24칸이어도 후반 교환소가 기존 8칸 조건으로 열리고 진행 수치가 8칸 기준인지 검증한다.
- 농장 집중 테스트, 관련 API 테스트, 타입 검사와 린트를 실행한다.

## 범위 제외

- 작물별 기본 수확량, 성장 시간, 희귀 작물 확률은 이번 변경에서 조정하지 않는다.
- 씨앗 획득량, 농장 증표 획득량, 목장 생산량과 사료 비용은 변경하지 않는다.
- 밭 페이지, 접이식 밭 구역, 새로운 일괄 작업 방식은 추가하지 않는다.
- 배포, 푸시, PR 생성은 수행하지 않는다.
