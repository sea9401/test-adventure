# 목업 기준 모험 홈·상단 내비게이션 정렬 설계

## 배경

개인화 모험 홈과 활동 체크 기능은 구현됐지만, 승인된 목업의 시각적 계층과 정보 밀도는
충분히 반영되지 않았다. 현재 캐릭터 요약은 이름·HP·MP만 남긴 별도 최소 카드이고,
활동 체크는 세 개의 지표 상자와 중첩된 접이식 패널을 사용한다. 상단 크롬도 아이콘형
브랜드와 큰 탭 글자를 사용해 목업의 얇고 정돈된 두 줄 내비게이션과 다른 인상을 준다.

이번 변경은 첨부된 `KakaoTalk_20260824_191809018.png`를 시각적 기준으로 삼는다. 목업의
데스크톱 720~864px 게임 폭과 모바일 카드 순서, 따뜻한 강조색, 촘촘한 목록 밀도를
그대로 적용하되 현재 구현된 생활 탭, 위젯 편집, 활동 선택과 알림 데이터는 유지한다.

## 목표

- 상단바와 메인 탭을 목업의 얇은 흰색 2단 내비게이션으로 맞춘다.
- 기본 캐릭터 요약에서도 EXP, 상태 칩과 장비 6칸을 확인한다.
- 오늘의 모험 체크를 주황색 완료 헤더와 PC 2열·모바일 1열 목록으로 표시한다.
- 기존 개인화 설정, 활동 상태 계산, 드롭다운 메뉴와 모바일 터치 영역을 보존한다.
- 라이트·다크 모드에서 모든 카드와 목록 배경을 불투명하게 유지한다.

## 상단 크롬

### 상단바

- 데스크톱 최대 폭은 864px이며 중앙에 배치한다.
- 왼쪽에는 아이콘 대신 `무슨무슨게임` 텍스트 브랜드를 표시하고 홈 링크로 사용한다.
- 오른쪽에는 현재 에너지와 최대 에너지를 작은 둥근 상태 칩으로 표시한다.
- 데스크톱에서는 사용 가능한 골드도 상태 칩으로 표시하고 모바일에서는 숨긴다.
- 기존 알림과 설정 메뉴는 원형 아이콘 버튼으로 유지한다.
- 기존 자동 벌목·채광·낚시 상태는 상단바에서 제거하되 생활 메뉴와 모험 체크에서 계속
  확인할 수 있다.
- 상단 안전 영역을 반영하고, 배경은 불투명 흰색 또는 zinc-900을 사용한다.

### 메인 탭

- 모험·전투·마을·생활·캐릭터·길드의 현재 여섯 탭은 유지한다.
- 탭은 864px 폭 안에서 동일한 너비로 배치하며 모바일에서도 한 줄을 유지한다.
- 글자 크기와 화살표를 목업처럼 줄이고 탭 높이는 최소 44px을 유지한다.
- 활성 탭은 보라색 글자와 얇은 하단선으로 표시한다.
- 처리 가능한 활동의 주황색 점과 기존 드롭다운 메뉴 동작은 유지한다.
- 드롭다운은 상단 크롬 폭 안에서 열리고 생활 항목의 진행 상태를 계속 표시한다.

## 캐릭터 요약

기본 접힘 상태를 목업의 압축 캐릭터 카드로 다시 정의한다. 별도의 최소 카드가 아니라 기존
캐릭터 카드의 핵심 정보가 한 화면에 들어오는 중간 밀도 카드다.

- 데스크톱은 약 112px, 모바일은 약 84px의 캐릭터 이미지를 사용한다.
- 이름, 레벨, 현재 직업과 길드를 이미지 오른쪽에 표시한다.
- HP·MP·EXP를 서로 다른 색의 가로 막대로 표시한다.
- 전직 또는 레벨 제한 정보는 우측 상단의 작은 강조 배지로 표시한다.
- 활성 음식, 모험 지원권과 활성 프리셋이 있을 때 상태 칩을 표시한다.
- 무기·갑옷·장갑·신발·반지·목걸이 여섯 장비 슬롯을 카드 하단에 한 줄로 표시한다.
- 모바일도 같은 정보 순서를 유지하며 장비 슬롯은 6열로 압축한다.
- 펼치기 버튼을 누르면 기존 전체 캐릭터 카드를 표시하고, 다시 접으면 압축 카드로 돌아온다.
- 접기·펼치기 저장 계약은 변경하지 않는다.

## 오늘의 모험 체크

- 상단은 `SURFACE_ACCENT` 기반의 따뜻한 배경으로 만들고 주황색 체크 아이콘, 제목,
  `완료 N / M`을 한 행에 표시한다.
- 서버 시각을 기준으로 다음 KST 일일 초기화까지 남은 시간을 제목 아래 표시한다.
- 처리 가능한 활동 수는 상단 바로 아래 한 줄 안내로 표시한다.
- 세 개의 독립된 요약 상자는 제거한다.
- 데스크톱은 오늘 항목과 이번 주·생활 항목을 2열로 표시한다.
- 모바일은 같은 두 그룹을 위에서 아래 순서로 표시한다.
- 각 행은 상태 아이콘, 제목, 세부 진행도와 작은 상태 배지로 구성한다.
- 완료는 초록색, 지금 행동 가능은 주황색, 진행 중은 중립색으로 구분한다.
- 행 전체를 기존 콘텐츠 링크로 유지하고 오류 시 재시도 기능도 보존한다.

## 위젯과 데이터 흐름

- 위젯 순서, 숨김, 복구와 기본 배치 기능은 변경하지 않는다.
- 활동 활성화 설정과 메인 탭 알림 계산도 변경하지 않는다.
- `V2AdventureHome`은 현재 보유한 캐릭터·장비·음식·지원권·프리셋 데이터를 압축 카드에
  전달하고, 대시보드의 `serverNow`를 활동 체크에 전달한다.
- `GameChrome`은 기존 게임 상태의 에너지와 사용 가능한 골드를 상단바에 전달한다.
- API와 저장 형식은 변경하지 않는다.

## 반응형·접근성

- 상단 크롬은 최대 864px, 본문은 기존 최대 720px 규칙을 유지한다.
- 320px에서도 여섯 탭이 한 줄에 들어가며 각 탭의 최소 높이는 44px이다.
- 정보는 색상뿐 아니라 아이콘, 문구와 접근성 이름으로 함께 전달한다.
- 긴 이름과 상태 문구는 한 줄 말줄임 처리하되 핵심 수치와 행동 배지는 줄어들지 않는다.
- 카드와 목록에는 `SURFACE_CARD`, `SURFACE_INSET`, `SURFACE_ACCENT`를 사용한다.

## 테스트

- 캐릭터 압축 카드가 EXP, 상태 칩과 장비 6칸을 렌더링하는지 확인한다.
- 활동 체크가 단일 완료 요약, KST 초기화 안내와 2열 그룹 구조를 사용하는지 확인한다.
- 상단바가 텍스트 브랜드, 에너지, 데스크톱 골드를 표시하는지 확인한다.
- 메인 탭이 864px 크롬 폭, 균등 너비, 작은 글자와 기존 알림·드롭다운을 유지하는지 확인한다.
- 320·360·390px 모바일 UI 회귀와 타입·린트·프로덕션 빌드를 검증한다.

## 비목표

- 생활 탭을 다시 마을 메뉴로 합치지 않는다.
- 위젯 종류, 활동 카탈로그, 보상과 초기화 규칙을 변경하지 않는다.
- 다른 개별 콘텐츠 화면의 디자인을 이번 변경에 포함하지 않는다.
- 운영 배포와 점검 모드 변경을 수행하지 않는다.
