# 모험 편의성 개선 설계

## 목표

일일 체크, 거래소, 자동사냥 물약 설정, 농장, 전직 로드맵에서 확인된 불편을 한 번에 정리한다. 데스크톱 통합 상단 메뉴는 이미 별도 작업 중이므로 이 변경에서는 다루지 않는다.

## 일일 체크의 아레나

아레나는 일일 완료 목표가 없는 반복 콘텐츠다. 목록에서는 오늘 참여 횟수를 계속 보여 주되 `countsTowardCompletion: false`인 참고 활동으로 표시한다. 전체 요약과 `오늘` 그룹의 완료 분자·분모는 이 활동을 제외하고, 행의 상태 문구는 `반복`으로 보여 준다.

## 거래소 음식 상태 문구

`실물 없음 — 구매 불가`는 희귀 지도 인스턴스를 검증하는 문구다. 모든 소비 아이템에 이 검사를 적용하지 않고 희귀 지도 아이템에만 적용한다. 음식과 일반 소비 아이템은 해당 문구를 렌더링하지 않으며, 유효하지 않거나 만료된 희귀 지도의 차단 동작은 유지한다.

## 기기 간 물약 설정 유지

자동사냥의 물약 사용 여부와 HP/MP 기준치를 계정 저장 데이터로 보관한다. 클라이언트는 서버 값을 우선 사용하며, 서버에 저장된 값이 없을 때 현재 기기의 로컬 값을 한 번 업로드해 기존 사용자의 설정을 보존한다. 변경 사항은 기존 훅 인터페이스 안에서 저장해 화면 호출부의 영향을 최소화한다. 파싱 시 범위를 제한하고 알 수 없는 값은 기본값으로 복구한다.

## 농작물 파내기

성장 중이며 아직 수확 가능 시간이 되지 않은 밭에 `작물 파내기` 동작을 제공한다. 확인창에는 씨앗, 결과물, 사용한 비료가 반환되지 않는다고 명시한다. 서버는 밭을 잠근 상태에서 다시 검증한 뒤 작물과 재배 시간, 비료 상태를 모두 비우며 인벤토리는 변경하지 않는다. 빈 밭이나 이미 수확 가능한 밭은 거부한다.

## 전직 로드맵 이동

로드맵 상단 도구 모음에 `처음`, `끝`, 각 1차 계열, `현재 직업` 이동 버튼을 추가한다. 버튼은 대상 노드를 선택하고 가로·세로 스크롤 중앙으로 이동시킨다. 1차 계열 버튼은 로드맵 데이터에서 1차 직업을 파생해 하드코딩을 피한다. 현재 직업이 로드맵에 없거나 아직 선택할 수 없는 경우 해당 버튼은 비활성화한다.

## 검증

각 변경은 기존 테스트 스타일에 맞춘 회귀 테스트를 먼저 추가한다. 도메인 로직, API 라우트, 사용자에게 보이는 문구와 이동 제어를 각각 검증하고 마지막에 관련 테스트, 타입 검사, 린트를 실행한다. 배포는 이 작업 범위에 포함하지 않는다.
