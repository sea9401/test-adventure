# 전투 패턴 역할 선택 일치 설계

## 문제

`역할 사용` 블록은 편집 화면과 도움말에서 같은 역할의 장착 스킬 중 장착 순서상 첫 스킬을 가리킨다. 그러나 전투 엔진은 그 스킬이 MP·재사용 대기 등으로 사용 불가능하면 같은 역할의 다음 스킬을 선택한다. 이 때문에 `내 보호막 없음 → 버프`가 첫 버프 대신 후순위 `명상`을 반복해서 사용할 수 있다.

## 동작 계약

- `역할 사용`은 활성 장착 스킬 중 역할이 맞는 첫 스킬 하나에 고정한다.
- 고정된 스킬이 현재 사용 불가능하면 해당 블록을 건너뛰고 다음 패턴 블록을 평가한다.
- 같은 역할의 후순위 스킬로 암묵적으로 대체하지 않는다.
- 특정 스킬 블록, 일반 공격 블록, 스마트 기본 패턴의 동작은 바꾸지 않는다.

## 구현

`resolveV2SkillCast`의 역할 해석기는 역할이 맞는 첫 활성 장착 스킬을 반환한다. 사용 가능 여부는 기존 `evaluateCombatPatternCandidates`의 `isUsable` 검사에 맡긴다. 이 경계는 편집 화면의 `roleCandidate`와 도움말의 장착 순서 계약을 전투 엔진과 일치시킨다.

## 검증

회귀 테스트는 장착 순서를 `마나 보호막 → 마력탄 → 명상`으로 두고, MP가 없어 마나 보호막을 사용할 수 없는 상태에서 `내 보호막 없음 → 버프`, `항상 → 마력탄` 패턴을 평가한다. 수정 전에는 명상이 선택되어 실패하고, 수정 후에는 다음 블록의 마력탄이 선택되어 통과해야 한다. 관련 전투 패턴 테스트와 타입 검사를 함께 실행한다.
