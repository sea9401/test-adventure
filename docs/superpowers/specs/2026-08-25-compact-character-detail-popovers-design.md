# 접힌 캐릭터 요약 상세 카드 설계

## 목표

메인 모험 화면에서 캐릭터 상세 정보가 접혀 있어도 현재 적용 중인 모험 지원권과 음식 효과, 장착 장비의 세부 정보를 필요한 순간에 확인할 수 있게 한다. 요약 카드 자체는 지금의 짧은 형태를 유지하고, 사용자가 해당 요소를 클릭했을 때만 상세 카드를 연다.

## 사용자 경험

- 적용 중인 `모험 지원권` 칩을 버튼으로 바꾼다. 클릭하면 지원권 혜택, 남은 시간, 만료 시각을 보여주는 읽기 전용 상세 카드를 연다.
- 적용 중인 음식 칩을 버튼으로 바꾼다. 클릭하면 음식 이름, 품질, 적용 효과, 남은 시간, 만료 시각을 보여주는 읽기 전용 상세 카드를 연다.
- 장착된 장비 슬롯을 버튼으로 바꾼다. 클릭하면 인벤토리와 상세 캐릭터 카드에서 이미 사용하는 `V2ItemCard`를 읽기 전용으로 열어 실제 굴림, 강화, 제작 품질, 제작자, 세트 정보를 보여준다.
- 빈 장비 슬롯은 현재 모양을 유지하되 클릭 가능한 컨트롤로 만들지 않는다.
- 한 번에 상세 카드 하나만 연다. 다른 요소를 누르면 기존 카드를 닫고 새 카드를 연다.
- 바깥 영역 클릭, 닫기 동작, `Esc` 키로 카드를 닫을 수 있어야 한다.

## 모바일 배치

- 상세 카드는 클릭한 요소의 화면 좌표를 기준으로 열되, 좌우 위치를 뷰포트 내부로 제한한다.
- 카드 최대 너비는 모바일 뷰포트에서 좌우 안전 여백을 뺀 값을 넘지 않는다.
- 상단 고정 UI와 하단 안전 여백을 고려해 카드 최대 높이를 제한한다.
- 내용이 화면 높이보다 길면 페이지 전체가 아니라 카드 본문만 세로 스크롤한다.
- 화면 회전, 리사이즈 또는 페이지 스크롤로 기준 요소와 위치가 어긋나면 열린 카드를 닫는다.

## 구성과 데이터 흐름

`CompactCharacterSummary`가 현재 열린 상세 항목과 클릭 좌표를 상태로 관리한다. 지원권과 음식은 이미 전달되는 `adventureSupport`, `activeFoodBuff` 값을 사용하므로 API 변경은 없다. 장비는 기존 `equipped`와 `owned`에서 장착 개체를 해석하고, 개체의 굴림·강화·제작 데이터를 `V2ItemCard`에 전달한다.

지원권과 음식용 상세 카드는 공통 팝오버 셸을 사용한다. 셸이 포털, 닫기 동작, 접근성 역할, 뷰포트 제한과 스크롤을 담당하고, 각 카드 본문은 해당 도메인의 기존 포맷 함수와 상수를 재사용한다. 장비는 기존 `V2ItemCard`의 위치 보정과 읽기 전용 표시를 그대로 재사용한다.

## 접근성

- 클릭 가능한 칩과 장비 슬롯은 실제 `button` 요소로 렌더링한다.
- 버튼 이름에 대상 이름과 상세 정보 보기 목적을 포함한다.
- 상세 카드는 적절한 팝오버/대화상자 역할과 제목 연결을 제공한다.
- 키보드 포커스 표시를 유지하고 `Esc`로 닫을 수 있게 한다.
- 색상만으로 클릭 가능 여부나 상태를 구분하지 않는다.

## 예외 처리

- 지원권 만료 시각이 유효하지 않거나 이미 만료됐으면 상세 카드를 열지 않는다.
- 음식 효과가 열린 동안 만료되면 남은 시간을 만료 상태로 표시하며, 다음 상태 갱신 때 기존 칩과 함께 사라진다.
- 장착 ID에 대응하는 보유 장비 개체나 카탈로그 정의가 없으면 해당 슬롯을 빈 슬롯처럼 비활성 처리한다.

## 테스트와 검증

- 접힌 요약의 지원권 칩을 클릭하면 혜택·남은 시간·만료 시각 카드가 열리는지 테스트한다.
- 음식 칩을 클릭하면 품질·효과·남은 시간 카드가 열리는지 테스트한다.
- 장착 장비 슬롯을 클릭하면 실제 개체 옵션이 포함된 `V2ItemCard`가 열리는지 테스트한다.
- 빈 슬롯은 버튼이 아니며 카드를 열지 않는지 테스트한다.
- 다른 항목 클릭 시 기존 상세 카드가 교체되고 `Esc` 또는 닫기 동작으로 사라지는지 테스트한다.
- 모바일 크기에서 위치 계산 결과가 뷰포트 안전 여백을 넘지 않고 긴 내용이 카드 내부 스크롤로 제한되는지 단위 테스트한다.
- 관련 테스트, TypeScript 검사, ESLint, 프로덕션 빌드를 실행한다.

## 범위 제외

- 접힌 요약에 남은 시간을 항상 노출하는 변경
- 지원권 또는 음식 효과의 서버 계산 변경
- 장비 장착·해제·강화 기능
- 활성 프리셋 상세 카드
- API 또는 데이터베이스 변경
