# 콘텐츠 알림 출처 표시 설계

## 목표

메인 탭의 주황색 알림 점이 어느 하위 콘텐츠에서 발생했는지 드롭다운에서 즉시 확인할 수 있게 하고, 사용자가 환경 설정에서 콘텐츠 알림 점을 켜거나 끌 수 있게 한다.

## 동작

- 행동 가능한 활동이 있는 메인 탭에는 기존처럼 주황색 점을 표시한다.
- 점이 있는 탭의 드롭다운을 열면 해당 하위 콘텐츠 행에도 주황색 점과 구체적인 활동 상태를 표시한다.
- 한 하위 경로에 행동 가능한 활동이 여러 개면 각 활동의 제목과 상태를 모두 표시한다.
- 기존 생활 메뉴의 진행 중 상태 안내는 유지한다. 행동 가능한 상태는 출처를 구분할 수 있도록 활동 제목을 포함한다.
- 환경 설정의 `콘텐츠 알림 표시`를 끄면 메인 탭과 하위 메뉴의 주황색 점을 모두 숨긴다.
- 알림 표시를 꺼도 모험 홈 활동 목록, 완료율, 활동별 활성화 설정은 바꾸지 않는다.
- 새 설정은 계정의 모험 홈 환경설정에 저장하며 기본값은 `true`다.

## 구조와 데이터 흐름

`AdventureHomePreferences`에 `activityNotificationsEnabled`를 추가한다. 서버 API와 클라이언트 provider가 이 값을 사용해 `activityTabDots`를 계산하므로, 설정 변경을 낙관적으로 반영한 직후 영속 내비게이션도 갱신된다. 서버 정규화는 값이 명시적으로 `false`일 때만 끄고 기존 저장 데이터에는 켜짐을 적용한다.

`MainTabNav`는 특정 경로의 활동을 집계하는 순수 함수를 사용한다. 모든 드롭다운 탭에서 이 함수를 호출하되, 알림 점은 `snapshot.notifications.paths`에 해당 경로가 있을 때만 표시한다. 메뉴 진입 경로와 실제 활동 경로가 다른 자동 벌목·채광은 `생활 지도`의 관련 경로로 명시해 실제 활동 이름과 상태를 모아 보여준다. 생활 메뉴는 알림이 없을 때도 기존 우선순위에 따른 진행 상태를 계속 보여준다.

## 오류 처리

설정 저장은 기존 `AdventureDashboardProvider.updatePreferences` 흐름을 사용한다. 저장 실패 시 낙관적 변경을 되돌리고 환경 설정 화면에 저장 실패 안내를 표시한다.

## 테스트

- 환경설정 정규화가 기존 저장값에는 알림을 켜고 명시적 `false`는 보존하는지 검증한다.
- 알림 계산이 설정 off에서 빈 탭·경로 결과를 반환하는지 검증한다.
- 메인 내비게이션에서 전투 하위 알림의 출처와 상태가 표시되는지 검증한다.
- 환경 설정 화면에 콘텐츠 알림 스위치가 노출되는지 검증한다.
- provider의 낙관적 설정 변경 및 실패 롤백은 기존 회귀 테스트로 함께 보호한다.
