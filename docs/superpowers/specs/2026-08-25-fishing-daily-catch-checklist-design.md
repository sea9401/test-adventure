# 낚시 일일 어획물 체크표 설계

## 목적

낚시에서 요리 재료로 지급되는 어획물 5종의 오늘 획득량과 등급별 일일 최대치를 낚시 화면에서 언제든 확인할 수 있게 한다.

## 사용자 경험

- 기존 낚시 상태 영역에 `요리 재료 일일 획득` 체크표를 항상 표시한다.
- 일반, 신선, 고급, 특급, 전설 어획물을 고정된 등급 순서로 나열한다.
- 각 행은 어획물 이름과 `오늘 획득량 / 일일 최대치`를 표시한다.
- 최대치에 도달한 행은 완료 아이콘과 완료 색상으로 구분한다.
- 낚시터에 처음 들어왔을 때 오늘의 전체 진행량을 표시하고, 어획 성공 또는 지급 한도 확인 뒤에는 해당 등급 행을 즉시 갱신한다.

## 데이터 흐름

1. `fishing-stock.v1`의 오늘 날짜별 `awarded` 값을 서버에서 읽는다.
2. 서버는 어획물 정의와 일일 최대치를 결합해 5종 전체의 표시용 진행 목록을 만든다. 오늘 기록이 없거나 특정 등급 기록이 없으면 획득량은 0이다.
3. `GET /api/v2/fishing/status`가 낚시 코인 진행량과 함께 전체 어획물 진행 목록을 반환한다.
4. 클라이언트 훅은 상태 응답을 검증해 보관한다.
5. 챔질 응답의 기존 `catchItemDaily` 값으로 같은 목록의 해당 등급만 교체한다. 이 값은 재료 지급 성공, 확률 미당첨, 일일 한도 도달 모두에서 반환되므로 추가 요청 없이 화면이 최신 상태를 유지한다.

## 컴포넌트 경계

- `fishingStock.ts`: 저장 상태를 화면용 일일 진행 목록으로 변환하는 순수 함수를 제공한다.
- 낚시 상태 API: 저장값을 읽어 전체 목록을 반환한다.
- `useFishing.ts`: API 응답 파싱과 챔질 후 단일 행 갱신을 담당한다.
- `FishingView.tsx`: 체크표 렌더링만 담당한다. 새 표면은 `SURFACE_INSET`을 사용해 배경 이미지가 비치지 않게 한다.

## 오류 처리

- 상태 조회에 실패하면 낚시 동작은 막지 않고 체크표를 숨긴다.
- 잘못된 목록이나 알 수 없는 아이템은 무시한다.
- 획득량은 0 이상 정수로, 최대치는 1 이상 정수로 정규화한다.
- 챔질 응답에 해당 등급 행이 없으면 기존 전체 목록을 유지한다.

## 테스트

- 저장값이 오늘 날짜와 일치할 때 5종 전체의 획득량과 최대치를 올바르게 만드는 단위 테스트.
- 이전 날짜 기록이 오늘 진행량에 섞이지 않는 단위 테스트.
- 상태 API가 저장된 진행량을 전체 목록으로 반환하는 라우트 테스트.
- 초기 상태 응답으로 체크표 5행이 렌더링되고, 챔질 뒤 해당 행이 갱신되는 UI/훅 회귀 테스트.

## 제외 범위

- 어획물 일일 최대치 또는 지급 확률 변경.
- 별도 낚시 탭, 팝업, 알림 설정 추가.
- 위험한 낚시의 화물이나 낚시 코인 진행량 변경.
