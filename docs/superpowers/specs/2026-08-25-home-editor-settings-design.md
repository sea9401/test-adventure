# 홈 편집 환경설정 이동 설계

## 목표

홈 화면에 항상 노출되는 `홈 편집` 진입점과 편집 상태를 제거하고, 같은 기능을 `/settings/preferences`의 `홈 화면 구성` 영역에서 제공한다.

## 사용자 경험

- 홈은 저장된 위젯 순서와 숨김 상태대로 콘텐츠만 표시한다.
- 환경설정의 `홈 화면 구성`에서 보이는 위젯을 위·아래로 이동하거나 숨길 수 있다.
- 숨긴 위젯은 별도 목록에서 다시 표시할 수 있다.
- `기본 배치로 되돌리기`는 기본 순서와 기본 숨김 목록을 한 번에 복원한다. 스태미나 위젯은 기본 숨김 상태다.
- 기존 `체크 항목 관리`도 환경설정에 함께 노출한다.

## 구조

`AdventureHomeLayoutSettings`는 위젯 순서·숨김 편집 UI만 담당한다. `V2PreferencesView`가 대시보드 상태를 전달하고 기존 `updatePreferences`를 통해 저장하며, 실패 시 오류 배너를 표시한다. `V2AdventureHome`과 `AdventureHomeWidgetGrid`는 편집 책임을 제거하고 저장된 배치를 렌더링하는 역할만 유지한다.

서버 API와 저장 형식은 변경하지 않는다. 기존 낙관적 반영과 실패 롤백을 그대로 사용한다.

## 오류 처리

레이아웃 또는 체크 항목 저장이 실패하면 환경설정 화면에 `홈 설정을 저장하지 못해 이전 상태로 되돌렸습니다.`를 표시한다. 공급자의 기존 롤백 동작이 화면 상태를 복원한다.

## 테스트

- 홈 화면에 `홈 편집` 버튼과 편집 컨트롤이 더 이상 나타나지 않는지 확인한다.
- 환경설정에 홈 구성과 체크 항목 관리가 나타나는지 확인한다.
- 이동·숨김·복원·기본 배치 조작이 정확한 환경설정 패치를 저장하는지 확인한다.
- 관련 단위 테스트, 전체 테스트, 타입 검사, 린트와 프로덕션 빌드를 실행한다.
