# 사냥터 상태 카드 및 인벤토리 세트 표기 보완 설계

## 목표

모바일 사냥터의 접이식 캐릭터 상태 정보가 펼침·접힘 상태 모두에서 같은 정보 계층과 안정적인 줄 배치를 유지하게 한다. 인벤토리에서는 중복된 도감 문구를 정리하고, 장착 장비 요약에 누락된 세트 정보를 복구한다.

## 범위

### 사냥터 캐릭터 상태

- 접힌 요약에도 현재 직업 숙련도를 별도 줄로 표시한다.
- 펼친 상태의 전환 문구는 `간략히 보기`, 접힌 상태는 `상세 보기`로 표시한다.
- 위쪽 요약과 아래쪽 상세 카드의 캐릭터 이름 및 부제 글자 크기를 각각 동일하게 맞춘다.
- HP 충전약과 MP 충전약은 합쳐진 한 줄이 아니라 각각 독립된 줄로 표시한다.
- 충전약 수량의 자릿수에 따라 줄이 합쳐지거나 갈라지지 않도록 두 줄 위치를 고정한다.
- MP를 사용하지 않는 캐릭터는 기존처럼 MP 충전약 정보를 노출하지 않는다.
- 기존 기본 펼침과 마지막 펼침 상태 저장 동작은 유지한다.

### 인벤토리 장비

- 회색 분류 문구 `도감`은 유지한다.
- 초록색 버튼의 문구를 `도감 일괄등록 (N)`에서 `일괄등록 (N)`으로 바꿔 화면상 `도감 도감 일괄등록` 중복을 제거한다.
- 장착 장비 6슬롯 카드 하단에 세트 정보를 한 줄 추가한다.
- 정규 세트(`setId`)와 태그 세트(`setTags`)를 모두 기존 캐릭터 장비 카드와 같은 이름으로 해석한다.
- 세트 장비는 `세트 · 이름`, 비세트 장비는 흐린 `세트 없음`을 표시해 슬롯 높이를 일정하게 유지한다.
- 빈 슬롯은 기존 `비어 있음` 표시를 유지하며 세트 문구 대신 자리 표시만 둔다.
- 정렬, 품질 기준 판매, 일괄 판매, 선택 판매, 장비 옵션 카드 동작은 변경하지 않는다.

## 제외 범위

- 상단 헤더, 캐릭터 아이콘, 알림 띠 및 메뉴의 크기나 배치
- 모험 탭 또는 메인 화면 통합
- 장비 카드 목록의 정렬 및 배치 변경
- 배포 및 점검 모드 변경

## 구현 방식

동시 작업 충돌을 줄이기 위해 기존 컴포넌트 경계를 유지하는 최소 변경을 적용한다.

- `CompactBattlePlayerStatus`에 선택적 숙련도 값을 전달하고 요약 줄을 렌더링한다.
- `V2DungeonFloorView`가 이미 계산하는 최신 `statusProficiency`를 요약과 상세 카드에 함께 전달한다.
- 충전약 표기는 두 개의 블록 줄로 분리하고 캐릭터 이름·부제의 타이포그래피를 상세 카드와 맞춘다.
- `EquipmentTab`은 버튼 내부의 중복 `도감`만 제거한다.
- `EquippedItemSummaryGrid`는 장비 카탈로그의 세트 목록을 조회해 기존 캐릭터 카드와 같은 세트 라벨을 만든다. 공용 데이터 구조나 다른 장비 화면은 리팩터링하지 않는다.

## 검증

- 사냥터 상태 회귀 테스트에서 숙련도, 전환 문구, 충전약 두 줄 및 저장된 펼침 상태를 검증한다.
- 인벤토리 도감 버튼 테스트에서 화면 조합이 `도감` + `일괄등록 (N)`인지 검증한다.
- 장착 요약 테스트에서 정규 세트, 태그 세트, 비세트 장비 표기를 검증한다.
- 관련 테스트, TypeScript 검사, 변경 파일 ESLint 및 프로덕션 빌드를 실행한다.
