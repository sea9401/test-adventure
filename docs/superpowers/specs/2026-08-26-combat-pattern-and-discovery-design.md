# 전투 패턴 AND 조건 발견성 개선 설계

## 목표

이미 저장·평가를 지원하는 복합 조건을 플레이어가 쉽게 발견하고, `내 HP가 충분함`과
`혈전 준비가 없음`을 동시에 만족할 때만 혈전을 사용하도록 구성할 수 있게 한다.

## 현재 상태

- 전투 패턴 데이터는 `all`(모든 하위 조건 만족)과 `any`(하나 이상 만족)를 지원한다.
- 저장 파서는 최대 4개의 하위 조건을 보존하며, 엔진은 재귀적으로 조건을 평가한다.
- 편집기는 이를 `모두 만족`과 `하나 만족`으로만 표시해 `AND`/`OR`를 찾는 사용자가
  기능이 없다고 인식하기 쉽다.

## 접근 방식

1. **기존 편집기의 발견성 개선(선택)** — 저장 포맷과 평가 로직은 유지하고 선택지와
   복합 조건 영역에 `AND`/`OR` 용어와 의미를 함께 표시한다. 위험이 가장 작고 기존
   패턴과 완전히 호환된다.
2. 모든 단일 조건에 `AND 조건 추가` 바로가기를 붙인다 — 접근은 빠르지만 조건 행의
   조작 밀도가 높아지고 모바일 화면이 복잡해진다.
3. 중첩 조건 트리 편집기로 교체한다 — 표현력은 크지만 현재 깊이·개수 제한보다 과도한
   기능이며 저장 UI와 검증 범위를 크게 넓힌다.

## UI와 문구

- 조건 선택지는 `AND (모두 만족)`, `OR (하나 만족)`으로 표시한다.
- 복합 조건 편집 영역은 AND가 모든 하위 조건을, OR가 하나 이상의 하위 조건을
  만족해야 한다고 짧게 설명한다.
- 화면 상단 안내와 게임 설명서에 다음 구성 예를 넣는다.
  - `내 HP 50% 이상 AND 혈전 준비 없음 → 혈전`
  - `혈전 준비 있음 → 파멸일격·멸왕일도 같은 필살기`
- 기존 불투명 표면 규칙을 지키며 새 반투명 패널은 만들지 않는다.

## 데이터와 전투 동작

`V2CombatCondition`, 저장 파서, API payload, 전투 평가 로직은 변경하지 않는다. 따라서
기존 `all`/`any` 패턴과 프리셋은 마이그레이션 없이 그대로 작동한다. 스킬 쿨다운·MP·
효과 중복 여부는 기존처럼 조건 통과 뒤 `isUsable` 단계에서 자동으로 검사한다.

## 테스트

- 전투 패턴 편집기가 AND/OR 의미와 혈전 예시를 렌더링하는지 확인한다.
- 게임 설명서가 복합 조건 구성법과 같은 예시를 안내하는지 확인한다.
- 기존 전투 패턴 단위 테스트로 `all`/`any` 평가와 파싱 회귀를 확인한다.

## 범위 밖

- 새로운 조건 종류나 중첩 깊이 추가
- 기존 저장 데이터 변환
- 배포 또는 점검 모드 변경
