# 위험 해역 귀환 낚시 코인 조정 설계

## 배경

위험 해역 일반 어획은 어종별 고정 낚시 코인을 성공 즉시 지급하고, 귀환 시 남은
화물 가치에 비례한 낚시 코인을 추가로 지급한다. 최대 위험도에서 귀환 보상이 화물
가치의 10%까지 올라가면서 두 지급 경로의 합계가 의도보다 크게 느껴진다.

심연 균열 심층에서 기본 미끼를 사용하고 최대 위험도로 안전 귀환하는 경우, 출현
가중치 기준 어획당 평균 보상은 약 140.5코인이다. 이번 조정의 목표는 일반 위험 해역의
중첩 코인을 약 40% 줄여 같은 조건의 평균을 약 85.5코인으로 낮추는 것이다.

## 변경 사항

귀환 낚시 코인 공식을 다음과 같이 변경한다.

```text
기존: floor(남은 화물 가치 × 현재 위험도 × 0.02)
변경: floor(남은 화물 가치 × 현재 위험도 × 0.01)
```

계수는 계산 모듈의 이름 있는 상수로 관리한다. 정상 귀환은 전체 남은 화물 가치를,
사고 강제 귀환은 사고 후 남은 화물 가치만 사용한다. 현재와 같이 한 귀환의 화물
전체를 합산한 뒤 소수점 이하를 버린다.

어획 성공 시 즉시 지급되는 어종별 4~40코인은 유지한다. 이 보상은 실패나 사고가
발생해도 이미 확정된 최소 보상 역할을 계속한다.

## 변경하지 않는 범위

- 거대어 기여도 보상 80/140/190/220코인과 발견자 40코인 추가 보상
- 어종별 고정 코인, 화물 가치와 출현 가중치
- 어획 성공 후 위험도 상승 규칙
- 위험도별 사고 확률, 최대 화물 손실과 장비의 화물 보호 효과
- 미끼·장비·강화·교환 가격과 재료 비용
- 위험 해역에는 별도 일일 상한을 추가하지 않음
- 낚시 지갑과 위험 해역 저장 데이터 구조

저장 구조가 바뀌지 않으므로 데이터 마이그레이션이나 기존 항해 상태 변환은 필요하지
않다. 배포와 점검 모드도 이번 변경 범위에 포함하지 않는다.

## 데이터 흐름

1. 어획 성공 시 기존 어종별 고정 코인을 즉시 지갑에 더한다.
2. 어획물을 기존 화물 가치로 항해 화물에 누적하고 위험도를 1 올린다.
3. 정상 귀환 또는 사고 강제 귀환 시 서버가 남은 화물 가치를 확정한다.
4. 계산 모듈이 남은 화물 가치와 현재 위험도에 1% 계수를 적용한다.
5. 서비스가 계산된 귀환 코인을 확정 어획물과 같은 트랜잭션에서 한 번만 지급한다.

유효하지 않은 숫자, 음수, 안전 정수 상한 처리와 중복 귀환 방지는 기존 동작을 그대로
유지한다.

## 사용자 안내

게임 매뉴얼의 위험 해역 귀환 보상 공식을 2%에서 1%로 수정한다. 결과 화면은 서버가
반환한 실제 지급액을 표시하므로 별도의 UI 계산 변경은 하지 않는다.

## 검증

- 순수 계산 테스트에서 `2,700 × 위험도 5`의 귀환 보상이 135코인인지 확인한다.
- 대표 최고 화물 가치 1,500과 위험도 5에서 귀환 보상이 75코인인지 확인한다.
- 정상 귀환과 사고 강제 귀환 라우트 테스트에서 실제 남은 화물 가치, 소수점 버림,
  지갑 증가량이 새 계수와 일치하는지 확인한다.
- 빈 화물, 음수·비유한 입력과 안전 정수 상한 방어가 유지되는지 확인한다.
- 어획 즉시 코인과 거대어 보상 테스트를 회귀 실행해 값이 바뀌지 않았는지 확인한다.
- 매뉴얼 렌더 테스트에서 1% 공식이 노출되고 이전 2% 안내가 남지 않았는지 확인한다.

## 완료 기준

- 심연 균열 심층·기본 미끼·최대 위험도 안전 귀환의 출현 가중치 기준 평균이 약
  85.5코인이다.
- 일반 위험 해역 외 코인 지급 경로와 모든 저장 형식은 변경되지 않는다.
- 관련 계산, 서비스, 라우트와 매뉴얼 테스트가 통과한다.
