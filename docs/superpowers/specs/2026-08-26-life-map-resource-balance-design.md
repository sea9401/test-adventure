# 생활 지도 주 생산물 보유량 표시 설계

## 목적

생활 지도에서 벌목지나 채광지를 선택했을 때, 다른 화면으로 이동하지 않고 해당 지역의 주 생산물 보유량을 확인할 수 있게 한다.

## 표시 위치와 범위

- 왼쪽 `선택 가능한 지역` 목록은 현재 구성을 유지한다.
- 오른쪽 선택 지역 상세의 벌목 수종·채광 광맥 카드에 주 생산물명과 `보유 N개`를 함께 표시한다.
- 벌목지는 선택한 수종의 원목만, 채광지는 선택한 광맥의 주 광석만 표시한다.
- 채광 부산물인 돌·석탄·원석 보석은 표시하지 않는다.
- 낚시터 화면은 변경하지 않는다.

예시:

- `소나무 원목 · 보유 1,234개`
- `철광석 · 보유 0개`

## 데이터 흐름

1. 생활 지도 진입 시 기존 `/api/v2/me/inventory` API에서 재료 인벤토리를 조회한다.
2. 선택한 벌목 수종 또는 채광 광맥의 `materialId`로 보유량을 찾는다.
3. 재료 카탈로그의 이름과 로케일 숫자 형식으로 상세 카드에 표시한다.

API 응답을 받기 전에는 보유량을 숨긴다. 조회가 실패해도 오류 화면으로 바꾸지 않고 기존 지역 정보와 이동 동작을 유지한다.

## UI 원칙

- 기존의 불투명 `SURFACE_INSET` 상세 카드를 그대로 사용한다.
- 현재 수종·광맥 배지는 유지하고, 그 아래 보조 정보 줄에 생산물명과 보유량을 넣어 정보 밀도를 제한한다.
- 보유량은 `tabular-nums`를 적용해 숫자 폭 변화에도 안정적으로 보이게 한다.
- 라이트·다크 모드의 기존 표면 및 텍스트 색상 체계를 재사용한다.

## 테스트

- 주입한 재료 인벤토리 기준으로 벌목지의 주 원목 보유량이 표시되는지 검증한다.
- 주입한 재료 인벤토리 기준으로 채광지의 주 광석 보유량이 표시되는지 검증한다.
- 채광 부산물 보유량은 상세에 표시하지 않는지 검증한다.
- 인벤토리가 아직 로드되지 않은 독립 렌더링에서는 보유량 문구가 나타나지 않는지 검증한다.
