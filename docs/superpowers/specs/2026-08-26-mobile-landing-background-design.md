# 모바일 로그인 배경 구도 보존 설계

## 문제

로그인 대문의 지역 이미지는 가로형이지만 모바일 세로 화면에서도 `object-cover`로 표시된다. 화면을 채우기 위해 이미지가 크게 확대되면서 좌우 구도가 대부분 잘리고, 특히 주요 요소가 양쪽에 배치된 전투 이미지에서 빈 중앙만 강조된다.

## 설계

- `sm` 미만에서는 각 슬라이드를 두 겹으로 표시한다.
  - 아래 레이어는 같은 이미지를 `cover`로 채우고 어둡게 처리해 빈 공간 없이 배경을 만든다.
  - 위 레이어는 `contain`으로 표시해 원본의 전체 구도를 보존한다.
- `sm` 이상에서는 기존처럼 선명한 단일 이미지를 `cover`로 표시한다.
- 기존 슬라이드 순서, 전환 시간, 수동 선택, 오류 이미지 건너뛰기, 캡션은 변경하지 않는다.
- 새 이미지 자산이나 네트워크 의존성은 추가하지 않는다.

## 검증

- 정적 렌더링 테스트로 모바일 배경 레이어와 `contain` 장면 레이어가 함께 생성되는지 확인한다.
- 기존 슬라이드 순환 테스트와 관련 린트·타입 검사를 실행한다.
