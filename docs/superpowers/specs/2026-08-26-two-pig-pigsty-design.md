# 돼지우리 두 마리 독립 비육 설계

## 목표

돼지우리 한 칸에 실제 돼지를 최대 두 마리까지 두고 각 돼지를 독립적으로 12시간 비육한다. 한 마리의 비용과 보상을 기존의 절반으로 줄여 두 자리를 모두 운영했을 때 총비용과 총보상이 기존 한 마리 출하와 같도록 유지한다.

## 확정 경제

- 돼지우리 정원: 2마리
- 돼지 한 마리 비육 시간: 12시간
- 첫 건설·재건축: 첫 돼지 1마리 포함
- 이후 입식: 돼지 한 마리당 배합 사료 2개
- 한 마리 출하: 돼지고기 4개, 농사 경험치 8
- 두 마리 합계: 배합 사료 4개, 돼지고기 8개, 농사 경험치 16

완료된 돼지는 출하할 때까지 자기 자리를 차지한다. 비육 중인 돼지와 출하 대기 돼지를 합쳐 두 마리를 넘을 수 없다. 한 마리를 먼저 들인 뒤 나중에 두 번째 돼지를 들이면 두 타이머는 서로 다른 시각에 끝난다.

## 상태 모델

`RanchState.version`을 3으로 올린다. 각 `RanchSlotState`에 `shipmentStartedAt: number[]`를 추가한다. 닭장과 외양간은 빈 배열을 사용하고 기존 `feed`, `lastSettledAt`, `progressMs` 생산 모델을 유지한다.

돼지우리는 다음 필드 조합을 사용한다.

- `shipmentStartedAt`: 현재 비육 중인 돼지별 입식 시각, 최대 2개
- `readyCycles`: 출하 대기 중인 돼지 수, 최대 2
- `readyItems`: `readyCycles * 4`
- `feed`: 항상 0. 사료는 입식 요청에서 즉시 소비한다.
- 총 점유 수: `shipmentStartedAt.length + readyCycles`, 최대 2

정착 시 현재 시각에서 12시간 이상 지난 입식 시각만 제거하고 같은 수만큼 `readyCycles`, `readyItems`, `pigCycles`를 증가시킨다. 아직 끝나지 않은 입식 시각은 그대로 보존하므로 서로 다른 진행도를 독립적으로 유지한다.

## 저장 호환성

버전 1의 고정 축사와 버전 2의 가변 부지 저장을 모두 읽고 버전 3으로 반환한다.

버전 1·2 돼지 저장은 기존 한 마리의 비용·보상을 잃지 않도록 변환한다.

- `feed >= 4`: 이미 사료 4개를 지불한 진행분이므로 같은 시작 시각의 비육 중 돼지 2마리로 변환한다.
- `readyCycles >= 1`: 기존 출하 대기 보상 8개·경험치 16을 보존하도록 출하 대기 돼지 2마리로 변환한다.
- 진행 시작 시각은 `lastSettledAt - progressMs`로 복원하고 유효 범위로 제한한다.
- 출하 대기 변환을 우선하며 총 정원 2를 넘는 진행분은 만들지 않는다.

새 버전 3 저장은 `shipmentStartedAt`만 신뢰하며 손상된 미래 시각, 음수, 비수치 값과 정원 초과 항목을 제거한다.

## 동작과 오류

돼지우리 건설·돼지우리로 재건축할 때 `shipmentStartedAt`에 현재 시각 하나를 넣는다. 추가 입식은 정확히 사료 2개만 허용하며, 총 점유 수가 2이면 `shipment_capacity`로 거부한다. 수확·출하는 준비된 돼지만 모두 처리하고 비육 중인 다른 돼지의 타이머는 변경하지 않는다.

재건축은 사료, 반복 생산 진행도, 출하 대기, 비육 중 돼지가 모두 없을 때만 허용한다.

## UI

돼지우리 카드는 `돼지고기 4개 / 마리 · 12시간 · 최대 2마리`를 표시한다. 내부에는 돼지 1·2 두 자리를 각각 표시한다.

- 비육 중: 남은 시간
- 출하 대기: 출하 대기
- 빈 자리: 빈 자리

빈 자리가 있고 사료가 2개 이상이면 `사료 2개로 돼지 데려오기` 버튼을 활성화한다. 두 자리가 모두 차면 `돼지우리 가득 참`으로 비활성화한다. 기존 불투명 표면 상수를 유지한다.

## 검증

`ranch.test.ts`에서 서로 다른 시각에 입식한 두 돼지의 독립 완료, 정원 제한, 부분 출하 후 재입식, 버전 2·3 정규화를 검증한다. `farm.test.ts`에서 사료 2개 소비와 마리당 돼지고기 4개·경험치 8 지급을 검증한다. `FarmRanchPanel.test.tsx`에서 두 자리 상태와 문구를 검증한다. 관련 서버 경로, 도움말, 전체 테스트, TypeScript, ESLint, 이미지 검사와 Next.js 빌드를 실행한다.

## 범위 밖

돼지우리 건설 비용, 해금 레벨, 돼지고기 요리 요구량, 닭장·외양간 생산 방식은 변경하지 않는다. 배포와 점검 모드 변경도 수행하지 않는다.
