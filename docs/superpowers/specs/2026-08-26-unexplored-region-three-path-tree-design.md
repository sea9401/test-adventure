# 미개척지 3대동맥 탐사 노드 설계

## 목표

PoE 아틀라스 트리처럼 화면 하단의 `탐사 시작`에서 전체 노드망이 위쪽으로 펼쳐지게 한다. 시작점은 정확히 좌·중·우 세 경로에만 연결되며, 콘텐츠는 시작점에 직접 붙지 않고 대동맥 옆의 선택형 군집으로 배치한다.

## 전체 구조

- 탐사 시작: 화면 하단 중앙, 1포인트
- 시작 대동맥: 좌·중·우 세 갈래, 각 경로에 동일 효과의 공통 소형 노드 3개
- 콘텐츠 층: 대동맥마다 하단과 상단에 콘텐츠 군집 1개씩, 총 6개
- 연결로: 하단 콘텐츠 통과 후와 상단 콘텐츠 통과 후에 인접 대동맥으로 건너갈 수 있는 소형 노드 2개
- 최종 공통 핵심 노드 없음: 특정 종착점을 정답으로 만들지 않는다.

| 경로 | 하단 군집 | 상단 군집 |
| --- | --- | --- |
| 좌측 | 태고 야수 | 공허 균열 |
| 중앙 | 고대 기계체 | 심연 침식체 |
| 우측 | 잊힌 군단 | 빙의 원혼 |

## 콘텐츠 군집

각 군집은 대동맥의 진입·출구 노드 사이에 붙는 작은 원형 우회로다. 대동맥만 따라가면 다음 구역으로 통과할 수 있고, 해당 콘텐츠를 원하는 유저만 군집 안에 포인트를 쓴다.

군집 하나는 일반 Ⅰ·일반 Ⅱ·정예 개체 해금 주요 노드 3개, 출현 비중·탐사 경험치·전용 재료·행동 변이·희귀 보상을 나눈 소형 노드 6개, 콘텐츠 규칙을 크게 바꾸는 핵심 노드 1개로 구성한다.

## 출현 비중

기본 생태 가중치는 항상 100이다. 콘텐츠 군집의 주요 이정표에 따라 특수 계열 가중치는 12, 24, 36, 60으로 변하며, 특수 계열 하나만 활성화했을 때 표시 비율은 약 11%, 19%, 26%, 38%가 된다. 여러 계열을 동시에 활성화할 수 있고 정수 백분율 합계는 항상 100%로 맞춘다.

## 목업 동작과 검증

기존 노드 선택, 활성화, 개별 반환, 전체 초기화, 몬스터 명단 표시를 유지한다. 총 포인트 40은 전체 밸런스가 확정되기 전의 임시 수치다.

- 시작점의 직접 연결이 정확히 3개인지 확인한다.
- 세 경로의 공통 노드가 각각 3개이며 효과가 동일한지 확인한다.
- 콘텐츠 군집 6개가 각각 10개 노드인지 확인한다.
- 군집을 투자하지 않고 대동맥을 통과할 수 있는지 확인한다.
- 하단·상단 연결로로 인접 경로를 이동할 수 있는지 확인한다.
- 출현 비중 11%→19%→26%→38%와 합계 100%를 확인한다.
- 1440px 화면에서 세 대동맥과 원형 군집이 구분되는지 확인한다.
