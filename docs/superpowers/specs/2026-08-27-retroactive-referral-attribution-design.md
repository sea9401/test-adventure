# 사후 추천인 등록 설계

## 목적

홍보 링크 없이 가입한 사용자도 가입 시점과 관계없이 게임 홍보 화면에서 추천인을
한 번 등록할 수 있게 한다. 등록 전에 완료한 홍보 이벤트 과제도 현재 진행도를 기준으로
소급 인정해 추천인과 피추천인 양쪽에 보상을 지급한다.

## 정책

- 사후 등록 가능 기간에는 제한을 두지 않는다.
- 한 로그인 주체는 추천인에게 한 번만 귀속되며 등록 후 변경하거나 취소할 수 없다.
- 자기 홍보 코드는 등록할 수 없다.
- 탈퇴 후 재가입해도 기존 보상 이력이 있는 로그인 주체는 다시 등록할 수 없다.
- 사후 등록 시 가입 단계 보상을 양쪽에 지급한다.
- 등록 전에 달성한 사냥, 길드, 생활 과제는 서버의 현재 상태로 재계산해 양쪽에 소급
  지급한다.

## 사용자 경험

게임 홍보 탭에서 아직 다른 사용자에게 귀속되지 않은 사용자에게만 `추천인 등록`
영역을 보여 준다. 사용자는 `/r/<code>` 형태의 홍보 링크 전체 또는 16자리 홍보 코드를
붙여 넣을 수 있다. 등록 버튼 근처에는 계정당 한 번만 등록할 수 있고 변경할 수 없다는
설명을 표시한다.

성공하면 입력 영역을 숨기고 최신 추천 진행도와 소급 완료 상태를 즉시 표시한다. 잘못된
형식, 존재하지 않거나 비활성화된 코드, 자기 추천, 이미 귀속되었거나 과거에 보상을 받은
로그인 주체는 보상을 만들지 않고 이해 가능한 오류 문구를 표시한다.

## 서버 구조와 데이터 흐름

인증된 사후 등록 전용 API를 추가한다. API는 원본 사용자 확인, 활성 기기 세션 확인,
사용자·IP 호출 제한을 거친 뒤 요청에서 홍보 링크 또는 코드를 정규화한다.

하나의 데이터베이스 트랜잭션에서 다음 작업을 수행한다.

1. 기존 `attributeReferral` 서비스로 홍보 코드 소유자와 자기 추천 여부를 확인하고,
   로그인 식별 HMAC 원장 및 `referral_conversions.referred_user_id` 고유 제약을 통해
   최초 귀속만 확정한다.
2. 귀속과 함께 양쪽 가입 단계 우편 보상을 만든다.
3. 기존 `loadReferralTutorialSnapshot`으로 현재 사냥 깊이, 길드 가입 상태, 생활 숙련도
   최고 레벨을 읽는다.
4. 기존 `rewardReferralTutorialTasks`로 달성한 과제만 기록하고 양쪽 소급 보상을 합산
   우편으로 만든다.

어느 단계든 실패하면 귀속과 모든 보상이 함께 롤백된다. 동시에 같은 요청이 들어와도
식별 원장과 데이터베이스 고유 제약이 중복 귀속 및 중복 보상을 차단한다.

## 인터페이스 변경

추천 요약 응답에 현재 사용자가 추천인 등록을 완료했는지를 명확히 나타내는 상태를
제공한다. 게임 홍보 화면은 이 상태로 등록 폼 노출 여부를 결정한다. 새 API는 성공 시
소급 완료된 과제 식별자를 반환하고, 실패 시 클라이언트가 사용자용 문구로 변환할 수
있는 제한된 오류 코드를 반환한다. 홍보 코드 소유자의 개인정보는 오류 응답에 노출하지
않는다.

## 오류 처리

- 요청 본문이나 링크/코드 형식이 잘못되면 `400`으로 거절한다.
- 로그인 또는 활성 세션이 없으면 기존 인증 응답을 사용한다.
- 유효하지 않은 코드와 비활성 코드는 동일 계열의 사용자 안내로 처리한다.
- 자기 추천 및 이미 귀속된 로그인 주체는 각각 영구 등록이 불가능함을 안내한다.
- 예상하지 못한 데이터베이스 오류는 보상을 남기지 않고 `500`으로 처리한다.

## 테스트와 문서

- 코드 정규화가 원시 코드와 홍보 링크를 모두 받고 다른 형식을 거절하는지 단위 테스트한다.
- 사후 귀속 성공, 자기 추천, 유효하지 않은 코드, 현재 계정 중복, 탈퇴·재가입 중복을
  서버 테스트로 검증한다.
- 등록 트랜잭션이 가입 보상과 기존 진행도 소급 보상을 한 번만 만드는지 검증한다.
- 게임 홍보 화면이 미귀속 사용자에게만 입력 폼을 표시하고 성공·오류 상태를 올바르게
  처리하는지 컴포넌트 테스트한다.
- 게임 설명서에 무기한 사후 등록, 1회 제한, 기존 과제 소급 인정 정책을 추가한다.

## 범위 제외

- 등록한 추천인의 변경 또는 취소
- 운영자 수동 귀속 도구
- 홍보 링크 방문만으로 로그인된 기존 사용자를 자동 귀속하는 동작
- 이벤트 보상 수량이나 과제 조건 변경
- 배포
