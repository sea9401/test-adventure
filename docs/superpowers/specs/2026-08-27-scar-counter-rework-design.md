# 상흔의 계수기 개편 설계

## 목표

혈맥 절단검이 출혈을 소비하지 않도록 바뀐 뒤 가치가 낮아진 상흔의 계수기의 `출혈 1스택 추가` 효과를, 4행동 폭발 주기에 맞는 출혈 유지 효과로 교체한다.

## 동작

- 혈맥 폭발이 발동하면 대상의 기존 출혈 지속 횟수를 최소 5회로 갱신한다.
- 출혈이 이미 5회를 초과하면 지속 횟수를 줄이지 않는다.
- 현재 출혈 스택, 최대 스택, 스택당 피해 계수와 피해 출처는 바꾸지 않는다.
- 현재 출혈 중첩당 방어 3% 감소, 2행동 효과는 유지한다.
- 혈맥 절단검이 없거나 실제 혈맥 폭발이 발동하지 않으면 갱신하지 않는다.

## 구현

공유 6티어 유니크 런타임은 `refresh_bleed` 명령을 생성한다. PvE/PvP 어댑터는 기존 `applyBleedChangeToDots`를 사용해 스택을 더하지 않고 `setTurns: 5`로 갱신한다. 표시 문구는 `출혈 지속 최소 5회`와 방어 감소 기준을 함께 안내한다.

## 검증

- 공유 런타임이 `apply_dot +1` 대신 `refresh_bleed(5)`를 생성하는지 확인한다.
- PvE/PvP에서 2회 출혈은 5회가 되고, 6회 출혈은 6회로 유지되며 스택·피해 출처가 보존되는지 확인한다.
- 장비 툴팁 문구가 새 효과를 정확히 안내하는지 확인한다.
