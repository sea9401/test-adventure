# 미개척지 160노드 탐사망 목업 설계

## 목적

지금까지 합의한 미개척지 탐사망의 전체 규모와 이동 동선을 한 화면에서 검토할 수 있는 독립형 HTML 목업을 만든다. 이 목업은 실제 게임 기능을 구현하거나 밸런스 수치를 확정하는 용도가 아니라, 160개 노드의 분포·깊이·접근 경로를 시각적으로 검증하는 용도다.

## 화면 구조

- 기존 게임의 불투명 카드, 상단 메뉴, 라이트·다크 색상 체계를 따른다.
- 중앙의 탐사 시작에서 바깥으로 확장되는 동심원형 탐사망을 사용한다.
- 160개 노드를 한 화면에 모두 표시한다.
- 작은 공용 노드는 아이콘만 표시하고, 특화 풀 핵심·중간 노드·심부 대형 노드만 이름을 표시한다.
- 선택한 노드의 이름, 종류, 효과, 깊이와 연결 상태는 우측 상세 패널에서 보여준다.
- 모바일에서는 탐사망 아래에 상세 패널을 배치하고, 탐사망 영역 안에서 확대·축소 없이 전체 구조를 축소 표시한다.

## 노드 구성

총 노드 수는 정확히 160개다.

| 종류 | 개수 | 역할 |
| --- | ---: | --- |
| 탐사 시작 | 1 | 미개척지 개방과 탐사망 시작점 |
| 작은 공용 성장 | 72 | 골드, 일반 재료, 장비 드랍, 장비 품질, 특화 전용 재료 증가 |
| 중간 공용 | 21 | 순수 이득 9개, 위험·보상형 12개 |
| 특화 풀 핵심 | 12 | 해당 몬스터 풀의 요청 출현 비중 20%p 추가 |
| 풀별 강화 | 48 | 12개 풀마다 출현·재료·흔적·집중 강화 4개 |
| 심부 대형 핵심 | 6 | 보상 변환, 위험 강화, 흔적과 개인 보스 개방 |

모든 노드는 1포인트를 사용한다. 사용 가능한 탐사 포인트의 최대치는 40으로 표시한다.

## 특화 몬스터 풀

12개 특화 풀은 현재 전투 엔진으로 표현 가능한 성향을 사용한다.

1. 철갑 군단 — 물리 방어와 피해 경감
2. 마력 방벽체 — 마법 방어와 상태 피해 저항
3. 재생 군체 — 높은 체력과 회복
4. 붉은 광전대 — 공격, 치명타와 격노
5. 수정 포격대 — 마법 공격
6. 정밀 사냥단 — 적중, 치명타와 방어 관통
7. 폭주 기계 — 속도와 추가 공격
8. 그림자 추적자 — 회피와 속도
9. 맹독 군락 — 중독
10. 혈흔 망자 — 출혈
11. 혹한 군단 — 둔화와 마법 공격
12. 파쇄 거수 — 방어 관통과 강타

각 특화 핵심 바깥에는 강화 노드 4개를 하나의 작은 군집으로 배치한다. 출시 보상 구성은 `2026-08-28-unexplored-reward-economy-design.md`를 우선한다.

- 출현 강화: 해당 풀 요청 비중 +10%p
- 재료 탐색: 해당 풀 전용 재료 획득 증가
- 앞쪽 6개 풀의 전리품 탐색: 해당 풀 몬스터의 일반 장비·골드 기대량 +20%
- 상위 6개 풀의 흔적 추적: 해당 흔적을 20% 확률로 1개 추가 획득
- 집중 강화: 해당 풀 몬스터가 강해지는 대신 고유 보상 증가

## 심부 대형 핵심

바깥 둘레에는 다음 6개를 균등하게 배치한다.

- 황금 탐사대
- 수집가의 길
- 무구 발굴단
- 위험한 계약
- 집중 추적
- 우두머리의 흔적

우두머리의 흔적은 하나의 방향에 종속되지 않도록 양쪽 인접 경로에서 접근할 수 있게 한다. 다른 대형 핵심도 최소 두 경로를 갖는다.

## 연결과 도달 비용

- 서로 다른 둘레 사이의 기본 연결은 노드당 하나의 방사형 부모만 사용한다.
- 다중 접근 경로는 대각선 부모를 추가하는 대신 같은 둘레의 좌우 연결로 확보한다.
- 특화 풀 핵심도 인접한 특화 핵심끼리 둘레로 연결해 한 방향에 종속되지 않게 한다.
- 첫 특화 풀 핵심은 시작점에서 최소 6포인트, 최대 8포인트로 도달한다.
- 첫 풀 강화는 최소 9포인트로 도달한다.
- 한 특화 풀의 강화 4개 완성에는 최소 15포인트가 필요하다.
- 중간 공용 핵심은 최소 12포인트로 도달한다.
- 심부 대형 핵심은 최소 18포인트로 도달한다.
- 우두머리의 흔적은 최소 24포인트로 도달한다.
- 각 둘레에는 옆 방향 연결을 두어 중앙까지 돌아가지 않고 인접한 특화 풀로 이동할 수 있게 한다.
- 특화 풀 핵심과 대형 핵심은 각각 최소 두 개의 진입 경로를 갖는다.

목업 검증에서는 실제 최단 경로를 계산해 위 조건을 확인한다. 구조 검토용 목업이므로 개별 노드의 최종 보상 수치는 확정하지 않으며, 효과 종류와 상대적 크기만 표시한다.

## 상호작용

- 노드를 클릭하면 우측 상세 패널이 갱신된다.
- 공용, 특화 풀, 위험·보상, 심부 필터로 관련 노드와 연결선만 강조할 수 있다.
- `10 / 20 / 30 / 40포인트 예시` 버튼으로 단계별 활성 경로를 바꿔 볼 수 있다.
- 활성 특화 풀과 요청 출현 비율을 요약해서 표시한다.
- 기본 몬스터 풀은 최소 30%, 특화 풀 합계는 최대 70%로 표시한다.
- 비활성 연결선은 기본 상태에서 배경처럼 흐리게 표시한다.
- 활성 노드끼리 연결된 경로는 주황색으로 선명하게 표시한다.
- 노드를 선택하면 시작점부터 해당 노드까지의 최단 경로를 보라색으로 강조한다.
- 선택 노드에 직접 연결된 선은 최단 경로보다 약한 보라색으로 표시해 다음 이동 방향을 보여준다.
- 모든 특화 풀을 한꺼번에 선택하는 기능과 실제 노드 구매·환불 경제는 이 목업에 넣지 않는다.

## 가독성 원칙

- 작은 노드의 텍스트 라벨은 기본적으로 숨긴다.
- 노드 종류는 크기, 색, 직관적인 아이콘을 함께 사용해 구분한다.
- 선택 노드와 활성 경로는 색과 선 굵기로 강조하며, 비활성 노드를 컨테이너 전체 투명도로 처리하지 않는다.
- 비활성 연결선은 노드보다 낮은 대비를 사용하고, 선택·활성 경로와 겹칠 때만 높은 대비로 전환한다.
- 범례와 노드 개수 검증 결과를 화면에 고정 표시한다.
- 선이 특화 풀 라벨 위를 지나지 않도록 군집과 둘레 간 간격을 확보한다.

## 검증

- DOM에 렌더된 노드가 정확히 160개인지 확인한다.
- 종류별 개수가 1/72/21/12/48/6인지 확인한다.
- 모든 노드가 시작점에서 도달 가능한지 확인한다.
- 특화 및 대형 핵심의 진입 경로가 최소 두 개인지 확인한다.
- 10/20/30/40포인트 예시가 각 포인트 상한을 넘지 않는지 확인한다.
- 브라우저 콘솔 오류가 없는지 확인한다.
- PC와 390px 모바일 화면에서 페이지 자체의 가로 넘침이 없는지 확인한다.
