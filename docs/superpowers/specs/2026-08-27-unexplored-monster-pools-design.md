# 미개척지 특화 몬스터 풀 설계

## 현재 런타임 상태 (2026-08-30)

이 문서의 아래 표는 몬스터별 전투 정체성을 정한 원설계 기록이다. 이후 모든 풀의
세 몬스터가 활성화되어 현재 런타임은 12개 풀·36종을 사용한다. 표의 `기본형`,
`공격형`, `변칙형`은 설계상 구분을 설명하는 문구이며 런타임 `role` 필드는 아니다.
현재 필드별 소비 경계와 제거 근거는
[미개척지 몬스터 풀 런타임 메타데이터 현황](./2026-08-30-unexplored-monster-pool-runtime-metadata.md)을
따른다.

## 목적과 범위

미개척지 탐사망에서 추가할 12개 특화 몬스터 풀의 전투 역할을 정의한다. 최초 출시 버전은 풀마다 아래 표의 `기본형` 1종만 사용해 총 12종으로 구성했으며, 이후 공격형과 변칙형까지 순차적으로 활성화했다. 이 문서의 능력치는 미개척지 공통 몬스터를 `1.00`으로 둔 상대 배율이다. 절대 능력치는 이후 성장 시스템과 상위 유저 전투 시뮬레이션을 기준으로 별도 산정한다. 출시 흔적 대상과 개인 보스 구성, 최종 드롭률은 `2026-08-28-unexplored-reward-economy-design.md`를 우선한다.

새로운 전투 조작이나 독립적인 전투 규칙은 만들지 않는다. 현재 전투 엔진이 지원하는 체력, 공격력, 물리·마법 방어, 속도, 회피, 적중, 치명타, 추가 공격, 상태 피해 저항과 기존 몬스터 스킬을 조합한다.

## 공통 규칙

- 최초 출시 시 각 특화 풀은 기본형 1종으로 구성했다. 현재는 공격형과 변칙형을 포함한 36종이 모두 실제 조우 풀에 들어간다.
- 한 풀의 몬스터는 동일한 전용 재료를 드롭한다. 흔적은 출시 개인 보스가 연결된 상위 6개 풀에서만 활성화한다.
- 전용 재료는 풀당 1종, 총 12종만 우선 추가한다.
- 몬스터별 별도 재료는 만들지 않는다. 이후 제작 콘텐츠에 필요한 경우에만 추가한다.
- 현재 같은 풀의 세 몬스터는 처치 시간과 관계없이 같은 풀 공통 보상 규칙을 사용한다.
- 출시 대상 상위 풀의 흔적은 `우두머리의 흔적` 노드가 활성화된 동안 특화 몬스터 처치 시 1개를 기본 지급하며, 풀별 흔적 강화와 공용 흔적 추적 노드만 추가 획득 확률에 관여한다.
- 집중 강화는 해당 풀의 핵심 전투 특성만 더 강하게 만들고 전용 재료와 지정 보상을 증가시킨다.

## 구현·밸런스 경계

- 현재 조우·보상·이미지 검증은 활성화된 특화 몬스터 36종 전체를 대상으로 한다.
- 이 문서의 상대 배율은 풀별 정체성을 비교하기 위한 기준이며 최종 데이터값이 아니다.
- 적중, 회피, 치명타, 상태 피해 저항처럼 공통 기준값이 0일 수 있는 항목은 절대 수치를 전투 시뮬레이션으로 정한다.
- 회복 사용 횟수와 마법 스킬 사용 횟수는 기존 스킬과 몬스터 MP로 제한한다.
- 중독, 출혈과 둔화는 기존 상태이상 처리 방식을 사용하고 중첩량과 수치만 조절한다.
- 집중 강화의 전투 수치는 별도 시뮬레이션으로 산정하고, 전용 재료 확률과 보상 노드 수치는 `2026-08-28-unexplored-reward-economy-design.md`를 따른다.
