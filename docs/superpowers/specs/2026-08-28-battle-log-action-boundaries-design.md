# 전투 로그 행동 경계 보존 설계

## 문제

철벽 태세는 전투 엔진에서 정상적으로 사용되고 반사 횟수도 준비되지만, 사용 시점의 로그가 `info` 한 줄뿐이다. 전투 로그 화면은 중간 HP 바를 접은 뒤 `info` 로그를 직전 행동 카드의 부가 효과로 묶으므로, 철벽 태세가 독립 행동으로 보이지 않거나 상대 행동에 붙어 보일 수 있다.

## 목표

- 철벽 태세 사용을 PvE와 PvP 모두 독립된 행동 로그로 기록한다.
- 반사 피해 계산, 충전 횟수, 자동 전투 패턴과 전투 결과는 바꾸지 않는다.
- 화면에서 중간 HP 바가 접혀도 철벽 태세의 행동 경계가 유지되게 한다.

## 설계

철벽 태세 발동 시 기존의 부가 정보 로그 대신 공격자 방향을 가진 직접 행동 로그를 남긴다. PvE에서는 플레이어 행동 종류를, PvP에서는 시전자 진영에 맞는 행동 종류와 진영 정보를 사용한다. 문구는 `철벽 태세! 철벽 반사 3회 준비`로 통일한다.

전투 로그 화면은 직접 행동 로그를 새 행동 카드의 시작으로 이미 취급한다. 따라서 표시 계층에 스킬명 정규식이나 철벽 태세 전용 예외를 추가하지 않고, 전투 엔진이 실제 행동을 구조적으로 올바르게 기록하도록 고친다.

## 검증

- PvE 철벽 태세 사용 로그가 `player_attack` 행동으로 남는지 검사한다.
- PvP 철벽 태세 사용 로그가 시전자 진영의 직접 행동으로 남는지 검사한다.
- 실제 문제와 같은 `다른 행동 → HP 바 → 철벽 태세 → HP 바` 형태를 화면에 전달해 두 개의 독립 카드로 렌더링되는지 검사한다.
