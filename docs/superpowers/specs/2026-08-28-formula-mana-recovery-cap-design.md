# 태초현자 MP 회복 상한 설계

## 문제

태초술사 `근원공명`은 태초회귀 시 최대 MP의 8%를 회복하고, 태초현자
`마력 최적화`는 완전식 완성 시 최대 MP의 10%를 추가 회복한다. 스킬 MP 비용은
고정값인데 회복량은 최대 MP에 비례하므로, 최대 MP가 성장하면 한 주문식 주기의
회복량이 실제 소비량을 넘어 MP가 고갈되지 않는다. 완전식 강제 시전은 현재 MP가
0이어도 허용되어 자원 생성이 더 분명하게 드러난다.

## 검토한 접근

1. **MP 비용 추가 인상**: 당장의 손익분기점만 늦추며 최대 MP가 더 성장하면 같은
   문제가 재발한다.
2. **각 회복 효과를 현재 시전 비용으로만 제한**: 태초회귀 8%의 순증가는 막지만,
   완전식 10%가 이전 주문식 투자와 무관하게 자원을 만들거나 MP 0 강제 시전의
   회복 정체성을 잃는다.
3. **실제 소비량 원장으로 제한**: 유료 MP 회복은 해당 시전의 실제 소비량을 넘지
   못하게 하고, 완전식 주기에는 소비량과 이미 돌려받은 양을 누적해 10% 회복을
   남은 미환급 소비량 이하로 제한한다.

3번을 채택한다. 고정 비용과 최대 MP 비례 회복을 유지하면서도 어떤 순서와 최대
MP에서도 누적 회복이 누적 소비를 넘지 않는 유일한 구조적 해결이다.

## 동작 규칙

- MP 비용이 0보다 큰 스킬의 `manaRestore` 효과는 `min(표시 회복량, 실제 소비 MP)`를
  사용한다.
- MP 비용이 0인 명상형 스킬은 기존 최대 MP 비례 회복을 그대로 유지한다.
- 완전식 상태는 현재 주기의 실제 MP 소비량과 이미 적용된 유료 스킬 MP 회복·비용
  환급량을 함께 보관한다.
- 완전식 10% 회복은 `min(최대 MP의 10%, 주기 소비량 - 주기 내 기존 회복량)`이다.
- 완전식이 끝나면 단계, 사용 스킬 ID, 소비량, 회복량을 모두 초기화한다.
- MP 부족 강제 시전은 유지하지만 현재 주기에서 미환급 소비량이 0이면 MP를 회복하지
  않는다.
- 기존 전투 중 상태에는 새 필드가 없을 수 있으므로 누적 소비·회복의 기본값은 0이다.
- PvE와 PvP가 동일한 순수 계산 함수를 사용한다.

## 로그와 설명

- 스킬 자체 MP 회복 로그에는 상한 적용 후 수치를 표시한다.
- 완전식 회복이 실제로 적용되면 `[마력 최적화] 마나 N 회복` 로그를 별도로 남긴다.
- `근원공명`과 `마력 최적화` 설명에는 실제 소비량 상한을 명시한다.

## 검증

- 유료 `manaRestore`가 실제 소비 MP보다 커지지 않는다.
- 무료 명상은 기존 수치로 회복한다.
- 완전식이 이전 주문식의 미환급 소비량까지만 회복한다.
- MP 0 강제 시전은 미환급 소비가 없으면 MP를 생성하지 않는다.
- PvE와 PvP에서 같은 상한과 로그를 적용한다.
