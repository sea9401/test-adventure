# 숙련의 탑 100층 도전 구간 설계

## 목표

숙련의 탑을 50층에서 100층으로 확장해 역대 최고층 랭킹에 충분한 변별력을 만든다. 기존 숙련도 공급량은 늘리지 않고, 51~100층은 현재 최상위권도 서로 다른 층에서 멈추는 순수 도전 구간으로 운영한다. 100층은 현재 콘텐츠만으로 쉽게 정복하는 목표가 아니라 향후 장비·직업·신규 콘텐츠 성장을 수용하는 장기 상한으로 둔다.

## 핵심 규칙

- 탑 최대층은 100층이다.
- 숙련 증서 보상 최대층은 50층이다.
- 1~50층의 난이도, 일일 기본 보상, 최초 돌파 보너스는 변경하지 않는다.
- 51~100층에서는 숙련 증서, 최초 돌파 보너스, 아이템, 재화, 능력치 보상을 추가하지 않는다.
- 51층 이상에 도달해도 일일 기본 보상은 50층 기준인 숙련 증서 2,400개로 고정한다.
- 최초 10·20·30·40·50층 보너스 총 1,500개는 현재와 동일하게 계정당 한 번만 지급한다.
- 랭킹은 기존과 동일하게 역대 최고층만 사용한다. 턴 수, 남은 HP, 달성 시각 등의 동률 기준은 추가하지 않는다.
- 하루 첫 실제 전투의 스태미나 200, 실패 후 30초 재입장 대기, KST 일일·주간 경계는 유지한다.

## 진행과 체크포인트

- 기존 10층 단위 주간 체크포인트를 90층까지 자연스럽게 확장한다.
- 그 주에 60층을 돌파했다면 새 등반에서 61층, 90층을 돌파했다면 91층을 시작점으로 선택할 수 있다.
- 매주 월요일 00:00 KST에는 주간 최고층과 체크포인트만 초기화한다.
- 일일 최고층과 수령 상태는 매일 초기화하고, 역대 최고층과 최초 돌파 보너스 기록은 유지한다.
- 실패하면 현재 연속 등반은 종료되며, 30초 뒤 1층 또는 이번 주에 확보한 최근 체크포인트 다음 층에서 다시 시작한다.
- 100층 완료 뒤에는 같은 날 100층 수호자에게 연습 재도전할 수 있다. 연습 전투는 기록·보상·스태미나를 변경하지 않는다.
- 기존 50층 완료자는 배포 뒤 기록이 초기화되지 않으며, 다음 정상 도전이 51층으로 이어진다.

## 보상 계산 분리

탑의 콘텐츠 상한과 보상 상한을 별도 상수로 둔다.

- `MASTERY_TOWER_MAX_FLOOR = 100`
- `MASTERY_TOWER_REWARD_MAX_FLOOR = 50`

`masteryTowerFloorReward(floor)`는 상태 저장용 층 범위와 무관하게 보상 계산 층을 `min(floor, 50)`으로 제한한다. 따라서 50층부터 100층까지 일일 기본 보상은 모두 2,400이다. 최초 돌파 보너스 카탈로그는 현재의 10·20·30·40·50층만 유지한다.

보상 수령, 날짜 변경 시 미수령 자동 지급, 관리자 일일 초기화 경로가 모두 같은 보상 계산 함수를 사용해야 한다. 클라이언트가 보상층이나 수량을 전달하지 않으며 서버 저장 상태만 신뢰한다.

## 난이도 곡선

1~50층의 `masteryTowerRequiredPower()`와 수호자 산식은 그대로 유지한다. 51~100층은 50층의 요구 전투력 5,100을 시작점으로, 100층 105,000을 목표로 하는 지수 곡선을 사용한다.

개념식은 다음과 같다.

```text
requiredPower(floor) = roundTo10(
  5,100 × (105,000 / 5,100) ^ ((floor - 50) / 50)
)
```

대표 목표치는 다음과 같다. 실제 구현값은 위 공식의 10단위 반올림 결과를 사용한다.

| 층 | 요구 전투력 목표 | 역할 |
| ---: | ---: | --- |
| 50 | 5,100 | 기존 보상 구간 끝 |
| 60 | 9,340 | 현재 상위권 1차 장벽 |
| 70 | 17,100 | 고성장 유저 도전 |
| 80 | 31,310 | 신규 콘텐츠 성장 반영 구간 |
| 90 | 57,340 | 장기 목표 |
| 100 | 105,000 | 미래 최종 목표 |

요구 전투력은 안내 지표일 뿐 자동 승리 조건이 아니다. 기존과 동일하게 실제 수호자와 80턴 전투를 수행해 승패를 결정한다. 수호자의 기본 HP·공격·방어·속도는 요구 전투력과 층수를 입력으로 하는 현재 산식을 재사용하되, 51층 이후의 큰 전투력 값이 실제 능력치에도 반영되게 한다.

## 10층 단위 보스

일반층은 공통 지수 곡선을 따르고, 60·70·80·90·100층은 별도 보스 프리셋으로 약점을 검사한다. 기존 전투 엔진의 물리·마법 공격, 치명타, 추가 행동, 명중·회피, 상태 이상 스킬을 조합하며 운에 따라 규칙이 바뀌는 무작위 기믹은 넣지 않는다.

### 60층: 심연의 처형자

- 높은 물리 공격과 치명타
- 분쇄·포효·출혈 계열 스킬
- 추가 행동으로 방어와 단기 생존력을 검사

### 70층: 비전 재판관

- 마법 공격 중심
- 비전 폭발과 한기·독 상태 이상
- 장기전에서 누적되는 마법·상태 이상 압박을 검사

### 80층: 추격의 환영

- 매우 높은 속도·명중·회피
- 반복되는 추가 행동
- 느린 빌드와 명중이 낮은 빌드를 강하게 제약

### 90층: 불멸의 문지기

- 매우 높은 HP와 방어
- 공격력 상승 폭은 다른 보스보다 낮게 두되 80턴 제한을 실질적인 화력 검사로 사용
- 관통·방어 약화·지속 화력의 필요성을 강조

### 100층: 탑의 초월자

- 물리·마법 혼합 공격
- 비전 폭발, 포효, 분쇄, 한기 등 여러 계열을 함께 사용
- 높은 속도·명중·치명타와 다중 추가 행동
- 화력, 생존, 명중, 속도 중 하나라도 크게 부족하면 정복하기 어려운 최종 보스

보스 배율은 고정 프리셋으로 관리한다. 최종 수치는 자동 전투 시뮬레이션으로 조정하되 난이도 목표를 낮춰 100층을 현재 스펙에 맞추지 않는다. 대표적인 현재 상위 빌드는 60~75층 사이에 분산되고, 80층 이후는 신규 성장 콘텐츠가 누적된 뒤 진입하는 것을 목표로 한다.

초기 구현 프리셋은 다음 값으로 고정한다. 배율은 해당 층의 일반 수호자 기본 능력치에 곱하고, 명중·치명타는 일반 수호자 값에 더한다. 추가 행동 확률은 기존 전투 엔진처럼 100%를 넘는 구간마다 확정 추가 행동 한 번과 나머지 확률을 뜻한다.

| 층 | HP | 공격 | 방어 | 속도 | 명중 | 치명타 | 추가 행동 | 스킬 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | --- |
| 60 | ×1.20 | ×1.30 | ×1.05 | ×1.10 | +10 | +12%p | 200% | 분쇄, 포효, 출혈 |
| 70 | ×1.25 | ×1.25 | ×1.10 | ×1.15 | +14 | +10%p | 240% | 비전 폭발, 한기, 독 |
| 80 | ×1.30 | ×1.30 | ×1.10 | ×1.35 | +22 | +15%p | 320% | 포효, 분쇄, 한기 |
| 90 | ×1.75 | ×1.15 | ×1.65 | ×1.00 | +15 | +8%p | 180% | 분쇄, 출혈, 포효 |
| 100 | ×1.80 | ×1.55 | ×1.35 | ×1.40 | +30 | +22%p | 500% | 비전 폭발, 포효, 분쇄, 한기 |

70층과 100층은 기본 공격을 마법으로 설정한다. 60·80·90층은 물리 기본 공격을 사용한다. 100층의 혼합 공격은 마법 기본 공격과 물리·마법 스킬 조합으로 구현한다. 시뮬레이션 결과가 목표 분포에서 크게 벗어날 때는 별도의 사용자 승인 없이 위 프리셋의 공격·HP·방어 배율을 최대 10% 범위에서만 조정할 수 있다. 요구 전투력 공식과 100층 목표값 105,000은 변경하지 않는다.

## 화면과 안내

- 탑 화면의 최대층과 진행 표시를 100층으로 바꾼다.
- 50층을 달성하면 `일일 보상 상한 달성`과 `51층부터 도전 구간` 안내를 표시한다.
- 51~100층의 층 정보에는 `도전 구간 · 추가 보상 없음`을 명시한다.
- 일일 예상 보상은 51층 이상에서도 숙련 증서 2,400개로 표시한다.
- 100층 완료 뒤에만 `100층 연습 재도전`을 표시한다.
- 전투 로그의 최고층 문구와 재입장 대기 문구를 100층 기준으로 변경한다.
- 게임 설명서는 총 100층, 50층 보상 상한, 51~100층 도전 구간, 확장 체크포인트를 설명한다.
- 랭킹 UI와 정렬 방식은 변경하지 않고 51~100층 기록을 그대로 표시한다.

## 저장 데이터와 호환성

숙련의 탑은 기존 `mastery-tower.v1` JSON 저장 구조를 유지하므로 DB 마이그레이션이 필요하지 않다. 파서의 층 상한만 100으로 확장한다.

- 기존 `todayBestFloor`, `runFloor`, `weekBestFloor`, `lifetimeBestFloor` 값은 그대로 유지한다.
- 기존 50층 역대 기록은 50층으로 유지되고 새 도전으로만 상승한다.
- 이미 받은 최초 돌파 보너스 목록은 그대로 유지한다.
- 이미 그날 보상을 받은 사용자가 51층 이상을 돌파해도 추가 보상을 받지 않는다.
- 아직 보상을 받지 않은 사용자가 51층 이상을 돌파하면 50층 기준 보상만 받는다.

## 오류와 경계 처리

- 100층을 초과하는 시작층과 요청은 기존 `invalid_start_floor` 또는 `max_floor` 흐름으로 거절한다.
- 51층 이상에서도 일일 첫 전투 스태미나 결제 여부를 중복 변경하지 않는다.
- 보상 수령과 날짜 변경 자동 지급은 동시 요청 시 기존 저장 행 잠금을 유지한다.
- 100층 완료 상태에서 일반 다음 층 요청을 만들지 않고 100층 연습 요청만 허용한다.
- 알 수 없는 옛 저장값과 100을 초과한 값은 100으로 안전하게 제한한다.

## 테스트와 검증

- 1~50층 요구 전투력과 보상 값이 기존과 동일한지 회귀 테스트
- 51·60·70·80·90·100층 요구 전투력 공식과 단조 증가 테스트
- 60·70·80·90·100층 보스 이름, 공격 유형, 스킬, 핵심 능력치 프리셋 테스트
- 51~100층에서 일일 기본 보상이 2,400으로 고정되는 테스트
- 최초 돌파 보너스가 50층 이후 추가되지 않는 테스트
- 기존 50층 저장 상태가 51층으로 이어지는 파서·다음 층 테스트
- 90층 체크포인트가 91층 시작점을 제공하고 주간 초기화 시 사라지는 테스트
- 100층 성공, 실패, 연습 재도전, 101층 거절 테스트
- 보상 수령·미수령 자동 지급 API 회귀 테스트
- 탑 화면과 전투 화면의 보상 상한·도전 구간·100층 문구 테스트
- 랭킹이 51~100층 역대 기록을 표시하는 테스트
- 설명서의 100층 및 50층 보상 상한 안내 테스트
- 대표 상위 전투 빌드 시뮬레이션으로 현재 기준 60~75층 분산과 100층 미정복 목표 확인

## 제외 범위

- 숙련 증서 이외의 신규 보상
- 51~100층 최초 돌파 업적·칭호·장식
- 랭킹 동률 세분화 또는 시즌 랭킹
- 수동 조작 전투와 탑 전용 장비
- 무작위 층 효과와 매주 바뀌는 보스 규칙
- 기존 1~50층 난이도 및 숙련도 공급량 재조정
