# 재전직 주기 MP 성장 누적 완화 설계

## 목표

재전직을 반복해 정신 영구 저점이 높은 캐릭터의 레벨업 MP가 지나치게 커지는 문제를 완화한다. HP 공식과 이미 확정된 캐릭터의 자원 기록은 변경하지 않는다.

조정 후에도 정신은 MP 성장의 저점을, 지능은 MP 성장폭의 고점을 높인다. 다만 99회 누적되는 레벨업 MP에서는 영구 스탯 단계의 40%만 적용한다. Lv.1 MP 굴림에는 현재 영구 스탯 효과를 그대로 유지한다. 여기에 순수하게 성장한 현재 지능·정신을 최대 MP에 직접 반영해, MP가 부족할 때 두 스탯을 육성하는 선택을 만든다.

## 확인된 문제

운영 캐릭터 류하린은 Lv.100, 표시 지능·정신 60·60이지만 정신 영구 저점은 218이다. 현재 공식에서는 정신 저점 단계가 `floor((218 - 15) / 10) = 20`이므로 다음 범위가 적용됐다.

- Lv.1 MP: `85..115`, 실제 111
- 레벨업당 MP: `23..25`, Lv.2~100 실제 누계 2,373
- 캐릭터 자체 MP: 2,484
- 목걸이 MP: 207
- 최종 최대 MP: 2,691

장비 중복, 세트 MP, 최대 MP 패시브 또는 음식 효과는 없었다. 문제는 정신 저점 단계 20이 레벨업 99회에 그대로 더해지는 누적 구조다.

## 확정 산식

영구 스탯의 원래 단계 계산은 유지한다.

```ts
spiFloorStep = floor(max(0, spiFloor - 15) / 10);
intCapStep = floor(max(0, intCap - 60) / 10);
```

Lv.1 MP는 현재 공식과 동일하다.

```ts
mpBaseMin = 65 + spiFloorStep;
mpBaseMax = mpBaseMin + 30 + intCapStep;
```

새 버전의 레벨업 MP만 단계 영향을 40%로 압축한다.

```ts
MP_LEVEL_STEP_SCALE = 0.4;
spiLevelStep = floor(spiFloorStep * MP_LEVEL_STEP_SCALE);
intLevelStep = floor(intCapStep * MP_LEVEL_STEP_SCALE);

mpGainMin = 3 + spiLevelStep;
mpGainMax = mpGainMin + 2 + intLevelStep;
```

기본 영구값에서는 두 단계가 모두 0이므로 기존 기본 범위 `3..5`와 Lv.100 기대 MP 476이 바뀌지 않는다. 영구 정신 저점과 지능 한계치가 충분히 오르면 레벨업 MP도 계속 증가하므로 장기 성장 상한을 두지 않는다.

## 순수 지능·정신 직접 MP

버전 2 기록을 사용하는 캐릭터는 전투 파생의 `baseAllocatedStats`를 기준으로 최대 MP 직접 보너스를 얻는다. 이 값은 영구 저점과 레벨 성장분을 합친 뒤 수행 한계치로 제한한 순수 스탯이며, 직업 보너스와 퍼센트 효과를 적용하기 전 값이다.

```ts
trainedMpBonus =
  max(0, baseAllocatedStats.int - 15) +
  max(0, baseAllocatedStats.spi - 15);

maxMp = floor(
  (lifeMp + trainedMpBonus + equipmentMp) * (1 + maxMpPct / 100),
);
```

- 순수 지능 또는 정신 1당 퍼센트 적용 전 최대 MP가 1 증가하며, 이후 명시적인 `maxMpPct`가 기존처럼 최종 적용된다.
- 기본 스탯 15·15는 직접 보너스를 주지 않아 신규 기본 기대값을 유지한다.
- 수행과 레벨 성장으로 순수 지능·정신이 오르면 현재 최대 MP가 즉시 증가한다.
- 직업 플랫 보너스, 직업 앵커 보정, 음식 스탯, `statPct` 패시브로 오른 지능·정신은 직접 MP에 포함하지 않는다.
- 지능·정신 % 패시브를 장착하거나 해제해도 최대 MP는 변하지 않는다.
- 명시적인 장비 MP와 `maxMpPct`는 기존 최종 적용 순서를 유지한다.
- 버전 1 기록과 레거시 캐릭터에는 이 직접 보너스를 추가하지 않는다.

## 류하린 기준 목표값

정신 영구 저점 218, 지능 유효 한계치 60에서는 `spiFloorStep=20`, `spiLevelStep=8`, `intCapStep=0`이다. 순수 지능·정신 60·60의 직접 MP 보너스는 `(60 - 15) + (60 - 15) = 90`이다.

- Lv.1 MP: `85..115`
- 레벨업당 MP: `11..13`
- Lv.100 무작위 성장 MP: `1,174..1,402`, 기대값 1,288
- 순수 지능·정신 직접 MP 90 포함: `1,264..1,492`, 기대값 1,378
- 현재 목걸이 MP 207 포함: `1,471..1,699`, 기대값 1,585

사용자가 승인한 목걸이 제외 Lv.100 기대 MP 약 1,400에 맞는다. 장비 MP와 최대 MP % 패시브의 최종 적용 순서는 변경하지 않는다.

## 기록 버전과 기존 캐릭터 보존

저장 레코드는 버전별 공용 필드를 유지한다.

```ts
type V2LifeResourceGrowth = {
  version: 1 | 2;
  rolledLevel: number;
  baseHp: number;
  baseMp: number;
  gainedHp: number;
  gainedMp: number;
};
```

- 현재 저장된 `version: 1` 기록은 값과 향후 레벨업 범위를 모두 기존 공식으로 유지한다.
- 배포 후 신규 캐릭터와 완료된 전투 재전직은 `version: 2` 기록을 생성한다.
- `version: 1` 캐릭터가 다음 전투 재전직을 완료하면 기존 기록을 버리고 `version: 2` Lv.1 값을 새로 굴린다.
- 자원 기록이 없는 레거시 캐릭터는 현재처럼 다음 완료 전투 재전직까지 레거시 파생 공식을 유지한다.
- Lv.1 생활직 전환은 재굴림하지 않는다.
- 수행 초기화는 기존 기록 버전과 Lv.1 굴림을 보존하고 누적 성장만 초기화한다.
- 저장값 일괄 변경이나 운영 데이터 마이그레이션은 하지 않는다.

따라서 류하린의 현재 2,691 MP는 유지되며, 다음 재전직에서만 새 공식이 시작된다. 같은 원칙을 모든 기존 버전 1 캐릭터에 적용한다.

## 코드 경계와 데이터 흐름

`lifeResourceGrowth.ts`가 두 버전의 범위를 계산하고 기록을 파싱한다. 버전 1 공식은 회귀 기준으로 그대로 보존하고, 기본 생성 버전만 2로 올린다.

`lifeResourceRangesForProficiency(proficiency, version)`는 동일한 영구 저점·한계치를 읽되 요청된 기록 버전에 맞는 범위를 반환한다. 레벨 상승 경로는 현재 기록의 버전을 반드시 전달한다.

- 일반·일괄 사냥
- 경험치 아이템
- 관리자 레벨 지정 지급

신규 생성과 완료 전투 재전직 경로는 버전 2 범위로 새 기록을 만든다. 전투 파생식은 버전 2에서만 저장된 `baseMp + gainedMp`에 순수 지능·정신 직접 MP를 더한다. 버전 1과 레거시 분기는 기존 파생 결과를 그대로 유지한다. HP 관련 범위·저장·파생식도 변경하지 않는다.

## 화면 표시

사용자 화면에서는 `생애`라는 표현 대신 `현재 성장`과 `다음 재전직 성장`을 사용한다.

- 버전 1 캐릭터: 현재 레벨업 범위는 기존 공식으로 표시하고, 다음 재전직부터 적용될 버전 2 범위를 별도로 안내한다.
- 버전 2 캐릭터: 현재 레벨업 범위만 표시한다.
- 레거시 캐릭터: 현재 레거시 상태와 다음 재전직 버전 2 미리보기를 표시한다.

현재 규칙과 다음 규칙을 섞어 표시하지 않는다.

## 검증

순수 함수 테스트에서 다음을 고정한다.

- 버전 1의 Lv.1·레벨업 범위와 기존 누계가 바이트 단위로 유지된다.
- 버전 2의 기본 영구값은 Lv.1 `65..95`, 레벨업 `3..5`다.
- 류하린 기준 버전 2 범위는 Lv.1 `85..115`, 레벨업 `11..13`이며 순수 지능·정신 직접 MP를 포함한 Lv.100 기대 캐릭터 MP는 1,378이다.
- 정신·지능 영구 단계가 증가할 때 40% 압축된 대응 레벨업 경계가 단조롭게 증가한다.
- 순수 지능·정신 60·60은 직접 MP 90, 100·100은 직접 MP 170을 준다.
- 동일한 순수 스탯에서 지능·정신 `statPct`, 직업 보너스와 음식 효과를 바꿔도 최대 MP가 변하지 않는다.
- HP 범위는 버전과 무관하게 완전히 동일하다.
- 버전 1·2 파싱, 수행 초기화, 레벨 불일치 거부가 모두 동작한다.

통합 테스트에서는 다음을 확인한다.

- 기존 버전 1 캐릭터의 일반 사냥·경험치 아이템·레벨 지급은 버전 1 범위를 사용한다.
- 신규 캐릭터와 완료 전투 재전직은 버전 2를 생성한다.
- 생활직 전환과 수행 초기화는 새 버전을 만들거나 Lv.1 MP를 재굴림하지 않는다.
- 상태 API와 캐릭터 화면이 현재 범위와 다음 재전직 범위를 구분한다.
- 버전 2의 순수 지능·정신 투자만 최대 MP에 직접 반영되고, 장비 MP, 최대 MP %, 버전 1·레거시 캐릭터 파생 및 모든 HP 결과가 기존 규칙을 유지한다.

## 범위 제외

- 기존 캐릭터의 저장된 MP 재계산 또는 보정
- HP 성장 조정
- 장비 MP, 최대 MP 패시브, 스킬 MP 비용 변경
- 지능·정신 % 패시브·직업 보너스·음식 스탯의 최대 MP 반영
- 운영 배포와 데이터 마이그레이션
