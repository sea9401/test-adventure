# Plump Solid 게임 아이콘 디자인

## 목적

게임 화면에 직접 노출되는 범용 유니코드 이모지를 자체 SVG 아이콘으로 교체한다. 아이콘은 기기와 운영체제에 관계없이 같은 모습으로 표시되어야 하며, 작은 UI에서도 빠르게 구분되어야 한다.

참고 이미지의 아이콘을 복제하거나 윤곽을 추적하지 않는다. 통통한 단색 실루엣, 둥근 형태, 흰색 음각이라는 조형 원칙만 참고해 게임의 항목과 용도에 맞는 독자적인 도형을 제작한다.

## 확정된 시각 규칙

- 모든 아이콘은 `64 × 64` 좌표계의 인라인 SVG로 제작한다.
- 아이콘 하나는 선명한 주색 한 가지와 흰색 음각 디테일로 구성한다.
- 외곽선, 그림자, 광택, 그라데이션, 반투명 음영을 사용하지 않는다.
- 모서리와 끝부분은 둥글고 통통하게 정리한다.
- 작은 크기에서 의미가 사라지는 장식은 넣지 않는다.
- 기본 표시 크기는 `20~24px`이며, `18px`에서도 대상을 구분할 수 있어야 한다.
- 색상만으로 의미를 전달하지 않는다. 아이콘은 항상 텍스트 이름이나 접근성 이름과 함께 사용한다.
- 흰색 음각은 배경색을 뚫는 투명 구멍이 아니라 일관된 흰색 디테일로 렌더링한다. 따라서 라이트·다크 표면에서 동일한 인상을 유지한다.

## 제외 범위

- 완성 요리 데이터에 저장되어 있지만 현재 화면에서 렌더링하지 않는 레시피 이모지
- 농장 아이템의 WebP 이미지가 존재할 때 사용되지 않는 이모지 대체값
- `✓`, `✗`, `★`, `→`처럼 상태나 문법을 나타내는 문자 기호
- 이미 `GameIcon` 또는 `CustomGameIcon`으로 표시되는 기존 메뉴·시설 아이콘
- 이번 작업과 관계없는 기존 `CustomGameIcon` 12종의 스타일 개편

## 컴포넌트 구조

새 세트는 기존의 굵은 외곽선형 `CustomGameIcon`과 분리된 `PlumpGameIcon` 컴포넌트로 구현한다. 두 스타일을 한 파일에 섞지 않아 아이콘 세트의 규칙과 테스트 범위를 독립적으로 유지한다.

`PlumpGameIcon`은 다음 인터페이스를 제공한다.

- `name`: 위 30개 식별자만 허용하는 유니온 타입
- `size`: 숫자 또는 CSS 크기, 기본값 `1em`
- `title`: 단독 아이콘에 사용할 접근성 이름
- `className`, `style`, `mirrored`: 기존 아이콘 컴포넌트와 같은 조작 옵션

각 아이콘의 주색은 메타데이터에 고정하고 SVG 도형은 `64 × 64` 좌표계에서 렌더링한다. 장식용 아이콘은 기본적으로 `aria-hidden`이며, 아이콘만으로 버튼이나 상태를 설명하는 경우에만 `title`을 제공한다.

서버와 클라이언트가 공유하는 데이터에는 이모지 문자열 대신 아이콘 식별자를 저장한다. React 화면은 식별자를 `PlumpGameIcon`으로 렌더링한다. 문자열 알림이나 서버 로그에는 아이콘을 삽입하지 않고 순수한 텍스트만 유지한다.

## 화면별 교체

- 출석 화면: 보상 종류를 이모지로 반환하는 함수를 아이콘 식별자 매핑으로 바꾼다.
- 요리 화면: 제목의 프라이팬 이모지와 주방 상점·가공 재료의 `icon` 문자열을 `iconName`으로 교체한다.
- 낚시 명예의 전당·순위표: 1~3위 메달 문자열을 순위 아이콘 컴포넌트로 바꾼다.
- 길드 정착지·시설 기금: 목재·광석 이모지가 포함된 문자열 조립을 제거하고 아이콘과 텍스트를 별도 요소로 렌더링한다.
- 장비 비교: 세트 이름 앞의 연결 고리를 아이콘으로 바꾼다.
- 레벨업·퀘스트 완료: 문장 끝의 축하 이모지를 시각 요소로 분리한다. 문자열만 허용하는 표면이라면 장식 이모지를 제거하고 텍스트만 남긴다.
- 폭풍 원정 지도: 전투 지점 문자를 전투 아이콘으로 바꾼다.

## 오류 처리와 호환성

- 알 수 없는 아이콘 이름은 타입 단계에서 차단한다.
- 런타임에서 잘못된 값이 넘어오는 경계에는 아이콘 없이 텍스트만 표시하는 안전한 대체 경로를 둔다.
- 아이콘 로딩을 위한 외부 네트워크 요청이나 외부 아이콘 패키지를 추가하지 않는다.
- SVG는 현재 색상 모드와 무관하게 같은 고정 팔레트를 사용한다. 주변 카드와 패널은 기존 불투명 표면 규칙을 따른다.

## 검증 기준

1. 30개 식별자가 모두 누락 없이 렌더링된다.
2. 모든 SVG가 `viewBox="0 0 64 64"`를 사용한다.
3. 아이콘 도형에 외곽선, 필터, 그림자, 그라데이션이 없다.
4. 흰색 음각 이외에는 아이콘당 한 가지 주색만 사용한다.
5. `18px`, `20px`, `24px`, `56px`에서 형태를 육안으로 확인한다.
6. 라이트·다크 모드의 불투명 카드 위에서 흰색 음각과 주색이 구분된다.
7. 단독 아이콘은 접근성 이름을 가지며, 텍스트 옆의 장식 아이콘은 스크린 리더에서 숨겨진다.
8. 교체 대상 화면의 컴포넌트 테스트가 통과한다.
9. 범위에 포함된 유니코드 그림 이모지가 해당 화면 코드와 데이터에서 제거되었는지 정적 검색으로 확인한다.
10. 완성 요리 데이터 등 제외 범위의 이모지는 이번 변경에서 건드리지 않는다.

## 배포 범위

이 디자인 승인과 로컬 구현은 배포 승인을 뜻하지 않는다. 구현과 검증이 끝나더라도 사용자가 별도로 배포를 요청하기 전에는 어떤 환경에도 배포하지 않는다.
