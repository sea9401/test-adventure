# 스킬 MP 비용 차등화 설계

## 문제

플레이어 스킬의 실제 MP 비용은 카탈로그의 개별 `mpCost`를 대부분 무시하고
`기준 풀 × 계열 배율 × 차수 배율`만 사용한다. 따라서 같은 계열과 차수에 속한
스킬은 위력과 성장 단계가 달라도 모두 같은 비용이 된다. 병사 계열 Tier 3
액티브 34개가 대표적으로 MP 76에 수렴한다.

카탈로그의 원본 비용은 같은 Tier 3 안에서도 32~100으로 증가하며, 상위 직업과
강한 스킬일수록 대체로 높다. 이 신호를 버리는 것이 획일화의 원인이다.

## 결정

현재 계열·차수 공식은 각 그룹의 기준 비용으로 유지한다. 여기에 카탈로그
`mpCost`와 차수별 원본 기준값의 차이를 더한다.

```text
기준 비용 = round(600 × 7% × 계열 배율 × 차수 배율)
실제 비용 = max(1, 기준 비용 + (원본 mpCost - 차수별 원본 기준값))
차수별 원본 기준값 = Tier 1: 30, Tier 2: 28, Tier 3: 50
```

이 기준값은 병사 계열의 대표 액티브인 강타·파쇄·검격의 원본 비용에 맞춘다.
따라서 기존 전투 시뮬레이션의 기준 스킬은 종전 비용을 유지하고,
저비용·고비용 스킬만 그 의도만큼 갈라진다.
예를 들어 기본 배율 Tier 3은 원본 36/50/65/100에 대해 각각 62/76/91/126이 된다.

`fixedMpCost`는 고비용 주문처럼 정말 절대 비용이 필요한 예외에 계속 우선한다.
다만 사혈격·혈전·파멸일격·멸왕일도에 지정된 `fixedMpCost: 76`은 기존 공통식 값을
고정한 흔적이므로 제거하고 각각의 원본 비용을 반영한다.

## 영향 범위

- 스킬 상세 표시는 `describeV2Skill`이 같은 계산 함수를 사용하므로 자동 반영된다.
- PvE, PvP, 격자 던전의 실제 차감도 같은 계산 함수를 사용하므로 표시와 일치한다.
- MP 0 스킬과 몬스터 전용 스킬은 기존 리터럴을 유지한다.
- 명시적인 `fixedMpCost`를 가진 주문과 특수기는 그대로 유지한다.
- SP 가격 루브릭은 일반 스킬의 원본 MP 편차를 재평가하지 않는다. 이번 변경은
  MP 표시·차감만 차등화하며 기존 로드아웃 SP 가격은 유지한다.

## 검증

- 같은 계열·차수이지만 원본 비용이 다른 스킬이 서로 다른 실제 비용을 갖는다.
- 계열 배율과 차수 배율은 계속 적용된다.
- `fixedMpCost`, MP 0, 몬스터 전용 예외가 유지된다.
- 광전사 계열 4개가 64/68/80/88로 단계적으로 증가한다.
- 스킬 설명 칩과 전투 차감이 공통 계산 결과를 사용한다.
- 기존 일반 스킬의 SP 가격은 변하지 않는다.
