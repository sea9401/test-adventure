# 스킬 MP 소모 압박 재조정 설계

## 문제

스킬별 MP 차이는 복원됐지만 절대 소모량은 최대 MP 성장에 비해 낮다. 현재
비캐스터 액티브 중앙값은 62, 마법 액티브 중앙값은 120이다. 100레벨 기본
비캐스터의 최대 MP가 약 377이고 마법 빌드는 장비·INT·패시브로 수천까지
성장하므로 전체적인 상향은 필요하다. 다만 마법 계열은 이미 상위 스킬이
150~210 수준이어서 비캐스터와 같은 폭으로 올리면 기존 비용 설계를 훼손한다.

또한 캐스터 계열을 수동 문자열 집합으로 분류해 주술사·의식술사·마검사·
비전술사·법칙술사 등 상위 마법 계보가 누락돼 있다.

## 결정

스킬별 차등 비용을 먼저 계산한 뒤 최종 자원 압박 배율을 적용한다.

```text
비캐스터 최종 비용 = round(차등 비용 × 1.5)
마법사 계보 최종 비용 = round(차등 비용 × 1.25)
```

마법 계보에 1.2배를 적용하면 중앙값 144로 상향 체감이 작고, 1.5배를 적용하면
상위 비용이 최대 315까지 올라간다. 1.25배는 중앙값 150, 상위 25% 구간
194~263으로 기존 150~210 비용대에 적당한 압박만 더하므로 채택한다.

마법사 계보 여부는 `V2_JOB_CATALOG`의 `unlock.prereqs`와
`jobUnlocked` 추가 조건을 따라가며 기본 직업 `mage`에 도달하는지로 판정한다.
무인과 도적 계열도 같은 방식으로 판정해 기존 0.85·0.7 기준 배율을 모든
상위 직업에 자동 계승한다. 복수 계보는 마법사, 무인, 도적 순으로 판정한다.

`fixedMpCost`는 압박 배율 적용 전의 스킬 고유 기준 비용으로 취급한다. 따라서
기존처럼 스킬 간 고저 차이는 유지하면서 마법 고정 비용도 빠짐없이 증가한다.
MP 0과 몬스터 전용 비용은 배율을 적용하지 않고 리터럴을 유지한다.

## 경계

- UI 표시와 PvE·PvP·격자 던전 차감은 기존 공통 함수를 계속 사용한다.
- 일반 스킬 SP 가격은 바꾸지 않는다.
- 고정 비용의 SP 효율 보정은 기준 비용과 고정 비용 양쪽에 같은 압박 배율을
  적용해 상대 비율을 유지한다.
- 최대 MP 비례 동적 비용은 도입하지 않는다. MP 투자로 더 많이 시전하는 성장
  가치는 유지한다.
