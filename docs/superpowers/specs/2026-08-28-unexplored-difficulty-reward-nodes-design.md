# 미개척지 난이도·보상 선택 노드 설계

## 목적과 우선순위

미개척지의 기본 난이도를 95로 고정하고, 플레이어가 탐사 노드에서 보상과 함께 난이도를 직접 추가하도록 한다. 노드의 위치나 트리 진행 깊이가 난이도를 자동으로 올리지 않는다. 같은 진행도에서도 원하는 보상과 감당할 수 있는 난이도에 따라 서로 다른 구성을 만들 수 있어야 한다.

이 문서는 이전 미개척지 시뮬레이션 문서의 난이도 목표를 갱신한다. 이전 문서에서 난이도 90을 진입 후보로 보거나 난이도 100을 사실상 장기 상한으로 본 부분보다 이 문서의 95~120 목표를 우선한다. 보상 수치, 드롭 분류, 심부 노드와 출시 개인 보스 범위는 `2026-08-28-unexplored-reward-economy-design.md`를 우선한다.

## 난이도 범위와 목표

- 노드를 하나도 선택하지 않은 미개척지의 기본 난이도는 95다.
- 선택한 난이도·보상 노드의 증가량을 합산해 최종 난이도를 계산한다.
- 실제 적용 난이도는 120을 넘을 수 없다.
- 모든 난이도 노드의 잠재 상승량은 약 +35로 두어, +25에 도달하는 구성이 하나로 고정되지 않게 한다.
- 난이도 강화 노드는 필수 통과 경로가 아닌 선택형 중형 노드다. 원하지 않는 플레이어는 탐사망을 진행해도 난이도 95를 유지할 수 있다.
- 모든 노드는 기존 탐사망 원칙과 같이 1 탐사 포인트를 사용한다. 증가량과 접근 경로 길이로 투자 강도를 조절한다.

출시 시점의 전투 목표는 다음과 같다.

| 난이도 | 목표 역할 |
| ---: | --- |
| 95 | 최초 진입. 현재 상위권 일부가 안정적으로 사냥할 수 있는 구간 |
| 100 | 현재 최상위권도 직업과 세팅에 따라 성공과 실패가 갈리는 도전 구간 |
| 105 | 현재는 극소수만 제한적으로 사냥 가능한 구간 |
| 110 | 예정된 골드 소모형 성장 요소를 진행한 뒤 접근하는 구간 |
| 115 | 추가 성장 이후를 위한 장기 구간 |
| 120 | 출시 시점에는 사실상 안정 파밍이 불가능한 최종 목표 |

높은 난이도가 현재 플레이어에게 과도하게 강한 것은 허용한다. 다만 명중 불가, 면역 또는 사실상 확정 즉사처럼 성장으로 해결할 수 없는 벽은 만들지 않는다. 충분한 스펙 성장으로 정직하게 돌파할 수 있는 수치 난이도여야 한다.

## 몬스터 성장 곡선

- 난이도 95~100은 현재 검증한 몬스터 속도와 기본 능력치 곡선을 사용한다.
- 101부터 체력, 공격력과 물리·마법 방어의 상승 폭을 더 크게 만든다.
- 몬스터 속도는 101~110에서 완만하게 증가하고, 111~120에서는 상한에 가까워지게 한다.
- 111 이후의 난이도는 행동 횟수가 비정상적으로 늘어나는 방식이 아니라 기본 능력치와 풀별 특화 능력으로 만든다.
- 모든 수치는 난이도 1단계마다 연속적으로 변해야 한다. 100, 105, 110 같은 이정표에서 숨겨진 급격한 배율 점프를 두지 않는다.

정확한 성장 배율은 기존 곡선을 임의로 연장해 확정하지 않는다. 현재 운영 숙련도 상위 30명의 직업, 장비와 세팅을 사용해 95·100·105·110·115·120을 시뮬레이션하고 목표 역할에 맞춰 보정한다.

## 난이도·보상 노드 구성

난이도 노드는 일반 `+1`, 상급 `+2`, 핵심 `+3~4`로 나눈다. 약 14개의 후보를 공용 경로 여러 위치에 분산하고 일부만 짧은 곁가지로 붙인다. 같은 보상 계열을 한 구역에 몰지 않는다.

| 보상 계열 | 후보 수 | 잠재 난이도 합계 | 역할 |
| --- | ---: | ---: | --- |
| 골드 | 2 | +3 | 골드 획득량을 보수적으로 증가 |
| 기본 재료 | 3 | +6 | 일반 재료 수량 증가 |
| 특화 재료 | 4 | +10 | 현재 활성화한 특화 몬스터 풀의 전용 재료 강화 |
| 보스 추적 | 3 | +9 | 출시 대상 상위 풀의 추가 흔적 획득 확률 강화 |
| 희귀 제작 | 2 | +7 | 희귀 제작 재료의 추가 획득 확률 강화 |

특화 재료 노드는 특정 몬스터 풀 하나에 종속하지 않고, 현재 활성화된 모든 특화 풀에 적용한다. 보스 소환품은 거래 가능한 제작물이므로 제작 결과물을 직접 복제하지 않는다. 흔적 추적 노드는 출시 시 보스가 연결된 상위 6개 풀의 추가 흔적 확률만 강화하며 개인 보스 직접 보상에는 적용하지 않는다.

## 보상 계산과 경제 원칙

- 난이도 숫자만 올랐다는 이유로 모든 보상에 공통 배율을 주지 않는다.
- 각 노드에 적힌 특정 보상만 증가한다.
- 같은 종류의 획득량 증가는 합연산한 뒤 한 번 적용한다. 노드끼리 곱연산하지 않는다.
- 골드는 보조 수익으로 유지하고 일반 골드 노드 둘의 합계를 +30%로 제한한다. 심부 보상 전환 노드는 비골드 보상 감소를 대가로 별도 적용한다.
- 큰 증가 폭은 특화 재료, 흔적, 보스 보상과 희귀 제작 재료에 배정한다.
- 110·115·120 도달만으로 별도 골드 배율을 주지 않는다.
- 고난도 이정표 보상이 필요하면 기존 전용 재료의 희귀도 또는 추가 획득 확률을 높인다. 해당 난이도에서만 나오는 필수 성장 재료는 두지 않는다.

최종 난이도는 `min(120, 95 + 선택한 난이도 증가량 합계)`로 계산한다. 현재 합계에서 120을 초과하게 만드는 노드는 선택할 수 없으며, 다른 난이도 노드를 반환한 뒤 교체할 수 있다.

## 40포인트 구성 목표

- 특화 몬스터 풀 2개를 깊게 강화한 구성은 난이도 120에 도달할 수 있다.
- 특화 몬스터 풀 3개를 넓게 사용하는 구성은 대략 110~115에 머무르게 한다.
- 낮은 난이도를 유지하면 공용 성장과 다양한 보상 노드에 더 많이 투자할 수 있다.
- 모든 특화 콘텐츠, 모든 공용 보상과 최대 난이도를 동시에 얻을 수는 없다.

난이도 120은 탐사 포인트가 많으면 자동으로 도달하는 구간이 아니라 다른 선택을 일부 포기한 난이도 집중 구성이다.

## UI 원칙

- 별도의 95~120 난이도 선택창이나 슬라이더는 만들지 않는다. 노드 선택 자체가 난이도 설정이다.
- 미개척지 탐사망 상단과 사냥터 목록에 현재 적용 난이도를 표시한다.
- 난이도 노드는 보상 종류의 직관적인 아이콘을 중심에 표시하고, 공통 테두리와 `+1`, `+2`, `+3`, `+4` 배지로 난이도 상승을 구분한다.
- 선택 전 상세 정보에 현재 난이도와 선택 후 난이도를 함께 보여준다.
- 120을 초과하는 노드는 비활성화하고 초과 이유를 안내한다.
- 노드 선택 후 현재 난이도와 주요 보상 강화 요약을 즉시 갱신한다.

## 시뮬레이션과 구현 경계

첫 검증은 실제 게임 기능을 연결하지 않고 시뮬레이션 전용 후보 데이터만 확장한다.

- 난이도 105·110·115·120을 기존 90·95·100 분석에 추가한다.
- 운영 데이터베이스는 이전과 동일하게 단일 연결과 `SELECT`만 사용한다.
- 익명화, 고정 시드, 물약 미사용과 직업·세팅별 집계 원칙을 유지한다.
- 전체 평균뿐 아니라 개인 분포, 직업·빌드 편중, 풀별 승률과 과도한 하드 카운터를 함께 확인한다.
- 몬스터 속도가 상한에 수렴하는지와 난이도별 실제 행동 비율을 출력한다.
- 기존 사냥터 스케일러, 전투 엔진, 실제 미개척지 사냥과 드롭에는 연결하지 않는다.
- 보상 증가율과 실제 시간당 수익 검증 기준은 `2026-08-28-unexplored-reward-economy-design.md`를 따른다.
- 배포하지 않는다.

## HP·MP 성장식 패치 전 후보

2026-08-28 01:00 KST 운영 스냅샷의 숙련도 상위 30명을 익명화해 풀마다 30회씩 돌린 결과를 최종 후보로 고정한다. 아래 수치는 몬스터의 풀별 기믹까지 적용한 `mechanics` 결과다.

| 난이도 | 전체 승률 | 개인 최대 승률 | 70% 이상 인원 | 해석 |
| ---: | ---: | ---: | ---: | --- |
| 105 | 20.8% | 95% | 5명 | 현재 최상위 일부만 안정적으로 사냥 가능 |
| 110 | 5.0% | 60% | 0명 | 추가 성장 뒤 접근할 첫 번째 수치 장벽 |
| 115 | 0.6% | 18% | 0명 | 장기 성장 구간 |
| 120 | 0.0% | 1% | 0명 | 출시 시점에는 사실상 안정 파밍 불가 |

난이도 95~100은 기존 후보의 능력치와 속도를 그대로 유지한다. 100을 초과하면 `x = (난이도 - 100) / 20`으로 두고 기존 사냥터 스케일링 이후 다음 추가 배율을 한 번만 적용한다.

- 체력: `1 + 2x + x² + 3x³`
- 공격력: `1 + 1.5x + 0.5x² + 1.5x³`
- 물리·마법 방어: `1 + 0.1x + 0.2x²`

따라서 추가 배율은 110에서 체력 `2.625`, 공격력 `2.0625`, 방어 `1.1`이며, 120에서 각각 `7`, `4.5`, `1.3`이다. 속도는 별도의 완만한 앵커 곡선을 사용해 120에 가까워질수록 증가 폭이 줄어든다.

110 이상의 낮은 승률은 특정 풀 하나가 아니라 모든 특화 풀에서 함께 나타났다. 현재 후보는 면역이나 확정 즉사 없이 순수 능력치 성장으로 넘는 벽이라는 목적에 부합한다. 다만 115·120에서 발생한 극소수의 승리는 한 마법 계열 세팅에 집중되었으므로, 예정된 성장 시스템을 연결한 뒤 직업·세팅별 분포를 다시 검증한다. 이 후보 데이터는 시뮬레이션 전용이며 실제 사냥터, 드롭 또는 운영 데이터에는 연결하지 않는다.

## HP·MP 성장식 패치 반영 최종 후보

생애 HP·MP 성장식이 운영에 적용된 뒤 같은 미개척지 후보를 다시 검증했다. 보정 전 `mechanics` 승률은 95 `58.4%`, 100 `49.2%`, 105 `24.3%`, 110 `5.9%`로, 95~100이 최초 진입 구간 역할을 잃었다. 이에 95~105에만 별도의 자원 성장 보정 배율을 적용하고 110부터 정확히 중립 배율로 합류시켰다.

| 난이도 | 추가 체력 | 추가 공격력 | 추가 방어 | 최종 승률 | 개인 최대 | 70% 이상 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 95 | ×1.75 | ×1.50 | ×1.12 | 40.3% | 100% | 10명 |
| 100 | ×1.90 | ×1.55 | ×1.14 | 27.4% | 94% | 6명 |
| 105 | ×1.30 | ×1.18 | ×1.06 | 15.8% | 82% | 3명 |
| 110 | ×1.00 | ×1.00 | ×1.00 | 5.5% | 58% | 0명 |

90과 110~120의 자원 성장 보정은 `1`이며, 앵커 사이 정수 난이도는 선형 보간한다. 기존 101+ 고난도 배율은 이 보정과 별도로 유지한다. 따라서 110·115·120의 장기 성장 벽, 몬스터 속도, 풀별 능력과 보상은 바뀌지 않는다.

최종 검증은 2026-08-28 운영 배포 리비전 `571b5667`, 숙련도 상위 30명, 몬스터별 30회, 고정 시드로 실행했다. 특성 적용 풀별 승률은 95에서 `24.8~54.8%`, 100에서 `15.7~42.7%`, 105에서 `7.7~31.2%`, 110에서 `2.6~12.7%`였다. 특정 풀 하나가 전체 난이도 하락을 만든 결과는 아니며, 95의 전체 승률 `40.3%`는 목표 상한 `40%`의 표본 허용 오차 안으로 받아들인다.
