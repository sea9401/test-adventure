# 미개척지 보상 경제·개인 보스 설계

## 목적과 우선순위

미개척지 난이도 95~120에서 플레이어가 선택한 탐사 노드만큼 보상이 커지되, 골드 인플레이션과 과도한 전용 재료 공급을 피한다. 일반 사냥은 기존 사냥 방식과 스태미나 규칙을 유지하고, 보상 구성만 탐사망으로 조율한다.

이 문서는 미개척지 보상 수치, 드롭 분류, 심부 대형 노드와 출시 개인 보스 범위의 최신 기준이다. 이전 미개척지 문서와 흔적 대상, 보스 수, 보상 수치 또는 심부 노드 효과가 충돌하면 이 문서를 우선한다. 실제 사냥·드롭·제작 기능 구현과 운영 배포는 이 문서의 범위가 아니다.

## 일반 사냥 보상 목표

현재 최상위 일반 사냥터의 스태미나 100당 순수익을 `100`으로 둔다. 노드를 추가로 선택하지 않은 난이도 95 미개척지는 `110`을 목표로 한다.

- 골드와 기존 보상의 고정 기대가치는 기준 사냥터보다 약 3% 높게 둔다.
- 나머지 약 7%는 기본 몬스터가 각자 드롭하는 재료와 희귀 아이템의 기대가치로 만든다.
- 이 목적만을 위한 공용 미개척지 재료는 추가하지 않는다.
- 개인 보스 직접 보상은 일반 사냥 수익에서 제외한다.
- 난이도 숫자 자체에는 공통 보상 배율을 붙이지 않는다. 선택한 보상 노드만 해당 보상을 바꾼다.

보상에 집중한 구성의 검증 기준은 다음과 같다. 같은 난이도라도 공용 성장이나 여러 특화 풀에 포인트를 분산한 구성은 표보다 낮을 수 있다.

| 적용 난이도 | 목표 순수익 |
| ---: | ---: |
| 95 | 110% |
| 100 | 122% |
| 105 | 136% |
| 110 | 150% |
| 115 | 165% |
| 120 | 180% |

일반 사냥의 최대 보상 특화 구성은 기준 사냥터 대비 약 180%를 중심으로 `170~185%` 범위에 들어오게 한다.

## 순수익 측정 기준

스태미나당 순수익을 기본 축, 실제 전투 처리량을 반영한 시간당 순수익을 보조 축으로 사용한다.

- 해당 난이도에서 승률 70% 이상인 캐릭터만 안정적인 파밍 표본으로 분류한다.
- 패배한 전투의 스태미나, HP·MP 충전량과 패배 골드 손실을 비용으로 차감한다.
- 골드는 액면가, 장비는 실제 처분 가치, 거래 재료는 최근 거래가 중앙값으로 환산한다.
- 출시 전 거래가가 없는 재료는 연결된 제작식의 투입 비용으로 임시 가치를 정한다.
- 흔적은 완성된 소환석 가치에서 다른 제작 재료를 차감한 뒤 요구 흔적 수로 나눠 평가한다.
- 개인 보스의 0.5% 초희귀 고유는 흔적과 소환석의 기준 가치에서 제외한다. 확정 보상과 일반 고유 2종만 사용해 보수적으로 계산한다.
- 출시 후 얇은 거래나 단기 이상 가격이 기준을 흔들지 않도록 최근 거래가 중앙값을 사용하고, 실제 보상률 변경은 별도 밸런스 패치로만 수행한다.

## 난이도·보상 노드 14개

모든 노드는 1 탐사 포인트를 사용한다. 난이도 상승량은 총 `+35`이며, 실제 난이도는 120을 넘을 수 없다.

| 계열 | 난이도 | 효과 |
| --- | ---: | --- |
| 골드 Ⅰ | +1 | 골드 획득량 +10% |
| 골드 Ⅱ | +2 | 골드 획득량 +20% |

| 기본 보상 Ⅱ | +2 | 일반 재료·장비 기대 획득량 +20% |
| 기본 보상 Ⅲ | +3 | 일반 재료·장비 기대 획득량 +35% |
| 특화 재료 Ⅰ | +1 | 활성 특화 풀 전용 재료 기대 획득량 +10% |
| 특화 재료 Ⅱ | +2 | 활성 특화 풀 전용 재료 기대 획득량 +20% |
| 특화 재료 Ⅲ | +3 | 활성 특화 풀 전용 재료 기대 획득량 +35% |
| 특화 재료 Ⅳ | +4 | 활성 특화 풀 전용 재료 기대 획득량 +50% |
| 흔적 추적 Ⅰ | +2 | 추가 흔적 획득 확률 +10%p |
| 흔적 추적 Ⅱ | +3 | 추가 흔적 획득 확률 +20%p |
| 흔적 추적 Ⅲ | +4 | 추가 흔적 획득 확률 +35%p |
| 희귀 제작 Ⅰ | +3 | 희귀 재료·아이템 획득 시 20% 확률로 1개 추가 |

같은 계열 보너스는 합연산한 뒤 한 번 적용한다. 골드 노드 둘의 합계는 +30%, 기본 보상 노드의 합계는 +65%, 특화 재료 노드의 합계는 +115%, 흔적 추적 노드의 합계는 +65%p, 희귀 제작 노드의 추가 획득 확률 합계는 55%다.

## 드롭 분류와 기본 확률

각 일반 사냥 드롭은 다음 분류 중 정확히 하나만 가진다.

| 분류 | 적용 노드 |
| --- | --- |
| 일반 장비·일반 재료 | 기본 보상 노드 |
| 특화 몬스터 전용 재료 | 특화 재료 노드 |
| 몬스터별 희귀 재료·희귀 아이템 | 희귀 제작 노드 |
| 흔적 | 풀별 흔적 강화와 흔적 추적 노드 |
| 골드 | 골드 노드 |

특화 재료가 희귀하더라도 희귀 제작 노드를 중복 적용하지 않는다. 추가 보상은 원래 드롭 확률을 바꾸지 않고 독립적인 추가 굴림으로 지급한다. 개인 보스 드롭에는 일반 사냥 보상 노드를 적용하지 않는다.

기본 몬스터 한 종류의 출시 드롭 슬롯은 두 개로 통일한다.

- 몬스터별 주 재료 1종: 해당 몬스터 처치 시 3%
- 몬스터별 희귀 재료 또는 희귀 아이템 1종: 해당 몬스터 처치 시 0.1%
- 기존 전체 사냥 공용 드롭은 별도로 유지한다.

특화 몬스터의 출시 고유 드롭은 전용 재료와, 보스가 연결된 상위 풀에 한해 흔적으로 제한한다. 일반 사냥 공용 골드·장비 드롭은 그대로 적용한다. 특화 풀마다 별도의 0.1% 희귀 아이템을 추가하지 않고, 고가 장비는 개인 보스에 둔다.

- 전용 재료 기본 확률: 1%
- 해당 풀 집중 강화 시 전용 재료 확률: 1.5%
- 특화 재료 노드 전체 투자 시 일반 특화 몬스터는 2.15%, 집중 강화 풀은 3.225%
- 천장이나 조각 보정은 출시 범위에 두지 않는다.

출시 보스가 없는 앞쪽 6개 풀은 흔적을 생성하지 않으므로 기존 풀별 `흔적 추적` 노드를 그대로 두지 않는다.

- 앞쪽 6개 풀: 같은 위치의 노드를 `전리품 탐색`으로 교체한다. 해당 풀 몬스터의 일반 장비·골드 기대량을 +20% 높이고 전용 재료에는 적용하지 않는다.
- 상위 6개 풀: 기존 `흔적 추적`을 유지하고 해당 풀의 추가 흔적 확률을 +20%p 높인다.
- 교체는 6개 노드를 일대일로 바꾸므로 탐사망 총 160노드 수와 연결 구조를 유지한다.
- 추후 앞쪽 풀의 개인 보스를 추가하더라도 전리품 탐색은 유지하고 흔적 기능은 별도 확장한다.

## 심부 대형 노드

심부 대형 노드도 각각 1 탐사 포인트를 사용한다.

| 노드 | 효과 |
| --- | --- |
| 황금 탐사대 | 골드 +30%, 장비·재료 획득량 -50% |
| 수집가의 길 | 일반·특화 재료 +80%, 골드·장비 획득량 -50% |
| 무구 발굴단 | 장비 드롭 +80%, 골드·재료 획득량 -50%, 높은 품질 등장 기대확률 +20% |
| 위험한 계약 | 난이도 +5, 골드 +5%, 흔적을 제외한 일반 사냥 비골드 드롭 +15% |
| 집중 추적 | 기본 풀 최소 비중 30%를 25%로 낮추고 감소한 5%p를 활성 특화 풀에 분배, 기본 풀 보상 -25%, 특화 재료 +30%, 추가 흔적 확률 +10%p |
| 우두머리의 흔적 | 출시 상위 6개 풀의 흔적 획득, 흔적 보관함과 소환석 제작 개방 |

`황금 탐사대`, `수집가의 길`, `무구 발굴단`은 보상 전환형 그룹이며 동시에 하나만 활성화할 수 있다. 다른 세 심부 노드와는 함께 사용할 수 있다. 위험한 계약을 포함해 최종 난이도가 120을 넘는 선택은 거부한다.

황금 탐사대와 일반 골드 노드의 합계는 +60%이며 위험한 계약까지 포함한 절대 최대치는 +65%다. 이는 장비와 재료 보상을 절반 포기하는 선택형 구성이다. 집중 추적, 풀별 +20%p 흔적 강화와 세 흔적 추적 노드를 모두 적용해도 추가 흔적 확률은 최대 95%다.

같은 드롭 분류에 여러 양수·음수 보정이 걸리면 모두 원래 기대 획득량을 기준으로 합연산한 뒤 한 번 적용하고, 최종 기대 획득량은 0 미만으로 내려가지 않게 한다. 보상 전환형 노드를 이미 활성화한 상태에서 다른 보상 전환형 노드를 선택하면 기존 노드를 먼저 반환하라는 안내와 함께 선택을 거부한다.

## 출시 개인 보스 범위

출시 시 12개 특화 풀 전부에 보스를 만들지 않는다. 상위 6개 풀을 두 개씩 묶어 개인 보스 3종만 제공한다.

| 개인 보스 가칭 | 연결 풀 | 전투 방향 |
| --- | --- | --- |
| 추적 병기 | 폭주 기계 + 그림자 추적자 | 빠른 행동, 연격과 회피 |
| 독혈 군주 | 맹독 군락 + 혈흔 망자 | 중독과 출혈 누적 |
| 빙하 거수 | 혹한 군단 + 파쇄 거수 | 둔화, 높은 체력과 강타 |

앞쪽 6개 풀은 출시 시 전용 재료만 드롭하고 흔적은 생성하지 않는다. 추후 같은 방식으로 보스를 추가할 수 있지만, 출시되지 않은 보스를 위한 흔적을 미리 쌓게 하지 않는다.

## 흔적과 소환석 제작

`우두머리의 흔적` 노드를 활성화한 동안에만 상위 6개 풀의 흔적을 얻고 소환석을 제작할 수 있다.

- 대상 특화 몬스터 처치 시 해당 풀 흔적 1개를 기본 지급한다.
- 풀별 흔적 보관 상한은 2,500개다.
- 노드를 반환해도 이미 모은 흔적은 보존한다.
- 제작된 소환석은 거래할 수 있다.
- 구매하거나 미리 제작한 소환석은 관련 풀 또는 흔적 노드가 현재 비활성이어도 사용할 수 있다.

보스 하나의 소환석 제작식은 다음과 같다.

- 연결 풀 A 흔적 500개
- 연결 풀 B 흔적 500개
- 연결 풀 A 전용 재료 10개
- 연결 풀 B 전용 재료 10개
- 보스 소환서 10장
- 골드: 출시 직전 현재 최상위 사냥터의 자연 회복 스태미나 1일 순수 골드 수익 중 25%

골드 비용은 출시 직전 경제 스냅샷으로 한 번 계산해 읽기 좋은 단위로 반올림하고 고정한다. 런타임 시세에 따라 자동 변경하지 않는다.

제작은 모든 재료의 확인과 차감을 하나의 원자적 작업으로 처리한다. 하나라도 부족하거나 중복 요청이 감지되면 어떤 재료도 소모하지 않는다.

## 개인 보스 보상

각 개인 보스는 다음 확정 보상을 지급한다.

- 모든 미개척지 개인 보스가 공유하는 거래 가능한 `우두머리 핵` 1개
- 연결된 두 전용 재료 중 무작위 하나 1개
- 골드는 지급하지 않는다.
- 최초 처치 기록과 칭호만 귀속하며 핵, 전용 재료, 고유 아이템과 소환석은 거래할 수 있다.

보스마다 고유 아이템 3종을 둔다. 세 아이템은 서로 배타적인 표가 아니라 각각 독립적으로 굴린다.

| 보상 | 독립 드롭 확률 |
| --- | ---: |
| 일반 고유 Ⅰ | 30% |
| 일반 고유 Ⅱ | 10% |
| 초희귀 고유 | 0.5% |

여러 굴림에 동시에 성공하면 해당 아이템을 모두 지급한다. 일반 고유를 먼저 얻어도 초희귀 고유 확률은 0.5% 그대로다. 고유 아이템이 하나도 나오지 않을 확률은 약 62.685%다. 일반 고유 2종은 완전한 하위 장비가 아니라 특정 세팅에서 사용할 수 있는 틈새 장비로 만들고, 초희귀 고유는 확정 제작 경로를 두지 않는다.

우두머리 핵은 후속 제작 확장을 위한 공통 거래 재료다. 출시 보상 가치 계산에서는 사용처가 확정된 일반 고유와 전용 재료만 반영하고, 후속 제작식이 추가되기 전까지 핵의 추정 미래 가치를 수익에 넣지 않는다.

개인 보스의 전투 세션, 공개 범위, 공격 스태미나와 대기시간은 기존 개인 보스 전투 설계를 변경하지 않는다. 이 문서는 제작과 보상 경제만 확정한다.

## UI와 정보 공개

- 탐사 노드 상세에는 효과, 불이익과 `현재 난이도 → 선택 후 난이도`를 표시한다.
- 탐사망 상단에는 현재 난이도, 선택한 보상 전환 노드, 활성 특화 풀과 주요 보상 보너스를 요약한다.
- 사냥터 목록에는 `미개척지 · 난이도 N`과 현재 특화 풀 2~3개만 표시한다.
- 사냥 화면 측면에는 풀 출현 비중, 적용 중인 보상 효과와 흔적 획득 가능 여부만 표시한다.
- 추가 굴림으로 나온 아이템에는 전투 결과에서 `탐사 노드 보너스` 표식을 붙인다.
- 흔적 보관함은 보스별 두 흔적과 두 전용 재료의 현재/필요 수량, 소환서와 골드 비용을 한 카드에 표시한다.
- 소환 화면에는 세 고유 아이템의 30%, 10%, 0.5%를 정확히 표시하고 서로 독립 드롭임을 안내한다.
- 내부 밸런스 지표인 예상 거래가와 110~180% 수익 목표는 플레이어 UI에 표시하지 않는다.

## 서버 권위와 검증

- 서버가 선택 노드, 최종 난이도, 드롭 보너스, 흔적과 제작 결과를 판정한다.
- 보상 전환형 대형 노드의 상호 배타성과 난이도 120 상한을 자원 변경 전에 검사한다.
- 각 드롭이 정확히 하나의 보상 분류만 갖고 노드 보너스를 중복 적용하지 않는지 검사한다.
- 전용 재료 1%·1.5%와 +115% 보너스 경계, 기본 몬스터 3%·0.1% 경계를 고정 난수로 검사한다.
- 흔적 기본 1개, 추가 확률 최대 95%, 풀별 2,500 상한, 비활성 시 미획득과 반환 후 보존을 검사한다.
- 출시 대상이 아닌 앞쪽 6개 풀에서 흔적이 생성되지 않는지 검사한다.
- 앞쪽 6개의 전리품 탐색과 상위 6개의 흔적 추적이 정확히 일대일로 배치되고 탐사망 총 노드 수가 160으로 유지되는지 검사한다.
- 소환석 제작 성공, 각 재료 부족, 동시·중복 요청에서 전부 차감 또는 무변경만 가능한지 검사한다.
- 고유 아이템 세 굴림에 서로 다른 고정 난수를 주어 30% 또는 10% 성공 여부가 0.5% 결과에 영향을 주지 않는지 검사한다.
- 보상 시뮬레이션은 승률 70% 이상 표본의 스태미나당 순수익과 시간당 순수익을 함께 출력하고 목표 110·122·136·150·165·180%에서 벗어난 구성을 보고한다.
- 실제 기능 구현 전까지 운영 사냥, 드롭과 저장 데이터에는 연결하지 않으며 배포하지 않는다.
