# 장비 해방 시스템 설계

## 목적

장비 해방은 별도의 캐릭터 성장 트리를 추가하지 않고, 기존 6티어 이상 장비에 무작위 옵션을 부여하는 장기 골드 소모형 성장 시스템이다. 직업 추가와 함께 열리는 기존 캐릭터 성장 구조는 유지하면서, 완성 장비에도 반복 투자와 득템의 여지를 만든다.

핵심 경험은 다음과 같다.

- 장비마다 최초 해방 시 영구적으로 정해지는 1~3개의 옵션 줄을 갖는다.
- 1회 15,000,000골드로 모든 옵션을 즉시 다시 뽑는다.
- 반복 해방 중 낮은 확률로 해방 단계가 상승하고, 높은 단계일수록 더 높은 옵션 레벨이 나온다.
- 좋은 옵션 종류, 높은 옵션 레벨, 많은 옵션 줄을 함께 노리는 장기 골드 소모처다.
- 일부 부위에는 사냥 보상, 레벨업 성장, 제작 비용 절감처럼 장비 교체를 유도하는 희귀 옵션을 둔다.

기존에 비활성화된 `재련` 기능은 삭제하거나 변경하지 않는다. 해방은 장비 품질을 다시 뽑지 않으며 재련과 연결되지 않는다.

## 대상 장비와 귀속

- 장비 원본 카탈로그의 표시 티어가 6티어 이상인 장비만 해방할 수 있다.
- 낮은 티어 장비를 폭풍 개량해 6티어급으로 강화한 경우는 대상이 아니다.
- 향후 추가되는 진짜 7티어 이상 장비는 별도 예외 없이 자동으로 대상이 된다.
- 최초 해방이 성공하는 순간 해당 장비 인스턴스는 귀속된다.
- 귀속 장비는 거래소 판매, 구매 주문 판매와 플레이어 간 이전이 모두 금지된다.
- NPC 판매와 분해는 허용하되 해방 정보가 사라진다는 강한 확인 절차를 거친다.
- 귀속 해제권은 출시 범위에 포함하지 않는다. 추후 판매 상품으로 추가할 수 있다.

귀속은 최초 해방의 서버 트랜잭션이 성공했을 때만 적용한다. 잔액 부족, 대상 불일치 또는 동시 요청 충돌로 실패한 경우에는 골드, 귀속과 해방 정보가 모두 변하지 않아야 한다.

## 해방 단계와 비용

해방 단계는 낮은 순서부터 `해방 3 → 해방 2 → 해방 1`이며 해방 1이 최고 단계다.

- 최초 해방과 이후의 재해방은 모두 회당 15,000,000골드다.
- 비용은 장비 부위, 해방 단계, 옵션 줄 수와 무관하게 고정한다.
- 지갑과 은행의 사용 가능 골드를 합산해 지불한다.
- 반지의 제작·조합 골드 할인 옵션은 해방 비용에 적용하지 않는다.
- 최초 해방은 항상 해방 3에서 시작한다.
- 재해방마다 현재 옵션 전체를 즉시 덮어쓴다.
- 이전 결과 유지, 결과 비교 후 선택, 옵션 잠금과 결과 복구는 제공하지 않는다.
- 해방 단계는 상승할 수 있지만 하락하지 않는다.
- 누적 천장이나 보정 확률은 두지 않는다.

단계 상승 확률은 다음과 같다.

| 현재 단계 | 결과 | 확률 |
| --- | --- | ---: |
| 해방 3 | 해방 2로 상승 | 5% |
| 해방 2 | 해방 1로 상승 | 1% |
| 해방 1 | 단계 유지 | 100% |

한 번의 재해방에서는 단계 상승을 먼저 판정한다. 성공했다면 같은 회차의 새 옵션 레벨을 상승한 단계의 범위에서 뽑는다.

단계 상승 확률만 고려한 해방 1까지의 기대 비용은 최초 해방을 포함해 장비 하나당 약 18억 1,500만골드다. 여섯 부위는 약 108억 9,000만골드이며, 원하는 줄 수와 최종 옵션을 다시 노리는 비용은 포함하지 않는다.

## 옵션 줄 수

최초 해방 시 옵션 줄 수를 한 번만 결정한다.

| 줄 수 | 확률 |
| ---: | ---: |
| 1줄 | 50% |
| 2줄 | 35% |
| 3줄 | 15% |

- 정해진 줄 수는 해당 장비 인스턴스에 영구적으로 고정된다.
- 이후 재해방이나 단계 상승으로 줄 수가 늘거나 줄지 않는다.
- 줄 확장 기능은 출시하지 않는다.
- 같은 장비 안에서는 동일한 옵션 종류가 두 번 나올 수 없다.
- 서로 다른 장비 부위에서 같은 종류의 옵션이 나온 경우에는 정상적으로 합산한다.

## 옵션 레벨과 분포

옵션 종류와 옵션 레벨은 매번 무작위로 결정한다. 해방 단계는 나올 수 있는 레벨 범위만 바꾸며, 옵션 종류의 상대 가중치는 바꾸지 않는다.

| 해방 단계 | 레벨 분포 |
| --- | --- |
| 해방 3 | Lv.1 24%, Lv.2 22%, Lv.3 20%, Lv.4 18%, Lv.5 16% |
| 해방 2 | Lv.5 19%, Lv.6 18%, Lv.7 17%, Lv.8 16%, Lv.9 15%, Lv.10 15% |
| 해방 1 | Lv.10~14 각 10.2%, Lv.15~17 각 9%, Lv.18~19 각 8%, Lv.20 6% |

모든 효과는 Lv.20 수치를 최댓값으로 두고 `최댓값 × 옵션 레벨 ÷ 20`으로 선형 계산한다. 정수 단위 효과는 소수점 첫째 자리에서 표준 반올림하고, 양수 옵션이 0이 되면 최소 1을 보장한다. 백분율과 퍼센트포인트 효과는 각 능력치의 기존 표시 정밀도를 따른다.

이 구조에서 해방 3은 최댓값의 약 5~25%, 해방 2는 약 25~50%, 해방 1은 약 50~100%를 제공한다. 해방 1의 최상위 값은 드물지만 Lv.20 확률을 6%로 두어 지나치게 가혹한 단일 최고점은 피한다.

## 옵션 종류 추첨

옵션마다 다음 상대 가중치를 사용한다.

| 가중치 | 역할 |
| ---: | --- |
| 100 | 흔하거나 상황을 타는 옵션, 이른바 꽝 역할 |
| 70 | 범용적으로 쓸 만한 옵션 또는 사냥 보상 옵션 |
| 40 | 선호도가 높은 핵심 옵션 |
| 15 | 희귀 핵심 옵션 |
| 5 | 장비 교체와 장기 추구를 만드는 최고 희귀 옵션 |

첫 번째 줄은 해당 부위 풀의 전체 가중치에서 추첨한다. 두 번째와 세 번째 줄은 이미 선택된 옵션 종류를 제외한 뒤 남은 가중치 합으로 확률을 다시 계산하는 비복원 가중 추첨을 사용한다. UI에는 상대 가중치와 첫 번째 줄 기준 실제 확률을 표시하고, 후속 줄은 선택된 종류를 제외해 확률이 다시 계산된다고 안내한다.

## 능력치 계산 원칙

해방의 기초 능력치 %는 이미 계산된 최종 능력치가 아니라 캐릭터 기초 능력치에만 적용한다.

- 기초 능력치는 캐릭터의 기본값과 현재 재전직 주기의 레벨 성장으로 확정된 값이다.
- 여러 장비의 같은 기초 능력치 %는 먼저 합산하고 기초 능력치에 한 번만 적용한다.
- 해방으로 더해진 능력치는 직업, 패시브 또는 다른 % 효과에 의해 다시 증폭되지 않는다.
- 음식의 능력치 %도 해방과 동일하게 기초 능력치에만 적용하도록 변경한다.
- 기존 패시브 능력치 %의 계산 방식은 바꾸지 않는다.
- 음식의 고정 수치 효과와 다른 음식 효과는 이번 변경 범위가 아니다.
- 공격력%, 방어력%, 피해 감소와 회피 확률 같은 직접 파생 옵션은 각 최종 파생 능력치 축에 적용한다.

정확한 계산 순서는 다음과 같다.

1. 캐릭터 기초 능력치를 확정한다.
2. 음식%를 제외한 기존 직업 앵커%, 직업 고정 보너스와 패시브% 계산을 지금과 같은 순서로 끝낸다.
3. 음식% 보너스와 해방% 보너스를 각각 1번의 기초 능력치만 기준으로 계산한다.
4. 3에서 구한 두 보너스를 2의 결과에 고정 수치로 더한다.
5. 완성된 1차 능력치로 파생 전투 능력치를 계산하고 해방의 직접 파생 옵션을 해당 축에 적용한다.

따라서 음식%와 해방%는 직업 앵커%나 패시브%의 배율을 다시 받지 않으며, 서로도 증폭하지 않는다.

## 레벨업 성장 옵션

- 갑옷의 최대 HP 성장과 목걸이의 최대 MP 성장은 해당 장비를 착용한 상태에서 레벨이 오를 때 발동한다.
- Lv.20 기준 HP는 레벨마다 0~30, MP는 레벨마다 0~10 중 하나를 동일 확률로 얻는다.
- 낮은 옵션 레벨은 공통 선형 배율로 계산하고 표준 반올림한 상한까지, 0을 포함한 각 정수를 동일 확률로 뽑는다.
- 한 번 얻은 수치는 장비를 벗거나 해당 옵션을 재해방해도 현재 재전직 주기 동안 유지된다.
- 재전직으로 레벨이 1이 되면 해방으로 누적한 HP와 MP 성장분을 모두 초기화한다.
- 일반 사냥, 희귀 지도, 미개척지, 오프라인 사냥, 경험치 책과 정상적인 이벤트 경험치 등 실제 레벨업 경로에 적용한다.
- 한 번에 여러 레벨이 오르면 오른 레벨 수만큼 각각 독립적으로 뽑는다.
- 관리자 복구, 직접 수치 지급이나 데이터 보정은 발동시키지 않는다.
- HP 옵션은 갑옷에만, MP 옵션은 목걸이에만 존재하므로 같은 종류의 성장 옵션은 부위 간 중첩되지 않는다.

장비를 바꿔가며 레벨업하는 스위칭 플레이는 허용한다. 이 선택은 의도된 장비 활용 방식으로 간주한다.

## 제작·조합 골드 할인

- 반지에만 등장한다.
- 플레이어 개인이 수행하는 제작과 조합의 골드 부분에만 적용한다.
- 재료 수량은 줄이지 않는다.
- 강화, 폭풍 개량, 해방, 스킬 의식, 거래소와 길드 금고 비용에는 적용하지 않는다.
- 제작 실행 시점에 착용한 반지를 기준으로 계산하며 제작 전에 반지를 교체하는 것을 허용한다.
- 같은 옵션은 한 부위에만 존재하므로 여러 장비의 할인율 합산 규칙은 만들지 않는다.

## 사냥 보상 옵션

사냥 보상 옵션은 확률에 퍼센트포인트를 더하지 않고 기존 확률에 배율을 곱한다. 예를 들어 기본 확률 0.1%에 `×1.10`을 적용하면 0.11%가 된다.

- 일반 사냥, 희귀 지도 사냥, 미개척지 사냥과 오프라인 자동 사냥에만 적용한다.
- 협동 보스와 개인 보스 보상, 퀘스트, 생활, 길드 및 이벤트 지급에는 적용하지 않는다.
- 전투 시작 시 착용 장비를 스냅샷으로 고정하고 보상 수령 직전 장비 교체는 반영하지 않는다.
- 오프라인 사냥은 정산 시작 시점의 장비를 해당 정산 전체에 적용한다.
- `일반 재료`, `특화 재료`, `희귀 재료`는 기존 드롭 분류를 사용하며 하나의 아이템을 여러 분류에서 중복 증폭하지 않는다.
- `일반 보스 소환서`는 미개척지 전용 개인 보스 제작물을 뜻하지 않고 기존 일반 보스 소환서 분류를 뜻한다.

## UI와 사용자 흐름

대장간의 기존 화면에 `해방` 탭을 추가한다. 화면은 데스크톱에서 좌우로 나뉜 작업대 구조를 사용한다.

- 왼쪽에는 해방 가능한 보유 장비 목록을 표시한다.
- 오른쪽에는 선택 장비, 현재 해방 단계, 고정 줄 수, 현재 옵션과 옵션 레벨, 효과 수치를 표시한다.
- 보유 장비 상세 화면의 바로가기로 대장간 해방 탭을 열고 해당 장비를 자동 선택할 수 있다.
- 상단에는 지갑과 은행을 합친 사용 가능 골드를 표시한다.
- 최초 해방 화면에는 장비 귀속과 옵션 줄 수 영구 고정을 명확히 경고한다.
- 재해방 화면에는 모든 현재 옵션이 즉시 사라진다는 확인 절차를 둔다.
- 실행 버튼 근처에 15,000,000골드 비용과 현재 단계의 상승 확률을 항상 표시한다.
- 확률 상세에서 줄 수 확률, 단계 상승 확률, 옵션 상대 가중치, 첫 줄 기준 실제 확률과 옵션 레벨 분포를 공개한다.
- 모바일에서는 장비 목록과 작업 영역을 세로로 배치하되 같은 정보를 생략하지 않는다.
- 장면 또는 지역 배경 위의 최상위 작업 패널과 내부 카드는 `SURFACE_CARD`, `SURFACE_INSET`, `SURFACE_ACCENT`를 사용한 불투명 표면으로 만든다.
- 잠긴 장비 카드는 전체 투명도를 낮추지 않고 텍스트, 아이콘과 비활성 버튼으로 상태를 표현한다.

## 서버 데이터와 원자성

장비 인스턴스에는 다음 정보를 저장한다.

- 귀속 여부
- 해방 단계
- 영구 옵션 줄 수
- 각 줄의 옵션 식별자와 옵션 레벨

캐릭터 또는 현재 재전직 주기 데이터에는 해방으로 얻은 누적 최대 HP와 최대 MP를 별도로 저장하고 재전직 시 초기화한다.

해방 요청은 서버 권위 난수와 하나의 원자적 처리 단위로 실행한다.

1. 요청 UUID의 중복 여부를 확인한다.
2. 장비 소유권, 원본 티어, 폭풍 개량 예외와 현재 해방 상태를 검증한다.
3. 클라이언트가 보낸 예상 장비 상태가 현재 상태와 같은지 확인한다.
4. 지갑과 은행의 사용 가능 골드가 충분한지 확인하고 15,000,000골드를 차감한다.
5. 최초 해방이면 줄 수를 결정하고 장비를 귀속한다.
6. 단계 상승을 판정한 뒤 새 단계 범위에서 옵션 종류와 레벨을 뽑는다.
7. 장비, 골드와 요청 처리 영수증을 함께 저장한다.

같은 UUID의 재시도는 최초 처리 결과를 반환하고 다시 과금하지 않는다. 예상 상태가 오래되었거나 동시에 다른 요청이 먼저 반영된 경우에는 과금 없이 실패시키고 최신 장비 상태를 반환한다. 난수 결과는 클라이언트가 결정하거나 제출할 수 없다.

귀속 장비 차단은 거래소 등록 화면 하나에만 의존하지 않는다. 일반 판매, 구매 주문 판매와 그 밖의 모든 플레이어 이전 서버 경로에서 공통으로 검증한다.

## 출시 제외 범위

다음 기능은 확장 가능성만 남기고 첫 출시에는 포함하지 않는다.

- 옵션 줄 잠금
- 이전 결과 유지, 복구 또는 골드 추가 재선택
- 옵션 줄 확장
- 귀속 해제권
- 단계 상승 누적 천장
- 기존 재련과의 연결
- 해방 비용 할인
- 품질 재굴림
- 특정 스킬 피해와 재사용 대기시간 옵션

## 검증 기준

구현 완료 전 최소한 다음을 검증한다.

- 원본 6티어 이상만 대상이며 폭풍 개량 저티어 장비는 제외되는지 확인한다.
- 최초 해방 귀속과 50%/35%/15% 줄 수 고정이 이후 재해방에도 유지되는지 확인한다.
- 잔액 부족, 중복 UUID, 오래된 상태와 동시 요청에서 골드나 장비가 부분 변경되지 않는지 확인한다.
- 귀속 장비가 모든 거래소 판매 및 플레이어 이전 경로에서 차단되는지 확인한다.
- 단계 상승이 옵션 추첨보다 먼저 적용되고 단계가 하락하지 않는지 확인한다.
- 한 장비 안의 옵션 종류 중복이 없고 후속 줄의 가중치가 정상적으로 재계산되는지 확인한다.
- HP·MP 성장이 다중 레벨업에서 레벨 수만큼 발동하고 재전직 시 초기화되는지 확인한다.
- 음식%와 해방%만 기초 능력치 기준으로 바뀌고 기존 패시브%는 기존 결과를 유지하는지 회귀 검증한다.
- 사냥 보상 옵션이 전투 시작 장비를 사용하고 협동 보스, 퀘스트, 생활과 길드 보상에는 적용되지 않는지 확인한다.
- 고정 시드 100,000회 이상 시뮬레이션으로 줄 수, 단계, 옵션 종류와 레벨 분포가 설계값의 허용 오차 안인지 확인한다.
- 실제 직업별 대표 6티어 장비 세팅으로 전투 시뮬레이션을 돌려 특정 직업이나 공격 계열만 과도하게 유리하지 않은지 확인한다.
- 데스크톱과 모바일, 라이트와 다크 모드에서 분할 작업대와 불투명 표면의 가독성을 확인한다.

Lv.20 최댓값은 출시 후보로 고정하되 최종 구현 단계에서 직업별 6티어 세팅 시뮬레이션 결과로 밸런스만 조정할 수 있다. 옵션 구조, 가중치 등급, 적용 범위와 계산 축을 바꾸는 경우에는 별도 설계 변경으로 다룬다.

## 출시 제어

- 서버와 UI 모두 기능 플래그 뒤에 둔다.
- 플래그가 꺼져 있으면 해방 탭, 바로가기와 해방 API를 사용할 수 없어야 한다.
- 로컬 구현과 검증만 수행하며 사용자의 별도 요청 없이 어떤 환경에도 배포하지 않는다.
- 운영 배포를 나중에 수행하더라도 점검 모드는 사용자의 별도 지시 전까지 자동으로 해제하지 않는다.
