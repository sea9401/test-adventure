# 전투 패턴 회복 스킬 실효 위력 명시 설계

## 목표

전투 패턴으로 발동한 반복형 직접 회복 스킬에 숨어 있던 차수별 회복 배율을 제거하고, 스킬 상세에 표시되는 원본 수치가 전투에서 그대로 적용되게 한다. 기존 운영 환경에서의 실효 회복량은 각 스킬 데이터로 옮겨 최대한 보존한다.

## 원인

`resolveV2SkillCast`는 전투 패턴이 발동 확률을 건너뛴 스킬의 직접 회복 합계에 차수별 배율(1차 18%, 2차 24%, 3차 32%)을 적용한다. 이 배율은 스킬 상세에 표시되지 않기 때문에 `잃은 체력 9%`와 `회복량 1000%`를 보고 90% 회복을 예상해도 실제로는 3차 배율까지 곱해진다.

운영 환경은 패턴에서도 발동 확률을 굴리지만, 발동률 100%인 반복형 유틸 회복기는 확률 게이트를 사용한 것으로 취급되지 않아 같은 숨은 배율을 받는다. 발동률이 낮은 공격+회복 스킬, 전투당 1회 회복기, 피해 비례 회복, 지속 재생은 이 배율의 적용 대상이 아니다.

## 변경 범위

반복 사용 가능하고 직접 `heal` 효과를 가지며 발동률이 100%인 다음 6개 스킬의 원본 회복 수치를 기존 실효 배율만큼 낮춘다.

| 스킬 | 차수 | 변경 |
|---|---:|---|
| 회복 | 1 | 최대 HP 10% → 1.8% |
| 기공 순환 | 2 | 잃은 체력 5% → 1.2% |
| 치유 | 2 | 잃은 체력 6% → 1.44%, 계수·고정값도 24%로 조정 |
| 대치유 | 3 | 잃은 체력 9% → 2.88%, 계수·고정값도 32%로 조정 |
| 성역 선포 | 3 | 잃은 체력 7% → 2.24%, 계수·고정값도 32%로 조정 |
| 기적 | 3 | 잃은 체력 9% → 2.88%, 계수·고정값도 32%로 조정 |

전투 계산에서는 직접 회복 합계에 패턴 차수 배율을 다시 곱하지 않는다. 공격 피해와 지속 피해의 기존 패턴 보정은 유지한다.

다음 효과는 현재도 숨은 직접 회복 배율을 받지 않으므로 수치를 바꾸지 않는다.

- 전투당 1회 회복: 응급 처치, 야영, 현장 처치, 사투, 긴급 구조, 생환
- 확률 발동 공격에 포함된 회복: 심판의 빛, 성전의 심판
- 실제 피해 비례 회복: 영혼 수확, 혈마군림
- 지속 재생: 영겁 순환
- 보호막, 마나 회복, 능력치·피해 감소 버프

## 검증

- 모든 플레이어 직접 회복 스킬을 카탈로그에서 동적으로 수집해 패턴 사용과 비패턴 사용의 직접 회복량이 같음을 검증한다.
- 위 6개 스킬의 새 원본 수치를 표 기반 테스트로 고정해 누락을 막는다.
- `기적`을 제보 수치에 가까운 조건으로 재현해 표시 수치와 전투 계산이 일치하는지 확인한다.
- 기존 전투당 1회, 피해 비례 회복, 스킬 설명, 직업 카탈로그 및 전체 전투 테스트를 실행한다.

## 비범위

- 공격 스킬의 평타 초과 피해 보정과 DoT 보정은 변경하지 않는다.
- 보호막·버프·마나 회복의 수치는 변경하지 않는다.
- 배포 및 운영 환경 변경은 수행하지 않는다.
