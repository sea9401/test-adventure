# 미개척지 업적 오류 수정 설계

## 문제

미개척지 업적이 `adventure-log.v2.coopBossKinds`의 전체 종류 수를 사용한다. 이 때문에 일반 협동 보스도 미개척지 업적으로 집계된다. 또한 미개척지 개인 보스는 3종뿐인데 기존 목표는 1/3/6/9/12종 처치를 요구해 10포인트 완성이 불가능하다. 미개척지 화면에는 업적 조건과 완료 상태도 표시되지 않는다.

## 승인된 동작

- 업적은 기존과 같이 총 10개이며 각 업적은 탐사 포인트 1을 지급한다.
- 보스 업적 5개는 `첫 미개척지 보스 처치`, 세 보스별 처치, `3종 모두 처치`로 구성한다.
- `tracking_weapon`, `toxic_blood_lord`, `glacial_colossus`만 보스 업적에 반영한다.
- 일반 협동 보스 ID는 보스 업적에 영향을 주지 않는다.
- 기존 비보스 업적 5개는 유지한다.
- 미개척지 화면은 업적 10개의 이름, 조건, 완료 여부, 보상 `탐사 포인트 +1`을 표시한다.
- 배포 전 기능이므로 잘못된 기존 `boss_kinds_*` 저장값은 새 업적으로 변환하지 않고 파싱에서 폐기한다.

## 구조

`unexploredState.ts`가 유효 업적 ID와 저장 파싱 계약을 계속 소유한다. `unexploredProgression.ts`는 미개척지 개인 보스 ID 목록을 입력받아 첫 처치·개별 처치·전체 처치 후보를 계산하고, UI가 함께 사용하는 업적 이름/설명 카탈로그를 내보낸다. 보상 수령 라우트는 전체 협동 보스 로그를 그대로 전달하되 후보 계산기가 개인 보스 3종만 필터링한다. 이렇게 하면 퀘스트용 전체 협동 보스 로그는 유지하면서 미개척지 업적만 정확히 분리된다.

## 검증

- 일반 협동 보스 ID만으로는 보스 업적이 생성되지 않는다.
- 첫 개인 보스는 첫 처치와 해당 보스 업적 두 개를 지급한다.
- 세 개인 보스는 보스 업적 다섯 개를 모두 지급한다.
- 저장 파서는 새 ID만 보존하고 기존 `boss_kinds_*`는 폐기한다.
- 개인 보스 보상 수령은 올바른 업적을 저장하며 일반 협동 보스 기록은 결과를 오염시키지 않는다.
- UI는 10개 업적과 완료/미완료 상태를 불투명 표면에 표시한다.
