# 성장 도약 패키지와 월간 회복약 세트 설계

## 목적

플레이 시간이 성장과 강하게 연결되는 현재 구조에서 신규·복귀 이용자가 실제 플레이를
통해 격차를 줄일 수 있는 한정 상품을 추가한다. 결제 즉시 레벨이나 전투력을 지급하지
않고, 스태미나 보충과 30일 성장 의뢰를 통해 한정된 추격 효과를 제공한다.

## 확정 상품

### 월간 스태미나 회복약 세트

| 항목 | 값 |
| --- | ---: |
| 가격 | 300 무슨 코인 |
| 구성 | 귀속 스태미나 회복약 20개 |
| 회복량 | 개당 200, 세트당 총 4,000 스태미나 |
| 구매 제한 | 계정당 KST 달력 월 3회 |
| 월 최대 | 회복약 60개, 총 12,000 스태미나, 900 무슨 코인 |

구매 횟수는 한국 시간 기준 매월 1일 00:00에 새 기간으로 전환한다. 이전 달의 미사용
구매 횟수는 이월하지 않는다. 구매한 회복약은 기존 `stamina-potions.v1`의 귀속 수량으로
지급하며 거래소에 등록할 수 없다.

### 성장 도약 패키지

| 항목 | 값 |
| --- | ---: |
| 가격 | 1,200 무슨 코인 |
| 구매 제한 | 계정당 평생 1회 |
| 즉시 지급 | 귀속 스태미나 회복약 30개 |
| 거래 가능 지급품 | 닉네임 꾸미기 상자 1개, 프로필 꾸미기 상자 1개 |
| 기간 콘텐츠 | 30일 성장 의뢰 |

일반·프리미엄 모험 지원권은 포함하지 않는다. 회복약은 귀속으로 지급하지만 두 꾸미기
상자는 현재 상품과 동일하게 거래할 수 있다. 캐릭터 초기화, 직업 변경, 재전직 및 캐릭터
데이터 변경으로 구매 자격이 복구되지 않는다.

## 30일 성장 의뢰

### 진행 규칙

- 패키지를 구매한 시각부터 정확히 30일 동안 진행할 수 있다.
- 구매 이전의 전투나 스태미나 사용량은 소급하지 않는다.
- 정상적인 게임 행동으로 실제 차감되어 확정된 캐릭터 스태미나만 누적한다.
- 회복약 사용은 스태미나를 충전하는 행동이므로 그 자체로 진행도를 올리지 않는다.
- 전투에서 패배해도 스태미나가 정상 차감되고 행동이 확정됐다면 진행도에 포함한다.
- 요청 검증 실패, 서버 오류 또는 트랜잭션 롤백으로 스태미나 차감이 확정되지 않으면
  진행도도 올리지 않는다.
- 누적 진행도는 최대 목표인 50,000에서 고정한다.
- 캐릭터 초기화, 직업 변경 및 재전직은 계정 단위 의뢰 진행도를 초기화하지 않는다.

성장 의뢰가 끝난 뒤 7일은 수령 유예 기간이다. 이 기간에는 진행도가 더 오르지 않지만
이미 달성한 단계의 보상을 받을 수 있다. 구매 후 37일이 지나면 미수령 보상은 소멸한다.

### 단계와 보상

| 단계 | 누적 스태미나 사용량 | 보상 |
| --- | ---: | --- |
| 1단계 · 첫걸음 | 3,000 | 숙련 증서 300개, 귀속 회복약 5개 |
| 2단계 · 성장 가속 | 10,000 | 숙련 증서 1,000개 |
| 3단계 · 숙련 축적 | 20,000 | 숙련 증서 600개, 귀속 회복약 5개 |
| 4단계 · 도약 준비 | 35,000 | 숙련 증서 1,400개 |
| 5단계 · 도약 완료 | 50,000 | 숙련 증서 1,700개, 꾸미기 30일 연장권 1개 |

성장 의뢰 전체 보상은 숙련 증서 5,000개, 귀속 회복약 10개, 꾸미기 30일 연장권
1개다. 패키지 즉시 지급분까지 포함하면 회복약은 총 40개, 총 회복량은 8,000이다.

숙련 증서는 결제 즉시 지급하지 않는다. 이용자가 각 스태미나 목표를 달성한 뒤 단계별로
직접 수령해야 하며, 현재 숙련 증서와 동일하게 계정 인벤토리에 기록한다. 꾸미기 연장권은
기존 상품과 동일하게 수령 후 거래할 수 있다.

## 상태와 처리 경계

월간 상품 구매 기록과 성장 도약 패키지 기록은 서버가 권위 있게 관리한다.

- 월간 회복약 세트 기록: 현재 KST 연월과 해당 기간 구매 횟수
- 성장 도약 기록: 구매 시각, 진행 종료 시각, 수령 종료 시각, 누적 스태미나 사용량,
  수령한 단계 목록
- 평생 1회 구매 여부는 성장 도약 기록의 존재로 판정하며 만료 후에도 기록을 보존한다.

상품 구매는 코인 차감, 구매 제한 기록, 회복약·꾸미기 상자 지급 및 성장 의뢰 생성을 한
트랜잭션에서 처리한다. 하나라도 실패하면 전체 구매를 롤백한다. 단계 보상 수령도 단계
수령 기록과 모든 보상 지급을 한 트랜잭션에서 처리하여 중복 지급을 막는다.

스태미나 진행도는 실제 스태미나 차감이 일어나는 서버 경계에서 함께 기록한다. 구현 전
사냥, 숙련의 탑, 협동 보스, 투기장 등 캐릭터 스태미나를 쓰는 모든 경로를 감사하고,
공용 누적 헬퍼를 통해 같은 규칙을 적용한다. 새 스태미나 소비 콘텐츠도 이 공용 경계를
사용해야 한다.

## 화면

무슨 코인 상점에서 다음 정보를 구매 전에 명확히 보여준다.

- 월간 회복약 세트: `이번 달 0/3회 구매`, 귀속 여부, 총 회복량
- 성장 도약 패키지: `계정당 1회`, 즉시 지급품, 성장 의뢰 전체 보상과 30일 제한
- 구매 완료 후 월간 상품은 남은 구매 횟수를 즉시 갱신한다.
- 성장 도약 패키지는 구매 완료 상태로 바꾸고 재구매 버튼을 비활성화한다.

퀘스트 화면에는 성장 의뢰 전용 영역을 둔다. 누적 스태미나 진행도, 단계별 보상, 진행
종료 시각과 수령 유예 시각을 표시한다. 진행 기간 종료 후에는 `진행 종료 · 보상 수령만
가능` 상태를 구분하고, 수령 기간까지 끝나면 만료 상태로 고정한다.

## 오류와 경계 조건

- 월 3회 구매 완료: 코인을 차감하지 않고 이번 달 구매 한도 안내
- 성장 도약 패키지 재구매: 코인을 차감하지 않고 계정당 1회 상품 안내
- 코인 부족: 기존 상점의 잔액 부족 처리 유지
- 동시에 같은 상품 구매: 서버 잠금과 트랜잭션 안에서 제한을 다시 검사
- 단계 보상 동시 수령 또는 재시도: 이미 수령한 단계면 보상을 다시 지급하지 않음
- 30일 경계와 37일 경계는 서버 시각으로 판정하며 클라이언트 시각을 신뢰하지 않음
- 오래된 저장값이나 잘못된 진행도는 음수가 되지 않게 정규화하고 50,000으로 제한

## 검증

### 도메인 테스트

- KST 월 경계 전후 구매 횟수와 월 3회 제한
- 성장 도약 평생 1회 제한과 만료 후 구매 기록 보존
- 30일 진행 및 7일 수령 유예의 정확한 시각 경계
- 단계별 필요 진행도와 숙련 증서 합계 5,000개
- 패키지 전체 회복약 합계 40개와 귀속 수량

### 서버 회귀 테스트

- 구매 성공 시 모든 지급과 기록이 함께 저장되는지 확인
- 지급 중 오류 시 코인과 보상이 모두 롤백되는지 확인
- 실제 스태미나 차감만 진행도에 반영되는지 확인
- 회복약 사용, 검증 실패 및 롤백된 행동이 진행도를 올리지 않는지 확인
- 보상 중복 수령과 동시 요청 차단

### UI 테스트

- 월간 남은 구매 횟수와 성장 도약 구매 완료 상태
- 진행 중, 수령 유예, 완전 만료 상태의 문구와 버튼
- 모든 보상 수량, 거래 가능 여부 및 귀속 여부 표시

## 운영 관찰

출시 후 월간 회복약 세트의 1·2·3회차 구매율, 성장 의뢰의 단계별 도달률, 평균 완주
일수, 패키지 구매 전후 30일 활동량과 숙련 증서 사용처를 관찰한다. 기존 이용자와 신규
이용자의 완주율 차이가 지나치게 크거나 5,000 숙련이 상위 이용자에게 상대적으로 과도한
추가 이득으로 작용하는지 함께 확인한다. 상품은 계정당 평생 1회이므로 반복적인 영구
성장 판매로 확장하지 않는다.

## 제외 범위

- 레벨 달성 비약, 경험치·골드·드롭률 증가
- 전투력, 피해량 또는 전투 계수 증가
- 자동 사냥 또는 전투 자동 진행
- 장비 선택권, 고유 장비 및 강화 장비 지급
- 일반·프리미엄 모험 지원권 지급
- 배포와 운영 상품 공개
