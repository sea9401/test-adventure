# Dangerous Fishing Keyboard Controls Design

## Goal

위험 해역 실시간 낚시의 감아올리기 버튼에서 `Space`와 `Enter`를 마우스 입력과 동일하게 사용할 수 있게 한다. 낚시 난이도와 시뮬레이션 수치는 변경하지 않는다.

## Design

- 감아올리기 버튼에 포커스가 있을 때 `Space` 또는 `Enter`의 `keydown`은 마우스 `pointerdown`처럼 감아올리기를 시작한다.
- 같은 키의 `keyup`은 마우스 `pointerup`처럼 줄 풀기로 돌아간다.
- 키 자동 반복은 추가 입력으로 기록하지 않으며 기본 브라우저 동작을 막아 이중 실행을 방지한다.
- 포인터와 키보드를 함께 누른 경우에는 남아 있는 입력이 모두 해제될 때만 줄 풀기로 돌아간다.
- 기존 포인터 동작, 사람 확인 중 입력 잠금, 서버 재현 가능한 입력 기록은 그대로 유지한다.
- 일반 낚시나 위험 해역 밸런스, 서버 API에는 손대지 않는다.

## Alternatives Considered

1. `Space`와 `Enter`를 모두 누르고 있는 동안만 감아올리게 한다. 마우스 누름/놓기 모델과 정확히 같고 기존 실시간 입력 기록을 그대로 재사용할 수 있어 이 방식을 선택한다.
2. 키를 누를 때마다 감아올리기 상태를 토글한다. 반복 클릭 부담은 줄지만 마우스 조작과 달라지고 실수로 상태를 유지할 위험이 있어 제외한다.
3. 위험 해역 화면 전체에서 전역 단축키를 받는다. 포커스가 다른 버튼이나 입력창에 있을 때 충돌할 수 있고 요청 범위를 넓히므로 제외한다.

## Testing

- 버튼 컴포넌트 테스트에서 `Space`와 `Enter` 각각의 down/up이 `aria-pressed`를 전환하는지 검증한다.
- hook 테스트에서 두 키가 포인터와 같은 `reel`/`release` 기록을 만들고 자동 반복을 무시하는지 검증한다.
- 기존 포인터·사람 확인·종료 흐름 회귀 테스트를 함께 실행한다.
