# 피드백 528 편의성·안내 보강 설계

## 목표

쿠키님의 피드백에서 반영하기로 한 항목을 기존 UI 패턴과 실제 게임 데이터에 맞춰 개선한다. 공개 요리의 미등록 필터와 복수 재료 검색은 미발견 정보 비공개 정책과 맞지 않아 이번 변경에서 제외한다.

## 1. 프리셋 안전장치

- 스킬 로드아웃 프리셋과 통합 전투 프리셋 모두 덮어쓰기와 삭제 전에 게임 공용 확인창을 표시한다.
- 확인창에는 대상 프리셋 이름과 실행할 작업을 명시한다.
- 취소하면 네트워크 요청이나 로컬 프리셋 갱신을 하지 않는다.
- 덮어쓰기는 경고 톤, 삭제는 위험 톤을 사용한다.

## 2. 농장·목장 정보

- 재배 씨앗 카드에 `재배 시간 · 기본 수확량 · 농사 XP`를 한 줄로 표시한다. XP는 실제 수확 계산이 사용하는 `farmCropMasteryGain`에서 가져와 안내와 보상이 어긋나지 않게 한다.
- 목장의 건설 후보와 운영 중 축사에 `생산 시간 · 생산 개수 · 농사 XP`를 표시한다. 돼지는 마리당 생산량과 경험치임을 명시한다.
- 단일 수확과 목장 일괄 수확은 이미 획득 XP를 알리고 있으므로 유지한다.
- 여러 밭을 한꺼번에 수확했을 때 각 응답의 XP를 합산해 완료 알림에 표시한다.

## 3. 메인 화면 길드 음식

- 접힌 캐릭터 요약에 이미 있는 길드 음식 표시를 유지한다.
- 펼친 캐릭터 카드에도 일반 음식 효과 바로 아래 길드 음식 이름, 효과, 남은 시간을 표시한다.
- 서버가 이미 제공하는 `activeGuildDiningEffect`를 카드까지 전달하며 새 API나 저장 형식은 만들지 않는다.

## 4. 폭풍 원정 도움말

- 원정 상단의 반응이 불분명한 새로고침 아이콘 자리를 도움말 아이콘으로 바꾼다. 원정 상태는 화면 진입과 행동 응답으로 계속 동기화되고, 오류 배너의 재시도 기능은 유지한다.
- 도움말 버튼은 접근 가능한 모달을 열고 다음 내용을 보여준다.
  - 해금 조건, 일일 입장 횟수, 실전·연습 차이
  - 9개 체크포인트와 7개 전투, 항로 변경, 임시 전리품과 귀환·패배 규칙
  - 일반 장신구의 항로별 드롭 위치
  - 항로 유니크, 교차 유니크, 폭풍심장 유니크의 드롭 위치와 실제 기본 확률
- 장비 이름과 확률은 장비·원정 보상 데이터에서 직접 읽어 운영 수치 변경 시 설명도 함께 갱신되게 한다.

## 5. 게임 안내서와 사냥터 표기

- 기존 안내서와 현재 구현을 대조해 이번 피드백에서 드러난 공백을 보강한다.
- 전투 계산식의 HP·MP 절에는 계산 순서를 단계별로 풀어 쓰고, STR·VIT는 HP, INT는 MP, SPI는 회복 배율·마법 능력치에 기여하지만 기본 최대 MP에는 직접 들어가지 않는다는 점을 명시한다.
- 최대 HP 증가율은 기본 HP와 스탯 HP에 먼저 적용되고 장비 고정 HP가 나중에 더해지는 순서를 예시로 설명한다. 최대 MP는 장비 고정 MP까지 합산한 뒤 증가율을 적용하는 현재 계산 순서를 명시한다.
- 사냥터의 내부 숫자 깊이는 사용자 안내에서 제거하고 `지역 · 입구/심부/최심부` 이름을 사용한다.
- 천공 균열과 별의 무덤 장비 설명의 `73~78`, `79~84`, `78단계` 표현을 지역·구역 이름으로 바꾼다.
- 모험의 서의 천공 균열 무기 안내도 `천공 균열 최심부`로 바꾼다.
- 원정 안내에는 화면 도움말과 같은 장비 획득 위치를 추가하여 공지에만 있던 원정 전용 유니크 정보를 안내서에서도 찾을 수 있게 한다.

## 오류 처리와 접근성

- 모든 확인창과 원정 도움말은 기존 게임 다이얼로그·모달 접근성 패턴을 사용한다.
- 원정 도움말은 Escape, 바깥 영역 클릭, 닫기 버튼으로 닫을 수 있고 `role="dialog"`, 제목 연결, 포커스 관리를 제공한다.
- 새 카드와 모달은 `SURFACE_CARD`, `SURFACE_INSET`을 사용해 라이트·다크 모드에서 불투명 표면을 유지한다.

## 테스트

- 프리셋 확인 헬퍼: 취소 시 콜백 미실행, 확인 시 1회 실행, 문구와 톤 검증.
- 농장: 작물 정보에 실제 XP가 표시되고 일괄 수확 XP가 합산되는지 검증.
- 목장: 각 동물의 시간·개수·XP가 표시되는지 검증.
- 캐릭터 카드: 펼친 화면에서 길드 음식 효과와 남은 시간이 표시되고 만료 시 숨는지 검증.
- 원정 도움말: 버튼·모달의 핵심 규칙과 장비 드롭 위치가 렌더링되는지 검증.
- 안내서: HP·MP 설명, 사용자용 사냥터 명칭, 원정 전용 장비 안내가 렌더링되는지 검증.

## 제외 범위

- 공개 발견 요리의 도감 미등록 필터는 추가하지 않는다.
- 요리 검색의 복수 재료 AND 검색은 추가하지 않는다.
- 데이터베이스 스키마, 레시피 조합, 보상 확률과 밸런스는 변경하지 않는다.
- 배포는 수행하지 않는다.
