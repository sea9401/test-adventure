# 월간 모험 지원권 프리미엄 설계

## 배경

현재 `월간 모험 지원권 (30일)`은 1,000 무슨 코인에 최대 스태미나 +1,000, 스태미나 회복 속도 +20%, 일괄 사냥 최대 50회, 거래소 등록 +10칸, 판매세 5%를 제공한다. 더 높은 가격대에서 직접 전투력이나 경험치·골드·드롭률을 판매하지 않으면서 반복 조작과 접속 부담을 더 줄이는 상위 상품이 필요하다.

상위 상품은 일반권을 폐기하거나 단순히 기간을 덮어쓰지 않는다. 프리미엄 이용 중에는 일반권의 남은 시간을 보존하고, 프리미엄이 끝난 뒤 일반권이 자동으로 이어져 기존 구매와 출석 보상의 가치를 지킨다.

## 상품 정의

- 상품명: `월간 모험 지원권 프리미엄 (30일)`
- 가격: 2,500 무슨 코인
- 기간: 사용 시점부터 30일
- 판매 방식: 일반권과 함께 무슨 코인 상점에서 판매하고, 구매 후 가방에 보관되는 거래 가능 아이템으로 제공한다.
- 상점 정렬: 이용권·소모품 그룹에서 프리미엄권을 일반권보다 먼저 표시한다.
- 사용 보상: 사용할 때마다 기존 거래 가능 아이템인 `꾸미기 30일 연장권` 2개를 지급한다.

## 프리미엄 혜택

- 최대 스태미나 +3,000
- 프리미엄권 사용 시 현재 스태미나 +3,000. 적용 후 최대 스태미나를 넘는 양은 저장하지 않는다.
- 스태미나 회복 속도 +20%
- 일괄 사냥 최대 100회
- 거래소 등록 +20칸
- 판매세 5%
- 활성 중 캐릭터 요약과 상세 효과 카드에 금색 프리미엄 전용 상태 아이콘 표시

일반권과 프리미엄권의 혜택은 합산하지 않는다. 프리미엄이 활성화된 동안에는 위 프리미엄 수치만 적용한다. 따라서 최대 스태미나 보너스는 +1,000과 +3,000을 더한 +4,000이 아니라 총 +3,000이다. 프리미엄 종료 후 보존된 일반 기간이 시작되면 일반권 수치로 자동 복귀한다.

경험치, 골드, 아이템 드롭률, 숙련도, 전투 능력치에는 보너스를 주지 않는다. 자동 또는 오프라인 사냥 관련 혜택도 추가하지 않는다.

## 기간 상태 모델

기존 일반권 저장 구조를 읽을 수 있도록 `activatedAt`과 `activeUntil`의 의미를 유지하고 선택 필드 `premiumUntil`을 추가한다.

```ts
type AdventureSupportState = {
  activatedAt: number;
  activeUntil: number;
  premiumUntil?: number;
};
```

- `premiumUntil`: 프리미엄 구간이 끝나는 시각
- `activeUntil`: 프리미엄 구간과 그 뒤에 대기 중인 일반 구간을 모두 포함한 최종 지원 종료 시각
- 현재 시각이 `premiumUntil`보다 이르면 프리미엄, 그렇지 않고 `activeUntil`보다 이르면 일반, 둘 다 아니면 비활성으로 판정한다.
- `premiumUntil`이 없는 기존 데이터는 전 구간을 일반권으로 해석한다.

이 표현은 별도의 만료 전환 작업 없이 시간만으로 프리미엄에서 일반권으로 자동 복귀하게 한다.

## 기간 적립 규칙

### 일반권 이용 중 프리미엄권 사용

일반권 남은 시간을 보존하고 프리미엄 30일을 현재 시각부터 앞에 삽입한다.

예를 들어 일반권이 10일 남았을 때 프리미엄권을 사용하면 `premiumUntil`은 30일 뒤, `activeUntil`은 40일 뒤가 된다. 앞의 30일은 프리미엄, 뒤의 10일은 일반 혜택을 적용한다.

### 프리미엄 이용 중 프리미엄권 사용

기존 `premiumUntil`과 `activeUntil`을 모두 30일 연장한다. 뒤에 대기 중인 일반권 기간은 그대로 보존된다.

### 프리미엄 이용 중 일반권 획득 또는 사용

`premiumUntil`은 바꾸지 않고 `activeUntil`만 일반권 지급 기간만큼 연장한다. 출석·우편·쿠폰 등 기존 일반권 지급 경로도 같은 규칙을 사용한다.

### 모든 지원권이 만료된 상태에서 프리미엄권 사용

현재 시각부터 30일 뒤를 `premiumUntil`과 `activeUntil`로 설정한다.

모든 기간 계산은 기존 최대 지급 기간 상한을 지키며, 비정상 숫자·음수·만료된 선택 필드는 안전하게 정규화한다.

## 상품 사용과 원자성

프리미엄권 사용은 하나의 서버 트랜잭션에서 다음 작업을 모두 처리한다.

1. 가방에서 프리미엄권 1개를 차감한다.
2. 프리미엄 기간 30일을 적립한다.
3. 갱신된 프리미엄 최대치 안에서 현재 스태미나를 3,000 회복한다.
4. `꾸미기 30일 연장권` 2개를 가방에 지급한다.
5. 갱신된 지원권 상태·스태미나·아이템 수량을 응답한다.

어느 단계든 실패하면 전체 작업을 되돌린다. 아이템만 사라지거나 연장권만 중복 지급되는 부분 성공은 허용하지 않는다. 재요청과 동시 사용도 서버의 기존 캐시 아이템 사용 트랜잭션과 행 잠금 규칙으로 직렬화한다.

## 계산 경계

지원권 활성 여부를 `boolean`만으로 전달하는 기존 계산은 프리미엄과 일반을 구분할 수 없으므로, 공용 판정에서 `none | standard | premium` 등급을 먼저 구한다. 다음 소비자는 이 등급으로 자기 수치를 선택한다.

- 스태미나: 최대치 보너스와 회복 속도
- 던전 사냥: 선택 가능한 일괄 사냥 횟수와 서버 요청 상한
- 거래소: 등록 가능 수량과 판매세
- 상태 API: 현재 등급, 프리미엄 만료 시각, 최종 지원 종료 시각
- 캐릭터 요약·상세 카드와 상점: 적용 혜택과 남은 기간 표시

판매세는 두 유료 등급 모두 5%지만 등급별 설정에 각각 명시한다. 이후 한쪽 값을 바꾸더라도 소비자가 하드코딩된 조건문을 갖지 않게 한다.

## 화면 표시

### 무슨 코인 상점

- 프리미엄권을 일반권 앞에 표시한다.
- 가격, 30일 기간, 최대 스태미나 +3,000, 회복 +20%, 일괄 사냥 100회, 거래소 +20칸, 판매세 5%, 연장권 2개 지급을 상품 상세에 표시한다.
- 경험치·골드·드롭률 보너스가 있는 것처럼 해석될 문구는 사용하지 않는다.
- 일반권이 남아 있어도 프리미엄 기간 동안 시간이 보존된다는 안내를 표시한다.

### 활성 상태

- 프리미엄 활성 중에는 기존 지원권 아이콘과 구분되는 금색 전용 상태 아이콘과 `프리미엄` 라벨을 표시한다.
- 상세 카드에는 프리미엄 남은 기간과, 뒤에 대기하는 일반권 기간이 있으면 그 기간을 별도로 표시한다.
- 프리미엄이 끝나 일반권으로 자동 전환되면 일반 아이콘·라벨·혜택으로 되돌아간다.
- 아이콘은 기존 코드 기반 게임 아이콘 체계에 추가하며 새 래스터 이미지는 만들지 않는다.

## 오류 처리

- 알 수 없는 지원권 상태나 유효하지 않은 만료 시각은 기존 파서 원칙대로 안전한 비활성 또는 정규화된 일반 상태로 처리한다.
- 프리미엄권 사용 중 아이템 부족, 저장 충돌 또는 지급 실패가 발생하면 사용자에게 기존 캐시 아이템 오류 체계로 안내하고 상태를 변경하지 않는다.
- 프리미엄권은 거래 가능하므로 거래소에 등록된 개체와 가방에서 사용하는 개체의 소유권 검증을 기존 캐시 소모품과 동일하게 적용한다.
- 꾸미기 연장권 지급은 기존 거래 가능한 `cosmetic_extension_30d` 수량에 2개를 더한다. 별도의 귀속 변형 아이템은 만들지 않는다.

## 테스트와 검증

### 상태 단위 테스트

- 기존 `{ activatedAt, activeUntil }` 데이터는 일반권으로 판정된다.
- 일반권 10일 위에 프리미엄 30일을 적용하면 프리미엄 30일 뒤 일반 10일이 이어진다.
- 프리미엄 중 프리미엄 재사용은 프리미엄과 최종 만료를 함께 30일 연장한다.
- 프리미엄 중 일반권 지급은 최종 만료만 연장한다.
- 프리미엄 만료 경계에서 일반권으로, 최종 만료 경계에서 비활성으로 전환된다.

### 서버·경제 회귀 테스트

- 프리미엄권 1개 차감, 기간 적립, 스태미나 +3,000, 꾸미기 연장권 2개 지급이 한 트랜잭션으로 완료된다.
- 중간 실패 시 네 변경이 모두 롤백된다.
- 프리미엄 최대 스태미나 보너스는 +3,000이고 회복 속도는 +20%다.
- 프리미엄 일괄 사냥은 100회까지 허용하고 100회를 넘는 요청은 거부한다.
- 거래소 등록은 +20칸, 판매세는 5%를 적용한다.
- 일반권의 기존 +1,000·20%·50회·+10칸·5% 동작은 유지된다.

### 화면 테스트

- 상점 정렬과 모든 상품 상세 수치를 검증한다.
- 프리미엄 아이콘·라벨, 프리미엄 남은 기간, 대기 중인 일반 기간을 검증한다.
- 시간 경계 뒤 일반권 표시로 자동 복귀하는지 검증한다.

## 제외 범위

- 경험치·골드·드롭률·숙련도·전투 능력치 보너스
- 자동 사냥 또는 오프라인 사냥 기능과 관련 혜택
- 일반권 가격이나 기존 혜택 변경
- 꾸미기 연장권 자체의 가격·거래 가능 여부·효과 변경
- 새로운 결제 수단이나 무슨 코인 충전 상품 추가
- 배포 및 운영 데이터 직접 수정

## 완료 조건

- 프리미엄권을 2,500코인에 구매하고 거래·사용할 수 있다.
- 사용 시 프리미엄 30일, 스태미나 +3,000, 거래 가능한 꾸미기 연장권 2개가 원자적으로 적용된다.
- 프리미엄 혜택은 +3,000·20%·100회·+20칸·5%이며 일반권과 합산되지 않는다.
- 프리미엄 이용 중 일반권 잔여 기간이 줄지 않고 종료 후 자동 재개된다.
- 기존 일반권 저장 데이터와 모든 일반권 지급 경로가 계속 동작한다.
- 상점과 캐릭터 상태 화면이 현재 등급·혜택·두 종류의 남은 기간을 정확히 표시한다.
- 관련 단위·API·UI 회귀 테스트와 전체 정적 검증이 통과한다.
