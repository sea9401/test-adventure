# 미개척지 혈흔 망자 확장 설계

## 목표

혈흔 망자의 기존 출시 몬스터 `갈고리 망자`에 `혈주 추격자`와 `절단 집행자`를 추가해 실제 미개척지 사냥에서 세 몬스터가 모두 출현하게 한다. 앞선 아홉 풀의 확장 상태는 유지하고, 혹한 군단과 파쇄 거수는 출시 몬스터 한 종만 출현해야 한다.

## 선택한 접근

기존 풀별 `releaseStage`와 `activeMonsters` 구조를 재사용한다. 혈흔 망자의 출시 단계만 `expanded`로 전환하고 조우, 런타임, 집중 효과, 풀 공통 보상 경로에는 새 분기를 추가하지 않는다.

전투는 이미 연결된 자동 전투용 `살점 뜯기` 출혈 스킬과 주기적 강타를 그대로 사용한다. 새로운 출혈 스킬, 중첩 규칙 또는 수동 행동을 추가하지 않는다. 세 몬스터는 같은 출혈을 사용하되 기본 수치, 행동 속도, 3페이즈 주기 2배 강타로 역할을 구분한다.

## 조우와 전투

혈흔 망자 풀이 선택되면 `activeMonsters` 세 종에서 균등 선택한다. 각 몬스터의 출현 확률은 1/3이다.

| 몬스터 | 역할 | 핵심 수치 | 능력 |
| --- | --- | --- | --- |
| 갈고리 망자 | 기본형 | HP 1.00, 공격 1.05, 방어 0.90, 마방 0.90, 일반 속도 | `살점 뜯기`: 출혈 |
| 혈주 추격자 | 공격형 | HP 0.85, 공격 1.00, 방어 0.80, 마방 0.85, 빠른 속도 | `살점 뜯기`: 빠른 행동 빈도로 출혈 누적 가속 |
| 절단 집행자 | 변칙형 | HP 1.10, 공격 1.20, 방어 1.00, 마방 0.90, 느린 속도 | `살점 뜯기`, 3번째 적 페이즈마다 직접 피해 2배 |

혈주 추격자는 가장 낮은 체력과 방어를 감수하고 빠른 속도로 출혈 사용 기회를 늘린다. 절단 집행자는 가장 느리지만 체력·공격·방어가 가장 높고 주기적 강타로 예고된 순간 피해를 준다. 갈고리 망자는 속도와 생존의 기준점이다.

혈흔 망자 집중 노드는 세 몬스터 모두에게 원래 속도와 직접 공격력의 10%를 반올림해 적용한다. `살점 뜯기`의 출혈 계수와 스택 수는 바꾸지 않으며, 속도 증가로 출혈 누적 빈도를 높인다. 절단 집행자의 3페이즈 주기와 2배 강타는 집중 후에도 그대로 유지한다.

## 런타임과 안전장치

기존 몬스터 ID 기반 런타임 생성기를 그대로 사용한다. 혈흔 망자가 확장되면 `bloodtrail_pursuer`와 `severing_executioner`가 활성 검증을 통과하며, 아직 출시되지 않은 혹한 군단과 파쇄 거수 후보는 계속 거부된다.

활성 특수 몬스터는 기존 30종에서 32종으로 늘어나고, 기본 몬스터 5종을 합친 전체 미개척지 런타임 카탈로그는 37종이 된다. 모든 정수 난이도 95~120에서 각 수치가 유한한 양수여야 한다.

## 이미지

기존 `갈고리 망자`와 같은 정사각형 투명 배경, 녹슨 흑철 갑옷, 해진 회색 천, 마른 피, 뼈 장식, 푸른 안광의 사실적인 어두운 판타지 언데드 렌더 스타일로 다음 파일을 추가한다.

- `public/images/monster/v2/unexplored-bloodtrail-pursuer.webp`
- `public/images/monster/v2/unexplored-severing-executioner.webp`

혈주 추격자는 마른 체구와 길게 뻗은 팔다리, 가벼운 해진 갑옷, 쌍 갈고리 낫 또는 짧은 사슬 낫, 낮게 몸을 숙인 질주 자세와 붉은 혈흔 잔상으로 고속 추격형을 표현한다. 절단 집행자는 두꺼운 녹슨 판금과 거대한 양손 단두 도끼 또는 사형 집행용 대형 칼날, 넓고 무거운 직립 자세로 주기적 강타형을 표현한다. 갈고리 망자와 두 신규 몬스터의 체형, 무기, 자세가 명확히 달라야 한다. 이미지에는 텍스트, 로고, 워터마크, 배경 장면을 넣지 않는다.

이미지 생성 결과가 체크무늬를 실제 픽셀로 포함하지 않도록 WebP 변환 전 RGBA 알파 채널을 검사한다.

## 보상

세 몬스터 모두 풀 ID 기준의 기존 재료 `v2_unexplored_bloodstained_dead_material`을 같은 확률로 드롭한다. 집중 여부에 따른 기존 특수 재료 확률만 적용하며 개별 몬스터 보너스나 신규 보상은 추가하지 않는다.

## 테스트와 검증

- 풀 카탈로그: 앞의 열 개 풀만 `expanded`, 나머지 2개는 `launch`
- 조우: 혈흔 망자 RNG 구간별 갈고리 망자·혈주 추격자·절단 집행자 선택
- 서버 사냥 준비: 선택된 두 확장 몬스터 ID 보존
- 런타임: 활성 특수 32종, 전체 37종
- 전투: 세 몬스터 모두 `살점 뜯기`, 절단 집행자만 3페이즈마다 2배 강타
- 집중: 세 몬스터의 속도·직접 공격력 10% 증가, 출혈 스킬 유지, 절단 집행자의 주기적 강타 유지
- 안전장치: 혹한 군단의 미출시 후보 거부
- 보상: 세 몬스터의 동일 응고 혈액 규칙
- 자산: 두 WebP의 512×512 RGBA 알파와 참조 존재
- 관련 테스트, 전체 타입 검사, 변경 파일 린트, 전체 테스트, `V2_UNEXPLORED=true` production build

## 제외 범위

- 새로운 출혈 스킬이나 중첩 규칙
- 수동 전투 행동 또는 전용 UI
- 기존 출혈 계수와 강타 주기 변경
- 개별 몬스터 보상 차등
- 혹한 군단과 파쇄 거수 활성화
- 배포, 병합, 푸시, PR 생성
