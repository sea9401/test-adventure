# 미개척지 우두머리 핵 확정 제작 설계

## 목적

개인 보스가 확정 지급하는 `우두머리 핵`에 실제 사용처를 만들고, 30%·10% 일반 고유 장비에 장기 획득 천장을 제공한다. 확률 드롭의 가치는 유지하되 충분히 반복 토벌한 플레이어가 특정 일반 고유를 끝내 얻지 못하는 상황을 해소한다.

## 범위

- 추적 병기, 독혈 군주, 빙하 거수의 일반 고유 2종씩 총 6종을 확정 제작 대상으로 한다.
- 각 보스의 0.5% 초희귀 고유는 드롭 전용으로 유지한다.
- 제작 결과는 기존 보스 드롭과 같은 거래 가능한 랜덤 옵션 장비 개체다.
- 중복 장비 전용 분해나 핵 환급은 만들지 않는다. 기존 판매·거래·제작소 해체를 그대로 사용한다.
- 운영 기능 플래그 전환과 배포는 포함하지 않는다.

## 제작 비용

| 대상 | 우두머리 핵 | 연결 풀 A 재료 | 연결 풀 B 재료 |
| --- | ---: | ---: | ---: |
| 30% 일반 고유 | 8개 | 25개 | 25개 |
| 10% 일반 고유 | 25개 | 75개 | 75개 |

추가 골드, 흔적, 보스 소환서는 요구하지 않는다. 보스 한 번을 소환할 때 이미 500만 골드, 소환서 30장, 연결 재료와 흔적을 소비하므로 확정 제작에서 같은 입장 비용을 다시 부과하지 않는다.

우두머리 핵은 세 보스가 공유하는 거래 재료라는 기존 계약을 유지한다. 연결 재료 두 종류가 제작 대상을 보스별로 구분한다. 특정 보스의 최초 처치나 현재 `우두머리의 흔적` 노드 활성화는 요구하지 않아 재료 거래와 전문 제작을 허용한다.

## 데이터 계약

`unexploredBosses.ts`에 고유 장비 제작 레시피를 파생 가능한 정적 카탈로그로 둔다. 레시피 ID는 장비 ID와 동일하게 사용하며 대상 장비, 보스, 드롭 등급, 핵 비용, 두 연결 재료 비용을 제공한다.

`character.v2.unexplored`에는 최근 50개의 장비 제작 영수증을 추가한다.

```ts
type UnexploredEquipmentCraftReceipt = {
  requestId: string;
  equipmentId: V2EquipmentId;
  equipmentIid: string;
  craftedAt: number;
};
```

파서는 손상된 값과 알 수 없는 장비를 제거하고 같은 `requestId`의 마지막 기록만 보존한다. 기존 저장에는 필드가 없으므로 빈 배열로 정규화한다.

## 서버 처리

새 `POST /api/v2/unexplored/equipment-craft`가 `{ equipmentId, requestId }`를 받는다.

1. 사용자와 기능 플래그, 장비 ID, 요청 ID를 검증한다.
2. 트랜잭션에서 `character.v2`를 먼저 잠근다.
3. 같은 요청 ID의 영수증이 있으면 같은 장비 요청에는 최초 장비 IID를 반환하고, 다른 장비 요청에는 `request_conflict`를 반환한다.
4. 핵과 연결 재료를 전부 검증한다. 부족하면 아무것도 변경하지 않는다.
5. 기존 `mintRolledEquipInstance`로 장비 개체를 하나 만들고 `equipment.v2`에 추가한다.
6. 재료를 차감하고 영수증을 추가한 `character.v2`를 저장한다.
7. 유니크 누적 획득 기록과 도감 숙련도를 `equipment.craft` 출처로 기록한다.

장비 도감 등록은 제작 시 자동으로 처리하지 않는다. 기존과 같이 보유 장비를 소비해 직접 등록해야 하며, 제작 획득과 도감 등록의 역할을 분리한다.

잠금 순서는 `character.v2` 다음 `equipment.v2`, 이후 `adventure-log.v2`와 도감 숙련도 관련 행 순서로 기존 개인 보스 보상 경로를 따른다. 어느 저장 단계에서든 실패하면 전체 트랜잭션을 롤백한다. 멱등 재시도는 장비·재료·누적 획득·숙련도를 다시 적용하지 않는다.

오류는 `invalid_request`, `not_craftable`, `insufficient_boss_cores`, `insufficient_pool_material`, `request_conflict`로 구분한다.

## 화면

미개척지 탐사망의 `흔적 보관함` 아래에 `우두머리 핵 제작소`를 추가한다.

- 보유 핵 수를 상단에 표시한다.
- 보스별 카드에 30%·10% 일반 고유 두 개와 각각의 정확한 비용을 표시한다.
- 초희귀 고유는 `0.5% · 토벌 드롭 전용`으로 표시하고 제작 버튼을 제공하지 않는다.
- 제작 가능 여부는 서버 스냅샷의 재료 수량으로 미리 표시하되 서버가 최종 재검증한다.
- 비용이 큰 작업이므로 공용 확인 대화상자에서 장비명과 소비 재료를 다시 보여준 뒤 요청한다.
- 성공 후 서버가 반환한 재료와 장비 개체 ID를 화면 상태에 반영하고 시스템 알림으로 장비 획득을 안내한다. 영수증 전체 목록은 서버 저장에만 두고 클라이언트 스냅샷에는 노출하지 않는다.

## 검증

- 카탈로그가 정확히 6개 일반 고유만 포함하고 세 초희귀를 제외한다.
- 30%와 10% 비용을 리터럴로 고정한다.
- 성공 시 핵과 두 연결 재료가 한 번만 차감되고 장비 한 개가 지급된다.
- 각 재료 부족, 잘못된 장비, 기능 비활성, 비인증 요청은 저장을 변경하지 않는다.
- 같은 요청 재시도는 같은 IID를 반환하며 장비나 비용을 다시 적용하지 않는다.
- 같은 요청 ID를 다른 장비에 사용하면 충돌한다.
- UI는 여섯 제작식과 세 드롭 전용 초희귀를 구분하고, 확인 뒤 올바른 요청을 보낸다.
- 미개척지 집중 테스트, 장비·도감 회귀, 타입 검사, 린트와 전체 테스트를 통과한다.

## 제외 사항

- 0.5% 초희귀 장비의 천장이나 확정 제작
- 중복 고유 전용 분해 및 핵 환급
- 보스별 핵 분리
- 운영 시세 기반 자동 비용 조절
- 앞쪽 6개 특화 풀의 신규 보스와 장비
