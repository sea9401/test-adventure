# 미개척지 파쇄 거수 확장 설계

> 현재 런타임 메타데이터 계약은 [미개척지 몬스터 풀 런타임 메타데이터 현황](./2026-08-30-unexplored-monster-pool-runtime-metadata.md)을 따른다. 아래 `releaseStage`, 확장 후보와 역할 구분은 이 확장을 진행한 당시의 이력이다.

## 목표

파쇄 거수의 기존 출시 몬스터 `암반 거수`에 `철벽 분쇄자`와 `지각 파괴자`를 추가해 실제 미개척지 사냥에서 세 몬스터가 모두 출현하게 한다. 이번 확장으로 12개 특수 풀이 모두 확장 상태가 된다.

## 선택한 접근

기존 풀별 `releaseStage`와 `activeMonsters` 구조를 재사용한다. 파쇄 거수의 출시 단계만 `expanded`로 전환하고 조우, 런타임, 집중 효과, 풀 공통 보상 경로에는 새 분기를 추가하지 않는다.

전투는 이미 연결된 자동 전투용 주기적 강타, 방어 관통과 `분쇄 일격`을 그대로 사용한다. 새로운 강타 스킬, 수동 행동 또는 별도 방어 파괴 상태를 추가하지 않는다. 세 몬스터는 생존 수치, 공격력, 관통 방식과 제한된 강타 횟수로 역할을 구분한다.

## 조우와 전투

파쇄 거수 풀이 선택되면 `activeMonsters` 세 종에서 균등 선택한다. 각 몬스터의 출현 확률은 1/3이다.

| 몬스터 | 역할 | 핵심 수치 | 능력 |
| --- | --- | --- | --- |
| 암반 거수 | 기본형 | HP 1.40, 공격 1.10, 방어 1.20, 마방 0.90, 느린 속도 | 3번째 적 페이즈마다 직접 피해 2배 |
| 철벽 분쇄자 | 공격형 | HP 1.25, 공격 1.25, 방어 1.10, 마방 0.85, 느린 속도 | `정밀 관통`: 방어 관통 11 |
| 지각 파괴자 | 변칙형 | HP 1.55, 공격 1.35, 방어 1.25, 마방 0.90, 느린 속도 | `분쇄 일격`: 공격 계수 1.8·고정 피해 40·60% 발동·2턴 재사용·MP 30, 최대 MP 60 |

철벽 분쇄자는 세 종 중 생존 수치가 가장 낮지만 방어 관통으로 안정적인 직접 피해를 준다. 지각 파괴자는 가장 높은 체력·공격·방어를 갖고 분쇄 일격을 최대 두 번 사용하지만 행동 속도가 느리다. 암반 거수는 3페이즈 주기의 예고된 강타를 사용하는 기준형이다.

파쇄 거수 집중 노드는 세 몬스터의 원래 공격력을 10% 높여 반올림하고 `playerDefVulnerable`을 0.08 추가한다. 이는 적의 모든 물리 공격이 플레이어 방어력의 8%를 추가로 무시하게 한다. 암반 거수의 3페이즈·2배 강타, 철벽 분쇄자의 관통 11, 지각 파괴자의 분쇄 일격과 최대 MP 60은 집중 후에도 그대로 유지된다.

## 런타임과 안전장치

기존 몬스터 ID 기반 런타임 생성기를 그대로 사용한다. 파쇄 거수가 확장되면 `ironwall_crusher`와 `crust_destroyer`가 활성 검증을 통과한다. 이제 모든 설계 몬스터가 활성화되므로 안전장치는 미출시 후보 대신 선택된 풀에 속하지 않는 몬스터 ID를 거부하는지 검사한다.

활성 특수 몬스터는 기존 34종에서 36종으로 늘어나고, 기본 몬스터 5종을 합친 전체 미개척지 런타임 카탈로그는 41종이 된다. 모든 정수 난이도 95~120에서 각 수치가 유한한 양수여야 한다.

## 이미지

기존 `암반 거수`와 같은 정사각형 투명 배경, 거친 암석·금속·마그마 균열, 주황색 핵과 사실적인 어두운 판타지 골렘 렌더 스타일로 다음 파일을 추가한다.

- `public/images/monster/v2/unexplored-ironwall-crusher.webp`
- `public/images/monster/v2/unexplored-crust-destroyer.webp`

철벽 분쇄자는 암회색 철갑과 길게 돌출된 쐐기형 관통 팔, 전진 자세와 비교적 압축된 체형으로 관통 공격형을 표현한다. 지각 파괴자는 산맥처럼 넓고 무거운 현무암 판, 붉은 마그마 균열과 거대한 망치형 양팔, 내리찍기 직전의 자세로 제한 강타형을 표현한다. 암반 거수와 두 신규 몬스터의 재질, 실루엣과 자세가 명확히 달라야 한다. 이미지에는 텍스트, 로고, 워터마크, 배경 장면을 넣지 않는다.

이미지 생성 결과가 체크무늬를 실제 픽셀로 포함하지 않도록 WebP 변환 전 RGBA 알파 채널을 검사한다.

## 보상

세 몬스터 모두 풀 ID 기준의 기존 재료 `v2_unexplored_crushing_colossi_material`을 같은 확률로 드롭한다. 집중 여부에 따른 기존 특수 재료 확률만 적용하며 개별 몬스터 보너스나 신규 보상은 추가하지 않는다.

후속 런타임 대조에서 느린 처치 보상 범위는 제거했다. 미개척지는 스태미나 한 번에 몬스터 한 종과 단판 전투를 처리하며, 현재 보상 계산에는 처치 시간이나 전투 길이를 반영하는 입력이 없다. 느린 속도에 대한 보상 배율도 추가하지 않는다.

## 테스트와 검증

- 풀 카탈로그: 12개 풀과 활성 특수 몬스터 36종, 폐기된 출시 단계·후보군 메타데이터 없음
- 조우: 파쇄 거수 RNG 구간별 암반 거수·철벽 분쇄자·지각 파괴자 선택
- 서버 사냥 준비: 선택된 두 확장 몬스터 ID 보존
- 런타임: 활성 특수 36종, 전체 41종
- 전투: 암반 거수의 3페이즈·2배 강타, 철벽 분쇄자의 관통 11, 지각 파괴자의 분쇄 일격·최대 MP 60
- 집중: 세 몬스터의 공격력 +10%·플레이어 방어 무시 8%, 기존 스킬과 MP 유지
- 안전장치: 선택된 풀 밖의 몬스터 ID 거부
- 보상: 세 몬스터의 동일 거수 골편 규칙
- 자산: 두 WebP의 512×512 RGBA 알파와 참조 존재
- 관련 테스트, 전체 타입 검사, 변경 파일 린트, 전체 테스트, `V2_UNEXPLORED=true` production build

## 제외 범위

- 새로운 관통·방어 파괴·강타 규칙
- 기존 스킬의 수치, 발동률, 재사용 대기시간과 MP 변경
- 수동 전투 행동 또는 전용 UI
- 개별 몬스터 보상 차등
- 느린 처치 보상 배율 추가
- 배포, 병합, 푸시, PR 생성
