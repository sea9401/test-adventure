# 미개척지 수정 포격대 확장 설계

## 목표

수정 포격대의 기존 출시 몬스터 `수정 술사`에 `굴절 포격체`와 `수정 파수체`를 추가해 실제 미개척지 사냥에서 세 몬스터가 모두 출현하게 한다. 앞선 네 풀의 확장 상태는 유지하고, 정밀 사냥단 이후 7개 특수 풀은 출시 몬스터 한 종만 출현해야 한다.

## 선택한 접근

기존 풀별 `releaseStage`와 `activeMonsters` 구조를 재사용한다. 수정 포격대의 출시 단계만 `expanded`로 전환하고 조우, 런타임, 집중 효과, 풀 공통 보상 경로에는 새 분기를 추가하지 않는다.

전투는 이미 연결된 `mob_arcane_bolt`, `mob_arcane_burst`, `mob_arcane_nova`를 그대로 사용한다. 공용 마력탄과 비전 작렬에 MP 비용을 추가하거나 수정 포격대 전용 전투 규칙을 만들지 않는다. 이 두 스킬은 현행 재사용 대기시간과 발동 확률에 따라 자동 시전되며, 비전 폭발만 기존 MP 35와 수정 파수체의 유한 MP를 사용한다.

## 조우와 전투

수정 포격대 풀이 선택되면 `activeMonsters` 세 종에서 균등 선택한다. 각 몬스터의 출현 확률은 1/3이다.

| 몬스터 | 역할 | 핵심 수치 | 능력 |
| --- | --- | --- | --- |
| 수정 술사 | 기본형 | HP 0.90, 공격 1.15, 방어 0.80, 마방 1.10, 일반 속도 | 마법 공격, 재사용 3행동·50% 발동의 `마력탄` |
| 굴절 포격체 | 공격형 | HP 0.75, 공격 1.35, 방어 0.70, 마방 1.00, 느린 속도 | 마법 공격, 재사용 4행동·45% 발동의 `비전 작렬` |
| 수정 파수체 | 변칙형 | HP 1.05, 공격 1.10, 방어 1.15, 마방 1.25, 느린 속도 | 마법 공격, MP 70으로 MP 35의 `비전 폭발` 최대 2회 |

수정 포격대 집중 노드는 세 몬스터 모두에게 공격력 10% 증가와 최대 MP 2배를 적용한다. 수정 술사와 굴절 포격체의 자동 마법은 MP 비용이 0이므로 실질적으로 공격력 증가가 핵심이다. 수정 파수체는 집중 시 MP가 70에서 140으로 증가해 비전 폭발을 최대 4회 사용할 수 있다. 스킬 발동 확률과 재사용 대기시간은 바꾸지 않는다.

## 런타임과 안전장치

기존 몬스터 ID 기반 런타임 생성기를 그대로 사용한다. 수정 포격대가 확장되면 `refraction_artillery`와 `crystal_sentinel`이 활성 검증을 통과하며, 아직 출시되지 않은 정밀 사냥단 이후 후보는 계속 거부된다.

활성 특수 몬스터는 기존 20종에서 22종으로 늘어나고, 기본 몬스터 5종을 합친 전체 미개척지 런타임 카탈로그는 27종이 된다. 모든 정수 난이도 95~120에서 각 수치가 유한한 양수여야 한다.

## 이미지

기존 `수정 술사`와 같은 정사각형 투명 배경, 청보라·자홍색 결정과 금색 테두리, 어두운 판타지 렌더 스타일로 다음 파일을 추가한다.

- `public/images/monster/v2/unexplored-refraction-artillery.webp`
- `public/images/monster/v2/unexplored-crystal-sentinel.webp`

굴절 포격체는 낮고 넓은 골렘 몸체에 거대한 다면 수정 포신과 렌즈를 결합해 느린 유리 대포 실루엣을 만든다. 수정 파수체는 두꺼운 수정 장갑판과 중앙 동력핵, 방패처럼 펼쳐진 결정 구조를 가진 넓고 견고한 수호 골렘으로 만든다. 두 이미지에는 텍스트, 로고, 워터마크, 배경 장면을 넣지 않는다.

이미지 생성 결과가 체크무늬를 실제 픽셀로 포함하지 않도록 WebP 변환 전 RGBA 알파 채널을 검사한다.

## 보상

세 몬스터 모두 풀 ID 기준의 기존 재료 `v2_unexplored_crystal_artillery_material`을 같은 확률로 드롭한다. 집중 여부에 따른 기존 특수 재료 확률만 적용하며 개별 몬스터 보너스나 신규 보상은 추가하지 않는다.

## 테스트와 검증

- 풀 카탈로그: 앞의 다섯 풀만 `expanded`, 나머지 7개는 `launch`
- 조우: 수정 포격대 RNG 구간별 수정 술사·굴절 포격체·수정 파수체 선택
- 서버 사냥 준비: 선택된 두 확장 몬스터 ID 보존
- 런타임: 활성 특수 22종, 전체 27종
- 전투: 세 몬스터 모두 마법 공격, 각 마력탄·비전 작렬·비전 폭발 연결, 수정 파수체 MP 70
- 집중: 굴절 포격체의 공격력 증가, 수정 파수체 공격력 증가와 MP 140
- 안전장치: 정밀 사냥단의 미출시 후보 거부
- 보상: 세 몬스터의 동일 수정 렌즈 규칙
- 자산: 두 WebP의 512×512 RGBA 알파와 참조 존재
- 관련 테스트, 전체 타입 검사, 변경 파일 린트, 전체 테스트, `V2_UNEXPLORED=true` production build

## 제외 범위

- 공용 마력탄·비전 작렬의 MP 비용 변경
- 새로운 전투 스킬 종류 또는 수동 행동
- 수정 포격대 전용 UI
- 개별 몬스터 보상 차등
- 정밀 사냥단 이후 풀의 활성화
- 배포, 병합, 푸시, PR 생성
