# 미개척지 혹한 군단 확장 설계

## 목표

혹한 군단의 기존 출시 몬스터 `서리 접촉자`에 `빙결 술사`와 `혹한 파수자`를 추가해 실제 미개척지 사냥에서 세 몬스터가 모두 출현하게 한다. 앞선 열 개 풀의 확장 상태는 유지하고, 파쇄 거수는 출시 몬스터 한 종만 출현해야 한다.

## 선택한 접근

기존 풀별 `releaseStage`와 `activeMonsters` 구조를 재사용한다. 혹한 군단의 출시 단계만 `expanded`로 전환하고 조우, 런타임, 집중 효과, 풀 공통 보상 경로에는 새 분기를 추가하지 않는다.

앞서 합의한 대로 새로운 빙결 중첩·행동 무시 규칙이나 수동 전투 행동을 추가하지 않고 기존 자동 전투용 한기 계열과 마법 공격을 유지한다. 세 몬스터는 한기의 강도, 마법 공격 유무, 생존력과 공격 자원으로 역할을 구분한다.

## 조우와 전투

혹한 군단 풀이 선택되면 `activeMonsters` 세 종에서 균등 선택한다. 각 몬스터의 출현 확률은 1/3이다.

| 몬스터 | 역할 | 핵심 수치 | 능력 |
| --- | --- | --- | --- |
| 서리 접촉자 | 기본형 | HP 1.05, 공격 0.90, 방어 1.05, 마방 1.10, 일반 속도 | `한기`: 기존 둔화 |
| 빙결 술사 | 공격형 | HP 0.85, 공격 1.15, 방어 0.80, 마방 1.10, 일반 속도 | 마법 공격, `심층 한기`: 속도 -22%·3턴, `마력탄`: 50% 발동·3턴 재사용 |
| 혹한 파수자 | 변칙형 | HP 1.20, 공격 1.05, 방어 1.15, 마방 1.25, 느린 속도 | 마법 공격, `혹한`: 속도 -28%·3턴, `비전 폭발`: 55% 발동·2턴 재사용·MP 35, 최대 MP 70 |

빙결 술사는 가장 낮은 체력과 방어를 감수하고 강한 둔화와 자원 소모 없는 마력탄을 함께 사용한다. 혹한 파수자는 가장 느리지만 생존 수치와 둔화가 가장 높고 비전 폭발을 최대 두 번 사용할 수 있다. 서리 접촉자는 생존과 둔화의 기준점이다.

혹한 군단 집중 노드는 서리 접촉자의 `한기`를 `심층 한기`로 교체한다. 빙결 술사와 혹한 파수자는 이미 상위 한기·마법 공격 묶음을 사용하므로 집중 후에도 장착 스킬, 마법 공격 타입과 최대 MP가 그대로 유지된다. 풀 설명의 마법 공격 강화는 특화 몬스터의 기존 마법 공격 구성으로 표현하며 별도의 공격력 배율은 추가하지 않는다.

## 런타임과 안전장치

기존 몬스터 ID 기반 런타임 생성기를 그대로 사용한다. 혹한 군단이 확장되면 `freezing_mage`와 `frozen_sentinel`이 활성 검증을 통과하며, 아직 출시되지 않은 파쇄 거수 후보는 계속 거부된다.

활성 특수 몬스터는 기존 32종에서 34종으로 늘어나고, 기본 몬스터 5종을 합친 전체 미개척지 런타임 카탈로그는 39종이 된다. 모든 정수 난이도 95~120에서 각 수치가 유한한 양수여야 한다.

## 이미지

기존 `서리 접촉자`와 같은 정사각형 투명 배경, 청백색 얼음 결정과 서리 안개, 차가운 청색 발광, 사실적인 어두운 판타지 렌더 스타일로 다음 파일을 추가한다.

- `public/images/monster/v2/unexplored-freezing-mage.webp`
- `public/images/monster/v2/unexplored-frozen-sentinel.webp`

빙결 술사는 가늘고 연약한 인간형 실루엣, 얼어붙은 남색 로브, 수정 지팡이와 손끝의 응축된 마력탄으로 공격형 마법사를 표현한다. 혹한 파수자는 넓고 무거운 얼음 골렘 실루엣, 두꺼운 빙정 장갑과 중심부의 비전 서리 핵, 방어적인 직립 자세로 제한 폭발형을 표현한다. 서리 접촉자와 두 신규 몬스터의 체형, 자세와 전투 역할이 명확히 달라야 한다. 이미지에는 텍스트, 로고, 워터마크, 배경 장면을 넣지 않는다.

이미지 생성 결과가 체크무늬를 실제 픽셀로 포함하지 않도록 WebP 변환 전 RGBA 알파 채널을 검사한다.

## 보상

세 몬스터 모두 풀 ID 기준의 기존 재료 `v2_unexplored_frozen_legion_material`을 같은 확률로 드롭한다. 집중 여부에 따른 기존 특수 재료 확률만 적용하며 개별 몬스터 보너스나 신규 보상은 추가하지 않는다.

## 테스트와 검증

- 풀 카탈로그: 앞의 열한 개 풀만 `expanded`, 파쇄 거수만 `launch`
- 조우: 혹한 군단 RNG 구간별 서리 접촉자·빙결 술사·혹한 파수자 선택
- 서버 사냥 준비: 선택된 두 확장 몬스터 ID 보존
- 런타임: 활성 특수 34종, 전체 39종
- 전투: 세 몬스터의 정확한 한기·마법 스킬, 빙결 술사와 혹한 파수자의 마법 공격 타입, 혹한 파수자의 최대 MP 70
- 집중: 서리 접촉자의 한기만 심층 한기로 교체하고 두 특화형의 상위 스킬·공격 타입·MP 유지
- 안전장치: 파쇄 거수의 미출시 후보 거부
- 보상: 세 몬스터의 동일 혹한 결정 규칙
- 자산: 두 WebP의 512×512 RGBA 알파와 참조 존재
- 관련 테스트, 전체 타입 검사, 변경 파일 린트, 전체 테스트, `V2_UNEXPLORED=true` production build

## 제외 범위

- 새로운 빙결 중첩·행동 무시 규칙 또는 한기 명칭 변경
- 기존 한기·마법 공격의 계수, 발동률, 재사용 대기시간 변경
- 수동 전투 행동 또는 전용 UI
- 개별 몬스터 보상 차등
- 파쇄 거수 활성화
- 배포, 병합, 푸시, PR 생성
