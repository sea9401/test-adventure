# 미개척지 빙하 거수 전투 기믹 설계

## 목표

빙하 거수를 미개척지 개인 보스 3종 가운데 **행동 속도를 극단적으로 압박하는 보스**로 완성한다. 전투는 기존 자동 ATB 방식을 유지한다. 보스가 행동할수록 플레이어에게 보스 전용 한기가 쌓이고, 한기가 늘어날 때 이미 예약된 플레이어 행동까지 즉시 늦어진다. 10중첩에 도달하면 빙결이 발생해 다음 플레이어 행동 한 번을 완전히 취소한다.

화면에 표시하는 명칭은 기존 얼음 마법사와 동일하게 `한기`, `빙결`을 사용한다. 다만 두 시스템은 내부 상태와 규칙을 공유하지 않는다. 얼음 마법사의 현재 `한기 5중첩 → 빙결 추가 피해와 행동 지연` 규칙, 스킬 수치와 빙결 주기는 이번 작업에서 전혀 변경하지 않는다.

## 범위

이 문서는 빙하 거수 한 종의 보스 전용 ATB 기믹만 다룬다.

- 보스 행동과 실제 HP 피해에 따른 한기 누적
- 한기 중첩에 비례한 플레이어 행동 속도 감소
- 10중첩 빙결과 다음 플레이어 행동 1회 취소
- 상태 방어, 정화, 회피와 보호막의 상호작용
- 공격 결과와 전투 재생 표시
- 결정론적 밸런스 시뮬레이션

얼음 마법사·빙결술사·빙천제의 한기와 빙결, 공용 몬스터 `chill` 규칙, 다른 보스, 보상, 소환 비용, 이미지와 운영 배포는 범위 밖이다.

## 채택한 구조

### 보스 전용 상태

빙하 거수는 선택적 `BossMechanicContext`와 전투 상태를 사용한다.

```ts
type GlacialColossusBattleState = {
  kind: "glacial_colossus";
  glacialChillStacks: number;
  glacialFreezePending: 0 | 1;
  glacialFreezeCount: number;
  glacialSkippedActionCount: number;
};
```

`glacialChillStacks`는 `0~9`만 저장한다. 10중첩은 지속 상태가 아니라 즉시 빙결로 전이되는 경계다. `glacialFreezePending`은 다음 플레이어 행동을 한 번 취소할 예약이며 중첩되지 않는다. 횟수 필드는 해당 공격 시도 안의 결과 요약과 시뮬레이션에 사용한다.

기존 `enemyFrostChillStacks`는 플레이어가 적에게 부여하는 얼음 마법사 자원이고, 기존 `stacks.chillStacks`는 몬스터가 플레이어에게 주는 고정 피해·회피 감소 상태다. 빙하 거수는 어느 쪽도 재사용하지 않는다. 같은 한글 명칭을 표시하더라도 저장 위치와 전이는 완전히 분리해 기존 전투의 결과를 바꾸지 않는다.

### 대안과 제외 이유

공용 몬스터 `chill` 타입에 속도 감소와 행동 취소를 추가하면 호수 보스와 일반 한기 몬스터까지 함께 변한다. 일반 속도 디버프 슬롯을 재사용하면 이미 예약된 ATB 행동에 즉시 반영되지 않고 다른 속도 효과와 충돌한다. 얼음 마법사의 한기 순수 함수를 재사용하면 5중첩·추가 피해·행동 지연이라는 다른 계약이 섞인다. 따라서 보스 전용 상태가 가장 작은 격리 경계다.

## 한기 누적

빙하 거수가 살아 있고 플레이어도 살아 있는 상태에서 예약된 적 행동 묶음 하나가 끝날 때 한기를 정산한다.

1. 냉기장으로 한기 `+1`
2. 같은 행동 묶음이 일반 보호막과 마법 장벽을 통과해 플레이어 HP에 실제 피해를 하나라도 주었다면 추가 `+1`
3. 여러 번 공격했거나 다단 스킬이어도 피격 추가량은 행동 묶음당 최대 `+1`

따라서 한 번의 보스 행동에서 얻는 한기는 `+1` 또는 `+2`다. 공격이 빗나가거나 회피되거나 보호막이 전량 흡수해도 냉기장 `+1`은 남는다. 보스가 감전 등으로 공격을 실행하지 못한 예약 행동에도 주변 냉기장은 유지되어 `+1`을 준다. 적 행동 진입 전에 보스가 지속 피해나 반사로 사망한 경우에는 새 한기를 만들지 않는다.

피격 추가량은 전투 로그 문자열을 파싱하지 않는다. 적 공격 로그의 정형 실제 HP 피해 메타데이터를 행동 묶음 단위로 합산한다. 피격 뒤 회복이 같은 행동에 발생하더라도 실제 피해 사건 자체는 보존한다.

## 상태 방어와 정화

냉기장 `+1`은 환경 효과라 상태이상 1회 방어와 정화 결계로 막을 수 없다. 실제 HP 피해에 따른 추가 `+1`만 상태 방어 대상이다.

- 상태이상 1회 방어가 남아 있으면 피격 추가량을 막고 해당 1회를 소비한다.
- 상태이상 1회 방어가 없고 정화 결계가 남아 있으면 피격 추가량을 막고 결계 1회를 소비한다.
- 두 방어가 모두 있으면 기존 우선순위대로 상태이상 1회 방어를 먼저 사용한다.
- 냉기장만으로 10중첩에 도달한 경우 불필요하게 피격 방어 횟수를 소비하지 않는다.
- 일반 정화 효과는 현재 `glacialChillStacks`를 0으로 만든다.
- 이미 발생한 `glacialFreezePending`은 정화로 제거하지 않는다.

정화로 중첩이 감소하면 아직 남아 있는 플레이어 행동 예약 시간도 낮아진 감속률에 맞춰 즉시 짧아진다. 플레이어 행동 중 정화가 일어난 경우에는 해당 행동 이후의 다음 예약부터 0중첩 속도를 사용한다.

## 속도 감소와 ATB 예약 시간

한기 중첩별 플레이어 속도 배율은 다음과 같다.

```text
한기 속도 배율 = 1 - 0.07 × 한기 중첩
```

실제 저장 중첩의 최댓값은 9이므로 최저 배율은 `0.37`, 즉 속도 63% 감소다. 기존 장비, 버프와 중량 효과를 반영한 플레이어 유효 속도에 이 배율을 마지막으로 곱한다.

한기는 적 행동 도중 증가하므로 다음 플레이어 행동이 이미 예약되어 있을 수 있다. 새 감속을 다음 행동 이후까지 미루지 않고 남은 예약 시간을 즉시 비례 조정한다.

```text
기존 남은 시간 = max(0, playerNextTick - currentTick)
조정된 남은 시간 = 기존 남은 시간 × 기존 한기 속도 배율 / 새 한기 속도 배율
playerNextTick = currentTick + 조정된 남은 시간
```

정화로 한기가 줄어드는 경우에도 같은 식을 사용해 남은 시간을 줄인다. 속도 배율은 유한한 양수로 정규화하며 손상된 상태가 무한대·음수 틱을 만들지 못하게 한다.

## 10중첩 빙결

한기 획득으로 합계가 10 이상이 되는 순간 다음 순서로 처리한다.

1. 한기를 전부 소비해 `glacialChillStacks = 0`으로 만든다.
2. `glacialFreezePending = 1`로 둔다.
3. `glacialFreezeCount`를 1 증가시킨다.
4. 빙결 발생 직전까지 누적된 예약 지연은 그대로 유지한다. 0중첩이 되었다는 이유로 이미 늦어진 다음 행동을 즉시 앞당기지 않는다.

빙결 예약이 남아 있는 동안에는 냉기장과 피격 한기를 새로 쌓지 않는다. 이 면역 구간은 플레이어가 한 번도 행동하지 못한 채 두 번째 빙결이 겹치는 것을 막는다.

다음 플레이어 행동 시점에 빙결 예약이 있으면 행동 전체를 취소한다.

- 자동 행동 선택기를 호출하지 않는다.
- 공격, 액티브 스킬과 물약을 사용하지 않는다.
- 재생, 흡혈과 행동 시작 회복을 실행하지 않는다.
- 플레이어 행동 기준 지속 피해를 틱하지 않는다.
- 플레이어 행동 기준 버프·디버프 지속시간을 줄이지 않는다.
- 포션 수량, MP와 기타 행동 자원을 소비하지 않는다.
- 완료한 플레이어 행동 수를 늘리지 않는다.

취소 시 `glacialFreezePending = 0`, `glacialSkippedActionCount += 1`로 바꾸고 현재 0중첩 유효 속도로 다음 플레이어 행동을 새로 예약한다. 이후 보스 행동부터 한기 누적이 다시 시작된다. 이 구조로 빙결 사이에는 최소 다섯 번의 보스 행동이 필요하고 연속 행동 봉쇄가 발생하지 않는다.

## 기존 빙하 거수 데이터 변경

빙하 거수의 기존 공용 몬스터 `chill` 스킬은 제거한다. 그 스킬이 제공하던 한기 고정 피해와 회피 감소도 함께 사라진다. 기본 마법 공격, 체력, 공격력, 방어력, 속도와 명중 등 원본 전투 수치는 우선 유지한다.

보스 카드 특성은 다음 세 문구로 교체한다.

- `냉기장으로 한기 누적`
- `한기 중첩당 행동 속도 감소`
- `10중첩 빙결 — 다음 행동 취소`

빙하 거수의 공격 난도는 직접 피해보다 행동 속도 통제에서 나오게 한다.

## 전투 기록과 재생 표시

기존 보스 전용 자원 표시 영역을 사용하며 새 화면이나 카드 표면을 만들지 않는다.

- 누적 상태: `한기 7/10`
- 빙결 예약 상태: `빙결 1/1`
- 한기 누적: `[한기] +2 · 현재 8/10 (냉기장 +1, 피격 +1)`
- 피격 추가량이 없을 때: `[한기] +1 · 현재 6/10 (냉기장)`
- 7중첩 최초 도달: `[한기] 빙결 임박`
- 10중첩 전이: `[빙결] 다음 행동이 봉쇄된다.`
- 행동 취소: `[빙결] 몸이 얼어붙어 행동할 수 없다.`

한기와 빙결 예약을 동시에 표시하지 않는다. 10중첩에서 한기가 0이 되면 다음 HP 바 스냅샷은 `빙결 1/1`을 표시하고, 취소가 끝난 뒤에는 둘 다 숨긴다.

공격 결과에는 다음 요약을 포함한다.

- 마지막 `glacialChillStacks`
- `glacialFreezePending`
- `glacialFreezeCount`
- `glacialSkippedActionCount`

## 세션과 API 경계

빙하 거수 공격 API만 `{ kind: "glacial_colossus" }` 보스 메커니즘을 활성화한다. 각 공격 요청의 전투는 한기 0, 빙결 예약 0과 횟수 0에서 시작한다.

이 상태는 플레이어에게 걸리는 전투 한정 상태이므로 개인 보스 세션의 `mechanic_state`에 저장하지 않는다. 결과와 재생 페이로드에만 해당 공격 시도의 마지막 상태와 횟수를 반환한다. 추적 병기의 세션 지속 추적 상태, 독혈 군주와 표준 협동 보스 데이터에는 빙하 거수 필드를 쓰지 않는다.

## 종료와 손상 상태 처리

- 음수, 유한하지 않은 중첩과 횟수는 0으로 정규화한다.
- 저장 한기는 `0~9`, 빙결 예약은 `0 | 1`로 제한한다.
- 플레이어가 적 행동에서 사망하면 한기와 빙결을 새로 부여하지 않는다.
- 보스가 적 행동 정산 전에 사망하면 냉기장을 발생시키지 않는다.
- 빙결 예약 상태로 전투가 끝나도 다음 공격 시도로 이월하지 않는다.
- 빙결 취소 시점에 보스가 이미 죽어 있거나 전투가 종료되었다면 추가 행동 예약을 만들지 않는다.
- 빙하 거수 메커니즘이 없는 전투는 플레이어 유효 속도, ATB 예약 시간과 행동 처리 결과가 기존과 동일해야 한다.

## 회귀 테스트

### 순수 전이와 시간 산식

- 0~9중첩의 속도 배율과 9중첩 0.37 하한
- 냉기장 `+1`, 피격 포함 `+2`, 다단 행동도 최대 `+2`
- 9중첩에서 `+1` 또는 `+2`가 정확히 한 번 빙결하고 초과분을 버림
- 빙결 후 한기 0과 예약 1
- 손상 값 정규화
- 중첩 증가·정화 시 남은 ATB 예약 시간 비례 조정

### ATB 통합

- 회피·완전 흡수는 냉기장만, 실제 HP 피해는 피격 추가량까지 부여
- 감전으로 공격하지 못한 보스 행동도 냉기장 부여
- 상태이상 1회 방어와 정화 결계가 피격 추가량만 차단·소비
- 정화가 현재 한기와 예약 시간을 함께 복구하지만 빙결 예약은 유지
- 빙결 예약 중 추가 한기를 쌓지 않음
- 다음 플레이어 행동을 정확히 한 번 취소하고 자동 행동 선택기를 호출하지 않음
- 취소 행동에서 물약·MP·회복·지속 피해·버프 지속시간을 소비하지 않음
- 취소 뒤 0중첩 정상 속도로 재개
- 플레이어나 보스 사망 뒤 추가 누적 없음

### 격리와 표현

- 얼음 마법사 기존 5중첩 빙결 피해·30~50% 지연·잔류 한기 결과 유지
- 공용 몬스터 한기 피해와 회피 감소 결과 유지
- 빙하 거수가 아닌 PvE, PvP와 다른 보스의 결정론적 결과 유지
- 보스 카드 특성 문구, 공격 API 활성화와 비저장 계약
- 재생 자원 `한기 7/10`, `빙결 1/1` 한글 표시
- 결과의 빙결 발동·행동 취소 횟수 일치

## 밸런스 검증

대표 7계보를 고정 시드로 50회씩 실행해 생존 틱, 완료한 플레이어 행동 수, 기여도, 빙결 발동 횟수와 실제 행동 취소 횟수를 집계한다.

출시 시작값은 다음과 같다.

- 빙결 임계: 10중첩
- 냉기장: 보스 행동당 +1
- 피격 추가: 실제 HP 피해가 있으면 행동당 +1
- 감속: 한기 1중첩당 7%, 최대 63%
- 빙결: 다음 플레이어 행동 1회 취소
- 발동 후: 한기 0, 빙결 소비 전 추가 누적 정지

대부분의 계보가 첫 빙결 전에 기존 직접 공격으로 사망하면 보스 원본 공격과 한기 도달 시간을 비교한다. 반대로 긴 전투에서도 빙결을 거의 경험하지 못하거나 감속이 기여도에 의미 있는 차이를 만들지 못하면 감속률과 누적량을 조정한다. 다른 보스와 얼음 마법사 수치는 캘리브레이션 다이얼로 사용하지 않는다.

빙결 발동 횟수와 실제 취소 횟수는 정상 종료 전 미소비 예약을 제외하면 일치해야 한다. 한 번의 빙결 예약이 두 행동을 취소하거나, 빙결 면역 구간 없이 예약이 중첩되거나, 취소 직후 다시 취소되는 결과는 실패로 본다.

## 완료 기준

- 냉기장·피격 한기 → 즉시 속도 감소 → 10중첩 빙결 → 행동 1회 취소 → 0중첩 재누적 순환이 자동 ATB에서 일치한다.
- 한기 증가와 정화가 이미 예약된 플레이어 행동 시간에 즉시 반영된다.
- 상태 방어와 보호막은 합의한 경계에서만 피격 추가량을 막는다.
- 공격 결과와 재생 로그·자원 표시가 같은 상태를 보여 준다.
- 공격 시도 사이에 한기와 빙결 예약이 남지 않는다.
- 얼음 마법사, 공용 한기, 다른 보스와 PvP 결과가 변하지 않는다.
- 집중 테스트, 타입 검사, 린트와 전체 회귀를 통과한다.
- 운영 데이터 쓰기, 배포, 푸시와 PR 생성은 수행하지 않는다.
