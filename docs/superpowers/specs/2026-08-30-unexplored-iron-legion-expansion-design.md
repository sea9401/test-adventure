# 미개척지 철갑 군단 확장 설계

## 목표

철갑 군단의 기존 출시 몬스터인 `철갑 방패병`에 `철갑 창병`, `철갑 파쇄병`을 추가해 실제 미개척지 사냥에서 세 몬스터가 모두 출현하게 한다. 다른 11개 특수 풀은 후속 작업 전까지 기존 출시 몬스터 한 종만 출현해야 한다.

## 범위

- 철갑 군단 풀의 단계적 출시 상태와 활성 몬스터 목록
- 활성 몬스터를 대상으로 한 균등 조우 선택
- 선택된 몬스터 ID를 실제 전투 런타임까지 보존
- 창병과 파쇄병의 기존 시뮬레이션 능력 배선
- 각 몬스터의 전용 이미지
- 풀 공통 보상 유지와 회귀 검증

UI, 신규 전투 규칙, 신규 재료, 다른 특수 풀 활성화는 이번 범위에 포함하지 않는다.

## 출시 상태 모델

각 특수 풀에 `launch` 또는 `expanded` 출시 단계를 둔다.

- `launch`: 첫 번째 몬스터만 `activeMonsters`에 포함하고 나머지 두 종은 `expansionCandidates`로 남긴다.
- `expanded`: 세 몬스터를 모두 `activeMonsters`에 포함하고 `expansionCandidates`는 비운다.

철갑 군단만 `expanded`로 전환한다. 이 구조는 다음 풀을 확장할 때 해당 풀의 단계만 바꾸고 이미지와 검증을 추가할 수 있게 한다.

`launchMonster`는 최초 출시 몬스터라는 기록과 기존 참조 호환성을 위해 유지한다.

## 조우와 전투

특수 풀이 선택되면 그 풀의 `activeMonsters` 안에서 RNG로 균등 선택한다. 따라서 철갑 군단의 세 몬스터는 각각 1/3 확률로 출현하며, 다른 풀은 기존과 동일하다.

사냥 준비 계층은 조우 선택기가 반환한 `monsterId`를 런타임 생성기에 반드시 전달한다. 런타임 생성기는 요청된 몬스터가 해당 풀의 활성 목록에 속하는지 검증하고, 미출시 후보나 다른 풀 몬스터라면 오류를 낸다.

전투 수치와 능력은 이미 승인된 시뮬레이션 카탈로그를 그대로 사용한다.

| 몬스터 | 역할 | 핵심 수치 | 능력 |
| --- | --- | --- | --- |
| 철갑 방패병 | 방어형 | HP 1.10, 공격 0.90, 방어 1.80, 마방 0.85 | 방어 태세 |
| 철갑 창병 | 공격형 | HP 0.95, 공격 1.05, 방어 1.65, 마방 0.75 | 방어 관통 11 |
| 철갑 파쇄병 | 변칙형 | HP 1.20, 공격 1.10, 방어 1.90, 마방 0.80 | 3회마다 2배 강타 |

집중 노드의 물리 방어 15% 증가는 철갑 군단 세 몬스터 모두에게 동일하게 적용한다.

## 이미지

기존 `철갑 방패병`과 같은 정사각형 투명 배경의 다크 판타지 몬스터 렌더 스타일로 다음 파일을 추가한다.

- `public/images/monster/v2/unexplored-armored-spearman.webp`
- `public/images/monster/v2/unexplored-armored-crusher.webp`

창병은 장창과 비교적 가벼운 철갑 실루엣, 파쇄병은 양손 대형 파쇄 무기와 무거운 철갑 실루엣으로 구분한다. 텍스트, 로고, 워터마크는 넣지 않는다.

이미지 경로는 풀 ID가 아니라 활성 몬스터 ID로 찾는다. 모든 활성 몬스터가 고유 이미지 경로를 가져야 하며 이미지 검사 스크립트가 실제 파일 존재를 검증한다.

## 보상

현재 미개척지 특수 보상은 개별 몬스터가 아니라 풀 ID를 기준으로 계산한다. 세 몬스터 모두 기존 철갑 군단 재료 `v2_unexplored_iron_legion_material`을 같은 확률로 드롭한다. 개별 처치 시간 보너스나 신규 보상은 추가하지 않는다.

## 오류와 안전장치

- 활성 목록이 비어 있으면 조우 선택 결과를 만들지 않는다.
- 풀에 속하지 않거나 아직 활성화되지 않은 몬스터 ID로 런타임 생성을 요청하면 즉시 오류를 낸다.
- 활성 몬스터의 시뮬레이션 프록시나 이미지 경로가 없으면 즉시 오류를 낸다.
- 95~120 난이도의 모든 활성 몬스터 수치가 유한한 양수인지 검증한다.

## 검증

- 풀 카탈로그: 철갑 군단 3종 활성, 다른 풀 1종 활성
- 조우: 철갑 군단 RNG 구간별 방패병·창병·파쇄병 선택
- 서버 사냥 준비: 선택된 몬스터 ID 보존
- 런타임: 활성 특수 몬스터 총 14종, 전체 런타임 총 19종
- 전투: 창병 관통과 파쇄병 3회 주기 강타 배선, 집중 방어 증가
- 보상: 철갑 군단 세 몬스터의 동일 재료 규칙
- 자산: 이미지 참조 검사, 타입 검사, 관련 테스트와 전체 테스트
