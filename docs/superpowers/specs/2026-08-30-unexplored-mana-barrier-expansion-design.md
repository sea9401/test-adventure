# 미개척지 마력 방벽체 확장 설계

## 목표

마력 방벽체의 기존 출시 몬스터 `결계 수호체`에 `룬 집행자`와 `봉인 감시체`를 추가해 실제 미개척지 사냥에서 세 몬스터가 모두 출현하게 한다. 철갑 군단의 확장 상태는 유지하고, 나머지 10개 특수 풀은 기존 출시 몬스터 한 종만 출현해야 한다.

## 선택한 접근

기존 풀별 `releaseStage`와 `activeMonsters` 구조를 재사용한다. 마력 방벽체의 출시 단계만 `expanded`로 전환하고, 조우·런타임·집중 효과·풀 공통 보상 경로에는 새 분기를 추가하지 않는다.

새 마법이나 상태 저항 규칙을 만들지 않는다. 세 몬스터의 수치와 능력은 이미 승인되고 전투 엔진에 배선된 시뮬레이션 카탈로그를 그대로 사용한다.

## 조우와 전투

마력 방벽체 풀이 선택되면 `activeMonsters` 세 종에서 균등 선택한다. 각 몬스터의 출현 확률은 1/3이다.

| 몬스터 | 역할 | 핵심 수치 | 능력 |
| --- | --- | --- | --- |
| 결계 수호체 | 방어형 | HP 1.05, 공격 0.90, 방어 0.85, 마방 1.90 | 상태 피해 저항 20% |
| 룬 집행자 | 공격형 | HP 0.90, 공격 1.10, 방어 0.70, 마방 1.70 | 마법 공격, `mob_arcane_bolt` |
| 봉인 감시체 | 변칙형 | HP 1.10, 공격 0.95, 방어 0.90, 마방 1.85 | 상태 피해 저항 40%, 방어 태세 |

룬 집행자의 `atkType`은 `magic`이며 마력탄은 기존 MP 및 자동 전투 규칙을 따른다. 봉인 감시체의 방어 태세는 기존 `brace` 능력의 피해 감소 6을 사용한다.

마력 방벽체 집중 노드는 세 몬스터 모두에게 다음 효과를 적용한다.

- 마법 방어 15% 증가
- 상태 피해 저항 10%p 증가, 최대 80%

## 런타임과 안전장치

기존 몬스터 ID 기반 런타임 생성기를 그대로 사용한다. 마력 방벽체가 확장되면 `rune_executor`와 `seal_watcher`가 활성 검증을 통과하며, 아직 출시되지 않은 다른 풀 후보는 계속 거부된다.

활성 특수 몬스터는 기존 14종에서 16종으로 늘어나고, 기본 몬스터 5종을 합친 전체 미개척지 런타임 카탈로그는 21종이 된다. 모든 정수 난이도 95~120에서 각 수치가 유한한 양수여야 한다.

## 이미지

기존 `결계 수호체`와 같은 정사각형 투명 배경, 상아색 석재·금속 테두리·청색 마력의 판타지 골렘 렌더 스타일로 다음 파일을 추가한다.

- `public/images/monster/v2/unexplored-rune-executor.webp`
- `public/images/monster/v2/unexplored-seal-watcher.webp`

룬 집행자는 방패 없이 날렵한 골렘 체형과 손·팔의 공격용 룬 마력으로 공격형 실루엣을 만든다. 봉인 감시체는 넓고 무거운 체형, 몸 주위의 봉인 고리와 판석으로 방어형 변칙 실루엣을 만든다. 두 이미지에는 텍스트, 로고, 워터마크, 배경 장면을 넣지 않는다.

이미지 생성 결과가 체크무늬를 실제 픽셀로 포함하지 않도록 WebP 변환 전 RGBA 알파 채널을 검사한다.

## 보상

세 몬스터 모두 풀 ID 기준의 기존 재료 `v2_unexplored_mana_barrier_material`을 같은 확률로 드롭한다. 집중 여부에 따른 기존 특수 재료 확률만 적용하며 개별 몬스터 보너스나 신규 보상은 추가하지 않는다.

## 테스트와 검증

- 풀 카탈로그: 철갑 군단과 마력 방벽체만 `expanded`, 나머지 10개는 `launch`
- 조우: 마력 방벽체 RNG 구간별 결계 수호체·룬 집행자·봉인 감시체 선택
- 서버 사냥 준비: 선택된 두 확장 몬스터 ID 보존
- 런타임: 활성 특수 16종, 전체 21종
- 전투: 룬 집행자의 마법 마력탄, 봉인 감시체의 저항 40%와 방어 태세
- 집중: 두 확장 몬스터의 마법 방어와 상태 피해 저항 증가
- 안전장치: 다음 미출시 풀 후보 거부
- 보상: 세 몬스터의 동일 방벽 결정 규칙
- 자산: 두 WebP의 512×512 RGBA 알파와 참조 존재
- 관련 테스트, 전체 타입 검사, 변경 파일 린트, 전체 테스트, `V2_UNEXPLORED=true` production build

## 제외 범위

- 새로운 전투 기술 또는 상태 이상
- 마력 방벽체 전용 UI
- 개별 몬스터 보상 차등
- 재생 군체 이후 풀의 활성화
- 배포, 병합, 푸시, PR 생성
