# 미개척지 몬스터 풀 런타임 메타데이터 현황

이 문서는 `src/adventure/data/v2/unexploredMonsterPools.ts`의 현재 런타임 계약을 설명한다. 최초 출시와 풀별 확장 과정을 기록한 기존 계획·설계 문서는 당시 작업 이력이며, 현재 카탈로그 필드의 필요 여부는 이 문서를 기준으로 판단한다.

## 전투와 보상 구조

미개척지 일반 사냥은 기존 사냥 라우트를 재사용한다. 요청 한 번에 조우 그룹과 몬스터 한 종을 고르고, 같은 요청에서 전투 결과와 기존 스태미나 차감을 확정한다. 보상은 몬스터 풀, 집중 효과와 탐사망 보상 효과를 입력으로 계산하며 처치 시간이나 전투 길이를 입력으로 받지 않는다.

따라서 느린 몬스터에게 별도의 보상 범위를 붙이던 `slowKillRewardBonusPctRange`는 현재 단판 구조와 맞지 않고 지급 경로도 없어 제거한다. 느린 속도로 인한 전투 밸런스는 `speedBand`, 상대 능력치와 능력 조합으로만 관리한다.

## 풀 필드 대조

| 필드 | 실제 소비 경로 | 상태와 근거 |
| --- | --- | --- |
| `id` | 탐사망 노드, 조우 선택, 런타임 몬스터, 흔적·보스 풀 연결 | 유지. 풀 정체성과 저장·보상 키다. |
| `name` | 탐사망 설명, 재료 설명과 미개척지 UI | 유지. 사용자에게 표시되는 풀 정체성이다. |
| `materialId`, `materialName` | 풀 재료 카탈로그, 보스 소환석·장비 제작, 탐사망 UI | 유지. 실제 인벤토리와 제작 비용에 사용한다. |
| `focusDescription` | 특화 및 집중 노드 설명 | 유지. 실제 UI 문구다. |
| `monsters` | 특수 몬스터 36종의 수치·기믹 런타임 생성 | 유지. 전체 전투 정의의 원천이다. |
| `activeMonsters` | 조우 RNG 후보, 선택 ID 검증, 활성 런타임 카탈로그 | 유지. 모든 풀이 확장된 현재는 `monsters`에서 파생하지만 실제 조우 경계로 소비한다. |
| `releaseStage` | 없음 | 제거. 12개 풀이 모두 확장되어 현재 분기가 없고 과거 출시 순서만 나타냈다. |
| `launchMonster` | 기본 ID fallback 한 곳 | 제거. 현재 활성 목록과 별개의 출시 이력 필드가 불필요해졌으며 fallback은 첫 번째 현재 몬스터로 동일하게 보존한다. |
| `expansionCandidates` | 없음 | 제거. 모든 값이 빈 배열이고 향후 후보 상태를 나타내는 런타임 분기도 없다. |
| `rewardCategories` | 없음 | 제거. 실제 지급은 풀 재료 ID와 탐사망 보상 효과가 결정하며 이 분류를 읽지 않는다. |
| `slowKillRewardBonusPctRange` | 없음 | 제거. 한 번의 스태미나 사냥에서 한 종과 단판 전투를 처리하는 현재 보상 모델과 모순된다. |

## 몬스터 필드 대조

| 필드 | 실제 소비 경로 | 상태와 근거 |
| --- | --- | --- |
| `id` | 조우 선택, 런타임 프록시·이미지 연결 | 유지. 몬스터 정체성 키다. |
| `name` | 런타임 몬스터 표시명 | 유지. 실제 UI 정체성 데이터다. |
| `speedBand` | 난이도별 속도 및 공격력 보정 | 유지. 전투 밸런스 입력이다. |
| `tags` | 런타임 `Monster.tags` | 유지. 몬스터 분류와 전투 데이터다. |
| `stats` | HP·공격·방어·마법 방어 계산 | 유지. 핵심 전투 수치다. |
| `abilities` | 실제 몬스터 스킬·치명타·회피·상태 효과 어댑터 | 유지. 전투 기믹의 원천이다. |
| `role` | 없음 | 제거. `base`·`attack`·`variant`는 과거 기획 분류였고 조우 비율이나 전투 동작을 바꾸지 않았다. 현재 차이는 수치와 능력이 직접 표현한다. |

## 파생 카탈로그

`UNEXPLORED_POOL_BY_ID`는 탐사망, 런타임, 제작과 UI가 풀을 조회하는 실제 인덱스이므로 유지한다. `UNEXPLORED_MONSTER_BY_ID`는 현재 밸런스 회귀 테스트가 36종의 수치와 능력을 몬스터 ID로 검증하는 파생 인덱스이므로 유지한다. 두 값 모두 별도의 설계 상태를 저장하지 않고 원본 카탈로그에서 생성된다.

과거 문서에 남아 있는 `launch`/`expanded`, 확장 후보와 역할 표기는 당시 단계별 구현의 근거로만 해석한다. 이후 풀을 늘리거나 일부 몬스터의 출현을 제한해야 한다면 실제 조우 요구사항과 소비 코드를 먼저 추가하고 현재 계약을 갱신한다.
