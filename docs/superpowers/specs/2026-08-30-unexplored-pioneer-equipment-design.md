# 미개척지 개척자 장비·명성상점 설계

## 목적

미개척지 앞쪽 공용 풀 6종과 기본 몬스터 5종의 재료에 반복 사용처를 만들고, 미개척지에 진입한 플레이어에게 기존 6T 특화 장비 다음의 체감 가능한 성장 목표를 제공한다. 방어구와 장신구는 길드 제작소의 고레벨 대장장이 콘텐츠로 연결하고, 무기는 공용 풀 희귀 드롭으로 분리한다.

이 문서는 앞쪽 6개 풀에는 희귀 아이템을 두지 않는다는 `2026-08-28-unexplored-reward-economy-design.md`의 출시 범위를 확장한다. 상위 특화 풀 6종의 흔적, 소환석, 개인 보스와 보스 장비 규칙은 변경하지 않는다.

운영 기능 플래그 전환과 배포는 범위에 포함하지 않는다.

## 콘텐츠 구성

- 길드 제작소에 개척자 방어구·장신구 12종을 추가한다.
- 공용 풀 몬스터의 직접 드롭으로 개척자 무기 6종을 추가한다.
- 18종 모두 하나의 `개척자` 태그 세트에 속한다.
- 내부 카탈로그 티어는 현행 최상위와 같은 16, 화면 표시는 6T다.
- 성능은 일반 6T보다 약 7~10% 높은 `6.5T`를 목표로 한다.
- 고유 발동 효과 없이 범용 능력치와 세트 조합으로 성장한다.
- 기존 6T 특화 세트는 해당 빌드에서 계속 경쟁할 수 있어야 하고, 미개척지 개인 보스의 희귀 고유 및 향후 7T는 넘지 않아야 한다.

## 개척자 세트

12개 제작 장비와 6개 드롭 무기가 `unexplored_pioneer` 세트 태그를 공유한다. 무기까지 착용하면 개척자 장비를 최대 6부위 장착할 수 있지만 세트 효과는 5부위에서 끝난다. 따라서 기존 특화 무기나 특화 장비 한 부위를 남긴 혼합 세팅이 가능하며, 6부위 착용을 강제하지 않는다.

세트 효과는 각 임계점까지 누적 적용한다.

| 착용 수 | 추가 능력치 |
| ---: | --- |
| 2 | HP +300, MP +180, 적중 +8 |
| 3 | 물리 방어 +45, 마법 방어 +40, 치명저항 +7 |
| 5 | HP +420, MP +260, 치명타 +5, 속도 +8, 회복량 +6%, 상태이상 피해 감소 +7% |

5부위 누적 총합은 HP +720, MP +440, 물리 방어 +45, 마법 방어 +40, 적중 +8, 치명저항 +7, 치명타 +5, 속도 +8, 회복량 +6%, 상태이상 피해 감소 +7%다. 세트 발동 효과나 상태이상 부여 효과는 추가하지 않는다.

각 공용 풀은 기본형 한 종과 집중형 한 종을 제공한다. 기본형 6종만으로 갑옷, 장갑, 신발, 반지, 목걸이를 모두 채워 5세트를 완성할 수 있다. 집중형은 더 높은 총예산이 아니라 같은 6.5T 예산을 특정 능력치에 몰아준 대체 선택지이며, 지정된 0.1% 극희귀 기본 몬스터 재료를 요구한다.

## 제작 비용

일반 제작 1회의 공통 비용은 다음과 같다.

- 해당 공용 풀 재료 8개
- 연결된 기본 몬스터 일반 재료 10개
- 태양석 4개
- 오로라 결정 4개
- 기존 6T 자원 프로필에 따른 편백나무와 아다만타이트 합계 480개
- 개인 제작 수수료 300,000G
- 집중형만 지정 극희귀 재료 1개

자원 프로필은 철갑 군단 `guard`, 마력 방벽체와 재생 군체 및 수정 포격대 `focus`, 붉은 광전대 `fury`, 정밀 사냥단 `pursuit`을 사용한다. 기존 명장 제작 규칙을 그대로 적용해 자원, 일반·특수 재료와 골드 비용을 모두 2배로 만든다. 따라서 집중형 명장 제작은 지정 극희귀 재료 2개를 요구한다. 재료 선택 슬롯, 교환 재료나 별도 예외 비용 기능은 만들지 않는다.

| 공용 풀 | 일반 재료 10개 | 집중형 극희귀 재료 1개 |
| --- | --- | --- |
| 철갑 군단 | 성해 갑각 | 성해의 핵 |
| 마력 방벽체 | 적색 성진 | 적색거성의 제의구 |
| 재생 군체 | 공허 이빨 | 압축 공허낭 |
| 붉은 광전대 | 적색 성진 | 적색거성의 제의구 |
| 수정 포격대 | 관측 렌즈 | 죽은 별의 눈 |
| 정밀 사냥단 | 혜성 깃털 | 빛바랜 별침 |

제작은 기존 길드 제작소 트랜잭션, 제작 품질, 제작자 각인, 전문 분야, 옵션 성향, 구조 제작, 촉매, 즐겨찾기, 기록, 주간 의뢰와 대장장이 랭킹 흐름을 그대로 사용한다. 개척자 장비를 위한 별도 제작 화면이나 별도 제작 API는 만들지 않는다.

공용 풀마다 같은 풀의 몬스터 세 종이 공유하는 무기 한 종을 둔다. 무기는 제작할 수 없고, 일반 던전 장비 드롭표에서도 제외하며 미개척지 공용 풀 보상에서만 직접 지급한다. 모두 고유 장비로 등록하되 고유 발동 효과는 두지 않는다.

무기는 희귀 보상으로 한 번만 분류한다. `희귀 제작` 노드의 추가 복사 확률은 적용하지만 `기본 보상`이나 풀별 `전리품 탐색`의 장비 배율을 중복 적용하지 않는다. 이는 한 드롭에 하나의 보상 분류만 적용한다는 기존 보상 계약을 유지한다. 별도 천장이나 조각 교환은 만들지 않으며 중복 획득은 허용한다.

## 개인 명성상점 확장

이 설계의 명성상점은 길드 공동 `fameAvailable`이 아니라 `character.v2.honor`를 소비하는 기존 개인 명성상점이다. 누적 명성 `honorEarned`와 길드 누적·사용 가능 명성은 차감하지 않는다.

기존 스태미나 회복약과 함께 길드 제작소 기본 재료 5종을 수량 제한 없이 판매한다. 상점은 현행과 같이 `V2_SETTLEMENT_WARFARE` 기능 플래그가 켜진 환경에서만 열린다.

| 품목 | 수량 | 명성 가격 |
| --- | ---: | ---: |
| 정제 철괴 | 1 | 10 |
| 미스릴 조각 | 1 | 20 |
| 태양석 | 1 | 40 |
| 오로라 결정 | 1 | 50 |
| 심해성철 | 1 | 70 |

몬스터 고유 재료, 협동 보스 재료, 폭풍 원정 재료와 미개척지 재료는 판매하지 않는다. 개인 명성은 수비 전투와 길드 골드 입금으로 제한되므로 별도 일일·주간 구매 한도를 추가하지 않는다. 상점 재료는 기존 `character.v2.materials`에 1개씩 지급하며 별도 귀속 재료 종류를 만들지 않는다.

## 서버 처리와 오류

### 길드 제작소

기존 `POST /api/v2/guild/workshop`의 잠금 순서와 원자적 제작 흐름을 유지한다. 대장장이 레벨, 제련소 레벨, 골드, 자원, 일반·특수 재료와 선택한 제작 기술을 모두 먼저 검증한다. 하나라도 부족하면 장비와 경험치를 지급하지 않고 어떤 비용도 차감하지 않는다. 성공 시 기존 제작 장비 개체 생성, 품질, 각인, 통계, 주간 진행도와 활동 로그를 같은 트랜잭션에서 처리한다.

### 미개척지 무기 드롭

기존 미개척지 사냥 보상 계획에 풀별 희귀 무기 굴림을 추가한다. 전투 승리와 실제 몬스터 풀을 서버에서 확인한 뒤 기존 장비 지급·도감 누적 경로를 사용한다. 일반·집중 경계는 각각 `rng < 0.001`, `rng < 0.002`로 고정한다. 보상 저장이 실패하면 전투 보상 전체가 롤백되는 기존 계약을 유지한다.

### 명성상점

상점 품목은 지급 종류와 대상 ID를 가진 데이터 카탈로그로 바꾼다. 구매 트랜잭션에서 `character.v2`를 잠그고 품목, 가격과 보유 명성을 다시 검증한 뒤 명성과 재료 잔액을 한 번에 저장한다. 스태미나 회복약은 기존 보조 저장 키를 함께 사용한다. 잘못된 품목은 `no_such_item`, 명성 부족은 `insufficient_honor`를 반환하며 어느 경우에도 일부 차감하지 않는다. 성공 응답은 품목명, 지급 종류, 지급 ID, 수량과 갱신된 잔액을 반환해 화면이 품목별 알림을 표시할 수 있게 한다.

## 화면과 정보 공개

- 길드 제작소의 기존 필터와 카드에 개척자 레시피 12종을 추가하고 `미개척지 · 개척자` 출처, 요구 대장장이 레벨, 제련소 레벨과 모든 재료를 표시한다.
- 집중형 카드에는 극희귀 재료가 들어가는 대체 선택지임을 표시하되 기본형보다 상위 등급인 것처럼 표기하지 않는다.
- 장비 상세와 비교 화면은 기존 세트 태그 표시를 사용해 개척자 2·3·5세트의 현재·다음 효과를 보여준다.
- 미개척지 공용 풀 상세에는 공유 재료 1%·집중 1.5%와 공유 무기 0.1%·집중 0.2%를 함께 표시한다.
- 명성상점은 스태미나 회복약과 재료를 같은 목록에서 보여주고, 구매 성공 알림에 실제 품목명과 지급 수량을 표시한다.
- 새 화면을 만들지 않으며 기존 불투명 카드와 표면 컴포넌트를 유지한다.

## 검증

- 장비 카탈로그에 제작 장비 12종과 드롭 무기 6종이 정확히 추가되고 모두 6T, 개척자 세트인지 검사한다.
- 기본형 6종만으로 무기를 제외한 5슬롯 세트가 완성되고, 무기를 포함한 5부위 혼합도 같은 효과를 받는지 검사한다.
- 세트 2·3·5 임계점과 누적 합계를 리터럴로 고정하고 6부위에 별도 보너스가 생기지 않는지 검사한다.
- 12개 레시피의 대장장이 Lv 13~18, 제련소 Lv 5, 제작 경험치, 공용 풀 재료 8개, 기본 재료 10개, 태양석·오로라 결정 각 4개와 집중형 희귀 재료를 검사한다.
- 일반 제작과 명장 제작의 자원·재료·골드 2배, 재료 부족 시 무변경, 성공 시 한 번만 차감과 지급이 일어나는지 검사한다.
- 여섯 풀의 일반·집중 무기 드롭 확률 경계, 다른 풀 무기 미지급, 희귀 추가 복사와 다른 보상 배율 미중복을 고정 난수로 검사한다.
- 명성상점이 다섯 가격과 한 개 지급을 정확히 노출하고, 성공·명성 부족·잘못된 품목·동시 구매에서 개인 명성과 재료가 원자적으로 유지되는지 검사한다.
- 길드 제작소와 명성상점 UI가 품목별 비용·결과를 표시하고 작은 화면에서 가로 넘침 없이 동작하는지 검사한다.
- 장비 비교 및 미개척지 대표 캐릭터 시뮬레이션에서 개척자 일반 품질 5세트가 일반 6T보다 강하고, 특화 6T의 유리한 전투와 미개척지 보스 희귀 고유를 일괄 지배하지 않는지 확인한다.
- 관련 집중 테스트, 타입 검사, 린트, 이미지 참조 검사와 프로덕션 빌드를 통과한다.

## 제외 사항

- 상위 특화 풀 6종의 추가 제작 장비와 대장장이 Lv 20 이상 레시피
- 새로운 개인 보스, 흔적, 소환석이나 보스 장비
- 공용 풀별 별도 희귀 제작 재료
- 제작 희귀 재료 선택 슬롯과 재료 교환 기능
- 무기 드롭 천장, 조각 교환과 중복 보호
- 개척자 세트 전용 발동 효과와 6부위 보너스
- 명성상점의 콘텐츠 전용 재료 판매, 구매 제한과 길드 공동 명성 소비
- 운영 기능 플래그 변경과 배포
