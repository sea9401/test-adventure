# 미개척지 정밀 사냥단 확장 설계

## 목표

정밀 사냥단의 기존 출시 몬스터 `정밀 척후병`에 `치명 저격수`와 `갑옷 사냥꾼`을 추가해 실제 미개척지 사냥에서 세 몬스터가 모두 출현하게 한다. 앞선 다섯 풀의 확장 상태는 유지하고, 폭주 기계 이후 6개 특수 풀은 출시 몬스터 한 종만 출현해야 한다.

## 선택한 접근

기존 풀별 `releaseStage`와 `activeMonsters` 구조를 재사용한다. 정밀 사냥단의 출시 단계만 `expanded`로 전환하고 조우, 런타임, 집중 효과, 풀 공통 보상 경로에는 새 분기를 추가하지 않는다.

전투는 이미 연결된 `accuracy`, `critPct`, `pierce`, `playerDefVulnerable` 필드를 그대로 사용한다. 조준 중첩이나 수동 타이밍 같은 새 전투 규칙은 추가하지 않는다. 모든 효과는 현재 자동 전투에서 일반 공격과 기존 관통 스킬에 자연스럽게 반영된다.

## 조우와 전투

정밀 사냥단 풀이 선택되면 `activeMonsters` 세 종에서 균등 선택한다. 각 몬스터의 출현 확률은 1/3이다.

| 몬스터 | 역할 | 핵심 수치 | 능력 |
| --- | --- | --- | --- |
| 정밀 척후병 | 기본형 | HP 0.95, 공격 1.05, 방어 0.90, 마방 0.90, 빠른 속도 | 공통 난이도 적중 기준보다 적중 +20 |
| 치명 저격수 | 공격형 | HP 0.80, 공격 1.20, 방어 0.75, 마방 0.80, 일반 속도 | 공통 난이도 적중 기준보다 적중 +30, 치명타 38% |
| 갑옷 사냥꾼 | 변칙형 | HP 1.00, 공격 1.10, 방어 1.00, 마방 0.90, 일반 속도 | 공통 난이도 적중 기준보다 적중 +30, 기존 관통 스킬의 고정 관통 11 |

정밀 사냥단 집중 노드는 세 몬스터 모두에게 적중 +15, 치명타 +8%p, 플레이어 방어 5% 비율 관통을 적용한다. 따라서 집중 상태의 치명 저격수는 기본 적중보다 총 +45, 치명타 46%, 방어 5% 관통을 갖는다. 집중 상태의 갑옷 사냥꾼은 기본 적중보다 총 +45, 치명타 8%, 방어 5% 비율 관통과 고정 관통 11을 함께 사용한다.

## 런타임과 안전장치

기존 몬스터 ID 기반 런타임 생성기를 그대로 사용한다. 정밀 사냥단이 확장되면 `lethal_sniper`와 `armor_hunter`가 활성 검증을 통과하며, 아직 출시되지 않은 폭주 기계 이후 후보는 계속 거부된다.

활성 특수 몬스터는 기존 22종에서 24종으로 늘어나고, 기본 몬스터 5종을 합친 전체 미개척지 런타임 카탈로그는 29종이 된다. 모든 정수 난이도 95~120에서 각 수치가 유한한 양수여야 한다.

## 이미지

기존 `정밀 척후병`과 같은 정사각형 투명 배경, 짙은 녹색 천과 어두운 가죽·금속, 황동 장식과 주황색 조준 렌즈의 사실적인 어두운 판타지 사냥꾼 렌더 스타일로 다음 파일을 추가한다.

- `public/images/monster/v2/unexplored-lethal-sniper.webp`
- `public/images/monster/v2/unexplored-armor-hunter.webp`

치명 저격수는 가벼운 장비와 길고 정교한 저격용 석궁, 크게 강조된 황색 조준경, 낮은 조준 자세로 치명타형 실루엣을 만든다. 갑옷 사냥꾼은 두꺼운 판금과 가죽 장비, 굵은 철갑 관통 볼트를 장전한 대형 공성 석궁을 든 넓고 단단한 체형으로 만든다. 두 이미지에는 텍스트, 로고, 워터마크, 배경 장면을 넣지 않는다.

이미지 생성 결과가 체크무늬를 실제 픽셀로 포함하지 않도록 WebP 변환 전 RGBA 알파 채널을 검사한다.

## 보상

세 몬스터 모두 풀 ID 기준의 기존 재료 `v2_unexplored_precision_hunters_material`을 같은 확률로 드롭한다. 집중 여부에 따른 기존 특수 재료 확률만 적용하며 개별 몬스터 보너스나 신규 보상은 추가하지 않는다.

## 테스트와 검증

- 풀 카탈로그: 앞의 여섯 풀만 `expanded`, 나머지 6개는 `launch`
- 조우: 정밀 사냥단 RNG 구간별 정밀 척후병·치명 저격수·갑옷 사냥꾼 선택
- 서버 사냥 준비: 선택된 두 확장 몬스터 ID 보존
- 런타임: 활성 특수 24종, 전체 29종
- 전투: 정밀 척후병 적중 +20, 치명 저격수 적중 +30·치명타 38%, 갑옷 사냥꾼 적중 +30·고정 관통 11
- 집중: 두 확장 몬스터의 적중 +15, 치명타 +8%p, 방어 5% 비율 관통
- 안전장치: 폭주 기계의 미출시 후보 거부
- 보상: 세 몬스터의 동일 정밀 조준경 규칙
- 자산: 두 WebP의 512×512 RGBA 알파와 참조 존재
- 관련 테스트, 전체 타입 검사, 변경 파일 린트, 전체 테스트, `V2_UNEXPLORED=true` production build
