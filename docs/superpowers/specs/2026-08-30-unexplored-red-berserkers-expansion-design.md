# 미개척지 붉은 광전대 확장 설계

## 목표

붉은 광전대의 기존 출시 몬스터 `붉은 광전병`에 `혈전 투사`와 `붉은 처형자`를 추가해 실제 미개척지 사냥에서 세 몬스터가 모두 출현하게 한다. 기존 광전병의 저체력 격노가 고난도 능력치에서도 실제 전투 효과를 내도록 보정한다. 앞선 세 풀의 확장 상태는 유지하고, 수정 포격대 이후 8개 특수 풀은 출시 몬스터 한 종만 출현해야 한다.

## 선택한 접근

기존 풀별 `releaseStage`와 `activeMonsters` 구조를 재사용한다. 붉은 광전대의 출시 단계만 `expanded`로 전환하고, 조우·런타임·집중 효과·풀 공통 보상 경로에는 새 분기를 추가하지 않는다.

기존 `enrage`, `critPct`, `heavy_blow` 엔진 필드를 그대로 사용한다. 다만 현재 저체력 격노의 공격력 증가량 `12`는 미개척지의 1만 이상 공격력 구간에서 무의미하다. 격노 생성 시 해당 몬스터의 런타임 공격력 20%를 반올림한 값을 `atkBonus`로 구워 넣는다. HP 40% 미만에서 한 번 발동해 전투 종료까지 유지되는 기존 행동 규칙은 바꾸지 않는다.

## 조우와 전투

붉은 광전대 풀이 선택되면 `activeMonsters` 세 종에서 균등 선택한다. 각 몬스터의 출현 확률은 1/3이다.

| 몬스터 | 역할 | 핵심 수치 | 능력 |
| --- | --- | --- | --- |
| 붉은 광전병 | 기본형 | HP 0.90, 공격 1.30, 방어 0.75, 마방 0.80, 일반 속도 | HP 40% 미만에서 공격력 20% 격노 |
| 혈전 투사 | 공격형 | HP 0.80, 공격 1.25, 방어 0.70, 마방 0.70, 빠른 속도 | 치명타 38% |
| 붉은 처형자 | 변칙형 | HP 1.05, 공격 1.40, 방어 0.80, 마방 0.80, 느린 속도 | 3번째 적 행동마다 피해 2배 강타 |

붉은 광전대 집중 노드는 세 몬스터 모두에게 다음 효과를 적용한다.

- 공격력 10% 증가
- 치명타 확률 10%p 증가, 최대 100%

따라서 집중 상태의 혈전 투사는 치명타 48%, 다른 두 몬스터는 치명타 10%가 된다. 격노의 고정 보너스는 집중 전 런타임 공격력에서 산출하며, 집중은 기본 공격력을 별도로 10% 높인다.

## 런타임과 안전장치

기존 몬스터 ID 기반 런타임 생성기를 그대로 사용한다. 붉은 광전대가 확장되면 `blood_duelist`와 `red_executioner`가 활성 검증을 통과하며, 아직 출시되지 않은 수정 포격대 이후 후보는 계속 거부된다.

활성 특수 몬스터는 기존 18종에서 20종으로 늘어나고, 기본 몬스터 5종을 합친 전체 미개척지 런타임 카탈로그는 25종이 된다. 모든 정수 난이도 95~120에서 각 수치가 유한한 양수여야 한다.

## 이미지

기존 `붉은 광전병`과 같은 정사각형 투명 배경, 검붉은 금속 갑주·핏빛 균열·헤진 붉은 천의 어두운 판타지 전사 렌더 스타일로 다음 파일을 추가한다.

- `public/images/monster/v2/unexplored-blood-duelist.webp`
- `public/images/monster/v2/unexplored-red-executioner.webp`

혈전 투사는 중갑을 줄인 날렵한 체형, 서로 다른 높이로 든 쌍검과 전진 자세로 빠른 치명타형 실루엣을 만든다. 붉은 처형자는 두꺼운 중갑과 거대한 양손 처형 도끼를 든 넓고 무거운 체형으로 느린 강타형 실루엣을 만든다. 두 이미지에는 텍스트, 로고, 워터마크, 배경 장면을 넣지 않는다.

이미지 생성 결과가 체크무늬를 실제 픽셀로 포함하지 않도록 WebP 변환 전 RGBA 알파 채널을 검사한다.

## 보상

세 몬스터 모두 풀 ID 기준의 기존 재료 `v2_unexplored_red_berserkers_material`을 같은 확률로 드롭한다. 집중 여부에 따른 기존 특수 재료 확률만 적용하며 개별 몬스터 보너스나 신규 보상은 추가하지 않는다.

## 테스트와 검증

- 풀 카탈로그: 앞의 네 풀만 `expanded`, 나머지 8개는 `launch`
- 조우: 붉은 광전대 RNG 구간별 붉은 광전병·혈전 투사·붉은 처형자 선택
- 서버 사냥 준비: 선택된 두 확장 몬스터 ID 보존
- 런타임: 활성 특수 20종, 전체 25종
- 전투: 붉은 광전병의 런타임 공격력 20% 격노, 혈전 투사의 치명타 38%, 붉은 처형자의 3행동 주기 2배 강타
- 집중: 두 확장 몬스터의 공격력 증가와 치명타 각각 48%·10%
- 안전장치: 수정 포격대의 미출시 후보 거부
- 보상: 세 몬스터의 동일 광폭 혈석 규칙
- 자산: 두 WebP의 512×512 RGBA 알파와 참조 존재
- 관련 테스트, 전체 타입 검사, 변경 파일 린트, 전체 테스트, `V2_UNEXPLORED=true` production build

## 제외 범위

- 새로운 전투 스킬 종류 또는 수동 행동
- 붉은 광전대 전용 UI
- 개별 몬스터 보상 차등
- 수정 포격대 이후 풀의 활성화
- 배포, 병합, 푸시, PR 생성
