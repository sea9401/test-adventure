# 미개척지 재생 군체 확장 설계

## 목표

재생 군체의 기존 출시 몬스터 `재생 포자체`에 `포식 재생체`와 `증식 핵체`를 추가해 실제 미개척지 사냥에서 세 몬스터가 모두 출현하게 한다. 철갑 군단과 마력 방벽체의 확장 상태는 유지하고, 붉은 광전대 이후 9개 특수 풀은 기존 출시 몬스터 한 종만 출현해야 한다.

## 선택한 접근

기존 풀별 `releaseStage`와 `activeMonsters` 구조를 재사용한다. 재생 군체의 출시 단계만 `expanded`로 전환하고, 조우·런타임·집중 효과·풀 공통 보상 경로에는 새 분기를 추가하지 않는다.

세 몬스터는 이미 시뮬레이션 카탈로그에 연결된 기존 `v2_skill_recover`를 사용한다. 별도의 재생 상태나 공격 후 즉시 회복 같은 새 전투 규칙은 만들지 않는다. 포식 재생체는 일반 공격 수치가 높은 회복 가능 공격형이며, 증식 핵체는 더 많은 MP로 회복을 오래 반복하는 체력형이다.

## 조우와 전투

재생 군체 풀이 선택되면 `activeMonsters` 세 종에서 균등 선택한다. 각 몬스터의 출현 확률은 1/3이다.

| 몬스터 | 역할 | 핵심 수치 | 능력 |
| --- | --- | --- | --- |
| 재생 포자체 | 기본형 | HP 1.45, 공격 0.85, 방어 0.90, 마방 0.90 | 회복, 최대 MP 16 |
| 포식 재생체 | 공격형 | HP 1.20, 공격 1.10, 방어 0.80, 마방 0.80 | 일반 공격과 회복, 최대 MP 16 |
| 증식 핵체 | 변칙형 | HP 1.70, 공격 0.90, 방어 0.95, 마방 0.95 | 회복 가능 횟수 증가, 최대 MP 32 |

세 몬스터의 회복은 기존 자동 전투 기술 선택과 MP 소모 규칙을 따른다. 포식 재생체에 공격과 회복을 결합한 새 단일 행동을 추가하지 않는다.

재생 군체 집중 노드는 세 몬스터 모두에게 다음 효과를 적용한다.

- 최대 체력 15% 증가
- 최대 MP 2배: 재생 포자체·포식 재생체 32, 증식 핵체 64

## 런타임과 안전장치

기존 몬스터 ID 기반 런타임 생성기를 그대로 사용한다. 재생 군체가 확장되면 `devouring_regenerator`와 `proliferating_core`가 활성 검증을 통과하며, 아직 출시되지 않은 붉은 광전대 이후 후보는 계속 거부된다.

활성 특수 몬스터는 기존 16종에서 18종으로 늘어나고, 기본 몬스터 5종을 합친 전체 미개척지 런타임 카탈로그는 23종이 된다. 모든 정수 난이도 95~120에서 각 수치가 유한한 양수여야 한다.

## 이미지

기존 `재생 포자체`와 같은 정사각형 투명 배경, 붉은 균모·썩은 목질 조직·녹색 재생액의 어두운 판타지 생물 렌더 스타일로 다음 파일을 추가한다.

- `public/images/monster/v2/unexplored-devouring-regenerator.webp`
- `public/images/monster/v2/unexplored-proliferating-core.webp`

포식 재생체는 네발 또는 앞으로 기운 날렵한 포식자 체형, 크게 벌어진 이빨 달린 입과 갈고리 발톱으로 공격형 실루엣을 만든다. 증식 핵체는 땅에 뿌리내린 육중한 중심핵, 여러 개의 포자 주머니와 싹트는 작은 균체로 느리고 끈질긴 실루엣을 만든다. 두 이미지에는 텍스트, 로고, 워터마크, 배경 장면을 넣지 않는다.

이미지 생성 결과가 체크무늬를 실제 픽셀로 포함하지 않도록 WebP 변환 전 RGBA 알파 채널을 검사한다.

## 보상

세 몬스터 모두 풀 ID 기준의 기존 재료 `v2_unexplored_regenerating_swarm_material`을 같은 확률로 드롭한다. 집중 여부에 따른 기존 특수 재료 확률만 적용하며 개별 몬스터 보너스나 신규 보상은 추가하지 않는다.

## 테스트와 검증

- 풀 카탈로그: 철갑 군단·마력 방벽체·재생 군체만 `expanded`, 나머지 9개는 `launch`
- 조우: 재생 군체 RNG 구간별 재생 포자체·포식 재생체·증식 핵체 선택
- 서버 사냥 준비: 선택된 두 확장 몬스터 ID 보존
- 런타임: 활성 특수 18종, 전체 23종
- 전투: 세 몬스터의 회복 스킬과 기본/추가 회복 MP 차이
- 집중: 포식 재생체와 증식 핵체의 체력 증가 및 최대 MP 2배
- 안전장치: 붉은 광전대의 미출시 후보 거부
- 보상: 세 몬스터의 동일 재생 조직 규칙
- 자산: 두 WebP의 512×512 RGBA 알파와 참조 존재
- 관련 테스트, 전체 타입 검사, 변경 파일 린트, 전체 테스트, `V2_UNEXPLORED=true` production build

## 제외 범위

- 새로운 전투 기술, 재생 상태 또는 행동 규칙
- 재생 군체 전용 UI
- 개별 몬스터 보상 차등
- 붉은 광전대 이후 풀의 활성화
- 배포, 병합, 푸시, PR 생성
