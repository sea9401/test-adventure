# 미개척지 폭주 기계 확장 설계

## 목표

폭주 기계의 기존 출시 몬스터 `질주 기계`에 `연격 자동인형`과 `과열 집행기`를 추가해 실제 미개척지 사냥에서 세 몬스터가 모두 출현하게 한다. 앞선 여섯 풀의 확장 상태는 유지하고, 그림자 추적자 이후 다섯 특수 풀은 출시 몬스터 한 종만 출현해야 한다.

## 선택한 접근

기존 풀별 `releaseStage`와 `activeMonsters` 구조를 재사용한다. 폭주 기계의 출시 단계만 `expanded`로 전환하고 조우, 런타임, 집중 효과, 풀 공통 보상 경로에는 새 분기를 추가하지 않는다.

전투는 이미 연결된 일반 속도 경로, `bonusAttackChancePct`, 저체력 `enrage`를 그대로 사용한다. 별도의 연격 중첩이나 수동 행동은 추가하지 않는다. 속도만 높이는 접근은 세 몬스터의 차이를 약하게 만들고, 새 연격 자원 시스템은 현재 자동 전투 범위를 불필요하게 넓히므로 채택하지 않는다.

## 조우와 전투

폭주 기계 풀이 선택되면 `activeMonsters` 세 종에서 균등 선택한다. 각 몬스터의 출현 확률은 1/3이다.

| 몬스터 | 역할 | 핵심 수치 | 능력 |
| --- | --- | --- | --- |
| 질주 기계 | 기본형 | HP 0.90, 공격 0.90, 방어 1.00, 마방 0.85, 극고속 | 추가 공격 없이 가장 빠른 행동 주기 |
| 연격 자동인형 | 공격형 | HP 0.80, 공격 0.75, 방어 0.90, 마방 0.85, 빠른 속도 | 행동마다 추가 공격 확률 50% |
| 과열 집행기 | 변칙형 | HP 0.95, 공격 0.90, 방어 1.00, 마방 0.90, 빠른 속도 | 추가 공격 확률 50%, 체력 40% 이하에서 공격력 20% 상당의 고정 공격 보너스 |

높은 행동 빈도와 추가 공격을 고려해 연격 자동인형의 1회 공격력은 가장 낮게 유지한다. 과열 집행기는 생존력이 조금 더 높고 저체력 구간에서 공격 압박이 커지며, 질주 기계는 추가 공격 대신 극고속 자체가 정체성이다.

폭주 기계 집중 노드는 세 몬스터 모두에게 원래 속도의 10%를 반올림해 더하고 추가 공격 확률 +15%p를 적용한다. 따라서 집중 상태의 질주 기계는 추가 공격 확률 15%, 연격 자동인형과 과열 집행기는 65%가 된다. 과열 집행기의 저체력 격노는 집중 여부와 관계없이 유지한다.

## 런타임과 안전장치

기존 몬스터 ID 기반 런타임 생성기를 그대로 사용한다. 폭주 기계가 확장되면 `combo_automaton`과 `overheated_enforcer`가 활성 검증을 통과하며, 아직 출시되지 않은 그림자 추적자 이후 후보는 계속 거부된다.

활성 특수 몬스터는 기존 24종에서 26종으로 늘어나고, 기본 몬스터 5종을 합친 전체 미개척지 런타임 카탈로그는 31종이 된다. 모든 정수 난이도 95~120에서 각 수치가 유한한 양수여야 한다.

## 이미지

기존 `질주 기계`와 같은 정사각형 투명 배경, 검게 그을린 다층 금속 장갑, 주황색 용융 동력선과 분사 화염을 사용하는 사실적인 어두운 판타지 기계 렌더 스타일로 다음 파일을 추가한다.

- `public/images/monster/v2/unexplored-combo-automaton.webp`
- `public/images/monster/v2/unexplored-overheated-enforcer.webp`

연격 자동인형은 가볍고 민첩한 인간형 자동인형으로 만들고, 여러 개의 짧은 칼날 팔 또는 연속 타격용 쌍날 구조로 빠른 연격 실루엣을 강조한다. 과열 집행기는 넓고 무거운 인간형 집행 기계로 만들며, 균열 난 장갑 사이의 밝은 용융 노심과 크고 무거운 처형용 무기로 저체력 과열 격노를 표현한다. 기존 질주 기계의 네발 짐승형 실루엣과 두 신규 몬스터의 실루엣이 명확히 달라야 한다. 이미지에는 텍스트, 로고, 워터마크, 배경 장면을 넣지 않는다.

이미지 생성 결과가 체크무늬를 실제 픽셀로 포함하지 않도록 WebP 변환 전 RGBA 알파 채널을 검사한다.

## 보상

세 몬스터 모두 풀 ID 기준의 기존 재료 `v2_unexplored_runaway_machines_material`을 같은 확률로 드롭한다. 집중 여부에 따른 기존 특수 재료 확률만 적용하며 개별 몬스터 보너스나 신규 보상은 추가하지 않는다.

## 테스트와 검증

- 풀 카탈로그: 앞의 일곱 풀만 `expanded`, 나머지 5개는 `launch`
- 조우: 폭주 기계 RNG 구간별 질주 기계·연격 자동인형·과열 집행기 선택
- 서버 사냥 준비: 선택된 두 확장 몬스터 ID 보존
- 런타임: 활성 특수 26종, 전체 31종
- 전투: 질주 기계 극고속, 연격 자동인형 추가 공격 50%, 과열 집행기 추가 공격 50%·저체력 격노
- 집중: 두 확장 몬스터의 속도 10% 증가, 추가 공격 확률 65%, 과열 집행기의 격노 유지
- 안전장치: 그림자 추적자의 미출시 후보 거부
- 보상: 세 몬스터의 동일 과열 동력핵 규칙
- 자산: 두 WebP의 512×512 RGBA 알파와 참조 존재
- 관련 테스트, 전체 타입 검사, 변경 파일 린트, 전체 테스트, `V2_UNEXPLORED=true` production build

## 제외 범위

- 새 연격 중첩, 에너지 또는 수동 행동
- 새로운 전투 스킬 종류
- 폭주 기계 전용 UI
- 개별 몬스터 보상 차등
- 그림자 추적자 이후 풀의 활성화
- 배포, 병합, 푸시, PR 생성
