# 미개척지 그림자 추적자 확장 설계

## 목표

그림자 추적자의 기존 출시 몬스터 `그림자 척후병`에 `밤의 암살자`와 `허상 추적귀`를 추가해 실제 미개척지 사냥에서 세 몬스터가 모두 출현하게 한다. 앞선 일곱 풀의 확장 상태는 유지하고, 맹독 군락 이후 네 특수 풀은 출시 몬스터 한 종만 출현해야 한다.

## 선택한 접근

기존 풀별 `releaseStage`와 `activeMonsters` 구조를 재사용한다. 그림자 추적자의 출시 단계만 `expanded`로 전환하고 조우, 런타임, 집중 효과, 풀 공통 보상 경로에는 새 분기를 추가하지 않는다.

전투는 이미 연결된 일반 속도 경로, `evasionPct`, `critPct`, 기존 관통 스킬을 그대로 사용한다. 별도의 은신 턴, 피격 무효 중첩 또는 수동 행동은 추가하지 않는다. 회피만 높이는 단일 역할 설계는 세 몬스터의 차이를 약하게 만들고, 새 은신 상태는 현재 자동 전투의 복잡도를 불필요하게 높이므로 채택하지 않는다.

## 조우와 전투

그림자 추적자 풀이 선택되면 `activeMonsters` 세 종에서 균등 선택한다. 각 몬스터의 출현 확률은 1/3이다.

| 몬스터 | 역할 | 핵심 수치 | 능력 |
| --- | --- | --- | --- |
| 그림자 척후병 | 기본형 | HP 0.85, 공격 1.00, 방어 0.80, 마방 0.90, 빠른 속도 | 회피 35% |
| 밤의 암살자 | 공격형 | HP 0.75, 공격 1.20, 방어 0.65, 마방 0.80, 빠른 속도 | 회피 45%, 치명타 38% |
| 허상 추적귀 | 변칙형 | HP 0.70, 공격 1.05, 방어 0.70, 마방 0.90, 극고속 | 회피 50%, 기존 관통 스킬의 고정 관통 11 |

밤의 암살자는 가장 높은 1회 공격력과 치명타 대신 체력과 방어가 가장 낮다. 허상 추적귀는 극고속·최고 회피·관통을 함께 가지지만 공격력은 밤의 암살자보다 낮게 유지한다. 그림자 척후병은 세 역할 가운데 생존과 공격의 기준점이다.

그림자 추적자 집중 노드는 세 몬스터 모두에게 원래 속도의 10%를 반올림해 더하고 회피 +10%p를 적용한다. 따라서 집중 상태의 그림자 척후병은 회피 45%, 밤의 암살자는 55%, 허상 추적귀는 60%가 된다. 밤의 암살자의 치명타 38%와 허상 추적귀의 고정 관통 11은 집중 후에도 그대로 유지한다.

## 런타임과 안전장치

기존 몬스터 ID 기반 런타임 생성기를 그대로 사용한다. 그림자 추적자가 확장되면 `night_assassin`과 `phantom_stalker`가 활성 검증을 통과하며, 아직 출시되지 않은 맹독 군락 이후 후보는 계속 거부된다.

활성 특수 몬스터는 기존 26종에서 28종으로 늘어나고, 기본 몬스터 5종을 합친 전체 미개척지 런타임 카탈로그는 33종이 된다. 모든 정수 난이도 95~120에서 각 수치가 유한한 양수여야 한다.

## 이미지

기존 `그림자 척후병`과 같은 정사각형 투명 배경, 검은 가죽과 흑철 장비, 해진 짙은 보라색 천, 보랏빛 눈과 에너지, 연기처럼 흩어지는 그림자 잔상의 사실적인 어두운 판타지 렌더 스타일로 다음 파일을 추가한다.

- `public/images/monster/v2/unexplored-night-assassin.webp`
- `public/images/monster/v2/unexplored-phantom-stalker.webp`

밤의 암살자는 가벼운 검은 암살자 장비와 길고 가는 보랏빛 쌍단검, 낮고 공격적인 인간형 자세로 치명타 공격형 실루엣을 만든다. 허상 추적귀는 다리가 땅에 닿지 않는 비인간형 망령으로 만들고, 길게 뻗은 관통용 팔날 또는 창날과 여러 갈래 그림자 잔상으로 극고속 관통형을 표현한다. 기존 그림자 척후병과 두 신규 몬스터의 자세와 실루엣이 명확히 달라야 한다. 이미지에는 텍스트, 로고, 워터마크, 배경 장면을 넣지 않는다.

이미지 생성 결과가 체크무늬를 실제 픽셀로 포함하지 않도록 WebP 변환 전 RGBA 알파 채널을 검사한다.

## 보상

세 몬스터 모두 풀 ID 기준의 기존 재료 `v2_unexplored_shadow_stalkers_material`을 같은 확률로 드롭한다. 집중 여부에 따른 기존 특수 재료 확률만 적용하며 개별 몬스터 보너스나 신규 보상은 추가하지 않는다.

## 테스트와 검증

- 풀 카탈로그: 앞의 여덟 풀만 `expanded`, 나머지 4개는 `launch`
- 조우: 그림자 추적자 RNG 구간별 그림자 척후병·밤의 암살자·허상 추적귀 선택
- 서버 사냥 준비: 선택된 두 확장 몬스터 ID 보존
- 런타임: 활성 특수 28종, 전체 33종
- 전투: 그림자 척후병 회피 35%, 밤의 암살자 회피 45%·치명타 38%, 허상 추적귀 회피 50%·고정 관통 11
- 집중: 두 확장 몬스터의 속도 10% 증가와 회피 +10%p, 치명타·고정 관통 유지
- 안전장치: 맹독 군락의 미출시 후보 거부
- 보상: 세 몬스터의 동일 그림자 피막 규칙
- 자산: 두 WebP의 512×512 RGBA 알파와 참조 존재
- 관련 테스트, 전체 타입 검사, 변경 파일 린트, 전체 테스트, `V2_UNEXPLORED=true` production build

## 제외 범위

- 새 은신 턴, 피격 무효 중첩 또는 수동 행동
- 새로운 전투 스킬 종류
- 그림자 추적자 전용 UI
- 개별 몬스터 보상 차등
- 맹독 군락 이후 풀의 활성화
- 배포, 병합, 푸시, PR 생성
