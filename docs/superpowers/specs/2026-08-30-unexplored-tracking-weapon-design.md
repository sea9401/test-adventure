# 미개척지 개인 보스 · 추적 병기 전투 설계

## 목적

추적 병기를 미개척지 개인 보스 3종 가운데 **공격형 캐릭터를 압박하는 보스**로 완성한다. 전투는 기존 협동 보스용 ATB 자동 전투를 그대로 사용한다. 플레이어가 전투 중 버튼을 눌러 패턴에 대응하게 만들지 않고, 높은 화력을 유지하려면 체력·방어·피해 감소·보호막·흡혈 같은 생존 수단도 함께 준비하게 한다.

이 문서는 추적 병기 한 종의 전투 메커니즘만 다룬다. 독혈 군주와 빙하 거수는 각자 별도 설계와 구현 주기를 갖는다.

## 확정된 역할과 제외 사항

- 추적 병기는 플레이어가 가한 피해량과 직접 타격 횟수를 함께 추적한다.
- 추적이 완료되면 플레이어 행동 직후 2연타 물리 반격 `추적 섬멸`을 사용한다.
- 추적 상태는 한 번의 공격 시도가 끝나거나 캐릭터가 사망해도 같은 개인 보스 세션에 유지된다.
- 별도의 HP 구간 페이즈나 보편적인 저체력 격노는 두지 않는다. 전투 처음부터 끝까지 추적 게이지만으로 압박한다.
- 명중 실패를 전제로 하지 않는다. 현재 PvE의 일반 회피는 공격을 빗나가게 하지 않고 직접 피해를 연속적으로 줄이는 구조이므로, `회피 발생 시 게이지 증가` 같은 규칙은 사용하지 않는다.
- 추적 섬멸은 최대 HP 비례 피해, 방어 무시 피해, 처형 피해가 아니다.

## 추적 게이지

### 기본 규칙

- 게이지 범위는 `0~100`이다.
- 세션 생성 시 0으로 시작한다.
- 플레이어가 발생시킨 모든 실제 피해는 피해량 비례 게이지를 만든다.
- 플레이어의 직접 공격은 실제 피해량에 더해 직접 타격 횟수만큼 추가 게이지를 만든다.
- 독·출혈 등의 지속 피해, 반사 피해와 반격 피해는 피해량 비례분에는 포함하지만 직접 타격 횟수 보너스에는 포함하지 않는다.
- 회복, 강화, 약화만 수행하고 피해를 주지 않은 행동은 게이지를 만들지 않는다.
- 보스 최대 HP를 분모로 사용하므로 공유 HP나 밸런스 수치가 변해도 피해량 비례분의 의미가 유지된다.

출시 시작식은 다음과 같다.

```text
피해 게이지 = floor(플레이어 귀속 실제 피해 × 500 / 보스 최대 HP)
타격 게이지 = 직접 타격 횟수 × 4
획득 게이지 = 피해 게이지 + 타격 게이지
```

보스 최대 HP의 1%에 해당하는 피해는 5게이지를 만들며, 직접 1타는 피해량과 별도로 4게이지를 만든다. 수치 조정이 필요할 때는 `500`과 `4`만 캘리브레이션 다이얼로 사용하고 규칙 자체는 바꾸지 않는다.

### 행동 경계와 초과분

`플레이어 행동`은 같은 ATB 시점에 실행되는 스킬 또는 기본 공격과 그 행동이 직접 만든 후속타 전체를 포함하는 한 묶음이다. 직접 피해와 타격 횟수는 묶음이 끝난 뒤 한 번 합산한다.

- 합산 결과가 100 미만이면 그대로 저장한다.
- 합산 결과가 100 이상이고 보스가 살아 있으면 추적 섬멸을 한 번 발동한다.
- 반격 후 `합산 결과 - 100`을 다음 게이지로 삼되 최대 99로 제한한다.
- 따라서 한 행동에서 반격은 최대 한 번만 일어나며, 큰 초과분은 다음 반격 하나를 즉시 앞당길 수 있지만 여러 번의 숨은 반격 빚으로 쌓이지 않는다.
- 적 행동 시점에 발생한 지속 피해·반사·플레이어 반격 피해는 게이지에 즉시 더하되 100에서 멈춘다. 이미 준비된 추적 섬멸은 다음 플레이어 행동이 끝난 뒤 발동한다.
- 플레이어 귀속 피해가 보스를 처치했다면 죽은 보스는 반격하지 않는다.

피해량은 문자열 전투 로그를 정규식으로 읽어 계산하지 않는다. 전투 상태의 실제 HP 차감량을 사용한다. 직접 타격 횟수는 공격 로그에 선택적 정형 메타데이터를 추가해 전달하며, 기존 로그에는 기본값 1을 적용한다. 적 행동 중 보스 HP가 감소한 양은 이 보스가 자가 피해나 회복을 사용하지 않는다는 전제 아래 지속 피해·반사·플레이어 반격 피해로 귀속한다.

## 추적 섬멸

추적 섬멸은 플레이어 행동 묶음이 완전히 끝난 직후, 다음 ATB 행동을 예약하기 전에 실행한다.

- 이름: `추적 섬멸`
- 횟수: 2타
- 속성: 물리 직접 피해
- 출시 확정 계수: 각 타격이 현재 스케일된 보스 기본 물리 공격의 2.0배
- 치명타: 발생하지 않음
- 상태이상: 부여하지 않음
- 방어 관통: 추적 병기의 일반 기술 `궤도 절단` 관통을 상속하지 않음
- 방어 판정: 플레이어 방어력, PvE 회피 기반 피해 경감, 일반 피해 감소, 활성 피해 감소, 보호막과 마법 방벽을 기존 순서대로 적용
- 생존 판정: 기존 불굴·사망 방지 효과를 정상 적용
- 첫 타격으로 플레이어가 쓰러지면 두 번째 타격은 실행하지 않음
- 플레이어의 피격 반사·반격 효과는 정상 발동하며, 그 피해는 다음 추적 게이지의 피해량 비례분에 포함
- 추적 섬멸 자체는 보스 일반 행동 횟수, 다음 행동 시각, 추가 공격 확률을 소비하거나 증가시키지 않음

반격이 실행되는 순간 100게이지를 먼저 소비한다. 반격으로 캐릭터가 사망해도 소비 후 남은 게이지가 세션에 저장된다. 마지막 일격이나 반사로 보스가 먼저 죽으면 남은 타격은 중단하고 세션 종료 규칙에 따라 게이지를 0으로 정리한다.

## 일반 공격 프로필

추적 섬멸이 핵심 위협이 되도록 현재 추적 병기의 무작위 연타 압박을 줄인다.

- `spd: 27`과 `atk: 2.2`는 유지한다.
- `bonusAttackChancePct: 100`은 제거한다.
- `evasionPct`는 22에서 12로 낮춘다.
- `궤도 절단`의 `armorPierce`는 18에서 10으로 낮춘다.
- HP 구간 `enrageStages`는 계속 비워 둔다.
- 표시 특성은 `빠른 행동`, `피해·타격 추적`, `추적 완료 시 2연타 반격`으로 교체한다.

일반 공격은 빠르지만 중간 수준의 압박만 주고, 플레이어가 예측하기 어려운 확정 추가 공격은 사용하지 않는다.

## 저장과 동시성

기존 `coop_boss_sessions.mechanic_state` JSON에 `trackingThreat` 정수를 추가한다.

- 파서는 유한한 정수만 허용하고 `0~100`으로 제한한다.
- 기존 `bossMp`와 서로 덮어쓰지 않도록 파싱·병합 헬퍼를 사용한다.
- 공격 시뮬레이션 시작값은 세션에 저장된 게이지다.
- 시뮬레이션이 반환한 최종 게이지는 세션 행 잠금과 공격 쿨다운 재검증을 통과한 트랜잭션에서 HP와 함께 저장한다.
- 개인 보스는 소환자 한 명만 공격할 수 있고, 기존 기여자 쿨다운과 `FOR UPDATE` 잠금이 동시 중복 요청의 두 번째 요청을 거부한다. 별도의 분산 잠금은 추가하지 않는다.
- 캐릭터 사망, 공격 타임아웃과 일반적인 공격 종료에서는 게이지를 유지한다.
- 보스 처치, 소환 만료 또는 새로운 세션 생성 시 게이지는 0이 된다.

공격 요청이 권한, 스태미나, 쿨다운이나 세션 상태 검증에서 거부되면 게이지도 바뀌지 않는다.

## 전투 엔진 경계

추적 로직을 `trackingWeaponMechanic` 모듈로 분리한다. 이 모듈은 게이지 계산, 100 도달 판정, 초과분 처리와 반격 결과를 담당하며 미개척지 라우트나 데이터베이스를 알지 않는다.

ATB 전투 엔진은 선택적인 보스 메커니즘 설정과 시작 게이지만 받는다. 설정이 없으면 현재 전투 결과와 로그가 변하지 않는다. 전투 상태에는 현재 게이지, 이번 전투 반격 발동 횟수와 반격 총피해만 보관한다. API 라우트는 세션 상태를 엔진 입력으로 변환하고 엔진 결과를 다시 세션에 저장하는 역할만 맡는다.

반격은 전투가 끝난 뒤 로그를 역산해 피해를 추가하지 않는다. 플레이어 행동 종료 지점에서 기존 물리 피해 경감과 생존 헬퍼를 사용해 즉시 처리한다. 그래야 보호막, 흡혈, 사망 방지, 반사, 승패와 리플레이 HP 순서가 실제 판정과 일치한다.

## API와 화면 표시

보스 목록·상세 응답에는 다음 값을 추가한다.

- `trackingThreat`: 현재 게이지
- `trackingThreatMax`: 100
- `trackingReady`: 현재 게이지가 100인지 여부

공격 결과에는 위 세 값과 함께 이번 공격의 `trackingCounterCount`, `trackingCounterDamage`를 반환한다. 다른 보스는 게이지 최댓값을 0으로 내려 기존 MP 표시와 충돌하지 않게 한다.

### 보스 화면

- 추적 병기 목록 카드와 상세 화면에 `추적 게이지 X / 100` 막대를 표시한다.
- 0~69는 기본 강조색, 70~99는 경고색과 `추적 섬멸 임박`, 100은 위험색과 `추적 완료`를 표시한다.
- 전투 진입 전에 현재 저장값을 볼 수 있어야 한다.
- 기존 불투명 카드 안에 막대를 배치하며 새 표면이 필요하면 `SURFACE_CARD`, `SURFACE_INSET`, `SURFACE_ACCENT`만 사용한다.

### 전투 기록

- 플레이어 행동이 끝날 때 `추적 +N · 현재 X/100`을 한 줄로 기록한다. 획득량이 0이면 생략한다.
- 70 이상이 된 첫 시점에는 `추적 섬멸 임박`을 강조한다.
- 발동 시 `추적 완료 — 추적 섬멸 발동`을 기록한다.
- 두 타격은 각각의 실제 피해를 기록하고, 마지막에 총피해를 표시한다.
- 반격 뒤 초과분이 남으면 `잔여 추적 X/100`을 기록한다.
- 전투 종료 결과에는 다음 공격으로 유지되는 게이지를 표시한다.
- 전투 HP 스냅샷의 적 자원에도 추적 게이지를 넣어 리플레이 진행 중 변화를 확인할 수 있게 한다.

## 밸런스 검증 기준

정해진 공식의 구조는 유지하고 피해 게이지 계수, 타격당 게이지와 반격 타격 계수만 조정할 수 있다. 대표 저장 캐릭터를 익명화한 읽기 전용 표본 또는 저장된 고정 픽스처로 결정론적 시뮬레이션을 수행한다.

- 순수 공격형: 추적 섬멸 총피해가 최대 HP의 약 55~70%
- 균형형: 약 35~50%
- 방어형: 약 20~30%
- 같은 총피해를 주더라도 다단 공격형은 단타형보다 게이지가 빠르게 차야 한다.
- 같은 타격 수라면 더 큰 피해를 준 빌드가 더 빠르게 차야 한다.
- 일반적인 상위 공격 시도에서 추적 섬멸이 전혀 보이지 않거나 매 행동마다 반복되지 않아야 한다.
- 생존력을 보완한 공격형은 화력이 완전히 무효화되지 않은 채 여러 번의 반격을 견딜 수 있어야 한다.

표본의 기존 장비나 저장 데이터는 변경하지 않는다. 캘리브레이션에 사용한 명령, 고정 시드, 빌드 분류와 결과 범위는 구현 기록에 남긴다.

### 출시 캘리브레이션 기록 · 2026-08-30

- 명령: `npm run sim:coop-boss -- --trials=50 --seed=20260830 --boss=tracking_weapon --json`
- 확정 상수: 피해 게이지 계수 `500`, 직접 타격당 게이지 `4`, 추적 섬멸 각 타격 계수 `2.0`
- 표본 하나는 게이지가 사망 뒤 유지되는 실제 규칙을 반영해 같은 빌드의 연속 공격 30회로 구성했다.
- 표본은 로컬 결정론적 종반 성장 픽스처이며 운영 DB를 읽거나 쓰지 않았다.

| 빌드 | 중앙 반격 횟수/30회 | 중앙 반격 1회 실제 피해/최대 HP |
| --- | ---: | ---: |
| STR | 4 | 41.9% |
| DEX | 27 | 19.3% |
| INT | 4 | 61.8% |
| LUK | 18 | 64.4% |
| BAL | 14 | 19.2% |
| VIT | 5 | 22.1% |

DEX·BAL은 반격 빈도가 높고 이미 일반 공격으로 HP를 잃은 시점에 자주 발동해 실제 HP 차감 비율이 낮게 집계됐다. 반대로 INT·LUK은 발동 횟수는 더 적지만 한 번의 반격 피해가 크다. 이 결과는 추적 병기가 공격형을 압박하되 VIT 방어형은 반격 피해를 약 22%로 낮추는 방향과 일치한다. 1.0 계수에서는 대부분의 빌드에서 반격 피해가 지나치게 낮아 2.0으로 올렸고, 누적 빈도 상수 `500`과 `4`는 유지했다.

## 회귀 테스트

- 순수 게이지 함수: 피해량 비례, 타격당 가산, 100 경계, 초과분 최대 99, 적 행동 중 100 정지
- 전투 엔진: 단타 고피해와 다단 저피해가 모두 게이지를 증가시키고 한 행동에는 반격이 한 번만 발생
- 피해 출처: 직접 피해, 지속 피해, 반사와 플레이어 반격은 포함하고 회복·강화는 제외
- 반격 순서: 행동 후 발동, 2타, 첫 타 사망 시 중단, 방어·피해 감소·보호막·생존 효과 적용, 보스 처치 시 미발동
- 저장: 승리하지 못한 공격과 플레이어 사망 후에도 잔여 게이지 유지, 처치 시 초기화, 잘못된 JSON 값 보정
- API: 목록·상세·공격 응답의 게이지 값과 공격 트랜잭션 저장, 거부된 요청의 무변경
- UI: 70·100 경고 상태, 개인 보스 외 화면에서 게이지 미표시, 라이트·다크 모드의 불투명 표면 클래스
- 격리: 추적 설정이 없는 일반 사냥, 협동 보스, 독혈 군주와 빙하 거수의 전투 결과가 변하지 않음

## 완료 기준과 범위 밖

구현은 회귀 테스트, 타입 검사와 대표 시뮬레이션을 통과하고 목록·상세·리플레이에서 지속 게이지와 반격을 확인할 수 있을 때 완료한다. 운영 배포는 이 작업 범위가 아니다.

독혈 군주의 탱커 카운터 패턴, 빙하 거수의 극단적 속도 저하 패턴, 보상·소환 비용 변경과 새 이미지 제작은 포함하지 않는다.
