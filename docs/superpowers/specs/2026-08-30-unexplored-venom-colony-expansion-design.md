# 미개척지 맹독 군락 확장 설계

## 목표

맹독 군락의 기존 출시 몬스터 `독니 포식자`에 `맹독 살포체`와 `부식 군체`를 추가해 실제 미개척지 사냥에서 세 몬스터가 모두 출현하게 한다. 앞선 여덟 풀의 확장 상태는 유지하고, 혈흔 망자 이후 세 특수 풀은 출시 몬스터 한 종만 출현해야 한다.

## 선택한 접근

기존 풀별 `releaseStage`와 `activeMonsters` 구조를 재사용한다. 맹독 군락의 출시 단계만 `expanded`로 전환하고 조우, 런타임, 집중 효과, 풀 공통 보상 경로에는 새 분기를 추가하지 않는다.

전투는 이미 연결된 자동 전투용 중독 스킬 세 종류를 그대로 사용한다. 별도 독성 게이지, 행동 선택 또는 새로운 중독 상태는 추가하지 않는다. 기존 스킬은 같은 3행동 쿨다운 안에서 1중첩, 2중첩, 2중첩과 생명력 약화를 구분하므로 세 몬스터의 역할을 표현하기에 충분하다.

## 조우와 전투

맹독 군락 풀이 선택되면 `activeMonsters` 세 종에서 균등 선택한다. 각 몬스터의 출현 확률은 1/3이다.

| 몬스터 | 역할 | 핵심 수치 | 능력 |
| --- | --- | --- | --- |
| 독니 포식자 | 기본형 | HP 1.00, 공격 0.90, 방어 0.95, 마방 0.95, 일반 속도 | `독니`: 중독 1중첩 |
| 맹독 살포체 | 공격형 | HP 0.85, 공격 1.05, 방어 0.80, 마방 0.90, 빠른 속도 | `재앙독`: 중독 2중첩 |
| 부식 군체 | 변칙형 | HP 1.15, 공격 0.90, 방어 1.05, 마방 1.00, 느린 속도 | `맹독 파쇄`: 중독 2중첩과 2턴간 생명력 12% 감소 |

맹독 살포체는 낮은 체력과 방어 대신 가장 빠른 속도와 높은 공격력으로 중독을 빠르게 누적한다. 부식 군체는 느리지만 가장 높은 체력과 방어를 가지며 생명력 약화로 장기전 생존을 압박한다. 독니 포식자는 세 역할의 생존과 중독 압박 기준점이다.

맹독 군락 집중 노드는 장착 스킬 중 `독니`만 `재앙독`으로 교체한다. 따라서 집중 상태의 독니 포식자는 중독이 1중첩에서 2중첩으로 강화되고, 이미 `재앙독`을 쓰는 맹독 살포체와 `맹독 파쇄`를 쓰는 부식 군체는 원래 스킬을 유지한다. 집중이 고급 스킬을 약한 스킬로 덮어쓰거나 생명력 약화 효과를 제거해서는 안 된다.

## 런타임과 안전장치

기존 몬스터 ID 기반 런타임 생성기를 그대로 사용한다. 맹독 군락이 확장되면 `venom_sprayer`와 `corrosive_colony`가 활성 검증을 통과하며, 아직 출시되지 않은 혈흔 망자 이후 후보는 계속 거부된다.

활성 특수 몬스터는 기존 28종에서 30종으로 늘어나고, 기본 몬스터 5종을 합친 전체 미개척지 런타임 카탈로그는 35종이 된다. 모든 정수 난이도 95~120에서 각 수치가 유한한 양수여야 한다.

## 이미지

기존 `독니 포식자`와 같은 정사각형 투명 배경, 어두운 올리브색과 검은 외피, 황록색 독낭과 형광 녹색 독액, 사실적인 어두운 판타지 렌더 스타일로 다음 파일을 추가한다.

- `public/images/monster/v2/unexplored-venom-sprayer.webp`
- `public/images/monster/v2/unexplored-corrosive-colony.webp`

맹독 살포체는 부풀어 오른 여러 독낭과 독을 뿜는 관 또는 주둥이를 가진 날렵한 슬라임 생물로 만들어 빠른 광역 살포형 실루엣을 만든다. 부식 군체는 여러 개체가 융합된 넓고 무거운 슬라임 덩어리, 단단하게 굳은 부식성 갑각, 다수의 독낭과 흘러내리는 산성 독액으로 느린 생존 약화형을 표현한다. 독니 포식자와 두 신규 몬스터의 종, 자세, 실루엣이 명확히 달라야 한다. 이미지에는 텍스트, 로고, 워터마크, 배경 장면을 넣지 않는다.

이미지 생성 결과가 체크무늬를 실제 픽셀로 포함하지 않도록 WebP 변환 전 RGBA 알파 채널을 검사한다.

## 보상

세 몬스터 모두 풀 ID 기준의 기존 재료 `v2_unexplored_venom_colony_material`을 같은 확률로 드롭한다. 집중 여부에 따른 기존 특수 재료 확률만 적용하며 개별 몬스터 보너스나 신규 보상은 추가하지 않는다.

## 테스트와 검증

- 풀 카탈로그: 앞의 아홉 풀만 `expanded`, 나머지 3개는 `launch`
- 조우: 맹독 군락 RNG 구간별 독니 포식자·맹독 살포체·부식 군체 선택
- 서버 사냥 준비: 선택된 두 확장 몬스터 ID 보존
- 런타임: 활성 특수 30종, 전체 35종
- 전투: 독니 포식자 `독니`, 맹독 살포체 `재앙독`, 부식 군체 `맹독 파쇄`
- 집중: 독니 포식자만 `독니`에서 `재앙독`으로 교체되고 두 확장 몬스터의 고급 스킬은 유지
- 안전장치: 혈흔 망자의 미출시 후보 거부
- 보상: 세 몬스터의 동일 농축 독낭 규칙
- 자산: 두 WebP의 512×512 RGBA 알파와 참조 존재
- 관련 테스트, 전체 타입 검사, 변경 파일 린트, 전체 테스트, `V2_UNEXPLORED=true` production build

## 제외 범위

- 새로운 중독 상태 또는 독성 게이지
- 수동 전투 행동이나 별도 전투 UI
- 기존 중독 스킬의 수치 변경
- 개별 몬스터 보상 차등
- 혈흔 망자 이후 풀의 활성화
- 배포, 병합, 푸시, PR 생성
