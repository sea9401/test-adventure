# 개척 노드 탭·탐사망 확대 설계

## 목표

캐릭터 메뉴의 `미개척지` 진입 명칭을 `개척 노드`로 바꾸고, 한 화면에 길게 이어진 미개척지 콘텐츠를 네 개 탭으로 분리한다. 탐사망은 작은 노드를 자세히 볼 수 있도록 마우스와 터치 환경에서 확대·축소·이동을 지원한다.

## 범위

- 캐릭터 상단 드롭다운과 캐릭터 메뉴 카드의 진입 명칭을 `개척 노드`로 변경한다.
- 미개척지 화면의 내부 세계관 명칭과 사냥터 명칭은 그대로 유지한다.
- 본문을 `탐사망`, `탐사 업적`, `흔적 보관함`, `우두머리 핵 제작소` 탭으로 분리한다.
- 탐사망 SVG에 확대·축소·화면 이동·화면 맞춤을 추가한다.
- 서버 API, 탐사 노드 규칙, 제작 비용과 보상 규칙은 변경하지 않는다.
- 사용자가 별도로 요청하기 전에는 테스트 서버와 본서버 모두 배포하지 않는다.

## 화면 구조

상단의 제목, 탐사 포인트·경험치·난이도 요약, 레벨 제한 안내는 탭 밖에 두어 항상 보이게 한다. 그 아래에 접근 가능한 탭 목록을 두고 활성 패널 하나만 보이게 한다. 탐사망 패널은 탭 전환 중에도 마운트를 유지하고 `hidden` 상태로 전환해 선택 노드와 지도 배율을 보존한다.

1. `탐사망`: 160노드 지도와 선택 노드 상세, 활성 공용 풀 정보를 표시한다.
2. `탐사 업적`: 기존 업적 진행도와 열 개 업적 목록을 표시한다.
3. `흔적 보관함`: 보스별 흔적, 소환석 제작 비용, 소환 기능을 표시한다.
4. `우두머리 핵 제작소`: 확정 제작 장비와 드롭 전용 장비를 표시한다.

탭 전환은 클라이언트 상태만 바꾸며 스냅샷을 다시 요청하지 않는다. 선택 노드, 제작 중 상태, 서버 응답으로 갱신된 재료도 유지한다. 탐사망 초기화 버튼은 탐사망 탭에서만 표시한다.

## 탐사망 조작

탐사망 전용 뷰포트가 SVG 변환 상태를 소유한다.

- 기본 배율은 100%, 허용 범위는 50~250%, 버튼 조정 단위는 25%다.
- `축소`, 현재 배율, `확대`, `화면 맞춤` 컨트롤을 지도 위에 둔다.
- 마우스 휠은 포인터가 가리키는 지점을 기준으로 확대·축소한다.
- 한 개 포인터 드래그는 확대된 지도를 이동한다.
- 두 개 터치 포인터는 두 손가락 사이의 거리와 중심점을 사용해 확대·축소와 이동을 함께 처리한다.
- 화면 맞춤은 배율 100%와 이동량 0으로 복원한다.
- 배율과 이동량은 탭을 오가더라도 탐사 화면 컴포넌트가 유지되는 동안 보존한다.
- 클릭과 짧은 터치는 기존 노드 선택으로 전달하고, 드래그 직후의 의도하지 않은 노드 선택은 막는다.
- 노드의 Enter·Space 키 선택과 기존 `aria-label`은 유지한다.

브라우저 기본 페이지 확대나 스크롤과 충돌하지 않도록 지도 상호작용 영역에만 포인터 제스처를 제한한다. 확대·축소 버튼은 경계값에서 비활성화하며 현재 배율을 텍스트로 알린다.

## 컴포넌트 경계

- `V2UnexploredTreeView`는 데이터 조회·변경, 활성 탭, 네 패널 구성을 담당한다.
- 새 탐사망 뷰포트 컴포넌트는 SVG 확대·축소·이동 입력과 변환만 담당한다. 탐사 모델이나 서버 데이터를 직접 알지 않는다.
- 기존 탐사 노드 SVG와 선택 콜백은 뷰포트 안에서 그대로 사용해 전투·보상 로직과 분리한다.

## 오류와 경계 상태

- 데이터 로딩 실패와 제작 실패 알림은 기존 동작을 유지한다.
- 100레벨 미만이어도 탭 조회와 기존 진행도 확인은 가능하고 편집 버튼만 비활성화한다.
- 줌 경계 밖 입력은 50~250%로 제한한다.
- 포인터가 취소되거나 영역을 벗어나면 해당 제스처 상태를 정리해 다음 입력을 방해하지 않게 한다.

## 검증

- 메뉴 기능 플래그가 켜졌을 때 두 진입점 모두 `개척 노드`를 표시하는지 확인한다.
- 네 탭과 각 탭 패널의 단독 노출, 탭 전환 후 스냅샷 비재요청을 확인한다.
- 줌 버튼의 50~250% 경계, 화면 맞춤, 휠 확대, 드래그 이동, 두 포인터 확대를 확인한다.
- 탭 전환 뒤 선택 노드와 서버 변경 결과가 유지되는지 기존 상호작용 회귀 테스트로 확인한다.
- 관련 Vitest, ESLint, TypeScript 검사와 production build를 실행한다.
