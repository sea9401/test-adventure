# 미개척지 상위 특화 세트 실전 밸런스 검증 설계

## 목표

미개척지 상위 특화 세트 4종을 실제 ATB 전투 엔진으로 검증한다. 제작 해금 시점의 실제 기반 장비인 개척자 6.5T 조합과 종합 성능이 비슷하되 각 세트의 전문 분야에서는 분명한 우위를 가져야 한다. 폭풍 원정 6T 전환은 정보성 관찰값으로 남긴다. PvP는 상향 목표로 삼지 않고 과도한 승률만 막는다.

검증 대상은 다음 네 세트다.

| 세트 | 대표 계보 | 전문 분야 |
| --- | --- | --- |
| 추적 병기 | DEX 천궁 계보 | 다타격, 회피, 행동 속도 |
| 독혈 군주 | LUK 흑월 계보 | 중독·출혈, 장기 피해 |
| 빙하 거수 | VIT 요새기사 계보 | 물리·마법·상태이상 생존 |
| 심층 마도 | INT 대마도사 계보 | 마법 피해, MP 지속력 |

## 범위

- 실제 `derivePlayerCombatV2Pure()`와 ATB 전투 엔진을 사용한다.
- 장비의 정적 옵션, 태그 세트 보너스와 장착 시그니처를 모두 반영한다.
- PvE를 주 기준으로 하고 PvP는 과성능 안전장치로만 사용한다.
- 현재 수치로 먼저 보고서를 만들고, 허용 범위를 벗어난 세트만 최소 조정한다.
- 조정은 신규 12종 장비의 `power`·옵션 또는 신규 4개 태그 세트 수치에 한정한다.
- 새 전투 메커니즘, API, 저장 형식, UI와 이미지는 추가하지 않는다.
- 운영 데이터, 실제 유저 저장과 개인정보는 사용하지 않는다.
- 기능 플래그, 배포 설정과 운영 환경은 변경하지 않는다.

## 검토한 접근법

### 1. 실제 ATB 시나리오 비교 — 채택

결정적 난수로 실제 전투를 반복해 피해, 행동 수, 생존과 자원 소모를 측정한다. 중독·출혈·감전·추가 공격·MP 환급·보호막·피격 방어 누적을 실제 엔진과 같은 순서로 평가할 수 있다.

### 2. 정적 장비 점수 비교

빠르고 설명하기 쉽지만 발동 조건과 전투 길이에 따라 가치가 달라지는 시그니처를 제대로 평가할 수 없다. 카탈로그 상한을 확인하는 보조 지표로만 사용한다.

### 3. 운영 캐릭터 표본 비교

현실적인 장비 조합을 얻을 수 있지만 유저별 성장·스킬·강화 편차가 크고 반복 가능한 회귀 기준이 되기 어렵다. 이 단계에서는 사용하지 않는다.

## 비교 장비 구성

모든 장비는 강화·재련·해방·개체 편차가 없는 카탈로그 기준값을 사용한다. 레벨, 성장치, 직업, 스킬과 전투 패턴은 같은 세트 비교 안에서 고정하고 장비만 바꾼다.

| 세트 | 기준 태그 | 무기 조건 |

## 성장 상태와 결정성

- 레벨 100, 각 대표 계보의 6차 직업과 현재 정규 스킬 구성을 사용한다.
- `buildLevelDesignProgressionSnapshot()`의 고정 성장 상태를 재사용하되 장비는 위 표로 덮어쓴다.
- 모든 비교는 같은 seed 묶음을 공유한다.
- 기본 보고서는 seed `20260831`, 케이스당 200회다.
- 빠른 회귀 테스트는 케이스당 4회로 결정성과 보고서 계약만 검사한다.
- 밸런스 게이트는 기본 200회 보고서의 중앙값과 승률을 사용한다.
- 전역 `Math.random`은 각 표본 뒤 반드시 복원한다.

## PvE 시나리오

### 공통 공격 시나리오

1. 800 ATB 틱 단기 허수아비: 첫 순환과 폭발적인 시그니처를 측정한다.
2. 3,000 ATB 틱 장기 허수아비: 지속 피해, 추가 공격과 MP 고갈을 측정한다.
3. 고회피 물리 적: 적중과 추적 계열의 안정성을 측정한다.
4. 고방어 물리 적: 중독·출혈과 장기 누적 효과를 측정한다.

### 생존 시나리오

1. 물리 연타 적: 회피, 방어, 보호막과 피격 방어 누적을 측정한다.
2. 마법 강타 적: HP·마법 방어와 행동 유지력을 측정한다.
3. 중독·출혈 적: 상태이상 피해 감소와 장기 생존을 측정한다.

적은 고정 fixture로 정의한다. 기준 장비에서 승패가 발생하는 시나리오는 승률이 20~80%여야 하고, 제한 시간형 시나리오는 양쪽 중 한쪽의 최대 HP가 표본 중앙값 기준 최소 10% 감소해야 한다. 첫 행동 전 즉사, 명중 0%, 피해 0과 제한 시간까지 양쪽 HP가 그대로인 fixture는 실패로 처리한다.

## PvE 측정값과 허용 범위

공통 보고 값은 다음과 같다.

- 1,000틱당 직접 피해와 총피해
- 승률, 생존 틱, 종료 HP 비율
- 완료한 플레이어 행동과 스킬 시전 수
- 종료 MP 비율과 MP 부족으로 기본 공격을 선택한 횟수
- 회피, 보호막 흡수, 중독·출혈·감전 적용 횟수
- 장비 추가 공격 발동 횟수

폭풍 6T 전환 조합은 보고서에 계속 표시하지만 실패 게이트로 사용하지 않는다. 개척자 기준 대비 종합 주 지표는 `0.97~1.08배` 안에 두되 다음 전문 분야 조건을 추가한다.

- 추적 병기: 장기 총피해 또는 1,000틱당 행동 수 중 하나가 개척자보다 최소 `3%` 높고, 다른 하나는 `5%` 넘게 낮아지지 않는다.
- 독혈 군주: 장기 총피해가 개척자의 `0.97~1.08배`이며 중독+출혈 적용 수는 최소 `5%` 높다.
- 빙하 거수: 세 생존 시나리오 중 한 곳 이상에서 받은 피해 또는 생존 틱이 개척자보다 최소 `3%` 좋고, 세 시나리오 종합 생존은 `0.97~1.08배`, 공격 지표는 `10%` 넘게 낮아지지 않는다.
- 심층 마도: 장기 총피해가 개척자의 `0.97~1.08배`이며 스킬 시전 수 또는 종료 MP 비율은 최소 `5%` 높다.

표본에서 분모가 0인 지표는 비율로 만들지 않고 원시 값과 별도 조건으로 판정한다.

## PvP 안전장치

- 같은 계보·성장·스킬에서 개척자 기준 조합과 신규 개척자 전환 조합을 대전시킨다.
- 동일 seed로 A 선공과 B 선공을 모두 실행하고 두 결과를 한 쌍으로 집계한다.
- 세트별 400쌍을 기본 표본으로 사용한다.
- 신규 전환 조합의 관찰 목표 승률은 `45~60%`다. PvP는 상향 목표가 아니므로 하한 미달은 실패시키지 않는다.
- `60%` 초과는 경고, `62%` 초과는 실패다.
- 제한 시간 무승부는 양쪽에 0.5승으로 계산한다.
- PvP 목표를 맞추기 위해 PvE 전문 분야를 삭제하지 않는다. PvP만 과도하면 PvP에도 그대로 적용되는 범용 수치부터 최소 조정한다.

## 보스 고유 상한 보조 검사

보스 고유는 슬롯과 무기 계보가 신규 세트와 일치하지 않으므로 모든 세트에 같은 전투 상한을 강제하지 않는다. 대신 같은 슬롯의 `power`와 역할 옵션을 정적 보고서에 나란히 표시하고, 독혈 LUK·빙하 VIT처럼 합법적인 보스 고유 3부위 조합이 있는 계보는 별도 전투 참고 행을 추가한다.

- 신규 세트가 보스 고유보다 강하게 나온 것만으로 자동 실패시키지 않는다.
- 신규 조합이 보스 고유 참고 조합을 PvE 주 역할과 생존 양쪽에서 동시에 `5%` 넘게 앞서면 실패한다.
- 심층 마도처럼 직접 대응하는 개인 보스 고유가 없는 계보는 이 상한을 적용하지 않는다.
- 향후 7T는 아직 공통 비교군이 없으므로 이번 회귀 게이트에 넣지 않는다.

## 결과 형식

새 시뮬레이터는 다른 밸런스 도구처럼 라이브러리와 CLI를 겸한다.

- `buildUnexploredSpecialtyBalanceReport(options)`는 JSON 직렬화 가능한 원시 보고서를 반환한다.
- `unexploredSpecialtyBalanceViolations(report)`는 경고와 실패를 분리한다.
- CLI 기본 출력은 세트별 폭풍 6T·개척자·신규 전환·보스 고유 참고 행과 비율을 표로 보여 준다.
- `--json`은 자동 분석용 전체 보고서를 출력한다.
- `--strict`는 실패 항목이 하나라도 있으면 종료 코드 1을 반환한다.
- 실행 명령은 `npm run sim:v2:unexplored-specialty`로 등록한다.

## 조정 절차

1. 현재 카탈로그로 200회 보고서를 생성한다.
2. 실패한 세트와 실패 지표만 분리한다.
3. 먼저 신규 태그 세트의 범용 수치를 작은 단위로 조정한다.
4. 특정 슬롯 때문에만 어긋나면 해당 신규 아이템 옵션을 조정한다.
5. 한 번에 한 묶음만 바꾸고 전체 보고서를 다시 실행한다.
6. 네 세트가 모두 통과하면 그 결과 범위를 회귀 테스트로 고정한다.

조정 우선순위는 `세트 보너스 수치 → 시그니처 확률·계수 → 개별 옵션 → power`다. 정체성을 결정하는 트리거 종류와 세트 슬롯 구성은 바꾸지 않는다.

## 테스트와 완료 조건

- 시뮬레이터가 네 세트와 세 비교군을 빠짐없이 만든다.
- 같은 seed 보고서는 완전히 동일하고 실행 순서에도 영향을 받지 않는다.
- 모든 수치가 유한하며 비율 분모 0을 안전하게 처리한다.
- 실제 장비 집계에서 신규 2·3세트와 남은 기준 세트 단계가 정확히 활성화된다.
- 각 세트의 전문 시그니처가 해당 PvE 시나리오에서 한 번 이상 관측된다.
- 200회 PvE 보고서와 400쌍 PvP 보고서가 모든 실패 게이트를 통과한다.
- 특화 장비·전투 엔진 집중 테스트, 전체 테스트, TypeScript, ESLint, 이미지 검사와 프로덕션 빌드가 통과한다.
- 변경 사항은 격리 브랜치에 커밋하고 사용자 승인 없이 푸시하거나 배포하지 않는다.

## 2026-08-31 보고서 표시 완성

원시 PvE 행만 보고 비율을 따로 계산해야 했던 불편을 없앴다. JSON 보고서의 `ratios`는 네 세트에 대해 폭풍 전환/폭풍 주 역할, 개척자 전환/개척자 주 역할, 전환/보스 주 역할과 전환/보스 생존 비율을 구조화한다. 합법적인 보스 참고 계보가 없는 추적 병기와 심층 마도의 보스 비율은 `null`이며 간결 CLI에서는 `-`로 표시한다.

`equipmentComparisons`는 유효 스케일이 적용된 실제 장비 카탈로그에서 다음 다섯 동일 계보·동일 슬롯 쌍만 투영한다.

- 추적 병기: 그림자 도약화 ↔ 허상 가속화
- 독혈 군주: 독혈 침식갑 ↔ 부패하지 않는 심장, 군주의 맥동환 ↔ 응고독 반지
- 빙하 거수: 거수 성벽갑 ↔ 얼어붙은 거갑, 빙벽 핵목걸이 ↔ 절대영도의 핵

각 행은 장비 ID, 이름, 유효 `power`와 원시 옵션을 JSON으로 제공한다. 간결 CLI는 같은 데이터를 한글 옵션 요약과 함께 출력한다. 직접 대응 보스 계보가 없는 심층 마도나 슬롯만 우연히 같은 다른 계보 장비는 비교하지 않는다. 보고서 완성 뒤 200회 PvE·400쌍 PvP 엄격 측정은 기존 비율을 유지하며 경고 0건·실패 0건으로 통과했다.
