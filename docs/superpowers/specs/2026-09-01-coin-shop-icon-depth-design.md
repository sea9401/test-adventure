# 무슨 코인 상점 아이콘 입체감 통일 설계

## 목표

월간 모험 지원권 프리미엄 아이콘을 기준으로 무슨 코인 상점의 나머지 10개 상품 아이콘을 같은 2.5D 벡터 스타일로 통일한다.

## 범위

- 상점에 노출되는 11개 상품 모두 `256×256` 전용 SVG를 사용한다.
- 기존 전용 SVG 7개는 원래 상징과 고유 색상을 유지하면서 명암을 보강한다.
- 공용 아이콘을 사용하던 대표 배지 전시대, 월간 스태미나 회복약 세트, 성장 도약 패키지에는 새 전용 SVG를 만든다.
- 상품 기능, 가격, 문구, 카드 배치와 프리미엄 지원권 원본 SVG는 변경하지 않는다.

## 시각 규칙

- 광원은 좌상단, 음영은 우하단으로 통일한다.
- 배경 타일은 밝은 상단에서 어두운 하단으로 흐르는 대각선 그라데이션을 쓴다.
- 중심 오브젝트는 밝은 면과 어두운 면을 분리하고, 하단 또는 우측에 짧은 그림자를 둔다.
- 외곽선은 기존의 굵고 둥근 게임 아이콘 문법을 유지한다.
- 아이콘별 색상과 상징은 유지해 작은 크기에서도 즉시 구분되게 한다.
- 필터 기반 블러나 래스터 효과는 사용하지 않아 SVG가 선명하게 축소되도록 한다.

## 연결 및 검증

`CASH_ITEM_ART_PATHS`가 `SHOP_ITEM_GROUPS`의 11개 상품을 모두 전용 SVG에 연결한다. 회귀 테스트로 누락된 매핑을 막고, 이미지 참조 검사와 SVG 렌더 미리보기로 경로·가독성·스타일 일관성을 확인한다.
