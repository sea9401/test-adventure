# 재마법부여 버튼 위치 안정화 설계

## 문제

재마법부여가 한 번 완료된 뒤 다시 버튼을 누르면, 요청 시작 시 직전 `result`와 `message`를 비워 버튼 위의 두 영역이 사라진다. 응답 후 새 결과와 안내가 렌더링되면서 버튼이 다시 내려가므로 화면이 덜그럭거린다.

## 설계

- 재마법부여 요청 중에는 직전 결과와 안내를 유지한다.
- 새 응답이 오면 기존 결과와 안내를 새 내용으로 교체한다.
- 장비를 바꿀 때는 기존처럼 다른 장비의 결과와 안내를 초기화한다.
- 요청 중 버튼은 계속 비활성화하고 문구를 `마법부여 중…`으로 표시한다.
- API 요청, 비용 차감, 오류 처리 방식은 변경하지 않는다.

## 검증

성공한 재마법부여 직후 다시 요청했을 때, 두 번째 요청이 대기 중인 동안 직전 완료 안내와 결과 상태가 DOM에 유지되는 회귀 테스트를 추가한다. 기존 마법부여 패널 테스트, 타입 검사와 린트를 실행한다.
