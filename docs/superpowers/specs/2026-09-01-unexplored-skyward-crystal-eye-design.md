# 미개척지 개인 보스 · 천공의 수정안 설계

## 목적

`수정 포격대`와 `정밀 사냥단`을 연결하는 다섯 번째 미개척지 개인 보스
`천공의 수정안`을 추가한다. 보스는 전투 내내 고정 주기로 수정 포격을 조준하고,
플레이어가 그 사이 적중시킨 실제 타격 수와 치명타 수로 포격을 약화한다. 연타 스킬은
모든 타격을 인정해 명확한 우위를 얻지만, 포격을 완전히 취소하거나 보스 행동을 봉쇄할
수는 없다.

기존 개인 보스와 역할을 다음처럼 분리한다.

- 추적 병기: 빠른 행동과 추적 반격에 대한 생존 대응
- 독혈 군주: 누적 상태 피해와 회복 억제 대응
- 빙하 거수: 한기와 행동 취소 대응
- 불괴의 성채: 제한 시간의 순간 피해로 구간 광폭 약화
- 천공의 수정안: 지속적인 실제 적중 수와 연타로 주기 포격 약화

## 확정 범위

- 개인 보스 `skyward_crystal_eye`
- 수정 포격대·정밀 사냥단 흔적을 사용하는 전용 소환석
- 공격 시도 사이에 이어지는 900틱 고정 포격 주기
- 실제 직접 타격과 치명타로 쌓는 `조준 붕괴` 24중첩
- 4중첩 단위의 포격 약화 6구간과 24중첩 보상
- 포격 뒤 250틱 동안의 핵 노출과 다음 조준의 동시 진행
- 목록·상세·공격 결과·전투 기록·재생의 기믹 상태 표시
- 고유 장비 3종, 보스·장비 이미지, 처치 업적과 칭호
- 결정론적 전투 시뮬레이션과 기존 전투 격리 회귀

다음 항목은 포함하지 않는다.

- 불괴의 성채나 기존 개인 보스의 기믹·수치·보상 변경
- 포격 취소, 보스 행동 정지 또는 핵 노출 중 조준 중지
- 지속 피해·반사 피해·자동 반격을 조준 붕괴에 포함하는 규칙
- 드롭 천장, 조각 교환, 중복 보호 또는 0.5% 장비 확정 제작
- 운영 기능 플래그 변경이나 테스트·운영 배포

## 보스 카탈로그

| 항목 | 값 |
| --- | --- |
| ID | `skyward_crystal_eye` |
| 이름 | 천공의 수정안 |
| 연결 풀 | `crystal_artillery`, `precision_hunters` |
| 공유 최대 HP | `10,800,000` |
| 기준 깊이 | `120` |
| 소환석 | `v2_unexplored_skyward_crystal_eye_summon_stone` |
| 칭호 | `v2_unexplored_skyward_crystal_eye` · 천공을 흐린 자 |
| 이미지 | `/images/monster/v2/unexplored-boss-skyward-crystal-eye.webp` |

외형은 거대한 부유 수정체 중앙의 눈 모양 조준핵과 그 주위를 도는 여러 수정 렌즈로
구성한다. 렌즈는 평소 표적을 계산하고 900틱마다 한 축으로 정렬되어 천공 포격을
발사한다. 연타를 맞으면 렌즈 배열이 흐트러지고, 24중첩에 도달한 주기의 포격 뒤에는
과부하된 중앙핵이 노출된다.

출시 시작 전투 수치는 `hp 1,150`, `atk 2.0`, `def 42`, `magicDef 48`, `spd 22`,
`accuracy -185`, `evasionPct 16`으로 둔다. 일반 공격은 명중률이 높은 단일 대상 마법
광선이다. 별도 MP 스킬, 회복, 보호막, 상태이상과 일반 HP 발악은 넣지 않는다. 실제 출시
수치는 대표 빌드 시뮬레이션에서 기믹 계약을 유지한 채 공격력, 방어·마법 방어, 명중과
회피 순서로 조정할 수 있다.

표시 특성은 다음 세 문구를 사용한다.

- `900틱마다 천공 포격`
- `연타·치명타로 조준 붕괴`
- `24중첩 시 포격 50%·핵 노출`

## 소환과 보상

소환석 제작은 기존 개인 보스 계약을 그대로 따른다.

- 수정 포격대 흔적 500
- 정밀 사냥단 흔적 500
- 수정 렌즈 10개
- 정밀 조준경 10개
- 보스 소환서 30장
- 골드 5,000,000G
- 거래 가능한 소환석 1개
- 기존 요청 ID 멱등성, 재료·골드 원자 차감과 소환자 전용 세션 규칙

보스 처치 시 우두머리 핵을 확정 지급하고 다음 고유 장비를 독립적으로 굴린다.

| 확률 | ID | 이름 | 슬롯 | 출시 옵션 |
| ---: | --- | --- | --- | --- |
| 30% | `v2_unexplored_prismatic_firing_gauntlets` | 분광 사격완갑 | 장갑 | HP 220, 치명타 12, 속도 18, 적중 30 |
| 10% | `v2_unexplored_starpath_aiming_ring` | 별궤 조준환 | 반지 | MP 280, 마법 방어 35, 치명타 16, 치명피해 85, 적중 24 |
| 0.5% | `v2_unexplored_infinite_focus_crystal_eye` | 무한초점 수정안 | 목걸이 | HP 480, MP 480, 마법 방어 100, 치명타 18, 치명피해 85, 적중 30 |

분광 사격완갑과 별궤 조준환은 현행 6T 옵션 예산 안에서 축을 바꾼 사이드그레이드로
두고 각각 우두머리 핵 8개·25개 확정 제작 대상에 포함한다. 두 제작식은 기존 규칙대로
연결 풀 재료를 각각 25개·75개 요구한다.

무한초점 수정안은 드롭 전용 추격 장비다. `every_n_hits` 시그니처를 사용해 실제 적중
5회마다 추가 기본 공격 한 번을 예약한다. 그 추가 공격은 자기 자신의 다음 5회 주기에는
포함하지 않는다. 기존 추적 병기 3세트의 6회 발동보다 강하지만 한 부위의 0.5% 추격
보상이라는 위치를 유지하며, 시뮬레이션에서 기존 완성 세트를 전투 전반에 걸쳐 일괄
지배하면 옵션 예산부터 낮춘다.

## 조준 붕괴

새 보스 세션은 `aimTicksRemaining 900`, `disruptionStacks 0`으로 시작한다. 포격
타이머는 보스의 일반 행동과 별개인 전용 ATB 사건이며, 보스가 행동하는 동안에도 계속
감소한다.

플레이어 행동에 귀속된 실제 직접 타격을 다음처럼 계산한다.

- 명중한 각 타격은 1중첩을 준다.
- 치명타로 명중한 각 타격은 총 2중첩을 준다.
- 연타 스킬과 그 행동에서 발생한 추가타는 실제 적중한 모든 타격을 개별 계산한다.
- 행동당 획득 상한은 없다.
- 지속 피해, 반사 피해와 플레이어 행동에 귀속되지 않은 자동 반격은 제외한다.
- 빗나간 타격은 중첩을 주지 않지만 기존 중첩을 감소시키지 않는다.
- 중첩은 24에서 저장 상한을 두고 초과분을 버린다.

한 다단 공격 도중 24중첩에 도달해도 그 자리에서 포격을 취소하거나 핵을 노출하지
않는다. 남은 타격은 정상 피해만 주며, 예약된 포격 시점까지 24중첩 상태를 유지한다.

## 포격 주기와 위력

포격은 새 세션 기준 900·1,800·2,700틱에 발생한다. 포격 직후 다음 900틱 조준을 즉시
시작하므로 핵 노출 250틱과 다음 조준은 겹친다. 3,000틱 공격 상한에 도달하면 네 번째
조준의 남은 600틱과 그동안 쌓인 중첩을 저장한다. 이후 공격은 저장된 타이머에서 이어져
전투 끝부분을 프리딜 구간으로 만들지 않는다.

이후 공격은 이전 남은 시간에 따라 한 시도 안의 포격 횟수가 달라질 수 있다. 정확히
3,000틱에 포격 사건이 도착하면 같은 틱의 플레이어 행동을 먼저 처리한 뒤 포격을
실행한다. 플레이어 행동으로 보스를 먼저 처치했으면 포격은 실행하지 않는다.

포격 직전 현재 공유 HP로 기본 계수를 고른다.

| 현재 보스 HP | 포격 기본 계수 |
| ---: | ---: |
| 75% 초과 | 일반 공격의 180% |
| 50% 초과 75% 이하 | 210% |
| 25% 초과 50% 이하 | 240% |
| 25% 이하 | 270% |

기본 계수에 조준 붕괴 구간 배율을 곱한다.

| 조준 붕괴 | 포격 위력 배율 |
| ---: | ---: |
| 0~3 | 100% |
| 4~7 | 90% |
| 8~11 | 80% |
| 12~15 | 70% |
| 16~19 | 60% |
| 20~23 | 50% |
| 24 | 50% |

포격은 항상 발사되며 치명타가 발생하지 않는 마법 피해다. 마법 방어 20% 관통과 일반
공격보다 높은 명중 보정을 사용하되 확정 명중은 아니다. 실제 피해는 기존 보스 피해
상한과 방어·회피 규칙을 통과한다.

포격 후 중첩을 0, 남은 조준 시간을 900으로 초기화한다. 발사 직전 중첩이 24였다면
포격 처리 뒤 `coreExposureTicksRemaining 250`을 설정한다. 24 미만이면 핵을 노출하지
않는다.

## 핵 노출

핵 노출 중 보스가 받는 모든 최종 피해를 25% 증가시킨다. 직접 피해뿐 아니라 이미 걸린
지속 피해에도 적용하되, 지속 피해는 조준 붕괴 중첩을 주지 않는다.

핵 노출은 보스 행동과 다음 조준을 멈추지 않는다. 보스는 일반 광선을 계속 발사하고,
다음 900틱 타이머와 새 조준 붕괴 중첩도 동시에 진행한다. 따라서 연타 빌드는 매 주기
최소 50% 포격과 약 27.8%의 최대 핵 노출 유지율을 얻을 수 있지만 보스를 허수아비로
만들 수 없다.

핵 노출 시간이 남은 상태에서 다음 공격 시도가 끝나면 남은 시간을 저장한다. 정상 규칙상
250틱 노출은 900틱 포격 간격보다 짧아 중첩 노출이 발생하지 않는다. 손상 상태에서 두
값이 겹쳐도 250으로 제한하고 새 노출은 250으로 교체하며 누적하지 않는다.

## 상태 모델과 저장

보스 전용 상태는 다음 의미를 가진다.

```ts
type SkywardCrystalEyeBattleState = {
  kind: "skyward_crystal_eye";
  aimTicksRemaining: number;
  disruptionStacks: number;
  coreExposureTicksRemaining: number;
  artilleryCount: number;
  lastArtilleryPowerPct: 25 | 50 | 60 | 70 | 80 | 90 | 100 | null;
};
```

세션의 `mechanic_state`에는 현재 보스 MP나 다른 알려진 전용 상태 키를 덮어쓰지 않고 위
상태를 병합한다. 공격 시뮬레이션의 최종 상태는 세션 행 잠금 뒤 권한·만료·공격 쿨다운과
공유 HP를 재검증한 트랜잭션에서 HP와 함께 저장한다. 같은 HP에서 먼저 처리된 동시 공격이
기믹 상태만 바꾼 경우에도 오래된 결과가 이를 덮어쓰지 않도록 전용 상태의 기준값을 함께
비교하고 충돌 응답을 반환한다.

거부·충돌·롤백된 요청은 HP, 타이머, 중첩, 핵 노출과 횟수를 모두 변경하지 않는다. 보스
처치·만료에는 전용 상태를 제거한다.

손상된 값은 다음처럼 보정한다.

- `aimTicksRemaining`: 유한한 정수 `0~900`; 0은 즉시 포격 대기 상태
- `disruptionStacks`: 유한한 정수 `0~24`
- `coreExposureTicksRemaining`: 유한한 정수 `0~250`
- `artilleryCount`: 0 이상의 정수
- `lastArtilleryPowerPct`: 허용된 일곱 값 이외에는 `null`

기존 상태가 없는 천공의 수정안 세션은 소급 포격이나 핵 노출 없이 `900틱·0중첩`으로
시작한다.

## 전투 엔진 경계

중첩 계산, 포격 구간 선택, HP 구간 계수와 상태 정규화는 데이터베이스·API·장비를 모르는
별도 순수 모듈에 둔다. ATB 엔진은 선택적 `skyward_crystal_eye` 문맥에서만 다음 사건을
추가한다.

1. 플레이어 행동의 실제 개별 타격 결과에서 명중·치명 여부를 전용 상태에 반영한다.
2. 다음 일반 행동보다 포격 타이머가 빠르면 포격 사건을 먼저 예약한다.
3. 같은 틱이면 플레이어 행동과 그 행동의 모든 타격을 먼저 처리한다.
4. 포격 시 현재 HP 계수와 저장된 중첩 구간으로 피해를 계산한다.
5. 포격 뒤 새 조준을 시작하고 필요하면 핵 노출을 설정한다.
6. 핵 노출 중 받는 피해만 증가시키고 보스·플레이어 행동 시계는 그대로 둔다.
7. 전투 결과에 최종 상태와 이번 공격에서 발생한 포격 결과를 정형 데이터로 반환한다.

전투 로그 문자열을 판정 입력으로 사용하지 않는다. 명중·치명·피해 출처와 타이머는 엔진의
정형 상태에서 계산한다. 새 보스 문맥이 없는 일반 PvE, PvP와 다른 보스는 기존 결과를
유지한다.

## API와 화면

보스 목록·상세·공격 결과에는 다음 값을 제공한다.

- 다음 포격까지 남은 틱
- 현재 조준 붕괴 `0~24`
- 현재 예상 포격 위력 `50~100%`
- 현재 HP 기준 포격 기본 계수
- 핵 노출 여부와 남은 틱, 받는 피해 증가 25%
- 누적 포격 횟수와 직전 포격의 중첩·위력·실제 피해

표시 예시는 다음과 같다.

- `천공 포격까지 640틱`
- `조준 붕괴 17 / 24`
- `현재 예상 포격 위력 60%`
- `수정 핵 노출 180틱 · 받는 피해 +25%`

전투 기록에는 조준 붕괴 증가, 포격 준비 완료, HP 구간 기본 계수, 중첩별 약화, 실제 포격

2. 기본 공격력과 속도
3. HP 구간별 포격 기본 계수
4. 기본 방어력과 마법 방어력

900틱 주기, 24중첩, 타격당 1·치명타 2중첩, 일곱 포격 배율, 250틱 핵 노출과 동시 조준
계약은 캘리브레이션 중 바꾸지 않는다.

출시 목표는 다음과 같다.

- 연타 특화 빌드는 새 세션의 포격 세 번 중 중앙값 두 번 이상 24중첩을 달성한다.
- 치명타 특화 빌드는 주로 16~24중첩에 도달한다.
- 일반 단타 빌드는 주로 8~19중첩에 도달한다.
- 일반 단타 빌드도 포격을 약화하지만 핵 노출을 안정적으로 반복하지 못한다.

  장비를 전투·생존 양쪽에서 동시에 지배하지 않는다.

운영 데이터베이스를 읽거나 쓰지 않고 로컬 고정 픽스처만 사용한다. 확정 시드, 실행 명령,
계보별 포격 세 번의 중첩·배율·실제 피해·생존 틱·기여도와 핵 노출 유지율을 구현 기록에

## 회귀 테스트

### 순수 상태 전이

- 모든 실제 연타가 개별 1중첩, 각 치명타가 개별 2중첩으로 계산됨
- 행동당 상한 없이 24에서 저장 상한 적용
- 빗나감·지속 피해·반사 피해·자동 반격은 중첩을 주지 않음
- `3/4`, `7/8`, `11/12`, `15/16`, `19/20`, `23/24` 경계에서 정확한 배율 선택
- HP `75/50/25%` 경계에서 정확한 기본 포격 계수 선택
- 포격 후 900틱·0중첩 초기화와 24중첩일 때만 250틱 핵 노출
- 손상된 시간·중첩·횟수·직전 배율 정규화

### ATB 통합

- 새 세션에서 900·1,800·2,700틱 포격과 2,700~3,000틱 다음 조준 진행
- 핵 노출 중 보스 일반 행동과 다음 조준·중첩 누적이 계속됨
- 핵 노출 중 모든 최종 피해 25% 증가, 지속 피해는 중첩 미부여
- 같은 틱 플레이어 행동 우선과 선처치 시 포격 미발사
- 포격의 비치명 마법 피해, 20% 마법 방어 관통과 회피 가능 명중 판정
- 새 보스 문맥이 없는 일반 PvE·PvP·기존 보스 결과 불변

### 저장·API·화면

- 공격 종료 뒤 남은 포격 시간·중첩·핵 노출·횟수·직전 결과가 HP와 함께 저장됨
- 다음 공격에서 저장된 타이머와 중첩을 그대로 이어 감
- 거부, 같은 HP 기믹 상태 충돌과 트랜잭션 롤백에서 모든 상태 무변경
- 목록·상세·공격 결과의 타이머, 중첩, 예상 위력과 핵 노출 일치
- 전투 기록과 재생 자원이 같은 사건 순서와 상태를 표시
- 라이트·다크 모드에서 보스 카드와 중첩 카드의 불투명 표면 유지
