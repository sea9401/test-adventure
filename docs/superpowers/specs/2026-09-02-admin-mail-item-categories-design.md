# 관리자 우편 아이템 분류 및 숙련 증서 지급 설계

## 목표

- 공지·우편 관리자 화면에서 숙련 증서를 지급할 수 있게 한다.
- 미개척지 재료, 보스 소환석, 개척자·제작·보스 장비가 긴 전체 목록 속에 묻히지 않게 한다.
- 기존 우편 payload와 수령 전 우편의 하위 호환성을 유지한다.

## 설계

`adminCatalogOptions`를 지급 카탈로그의 단일 분류 원천으로 확장한다. 재료는 성장·강화, 생활, 제작, 협동 보스, 원정·위험 해역, 미개척지 재료, 미개척지 보스 재료, 미개척지 보스 소환석으로 나눈다. 장비는 일반 장비를 부위별로 나누고, 미개척지 장비는 개척자, 특화 제작, 보스 고유 장비로 나눈다. 모든 항목은 정확히 한 분류에만 들어가며 기존 평면 옵션 함수도 유지한다.

`AttachmentPicker`는 기존 평면 목록과 새 분류 목록을 모두 받는다. 분류 목록을 받으면 분류 선택과 아이템 선택을 별도로 표시하여 한 번에 보이는 항목 수를 줄인다. 확정된 첨부 항목은 기존처럼 하나의 목록에 합쳐지고, 분류를 바꿔도 이미 추가한 항목은 보존한다.

숙련 증서는 재료나 장비 ID가 아니라 `inventory.v2.masteryCertificates`에 저장되는 전용 재화이므로 우편 payload에 `masteryCertificates` 숫자 필드를 추가한다. 관리자 입력, 발송 API 검증, payload 파싱, 수령 처리, 우편 보상 표시를 모두 연결한다. 누락된 레거시 payload는 0으로 정규화한다.

## 안전성

- 숙련 증서는 우편 한 건당 기존 첨부 수량 상한과 같은 1,000,000개로 제한한다.
- 0개는 미첨부로 처리하고 숙련 증서만 있는 우편도 유효하게 허용한다.
- 미개척지 분류는 실제 카탈로그 상수와 장비 메타데이터에서 계산하여 새 항목 추가 시 누락 가능성을 줄인다.
- 운영 배포는 이 작업 범위에 포함하지 않는다.
