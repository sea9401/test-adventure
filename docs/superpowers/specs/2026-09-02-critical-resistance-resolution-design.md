# 치명타 저항 계산 순서 개편 설계

## 목표

치명타 저항이 공격자의 치명타 확률과 초과 치명타 피해 전환을 모두 실질적으로 낮추도록 계산 순서를 바꾼다. 방어자의 치명타 저항 50%p 상한은 제거하되, 확정 치명타는 지금처럼 저항을 무시한다.

## 계산 규칙

확률형 치명타는 다음 순서로 계산한다.

1. 공격자의 모든 치명타 확률 보너스를 합쳐 원본 치명타 확률을 만든다.
2. 원본 치명타 확률에서 방어자의 치명타 저항을 %p로 뺀다. 결과의 최솟값은 0%다.
3. 저항 적용 후 확률에 공격 유형별 치명타 확률 상한을 적용한다.
4. 저항 적용 후에도 상한을 넘는 부분만 기존 규칙에 따라 치명타 피해로 전환한다.

예를 들어 원본 치명타 확률 150%, 치명타 저항 50%p, 확률 상한 75%라면 저항 적용 후 100%가 된다. 실제 치명타 확률은 75%이고 남은 25%p만 치명타 피해 전환 대상이다.

확정 치명타는 확률 판정을 사용하지 않으므로 치명타 저항을 적용하지 않는다. 초과 치명타 피해도 저항 차감 전 원본 치명타 확률을 사용한다. 연쇄 운명, 집중의 호흡, 흑월지배 등 기존 확정 치명타 동작을 유지한다.

## 적용 범위

- PvP 일반 공격: 저항 적용 후 확률 상한과 초과 치명타 피해 전환을 계산한다.
- PvP 직접 피해 스킬: 저항 적용 후 확률 상한을 계산하고, 스킬 초과 치명타 전환 효과가 있을 때 같은 저항 적용 후 초과분을 사용한다.
- PvE 몬스터 공격: 기존처럼 몬스터 치명타 확률에서 플레이어 저항을 직접 차감한다.
- 플레이어 치명타 저항 파생값: 정신, 장비, 해방 효과를 합산하되 50%p 상한을 적용하지 않는다.
- 내 정보 상세 능력치: 실제 전투에 전달되는 치명타 저항을 표시하고, 상대 치명타 확률에서 먼저 차감된다는 설명을 제공한다.

치명타 확률 자체의 상한, 초과분 전환 계수와 전환 피해 상한은 이번 변경에서 유지한다. 별도의 "치명타 피해 저항" 능력치는 현재 존재하지 않으므로 새로 만들지 않는다.

## 테스트

- 치명타 저항 파생값이 50%p를 넘어도 잘리지 않는지 검증한다.
- PvP에서 150% 치명타 확률과 50%p 저항이 75% 실제 확률 및 25%p 초과분으로 계산되는지 검증한다.
- 저항이 초과 치명타 피해 전환량을 낮추는지 검증한다.
- 저항이 확정 치명타를 막지 않는지 기존 회귀 테스트를 유지한다.
- PvE 몬스터 치명타가 충분한 저항으로 계속 차단되는지 검증한다.
- 상세 능력치에 치명타 저항 실효값과 계산 설명이 표시되는지 검증한다.
