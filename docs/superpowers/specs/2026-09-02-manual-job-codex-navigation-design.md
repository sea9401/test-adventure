# 매뉴얼 직업 도감 탐색 개선 설계

## 목표

게임 안내서의 `직업·숙련도·전직` 문서에서 전체 직업 목록을 분리해 같은 성장 그룹의 독립 `전체 직업 도감` 섹션으로 제공한다. 141개 직업 목록은 기존 검색·종류·직군·차수 필터를 유지하면서 페이지당 12개만 표시한다. 상세 페이지는 복잡한 고차 직업에 운용 설명과 실제 스킬 순서 예시를 추가한다.

## 정보 구조

- `/manual/jobs`는 직업 계보, 전직, 숙련도, 숙련의 탑, 수행만 설명한다.
- `/manual/job-codex`는 전체 직업 도감의 검색·필터·목록을 담당한다.
- `/manual/jobs/[jobId]` 상세 경로는 기존 링크 호환을 위해 유지한다.
- 상세 페이지의 사이드바 활성 섹션과 “전체 직업 도감” 돌아가기 링크는 `/manual/job-codex`를 가리킨다.
- `전체 직업 도감`은 `직업·숙련도·전직` 바로 다음에 배치해 데스크톱 사이드바와 모바일 선택 목록에서 함께 노출한다.

## 목록 페이지네이션

- 필터가 적용된 결과를 먼저 계산하고 그 결과에 페이지네이션을 적용한다.
- 페이지 크기는 12개로 고정한다. 3열 데스크톱에서는 4행, 2열 화면에서는 6행으로 목록 길이를 제한한다.
- 이전·다음 버튼과 `현재 / 전체 페이지`를 제공한다.
- 첫 페이지의 이전 버튼과 마지막 페이지의 다음 버튼은 비활성화한다.
- 검색어나 종류·직군·차수 필터가 바뀌면 항상 1페이지로 돌아간다.
- 결과가 없거나 한 페이지만 있으면 페이지 이동 UI를 표시하지 않는다.
- 결과 요약은 전체 카탈로그 수, 필터 결과 수, 현재 표시 범위를 구분해 읽을 수 있게 한다.

## 직업별 운용 가이드

모든 직업에 일반론을 반복하지 않고, 규칙을 오해하기 쉬운 공개 7차 전투 직업 4종에 선택적 `운용 이해하기` 블록을 제공한다. 각 가이드는 핵심 원리, 주의할 규칙, 실제 스킬 순서 예시로 구성한다. 상세 수치와 스킬 효과는 기존 자동 생성 영역을 그대로 사용한다.

비천무신은 다음 내용을 명시한다.

- 원거리 계열: `낙성`, `천궁궤적`
- 체술 계열: `파공`, `천룡난무`
- 체술 다음 원거리 적중은 `포획`
- 원거리 다음 체술 적중은 `추격`
- 같은 계열 연속 사용은 교차로 취급하지 않음
- 예시: `파공 → 낙성 = 포획`, `낙성 → 파공 = 추격`

나머지 7차 직업은 검영 기록·정련, 검의 3중첩과 멸검 충전, 서로 다른 직접 마법의 완전식 단계를 각각 예시로 설명한다.

## 컴포넌트와 데이터 경계

- 새 정적 본문 컴포넌트 `JobCodexContent`가 도감 소개와 `JobWikiIndex`를 조합한다.
- `JobWikiIndex`만 클라이언트 상태를 가지며 필터 결과와 현재 페이지를 계산한다.
- 페이지 크기와 순수 페이지 계산 함수는 컴포넌트 파일에서 내보내 단위 테스트가 실제 동작을 검증한다.
- 선택적 가이드는 별도 `jobManualGuides.ts`에 두고 `jobManualModel`이 상세 모델에 포함한다. 상세 UI는 가이드가 있을 때만 블록을 렌더링한다.

## 접근성과 표면

- 페이지 이동은 명시적 `nav`와 접근 가능한 이름을 사용한다.
- 현재 페이지 정보는 `aria-live` 결과 요약에 포함한다.
- 모든 본문과 카드는 `SURFACE_CARD`, `SURFACE_INSET`, `SURFACE_ACCENT`의 불투명 표면을 사용한다.
- 잠금 상태용 컨테이너 투명도는 추가하지 않는다.

## 검증

- 섹션 목록과 본문 매핑이 새 슬러그를 포함하고 순서가 올바른지 검사한다.
- 기존 직업 문서에서 목록이 제거되고 새 도감 문서에만 전체 목록이 나타나는지 검사한다.
- 13개 이상의 고정 fixture로 첫 페이지 12개, 다음 페이지, 경계 버튼, 필터 변경 시 1페이지 복귀를 검사한다.
- 비천무신 상세 모델과 렌더링에서 네 스킬의 계열, 포획·추격 방향, 두 예시를 검사한다.
- 집중 테스트 후 타입 검사, 린트, 전체 테스트, 프로덕션 빌드를 실행한다.
