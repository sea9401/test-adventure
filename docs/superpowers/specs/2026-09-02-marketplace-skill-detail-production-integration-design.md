# 거래소 경매제·공용 스킬 상세창 운영 통합 설계

## 목표

완료됐지만 운영 승격에서 빠진 두 기능만 최신 `main`에 다시 통합한다.

- 모든 거래소 등록을 6시간짜리 묶음 전체 경매로 통일한다.
- 스킬 학습, 장착 목록, 직업 로드맵에서 같은 공용 스킬 상세창을 연다.

두 기능의 기존 설계와 테스트를 동작 기준으로 사용하며, 밸런스나 별도 콘텐츠는 추가하지
않는다.

## 거래소 경계

- 고정가 즉시 구매와 장비 구매 주문은 종료한다.
- 재료·소모품도 등록한 수량 전체를 한 번에 낙찰한다.
- 경매 기본 시간은 6시간이며 종료 직전 입찰은 기존 설계대로 종료 시각을 연장한다.
- 만료 처리에서 낙찰 정산과 유찰 반환을 원자적으로 수행한다.
- 기존 고정가·구매 주문 엔드포인트는 명시적인 종료 응답을 반환한다.
- 기존 에스크로와 거래 정지 정산 규칙은 보존한다.

`main`이 이미 `0179` 마이그레이션을 사용하므로 거래소 정책 컬럼은 새 `0180` 마이그레이션과
스냅샷으로 생성한다.

## 스킬 상세창 경계

- 실제 스킬 데이터에서 피해·회복, MP, 재사용 대기시간, 발동률, SP와 조건부 효과를 만든다.
- 데이터만으로 설명하기 어려운 발동 순서, 연계, 제한과 PvP 차이는 기존 수동 상세 원문을
  사용한다.
- `V2SkillLearnView`, `V2LoadoutPanel`, `JobRoadmapDialog`가 한 공용 다이얼로그를 재사용한다.
- 학습·장착·해제·강화 버튼의 기존 동작과 목록 높이는 바꾸지 않는다.
- 불투명 표면과 기존 모달 접근성 유틸을 사용한다.

## 통합 및 배포

- 두 원본 기능 브랜치의 기능 전용 커밋만 최신 `main`에 적용한다.
- 충돌 해결과 마이그레이션 재번호를 포함한 최종 결과는 운영 `main` 위의 단일 스쿼시
  커밋으로 만든다.
- 기능별 회귀 테스트, 타입 검사, 린트, 마이그레이션 검사, 전체 단위 테스트와 프로덕션
  빌드를 통과시킨다.
- PR CI와 정확한 `main` SHA의 운영 산출물을 확인한 뒤 배포한다.
- 배포가 성공하고 외부 상태가 정상인 경우에만 점검 모드를 해제한다.
