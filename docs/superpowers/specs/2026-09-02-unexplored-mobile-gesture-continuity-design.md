# 모바일 개척 노드 지도 제스처 연속성 설계

## 문제

개척 노드 지도는 노드 탭을 보존하기 위해 포인터 캡처를 드래그 임계값을 넘긴 첫 `pointermove`까지 늦춘다. 모바일 브라우저는 캡처되기 전 포인터를 네이티브 제스처로 전환하거나 대상 밖으로 이동시키며 스트림을 취소할 수 있어, 첫 이동만 반영되고 이후 드래그·핀치가 끊길 수 있다.

## 설계

`pointerdown`에서 바깥 지도 컨테이너가 아니라 실제로 눌린 원본 `Element`가 해당 포인터를 즉시 캡처한다. 포인터별 캡처 대상을 저장하고 종료·취소·캡처 상실 시 같은 대상에서 해제 및 정리한다.

원본 노드가 캡처를 유지하므로 짧은 탭의 `pointerup`과 후속 클릭 대상도 노드로 남는다. 동시에 포인터 이동 이벤트는 지도 컨테이너까지 버블링하므로 기존 이동·핀치 계산을 그대로 연속 적용할 수 있다. 드래그 임계값과 클릭 억제 동작은 유지한다.

## 대안 검토

- 지도 컨테이너가 즉시 캡처: 연속성은 확보되지만 노드 클릭이 컨테이너로 재대상화되는 기존 회귀가 다시 발생한다.
- 별도 `touchstart`/`touchmove` 구현: 모바일 제어는 가능하지만 Pointer Events 경로와 상태가 중복되고 마우스·펜·터치 간 동작 차이가 커진다.
- 원본 대상 즉시 캡처: 하나의 Pointer Events 경로로 노드 탭과 연속 제스처를 함께 보존하므로 채택한다.

## 검증

- 노드에서 시작한 포인터가 원본 노드에 즉시 캡처되는지 확인한다.
- 캡처된 단일 터치의 연속 이동이 모두 누적되는지 확인한다.
- 두 터치의 연속 이동으로 배율이 매 이동마다 갱신되는지 확인한다.
- 단순 노드 탭이 계속 선택 이벤트를 발생시키는지 확인한다.
- 컴포넌트 회귀 테스트, 타입 검사, 린트를 실행한다.

## 범위

개척 노드 지도 입력 처리와 해당 회귀 테스트만 변경한다. 배율 제한, 버튼 단위, 지도 좌표계, 노드 데이터 및 서버 API는 변경하지 않는다.
