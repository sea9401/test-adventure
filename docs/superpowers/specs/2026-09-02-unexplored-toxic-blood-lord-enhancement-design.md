# 미개척지 독혈 군주 강화 설계

## 목표

독혈 군주가 독혈 기믹을 충분히 전개하도록 행동 빈도와 내구도를 소폭 높인다. 기믹의 피해량이나 누적 규칙은 바꾸지 않아 기존 공략법은 유지한다.

## 변경 사항

### 행동 속도

- 몬스터 원시 속도를 `23`에서 `52`로 변경한다.
- 화면에 표시되는 행동 속도는 `148`에서 `322`가 된다.
- 실제 행동 간격은 `66틱`에서 `45틱`이 된다.
- 3,000틱 전투 기준 이론상 행동 횟수는 약 45회에서 약 66회로 증가한다.

### 방어 능력치

- 원시 물리 방어력을 `40`에서 `44`로 변경한다.
- 원시 마법 방어력을 `42`에서 `46`으로 변경한다.
- 깊이 120 보스 스케일 적용 후 물리 방어력은 `1,737`에서 `1,910`으로 증가한다.
- 같은 조건에서 마법 방어력은 `1,823`에서 `1,997`로 증가한다.

## 유지 사항

- 최대 체력 32,400,000과 공격력은 유지한다.
- 플레이어 방어력 35% 관통과 보스 방어력 35% 취약 규칙은 유지한다.
- 맹독 파쇄, 분쇄 일격, 독혈 파열의 계수·마나·재사용 대기시간·발동 조건은 유지한다.
- 독혈 누적량, 중첩당 최대 체력 0.5% 지속 피해, 10중첩 폭발 피해 20%, 회복 감소 효과는 유지한다.
- 보호막, 마력 장벽, 상태 피해 감소와의 기존 상호작용은 유지한다.
- 다른 미개척지 보스와 일반 사냥터 몬스터의 능력치는 변경하지 않는다.

## 구현 범위

독혈 군주 정의의 `spd`, `def`, `magicDef` 세 능력치와 특성 안내 문구만 변경한다. 공용 속도 공식이나 전투 엔진은 수정하지 않는다. 보스 특성 안내에는 실제 행동 간격을 반영해 `45틱마다 빠른 행동`을 추가한다.

## 검증

- 데이터 회귀 테스트에서 원시 속도 `52`, 표시 속도 `322`, 행동 간격 `45틱`을 고정한다.
- 깊이 120 스케일 결과가 물리 방어력 `1,910`, 마법 방어력 `1,997`인지 검증한다.
- 독혈 누적·폭발·회복 감소 관련 기존 테스트를 실행해 기믹이 바뀌지 않았음을 확인한다.
- 전체 타입 검사와 관련 린트를 실행한다.

## 배포 범위

구현 후 별도의 명시적 요청이 있을 때만 테스트 서버에 배포한다. 본 서버와 `main`, 점검 모드는 변경하지 않는다.
