# 쿠키 피드백 편의성·밸런스 보강 설계

## 목표

쿠키님의 다섯 가지 피드백을 현재 게임의 저장 형식과 UI 흐름을 유지하면서 반영한다. 스킬 패턴 프리셋은 명시적인 덮어쓰기 동작을 제공하고, 폭풍 원정 일괄 진행은 위험 이벤트별 정책과 진행 중 시작을 지원한다. 모바일 낚시 입질 진동의 인지성을 높이고, 별의 무덤 최심부의 전체 장비 획득 기회를 천공 균열 최심부와 맞추며, 전문 제작과 전투 로그의 누락된 선택·종료 동작을 보강한다.

## 1. 스킬 패턴 프리셋 덮어쓰기

- 각 저장 프리셋 행에 스킬 프리셋과 같은 회전 화살표 덮어쓰기 버튼을 표시한다.
- 버튼은 현재 편집 중인 패턴으로 해당 프리셋을 교체한다.
- 공용 `confirmPresetOverwrite` 확인창을 사용하며 취소 시 저장 요청을 보내지 않는다.
- 성공 메시지는 대상 이름과 덮어쓰기 완료를 명시한다.
- 기존의 같은 이름 저장 동작은 호환성을 위해 유지한다.

## 2. 폭풍 원정 위험 이벤트와 진행 중 일괄 진행

- 일괄 진행 계획에 위험 이벤트 4종 각각의 `accept`/`decline` 결정을 선택적으로 저장한다.
- 저장값이 없는 기존 계획은 모두 `decline`으로 해석하여 현재 안전 기본값을 유지한다.
- 설정 창에는 이벤트 이름, 이익, 대가와 수락/지나치기 선택을 표시한다.
- 자동 실행기는 현재 발생한 이벤트 ID의 설정을 사용한다.
- 직접 진행 중이고 자동 실행이 유휴 상태일 때도 `남은 구간 일괄 진행 설정` 버튼을 표시한다.
- 설정을 열 때 이미 방문한 외곽·중층·수호자 항로는 현재 경로로 계획에 고정하고, 아직 방문하지 않은 구간만 바꿀 수 있게 한다.

## 3. 모바일 낚시 입질 진동

- 현재의 35ms 단발 진동을 두 번 구분되는 짧은 패턴으로 바꿔 기기 진동 모터가 인지할 시간을 확보한다.
- 브라우저가 Vibration API를 지원하지 않거나 호출을 거부해도 낚시 진행에는 영향을 주지 않는다.
- 진동은 입질 시점에 한 번만 요청하고 추가 타이머나 서버 요청은 만들지 않는다.

## 4. 별의 무덤 최심부 드랍 보정

- 천공 균열 최심부에는 일반 방어구 0.10%, 전용 무기 0.05%, 시그니처 0.0025%의 독립 기회가 있다.
- 별의 무덤 최심부에는 별도 무기 경로가 없으므로 84단계 일반 방어구 확률을 0.10%에서 0.15%로 높인다.
- 별의 무덤의 기존 시그니처 확률 0.0035%와 다른 단계 확률은 유지한다.

## 5. 전문 제작 설정과 전투 로그 종료

- 아이템의 조정 가능한 양수 옵션이 한 성향에 모두 속한 경우에도 해당 성향을 선택할 수 있게 한다. 이 경우 기본 성능과 옵션 품질 사이에서 우선순위를 재배분한다.
- 무기의 방어 옵션, 방어구의 공격 옵션, 장신구의 저항 옵션처럼 슬롯의 일반 성향 밖에 있는 특수 옵션도 대응하는 성향 선택지를 제공한다.
- 조정 가능한 보조 옵션이 전혀 없는 아이템은 빈 선택 상자 대신 적용 가능한 옵션 성향이 없다는 설명을 표시한다.
- 공용 전투 로그 페이지와 허수아비 전체 로그 모달의 본문 아래에 명시적인 닫기/이전 화면 버튼을 추가한다.

## 접근성·표면

- 새 버튼은 구체적인 `aria-label`과 최소 터치 높이를 가진다.
- 원정 설정과 전문 제작의 중첩 패널은 기존 `SURFACE_CARD`, `SURFACE_INSET`, `SURFACE_ACCENT`만 사용한다.
- 하단 로그 버튼은 키보드로 접근 가능하고 상단 뒤로가기와 동일한 콜백을 호출한다.

## 테스트

- 패턴 프리셋: 명시적 덮어쓰기 확인·저장 요청·성공 메시지를 검증한다.
- 폭풍 원정: 기존 계획의 안전 기본값, 이벤트별 결정, 진행 경로와 계획 정합성, 설정 UI를 검증한다.
- 낚시: 지원·미지원 브라우저에서 햅틱 요청과 무해한 실패를 검증한다.
- 드랍률: 84단계만 0.15%이고 83단계와 천공 균열 곡선은 유지되는지 검증한다.
- 전문 제작: 기존에 비어 있던 대표 특수 장비에 의미 있는 성향이 노출되고 단일 성향 적용이 실제 굴림을 바꾸는지 검증한다.
- 로그: 공용 페이지와 허수아비 모달에서 본문 뒤 하단 닫기 동작을 검증한다.

## 제외 범위

- 위험 이벤트의 서버 규칙과 이벤트 보상·대가는 바꾸지 않는다.
- 천공 균열 무기 드랍과 시그니처 유니크 확률은 바꾸지 않는다.
- 진동 미지원 기기에 소리나 알림 권한을 추가하지 않는다.
- 데이터베이스 스키마를 변경하지 않는다.
- 배포하지 않는다.
