# 게임 등급표시 설계

## 목표

게임콘텐츠등급분류위원회가 2026년 9월 3일 결정한 `12세이용가` 등급과
`폭력성` 내용정보를 웹게임의 최초 화면과 상시 확인 화면에 정확히 표시한다.

## 확정 정보

- 게임명: 무슨무슨게임
- 상호: 무슨게임
- 플랫폼/장르: PC/온라인 게임 / 롤플레잉
- 이용등급: 12세이용가
- 등급분류번호: `GC-CC-NP-260903-001`
- 제작연월일: `2026.08.07`
- 등급결정일: `2026.09.03`
- 게임물제작업 등록번호: `제2026-000005호`
- 게임물배급업 등록번호: `제2026-000001호`
- 내용정보: 폭력성
- 결정사유: 전투·생활 콘텐츠를 통해 캐릭터를 성장시키는 어드벤처 RPG로,
  무기와 붉은 선혈이 표현된 일러스트에 경미한 폭력 표현이 있음

## 접근 방식

### 채택: 최초 진입 고지와 상시 게임정보 페이지

루트 레이아웃에 작은 클라이언트 컴포넌트를 두고 실제 게임 진입 경로에서 최초 한 번만
3.5초 동안 등급 고지를 표시한다. 루트 레이아웃은 클라이언트 내비게이션 동안 유지되므로
화면을 이동할 때마다 고지가 반복되지 않는다. `/game-info`에는 같은 단일 정보 소스를
사용하는 공개 상세 페이지를 두고 대문 푸터와 인게임 메뉴에서 연결한다.

### 제외한 방식

- 대문에만 표시: 인증된 사용자의 딥링크·설치 앱 직접 진입을 놓친다.
- 매시간 강제 팝업: 상시 확인 경로를 제공할 수 있는데도 플레이를 방해한다.

## 구성

### 단일 정보 소스

`src/lib/gameRating.ts`가 등급결정 정보, 공식 이미지 경로, 최초 고지 지속시간과
게임 진입 경로 판별을 소유한다. 화면 컴포넌트는 값을 중복 작성하지 않는다.

### 최초 고지

`GameRatingLaunchNotice`는 실제 게임 경로(`/`, `/sign-in`, `/create` 및 게임 라우트
그룹의 공개 URL)에 처음 진입했을 때만 표시한다. 불투명 검정 배경이 전체 화면을 가리고,
공식 12세이용가 표시는 우측 상단에 둔다. 중앙 불투명 카드에는 다음 내용을 표시한다.

- `12세 미만은 이용할 수 없습니다.`
- 공식 폭력성 내용정보 표시
- 게임명, 상호, 등급분류번호, 제작연월일
- 제작업·배급업 등록번호

표시는 3.5초 뒤 자동으로 사라지며 건너뛰기 기능을 두지 않는다. 설치 앱의 기존 0.24초
전환 스플래시와 겹쳐도 법정 고지가 3초 이상 실제 노출되도록 3초보다 여유 있게 유지한다.

관리자·개발·정책·공개 프로필·게임정보 같은 비게임 경로를 직접 열 때는 고지를 띄우지 않는다.

### 상시 확인

`/game-info`는 로그인 없이 접근 가능한 정적 페이지다. 확정 정보, 폭력성 내용정보와
등급결정 사유를 표시하고 게임콘텐츠등급분류위원회의 결정 확인 페이지를 연결한다.
대문 푸터와 인게임 햄버거 메뉴에 `게임 등급정보` 링크를 추가한다. 인게임 링크는 새 탭으로
열어 현재 게임 상태를 보존한다.

## 공식 이미지와 권리 기록

게임콘텐츠등급분류위원회가 공개한 다음 표시를 로컬 WebP 자산으로 보관한다.

- `https://www.gcrb.or.kr/images/grade_icon/icon_over12.gif`
- `https://www.gcrb.or.kr/images/grade_icon/grade2.gif`

`public/images/rating/`을 새 이미지 카테고리로 만들고 최적화 프로필과 자산 권리 원장에
공식 출처를 기록한다. 런타임에서 외부 사이트에 핫링크하지 않는다.

## 오류와 접근성

- 이미지에는 의미가 중복되지 않는 한국어 대체 텍스트를 제공한다.
- 최초 고지는 `role="dialog"`, `aria-modal="true"`와 명확한 레이블을 사용한다.
- 고지와 상세 페이지의 표면은 불투명하게 유지한다.
- JavaScript가 실행되지 않는 경우에도 `/game-info`의 서버 렌더 HTML에서 전체 정보를
  확인할 수 있다.

## 검증

- 경로 판별과 고지 시간은 가짜 타이머를 사용한 컴포넌트 테스트로 검증한다.
- 최초 고지와 상세 페이지가 확정된 등급·번호·폭력성·등록번호를 렌더하는지 검증한다.
- 대문과 인게임 메뉴에 상시 링크가 있는지 검증한다.
- 이미지 참조, 자산 권리 원장, TypeScript, ESLint, 전체 Vitest와 프로덕션 빌드를 실행한다.

## 범위 밖

- 등급분류 내용수정 신고
- 운영 배포, 점검 모드 변경, 기능 플래그 변경
