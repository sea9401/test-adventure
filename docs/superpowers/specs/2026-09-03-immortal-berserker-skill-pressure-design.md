# 불멸의 광전왕 기본 스킬 압박 보강 설계

## 목표

불멸의 광전왕이 포효와 평타만 반복하지 않고 방어력으로 줄일 수 있는 강한 물리 스킬을
섞어 사용하게 한다. 이미 구현된 세 생명, 부활, 재생과 광폭이 핵심 기믹이므로 새 자원이나
즉시 반격은 추가하지 않는다.

## 현재 상태

- 공유 HP는 `32,400,000`이며 세 생명을 `33% · 33% · 34%`로 나눈다.
- 생명 경계의 초과 피해와 같은 행동의 남은 후속타를 차단한다.
- 첫째·둘째 생명은 제한 횟수만큼 재생하며, 부활할수록 공격력과 속도가 오른다.
- 기본 공격 외에 세 번째 보스 행동마다 `광란 참격`을 사용한다.
- 몬스터 V2 스킬은 `포효` 하나뿐이어서 스킬 발동 행동이 공격 없이 버프로 끝난다.
- 미개척지 공통 공격력 상향 뒤 오프라인 대표 계보 시뮬레이션은 이미 매우 치명적이므로
  기본 공격력과 광폭 배율을 더 올릴 근거가 없다.

## 변경 사항

불멸의 광전왕의 몬스터 V2 스킬에 `mob_crushing_blow`를 추가한다.

- 장착 순서는 `포효`, `분쇄 일격`로 둔다.
- 포효가 사용 가능하면 먼저 포효하고, 포효의 재사용 대기시간 동안 분쇄 일격이 발동
  후보가 된다.
- 분쇄 일격은 기존 몬스터 공용 정의를 그대로 사용한다: MP 30, 재사용 대기시간 2행동,
  발동률 60%, 공격력 계수 1.8과 고정 피해 40.
- 스킬이 발동하지 않거나 MP가 소진되면 기존 평타와 `광란 참격`으로 돌아간다.
- 공유 보스 MP 최대치와 공격 사이 MP 소진·공략 규칙은 바꾸지 않는다.

목록의 특성 설명은 `포효·분쇄 일격과 광란 참격`을 명시해 실제 공격 구성을 미리 알 수
있게 한다.

## 유지 사항

- 공유 HP와 `33% · 33% · 34%` 생명 배분
- 두 번 부활과 생명 경계 초과 피해·후속타 차단
- 생명별 재생 주기·횟수·회복량
- 생명별 공격력·속도 광폭 배율
- 기본 공격력, 방어력, 마법 방어력, 속도, 명중과 회피
- `광란 참격` 주기와 배율
- 소환 비용, 보상, 업적, 상태 저장과 UI
- 다른 미개척지 보스와 공용 몬스터 스킬 정의

## 검증

- 카탈로그 테스트에서 `포효`, `분쇄 일격` 장착 순서와 기존 MP를 고정한다.
- ATB 테스트에서 충분한 MP와 결정된 난수 아래 포효 뒤 분쇄 일격이 실제 적 행동으로
  발동하고, 두 행동 모두 평타와 중복되지 않는지 확인한다.
- 방어력이 높은 대상이 낮은 대상보다 분쇄 일격 피해를 적게 받아 방어 투자가 유효한지
  검증한다.
- 부활·재생·광폭과 생명 경계 차단 회귀 테스트를 함께 실행한다.
- 타입 검사와 변경 파일 린트를 실행한다.

## 배포 범위

로컬 구현·검증·커밋까지만 수행한다. 사용자가 별도로 배포를 요청하기 전에는 테스트
서버와 운영 서버를 변경하지 않는다.
