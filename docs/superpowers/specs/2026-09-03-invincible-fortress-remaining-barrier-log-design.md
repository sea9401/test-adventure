# 불괴의 성채 방벽 잔량 전투 로그 설계

## 목표

플레이어의 피해가 불괴의 성채 방벽에 적용될 때마다, 해당 피해로 줄어든 뒤의 방벽 잔량을 같은 전투 로그에서 바로 확인할 수 있게 한다.

## 확정 표시 방식

- 기존 `방벽 누적 피해` 로그를 새 로그로 추가하지 않고 같은 한 줄에서 교체한다.
- 형식은 `방벽 피해 +{적용 피해} · 남은 {잔량} / 3,000,000`으로 통일한다.
- `{적용 피해}`는 해당 피해 처리에서 방벽이 실제로 흡수한 수치다.
- `{잔량}`은 그 피해가 적용된 직후의 `3,000,000 - 누적 방벽 피해`이며 0 미만으로 내려가지 않는다.
- 숫자는 기존 전투 로그와 동일하게 한국어 로케일 천 단위 구분 기호를 사용한다.

예시:

```text
방벽 피해 +100,000 · 남은 2,900,000 / 3,000,000
```

## 피해와 파괴 처리

- 방벽에 피해가 적용된 이벤트마다 잔량 로그를 한 번 기록한다.
- 다단 공격이 별개의 방벽 피해 이벤트를 만들면 각 이벤트 뒤의 잔량을 순서대로 기록한다.
- 방벽을 파괴하는 피해에는 `남은 0 / 3,000,000`을 표시한다.
- 파괴 피해 로그 다음에는 기존 `방벽 파괴 — 누적 3,000,000`과 `광폭 0단계 적용` 로그를 그대로 유지한다.
- 파괴 타격의 초과 피해와 이후 타격이 본체에 적용되는 기존 전투 규칙은 변경하지 않는다.
- 본체에만 들어간 피해에는 방벽 잔량 로그를 추가하지 않는다.

## 구현 범위

- 방벽 피해 이벤트가 이미 제공하는 `totalDamage`와 고정 방벽 내구도 상수를 이용해 전투 로그 문자열에서 잔량을 계산한다.
- 방벽 상태 구조, 피해 정산, 저장 데이터, API 응답, 협동 보스 상태 화면은 변경하지 않는다.
- 플레이어 공격 외의 기존 방벽 피해 이벤트가 같은 로그 생성 경로를 사용하더라도 잔량 계산은 동일하게 정확해야 한다.

## 검증

- 첫 100,000 피해 뒤 `남은 2,900,000 / 3,000,000`이 표시되는지 검증한다.
- 누적 피해가 있는 방벽에 추가 피해를 주면 적용 후 잔량이 정확한지 검증한다.
- 파괴 피해에 `남은 0 / 3,000,000`이 표시되고 기존 파괴·광폭 로그가 유지되는지 검증한다.
- 방벽 피해가 아닌 본체 피해에는 잔량 로그가 생기지 않는지 검증한다.
- 관련 불괴의 성채 전투와 방벽 정산 회귀 테스트를 통과시킨다.

## 배포 범위

구현과 로컬 검증, 커밋까지만 수행한다. 사용자가 별도로 요청하기 전에는 테스트 서버와 본 서버 어느 환경에도 배포하지 않는다.
