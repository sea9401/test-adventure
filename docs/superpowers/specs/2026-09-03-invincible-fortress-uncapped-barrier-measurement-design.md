# 불멸의 요새 방벽 실제 피해 측정 설계

## 목표

불멸의 요새의 400틱 방벽 시험에서 목표치를 넘긴 피해도 실제 누적량으로 기록하고 표시해, 빌드별 순간 화력을 확인할 수 있게 한다. 방벽이 유지되는 시간과 본체 피해 차단, 광폭 판정 기준은 변경하지 않는다.

## 현재 동작

- 전투 시작과 본체 체력 75%, 50%, 25% 경계에서 마력 방벽 시험이 시작된다.
- 방벽 시험은 목표 달성 여부와 관계없이 400틱 동안 유지된다.
- 방벽이 활성화된 동안 받은 피해는 본체 체력을 줄이지 않는다.
- 누적 피해는 목표치까지만 저장되어, 목표를 넘긴 빌드의 실제 400틱 피해량을 확인할 수 없다.
- 목표치 이상이면 다음 구간의 광폭 단계는 0단계가 된다.

## 변경 사항

### 실제 누적 피해 보존

- 활성 방벽이 받은 최종 피해를 목표치에서 자르지 않고 모두 `barrierDamage`에 누적한다.
- 본체 체력 경계에 도달시킨 공격의 초과 피해도 전부 방벽 누적 피해로 기록한다.
- 안전하지 않은 숫자가 저장 상태에 들어가지 않도록 누적값은 0 이상 `Number.MAX_SAFE_INTEGER` 이하의 정수로 정규화한다.
- 기존 `barrierDamage` 필드와 저장 구조는 유지한다.

### 전투 규칙 유지

- 목표치를 일찍 달성해도 방벽은 즉시 파괴되지 않는다.
- 방벽은 반드시 400틱이 끝날 때까지 유지되며, 그동안 본체 피해는 계속 0이다.
- 목표치와 광폭 단계별 판정 기준은 바꾸지 않는다.
- 목표치를 넘긴 모든 누적 피해는 기존과 동일하게 광폭 0단계로 판정한다.
- 본체 체력 경계를 넘긴 피해가 다음 체력 구간으로 관통하지 않는 규칙도 유지한다.

### 로그와 화면

- 전투 중 방벽 누적 로그와 400틱 종료 로그에 실제 누적 피해를 표시한다.
- 협동 보스 상태의 수치도 `실제 누적 피해 / 목표 피해` 형식으로 표시한다.
- 진행 막대는 실제 피해가 목표를 넘겨도 시각적으로 100%까지만 채운다.
- 접근성 진행값은 목표치를 넘지 않게 제한하고, 초과분은 화면의 실제 수치로 확인하게 한다.

## 구현 구조

- `invincibleFortressMechanic.ts`에서 활성 방벽 및 체력 경계 초과 피해의 목표치 상한을 제거한다.
- 저장 상태 정규화는 목표치가 아니라 `Number.MAX_SAFE_INTEGER`를 상한으로 사용한다.
- `InvincibleFortressStatus.tsx`는 표시용 실제 피해와 진행 막대용 제한 피해를 분리한다.
- 전투 엔진의 기존 로그 생성 코드는 상태의 누적값을 그대로 사용하므로 별도의 로그 형식 변경은 하지 않는다.

## 검증

- 목표치를 넘긴 한 번의 공격이 전량 기록되고 본체 HP는 감소하지 않는지 검증한다.
- 체력 경계를 넘긴 공격의 초과분이 전량 기록되면서 본체 HP는 경계에서 멈추는지 검증한다.
- 목표 초과 저장 상태가 유효하게 복원되는지 검증한다.
- 실제 누적 피해가 목표를 넘겨도 광폭 0단계 판정이 유지되는지 검증한다.
- 400틱 종료 로그와 협동 보스 상태 화면이 목표 초과 실제 피해를 표시하는지 검증한다.
- 화면 진행 막대와 접근성 값은 100%를 넘지 않는지 검증한다.

## 배포 범위

구현과 로컬 검증, 커밋까지만 수행한다. 별도의 명시적 요청 전에는 테스트 서버와 본 서버 어느 환경에도 배포하지 않는다.
