# 불멸의 요새 300만 방벽 즉시 파괴 설계

## 목표

불멸의 요새의 마력 방벽을 300만 내구도의 실제 방벽으로 바꾼다. 제한 시간 안에 방벽을 파괴한 빌드는 400틱이 끝날 때까지 기다리지 않고 즉시 본체를 공격할 수 있어야 한다.

## 확정 규칙

- 전투 시작과 본체 체력 75%, 50%, 25% 경계에서 총 네 번 마력 방벽이 생성된다.
- 각 방벽의 내구도는 고정 `3,000,000`이다.
- 방벽은 최대 `400틱` 동안 유지된다.
- 누적 피해가 300만에 도달하면 해당 방벽을 즉시 파괴하고 광폭 `0단계`를 적용한다.
- 방벽을 파괴한 공격의 초과 피해는 같은 피해 처리 안에서 본체에 즉시 적용한다.
- 다중 타격 행동의 남은 타격도 본체에 적용한다.
- 초과 피해가 다음 체력 경계에 도달하면 다음 방벽을 생성한다. 그 초과 피해로 다음 방벽까지 파괴할 수 있으며, 체력 경계나 방벽을 건너뛰지는 않는다.
- 400틱 동안 파괴하지 못하면 그 시점까지의 누적 피해 비율로 기존 광폭 1~4단계를 적용하고 방벽을 종료한다.
- 방벽이 종료되면 보스도 방벽 종료 시점부터 정상 행동 간격으로 행동을 다시 예약한다.

## 광폭 판정

- 300만 이상: 0단계, 즉시 파괴
- 225만 이상 300만 미만: 1단계
- 150만 이상 225만 미만: 2단계
- 75만 이상 150만 미만: 3단계
- 75만 미만: 4단계

광폭 배율은 기존 단계별 공격·속도 배율을 그대로 사용한다.

## 피해 처리

피해 정산은 한 번의 입력 피해를 다음 순서로 소비한다.

1. 활성 방벽이 있으면 남은 내구도만큼 방벽 피해로 소비한다.
2. 방벽 내구도가 0이 되면 방벽을 완료 처리하고 남은 피해를 본체로 넘긴다.
3. 본체 피해는 다음 방벽 체력 경계까지만 적용한다.
4. 경계에 도달하면 다음 방벽을 생성하고 남은 피해를 다시 방벽에 적용한다.
5. 네 번째 방벽까지 완료했다면 남은 피해를 본체에 제한 없이 적용한다.

이 순환으로 큰 단일 피해도 각 방벽 300만을 반드시 소비하면서 초과 피해를 잃지 않는다. 피해량 계산은 0 이상 `Number.MAX_SAFE_INTEGER` 이하의 정수로 제한한다.

## 상태와 로그

- 기존 `barrierDamage`, `completedBarrierCount`, `barrierResults` 저장 필드는 유지한다.
- 진행 중인 `barrierDamage`는 0~300만 범위로 정규화한다. 과거 버전에서 300만을 넘는 누적값이 저장되어 있으면 300만으로 제한해 다음 피해 시 정상적으로 완료할 수 있게 한다.
- 피해 로그는 실제로 각 방벽이 흡수한 피해와 해당 방벽의 누적값을 표시한다.
- 조기 파괴 시 `방벽 파괴 — 누적 3,000,000`과 `광폭 0단계 적용`을 기록한다.
- 시간 만료 시 기존 `방벽 시험 종료 — 누적 N`과 판정된 광폭 단계를 기록한다.
- 상태 화면은 `현재 방벽 피해 / 3,000,000`과 남은 시험 시간을 표시한다.

## 구현 구조

- `invincibleFortressMechanic.ts`가 고정 방벽 내구도, 연속 방벽·본체 피해 소비, 조기 완료 이벤트를 순수하게 계산한다.
- 피해 정산 결과에 순서가 보존된 방벽 시작·피해·파괴 이벤트를 포함해 한 번의 큰 피해에서 발생한 여러 방벽 로그도 정확히 만든다.
- `engine.atb.ts`는 이 이벤트를 전투 로그에 반영하고, 조기 파괴 후 보스 행동 틱을 다시 예약한다.
- 협동 보스 상태와 리플레이 자원 스냅샷은 기존 필드를 통해 고정 300만 목표를 표시한다.

## 검증

- 300만 미만 피해는 본체 HP를 줄이지 않고 방벽에만 누적되는지 검증한다.
- 정확히 300만 피해로 방벽이 즉시 종료되는지 검증한다.
- 350만 피해가 방벽 300만을 파괴하고 본체에 50만을 적용하는지 검증한다.
- 큰 피해가 본체 체력 경계와 다음 방벽을 순서대로 소비하는지 검증한다.
- 같은 다중 타격 행동의 첫 타격이 방벽을 깨면 남은 타격이 본체에 들어가는지 검증한다.
- 조기 파괴 이후 보스가 400틱까지 멈춰 있지 않고 정상 행동을 재개하는지 검증한다.
- 400틱 미파괴 시 누적 비율에 맞는 기존 광폭 단계가 적용되는지 검증한다.
- 상태 화면과 리플레이 스냅샷이 300만 목표를 표시하는지 검증한다.

## 배포 범위

구현과 로컬 검증, 커밋까지만 수행한다. 별도의 명시적 요청 전에는 테스트 서버와 본 서버 어느 환경에도 배포하지 않는다.
