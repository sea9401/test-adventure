# 게임 등급 고지 반복 노출 개선 설계

## 목표

온라인게임의 최초 화면 등급 고지 요건은 유지하면서, 같은 탭에서 새로고침할 때마다
3.5초 동안 전체 화면이 가려지는 불편을 없앤다.

## 사용자 경험

- 앱 또는 새 브라우저 탭에서 게임 경로에 처음 진입하면 등급 고지를 3.5초 표시한다.
- 같은 탭에서 새로고침하거나 다시 게임 경로로 이동하면 고지를 반복하지 않는다.
- 최초 고지는 화면을 가리는 검은 배경과 포커스 잠금을 사용하지 않는다.
- 고지는 우측 상단의 불투명 패널에 배치하고 최소 화면 높이의 25%를 확보한다.
- 패널에는 `12세이용가`, `12세 미만은 이용할 수 없습니다.`, `폭력성` 내용정보를
  공식 이미지와 함께 표시한다.
- 기존 `/game-info` 상세 페이지와 로그인 화면·게임 메뉴의 상시 링크는 유지한다.

## 상태 관리

노출 여부는 버전이 포함된 `sessionStorage` 키에 저장한다. `sessionStorage`는 같은 탭의
새로고침에서는 유지되지만 새 탭에서는 분리되므로, 반복 새로고침을 막으면서 새로운 게임
진입에는 고지를 다시 표시할 수 있다. 저장소 접근이 차단된 환경에서는 고지를 표시하는
보수적인 동작으로 되돌아간다.

첫 서버 렌더에서 고지가 잠깐 보였다가 사라지는 현상을 막기 위해 루트 레이아웃의 초기화
스크립트가 저장된 키를 확인해 문서 루트에 숨김 클래스를 붙인다. 이 클래스는 CSS에서
고지 컴포넌트만 숨기며 게임 콘텐츠에는 영향을 주지 않는다. 클라이언트 컴포넌트도 같은
키를 확인하므로 접근성 트리와 React 상태에서도 고지가 제거된다.

## 접근성 및 표면

고지는 사용자 입력을 막는 모달이 아니므로 `role="status"`로 알리고 포커스를 이동하거나
Tab 키를 가로채지 않는다. 패널은 `SURFACE_CARD`를 사용해 라이트·다크 모드 모두에서
배경 그림이 비치지 않게 한다. 바깥 래퍼는 포인터 이벤트를 받지 않아 즉시 게임을 사용할
수 있다.

## 검증

- 첫 게임 진입에서 3.5초 동안 필수 등급·연령·내용정보가 표시되는지 검증한다.
- 같은 탭의 두 번째 마운트에서는 표시되지 않는지 검증한다.
- 정책 페이지에서 게임으로 이동할 때 최초 한 번만 표시되는지 검증한다.
- `sessionStorage` 접근 실패 시 고지가 계속 표시되는지 검증한다.
- 컴포넌트 테스트, 타입 검사, ESLint와 프로덕션 빌드를 실행한다.

## 범위 밖

- 등급분류 또는 연령 확인 정책 변경
- 운영 배포 및 점검 모드 변경
