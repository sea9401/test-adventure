# 불멸의 광전왕 부활 광폭 강화 설계

## 목표

불멸의 광전왕이 부활할 때마다 공격적인 체급이 확실히 높아지도록 광폭 배율을 강화한다.
특히 재생이 사라지는 마지막 생명은 짧지만 매우 위협적인 마무리 구간이 되게 한다.

## 현재 상태

- 공유 HP는 `32,400,000`이며 세 생명을 `33% · 33% · 34%`로 나눈다.
- 첫째 생명은 공격력 `100%`, 속도 `100%`다.
- 둘째 생명은 공격력 `112%`, 속도 `106%`다.
- 셋째 생명은 공격력 `125%`, 속도 `112%`다.
- 첫째·둘째 생명은 제한 횟수만큼 재생하며, 셋째 생명에는 재생이 없다.
- 현재 깊이 120 기준 공격력은 약 `8,044`, 기본 행동 주기는 `45틱`이다.

## 확정 변경: 강경형

부활 단계별 공격력·속도 배율을 다음과 같이 변경한다.

| 생명 | 공격력 배율 | 속도 배율 | 예상 공격력 | 예상 행동 주기 |
| --- | ---: | ---: | ---: | ---: |
| 첫째 | `100%` | `100%` | 약 `8,044` | `45틱` |
| 둘째 | `120%` | `110%` | 약 `9,653` | `43틱` |
| 셋째 | `160%` | `125%` | 약 `12,870` | `40틱` |

예상 수치는 현재 깊이 120 보정값을 기준으로 한 반올림 표기다. 내부 계산에서는 기존처럼
배율을 적용한 실수 값을 사용한다.

셋째 생명은 재생을 잃는 대신 공격력이 첫째 생명보다 `60%`, 속도가 `25%` 높아진다.
따라서 포효가 적용된 셋째 생명의 공격력은 약 `16,088`, 방어력 0 기준 포효 후
`분쇄 일격` 원시 피해는 약 `28,998`이 된다.

## 유지 사항

- 공유 HP와 `33% · 33% · 34%` 생명 배분
- 두 번 부활과 생명 경계 초과 피해·같은 행동의 후속타 차단
- 첫째 생명 `4행동마다 427,680`, 최대 3회 재생
- 둘째 생명 `4행동마다 320,760`, 최대 2회 재생
- 셋째 생명 재생 없음
- `포효`, `분쇄 일격`, `광란 참격`의 효과·주기·선택 로직
- 기본 공격력, 방어력, 마법 방어력, 기본 속도, 명중과 회피
- 소환 비용, 보상, 업적, 상태 저장과 UI
- 다른 미개척지 보스와 공용 몬스터 스킬 정의

## 표시와 전투 로그

부활 시 기존 광폭 안내 형식을 유지하되 실제 배율에 맞춰 다음과 같이 표시한다.

- 둘째 생명: `공격 +20% · 속도 +10%`
- 셋째 생명: `공격 +60% · 속도 +25%`

## 검증

- 광폭 배율 단위 테스트에서 세 생명의 공격력·속도 배율을 정확히 고정한다.
- ATB 전투 테스트에서 부활 직후 실제 공격력과 행동 속도에 새 배율이 적용되는지 확인한다.
- 부활 안내가 `공격 +20% · 속도 +10%`, `공격 +60% · 속도 +25%`로 표시되는지 확인한다.
- 기본 상태의 `45틱` 행동 주기가 유지되는지 확인한다.
- 생명 배분, 재생, 초과 피해·후속타 차단, 스킬 사용 회귀 테스트를 실행한다.
- 타입 검사와 변경 파일 린트를 실행한다.

## 배포 범위

로컬 구현·검증·커밋까지만 수행한다. 사용자가 별도로 배포를 요청하기 전에는 테스트
서버와 운영 서버를 변경하지 않는다.
