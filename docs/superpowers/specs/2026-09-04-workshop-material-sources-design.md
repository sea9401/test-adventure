# 제작소 부족 재료 입수처 안내 설계

## 배경

모험가 협회 제작소는 부족한 개인 재료의 필요량과 보유량은 표시하지만, 해당 재료를 어디서 얻는지는 같은 제작 행에서 확인할 수 없다. 일부 입수처는 접힌 `제작 참고`에만 있으며 폭풍 원정 재료는 그 목록에서도 누락돼 있다.

## 목표

- 일반 제작과 명장 제작에서 부족한 재료마다 최소 한 곳의 입수처를 바로 표시한다.
- 벌목·채광, 필드 사냥, 특정 몬스터, 협동 보스, 폭풍 원정 재료를 모두 지원한다.
- 이동 가능한 콘텐츠에는 해당 화면 바로가기를 제공한다.
- 충분히 보유한 재료에는 입수처를 노출하지 않아 제작 행의 밀도를 유지한다.

## 설계

재료 ID를 입력받아 `label`과 선택적 `href`를 반환하는 순수 입수처 해석기를 제작소 모듈에 둔다. 기존 재료·드랍·지역 카탈로그를 조합하며 별도의 중복 입수처 표는 만들지 않는다.

입수처 표시는 제작 비용 아래의 작은 불투명 인셋 영역에 배치한다. 부족한 재료가 여러 개면 재료별로 한 줄씩 표시하고, 링크가 있는 경우 `이동` 링크를 제공한다. 알 수 없는 재료 ID는 잘못된 정보를 추측하지 않고 거래소 확인 안내로 대체한다.

콘텐츠별 연결은 다음과 같다.

- 벌목·채광: 실제 채집 지점 이름, `/character/life`
- 제작소 공용 재료: 실제 필드 사냥 깊이 구간, `/battle`
- 몬스터 전용 재료: 지역과 몬스터 이름, `/battle`
- 협동 보스 재료: 보스 이름, `/battle/coop`
- 폭풍 원정 항로 재료: 항로 이름, `/battle/storm-expedition`
- 미등록 재료: 거래소 확인, `/plaza/market`

## 테스트

- 순수 해석기 테스트로 각 재료 계열과 알 수 없는 ID의 안내를 고정한다.
- 모든 제작 레시피의 재료 ID가 실제 입수처로 해석되는지 전수 검사한다.
- 제작 패널 렌더링 테스트로 부족한 재료에만 입수처와 바로가기가 표시되는지 확인한다.
- 기존 제작 패널 및 제작 데이터 회귀 테스트를 함께 실행한다.

## 제외 범위

- 새로운 재료 도감이나 팝업은 만들지 않는다.
- 드랍률과 제작 비용은 변경하지 않는다.
- 배포·운영 반영은 수행하지 않는다.
