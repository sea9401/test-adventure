# 길드 토벌전 종료 후 연습 전투 설계

## 목표

길드 토벌전의 실전 기간이 끝난 뒤에도 해당 주차 보스를 상대로 연습 전투를 할 수 있게 한다. 실전 공격, 길드 진행도, 개인 기여도, 보상 자격, 최근 전투 기록에는 어떤 변화도 주지 않는다.

이 문서는 2026-09-04 연습 모드 설계의 “활성 전투 기간에만 연습” 제한을 대체한다. 나머지 읽기 전용 연습 규칙은 그대로 유지한다.

## 접근 방식

### 채택: 기존 읽기 전용 연습 경로의 기간 제한만 제거

- 현재 주차의 토벌 이벤트와 현재 길드가 존재하면 이벤트의 `status`, `endsAt`, 화면의 `phase`와 무관하게 연습을 허용한다.
- 클라이언트의 연습 버튼은 실전 활성 여부가 아니라 전투 요청 중 여부만으로 비활성화한다.
- 기존 `simulateGuildRaidBattle(..., lockForUpdate: false)` 경로를 그대로 사용해 DB 쓰기 없이 일회성 결과와 재생 로그만 반환한다.
- 일반 공격 버튼과 공격 API의 종료 판정은 변경하지 않는다.

이 방식은 서버와 UI에 중복된 차단 조건만 제거하므로 변경 폭이 작고, 이미 검증된 무소모·비기록 연습 경로를 유지한다.

### 대안 1: 종료 이벤트 전용 연습 API 추가

활성 이벤트와 종료 이벤트를 서로 다른 API로 나눌 수 있지만 전투 계산, 인증, 요청 제한, 오류 처리가 중복된다. 결과 동작도 같으므로 채택하지 않는다.

### 대안 2: 과거 주차와 보스를 선택하는 연습장 추가

이벤트 선택 UI와 과거 데이터 조회 정책이 필요해 이번 건의의 범위를 크게 넘어선다. 이번 변경은 화면에 표시되는 현재 주차 토벌 보스만 대상으로 한다.

## 세부 동작

- 실전 기간(`active`)에는 기존과 동일하게 실전 공격과 연습 전투를 모두 제공한다.
- 정산 중(`settling`)과 보상 수령 기간(`claim`)에도 연습 전투 버튼을 활성화한다.
- 현재 주차 이벤트가 없으면 `event_ended`를 반환한다. 길드 없음, 캐릭터 없음, 잘못된 보스 식별자도 기존 오류를 유지한다.
- 연습과 실전 공격은 기존 공용 in-flight 잠금을 유지해 동시에 시작하지 않는다.
- 연습 결과는 서버 응답과 화면 상태에만 존재하며 DB에 저장하지 않는다.
- 안내 문구와 게임 매뉴얼에 종료 뒤 이용 가능하다는 규칙을 명시한다.

## 테스트

- 서버 서비스: `settled` 상태이거나 `endsAt`이 지난 이벤트도 시뮬레이션을 실행하고 성공 결과를 반환한다.
- 서버 서비스: 이벤트 자체가 없는 경우는 계속 `event_ended`이고 시뮬레이션을 실행하지 않는다.
- UI: `settling`, `claim` 상태에서 연습 버튼이 활성화되고 클릭 콜백을 호출한다.
- UI: 종료 뒤에도 연습 가능하다는 안내를 표시하면서 일반 공격 버튼은 계속 비활성화한다.
- 매뉴얼: 실전 기간 종료 뒤에도 연습할 수 있으며 기록·보상에 반영되지 않는다고 안내한다.

## 제외 범위

- 일반 토벌 공격 가능 기간과 주간 정산·보상 규칙은 변경하지 않는다.
- 과거 주차 선택, 보스 선택, 연습 결과 저장 기능은 추가하지 않는다.
- 데이터베이스 스키마와 배포 설정은 변경하지 않는다.
- 배포와 점검 모드 전환은 수행하지 않는다.
