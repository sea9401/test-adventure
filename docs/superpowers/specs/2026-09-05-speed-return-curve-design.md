# 속도 투자 효율 곡선 개편 설계

## 목표

속도 100을 행동 간격 100틱의 기준점으로 만들고, 속도 1000까지 투자했을 때
행동 빈도가 약 4.5~5배가 되게 한다. 속도 1024 이후의 죽은 투자 구간을 없애되,
3000틱 전투에서 행동 처리량이 폭주하지 않도록 기술적 안전 한계는 유지한다.

## 행동률 곡선

속도 `s`는 최소 1로 보정하고 다음 세 구간으로 계산한다.

1. `s <= 100`: `rate = 100 × (s / 100)^0.5`
2. `100 < s <= 1000`: `rate = 100 × (s / 100)^p`,
   `p = log(4.8) / log(10)`
3. `1000 < s < 20000`: `rate = 480 × (s / 1000)^q`,
   `q = log(1000 / 480) / log(20)`
4. `s >= 20000`: `rate = 1000`

행동 간격은 기존처럼 `ceil(10000 / rate)`이다. 이에 따라 속도 100은 100틱,
속도 1000은 21틱으로 약 4.76배 자주 행동한다. 속도 20000부터는 최소 10틱이며,
3000틱 안에서 한 액터가 가질 수 있는 기본 행동 묶음은 시작 행동을 포함해 최대
301개다. 기존 `ATB_ACTION_GUARD = 1000`은 추가 안전장치로 유지한다.

속도 100 이하의 상대적인 제곱근 곡선과 몬스터 원시 속도 매핑은 유지한다.
절대 행동률은 기존의 80%가 되므로 속도 100 캐릭터와 일반 몬스터의 상대 행동비는
거의 같지만, 3000틱 동안 발생하는 저속 구간의 전체 행동 수는 줄어든다.

대표 행동 간격은 다음과 같다.

| 속도 | 행동 간격 |
| ---: | ---: |
| 64 | 125틱 |
| 100 | 100틱 |
| 200 | 63틱 |
| 400 | 39틱 |
| 800 | 25틱 |
| 1000 | 21틱 |
| 2000 | 18틱 |
| 4000 | 15틱 |
| 10000 | 12틱 |
| 20000 이상 | 10틱 |

## 전투력 점수

속도 1024 이하의 전투력 기여는 기존 `spd × 0.5`를 그대로 유지해 현재 순위와
던전 진입 기준의 급격한 변화를 막는다. 1024를 넘는 속도는 더 이상 버리지 않고,
1024 시점의 행동률 대비 현재 행동률 비율을 속도 등가값에 반영한다.

`effectivePowerSpd = 1024 × actionRate(spd) / actionRate(1024)`

이 식은 1024에서 연속이고, 속도 20000의 최대 행동률에서도 전투력 속도 기여가
무한히 커지지 않는다. 전투력 계산과 실제 행동률은 동일한 `actionRate` 함수를
사용한다.

## 성도 조준

천궁의 `성도 조준`은 기존 점근식을 유지하고 `spdToAtkMaxPct`만 30에서 20으로
조정한다.

`공격력 보너스 = 20 × spd / (spd + 500)`

- 속도 500: 공격력 +10%
- 속도 1000: 공격력 약 +13.3%
- 속도 2000: 공격력 +16%
- 속도가 무한히 높아질 때 +20%에 접근하며 정확히 도달하지는 않는다.

속도 1000 천궁은 공격력 전환 수치만 보면 기존 +20%에서 약 +13.3%로 낮아지지만,
행동 간격이 26틱에서 21틱으로 줄어 같은 속도의 현행 천궁보다 직접 공격 처리량이
약 16.9% 증가한다. 민첩·명중·치명타·스킬 치명타 피해 효과는 변경하지 않는다.

## UI와 문서

전투 공식 매뉴얼은 단일 멱 공식과 1024 상한 설명을 제거하고 세 구간의 의미,
속도 100/1000 기준점, 속도 20000의 10틱 기술적 안전 한계를 설명한다. 기존 전투
화면의 상대 행동 횟수 표시는 `actionInterval`을 사용하므로 별도 UI 계산을 만들지
않는다. 성도 조준 설명은 최대 20% 점근으로 자동 표시되는 기존 칩 생성을 유지한다.

## 검증

- `combatTimeline` 단위 테스트로 세 구간의 경계, 대표 행동 간격, 단조 증가,
  속도 20000 이후 10틱 고정을 검증한다.
- `power` 단위 테스트로 1024 이하 점수 보존, 초과 속도 반영, 최대 행동률 이후
  전투력 고정을 검증한다.
- `derivePlayerCombatV2`와 기술 카탈로그 테스트로 성도 조준 최대 20%와 속도 1000의
  약 13.3% 전환을 검증한다.
- PvE·PvP ATB 및 선공 테스트, 레벨 디자인 시뮬레이션, TypeScript, ESLint와 전체
  테스트를 실행한다.

## 범위 제외

- 몬스터 원시 속도 데이터와 깊이 보정은 이번 변경에서 재조정하지 않는다.
- 속도 버프·둔화·행동 지연 및 행동 횟수 기반 지속 효과 규칙은 바꾸지 않는다.
- 운영 배포와 점검 모드 변경은 수행하지 않는다.
