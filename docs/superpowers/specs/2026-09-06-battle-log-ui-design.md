# 전투 로그 UI — 승인 시안 v5

사용자가 승인한 `전투로그-상대우측정렬-개선시안-v5.png`를 실제 공용 로그 렌더러에 적용한다.

- 내 행동은 왼쪽, 상대 행동은 오른쪽 정렬한다. 이름·결과·효과·상세까지 같은 방향을 따른다.
- 스킬명과 총 피해를 같은 제목 영역에 둔다. 좁은 화면에서는 자연스럽게 줄바꿈한다.
- 지속 효과는 작은 배지로 표시한다. 원문에 기록된 효과, 대상, 수치, 행동 수를 보존한다. 과거 로그에는 매 행동의 상태 스냅샷이 없으므로 이후 잔여 행동 수를 추정하거나 시안의 예시 효과를 생성하지 않는다.
- 개별 타격과 추가 피해는 닫힌 `타격별 기록 보기` 안에 둔다. 방어 계산 상세는 보존한다.
- 명시적인 시전 경계를 끝까지 보존해 추가 효과가 끼어도 연타가 분리되지 않도록 한다. 별도 시전·기본 공격·다른 행동 주체·시간·HP 스냅샷 경계는 유지한다.
- 합산은 이미 기록된 피해만 사용한다. PvP 추격 로그는 방어 적용 전 값이므로 신규 로그에 실제 HP 피해 메타데이터를 추가하고, 메타데이터 없는 과거 PvP 추격은 총 피해에 추측 합산하지 않는다.
- 전투 공식·판정·밸런스는 변경하지 않는다. 새 의존성, 필터 기능, 스킬 카드 변경은 이번 전투 로그 작업 범위에 넣지 않는다.
- 불투명 공용 surface 토큰, 라이트·다크 모드, 모바일 가독성을 유지한다.

회귀 테스트와 실제 브라우저에서 모바일/데스크톱, 상세 펼치기, 정렬, 넘침을 검증한다. 로컬 커밋까지만 수행하며 푸시·통합·배포하지 않는다.
