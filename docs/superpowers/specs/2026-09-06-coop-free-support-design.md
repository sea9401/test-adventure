# 협동 보스 무료 토벌 지원

건의 #599 후속. 사용자가 승인한 소환자 선택 방식으로 구현한다.

- 소환 시 `allowFreeSupport`를 선택한다. 기본은 false이며 기존 세션과 낚시 소환도 false다.
- 활성 세션의 소환자는 상세 화면에서 언제든 허용/해제한다. 공개 범위와 독립이며 기존 접근 권한을 우회하지 않는다.
- 허용된 활성 세션에 일반 공격과 별도의 무료 지원 버튼을 제공한다. HP 비율 제한은 없다.
- `attack` 요청의 `support: true`는 스태미나 비용 0, 보상 기여 피해량 0, 처치 확정타 보상 없음이다. 기존 기여 피해량·보상 수령 상태는 보존한다.
- 일반 공격과 같은 전투·세션별 쿨다운·요청 제한을 사용한다. 지원도 공유 HP/MP 및 기믹에 반영하며 처치 시 기존 기여자 보상/알림 흐름을 유지한다.
- 세션 행 잠금 이후 지원 허용을 재검증하여 동시 해제와 직렬화한다. 소유권과 종료 여부 역시 잠금 후 확인한다.
- contributor 행은 지원자도 생성해 재공격 시간을 기록한다. attackCount는 일반 공격 횟수를 유지한다. 지원 전투에는 별도 isSupport 표식을 남긴다. 피해량 0인 지원 전용 기록은 미수령 보상에서 제외한다.
- 안내: 지원 공격으로 보스가 처치되면 토벌이 종료됨. 스태미나·기여도·처치 확정타 보상 없음. 기존 일반 공격 보상 자격 유지.

DB에 세션 allow_free_support, 공격 로그 is_support boolean default false 컬럼을 추가한다. 공유 기믹 JSON에 설정을 섞는 방식보다 소유자 설정과 전투 상태의 덮어쓰기 위험이 적다.

검증: 소환 기본값/입력, 소유권·종료·해제, 무료 공격의 비용/보상/기존 기여 보존/쿨다운/잠금 후 재검증, UI 선택과 공격 분기, 관련 기존 테스트·타입·린트·마이그레이션 정합성. 로컬 변경과 커밋까지 수행하며 배포하지 않는다. 기존 전투 패턴 작업은 수정하지 않는다.
