# 미개척지 전투 스태미너 표시

스크린샷의 탐사 설정 패널은 현재 코드에서 이미 제거되어 있다. 남은 문제는 결과와 드랍을 읽으려고 스크롤할 때 공용 스태미너 바가 사라지는 것이다.

미개척지 경로에서 기존 공용 바를 상단 메뉴 아래 sticky로 유지한다. 메뉴 높이는 기존 --game-header-height를 사용한다. 다른 전투 화면의 배치는 유지한다. 중복 고정 바 추가보다 기존 바 재사용이 화면 점유와 상태 동기화에 유리하다.

미개척지에서는 여백과 진행 막대를 줄이는 compact 표시를 사용한다. 현재/최대 수치, 회복 정보, 포션 버튼과 모달은 유지한다. 표면은 라이트·다크 모두 SURFACE_INSET의 불투명 배경을 사용한다. 전투 결과와 사냥 동작은 변경하지 않는다.

검증: 경로별 고정 여부, 쿨다운 모드 숨김, 회복과 상태 갱신, 포션 모달 동작을 테스트하고 관련 테스트·린트·타입 검사를 실행한다. 배포는 하지 않는다.
