# 원정 최단 경로 포인트 안내 (#602)

미지 원정의 노드 상세에서 포인트 부족 상태에도 최단 경로 비용을 안내한다. 현재 활성 노드에서 목표 노드까지 기존 shortestUnexploredPathFromActive를 사용한다. 활성 노드는 제외하고 목표를 포함한 미활성 노드당 1포인트를 계산한다. 사용 가능 포인트는 max(0, earnedPoints - spentPoints), 부족량은 max(0, 필요량 - 사용 가능량)이다.

활성화 검증과 별도 모델 routePointPreview { required, available, shortfall }를 추가한다. 미선택·잘못된 노드·이미 활성화된 노드는 null이다. 시작 노드도 미활성이면 비용 1을 표시한다. 상세의 불투명 SURFACE_INSET 안에 최단 경로 필요량, 사용 가능량, 부족량을 표시한다. 기존 활성화 조건과 오류 안내, 반환 동작 및 실행 가능한 경로 강조는 유지한다. 보상 전환 충돌·난이도 제한은 비용이 충족되어도 기존대로 차단한다.

별도 확인창이나 예산을 무시하는 활성화 계획을 만드는 대신 읽기 전용 비용 정보로 구현한다. 서버/DB 변경 없음. origin/main 기반 /tmp/adventure-feedback-602에서 작업하며 배포·통합하지 않는다.
