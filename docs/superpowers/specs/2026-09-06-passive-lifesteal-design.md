# 패시브 흡혈 누락 수정 (#593)

장착 패시브의 lifestealPct를 PlayerCombat.passiveLifestealPct로 분리한다. 기존 enchantLifestealPct에는 기존 특수 효과만 유지한다. 불사의 순교와 동일 필드를 사용하는 불사마혈 모두 일반 공격, 추가타, 직접 피해 스킬의 실제 HP 피해에 비례하여 회복하며 로그에 `패시브 흡혈`을 표시한다.

계산은 실제 HP 피해 × 패시브 흡혈률을 내림한다. 초과 피해와 보호막 흡수량은 제외한다. 지속 피해와 피해 없는 스킬은 발동하지 않는다. HP 상한, 받는 회복량 보정, PvP 지속력 보정을 적용하며 회복이 0이면 로그를 남기지 않는다. 일반 회복 스킬의 증폭/회복 감소는 흡혈에 중복 적용하지 않는다.

기존 스킬 자체 흡혈·룬·특기·인챈트 효과는 그대로 두며 패시브와 중복 계산하지 않는다. 현재 브랜치의 다른 변경을 보존하고 로컬 검증·커밋까지 수행한다. 배포하지 않는다.
