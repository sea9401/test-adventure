# 스킬 카드 정보 계층

승인된 스킬 카드 시안을 실제 장착·학습 UI에 적용한다. 게임 계산과 데이터는 변경하지 않는다.

- 이름·종류·공격 횟수·효과 요약·MP·발동률·SP는 바로 표시한다.
- 반복 타격 계수는 순서를 보존해 같은 연속 타격끼리 묶고 기본 접힌 상세에 표시한다.
- 교차 연계에는 필요 패시브와 반대 계열 교대 공격 적중 조건을 명시한다. PvP 차이는 상세로 분리한다. 엔진 대조 결과 직전 타격 적중 여부가 아니라 현재 교대 공격 적중이 조건이므로 시안 문구를 보정한다.
- 기존 효과 문구는 요약 또는 상세에 빠짐없이 남긴다. 스킬 이름의 전체 설명창도 유지한다.
- 즐겨찾기 하나와 작은 장착/해제 버튼을 카드 하단에 배치한다. 이동 핸들 및 기존 저장 로직은 유지한다.
- 불투명 공통 표면 토큰을 사용하고 320/390px, 데스크톱 및 라이트/다크에서 확인한다.
- 현재 격리 브랜치에서 작업·검증·커밋한다. 배포·푸시·통합은 하지 않는다.
