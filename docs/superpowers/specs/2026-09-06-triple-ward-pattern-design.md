# 결계 행동패턴 조건 (#595)

`내 전투 자원`에 금강결계(physicalWard), 봉마결계(magicWard), 정화결계(purificationWard)의 남은 횟수를 추가한다. 기존 없음/이상/이하 비교와 OR 조건을 재사용하여 세 결계 중 하나라도 0회일 때 만법불침을 선택할 수 있게 한다. 별도 전용 조건이나 자동 패턴 변경은 도입하지 않는다.

PvE와 PvP는 시전자 자신의 현재 tripleWard 상태를 공통 패턴 평가기에 전달한다. 미전개·미지정 상태는 기존 숫자 자원과 같이 0으로 취급한다. 스킬 장착, MP, 쿨다운, 발동률 판정은 기존 규칙을 따른다. 저장 파서와 프리셋에서도 새 자원을 보존한다.

에디터에 세 결계 이름과 OR 설정 예시를 제공한다. 기존 표면 컴포넌트를 유지한다. 파서·평가·UI와 PvE/PvP 시전 테스트로 전부 남음, 각 결계 소진, 재전개, 시전자 구분을 검증한다. 배포와 외부 피드백 상태 변경은 범위에 포함하지 않는다.
