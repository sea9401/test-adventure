# 미개척지 희귀맵 발견 설계

## 목표

미개척지 사냥에서도 일반 사냥과 같은 규칙으로 희귀맵을 발견할 수 있게 한다.

## 동작

- 미개척지 승리 시 기존 희귀맵 발견 확률과 장비 해방의 희귀맵 확률 보너스를 적용한다.
- 발견된 지도 깊이는 미개척지 난이도가 아니라 캐릭터가 정복한 일반 사냥 최고 대표 단계로 저장한다.
- 레거시 홀수 `frontierDepth`는 바로 아래 짝수 대표 단계로 정규화하고, 최대 단계는 일반 사냥 상한으로 제한한다.
- 패배 시에는 지도를 발견하지 않는다.
- 희귀맵 보유 상한, 유효 시간, 종류별 보상 횟수는 기존 규칙을 그대로 사용한다.
- 희귀맵을 사용해 미개척지에 입장하는 요청은 계속 금지한다. 이번 변경은 미개척지의 지도 발견만 허용한다.

## 회귀 방지

실제 사냥 라우트 통합 테스트에서 미개척지 승리와 희귀맵 확정 굴림을 만들고, 응답과 저장 데이터 모두에 일반 사냥 최고 개방 단계의 지도가 생기는지 검증한다.
