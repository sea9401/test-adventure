# 숙련 화면 정리와 미발견 요리 보호

- 숙련 기록의 currentTier가 none이고 주방의 발견 레시피에도 없는 요리는 서버 snapshot에서 이름을 `미발견 요리`로 반환한다. 주방에서 발견했거나 숙련 기록이 있으면 이름을 공개한다. 서버의 nameHidden 필드로 두 기록의 시차를 표현한다.
- 클라이언트에서도 같은 기준을 적용해 목록, 고정 목표, 상세, 접근성 이름과 검색으로 미발견 이름이 노출되지 않게 한다. 내부 ID는 상세에 표시하지 않고 미발견 요리 검색에서도 제외한다.
- 분야 카드는 선택 상태와 발견 진행도를 표시한다. 항목 상세는 선택한 행 바로 아래에서 펼치고 다시 누르면 닫는다. 필터·분야·검색 변경 시 선택을 초기화한다.
- 기존 불투명 표면 토큰과 라이트·다크 모드 색상을 사용한다. 점수와 승급 조건은 변경하지 않는다.
- 서버 직렬화 및 UI 렌더링/검색 회귀 테스트, 관련 기존 테스트, 타입 검사와 lint로 검증한다. 배포 및 푸시는 하지 않는다.
