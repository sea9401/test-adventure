# 침식 스킬 사용 조건 (#607)

적 디버프 조건에 `dotVulnerability`를 추가한다. 표시명은 ‘지속/저주 피해 증가(침식)’이며 있음/없음을 선택한다. 스택 조건 신설이나 임의의 1스택 취급 대신 기존 디버프 활성 조건을 확장한다.

PvE는 `enemyDotVulnTurns > 0`, PvP는 상대의 `dotVulnTurns > 0`을 판정한다. 만료 후 남는 피해 증가 수치는 활성 여부에 영향을 주지 않는다. 저장 파서, 설정 선택지, 아레나 요약을 함께 지원한다. 밸런스와 지속시간은 변경하지 않는다.

검증: 저장 왕복, 있음/없음과 만료 경계, PvP 양쪽 공격자 시점, PvE 실제 시전, UI 표시. 배포 및 피드백 상태 변경은 범위 밖이다.
