# 드레드노트 설계

사용자와 합의한 성채기사 + 금강나한의 7차 전직. 기존 충격/반격을 연결한다.

- ID `dreadnought`, 전사/드레드노트 저장 매핑. 수행 vit 4/str 2/spi 1, 직업 보너스 vit 32/str 10/spi 6 (기존 7차 합 7/48 기준).
- 최초 해금: 성채기사·금강나한 각각 숙련도 100,000, 두 직업 중 하나로 Lv100, 폭풍 기원의 파편 30개. 기존 영구 해금 규칙 재사용.
- 시즈 브레이커: 14 SP, 방어력 220% + 500 물리 피해, MP65, 발동45%, 충격 최대3 모두 소비. 개당 피해20%와 기존 장착 충격 강화는 합산. 3개 소비 적중 시 다음 자동 반격 최종 피해50% 강화(중첩 없이 갱신, 반격 발동 시 해제).
- 리액티브 아머: 12 SP, 방어력20%, 최종 자동 반격 확률10%p(100% 상한), 자동 반격 적중 시 충격1. 적 행동당 추가 획득 최대1, 기존 최대3 유지. 반사·룬 반격은 대상 아님.
- 끝없는 진군: 10 SP, 최대HP20%, 충격 소비 공격 적중 후 개당 최대HP2% 회복(최대6%). 성채 충각 포함. 회복 감소와 받는 회복 보정 및 HP 상한 적용.
- 신규 방어 버프나 별도 충격 자원은 만들지 않는다. 스킬은 다른 직업에서도 기존 장착 규칙으로 사용 가능.
- 반격은 기존처럼 HP 피해 후 생존 시 확률 발동. 반사로 반격 자원을 얻거나 반격끼리 연쇄하지 않는다. 강화는 피해량0/미발동에는 보존한다.
- PvE 일반 공격·몬스터 스킬·기존 턴 처리와 PvP 모두 같은 효과를 적용한다. 회피 시 충격을 소비/회복/강화하지 않는다.
- SP36은 기존 7차46 패키지와 별도로 합의한 계승 의존 구성이다. 기존 패키지 평가 기준은 보존한다.
- 사용자 미완료 장비 변경은 별도 작업 공간으로 보존. 배포·푸시·브랜치 통합은 하지 않는다.

검증: 전직/저장/수행/스킬 카탈로그, SP 실제값, 패시브 집계와 서버 전달, 충격0~3·실패·행동상한·회복감소·반격1회·양 전투 엔진 회귀 테스트, 타입/린트/모듈 예산 점검.

## 구현 검토

- 기존 충격 강화 패시브끼리는 높은 값 하나를 적용하며, 시즈 브레이커의 개당20%를 여기에 합산한다. 움직이는 성채20%와 충격3이면 최종 피해2.2배.
- PvE 다단 기본 공격은 공통 행동 ID를 사용한다. 수호의 도발은 별도 음수 행동 ID를 사용하고 종료 후 복원하여 다음 정상 공격의 획득 기회를 보존한다. PvP 도발도 동일 규칙이다.
- 반격 강화는 금강인의 기존 공격력 강화 적용 뒤 반격 피해에1.5배 적용한다. 반사·룬 반격은 기존 동작 유지.
- 엔진의 동결된 파일 크기 제한을 지키기 위해 기존 자동 반격 함수를 `engine.passiveCounter.ts`와 `engine.pvpCounter.ts`로 분리하고 기존 export를 유지했다.
- 회복·강화 준비 로그는 효과로 표시한다. 추가 액티브 행동으로 표시하지 않는다.
