# 화염·바람 패시브 보강

사용자의 추가 요청과 확인에 따라 기존 패시브 네 개에 보조 효과를 하나씩 추가한다. 새 스킬·지능·범용 마법 피해는 추가하지 않는다.

- 불꽃의 정신: 연소 지속+1 유지. 홍련술·홍염의 낙인·겁화 붕괴 MP소모20% 감소. 다른 주문·동적 원소합성 주문 제외. 공통 시전 MP 계산에서 조건 선택과 지불 모두 할인액을 사용한다. 학습+장착 필요. 다른 직접 마법 MP 할인과 합산, 총100% 상한·최소1MP의 기존 규칙 유지.
- 겁화의 심장: 겁화 붕괴 연소 부여 유지. 사용 시 최대MP20% 보호막(자기 효과이므로 대상 회피와 무관, 발동실패·MP부족은 제외). 기존 equippedSynergies 및 보호막·PvP 유지력 배율 재사용.
- 바람의 정신: 실제 신규 기류당 MP1% 회복 유지. 같은 실제 증가량당 최대MP5% 보호막. 상한·미적중·MP부족·발동실패는 추가 생성량0. PvP 기존 보호막 배율 적용. 회복과 보호막을 분리 계산해 MP가 가득 차도 기류 생성 자체가 있으면 보호막 제공.
- 폭풍의 의지: 기류3소비 후 재생성 준비 유지. 해당 소비가 적중하면 확정회피 최소1회 확보. 기존 회피가1 이상이면 추가 누적하지 않고 유지(다른 스킬의 더 많은 회피도 보존). 같은 시전의 다른 회피 추가량도 보존.

SP는 공통 평가식에 새 효과를 반영하여 재계산. 조건부 액티브 시너지에 일부 평가가 붙는 기존 방식 유지. 4차·비전·태초·기존 연소/기류 피해 패시브는 그대로. 기존 워크트리·브랜치에서 구현·비파괴 검증·커밋, 배포/푸시/병합 없음.

최종 SP: 불꽃의 정신5(기존3), 겁화의 심장5(기존2), 바람의 정신6(기존4), 폭풍의 의지6(기존3). 네 패시브 합계22. 겁화 붕괴는 장착 보호막 시너지의 공통 평가로13→14 SP; MP140·발동41%·기본 피해 계수는 그대로.
