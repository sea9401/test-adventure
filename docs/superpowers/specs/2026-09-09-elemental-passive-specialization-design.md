# 화염·바람 중복 능력치 패시브 정리

사용자 승인 범위: 화염·바람 5·6차 중복 패시브 4개를 속성별 전투 효과로 변경. 학습 ID/이름과 별도 연소·기류 피해 패시브는 유지. 비전·태초·4차는 이번 변경 범위 밖.

- 불꽃의 정신: 자신이 새로 부여하는 연소 지속 +1 대상 행동. 기존 연소에 반복 가산하지 않고 새 적용 데이터에만 추가. 연소 피해 증가와 독립, 다른 DoT 불변.
- 겁화의 심장: 겁화 붕괴 적중 시 공통 연소를 부여. 기존 equippedSynergies로 구현해 미장착/미적중/정화 결계/MP 부족 경로를 재사용. 재부여는 기존 연소 갱신 규칙. 재점화 효과에 별도 피해 계수 없음.
- 바람의 정신: 실제로 새로 얻은 기류 1개당 최대 MP 1% 회복. 기류 상한에 막혀 증가량0이면 회복0. 현재 주문 비용 지불 후 적용, 최대MP 상한. 다른 주문/미적중/소비에는 미적용.
- 폭풍의 의지: 템페스트 버스트가 기류3을 소비하면 재생성 강화 준비. 다음 적중한 질풍술/에어 블레이드는 기류1 추가 생성(최대3), 준비 해제. 일반 주문/빗나감/발동실패/MP 부족은 준비를 소모하지 않음. 전투간 초기화. 기류 생성은 기존 기류 패시브 장착 필요.

네 패시브의 지능/정신/마법피해/최대MP/MP할인 제거. 장착 합산과 서버 전달, 도움말, SP 산식 업데이트. PvE/PvP 같은 순수 전이 함수를 사용하고 기존 엔진 크기 예산 유지. 반동 준비는 기류 자원 표시와 함께 표시. 기존 저장 ID 그대로 유지해 재학습 불필요. 로컬 커밋만, 배포/푸시/병합 없음.

최종 SP: 불꽃의 정신3, 겁화의 심장2, 바람의 정신4, 폭풍의 의지3. 합계12(기존40). 겁화 붕괴의 시너지 비용은 기존 공통 산식으로 평가한다.

후속 보강: 현재 추가 효과와 SP는 `2026-09-09-elemental-passive-reinforcement-design.md`를 따른다.
