# 농장 주간 선택 납품

전체 작물 11종의 주문을 표시하고 실제 납품한 서로 다른 작물 3종을 이번 주 선택으로 기록한다. 사전 선택·취소는 필요 없다. 기존 3개 주문 ID·수량·보상 및 주간 완료 기록을 유지한다. 재배 스킬 해금, 일일 납품, 씨앗 주머니 보상은 변경하지 않는다.

새 주문은 평균 수확량 기준 약 15~17시간의 밭 한 칸 재배 부담으로 맞춘다. 수량/씨앗 보상: 토마토 15/3, 딸기 8/2, 감자 10/1, 양파 7/1, 쌀 8/1, 콩 7/1, 사탕수수 6/1, 카카오 4/1. 새 주문의 기본 증표는 7개. 희귀 보너스는 기존 정책인 해당 희귀 납품 보상 +2를 적용하고 자동 사용 동작을 유지한다. 기본 증표의 주간 최대는 기존 21에서 23으로 소폭 증가한다.

서버는 기존 트랜잭션과 세이브 잠금을 사용해 주간 총 3건을 강제한다. 동일 주문 중복 오류는 유지하고 총량 초과 오류를 추가한다. 새 주에는 완료 기록을 초기화한다. 목록 수와 주간 한도를 분리하여 대시보드와 납품 화면에 0/3을 표시한다. 한도 도달 시 미완료 주문 버튼과 납품 가능 집계에서 제외한다. 패널·카드는 불투명 표면 토큰을 사용한다.

검증: 11종 납품 가능, 4번째 거절 및 재료/보상 무변경, 중복 거절, 기존 완료 기록 합산, 주간 초기화, 희귀 보상, 대시보드 3건 목표, UI 버튼과 진행 표시. 배포·푸시는 하지 않는다.
