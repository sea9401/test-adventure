# 건의 618 개선 설계

기존 화면 구조를 유지하며 정보 누락과 상태 식별 문제를 수정한다. 별도 전면 UI 재설계보다 기존 카드의 장착 배지와 테두리·호버·키보드 포커스·펼침 상태를 강화한다. 간략 스킬 태그는 빌드 분류 대신 공통 효과 설명을 사용한다.

거래소 요리 카드에는 판매 payload의 레시피·품질로 실제 음식 효과와 지속 시간을 표시한다. 유니크 상세 카드에는 기존 효과 요약 외에 용어·발동 조건·필수 조합을 읽을 수 있는 설명을 제공한다. 반중력 인장의 중력 반발 방출에 필요한 장비를 명시한다.

캐릭터 카드에서 장착 장비의 해방 상태를 상세 팝업까지 전달하고, 공개 캐릭터 API에서도 장착 장비의 해방만 노출한다. 본인·메인 상세·다른 모험가가 같은 컴포넌트 경로를 사용한다.

점검 중 살아 있던 경매의 입찰 마감·만료 시각은 점검과 겹친 시간만큼 연장한다. 예정/긴급을 구별할 신뢰 가능한 입력이 없으므로 모든 점검에 적용한다. 이미 종료된 경매는 부활시키지 않으며 재실행은 중복 연장하지 않는다. 점검 기간 정산 차단과 연장 트랜잭션을 함께 검증한다. 배포·실제 점검 조작·제보자 응답은 수행하지 않는다.
