# 화염 마법사 5·6차

화염 마법사(firemage) 숙련도 18,000 → 홍염술사(pyromancer, 5차) → 숙련도 35,000 → 겁화술사(infernomancer, 6차). 원소군주 혼합 계보와 별도로 화염 단일 계보를 제공한다. 기존 4차와 원소 조합은 유지한다.

5차 수행 int3/spi2, 직업 보너스 int20/spi8. 6차 수행 int4/spi2, 직업 보너스 int28/spi12. class mage/spec 직업 ID로 저장·복원한다.

액티브: 홍염의 낙인은 마법공격력×1.8 + 지능×1.8, 공통 연소 1중첩, 적 지속 피해 취약25% 3행동. 겁화 붕괴는 마법공격력×3 + 지능×3에 0방어 기준20% 추가 피해. 연소 유지·회복 방해(4차), 지속 피해 강화(5차), 고위력 즉발(6차)로 구분한다. 별도 자원이나 계열 조건은 없다. 기존 dot·enemyDotVuln·pierceDamagePct 공용 엔진을 사용한다.

패시브는 차수별로 능력치와 연소 강화를 분리한다. 5차 불꽃의 정신은 지능25%/정신15%/마법스킬피해8%(7SP), 작열은 연소피해30%(4SP). 6차 겁화의 심장은 지능30%/최대MP25%/마법스킬피해12%/MP소모량감소8%(13SP), 영겁의 불꽃은 연소피해50%(6SP). 직업과 무관하게 장착하면 동일하게 적용한다. SP·MP·확률은 기존 공통 산식을 따른다. 액티브 원시 MP52/64, proc30, tempo steady/burst로 설정하고 최종 값을 검증한다.

검증: 전직 숙련도 경계, 저장 매핑, 교관 킷, 수행 성향, 범용 패시브, 실제 시전 및 PvE/PvP 효과, 직업 총수149개와 해금 SP 총합. 기존 변경 중인 숙련 성장 파일은 수정하거나 커밋에 포함하지 않는다. 배포하지 않는다.

## 최종 수치

개인 발동률·MP비용 보정 전 수치. 연소는 대상 행동2회, 최대1중첩이며 취약은 대상 행동3회 동안 유지된다. 공통 순수 마법 공식에서 공격력 계수를0.65 보정하므로 원시 attackCoef2.45/3.65를 사용한다. 피해는 공통 엔진의 단계별 정수 내림을 따른다.

작열과 영겁의 불꽃은 각각 별도로 학습·장착하며, 직업과 관계없이 자신이 부여하는 연소의 최종 지속 피해를 증폭한다. 30%와50%를 함께 장착하면+80%이며 재시전으로 중복 곱하지 않는다. 홍염의 낙인의 지속 피해 취약25%는 대상 측 별도 배율로 적용된다. 직접 타격·출혈·중독은 연소 패시브로 증가하지 않는다. SP 평가는 연소 피해20%당 효과 점수1을 부여한다.

연소 sourceAtk는 시전 시점 공격력과 마법 공격력 중 높은 값을 참조한다. 기본 1회 피해는 `12 + sourceAtk × 0.2`이며 차수 보정을 적용하지 않는다. 상세 지속 피해 비교는 `2026-09-09-burn-dot-comparison.md`에 기록한다.

연소 공통 효과로 회복 스킬·재생50% 감소를 부여한다. 생존 중인 연소 스택(turns>0, stacks>0)에서 판정하므로 마지막 틱 소진/정화 직후 즉시 해제된다. 별도 회복 감소와는 최댓값만 적용한다. 기존 홍련술·원소술사의 중복된50%/3행동 디버프는 제거하고 더 강한 원소 조합 디버프는 독립 효과로 유지한다. 흡혈 패시브·물약·MP회복은 이 감소의 대상이 아니다. 추가된 유틸리티는 공통 SP 산식에 반영하며 홍염의 낙인은13SP다.
