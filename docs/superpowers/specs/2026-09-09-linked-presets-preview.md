# 연결형 전투 프리셋 미리보기

사용자가 승인한 예시안을 `/dev/linked-presets`의 실제 클릭 가능한 검토 화면으로 만든다. 실제 세이브/API 변경은 하지 않고 React 상태의 샘플 데이터만 사용한다. 개발 프리뷰 허브에 링크를 추가한다.

전투 조합·장비·스킬·전투 패턴 네 탭. 조합은 안정적인 샘플 ID로 각 라이브러리를 참조한다. 조합 편집/저장/적용, 개별 프리셋 이름 및 구성 수정, 사용 중인 조합 안내, 삭제 전 연결 영향 안내, 삭제된 참조의 적용 차단을 제공한다. 실제 적용 상태는 복사본으로 유지하여 라이브러리 수정만으로 현재 적용된 상태가 바뀌지 않게 한다. 기존 저장 방식의 샘플은 내용 보존 및 연결형 전환을 체험하도록 한다.

## 실행·검증

- [x] 상호작용 테스트를 먼저 작성: 공유 스킬 수정 후 재적용, 저장만으로 적용 상태 불변, 삭제 시 차단, 기존 설정 전환.
- [x] 반응형 화면 구현. 패널은 공통 불투명 표면 토큰을 사용한다.
- [x] 로컬 dev 서버에서 데스크톱/모바일 및 라이트/다크 스크린샷 확인.
- [x] 테스트·린트·타입 검사 후 커밋하고 로컬 링크·화면 이미지를 제공한다. 배포하지 않는다.
