# 3000틱·최종 행동 간격 최소 20틱 설계 검증

2026-09-09. 사용자의 최신 기준인 전투 상한 3000틱, 최종 행동 간격 최소 20틱으로 앞선 6000틱 설계를 대체한다. 이 문서는 임시 엔진에서 수행한 비교와 후속 밸런스 보정의 초안을 기록한다. 게임 코드 적용·운영 배포는 수행하지 않았다.

## 설계 기준과 판단

- 전투 시간 상한은 기존 3000틱을 유지한다.
- 속도 100 이하의 기존 정수 행동 간격을 보존한다. 속도 100은 100틱 간격으로, 첫 행동을 포함한 기본 행동 기회가 31회다.
- 가속과 예약 행동 당김을 처리한 뒤에도 같은 액터가 직전 ATB 행동으로부터 최소 20틱 뒤에 행동하도록 제한한다. 최초 행동은 기존 규칙을 따른다.
- 한 액터의 기본 행동 기회는 최대 151회다. 동속도 PvP의 두 액터 합계는 최대 302회다. 연타·반격 등 한 행동 안에서 발생하는 여러 타격과 별도 보스 이벤트는 이 행동 수와 구분한다.
- 속도 1000의 기존 간격 21틱을 그대로 두면 최저 20틱까지 성장 여유가 거의 없다. 따라서 중·고속 구간의 간격을 늘리는 변경과 기존 전투 밸런스 보정이 함께 필요하다.

후속 보정은 **속도 1000에서 40틱, 10000에서 20틱인 안**을 초안으로 삼는다. 35틱안보다 1000 이후 성장 폭을 넓히고, 50틱안보다 현재 캐릭터의 성능 감소를 줄이는 절충이다. 이 선택은 설계 판단이며, 현재 승률을 유지하는 검증을 통과한 최종 공식이라는 의미가 아니다.

## 비교식

속도 `s`는 최소 1로 보정한다. `I`는 속도 1000에서 목표로 하는 35/40/50틱 중 하나다.

```text
s <= 100:
  interval = 기존 정수 actionInterval(s)
100 < s <= 1000:
  interval = ceil(100 / (s / 100)^log10(100 / I))
s > 1000:
  interval = max(20, ceil(I / (s / 1000)^log10(I / 20)))
```

임시 구현은 기준점의 부동소수 오차를 피하기 위해 `ceil` 전에 `1e-10`을 뺐다. 실제 구현에서는 경계값을 명시적으로 처리할 수 있다. 표의 값은 가속·둔화 전 기본 간격이다.

모든 후보는 속도 10000에서 기본 간격 20틱에 도달한다.

- 기준 엔진은 운영 커밋 `96ac1af6009b4d2e86e8207f25d8600816872981`을 추출한 임시 복사본이다. 현재 작업 브랜치의 다른 기능 변경은 반영하지 않았다.
- 입력 스탯·장착 스킬·몬스터·난수 시드를 고정했다. 만피/만MP 시작, 물약·요리 버프 제외, 저장된 도달 사냥터 기준이다. 활성 계정이나 실제 사냥 빈도 가중치는 없다.
- 대조군은 기존 공식과, 기존 공식에 최종 20틱 하한만 추가한 `cap20-current`다.
- 후보당 전체 사냥 44100회(882명×몬스터 5종×10회), 추가 90명 사냥·탑·아레나 표본을 비교했다.
- 보스는 상위 30명×14종×10회=4200회씩 초기 기믹·만피 상태에서 전체 로그로 비교했다. 고정 틱 기믹은 기존 값을 유지했다. 기본 하네스의 기믹 없는 `coop` 행은 보스 결론에서 제외했다.
- 속도 25~20000의 합성 장기전과 치명타 가속 80%를 부여한 별도 스트레스 조건으로 최종 행동 간격을 검증했다. 80%는 제한 검증용 합성 조건이며 실제 장비/직업의 허용 최대치를 뜻하지 않는다.
- 공용 actionRate·전투력 점수·PvP 선공 확률은 고정했다. 이번 비교는 간격/스케줄링 변경의 효과를 분리하며, 실제 공용 함수 변경 시 이 항목들은 추가 검증해야 한다.

## 처리량과 검증 결과

모든 신규 후보의 실측 액터 간격은 부동소수 오차 허용 `1e-7` 내에서 20틱 이상이었다. 일반·가속 스트레스와 실제 저장 표본 모두 각 액터의 행동 수는 151회 이하였다. 기존의 행동 가드 종료는 없었다.

속도 20000/치명타 가속 80% 합성 PvP에서 기존 엔진의 최소 행동 간격은 약 2틱이었다. 최종 하한을 넣은 대조군과 세 후보는 모두 최소 20틱, 양측 합계 302행동으로 제한됐다. 이 검사는 실제 가속 조건에서 최종 하한이 작동함을 확인하는 양성/음성 대조다.

임시 스케줄러는 매 이벤트 선택 전에 예약 틱을 `max(예약 틱, 해당 액터 직전 행동 틱 + 20)`으로 보정했다. 따라서 자기 가속뿐 아니라 상대 이벤트에서 발생하는 예약 당김도 다음 이벤트 선택 전에 제한한다. 실제 적용에서는 별도 공용 스케줄링 헬퍼와 회귀 테스트로 구현할 수 있다.

단조성·기준점·속도 1~30000 범위, 조건별 표본/시드 대응, 882명 커버리지, 최종 간격, 가속 대조, 최대 액터 행동 수를 검증했고 통과했다. 이는 시뮬레이션 하한의 검증이며, 후보들의 기존 게임 균형 보존이 통과했다는 뜻이 아니다.
