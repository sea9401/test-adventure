# 6000틱 고속 구간 곡선 비교

> 이후 사용자 지시로 전투 상한 3000틱·가속 후 최종 행동 간격 최소 20틱을 채택했다. 아래 6000틱/B안 권고는 현재 설계 기준이 아니며, 후속 비교는 [3000틱·최종 20틱 설계](2026-09-09-speed-3000-final20-comparison.md)를 따른다.

2026-09-09. 이번 범위는 속도 1000 이후 후보 비교와 권고안 선정이다. 게임 공식의 실제 적용, MP·독 빌드 보완, 보스 재조정, 운영 배포는 포함하지 않는다.

## 권고

6000틱, 속도 100에서 200틱, 속도 1000에서 20틱을 유지하고 **1000 초과 구간의 행동 빈도를 속도의 0.75제곱에 비례**시키는 B안을 다음 설계의 기준으로 권고한다.

B안은 속도 1000→2000에서 실제 기본 행동 빈도가 약 1.67배, 1000→4000에서 2.5배가 된다. A안보다 투자 효과가 크고 C안보다 최대 빈도에 늦게 도달한다. 실제 사냥 승률 차이는 작았으므로 이 선택은 승률 최적화의 결론이 아니라 투자 효율과 장기전 처리량을 고려한 설계 판단이다.

최소 6틱은 이번 비교에서 통일한 시험 상한이다. B안은 약 4980부터 기본 행동 빈도가 더 증가하지 않으므로, 이 상한은 향후 성장 범위와 처리 예산을 고려해 최종 확정해야 한다. 기존 행동 가드를 그대로 두고 적용할 수 있다는 결론은 아니다.

## 공통 조건과 후보

- 전투 상한: 6000틱.
- 속도는 최소 1로 보정한다.
- 속도 100 이하: 기존 정수 행동 간격의 정확히 두 배. 저속 선후공의 반올림 변화를 방지한다.
- 속도 100 초과~1000 이하: `ceil(20000 / spd)`.
- 속도 1000 초과: `max(6, ceil(20 / (spd / 1000)^p))`.
- A: `p = 0.5`, B: `p = 0.75`, C: `p = 1`.
- 공용 `actionRate`는 유지하고 `actionInterval`만 바꿨다. 전투력 점수·PvP 선공 확률 변경은 실험 범위 밖이다.
- 보스의 고정 틱 기믹은 세 후보 모두 두 배로 맞췄다. 장판 100→200, 방벽 400→800, 수정안 조준 900→1800, 노출 250→500틱.

## 행동 가드와 남은 작업

실제 저장 표본의 사냥·아레나·보스에서는 세 후보 모두 행동 가드 종료가 없었다. 합성 최고속 장기전에서는 모두 가드에 도달했다. 기본 간격 6틱이면 한 액터가 1001번, 양측 합계 2002번의 행동 기회를 갖는데 현재 PvE 1000/PvP 2000 가드와 충돌한다.

6틱은 기본 `actionInterval`의 하한이다. 행동 간격을 직접 줄이는 스킬 가속에는 그대로 적용되는 최종 하한이 아니므로, 2002를 모든 전투의 최대 처리량으로 간주하면 안 된다. 실제 구현 전 최종 행동 간격·가속·보스 이벤트를 포함해 처리 예산과 가드를 함께 정해야 한다.

다음 작업은 B안을 기준으로 이전 검증에서 악화된 독·MP·조건부 공격 표본을 보완하는 것이다. 이번 곡선 비교는 그 문제가 해결됐음을 검증하지 않았다. 이어서 보스 피해량과 고정 틱 기믹, 실제 공용 속도 함수 변경에 따른 전투력·선공 확률·UI 영향을 확인한다.

## 재현 자료와 확인

임시 실험 디렉터리: `/tmp/adventure-speed-production-audit-7jbwllz3`.

```bash
for mode in curve-sqrt curve-threequarter curve-linear; do
  SPEED_AUDIT_MODE="$mode" node --import tsx check-curves.cjs
  node run.cjs "$mode" census
  node run.cjs "$mode" main
  SPEED_AUDIT_CLOCK_SCALE=2 node run.cjs "$mode" mechanics
  node run.cjs "$mode" stress
done
python3 curve-summary.py
python3 verify-curves.py
```

`check-curves.cjs`는 속도 1~30000의 단조성, 하한, 공통 저·중속 구간, 기준점을 확인했다. `verify-curves.py`는 후보별 표본 수·입력/시드 대응·882명 커버리지·저중속 결과 보존·실제 표본의 가드 미도달·합성 최고속 가드 도달을 확인했다. 모두 통과했다. 집계는 `results/curve-summary.json`, 원본은 후보별 JSON에 있다.

프로젝트의 게임 코드는 수정하지 않았으며 배포하지 않았다. 이 문서는 비교 결과와 다음 설계의 우선 후보만 기록한다.
