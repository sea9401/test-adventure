# 성기사 5·6차 성력과 범용 패시브

사용자와 합의한 4차 성전사는 유지한다. 5차 성역 선포는 시전 행동을 포함한 자기 행동 종료 4회에 최대 HP 4% 회복과 성력 10을 부여한다. 성력 상한은 100이며 만피에도 생성한다. 재시전은 남은 행동을 4로 갱신하며 중첩하지 않는다. 치유량 비례 성력 전환은 없다.

6차 여명의 심판은 방어/버프 전 공격력×2 + 힘×2 + 정신×2의 물리 단일 피해다. 시전 성공 시 성력을 전부 소모하고 성력 1당 기본 피해를 1.5% 늘린다. 자원이 0이어도 사용 가능하며 실패한 시전(MP 부족 등)은 소모하지 않는다. 빗나간 시전은 성력을 소모한다. 합의된 실제 계수를 공통 계수/패턴 감쇠가 다시 바꾸지 않는다.

성휘의 가호는 활력·정신 20%, 받피감 5%, 성기사 계열에서 회복량 10%, 7 SP. 영원의 서약은 힘·정신 20%, 회복량 25%, 성기사 계열에서 받피감 3%, 6 SP. 보너스 계열은 templar/crusader/radiantknight/dawnpaladin만 포함한다. 패시브 미장착 시 보너스가 없다. 스킬 ID는 기존 저장 데이터 호환을 위해 유지한다.

성역/심판은 기존 카탈로그 MP 130/150을 유지한다. 공통 MP 압박 보정 후 실제 기본 소비는 163/188이다. 액티브 SP는 기존 성능 산정 방식에 성력 최대 피해/성역 지속 회복 가치를 포함해 성역 9 SP, 심판 20 SP로 산정한다. 계열 보너스는 비용 산정에 포함하고 합의한 패시브 SP에 할인을 명시한다.

패턴에 성력(0~100), 성역 남은 행동(0~4)을 추가한다. 기본 조건은 성역 없음 시 성역 선포, 성력 40 이상 시 심판이다. 사용자는 0 조건을 포함해 수정할 수 있다. 자원은 전투 상태에서만 저장하고 전투별 초기화하며 로그 스냅샷에 표시한다. PvE/PvP는 같은 상태 전이 함수를 사용하고 회복은 기존 각 모드의 회복 보정을 따른다.

범위: 카탈로그, 패시브 집계/서버 주입, 공유 피해 산식, 전투 어댑터, 패턴 파서/편집/요약, 자원 로그와 회귀 테스트. 배포/외부 쓰기/다른 계열 수정은 하지 않는다.
