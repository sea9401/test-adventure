# 미개척지 특화풀 전용 드롭 세트 설계

## 상태

- 설계 승인일: 2026-09-09
- 범위: 미개척지 특화 몬스터 풀 12종의 전용 3부위 장비 세트
- 이 문서는 설계만 확정한다. 장비 데이터, 드롭 테이블, 전투 로직, UI는 아직 구현하지 않는다.

## 목표

- 특화풀마다 몬스터 세 종이 각자 고정된 신규 장비 한 종을 드롭한다.
- 풀별 장비 세 종을 모으면 해당 풀의 전투 성격이 분명하게 드러나는 3세트를 완성한다.
- 모든 신규 장비는 무기 외 슬롯을 사용해 직업 제한 없이 장착할 수 있게 한다.
- 단일 세트뿐 아니라 무기를 포함한 기존 3세트와의 `3+3` 혼합도 고려해, 서로 다른 공격 세트가 무조건적인 정답 조합이 되지 않게 한다.

## 공통 규칙

### 장비와 드롭

- 신규 장비는 총 36종이다: 12개 풀 × 몬스터 3종.
- 각 몬스터는 자기에게 지정된 장비 한 종만 드롭한다.
- 신규 장비의 화면 표시 티어는 6티어, 희귀도는 일반 세트 장비다.
- 기본 장비 드롭률은 0.4%, 해당 풀 집중 시 0.6%다.
- 기존 특화 재료 드롭률 1%/집중 1.5%, 기존 희귀 무기 드롭률 0.1%/집중 0.2%는 별도로 유지한다.
- 중복 획득과 거래를 허용한다.
- 기존 개척자 장비·고급 제작 세트·개인 보스 고유 장비는 제거하거나 대체하지 않는다.
- 신규 드롭 세트는 6티어 특화 사이드그레이드이며, 6.5티어 고급 제작 세트와 개인 보스 장비는 상위 추구 목표로 남긴다.

### 세트 판정

- 같은 풀의 장비 두 종 장착 시 2세트 효과가 활성화된다.
- 세 종을 모두 장착하면 2세트 효과와 3세트 효과가 누적 적용된다.
- 신규 세트끼리는 무기를 포함하지 않지만, 무기를 포함한 기존 세트와 남은 슬롯을 이용한 `3+3` 조합은 가능하다.
- 따라서 공격형 3세트는 다른 범용 공격 세트와 결합했을 때의 총효율까지 기준으로 조정한다.

### 전투 용어

- `직접 피해`는 평타와 즉시 피해를 주는 액티브 스킬의 피해를 뜻한다.
- 중독·출혈·연소, 반사 피해, 장비가 독립적으로 발생시킨 피해는 직접 피해가 아니다.
- `실제 HP 피해`는 방어·회피 경감·피해 감소·보호막을 모두 처리한 뒤 실제 HP에서 감소한 양이다. 보호막 흡수량과 초과 피해는 제외한다.
- `적의 한 행동`은 단일타와 다단타를 모두 포함하는 하나의 적 행동 경계다.

## 구현 시 필요한 데이터 확장

현재 장비 데이터만으로 표현되지 않는 아래 항목을 명시적인 옵션 또는 세트 시그니처 필드로 추가한다. 문자열 이름에 의존해 분기하지 않는다.

- 기본 공격 피해 증가
- 추가 기본 공격 피해 증가
- 중독·출혈·연소 통합 지속 피해 증가
- 물리·마법 방어 관통
- 적 행동 실제 HP 피해 임계값과 다음 공격 강화
- 스킬 사용 횟수 기반 보호막 재전개와 포격 집속
- 행동 종료 시 고정 비율 재생
- 회피 경감량 기반 보호막 전환
- 저체력 상태 피해 포함 최종 피해 감소
- 치명타 기반 속도·명중 약화

## 검증 기준

- 36개 장비 ID, 슬롯, 세트 태그와 드롭 몬스터의 역참조가 모두 일치해야 한다.

- 집중 여부에 따라 신규 장비 드롭률이 정확히 0.4%/0.6%여야 한다.
- 2세트와 3세트의 누적 적용, 장비 해제 시 즉시 비활성화를 검증한다.

- 무기를 포함한 기존 3세트와 신규 3세트를 조합한 대표 `3+3` 빌드의 총 공격·생존 효율을 별도로 비교한다.
