# 바람 마법사 5·6차

승인된 계보: 바람 마법사 → 에어로맨서(aeromancer,5차) → 스톰브링어(stormbringer,6차). 기존과 동일하게 선행 숙련도18,000/35,000. 수행 int3/spi2, int4/spi2; 보너스 int20/spi8,int28/spi12. mage/spec=jobId.

## 스킬
- 5차 에어 블레이드: 마법공격력×2 + 지능×2, 다음 행동35% 가속, 장착 기류 패시브가 있으면 적중 후 기류1. 원시 MP52,proc30,rapid.
- 5차 바람의 정신: 지능25%,정신15%,마법스킬피해8%. 기류 효과 없음.
- 5차 기류 제어: 바람 주문 적중 시 기류 생성 활성화, 보유 기류당 해당 바람 주문의 직접 피해8% 증가.
- 6차 템페스트 버스트: 마법공격력×3.5 + 지능×3.5, 적중 후 기류 전부 소비. 기류당 자체 직접 피해20% 및 다음 행동15% 가속(최대45%). 원시 MP64,proc30,rapid.
- 6차 폭풍의 의지: 지능30%,최대MP25%,마법스킬피해12%,MP소모8% 감소. 기류 효과 없음.
- 6차 폭풍 순환: 기류 생성 활성화, 기류당 바람 주문 직접 피해12% 증가. 기류 제어와 합산해 최대20%/중첩.
- 원시 순수 마법 attackCoef는 공통0.65 보정 전2.65/4.15,primaryStatCoef2/3.5로 정의한다. 실제 스킬 비용·MP·발동률은 공통 계산식으로 검증한다.

## 기류
전투 시작0,최대3. 질풍술·에어 블레이드로 시전당1 생성(적중 필수). 템페스트 버스트는 생성하지 않고 적중 시 모두 소비. 현재 주문은 시전 전 기류로 피해를 계산하며 새 기류는 다음 바람 주문부터 강화한다. 피해 강화는 질풍술/에어 블레이드/템페스트 버스트만 적용하고 일반 마법·물리·DoT에는 적용하지 않는다. 원소군주의 동적 합성 주문은 이번 범위에서 제외한다. 캐릭터 속성과 무관하다.

기류0 폭풍도 기본 피해를 준다. 미장착·MP부족·발동실패·확정회피는 자원을 만들거나 소비하지 않는다. 소비 가속은 적중한 뒤에만 발생한다. 보호막에 막혀도 직접 공격이 적중했으면 적용한다. 폭풍 최대 기류3에서5·6기류 패시브를 모두 장착하면 직접 피해1+(20+20)*3/100=2.2배. 가속을 추가 곱연산하지 않고 기존 가속과 큰 값을 적용한다.

PvE·PvP 및 기존 턴 엔진 경로에 동일 적용한다. 전투 패턴 자원 windCurrent(기류) 추가, 기본 패턴 폭풍은 기류3 조건, 바람 주문은 생성기로 사용. 자원 스냅샷과 스킬 도움말에 표시. 일반 스킬처럼 학습 후 다른 직업에서도 장착 가능.

별도 /tmp 작업공간에서 구현, 기존 드레드노트 브랜치는 그대로 보존. 배포/푸시/통합 없음. 회귀 테스트 먼저, 전직·서버전달·패턴·엔진·공통 산식 및 타입/린트/모듈 예산 검증 후 로컬 커밋.
