# 인벤토리·거래소 판매 검색 (#633)

현재 분류의 아이템 이름을 부분 검색한다. 검색어 앞뒤 공백과 영문 대소문자를 무시하고 빈 검색어는 전체 목록을 복원한다. 두 화면의 검색어는 독립적이며 분류를 바꿔도 유지한다. 장비, 재료, 소모품에 적용한다.

이미 내려받은 목록을 클라이언트에서 필터링한다. 서버 검색은 추가 요청이 불필요하고, 장비에만 검색을 두면 다른 분류의 사용성이 달라지므로 공통 이름 비교와 검색 입력을 사용한다. 필터링 후 페이지를 나누고 검색어 변경 시 첫 페이지로 돌아간다. 검색 초기화 버튼을 제공한다. 입력 배경은 라이트·다크 모두 불투명하다.

원본 보유 수량, 장착 슬롯, 잠금·판매 가능 여부, 판매·도감 등록 동작은 유지한다. 인벤토리 일괄 동작은 검색과 무관한 기존 범위임을 검색 중 알린다. 검색 결과 없음과 실제 미보유를 구분한다.

검증: 이름 부분 검색·공백·대소문자·초기화, 장비 필터와 페이지 복귀, 보유 수량 보존, 기존 인벤토리·거래소 회귀 테스트, 타입 검사, 변경 파일 린트. 배포와 피드백 상태 변경은 범위에 포함하지 않는다.
