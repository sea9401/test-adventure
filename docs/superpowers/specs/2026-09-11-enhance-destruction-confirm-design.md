# 파괴 위험 강화 확인

강화석 효과를 반영한 `enhanceOutcomeRow(level, stone)[3]`가 0보다 큰 시도마다 확인한다. 붉은 돌은 +7→+8, 푸른 돌은 +12→+13부터 해당한다. 확률 0인 시도는 바로 진행한다.

브라우저 기본 확인 메시지를 공통 `doEnhance` 핸들러에 추가한다. 별도 모달보다 변경 범위가 작고 PC·모바일 버튼 모두 같은 검사를 거친다. 장비명, 현재·목표 단계, 실제 파괴 확률과 장비 소멸 경고를 표시한다. 취소 시 POST와 비용 소모가 없고 확인 시 기존 요청을 한 번 수행한다. 서버 확률·비용 정책은 유지한다.

실제 화면 클릭 테스트로 경계 단계, 강화석 변경, 취소·확인 및 두 버튼의 동작을 검증한다. 사용자 AGENTS.md에 따라 추가 승인 없이 로컬 구현·검증·커밋하며 배포하지 않는다.
