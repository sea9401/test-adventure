# 희귀 탐사 복귀 전투 세션 설계

## 문제

일반 사냥 화면에서 희귀 탐사로 이동하고 탐사 소진 뒤 같은 층의 일반 사냥 URL로 돌아오면, Next.js 클라이언트 전환이 같은 `V2DungeonFloorView` 인스턴스를 재사용한다. 이때 이전 탐사의 `busy`, 자동 사냥, 일괄 사냥, 요청 차단 ref 같은 일시 상태가 남아 일반 사냥 버튼이 동작하지 않을 수 있다. 다른 화면을 거쳐 돌아오면 컴포넌트가 새로 마운트되어 문제가 풀리는 신고와 일치한다.

## 설계

던전 층 페이지에서 전투 화면의 React `key`를 `floorId`와 `rareMapIid`로 구성한다. 일반 사냥과 각 희귀 탐사를 별도 전투 세션으로 취급하여 URL의 전투 문맥이 바뀌면 `V2DungeonFloorView`를 새로 마운트한다. 개별 상태를 수동으로 나열해 초기화하지 않으므로 이후 추가되는 일시 상태도 같은 문제를 만들지 않는다.

서버 API와 저장 데이터는 바꾸지 않는다. 이미 제출된 요청은 서버 권위로 완료되지만, 새 전투 문맥의 UI는 이전 문맥의 처리 상태를 이어받지 않는다.

## 검증

페이지 통합 테스트에서 희귀 탐사 요청을 처리 중인 상태로 만든 뒤 검색 매개변수를 일반 사냥으로 전환한다. 전환 후 일반 사냥 버튼이 새 세션 상태로 활성화되는지 확인한다. 기존 던전 화면 테스트와 타입 검사를 함께 실행한다.
