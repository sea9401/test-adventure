# 미개척지 탐사망 초기화 확인 모달 설계

## 문제

미개척지 탐사망의 개별 노드 반환 버튼은 반환 수와 골드 비용을 표시하지만, 전체 초기화 버튼은 비용 안내 없이 즉시 서버 요청을 보낸다. 서버는 시작 노드를 제외한 모든 활성 노드에 노드당 `refundGoldCost`를 부과하므로, 여러 번 구성을 바꾸는 이용자가 큰 금액을 예상하지 못하고 사용할 수 있다.

## 선택한 접근

기존 전역 `confirmGameAction` 모달을 재사용한다. 이 모달은 앱 표면 스타일, 모바일 바텀시트, 키보드 포커스, ESC 취소 동작을 이미 제공한다. 컴포넌트 전용 모달은 같은 접근성 로직을 중복시키고, 브라우저 기본 확인창은 게임 UI와 일관되지 않아 사용하지 않는다.

## 동작

- 초기화 버튼을 누르면 서버 요청 전에 `탐사망 초기화` 확인 모달을 연다.
- 반환 노드 수는 서버와 동일하게 `selectedNodeIds`에서 `start`를 제외해 계산한다.
- 총비용은 `반환 노드 수 × snapshot.refundGoldCost`로 계산한다.
- 안내에는 반환 노드 수, 총비용, 현재 보유 골드와 은행 골드의 합계, 되돌릴 수 없다는 경고를 표시한다.
- 확인 버튼에도 총비용을 표시한다.
- 취소하면 네트워크 요청과 자원 변경을 수행하지 않는다.
- 확인하면 기존 `reset` mutation을 그대로 호출한다. 서버의 차감·검증 로직은 변경하지 않는다.

## 오류 처리와 테스트

기존 서버 오류 토스트와 원자적 저장 흐름을 유지한다. 컴포넌트 회귀 테스트는 계산된 비용과 보유 골드가 모달 옵션에 포함되는지, 취소 시 `fetch`가 호출되지 않는지를 검증한다. 기존 초기화 성공·실패 테스트는 확인 후 요청과 잔액 반영이 그대로 동작하는지 보호한다.
