# 거래소 낙찰 알림 (#655)

현재 경매 정산은 구매자 보관 데이터에 물품을 직접 지급하고 판매자에게만 대금 우편을 보낸다. 구매자에게는 우편도 일반 알림도 없어 낙찰과 입수를 확인하기 어렵다.

낙찰 시 `auction_won` 일반 알림 한 건에 품목 이름, 수량, 최종 낙찰가와 지급 완료 사실을 표시한다. 정산 트랜잭션 안에서 기존 `insertNotificationWith`로 저장한다. 정산 실패 시 함께 롤백하고 이미 종료된 매물은 기존 잠금·상태 검사로 중복 처리하지 않는다. 판매자 정보는 포함하지 않는다.

기존 알림 종과 알림 센터에 같은 문구를 표시한다. 알림 종에서 누르면 기존 일반 알림처럼 알림 센터로 이동한다. 푸시는 커밋 후 기존 구독자 전송 함수를 사용하고 실패해도 정산을 실패시키지 않는다. 푸시 태그에는 매물 ID를 넣어 서로 다른 낙찰이 덮어써지지 않게 한다.

우편으로 바꾸는 방식은 불필요한 수령 단계를 만들고, 화면 토스트만 사용하는 방식은 오프라인 낙찰을 놓치므로 채택하지 않는다. 전투·제작 등 다른 아이템 입수 경로는 이 건의 범위에 포함하지 않는다. 기존 5분 정산과 알림 배지 폴링 주기는 유지한다. 배포와 건의 답변 등록은 수행하지 않는다.

검증: 정산 성공 시 구매자 알림, 유찰·지급 실패·기정산 시 미발생, 재실행 중복 방지, 알림 저장 실패 롤백, 커밋 후 푸시 및 푸시 실패 격리, 실제 알림 종 렌더링, 기존 거래 제한 회귀 테스트와 타입 검사.
