# 복합 스킬 회복 로그 표시

운영 리플레이에서 성전의 심판의 회복과 실제 HP 증가는 확인됐지만 신고 화면에서는 피해가 있는 시전의 회복 내역이 보이지 않았다. 현재 로컬 표시 코드는 피해와 회복을 별도 행동으로 분리한다. 같은 시전의 공격 카드에 회복을 부가 효과로 붙여 두 결과를 함께 확인하게 한다.

엔진에서 로그 종류를 변경하는 방식은 저장된 리플레이에 적용되지 않는다. 별도 회복 카드는 하나의 시전을 두 행동처럼 보이게 하므로, 표시 단계에서 같은 스킬·주체·틱의 피해와 HP/마나 회복을 묶는다. 틱 없는 레거시 로그는 바로 이어진 같은 스킬의 회복만 묶는다. 회복만 발생한 시전은 독립 카드로 유지한다.

전투 계산, 저장 데이터, 표면 스타일은 변경하지 않는다. 익명화한 신고 전투의 회복량(6143/10753/14384)을 회귀 사례로 쓰고, 양쪽 주체·두 스킬·반복 시전·다른 틱을 검증한다. 운영 원본이나 계정 식별자는 저장소에 넣지 않는다.
