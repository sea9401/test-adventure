# 경매장 건의 #658

- 내 거래에 미판매 종료 탭: 본인이 등록한 expired/cancelled 이력만 종료 최신순 100건. 기존 체결 내역과 공개 거래 이력은 유지한다. 아이템 옵션과 등록가, 만료/취소 상태를 보여준다.
- 기존 품목별 즐겨찾기를 유지하고 개별 등록 ID로 관심 매물을 저장한다. 브라우저 저장소를 사용하며 최대 200건. 장비·재료·소모품 모두 지원한다. 관심 매물 필터는 서버에서 ID로 조회하여 최신 500건 밖의 활성 매물도 조회한다. 종료된 관심 매물은 활성 목록에서 제외된다.
- 남은 시간 짧은순/긴순: bidEndsAt 기준. 등록 기간과 입찰 연장을 반영하며 서버에서도 제한 적용 전에 정렬한다.
- 기존 인증·조회 제한·식별자 비공개 정책 유지. 로컬 구현/검증/커밋, 배포 없음.
