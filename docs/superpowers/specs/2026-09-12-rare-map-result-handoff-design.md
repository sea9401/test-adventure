# 희귀 탐사 완료 결과 유지 (#651)

희귀 지도를 소진한 응답에서 일반 사냥으로 이동하면 페이지의 전투 세션 key가 변경되어 결과가 사라진다. 세션 key는 이전 요청의 busy 상태를 차단하므로 유지한다.

던전 공통 레이아웃의 `DungeonResultHandoffProvider`에 완료 콜백으로 마지막 서버 전투 결과를 전달하고, 일반 사냥 화면 생성 시 표시 결과의 초기값으로 사용한다. 기존 만료·수동 복귀 콜백은 결과를 전달하지 않는다. 목적지 페이지는 초기 결과를 전달한 뒤 전달값을 비워 이후 다른 사냥터 방문에 오래된 결과가 재등장하지 않게 한다. 서버 보상 적용은 기존 전투 처리에서 한 번만 수행한다.

결과 카드와 리플레이는 기존 컴포넌트를 사용한다. 일반 사냥 버튼은 저장된 횟수로 바로 실행되며 요청에 소진된 지도 iid를 포함하지 않는다. 일반 사냥의 새 결과가 도착하면 표시 결과를 대체한다. 레거시 깊이에서 대표 사냥 깊이로 이동할 때도 결과를 전달한다.

검증: 실제 페이지·전투 화면·사냥 훅을 렌더하고 HTTP/라우터 경계만 대체한다. 마지막 전투 → 일반 URL 전환 → 결과 유지 → N회 일반 사냥 요청 및 결과 교체 → 재방문 시 결과 미복원 흐름을 검증한다. 기존 요청 중 복귀 회귀 테스트도 유지한다.
