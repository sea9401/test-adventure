# 목장 사료 모두 채우기 (#665)

- 목장 요약에 `사료 모두 채우기` 버튼을 추가한다.
- 생산 시간을 정산한 뒤 닭장·외양간의 빈 사료 용량을 부지 순서대로 채운다. 사료가 부족하면 보유량만 사용한다.
- 돼지 입식은 기존 별도 동작으로 유지한다. 버튼 설명에 대상을 표시한다.
- 기존 사료 API에 `slotId: "all"`을 추가하고 저장 잠금이 걸린 트랜잭션 안에서 일괄 처리한다. 개별 요청 반복보다 요청 수가 적고 차감과 저장을 원자적으로 처리할 수 있다.
- 잠금 상태, 사료 없음, 충전 대상 없음, 충전 진행 중에는 버튼을 비활성화한다.
- 회귀 테스트로 용량, 부족분, 정산, 돼지 제외, 중복 충전 및 접근 제한을 확인한다.
- 로컬 구현·검증·커밋만 수행한다.
