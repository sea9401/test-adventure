# 그림자 도약 사용자 패턴 존중

피드백 #668: 그림자 도약의 HP 조건이 첫 턴 조건으로 덮어써진다.
사용자가 원하는 시점에 쓰도록 수정 요청했으므로 추가 설계 승인 없이 진행한다.

공유 `effectiveCombatPatternFromEquipped`에서 그림자 도약 강제 삽입과
기존 블록 제거를 없앤다. 저장된 패턴의 조건·순서를 존중하고, 사용자가
제외한 스킬을 다시 추가하지 않는다. 미설정·빈 패턴은 기존 기본 패턴을
사용한다. 기본 패턴의 첫 행동과 전투당 1회 제한은 유지한다.

조건이 있는 블록만 예외 처리하면 순서 변경·패턴 제외 요청은 계속 무시된다.
기본 패턴까지 바꾸면 미설정 캐릭터 동작도 달라진다. 공유 보정의 강제
삽입만 제거하는 범위가 요청에 맞는다. PvE·PvP·편집기는 같은 함수를 쓴다.

실제 시전 테스트로 HP 조건, 후순위, 제외, 전투당 1회와 기본 패턴을 검증한다.
저장 데이터 마이그레이션은 하지 않는다. 기존에 저장된 첫 턴 조건은
사용자가 원하는 조건으로 다시 편집할 수 있다. 배포·외부 쓰기는 수행하지 않는다.
