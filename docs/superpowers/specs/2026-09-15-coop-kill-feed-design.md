# 협동 보스 처치 피드 공개 범위

전체 소식이 비공개 보스 처치로 도배된다는 건의를 반영한다. 처치 알림 전체 제거는 공개 토벌의 종료 안내도 없애므로, 제안된 대안인 전체 공개 보스만 기록하는 방식을 적용한다.

- 공격 트랜잭션에서 잠근 세션의 공개 범위로 피드 발행 여부를 결정한다.
- `summoner_only`, `guild_only`는 전체 처치 피드를 만들지 않는다. 기존 공개 범위 파서의 레거시 public 처리를 유지한다.
- 일반 공격과 무료 지원에 동일하게 적용한다. 기여자 개인 알림, 기여도, 확정타 보상은 유지한다.
- API 응답 형식은 유지하고 과거 피드는 삭제하지 않는다. 배포는 하지 않는다.
- 공개 범위별 처치, 비처치, 잠금 전후 공개 범위 변경을 라우트 테스트로 검증한다.
