# 협동 보스 소환 설정과 일괄 변경

건의 #678: 소환마다 무료 지원을 다시 켜는 불편과 여러 보스의 설정 변경을 줄인다.

## 선택과 동작

- 계정별 `coop-preferences.v2`에 `autoFreeSupport`를 저장한다. 기본값은 false다. 화면 재진입과 다른 기기에서도 유지한다.
- 소환서 및 낚시 출현/미끼 소환에 이 값을 적용한다. 소환 API의 명시적인 `allowFreeSupport`는 기존 호환성을 위해 우선한다. 공개 범위는 기존대로 나만이다.
- 소환 목록에서 자동 무료 지원 설정을 켜고 끈다. 저장 성공 전에는 소환을 잠시 막고, 실패를 표시한다.
- 내 보스 일괄 설정은 화면에 표시된 진행 중인 내 보스를 대상으로 한다. 무료 지원과 공개 범위에 각각 변경 안 함을 제공한다. 적용 버튼을 눌러야 변경한다.
- 기존 개별 API를 순차 호출한다. 일괄 서버 API보다 요청 수는 늘지만 소유권, 세션 잠금, 공개 알림, 길드 스냅샷 정책을 그대로 재사용할 수 있다. 성공한 변경은 유지하며 실패와 건너뜀을 따로 알린다.
- 전체 공개한 보스의 범위 축소는 건너뛴다. 무료 지원 변경은 별도로 적용할 수 있다. 길드 없는 사용자의 길드원만 요청은 기존 API처럼 나만으로 적용하며 안내한다.
- 새 소환 자동 설정은 기존 보스를 바꾸지 않는다. 일괄 변경은 다음 소환의 기본값을 바꾸지 않는다.

## 검증 및 범위

인증·입력 검증·저장 재조회·소환 기본값과 명시값 우선순위·낚시 소환을 테스트한다. UI 재진입, 일괄 요청 대상, 부분 실패, 전체 공개 제한, 요청 중 중복 실행 방지와 결과 안내를 검증한다. 패널은 공통 불투명 표면을 사용하며 모바일에서 컨트롤이 줄바꿈되도록 한다. 배포와 외부 답변 전송은 하지 않는다.
