# 길드 창고 장비 상세·비교 (#671)

보관 장비마다 상세·비교 버튼을 제공한다. 기존 V2ItemCard와 V2ItemCompareCard를 재사용해 제작 정보, 옵션, 세트 효과와 같은 부위 착용 장비의 차이를 조회한다. 착용 장비가 없으면 상세만 제공한다. 입출고 권한과 무관하게 조회할 수 있으며 장착·입출고 동작은 연결하지 않는다.

GET 응답에 equippedEquipment를 별도로 추가한다. 입고 후보 personalEquipment의 거래 가능 필터는 유지한다. 착용 장비는 귀속·잠금 여부와 무관하게 비교에 포함한다.

별도 상세 화면이나 자체 비교 계산은 기존 UI와 중복되므로 사용하지 않는다. 기존 불투명 팝업을 재사용하며 선택 모달 동작은 유지한다.

검증: 조회 전용 길드원 상세 열기, 동일 부위 비교, 미착용 시 상세만 제공, 닫기, API의 입고 후보/착용 장비 분리.
