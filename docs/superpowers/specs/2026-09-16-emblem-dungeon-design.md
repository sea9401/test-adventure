# 던전 선택과 문장 성장

## 합의된 동작

원정 메뉴를 던전으로 바꾸고 선택 화면에서 폭풍 원정과 태초의 성소로 진입한다. 폭풍 원정은 기존 기능을 유지한다. 태초의 성소는 미개척지 해금 이후 입장 가능하며 던전별 입장 횟수는 한국 날짜 기준 하루 3회로 독립적이다.

태초의 성소는 일반 2연전 → 보급 → 일반 2연전 → 휴식 → 정예 → 제단 → 수호자 → 최종 정비 → 최종 보스 순서의 일자길이다. 보급·휴식·제단의 효과 선택은 유지한다.

문장은 HP, MP, 힘, 활력, 민첩, 지능, 정신, 행운 8종이다. 거래할 수 없고 4개 전용 슬롯에 동일 종류도 장착 가능하다. 동일 개체를 두 슬롯에 넣을 수 없다. 캐릭터 드롭다운과 캐릭터 홈의 문장 메뉴에서 장착·해제·합성을 제공한다.

문장 장착 중 실제 레벨업 때 각 문장마다 독립적인 정수 균등 추첨으로 추가 성장한다. 얻은 능력치는 문장 해제로 소실되지 않는다. 미장착 레벨업 및 과거 레벨에 소급하지 않는다. 문장 개체에 성장 수치를 저장하지 않는다.

| 등급 | HP | MP | 각 스탯 | 다음 등급 성공률 |
|---|---|---|---|---|
| 1 | 0~3 | 0~2 | 0~1 | 35% |
| 2 | 0~6 | 0~4 | 0~2 | 20% |
| 3 | 0~10 | 0~7 | 0~4 | 8% |
| 4 | 0~18 | 0~11 | 0~6 | 2% |
| 5 | 0~30 | 0~18 | 0~9 | 최대 등급 |

같은 종류·등급의 문장 하나를 재료로 사용한다. 성공하면 대상 문장 등급 +1, 실패하면 대상 유지. 재료는 결과와 관계없이 소모한다. 장착된 재료는 해제 후 사용하도록 제한해 의도치 않은 슬롯 변경을 방지한다.

일반 전투 승리마다 5%, 정예·수호자 승리마다 15%, 최종 보스 승리에는 문장 하나 확정. 문장 종류는 각각 12.5%, 등급은 독립적으로 1등급 89% / 2등급 10% / 3등급 1%. 4·5등급은 합성 전용이다.

## 구현 경계

문장은 일반 거래 장비 카탈로그에 넣지 않는다. 소유·장착은 서버 권위 저장 상태이며, 변경과 보상은 캐릭터 행 잠금 아래 트랜잭션으로 처리한다. 슬롯 변경과 합성에는 상태 버전 검사를 사용해 중복 요청을 거절한다. 확률은 서버에서만 굴린다.

UI는 기존 PageShell, SubViewHeader와 불투명 SURFACE_CARD/SURFACE_INSET를 사용한다. 모든 확률, 거래 불가, 합성 실패 시 재료 소모, 장착 중 레벨업 성장 규칙을 화면에 표시한다.

## 기존 시스템과의 연결

사용자 승인에 따라 미개척지가 포함된 main(b0f234fd3)을 기준으로 구현했다. 미개척지 기능이 활성화되어 있고 현재 레벨 100 이상이거나, 기존 재전직 처리에서 보존한 최초 탐사 포인트가 있으면 성소 입장이 가능하다.

문장 종류·등급·소유·슬롯은 character.v2.emblems에 저장해 일반 장비 거래 목록과 분리한다. 슬롯/합성 변경과 성소 전리품 수령은 모두 character.v2 행 잠금 아래 수행한다. 문장 상태와 성소 진행에 독립적인 revision을 사용해 중복 요청을 거절한다.

사용자가 재전직 시 추가 성장 초기화와 수행 한계치 적용을 최종 확정했다. 스탯 추가 성장은 기존 grown과 수행 한계치를 사용한다. HP·MP 추가 성장은 proficiency.v2.emblemCycleGrowth에 저장해 장착 해제에도 보존한다. resetLevelGrowth에서 다른 생애 성장과 함께 초기화하며 문장 아이템·등급·장착 상태는 유지한다. 전투에서의 HP·MP 계산은 문장 착용 여부와 무관하게 이 누적분을 반영한다.

일반·희귀·미개척지·오프라인 사냥이 공유하는 applyHuntProficiency와 경험치 비약/목표 레벨 부여 처리에서 실제 상승한 레벨마다 독립 추첨한다. 신규 문장 던전 자체는 기존 원정처럼 경험치를 지급하지 않는다.

성소의 전투·보급·회복 효과는 기존 원정의 공통 모듈을 사용한다. 난이도는 기존 부유 잔해지 전투 수치를 기준으로 하고 성소용 이름을 사용한다. 분기 선택·위험 이벤트·골드 보상은 제공하지 않는다. 일반 2연전의 각 적마다 문장 드롭을 판정해 한 번의 완주에서 7회 판정한다. 전리품은 기존 원정과 동일하게 귀환/완주 때 확정하고 패배 때 소실된다.

폭풍 원정의 실전 횟수를 소진해도 선택 화면에서 기존 무제한 연습 모드로 진입할 수 있다. 캐릭터 홈/드롭다운, 던전 선택, 일일 활동 목록과 매뉴얼을 함께 갱신했다.
