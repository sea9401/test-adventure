# 건의 #685

정신 설명은 실제 자원 성장 버전별 계산을 따른다. 최신 방식은 보정 전 INT/SPI의 15 초과분을 각각 최대 MP에 더한다. 생애 시작 SPI는 시작 MP와 레벨 성장 하한에 관여하며 관련 숙련도 보정은 별도다. 공통 안내 컴포넌트를 두 안내서에 재사용하고 툴팁도 정정한다. 전투 밸런스는 변경하지 않는다.

관심매물은 기존 savesKv의 계정별 전용 키에 최대 200개를 저장한다. 전체 목록 덮어쓰기 대신 추가/삭제/비우기/가져오기 명령을 트랜잭션으로 처리한다. 최초 행 생성도 충돌 안전하게 처리한 후 행을 잠근다. 인증 및 요청 제한을 적용한다. 화면 진입과 창 복귀에 다시 읽는다. 저장 중 중복 조작은 막고 실패 시 기존 목록을 보존한다.

기존 localStorage는 계정 식별자가 없으므로 자동 귀속시키지 않는다. 사용자가 가져오기 버튼을 누르면 계정 목록과 합치고, 성공했을 때만 로컬 원본을 지운다. 200개 초과는 조용히 유실하지 않고 오류로 알린다. 브라우저만 유지하는 방식은 기기 간 공유를 못 하고, 전체 목록 업로드는 다른 기기의 변경을 덮어쓸 수 있어 채택하지 않는다.

회귀 검증: 계정 분리, 인증/입력/한도, 명령별 보존, 새 기기의 목록 복원, 실패/재시도, 기존 목록 가져오기, 화면 재진입. 로컬 변경만 수행한다.
