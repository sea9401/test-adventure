# 결투가 패턴 블록 보존 (#687)

## 원인과 목표

패턴 편집 화면이 로드할 때 전투용 `effectiveCombatPatternFromEquipped`를
호출하여 하위 결투 선언 블록을 제외한다. 서버 파서는 네 선언을 모두
보존하지만 화면 재진입 뒤 다시 편집·저장하면 제외된 블록이 실제로 유실된다.

저장한 조건·행동·순서는 편집 화면에서 그대로 유지한다. 미설정·빈 패턴만
기존 스마트 기본 패턴으로 보완한다. 전투에서는 기존 설계대로 최고 선언만
시전하고 장착한 하위 선언 효과를 합성한다.

## 선택한 수정

편집 화면은 저장 블록을 직접 읽고 기본값 생성만
`smartDefaultPatternFromEquipped`에 맡긴다. 전투 필터를 변경하면 결투가
전투 규칙까지 바뀌며, 하위 선언 선택을 막으면 기존 패턴을 보존하지 못하므로
채택하지 않는다.

상위 선언에 연계되어 건너뛰는 블록에는 시전되지 않는 이유를 표시한다.
미장착 선언은 기존 미장착 안내를 사용하며 효과가 합쳐진다고 안내하지 않는다.
교대 사용 블록도 보존하되 하위 선언 포함 시 블록 전체가 건너뛰어지는 현재
전투 규칙을 안내한다. 안내는 기존 불투명 카드 안의 텍스트로 표시한다.

## 검증 범위

- 신고 순서의 네 선언이 저장·탭 재진입·프리셋 재적용 후 유지된다.
- 재진입 후 편집 자동 저장과 프리셋 저장 요청에 모든 블록이 포함된다.
- 교대 블록 및 미장착 스킬 참조도 보존한다.
- 미설정·빈 패턴의 스마트 기본값과 PvE/PvP 선언 합성 규칙을 유지한다.
- 회귀 테스트, 관련 기존 테스트, 타입 검사, 변경 파일 린트를 실행한다.

운영 데이터 변경이나 배포는 범위에 포함하지 않는다.
