# 문장 보관함 정렬과 장착 표시 (#691)

## 문제와 결정

문장 보유 목록은 획득 순서로만 표시되고 장착 상태는 작은 보조 문구에 섞여 있다.
종류별 그룹 구획은 목록을 길게 만들고, 필터만 제공하면 다른 보유 문장이 숨겨진다.
이번에는 모든 문장을 유지하는 정렬 선택과 눈에 띄는 장착 배지를 추가한다.

- 기본값 `종류순`: HP, MP, 힘, 민첩, 활력, 지능, 정신, 행운 순서이며 같은 종류는 높은 등급부터 표시한다.
- `등급순`: 5등급부터 1등급까지, 같은 등급은 위 종류 순서로 표시한다.
- `획득순`: 서버의 기존 보유 배열 순서를 표시한다. 종류·등급이 같으면 이 순서를 유지한다.
- 정렬은 화면의 사본에만 적용한다. 문장 번호는 원래 보유 배열의 위치를 사용해 합성 재료 선택과 일치시킨다.
- 장착된 각 문장은 제목 옆에 `장착 중 · 슬롯 N` 배지를 표시한다. 종류·등급이 같은 다른 개체에는 표시하지 않는다.
- 서버에서 장착·해제·합성 결과를 받으면 현재 정렬을 유지하며 목록과 배지를 갱신한다.
- 정렬 선택은 이 화면의 React 상태로 유지한다. 저장 API나 계정 설정은 추가하지 않는다.
- 최상위 표면과 카드는 기존 불투명 토큰을 사용하고 정렬 입력은 `SURFACE_INSET`을 사용한다. 모바일에서는 컨트롤이 줄바꿈된다.

## 범위와 검증

서버 API, 저장 형식, 장착·합성 규칙은 변경하지 않는다. 정렬 모델의 순서·불변성 검증,
화면의 정렬 전환·개체별 배지·장착/해제 갱신·정렬 후 장착 및 합성 요청을 검증한다.
기존 문장 관련 테스트, TypeScript, 변경 파일 ESLint를 실행한다.
