# 사람 확인 대기 복구

낚시 화면에서 Turnstile이 콜백 없이 대기하면 현재 앱은 재시도 경로를 표시하지 않는다. 실제 이용자의 브라우저에서 인증이 지연된 원인은 확정하지 않았으며, 이번 변경은 이 대기 상태의 복구 경로를 제공한다.

공용 `ActivityVerificationGate`에서 스크립트 로드와 Turnstile 결과를 기다리는 시간을 30초로 제한한다. 시간이 지나면 기존 오류 상태로 전환하여 안내와 수동 재시도를 제공한다. 표시된 위젯은 유지하므로 늦게 완료된 정상 인증도 처리할 수 있다. 추가 hCaptcha 위젯이 준비되어 이용자가 문제를 푸는 동안에는 자체 타이머를 적용하지 않는다. 서버 검증은 기존 요청 제한 시간을 유지한다.

Turnstile의 timeout/unsupported 콜백도 오류 안내로 연결하고, 자동 재시도·시간 초과 갱신·토큰 만료 갱신을 끈다. 수동 재시도는 기존 위젯을 제거하고 새 위젯을 만든다. 필수 스크립트가 준비되지 않았다면 Next Script 캐시로 재시도가 무효화되지 않도록 페이지 새로고침을 제공한다.

팝업이 필요하지 않다는 안내와 지속 실패 시 브라우저·콘텐츠 차단·네트워크 확인 안내를 추가한다. 패널은 `SURFACE_ACCENT`로 라이트/다크 모두 불투명하게 유지한다. 인증을 우회하거나 서버 보호 정책을 변경하지 않는다.

대안인 무제한 자동 재시도는 사용자가 같은 상태에 갇힐 수 있어 선택하지 않았다. 무조건 새로고침하는 방식보다 정상 로드된 위젯만 재생성하는 방식이 현재 화면 상태를 보존한다.

검증: 가짜 타이머와 외부 SDK 경계의 테스트 더블로 무응답, 스크립트 미로드, SDK 시간 초과, 수동 복구 후 정상 제출, 서버 확인 중 타이머 취소, 추가 CAPTCHA 대기, 언마운트 정리를 검증한다. 실제 모바일 Cloudflare 통과 여부는 로컬 테스트로 확정하지 않는다. 배포는 하지 않는다.
