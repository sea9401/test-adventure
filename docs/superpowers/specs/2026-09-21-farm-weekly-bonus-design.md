# 주간 납품 선택 보너스 안내 (#704)

현재 운영 코드와 로컬 코드는 희귀 작물 보유 시 1개를 소모하고 추가 증표를 지급한다. 제보 계정을 읽기 전용으로 조회한 결과 현재 농장에는 희귀 작물이 없고 이번 주 기본 3종 납품은 완료되어 있다. 납품 당시 보유량은 확인하지 못했으므로 보상 누락이나 사용자 착오로 단정하지 않는다.

보상 계산 변경은 근거가 없어 하지 않는다. 현재 화면은 보유량과 관계없이 같은 선택 보너스 설명을 표시하므로, 희귀 작물 보유량과 적용 가능 여부를 별도로 표시한다. 미완료 주문은 보너스 포함 예상 증표를 표시한다. 완료 주문은 현재 보유량으로 과거 보상을 추정하지 않고 기본 보상과 완료 상태만 표시한다. 기존 불투명 카드 표면을 유지한다.

API 테스트는 실제 파싱·납품 함수를 사용하고 DB 입출력만 대체한다. 전체 11종의 보너스 지급·희귀 작물 1개 차감, 미보유 기본 보상, 중복·한도·재료 부족 시 무변경을 확인한다. UI 테스트로 미보유/보유/완료 상태를 검증한다. 운영 데이터 수정, 보상 지급, 피드백 답변 전송, 배포는 하지 않는다.
