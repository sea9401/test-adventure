## 설계

실제 미개척지 몬스터 정의 36개에 지정 장비 ID를 필수 필드로 둔다. 기존 별의 무덤
선택 기능을 복원하거나 일반 장비 풀에 섞는 방법은 대상 지역과 확률이 달라지므로
채택하지 않는다. `buildUnexploredRewardPlan`이 실제 poolId/monsterId로 장비를 찾고,
`rollUnexploredHuntRewards`가 기존 모든 RNG 뒤에서 독립적으로 판정한다.

- 해당 특화 몬스터 처치당 0.4%, 해당 몬스터군 집중 강화 시 0.6%.
- 기본 몬스터·일반 사냥·희귀 지도에는 적용하지 않는다.
- 장비·재료·희귀·풀 전리품 보너스 및 희귀 복사로 확률이나 수량을 바꾸지 않는다.
- 성공 시 `droppedEquipments`와 equipment/special 몬스터 보상 기록에 1개를 추가한다.
  기존 라우트가 개체 발급·품질 굴림·인벤토리 저장·응답·일괄 보상을 처리한다.
- 같은 장비 중복 획득을 허용한다. 개척자 무기와 재료·흔적·SP 열매 RNG는 보존한다.
- 노드 보상 미리보기에 몬스터별 장비와 처치당 확률을 표시한다. 매뉴얼의 삭제된
  별의 무덤 선택 안내를 실제 노드 조건으로 고친다.
- DB 형식·전투·세트 수치 변경 없음.
