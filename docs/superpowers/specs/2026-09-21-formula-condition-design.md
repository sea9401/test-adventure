# 완전식 발동 조건 (#693)

완전식은 3단계를 완성한 현재 주문에 발동하고 즉시 초기화된다. 따라서 보유 스택을 3과 비교하는 조건은 성립하지 않는다. 단순 2단계 이상 비교도 2단계 주문과 같은 주문 중복 제외를 반영하지 못한다. 선택된 스킬의 완전식 완성 여부를 미리 판정하는 방식을 사용한다.

`formula_completion` 조건에 `active: boolean`을 저장한다. 화면에서는 ‘완전식 발동’과 ‘발동할 때/발동하지 않을 때’를 제공하며, 선택한 스킬로 주문식 3단계를 완성하는지 확인한다는 설명을 붙인다. 기본값은 발동할 때다.

PvE/PvP는 기존 완전식 시전 미리보기로 완성 가능한 장착 스킬 ID 목록을 만든다. 완전식 패시브가 없으면 목록은 비어 있다. 최적화 장착 여부는 조건 판정과 무관하며 MP 부족 허용에만 사용한다. 패턴 평가기는 특정 스킬, 교대의 현재 차례 스킬, 역할로 선택된 스킬에 대해 조건을 평가한다. 일반 공격은 완전식을 발동하지 않는 행동이다. AND/OR에도 동일한 스킬 ID를 전달한다. MP/쿨다운/발동 확률과 주문식 전투 규칙은 유지한다.

기존 패턴 파서와 프리셋 저장 경로를 사용하고 아레나 요약도 지원한다. 배포와 외부 피드백 상태 변경은 범위 밖이다. 기존 화면의 불투명 표면을 재사용한다.

검증: 저장 왕복과 잘못된 active 거부, UI 선택, 복합/교대/역할/일반 공격, PvE와 PvP 양쪽 공격자, 단계 경계/중복 주문/2단계 변형/패시브 미장착/발동 후 초기화/MP와 쿨다운.
