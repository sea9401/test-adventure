# 길드장 3일 미접속 시 승계

사용자 요청: 길드장이 3일 이상 미접속이면 다른 길드원이 길드장 자리를 직접 넘겨받는다.

- 자동 선출이나 운영자 수동 처리 대신 길드원 탭에 `길드장 승계` 버튼을 둔다. 일반 길드원과 관리자 모두 신청할 수 있고 먼저 성공한 사람이 승계한다. 가입 기간·기여도 조건은 추가하지 않는다.
- 마지막 접속은 기존 `presence.lastSeenAt`으로 판정한다. 서버 기준 연속 72시간 이상이어야 한다. 기록이 없으면 미접속으로 단정하지 않고 승계를 막는다.
- 길드 정보 API가 승계 가능 여부를 제공하고 실행 API가 다시 검증한다. 현재 길드장 ID도 요청에 포함하여 화면 조회 이후 길드장이 바뀌면 거절한다.
- 실행 트랜잭션은 길드 행을 잠근 다음 현재 신청자 멤버십과 길드장 접속 행을 잠가 재검증한다. 해산·탈퇴·추방·기존 양도와의 경쟁을 방어한다. 접속 갱신이 먼저 완료되었다면 승계를 거절한다.
- `guilds.masterId`, 신청자 `role=master`, 전임자 `role=member`를 함께 변경하고 `leadership_claim` 활동 내역을 남긴다. 신청자 접속 기록도 현재 시각으로 갱신해 곧바로 다시 빼앗기는 일을 막는다.
- 기존 길드장은 길드에 남고 복귀 시 자동 복권되지 않는다. 길드 재산·멤버십·탈퇴 쿨다운에는 변화가 없다.
- 불투명 표면 토큰을 사용한다. 확인창, 처리 중 비활성화, 서버 거절 안내, 성공 후 정보/권한 새로고침을 제공한다. 매뉴얼에 조건과 결과를 명시한다.
- DB 스키마 변경은 없다. 운영 데이터 변경·배포·외부 답변 등록은 수행하지 않는다.

검증: 72시간 경계, 미인증/무소속/본인/변경된 길드장/해산/접속 기록 누락/최근 접속/멤버십 상실, 성공 시 원자적 역할 변경과 활동 기록, 중복 요청, UI 승인/취소/실패/갱신을 확인한다.
