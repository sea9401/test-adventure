# 숙련의 탑 기본 입장 체크포인트 수정

신고 #699: 날짜 변경 후 1층에서 시작하고 79층 패배 후 81층 체크포인트가 표시됨.
현재 코드는 역대 최고층 체크포인트를 보존하지만, 전투 화면의 이어 하기 요청처럼
`startFloor`가 없는 요청은 날짜 정산으로 `runFloor`가 0이 되면 1층을 선택한다.
패배 후 입장 화면은 보존된 기록을 사용하므로 81층을 다시 기본 선택할 수 있다.
운영 계정의 실제 요청 이력은 조회하지 않았으므로 신고 당시의 진입 경로는 미확정이다.

화면에서만 새 날짜를 감지하는 방법보다 서버의 공통 시작층 판정을 수정한다.
새 등반에서 시작층을 생략하면 기존 체크포인트를 기본값으로 사용하고, 체크포인트가
없으면 1층으로 시작한다. 명시적인 1층 선택, 진행 중 다음 층, 100층 연습,
잘못된 시작층 거부, 보상과 스태미나 정산 규칙은 유지한다.

일반 날짜 변경과 월요일 변경, 이미 주간 기록이 초기화된 저장, 패배 후 재입장을
회귀 테스트한다. 실제 정산 헬퍼에서 받은 상태를 입장 판정에 연결해 전날 보상과
오늘 보상 및 입장료 상태도 함께 확인한다. 운영 데이터 수정과 배포는 범위에 없다.
