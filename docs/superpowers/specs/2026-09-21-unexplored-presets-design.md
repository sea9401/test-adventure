# 개척 노드 독립 프리셋 (#697)

- 프리셋은 모든 계정에 3개를 제공한다. 기존 배분은 1번에 보존하며 2·3번은 빈 배분으로 시작한다.
- 탐사 경험치, 획득 포인트, 업적, 흔적, 제작 영수증은 계정 내 공유한다. 각 프리셋은 획득 포인트 한도를 독립적으로 사용한다.
- 프리셋 전환은 무료다. 선택한 프리셋만 탐사 효과와 사냥 진입 조건에 반영한다. 빈 프리셋도 기존과 같이 시작 노드를 활성화해야 사냥할 수 있다.
- 각 프리셋의 배분 변경은 즉시 저장한다. 복사·덮어쓰기·슬롯 삭제는 제공하지 않는다. 반환과 초기화는 현재 프리셋에만 적용하고 시작 노드를 제외한 반환 노드당 500,000G를 기존 보유/은행 골드 결제 규칙대로 지불한다.
- `UnexploredSave`에 `activePresetIndex`(0~2), `nodePresets`(3개 노드 배열)를 추가한다. 기존 `selectedNodeIds`는 활성 배분으로 유지한다. 파서는 이를 활성 슬롯에도 동기화하므로 기존 사냥·성장·제작 저장 경로를 보존한다.
- 서버는 기존 캐릭터 행 잠금 트랜잭션 안에서 프리셋을 바꾼다. 클라이언트는 `expectedPresetIndex`를 보내며 실제 활성 슬롯과 다르면 변경을 거절한다. 구 클라이언트의 인덱스 없는 요청은 1번 대상으로 해석한다.
- UI는 독립 프리셋 1·2·3 버튼, 현재 선택, 슬롯별 사용 포인트와 비용 정책을 표시한다. 요청 중 전환을 잠그고 실패하면 이전 화면을 유지한다. 초기화 확인에는 대상 프리셋을 명시한다. 불투명 surface 토큰을 사용한다.
- 검증: 기존 저장 이전, 세 슬롯 독립성, 무료 전환, 공유 진행도, 개별 비용과 잔액 부족, 잘못된/오래된 요청 거절, 활성 사냥 효과, UI 전환·실패·요청 중 잠금, 관련 테스트·타입 검사·린트.
- 배포·푸시·피드백 상태 변경은 범위에 포함하지 않는다.
