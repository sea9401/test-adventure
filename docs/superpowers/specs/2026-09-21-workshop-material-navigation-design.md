# 제작 재료 수급처 바로 이동 (#698)

부족 재료 입수처의 사냥 링크가 `/battle`로 고정되어 지역 정보가 이동에 반영되지 않는다. 공용 재료는 실제 드랍 규칙의 최소 깊이, 몬스터 재료는 사냥 몬스터 도감의 첫 출현 깊이를 사용해 기존 `normalHuntFloorHref`로 해당 사냥 단계에 연결한다. 심해성철처럼 지역 최심부부터 나오는 재료도 정확한 단계로 안내한다.

전투 메뉴 링크 유지와 지역 목록 펼치기보다 사냥 단계 직접 연결이 요청에 맞고 추가 선택을 줄인다. 기존 사냥터 해금 검증과 전투 시작 절차를 유지한다. 채집·협동 보스·원정·거래소 링크와 표시 문구는 유지한다. 새로운 서버 요청이나 자동 전투는 추가하지 않는다.

모든 공용·몬스터 재료의 목적지와 해당 단계의 실제 드랍 가능성을 검증하고, 렌더링된 일반·명장 제작 부족 재료 링크도 확인한다. 배포·외부 피드백 갱신은 범위에 포함하지 않는다.
