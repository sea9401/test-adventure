# 추석 이벤트

- 이벤트 화면에 추석 탭을 추가한다. 기간 안내 아래에 출석·복주머니 하위 탭을 두고 출석을 기본으로 연다. 토벌 결과와 전투 로그는 복주머니 탭에만 표시한다.
- 배포 시 `CHUSEOK_EVENT_STARTS_AT`에 시간대가 포함된 시작 시각을 지정한다. 시작부터 정확히 10일 동안 참여 가능하고 미설정이면 준비 중이다. 배포/재시작 때 자동 연장하지 않는다.
- 출석 보상은 5·5·10·10·15·15·20개다. 한국 시간 하루 한 번, 빠진 날은 진도를 유지하며 기존 회복약 보관함에 지급한다. 월간 출석과 별도로 기록한다.
- 복주머니는 길드 가입 여부와 무관하게 같은 체력을 공유한다. 체력은 1억, 5억, 10억, 이후 단계당 5억 증가한다. 기존 토벌전처럼 초과 피해를 다음 단계로 넘긴다.
- 공격은 기존 토벌전과 같은 하루 3회이며 스태미나/현재 HP/MP를 소비하지 않는다. 공격력 1, 방어력 10, 특수 기술 없는 허수아비 보스를 기존 토벌전 전투 계산기로 처리한다.
- 이벤트에서 한 번이라도 유효하게 공격한 사용자는 참여 전에 처치된 단계를 포함해 모든 처치 보상을 단계당 회복약 15개씩 우편으로 받는다. 첫 공격 시 이전 단계 보상을 소급 지급하고, 이후 처치에는 해당 처치 공격자를 포함한 참여자 전원에게 지급한다. 한 공격에 여러 단계 처치 시 합산 우편을 지급한다. 2026-09-23 정책 변경 이전 참여자의 누락분은 데이터 마이그레이션으로 보정한다.
- 캐릭터 → 개인 참여 기록 순서로 출석·공격을 직렬화한다. 공격은 전투 계산 후 이벤트에 NO KEY UPDATE 잠금을 걸어 체력을 갱신한다. 신규 참여의 외래키 잠금과 충돌하지 않으며 요청 식별자와 저장된 결과로 공격 재시도를 멱등 처리한다. 체력·참여·우편·공격 기록은 같은 트랜잭션으로 반영한다.
- 화면에는 한국 시간 일정, 출석 보상, 단계/체력, 남은 공격, 개인 누적 피해, 공격 결과 및 보상 규칙을 표시한다. 기존 불투명 카드 표면과 전투 리플레이 UI를 사용한다.
- 로컬 변경·검증·커밋까지만 수행하며 배포하지 않는다.
- 복주머니 일러스트는 기존 산군의 수채화 질감과 색감만 참고해 내장 imagegen 도구로 생성한다. 호랑이 얼굴이나 동물 문양 없이 은은한 구름·꽃 자수와 전통 매듭 장식이 있는 투명 배경 복주머니를 `monster/v2/chuseok-lucky-bag.webp`에 저장하고 이벤트 화면과 전투 리플레이에서 공유한다.
