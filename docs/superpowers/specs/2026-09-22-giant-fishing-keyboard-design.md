# 거대어 낚시 키보드 조작 (#710)

기존 실시간 낚시는 감아올리기 버튼에 포커스가 있을 때만 Enter/Space를 받는다. 버튼 클릭 없이도 조작하도록 공용 실시간 패널에서 키 입력을 받는다. 거대어와 같은 패널을 쓰는 위험 해역 낚시에 함께 적용한다.

- 누르는 동안 감고, 떼면 줄을 푼다. 두 키를 같이 누르면 마지막 키를 뗄 때 풀며 포인터와의 혼합 입력도 유지한다.
- 입력창, 편집 영역, 다른 버튼/링크/대화상자, 조합 입력, 보조 키 조합과 충돌하지 않는다.
- 준비 중, 종료, 포획 확보, 사람 확인 중에는 시작하지 않는다. 창 포커스 상실과 화면 이탈 시 해제한다.
- 버튼 아래에 Enter/Space 사용 안내를 표시하고 기존 불투명 표면을 유지한다.
- 자동 포커스만 주는 방식은 배경 클릭 후 다시 조작이 막히므로 제외한다. 토글 방식은 기존 누름/놓기 모델과 달라 제외한다.
- 서버 API, 난이도, 피드백 접수 상태와 배포는 변경 범위에 포함하지 않는다.

회귀 테스트는 버튼에 포커스가 없는 거대어 조작과 입력 충돌, 잠금, 키 반복, 포커스 이동 후 해제를 확인한다.
