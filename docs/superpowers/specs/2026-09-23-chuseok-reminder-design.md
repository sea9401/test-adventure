# 추석 이벤트 참여 알림

- 월간 출석과 같은 빨간 알림을 메뉴 버튼, 이벤트 링크, 추석 탭에 표시한다.
- 진행 중인 추석 이벤트에서 출석 보상을 받을 수 있거나 복주머니 공격 횟수가 남으면 알린다. 시작 전·종료 후·오늘 참여 완료 상태는 알리지 않는다.
- 추석 하위 출석·복주머니 탭에도 각각 남은 활동을 표시한다. 월간 출석 알림은 유지한다.
- 기존 추석 GET API를 사용하는 공유 클라이언트 캐시를 추가한다. 동시 요청을 합치고 5분 동안 재사용하며, 보이는 페이지에서 1분마다 날짜·기간 경계와 캐시 만료를 확인한다.
- 이벤트 화면의 상태 조회 결과를 같은 캐시에 반영하여 참여 완료가 메뉴와 탭에 함께 반영된다. 늦게 도착한 알림 조회는 이후 갱신을 덮어쓰지 않는다.
- 로컬 변경·검증·커밋만 수행한다. 운영 DB 변경, 배포, 외부 알림은 없다.

기존 출석 알림 확장은 서로 다른 API와 활동 조건을 결합하므로, 추석 전용 공유 훅을 선택한다. 화면에서만 표시하는 방식은 메뉴에서 참여 기회를 발견할 수 없어 사용하지 않는다.
