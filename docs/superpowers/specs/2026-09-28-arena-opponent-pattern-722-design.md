# 아레나 상대 무기·최대 MP 패턴 조건 (#722)

## 목표

아레나에서 상대의 무기 종류와 최대 MP를 기준으로 방어 스킬 우선순위를 다르게 설정할 수 있게 한다. 상대의 실제 공격 속성을 자동 판정하지 않는다. 기존 저장 패턴과 기본 패턴은 변경하지 않는다.

## 동작

- `상대 무기 종류` 조건은 대검·지팡이·활·단검 중 하나를 고른다. 전투 스냅샷의 상대 장착 무기 종류와 정확히 일치할 때만 참이다. 장비 정보가 없거나 무기 종류를 알 수 없으면 거짓이다.
- `상대 최대 MP` 조건은 0 이상의 정수 기준값과 `이상`/`이하` 비교를 제공한다. 전투 중 현재 MP가 감소해도 판정은 바뀌지 않는다. 상대 최대 MP 정보가 없으면 거짓이다.
- 두 조건은 기존 AND/OR 복합 조건 및 블록 우선순위 규칙을 그대로 따른다. 상대가 지팡이를 들고 최대 MP가 일정 값 이상인 경우를 조합할 수 있다.
- 이 정보는 PvP 캐릭터 대전에서 전달한다. 무기 정보가 없는 몬스터에게 무기 조건은 참이 되지 않는다. 다른 PvE 전투 동작과 기존 패턴의 결과는 유지한다.

## 구현 경계

서버의 장비 파생 결과에 무기 종류를 선택적으로 보관하고, PvP 스킬 시전 시 공격자 기준 상대의 최대 MP·무기 종류를 공용 패턴 평가기에 전달한다. 저장 파서는 유효한 무기 종류와 유한한 비음수 정수 MP만 보존한다. 에디터, 아레나 템플릿 요약, 게임 설명서에 두 조건의 의미와 예시를 추가한다.

## 검증

순수 평가와 저장 왕복, 실제 장비 파생, PvP 양쪽 공격자 시점, MP 소모 뒤 안정성, 정보 없는 상대의 폴백, 에디터와 템플릿 요약을 테스트한다. 기존 패턴 테스트와 타입 검사도 실행한다. 배포나 피드백 시스템 상태 변경은 하지 않는다.
