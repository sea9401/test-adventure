# PvP 치명타 저항·회복 밸런스 설계

## 목적

치명타 저항이 상대의 확률 치명타를 0%로 만들 수 있는 구조를 완화하고, PvP 회복과 보호막을 독립적으로 조정한다. PvE의 치명타와 회복은 유지한다.

## 동작

- PvP 평타와 직접 피해 스킬은 `min(저항 수치, 공격자 원본 치명타 확률 × 0.75)`만 치명타 확률에서 뺀다. 75% 원본 확률과 100%p 저항이면 18.75%가 남는다. 확정 치명타는 기존처럼 저항을 건너뛴다. 저항 후 75% 확률 상한과 초과 치명 피해 전환 순서는 유지한다.
- 투기장·친선 대련·챔피언십의 회복 배율과 보호막 생성 배율을 별도 입력으로 전달한다. 회복은 50%안을 검증하고, 보호막은 기존 65%를 유지한다. 별도 PvP 제한이 있는 무자원 1회 회복기는 추가 배율을 적용하지 않는다.
- 일반 PvP 호출은 입력을 생략하면 기존 100% 동작을 유지한다.
- 게임 내 공식 안내를 실제 계산 순서 및 최종 수치에 맞춘다.

## 검증

치명타의 저항 경계·초과 치명타·PvE 유지, 회복/보호막 분리, 세 PvP 호출부의 입력을 회귀 테스트로 확인한다. 대표 치명타·회복·회피 조합을 시뮬레이션해 완전 무력화와 과도한 회복이 개선되는지 확인한다. 실제 #721 경기 기록은 접근할 수 없으므로 특정 승패 재현으로 주장하지 않는다.
