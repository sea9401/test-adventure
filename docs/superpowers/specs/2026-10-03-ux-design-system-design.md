# 화면 구성(UX·UI) 개편

## 배경

2026-10-03 오너가 "원했던 건 색감이 아니라 UX·UI"라고 정정했다. 로컬 운영 빌드에 E2E 테스트
계정으로 로그인해 게임 화면 59개(휴대폰 390px, PC 1280px)를 점검했다. 점검 보고서:
https://claude.ai/artifact/WXR66p4njkQb1vV5BBa2DS

공통 문제 10가지:

1. 화면 첫머리에 설명문이 먼저 나온다(스킬 패턴, 협동 보스, 태초의 성소).
2. 탭이 2~3단으로 겹치고 모양이 다섯 가지다(생활 조합 작업장, 아레나, 낚시, 대련장, 모험의 서).
3. 주 행동 버튼 색이 화면마다 다르다(치료소 빨강, 아레나 주황, 은행 초록 등).
4. 같은 카드가 반복되어 화면이 길다(전투 프리셋, 모험가 협회, 트로피, 꾸미기).
5. 빈 화면이 다음 행동을 알려 주지 않는다.
6. 잠긴 기능을 들어가 봐야 안다(개척 노드, 위험 해역).
7. 상단 바에 있는 스태미나가 전투 화면 안에 큰 카드로 한 번 더 나온다.
8. 떠 있는 채팅 버튼이 스크롤 중 내용을 가린다.
9. PC에서 가운데 좁은 기둥만 쓴다.
10. 10~11px 글씨가 본문처럼 쓰인다(1,271곳).

문장 화면은 먼저 개편했다(`feat/ux-emblem`의 첫 커밋).

## 진행 순서 (오너 승인: "순서대로")

1. **공통 틀**: 부품·규칙·자동 검사·전역 수정(이 문서의 1단계)
2. **자주 쓰는 화면**: 스킬 패턴, 인벤토리, 전투 프리셋, 협동 보스, 아레나, 모험가 협회, 생활 조합 작업장
3. **나머지 화면과 PC 2단**: 트로피, 꾸미기, 성장의 신전, 낚시 하위 화면 등, 1024px 이상 목록·상세 2단

2·3단계는 화면마다 1단계 부품으로 교체하며, 화면별 결정은 각 단계 시작 때 이 문서에 덧붙인다.

## 1단계: 공통 틀

### 1-1. 화면 첫머리와 도움말

- `SubViewHeader`에 `help?: ReactNode`를 더한다. 주면 제목 오른쪽에 "?" 버튼(`aria-label="도움말"`,
  `aria-expanded`)이 생기고, 누르면 머리 바로 아래에 도움말 패널(`SURFACE_INSET`, 14px)이 열린다.
- 규칙: 화면 첫머리는 "제목 → 지금 상태 한 줄 → 주 행동". 규칙·설명 문단은 `help`나 접기로 옮긴다.

### 1-2. 탭 두 종류

- 화면을 나누는 탭: 기존 `TabBar`(밑줄). 넘치면 `scrollable`.
- 화면 안 보기 전환: 새 `SegmentedControl`(회색 트랙 안에서 선택된 칸만 흰 바탕). `role="group"`,
  각 버튼 `aria-pressed`. 2~4개 선택지용.
- 규칙: 탭은 2단까지. 필터는 칩 한 줄이나 선택 상자 하나.

### 1-3. 버튼 위계

- 공용 `Button`의 변형을 주 행동(`primary`)·보조(`secondary`)·위험(`danger`)·약한 강조(`soft`)·
  글자(`ghost`)로 정리한다. `success`·`warning`·`info`는 API는 남기되 `primary`와 같은 모양으로
  그린다(화면마다 색이 달라지던 원인). 위험 행동(삭제·판매·초기화)만 `danger`.
- 손으로 색을 칠한 버튼(색 바탕 + 흰 글자, 현재 256곳)은 자동 검사로 늘지 않게 막고, 2·3단계에서
  화면을 고칠 때 `Button`으로 옮긴다.

### 1-4. 빈 상태와 잠금 상태

- `EmptyState`에 `action?: { label: string; href?: string; onClick?: () => void }`를 더해
  "채우는 방법 + 바로가기"를 넣을 수 있게 한다.
- `EntryRow`·`EntryCard`에 `locked?: string`(해금 조건 문구)을 더한다. 자물쇠 아이콘과 조건을
  설명 자리에 보여 주고, 제목은 흐린 글자색으로 한다(컨테이너 `opacity` 금지 규칙 유지).

### 1-5. 전역 수정

- **스태미나 중복**: 화면 안 큰 스태미나 카드는 계속 소모하는 사냥터(`/battle/dungeon`)에서만
  고정형으로 둔다. 아레나·협동 보스·숙련의 탑·폭풍 원정에서는 없앤다. 상단 바 스태미나를 누르면
  열리는 회복약 창에 회복 속도와 최대치까지 남은 시간을 보여 준다.
- **채팅 버튼**: 아래로 스크롤하는 동안 숨기고, 위로 스크롤하거나 멈추면 다시 보인다. 크기는
  56px → 48px. 모션 줄이기 설정에서는 이동 효과 없이 바로 숨김·표시한다. 채팅 창이 열려 있으면
  숨기지 않는다.

### 1-6. 자동 검사(늘지 않게 막기)

`src/components/ui/designSystemBudget.test.ts`가 `src`(테스트·`/dev` 제외) 전체를 세어 기준 이하인지
확인한다. 기준은 1단계 시작 시점 수치이며, 화면을 고쳐 줄면 기준도 함께 낮춘다.

- 손으로 칠한 색 바탕 + 흰 글자 버튼 문자열: 250 이하(`/dev` 제외 실측)
- 10px·11px 등 12px 미만 글씨 클래스: 1,265 이하(`/dev` 제외 실측)

### 1-7. 규칙 문서와 미리보기

- `.claude/skills/anti-slop-ui/SKILL.md`에 "화면 골격" 절(첫머리·탭·버튼·빈 상태·잠금)을 추가한다.
- `/dev/ui-system`에 도움말 머리, `SegmentedControl`, 빈 상태 바로가기, 잠긴 메뉴 행을 보여 준다.

## 2단계: 자주 쓰는 화면 (2026-10-03 결정)

공통: 규칙·설명 문단은 `SubViewHeader`의 `help`로, 손칠 버튼은 `Button`으로, 12px 미만 글씨는
`text-xs` 이상으로 옮긴다. 플레이어가 쓰던 기능(버튼·설정·정보)은 하나도 없애지 않고 위치만 옮긴다.

### 2-1. 전투 프리셋 (`/character/presets`)

- 첫머리 설명은 도움말로. 맨 위에 "현재 세팅 저장" 카드 하나(이름 입력 + 저장). 저장하면 첫 빈 칸에
  들어가고, 빈 칸이 없으면 버튼을 막고 "빈 칸이 없습니다. 아래 프리셋을 덮어쓰거나 삭제하세요."를 보인다.
- 저장된 프리셋은 카드 하나 안의 행 목록(이름, 적용 중, 스킬·패턴·장비 수, 저장 시각, 적용·덮어쓰기·삭제).
  빈 칸은 "빈 칸 N개" 한 줄로 접는다. 저장된 프리셋이 없으면 빈 상태 문구.

### 2-2. 스킬 패턴 (`/character/combat-pattern`, 스킬 화면의 "스킬 패턴" 탭)

- 규칙 문단은 단독 화면에서는 도움말, 스킬 화면 탭에서는 맨 위 접기("패턴이 작동하는 방식")로 옮긴다.
- 순서: 경고 → 블록 목록 → 블록 추가·저장 상태 → 패턴 프리셋(접기, "패턴 프리셋 n/8").
- 블록이 없으면 빈 상태("블록이 없으면 기본 공격만 사용합니다") + "블록 추가" 바로가기.
- 발동 가능한 장착 스킬이 없을 때의 경고는 `StatusBanner`와 "스킬 장착하러 가기" 링크로.

### 2-3. 인벤토리 (`/character/inventory`)

- 장비 목록 위 도구 줄은 [잠금만 보기] [정렬] [일괄 작업] 셋만 둔다. 도감 일괄 등록·품질 이하 판매·
  미장착 전부 판매·선택 판매와 검색 중 안내는 "일괄 작업"을 눌러 여는 패널 안으로 옮긴다.
- 판매(품질 이하·미장착 전부)는 `danger`, 선택 판매 시작과 도감 일괄 등록은 `secondary`.

### 2-4. 아레나 (`/battle/arena`)

- 탭 6개(두 줄 버튼 격자)를 밑줄 탭 5개로: 도전 · 순위 · 전투 세팅 · 기록 · 상점. 순위 탭 안에서
  `SegmentedControl`로 주간 순위 / 본선을 바꾼다.
- 도전 탭: 전적 카드 → 도전 버튼(`Button` 주 행동, 전체 폭) → 오늘 전적·비용 한 줄 → 최근 전투.
  규칙 표와 주간 보상은 도움말로.

### 2-5. 협동 보스 (`/battle/coop`)

- 첫머리 소개와 "새 보스는 먼저 나만 볼 수 있습니다" 안내는 도움말로.
- 순서: 알림 → 미수령 보상 → 진행 중 보스 → 새 보스 소환 → 토벌 설정(접기). 토벌 설정 안에는 기존
  자동 무료 지원과 내 보스 일괄 설정을 그대로 둔다.
- 소환·보상 받기 버튼은 `Button`, NORMAL/HARD 선택은 `SegmentedControl`.

### 2-6. 모험가 협회 (`/town/association`)

- 목록: 소개 문단은 도움말로, 시설 6개는 `EntryList` 행(아이콘, 이름, "Lv.N · 현재 효과").
- 시설을 누르면 상세: `SegmentedControl`로 이용 / 공동 기부(Lv.N+1)를 바꾼다. 기부 양식은 기부 탭에서만.

### 2-7. 생활 조합 작업장 (`/town/life-workshop`)

- 분류 7개 버튼 격자 → 밑줄 탭(가로 스크롤). 의뢰 게시판의 오늘·주간·의뢰인·기록 → `SegmentedControl`.
  탭은 이 2단까지.
- 등급 필터 버튼 4개 + 납품 가능만 보기 → 등급 선택 상자 하나 + "납품 가능만" 체크 상자.
- 오늘의 의뢰는 납품할 수 있는 것을 먼저, 완료한 것을 마지막에 둔다. 의뢰 카드는 설명을 한 줄로 줄이고
  카드 하나 안의 행으로 나눈다.
- 가공·제작 탭의 소개 카드는 도움말로.

### 2-8. 마무리

- 예산 검사 기준을 2단계 후 실측치로 낮춘다.
- 로컬 로그인 환경에서 일곱 화면을 다시 캡처해 확인한다.

## 3단계: 나머지 화면과 PC 2단 (2026-10-03 결정)

### 3-1. 트로피 전시대 (`/character/trophies`)

- 수집 목록은 획득한 트로피를 지금처럼 큰 칸으로, 미획득은 종류(업적·도감 숙련·월간 연구)별 접기
  ("미획득 업적 40개")로 묶고 펼치면 작은 행(메달·이름·조건)으로 보여 준다. "미획득" 보기에서는 접기를 편다.
- 전체·획득·미획득은 `SegmentedControl`. 검색은 그대로 두고 종류·분야·등급·연도 필터는 "필터" 접기로.

### 3-2. 꾸미기 (`/settings/cosmetics`)

- 보관함 소개 문단은 도움말로, 연장권 개수는 머리 오른쪽에.
- 도감마다 보유한 꾸미기를 먼저 카드로, 미획득은 "미획득 N종" 접기 안의 작은 칸(이름·희귀도)으로.
  미획득 칸에는 버튼을 두지 않는다. 연장 버튼은 보조(`secondary`).

### 3-3. 성장의 신전 (`/character/shrine`)

- 직업 행은 이름·상태 배지 + "숙련도 N · 해금 조건" 한 줄과 목표·전직 버튼만 기본으로 보이고,
  태그·직업 보너스·수행 스탯은 행을 눌러 펼친다. 10~11px 글씨는 12px로.

### 3-4. 낚시 하위 화면

- 낚시 상점의 일반 낚시/위험 해역, 위험 해역의 출항/거대어는 화면 안 보기 전환이므로 `SegmentedControl`
  (알림 점은 라벨 안에). 상점의 "크기 효과 적용 범위"와 위험 해역 소개 문장은 접기로.

### 3-5. 치료소·은행

- 치료소 "전부 회복(무료)"은 주 행동(`primary`), 충전·가득은 `Button`. 은행 "전액 입금"은 주 행동,
  입금·출금 버튼은 `Button`. 은행 화면 아래 중복 안내문은 지운다(카드 안 문장과 같음).

### 3-6. 잠금 표시

- 캐릭터 메뉴의 개척 노드는 100레벨 전이면 `EntryRow locked="Lv 100에 열립니다"`.
- 던전 선택은 잠긴 던전에 입장 버튼 대신 자물쇠와 해금 조건을 보여 준다.

### 3-7. 홈

- 공지사항·최근 게시글 위젯은 글이 없으면 숨긴다.
- 오늘의 모험 체크는 묶음마다 앞의 3개(지금 할 수 있는 것 먼저)만 보이고 나머지는 "나머지 N개 보기"로 접는다.

### 3-8. PC 2단 (1024px 이상)

- 공용 `TwoPane`(왼쪽 고정 폭 20rem·sticky, 오른쪽 나머지)을 만든다. 1024px 미만에서는 위아래로 쌓인다.
- 인벤토리: 왼쪽 장착 요약, 오른쪽 분류·목록.
- 모험가 협회: 왼쪽 시설 목록, 오른쪽 고른 시설(이용·공동 기부). PC에서는 처음에 첫 시설을 고른 상태로 연다.
- 퀘스트·거래소·사냥터는 3-10에서 이어서 한다.

### 3-9. 마무리

- 예산 검사 기준을 실측치로 낮추고, 로컬 로그인 환경에서 바뀐 화면을 390px·1280px로 캡처해 확인한다.

### 3-10. PC 2단 확장: 사냥터·퀘스트·거래소 (오너 요청 "진행해주세요")

- `TwoPane`에 `sticky?: boolean`(기본 true)을 더한다. 왼쪽 칸이 화면보다 길어질 수 있는 화면은 false로 둬서
  아래쪽이 가려지지 않게 한다.
- 사냥터(`/battle/dungeon`): PC에서는 왼쪽에 현재 성장·미개척지·열린 레어맵·사냥터 목록(표시 설정 포함),
  오른쪽에 고른 사냥터의 지역 그림과 입구·심부·최심부 카드. 처음에는 도전 구역이 있는 사냥터, 없으면 첫
  사냥터를 고른 상태로 연다. 고른 사냥터 카드는 `aria-current`로 표시한다. 휴대폰은 지금처럼 목록 → 사냥터.
- 퀘스트(`/quests`): 일일·주간은 왼쪽 보상 묶음 카드, 오른쪽 퀘스트 목록. 튜토리얼·업적은 왼쪽에 성장 미션 또는
  업적 점수·진행 중/완료 탭·모두 받기, 오른쪽에 계열별 퀘스트 카드.
- 거래소(`/plaza/market`) 둘러보기: 왼쪽 분류·검색·필터·정렬 카드, 오른쪽 매물 목록과 페이지 넘김. PC에서
  화면 폭을 다른 2단 화면과 같은 60rem으로 넓힌다. 최근 거래·내 거래·판매 탭은 한 줄 그대로.
