# 골렘 2~6차 단일 계보 설계

## 상태

대화 설계 승인(2026-10-10). 구현 계획 작성 전 문서 검토 단계.

## 결정

골렘은 변이자 1차 직업으로 추가된 뒤 상위 직업 없이 남아 있었다. 수인 2~6차 계보와 짝을 이루도록
골렘 아래에 단일 갈래 다섯 직업을 추가한다. 계보의 정체성은 **중량 축적과 해방의 순환**이다.
중량을 쌓는 축적기와 중량을 모두 푸는 해방기를 차수마다 번갈아 강화하고, 해방할 때 가속·보호막·
회복 같은 보상을 얻는다.

```text
변이자(0차)
└─ 골렘(1차)
   └─ 바위투사(2차)
      └─ 암석거인(3차)
         └─ 강철골렘(4차)
            └─ 산맥골렘(5차)
               └─ 태고골렘(6차)
```

| 차수 | 표시명 | 직업 ID |
|---:|---|---|
| 2 | 바위투사 | `rockbrawler` |
| 3 | 암석거인 | `rockgiant` |
| 4 | 강철골렘 | `irongolem` |
| 5 | 산맥골렘 | `mountaingolem` |
| 6 | 태고골렘 | `primevalgolem` |

이름은 재질이 커지는 순서(돌 → 바위 → 강철 → 산 → 태고)로 짓는다. 2·3차는 평범하게, 5·6차에서
거대함을 드러낸다.

## 목표와 제외 방향

### 목표

- 골렘을 고른 플레이어가 6차까지 성장할 경로를 만든다.
- 기존 골렘 세 스킬(암석 강타·지각 붕괴·돌가죽)과 중량 규칙을 그대로 이어받는다.
- 축적기와 해방기를 번갈아 추가해 하위 스킬을 계속 장착할 이유를 남긴다.
- 수인(대상 출혈 유지)과 방패 계열(피격으로 충격 충전 후 소모)과 구조가 겹치지 않게 한다.
- 다른 직업과 비교 가능한 성능 점수와 SP 비용으로 가격을 정한다.
- PvE와 PvP가 같은 중량·해방 판정과 시전 전 스냅숏을 사용한다.

### 제외 방향

- 중량 상한(3), 중량 1당 직접 물리 스킬 피해 +5%·SPD −5% 공용 규칙 변경
- 중량을 최대로 유지하는 것만으로 받는 큰 방어 보상(부동 요새형)
- 시간제 변신, 저체력 광폭화, 별도 저장형 전투 자원
- 평타·마법·지속 피해·반사·반격·장비 추가타까지 넓어지는 범용 보너스
- DB 마이그레이션과 세이브 형식 변경

## 직업 성장

| 차수 | 직업 | 수행 성향 | 전직 중 보너스 | 해금 조건 |
|---:|---|---|---|---|
| 2 | 바위투사 | VIT 2 / STR 2 | VIT +12 / STR +6 | 골렘 숙련도 1,000 |
| 3 | 암석거인 | VIT 2 / STR 2 | VIT +13 / STR +7 | 바위투사 숙련도 2,500 |
| 4 | 강철골렘 | VIT 2 / STR 2 | VIT +14 / STR +8 | 암석거인 숙련도 4,500 |
| 5 | 산맥골렘 | VIT 3 / STR 2 | VIT +17 / STR +9 | 강철골렘 숙련도 18,000 |
| 6 | 태고골렘 | VIT 3 / STR 2 / SPI 1 | VIT +26 / STR +10 / SPI +4 | 산맥골렘 숙련도 35,000 |

보너스 총합 `18 → 20 → 22 → 26 → 40`과 수행 총합 `4 → 4 → 4 → 5 → 6`은 수인 계보와 같다. 해금
임계는 `TIER2_UNLOCK_CUMLEVEL`·`TIER3_UNLOCK_CUMLEVEL`·`TIER4_UNLOCK_CUMLEVEL`·
`TIER5_UNLOCK_CUMLEVEL`·`TIER6_UNLOCK_CUMLEVEL` 상수를 그대로 쓴다. 모든 해금은 바로 아래 직업의
`jobCumLevel`을 `cumLevelForJob`으로 읽는다. 골렘은 mutant 직군의 Tier 1 전문 직업이므로 바위투사
해금도 `groups.mutant`가 아니라 `jobCumLevel.golem`을 본다. 변이자나 수인 숙련도로는 열 수 없다.

## 공통 전투 규칙

### 중량

- 중량 범위 0~3, 전투 시작 시 0, 전투 종료 시 소멸하는 기존 규칙을 유지한다.
- 중량 1당 직접 물리 스킬 피해 +5%, 유효 SPD −5% 공용 규칙을 바꾸지 않는다.
- 중량을 얻는 스킬은 이번 피해를 계산한 뒤 중량을 올린다(기존 규칙).

### 해방

- **해방**은 중량을 모두 소모하는 스킬의 정상 시전을 뜻한다. 기존 `지각 붕괴`도 해방에 포함된다.
- 소모량은 행동 시작 후 스킬 효과를 적용하기 전에 한 번 읽은 시전 전 중량이다.
- 시전이 성립하면 회피·피해 무효와 관계없이 중량을 소모한다(기존 규칙).
- 소모량이 0이면 해방 보상은 발생하지 않는다. 해방기의 기본 피해는 소모량 0에서도 발생한다.
- 해방 보상은 소모량에 비례하고, 한 시전에 한 번만 적용한다.
- 해방 보상을 주는 패시브는 어느 해방기(지각 붕괴 포함)로도 발동한다.

### 판정 순서

1. 시전 전 중량을 스냅숏한다.
2. 스냅숏으로 이번 시전의 소모 보너스·과적 조건·중량 3 조건을 만든다.
3. 명중, 직접 피해, 관통, 조건부 지연을 계산한다.
4. 해방기라면 중량을 소모하고, 해방 보상(보호막·재부착 중량)을 처리한다.
5. 축적기라면 중량을 얻는다.
6. 정상 시전 조건의 행동 가속을 다음 행동 간격에 적용한다.

행동 가속과 보호막·재부착 중량은 정상 시전이면 빗나가도 적용한다. 적 지연과 피해 기반 회복은
명중하거나 실제 피해를 준 경우에만 적용한다. 회복 기준 피해는 보호막과 HP에 실제로 적용된 피해만
포함한다.

### 적용 공격

조건부 피해·관통 보너스는 순수 직접 물리 스킬에만 적용한다. 기본 공격, 마법, 회복·버프 스킬, 지속
피해, 반사, 반격, 고정 피해, 장비 추가타와 별도 온힛 피해는 제외한다.

### 수집형

현재 직업을 판정에 포함하지 않는다. 배운 골렘 계보 스킬은 어느 직업에서 장착해도 같은 중량을
생성·소모하고 같은 보상을 얻는다.

## 2차 — 바위투사

역할은 해방 직후 빠르게 다시 쌓는 순환의 시작이다.

### 액티브 `바위 굴리기`

- 스킬 ID: `v2c_rockbrawler_boulderroll`
- 단일 직접 물리 공격, DEF 계수, 주 능력치 VIT
- 피해 계산 뒤 중량 +1
- 시전 전 중량이 0이면 중량 +2
- 스마트 기본 조건: 중량 0일 때 우선

### 패시브 `짐 벗기`

## 겹침과 상한

- `짐 벗기`와 `태고의 붕괴`의 가속은 합산해 최대 30%가 되고, 기존 PvE·PvP 행동 간격 하한을 적용한다.
- 관통은 기존 관통과 합산한 뒤 현행 PvE·PvP 관통 상한을 적용한다.
- 보호막은 기존 보호막 중첩·상한 규칙을 따른다.
- `강철 골격`의 SPD 완화와 `대지의 정점`의 피해 감소는 기존 속도·피해 감소 상한을 우회하지 않는다.
- 기존 `돌가죽`(중량 1당 DEF +6%)과 모든 새 효과는 독립적으로 함께 적용된다.

## 액티브 공통 가격 기준

- 모든 액티브는 단일 직접 물리 스킬이며 일반 비캐스터 차수별 MP 산식을 사용한다.
- `fixedMpCost` 예외와 별도 재사용 대기시간을 두지 않는다.
- 계보의 직업 템포는 지속전형 `steady`로 등록한다.
- 축적기(`바위 굴리기`, `강철 망치`)는 `control`, 해방기(`암반 내려찍기`, `산사태`, `태고의 붕괴`)는
  `payoff` 스킬 템포를 사용한다.
- 직접 피해는 현행 차수별 DEF 계수 직접 물리 단일기 공식을 따른다.

옮긴다.

### 점수화 가정

- 해방 1회 평균 소모량: 3.0 (구현 sim 실측으로 2.4에서 수정)
- 중량 3 가동률: 35%
- 과적 타격(`강철 망치` 시전 전 중량 3) 비율: 35%
- 직접 물리 스킬 시전 중 해방 비율: 40% (해방 패시브 점수에 적용)

가속, 지연, 관통, 피해 증가, 보호막, 재부착 중량, 회복과 SPD 완화는 위 가정과 적용 범위를 반영해
점수화한다. 구현 후 실제 점수가 목표에서 ±0.10을 벗어나면 효과 수치를 조정한다. 효과를 유지한 채
임의 SP 할인으로 맞추지 않는다. 장기전 시뮬레이션에서 실제 가동률·평균 소모량이 가정과 10%p
(소모량은 0.3) 이상 다르면 다시 계산한다.

## 데이터와 구현 경계

- 직업 카탈로그, 구형 class/spec 호환(`class: "mutant"`), 직업별 스킬 매핑, 로드맵과 직업 탐색기에
  다섯 직업과 단일 연결선을 추가한다.
- 각 직업에 액티브 하나와 패시브 하나, 총 10개 스킬을 등록한다.
- 조건을 스킬 ID별 분기문으로 만들지 않고 선언형 `weightCycle` 메타데이터로 둔다. 같은 선언을
  PvE·PvP 전투, 스킬 상세 칩과 `skillPowerScore`가 함께 읽는다.
- 해방 판정, 시전 전 스냅숏, 소모 보너스, 과적 조건과 해방 보상 계산은 `mutationCombat.ts`의 순수
  함수로 두고 PvE·PvP 어댑터가 같은 함수를 사용한다.
- 기존 `mutationWeightGain`·`mutationWeightConsumePctPerStack` 필드와 지각 붕괴·암석 강타·돌가죽
  동작은 유지한다.
- 신규 전투 자원을 저장하지 않으므로 세이브와 DB 스키마를 변경하지 않는다.
- 플레이어 매뉴얼의 직업 섹션을 함께 갱신한다. 매뉴얼에 "v2" 표기를 노출하지 않는다.
- 직업 이미지는 기존 직업 이미지 규칙을 확인해 필요한 경우 사양만 안내한다.

## UI와 로그

- 직업 탐색기와 로드맵에 `골렘 → 바위투사 → 암석거인 → 강철골렘 → 산맥골렘 → 태고골렘`을 표시한다.
- 잠긴 카드는 바로 아래 직업명과 요구 숙련도를 표시한다.
- 스킬 상세에는 축적량, 과적 조건, 소모 1당 효과, 상한, SP를 수치 칩으로 표시한다.
- 로그 형식
  - `[짐 벗기] 다음 행동 15% 가속`
  - `[암벽 갑주] 보호막 +9%`
  - `[산맥의 몸] 중량 +1 (1/3)`
  - `[강철 망치] 과적 타격`
- 새 UI 패널이 필요하면 기존 불투명 표면 상수를 재사용한다.

## 검증

### 카탈로그와 해금

- 각 직업 ID, 이름, 차수, 수행 성향, 전직 보너스와 단일 선행 관계
- 999/1,000, 2,499/2,500, 4,499/4,500, 17,999/18,000, 34,999/35,000 해금 경계
- 변이자·수인 계보 숙련도만으로 바위투사가 열리지 않음
- 레거시 매핑, 직업 탐색기와 로드맵의 단일 계보

### 전투

- 시전 전 중량 0·1·2·3의 축적기·해방기 모든 분기
- `바위 굴리기` 중량 0에서 +2, 그 외 +1, 상한 3
- `강철 망치` 중량 3에서 중량 불변·관통 적용, 0~2에서 관통 없음
- 소모량 0 해방에서 해방 보상 없음
- 지각 붕괴로 해방해도 `짐 벗기`·`암벽 갑주`·`산맥의 몸`이 발동
- 빗나가면 지연·회복이 없고, 가속·보호막·재부착은 정상 시전이면 적용
- `산맥의 몸` 재부착 중량이 이번 시전 피해에 반영되지 않음
- `강철 골격` SPD 완화가 장착 시에만 적용되고 미장착 공용 규칙은 불변
- 가속·관통·보호막·피해 감소 합산이 기존 상한·하한을 우회하지 않음
- 평타, 마법, 지속 피해, 반사, 반격, 장비 추가타 제외
- 같은 판정이 PvE와 PvP에서 성립
- 다른 직업이 골렘 계보 스킬만 장착해도 같은 동작
- 기존 골렘 세 스킬과 수인 계보 회귀 없음

### 성능 점수와 SP

- 10개 스킬의 실제 정규화 후 성능 점수, SP와 성능/SP
- 직업별 합계가 목표 범위에 포함
- 조건부 효과 제거·상향 시 점수와 SP가 같은 방향으로 변함
- 명시 할인 없이 현행 루브릭 바닥 이상으로 가격 책정

### 시뮬레이션

- 짧은 일반 전투와 장기 보스전에서 해방 평균 소모량과 중량 3 가동률
- 전체 계보 장착과 일부 스킬 수집 장착의 SP 대비 피해·생존·행동 수
- 동차 중앙 물리 직업, 수인 계보와의 PvE·PvP 장기전 비교
