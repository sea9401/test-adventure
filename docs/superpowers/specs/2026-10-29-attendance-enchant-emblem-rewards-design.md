# 2026년 11월 출석판: 마법부여서·문장 상자

## 결정 (오너, 2026-10-29)

- 2026년 11월 출석판부터 월간 모험 지원권과 꾸미기 상자 3종(닉네임·채팅 배지·프로필)을 뺀다.
- 특수 보상으로 마법부여서와 문장 상자를 새로 만든다.
- 진행 중인 10월 출석판은 바꾸지 않는다. `monthKey < "2026-11"`이면 기존 출석판을 쓴다.

| 일차 | 10월까지 | 11월부터 |
|---|---|---|
| 1 | 지원권 15일 | 마법부여서 1장 |
| 7 | 스태미나 2개 + 닉네임 꾸미기 상자 | 스태미나 2개 + 문장 상자 1개 |
| 14 | 지원권 7일 + 채팅 배지 상자 | 마법부여서 1장 |
| 21 | 증표 300개 + 지원권 7일 | 증표 300개 |
| 28 | 증표 500개 + 프로필 꾸미기 상자 | 증표 500개 + 마법부여서 1장 + 문장 상자 1개 |

나머지 칸은 같다. 한 달 합계는 마법부여서 3장(골드 4,500만 상당)과 문장 상자 2개다.

## 아이템

두 아이템 모두 `수행 초기화 물약`과 같은 방식이다. `museunCashItems`의 `delivery: "inventory"`,
`coinPrice: 0`, `tradeable: false`이고, 상점에서 팔지 않으며 관리자 우편으로는 보낼 수 있다.

- `enchant_scroll` 마법부여서: `/api/v2/me/equipment/liberate`에 `payment: "enchant_scroll"`을
  보내면 골드 대신 1장을 쓴다. 마법부여와 재마법부여에 쓸 수 있고 전체 이전에는 쓸 수 없다.
  영수증의 `spentGold`는 0이라 "마법부여에 쓴 골드" 업적·랭킹에 더해지지 않는다.
  가방에서 `사용`을 누르면 대장간 마법부여 탭으로 이동한다. 사용 API에 직접 보내면
  `use_at_enchant_workbench`로 거절한다.
- `emblem_box` 문장 상자: 가방에서 열면 `rollEmblemBox`로 문장 1개를 `character.v2.emblems`에
  추가한다. 성소 노말 최종 보스와 같은 표를 쓴다(종류 8종 균등, 등급 89/10/1%).

## 화면

- 마법부여 작업대: 마법부여서가 있으면 주 버튼은 "마법부여서로 마법부여", 골드 버튼은 보조
  버튼으로 바뀐다. 없으면 기존 화면과 같다. 최초 마법부여 확인 창의 버튼 문구도 결제 수단을 따른다.
- 출석판: 새 아이콘 `enchant_scroll`·`emblem_box`를 추가하고, 특수 보상 칸을 강조 표면으로
  표시한다. 지원권 안내 문구는 그달 출석판에 지원권이 있을 때만 보인다.
- 매뉴얼: 출석 체크와 마법부여 섹션에 두 아이템의 사용처를 적고, 지원권 설명은 별도 소제목으로 옮겼다.
