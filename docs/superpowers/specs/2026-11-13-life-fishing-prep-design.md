# 전투 준비물 3번째 칸: 기력 보충 (어유)

## 배경

2026-11-13 오너가 생활 확장 후보 중 낚시를 골랐다. 운영 수치를 다시 뽑아 보니 낚시 참여는 줄지 않았고, 낚시 산물이 낚시 밖에서 쓰이지 않는 것이 실제 문제였다.

- 주간 낚시 인원은 117~144명으로 석 달째 비슷하다(주간 활동 인원의 약 60%). 248명이던 주는 가입이 몰린 9월 21일 주 한 번이다.
- 낚시 코인의 실질 용도는 스태미나 회복약 하나다. 이번 주 구매자 60명 중 47명이 주간 한도 30개를 채웠다.
- 위험 해역은 열어 본 152명 중 최근 7일 이용자가 23명이다. 최근 7일 낚시한 119명 중 해금 레벨(Lv.15)을 넘긴 사람은 72명이다. 보상이 미끼, 전용 장비 강화, 칭호로 그 안에서만 돈다.
- 낚시 주전공은 0명, 부전공은 4명이다(전공 지정 32명). 명장 어획의 쓰임은 명장 요리 하나이고 요리 주전공은 7명이다.
- 일반 어획물 5종은 요리 재료로만 쓰인다. 음식 효과를 켠 사람은 277명 중 19명이다.

오너 결정(2026-11-13): 낚시 산물에 낚시 밖 쓸모를 준다. 형태는 숫돌·보강재 옆의 세 번째 준비 칸이고, 효과는 최대 MP다. 명장 등급은 숫돌·보강재와 같이 주전공 전용으로 둔다.

## 목표

- 일반 어획물, 위험 해역 어획물, 명장 어획에 각각 이어지는 소비처를 만든다.
- 위험 해역에 갈 이유와 낚시를 전공할 이유를 만든다.
- 숫돌·보강재와 같은 사용법이라 플레이어가 새로 배울 것이 없게 한다.

낚시 참여 인원을 늘리는 것과 낚시 코인 소비처는 목표가 아니다.

## 1. 칸과 품목

전투 준비 칸이 넷이 된다. 서로 중복 적용되고, 같은 칸끼리는 새로 쓴 것으로 교체된다(시간 누적 없음).

| 칸 | 재료 출처 | 효과 |
|---|---|---|
| 음식 (기존) | 농사·목장·낚시 → 요리 | 기존 그대로 |
| 무기 손질 (기존) | 채광 가공재 | 공격력, 마법공격력 |
| 방어구 손질 (기존) | 벌목 가공재 | 방어력, 마법방어력, 최대 HP |
| 기력 보충 (신규) | 낚시 어획물 | 최대 MP |

품목은 4등급 4종이다. 품질 판정은 없다.

| id | 이름 | 효과 | 지속 |
|---|---|---|---|
| `v2_prep_fishoil_1` | 초급 어유 | 최대 MP +250 | 12시간 |
| `v2_prep_fishoil_2` | 중급 어유 | 최대 MP +500 | 12시간 |
| `v2_prep_fishoil_3` | 상급 어유 | 최대 MP +800 | 12시간 |
| `v2_prep_fishoil_master` | 명장의 어유 | 최대 MP +1,100 | 24시간 |

적용 범위는 숫돌·보강재와 같다. 사냥, 숙련의 탑, 토벌전, 협동 보스, 폭풍 원정, 미개척지에 적용되고 아레나·챔피언십·거점전·훈련 대련·스탯 합계 랭킹에서는 빠진다.

전투는 현재 MP를 최대치로 채워 시작하는 경로와 저장된 현재 MP를 이어 쓰는 경로가 있다. 어유는 최대 MP만 올리고 현재 MP를 즉시 채우지 않는다. 음식의 최대 MP 효과와 같은 처리다.

## 2. 제작

생활 공방 제작 탭의 전투 준비물 묶음에서 만든다. 한 번에 1~20개.

| 품목 | 재료 (1개) | 조건 |
|---|---|---|
| 초급 어유 | 일반 어획물 3, 신선한 어획물 1 | 낚시 Lv.1 |
| 중급 어유 | 신선한 어획물 3, 고급 어획물 3 | 낚시 Lv.15 |
| 상급 어유 | 고급 어획물 4, 특급 어획물 1, 위험 해역 희귀 이상 어획물 2 | 낚시 Lv.25 |
| 명장의 어유 | 특급 어획물 2, 전설의 어획물 1, 위험 해역 영웅 이상 어획물 2, 명장 어획 1 | 낚시 주전공 명장 3단계 이상 |

- 제작 레벨이 숫돌(1/20/35)보다 낮은 이유: 낚시는 수동이라 레벨이 낮다. 최근 7일 낚시한 119명 중 Lv.15 이상 72명, Lv.25 이상 47명, Lv.35 이상 32명, Lv.100은 7명이다. 중급은 위험 해역 해금 레벨, 상급은 폭풍 해구 해금 레벨에 맞췄다.
- 명장 등급 판정은 `lifeMajorCanCraft(state, "fishing")`을 쓴다(부전공 불가).
- 골드 비용은 없다.

### 위험 해역 어획물 묶음 재료

"위험 해역 희귀 이상 어획물 2"는 특정 어종이 아니라 등급 조건이다. 위험 해역 18종 중 희귀·영웅·전설 등급 어획물을 합쳐 2개를 낸다.

- 자동 선택 순서: 낮은 등급부터 쓴다. 같은 등급 안에서는 기존 `selectCatchMaterials` 규칙(보유량 많은 어종 먼저, 같으면 화물 가치 낮은 어종 먼저)을 그대로 쓴다.
- 플레이어가 어종을 직접 고르는 화면은 두지 않는다. 제작 행에는 조건을 채우는 어획물의 보유 합계만 보여 준다.
- "영웅 이상"은 영웅·전설 등급이다.

### 재료 보관 위치

재료가 두 세이브에 나뉘어 있다.

| 재료 | 세이브 |
|---|---|
| 일반·신선한·고급·특급·전설의 어획물 | `fishing-stock.v1`의 `items` |
| 위험 해역 어획물, 명장 어획, 완성된 어유 | `character.v2`의 `materials` |

어유 제작은 한 트랜잭션에서 `fishing-stock.v1`을 먼저 잠그고 `character.v2`를 잠근다. 낚시 챔질 라우트(`fishing/reel`)와 같은 순서다. 길드 교역 납품은 반대 순서지만, 낚시하면서 어유를 만드는 경우가 훨씬 흔하므로 챔질 쪽에 맞춘다. 숫돌·보강재 제작은 `fishing-stock.v1`을 잠그지 않는다. `fishing-stock.v1`의 `daily`(하루 획득량 기록)는 건드리지 않고 `items`만 줄인다.

## 3. 저장

- 어유 4종을 재료 카탈로그(`V2_MATERIALS`)에 등록하고 `character.v2`의 `materials`에 보관한다. 인벤토리 표시와 거래소 재료 거래가 기존 경로로 동작한다.
- NPC 판매 대상에는 넣지 않는다(숫돌·보강재와 같은 처리).
- 켜 둔 효과는 기존 `character.v2.activeBattlePreps`에 칸 하나를 더한다.

```ts
type ActiveBattlePreps = {
  weapon?: { itemId: string; expiresAt: number };
  armor?: { itemId: string; expiresAt: number };
  vigor?: { itemId: string; expiresAt: number };
};
```

- 마이그레이션은 없다. 필드가 없으면 빈 칸으로 본다.

`derivePlayerCombatV2Pure.ts`는 모듈 예산이 꽉 차 있어 건드리지 않는다.

### 재료 정의 형태

기존 `costs: Record<string, number>`는 `character.v2` 재료만 표현한다. 이 필드는 그대로 두고 품목 정의에 선택 필드 두 개를 더한다.

```ts
type BattlePrepItem = {
  // 기존 필드
  costs: Record<string, number>;                               // character.v2 재료
  catchCosts?: Partial<Record<FishingCatchItemId, number>>;    // fishing-stock.v1
  dangerCatchCost?: { minRarity: "rare" | "epic"; amount: number };
};
```

숫돌·보강재 8종의 정의는 바뀌지 않는다. 제작 함수는 두 재고(재료, 어획물)를 받아 두 재고의 다음 값을 돌려준다.

## 5. API

### GET·POST `/api/v2/life-workshop/battle-prep`

요청과 응답 모양은 그대로다. 달라지는 점:

- 행이 8개에서 12개가 된다.
- 재료 항목에 종류가 붙는다. 묶음 재료는 조건 이름("위험 해역 희귀 이상 어획물")과 보유 합계를 준다.
- 제작 시 어획물 재고를 쓰는 품목이면 `fishing-stock.v1`도 잠그고 저장한다.
- 오류 코드는 기존 다섯 개를 그대로 쓴다.

### POST `/api/v2/me/use-battle-prep`

변경 없음. 어유를 쓰면 `vigor` 칸이 교체되고 다른 칸은 유지된다.

## 6. 화면

- **생활 공방 제작 탭**: 전투 준비물 묶음에 어유 4행을 추가한다. 순서는 숫돌, 보강재, 어유다. 행 모양은 기존과 같다. 묶음 재료는 한 줄로 "위험 해역 희귀 이상 어획물 2 (보유 14)"처럼 보여 준다.
- **인벤토리 소모품 탭**: 기존 준비물 구역에 어유가 함께 보인다.
- **캐릭터 간략 정보·캐릭터 카드**: 무기 손질·방어구 손질 배지 옆에 기력 보충 배지를 같은 모양으로 추가한다.
- 표면은 `surfaces.ts` 토큰을 쓰고 새 색·장식은 넣지 않는다.
- 아이콘 4종은 `public/images/items/battle-prep/<id>.webp`에 둔다. 숫돌·보강재 아이콘과 같은 화풍으로 만든다.

## 7. 안내서와 문구

- 전투 준비물 표는 카탈로그를 읽어 자동으로 4행이 늘어난다. 제작 조건 문구 함수가 낚시를 처리하게 하고, 묶음 재료 문구를 추가한다.
- 전투 준비물 설명 문장을 "벌목·채광 가공재로 숫돌과 보강재를, 낚시 어획물로 어유를 만든다"로 고친다. 칸 수 표현("하나씩")이 세 칸에 맞는지 확인한다.
- 생활 전공 항목의 명장 등급 문장에 명장의 어유(낚시 주전공)를 추가한다.
- 위험 해역 항목에 어획물이 상급·명장 어유의 재료라는 문장을 추가한다.
- 패치노트에는 수치 표를 그대로 싣는다.

- 상급 어유의 토벌 피해 효과는 상급 숫돌과 비슷하거나 작다. 음식 최대 MP 상한은 1,500이다.

### 재료 수급

- 일반 어획물 5종의 지난주 생산은 약 2.1만 개다(일반 8,701, 신선 6,005, 고급 4,386, 특급 1,796, 전설 478). 낚시하는 사람의 주간 중앙값은 62개다. 최근 7일 접속자의 보유 합계는 약 15.6만 개다.
- 하루 획득 한도는 일반 50, 신선 35, 고급 25, 특급 10, 전설 3이다. 한도까지 낚은 하루치로 한 등급만 만든다면 초급 16개, 중급 8개, 상급 6개, 명장 3개까지 나온다(등급끼리 재료를 나눠 쓰므로 동시에 다 만들 수는 없다).
- 50명이 상급을 하루 두 번 쓰면 주당 고급 2,800개, 특급 700개, 위험 해역 희귀 이상 어획물 1,400개가 든다. 지금 낚시량으로 감당되지만 넉넉하지 않다. 낚시를 조금 더 하게 만드는 수준으로 잡았다.
- 위험 해역 희귀 어획물은 파쇄 암초 중층(Lv.15)에서도 나온다.
- 명장 어획은 5명이 99개를 갖고 있다. 낚시 Lv.100이 8명이라 명장의 어유는 한동안 귀하다.

## 9. 테스트

테스트를 먼저 작성한다.

- 카탈로그: 12종의 `material` 재료 id가 모두 `V2_MATERIALS`에 있고 `catch` 재료 id가 모두 어획물 정의에 있다. 어유는 등급이 오를수록 최대 MP가 커지고 명장만 24시간이다. 숫돌·보강재 8종의 재료와 수치는 바뀌지 않는다.
- 묶음 재료 선택: 낮은 등급부터 쓴다. 희귀가 모자라면 영웅·전설로 채운다. "영웅 이상"은 희귀를 쓰지 않는다. 합계가 모자라면 실패한다.
- `activeBattlePreps` 파서: `vigor` 칸을 읽고, 칸과 품목이 어긋나면 버린다.
- 전투 반영: 어유는 최대 MP만 정확한 수치만큼 올린다. 음식 최대 MP와 함께 켜면 둘 다 더해진다. `includeCookingBuff: false`면 어유도 빠진다.
- 제작 API: 낚시 레벨 미달, 전공 미달(부전공 포함), 어획물 재고 부족, 위험 해역 어획물 부족, 정상 제작 후 두 세이브의 수량. 숫돌 제작이 `fishing-stock.v1`을 건드리지 않는다.
- 사용 API: 어유 사용 시 `vigor`만 바뀌고 `weapon`·`armor`는 유지된다.
- 화면: 제작 패널의 묶음 재료 표시와 조건 미달 사유, 캐릭터 요약의 세 번째 칸 표시.
- 안내서 렌더링 테스트와 기존 검사(`check-module-budgets`, `anti-slop-ui` 스캔, 디자인 시스템 예산 테스트, 종 수 고정 테스트)를 통과한다.
