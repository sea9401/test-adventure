# 전격 마법사·룬 기사 5·6차

2026-11-13 대화 설계 승인. 4차에서 전용 상위 직업이 없던 두 계보를 6차까지 잇는다.

- 전격 마법사는 원소군주(원소 4차 5종 필요)로만 갈 수 있었다. 화염·냉기·바람·대지는 각자 5·6차가 있다.
- 룬 기사는 초월자(성전사 + 룬 기사)로만 갈 수 있었다. 성전사는 성휘기사·여명성기사 계보가 따로 있다.

원소군주·초월자 해금 조건, 7차 연결, 세이브 형식, DB는 바꾸지 않는다.

## 전격 계보: 취약을 걸고 치명타로 터뜨린다

4차 천뢰격이 이미 취약 18%(3행동)와 치명타 패시브를 갖고 있다. 5·6차는 취약이 걸린 대상에게 치명타와 관통으로 보상한다. 별도 전투 자원은 없다. 중첩 자원(전하)은 바람의 기류와 구조가 같아져 제외했다.

**전격 주문**은 천뢰격·연쇄 뇌격·만뢰 강림 세 개(`lightningMageSpell`)다.

**취약 대상**은 이번 행동 시작 시점에 시전자가 건 취약이 대상에게 남아 있는 상태다. 같은 시전이 새로 거는 취약은 포함하지 않는다.

| 직업 | 스킬 | ID | 효과 |
| --- | --- | --- | --- |
| 뇌전술사 | 연쇄 뇌격 | `v2c_electromancer_chain` | 마법 2연타. 취약 대상에게 이 스킬 치명타 확률 +25%p |
| | 축전 | `v2c_electromancer_capacitor` | 스킬 치명타 피해 +20% |

| 뇌천제 | 만뢰 강림 | `v2c_thundersovereign_descent` | 큰 단일 마법 피해, 취약 18%(3행동), 취약 대상에게 관통 20% |
| | 뇌신의 심장 | `v2c_thundersovereign_heart` | 전격 주문이 치명타로 적중하면 다음 행동 20% 가속 |

대화 초안에 있던 지능 %와 마법 스킬 피해 %는 뺐다. 화염·바람 5·6차가 2026-09-09에 중복 능력치 패시브를 속성 전용 효과로 바꾼 결정을 따른다.

### 규칙

- 조건부 치명타 확률은 기존 `skillCritChancePct`와 같은 자리에서 합산하고 치명타 상한(75%)과 PvP 치명타 저항을 그대로 따른다.
- 조건부 관통은 기존 `pierceDamagePct` 경로(0방어 피해 기준 추가 피해)에 더한다.
- 취약 지속 연장은 새로 거는 취약에만 더한다. 천뢰격·룬 검격 등 시전자가 거는 모든 `enemyVuln`에 적용한다.
- MP 감소는 화염 계보(`fireSpellMpCostReductionPct`)와 같은 자리에서 계산한다.
- 치명타 가속은 기존 가속과 큰 값만 적용한다(바람·교차 가속과 같은 규칙). 빗나가면 발생하지 않는다.
- 패시브는 현재 직업과 무관하게 장착하면 적용한다. 판정은 장착한 스킬 정의를 직접 읽는다.

## 룬 기사 계보: 물리와 마법을 함께 때리고 양쪽 방어를 깎는다

4차 룬 검격의 물리 + 마법 이중 타격을 키운다. 신규 엔진 규칙은 없고 기존 효과만 쓴다.

| 직업 | 스킬 | ID | 효과 |
| --- | --- | --- | --- |
| 마검호 | 룬 연격 | `v2c_spellswordmaster_flurry` | 물리·마법·물리 3연타 |
| | 이중 각인 | `v2c_spellswordmaster_dualmark` | 힘·지능 +16%, 물리·마법 스킬 피해 +6% |
| | 균열 간파 | `v2c_spellswordmaster_fissure` | 적 물리 방어·마법 방어 −8% |
| 마검황 | 마검 해방 | `v2c_spellswordemperor_release` | 물리 + 마법 이중 일격, 각 타 관통 15%, 취약 14%(3행동) |
| | 만룬 합일 | `v2c_spellswordemperor_unity` | 힘·지능 +20%, 치명타 +6% |
| | 룬 균열 | `v2c_spellswordemperor_rift` | 적 물리 방어·마법 방어 −12% |

방어 감소는 갑주 간파·마력 해체와 함께 장착할 수 있다. 기존 공용 규칙(`combineDefReductionPcts`)대로 남은 방어력에 차례로 곱한다. 대화 초안의 "함께 장착 불가"는 기존 방어 감소 패시브가 모두 이 규칙으로 겹치고 있어 따로 막지 않기로 했다.

## 대전 취약 판정 수정

`engine.pvpSkillInput.ts`가 "대상이 취약 상태인가"를 상대 쪽 스택(`opp.stacks.enemyVulnTurns`)에서 읽고 있었다. 대전에서 취약은 시전자 쪽 스택에 저장되므로(`side.stacks.enemyVulnTurns`) 반대편을 보고 있던 것이다. 전투 패턴의 "적 취약" 조건과 순수 취약 스킬의 중복 시전 방지가 이 값을 쓴다. 전격 계보의 조건부 관통이 같은 값을 쓰므로 시전자 쪽을 읽도록 고친다. 대전은 행동 시작에 취약 지속을 1 줄이므로 `> 1`일 때 이번 행동에 유효하다.

## 밸런스 기준

7차 확장 5종과 같은 결정적 시뮬레이션을 쓴다(`scripts/sim-lightning-rune-advancement.ts`). 실제 서버 능력치 산출로 Lv100·장비 없음 캐릭터를 만들고, 각 계보의 4차부터 해당 차수까지 고유 스킬을 모두 장착한 계보 세트끼리 비교한다. 마법은 지능 60·정신 20·활력 20, 검·용은 힘 60·활력 30·정신 10, 마검은 힘 40·지능 40·활력 20 분배다.

- MP 제약 없는 80행동 사냥 피해와 PvP 피해가 같은 차수 기존 계보 중앙값의 0.95~1.3배 안에 든다.
- `lightningRuneBalanceSim.test.ts`가 시드 60개로 이 범위를 고정한다.

상한을 1.3으로 둔 이유는 전격 4차가 이미 기존 4차 중앙값의 1.15배이기 때문이다(천뢰격이 4차 원소 주문 중 계수가 가장 높고 취약을 건다). 5·6차의 성장 비율은 다른 원소와 같게 맞췄다.

## 최종 수치

SP·MP·발동률은 공통 산식 결과다. 발동률은 확률 패턴 경로 기준값이다.

계수는 차수별 공통 재조정 전 원시 값이다. 균열 간파와 룬 균열은 SP를 6·9로 고정했다. 공통 산식 값(5·7)으로 두면 물리 한쪽만 쓰는 빌드가 갑주 간파 II(11%·7 SP)·III(13%·9 SP)보다 싸게 방어 감소를 쌓을 수 있다. 고정한 값에서는 한쪽만 쓰면 손해이고 양쪽을 함께 쓰는 빌드에만 이득이다.

마검 해방은 초기 계수(2.0·1.6)에서 마검 6차 세트가 검성·용왕기사 세트보다 2~7% 낮아 2.4·1.9로 올렸다. 나머지는 초기 계수 그대로다.
