# 채집지 정비

## 배경

채광과 벌목은 생활 중 Lv.100 보유자가 가장 많지만, 다른 생활과 달리 상한 뒤에 반복해서 키울 것이 없다. 2026-11-14 운영 데이터(최근 7일 접속 198명) 기준이다.

- Lv.100 보유자는 채광 66명, 벌목 69명이다. 농사 30명, 요리 15명, 낚시 8명보다 많다.
- 도구는 3단계가 끝이고 공방 이용자 187명 중 95명이 이미 3단계다. 가공 전문은 랭크 3이 끝이다. 명장 10단계에 닿은 주전공도 3명 있다.
- 원목 6종 재고는 약 319만 개, 광석 6종은 약 347만 개, 부산물(단단한 돌·석탄·원석 보석)은 약 217만 개다. 1인당 하루 약 2,600개를 캐는데, 숫돌과 보강재를 매일 하나씩 써도 원자재 800개면 된다. 부산물은 도구 승급에 몇 개 쓰는 것 말고 쓸 곳이 없다.
- 명장 목재·합금은 보유자 22~24명의 중앙값이 약 200개다. 쓸 곳은 단련 촉매와 명장 등급 전투 준비물뿐이다.
- 자동 채집을 돌리는 사람은 재료 효율이 60%로 떨어지는데도 2시간짜리 "느긋한 작업"을 30분짜리보다 훨씬 많이 고른다(126건 대 27건). 더 많이 캐는 것보다 덜 자주 들어와도 되는 것을 원한다.
- 자동 벌목과 자동 채광은 동시에 돌릴 수 없다.

오너 결정(2026-11-14~15): 채광·벌목에 품종 개량 같은 장기 목표를 만든다. 보상은 생산량이나 전투 수치가 아니라 자동 채집 편의로 한다. 처음 제안한 4시간·8시간은 너무 길어 최대 3시간 30분으로 줄였고, 소모량은 처음 제안보다 약 40% 올렸다.

## 목표

- 쌓인 원목·광석·부산물에 계속 이어지는 소비처를 만든다.
- 상한에 닿은 채광·벌목 이용자에게 몇 달짜리 목표를 준다.
- 시간당 생산량과 전투 수치는 건드리지 않는다.

## 1. 규칙

- 채집지는 광맥 6곳(철·구리·은·금·미스릴·아다만타이트)과 숲 6곳(소나무·자작나무·버드나무·참나무·삼나무·편백나무)이다. 채집지마다 정비 단계를 둔다.
- 0에서 시작해 5까지 누구나 올릴 수 있다. 6단계(명장 정비)는 그 생활의 주전공 명장 3단계 이상만 올릴 수 있다. 광맥은 채광, 숲은 벌목 주전공을 본다.
- 한 번에 한 단계씩 올린다. 내려가지 않고, 전공을 바꿔도 유지된다.
- 생활 레벨 조건은 없다. 재료를 가지고 있으면 정비할 수 있다.
- 골드는 들지 않는다.

## 2. 보상

정비한 채집지에서 "느긋한 작업"의 작업 시간이 길어진다.

| 정비 단계 | 느긋한 작업 시간 |
|---|---|
| 0 | 2시간 |
| 1 | 2시간 12분 |
| 2 | 2시간 24분 |
| 3 | 2시간 36분 |
| 4 | 2시간 48분 |
| 5 | 3시간 |
| 6 (명장 정비) | 3시간 30분 |

- 재료 효율 60%, 성공률 보정 80%, 경험치 효율 70%는 그대로다. 작업 시간에 비례해 작업 횟수만 늘어난다.
- 30분짜리 "기본 작업"은 바뀌지 않는다.
- 작업 시간은 시작할 때 정해진다. 진행 중인 작업은 정비해도 길어지지 않는다.
- 중간에 멈추면 지금처럼 그때까지 마친 작업만큼 정산된다.

## 3. 비용

원자재 수량은 "느긋한 작업 몇 회분 × 그 채집지의 1회분"이다. 1회분은 Lv.100·도구 3단계·채집 전문 랭크 3 기준 2시간 느긋한 작업의 기대 수확량을 10 단위로 맞춘 고정값이다.

| 등급 | 채집지 | 1회분 |
|---|---|---|
| 1 | 철 광맥, 소나무 | 640 |
| 2 | 구리 광맥, 자작나무 | 550 |
| 3 | 은 광맥, 버드나무 | 430 |
| 4 | 금 광맥, 참나무 | 350 |
| 5 | 미스릴 광맥, 삼나무 | 270 |
| 6 | 아다만타이트 광맥, 편백나무 | 220 |

| 단계 | 원자재 | 부산물 | 명장 산물 |
|---|---|---|---|
| 1 | 3회분 | 단단한 돌 200 | |
| 2 | 8회분 | 단단한 돌 400 | |
| 3 | 15회분 | 석탄 250 | |
| 4 | 25회분 | 석탄 500 | |
| 5 | 40회분 | 원석 보석 400 | |
| 6 (명장 정비) | 60회분 | 원석 보석 600 | 20 |

- 원자재는 그 채집지에서 나는 원목 또는 광석이다.
- 부산물은 숲도 채광 부산물을 쓴다(도구 승급과 같다).
- 명장 산물은 광맥이면 명장 합금, 숲이면 명장 목재다.

12곳 전부 5단계까지는 원자재 447,720개, 단단한 돌 7,200개, 석탄 9,000개, 원석 보석 4,800개가 든다. 명장 정비까지 하면 원자재 295,200개, 원석 보석 7,200개, 명장 합금·목재 120개씩이 더 든다.

### 예상 소요

한 채집지를 5단계까지 올리는 데 느긋한 작업 91회분이 든다. 운영 평균은 1인당 하루 약 6.5회분이다.

| | 수확을 전부 정비에 넣을 때 |
|---|---|
| 한 곳 5단계 | 약 14일 |
| 12곳 5단계 | 약 24주 |
| 12곳 명장 정비까지 | 약 40주 |

실제로는 가공·납품과 나눠 쓰므로 1.5~2배로 본다. 재고 상위 10%는 철광석·소나무 원목 약 18,000개, 다른 원자재 7,000~10,000개씩을 가지고 있어 출시 당일 여러 곳을 2~3단계까지 올릴 수 있다.

## 4. 장기 목표

칭호 두 개를 준다. 정비에 성공한 요청에서 조건을 처음 채웠을 때 지급한다.

| 칭호 | 조건 |
|---|---|
| 개척자 | 정비 단계 합계 24 이상 |
| 산과 숲의 주인 | 채집지 12곳 모두 5단계 이상 |

## 5. 저장

`life-workshop.v1`의 `LifeWorkshopState`에 선택 필드를 추가한다.

```ts
// 채집지 id(광맥 id 또는 나무 id) → 정비 단계 1~6. 0단계는 저장하지 않는다.
siteUpkeep?: Partial<Record<GatheringSiteId, number>>;
```

- 마이그레이션은 없다. 필드가 없으면 전부 0단계다.
- 파서는 모르는 id와 범위를 벗어난 값을 버린다.
- 채집지 id는 자동 채집 세션의 `sourceId`와 같다(광맥 id와 나무 id는 서로 겹치지 않는다).

## 7. API

`GET /api/v2/life-workshop/upkeep`

```ts
{
  ok: true,
  stages: Partial<Record<GatheringSiteId, number>>,
  materials: Record<string, number>,          // 정비에 쓰는 재료의 보유량
  masterUnlocked: { mining: boolean, woodcutting: boolean },
}
```

`POST /api/v2/life-workshop/upkeep` `{ siteId }`

- 성공하면 위 현황에 `result: { siteId, stage, grantedTitleIds }`를 더해 돌려준다.
- 잠금 순서는 생활 공방 요청과 같다: `character.v2` → `life-workshop.v1`. 전공은 잠그지 않고 읽는다.
- 오류(409): `upkeep_max`, `upkeep_master_locked`, `not_enough_materials`, `not_enough_byproducts`, `not_enough_master_product`. 잘못된 `siteId`는 400 `bad_request`.
- 요청 제한은 생활 공방과 같은 틀을 쓴다.

## 8. 화면

- 생활 공방에 "채집지 정비" 탭을 둔다. 위쪽에 단계 합계와 두 칭호의 진행도를 보여 주고, 광맥 6곳과 숲 6곳을 한 카드 안의 행으로 나열한다.
- 행에는 채집지 이름, 단계, 지금의 느긋한 작업 시간, 다음 단계 비용(보유량/필요량, 모자라면 붉은색), "정비" 버튼을 둔다. 6단계가 잠겨 있으면 주전공 조건을 한 줄로 알린다.
- 채광·벌목 화면의 자동 채집 카드는 고른 채집지의 정비 단계에 맞는 느긋한 작업 시간을 보여 준다. 진행 중인 작업은 그 작업의 실제 시간을 보여 준다.

## 9. 생산량과 서버 영향

- 시간당 생산량은 같다. 접속 간격이 2시간보다 긴 사람은 한 번 접속으로 받는 양이 최대 1.75배가 되므로 서버 전체 생산량은 조금 늘 수 있다. 정비 비용이 이를 훨씬 넘게 태운다.
- 자동 채집 시작·정산 요청은 작업이 길어지는 만큼 줄어든다.

## 10. 검증

- 규칙 모듈: 비용 표, 작업 시간 표, 판정 순서, 정비 실행, 칭호 조건.
- 파서: 모르는 id·범위 밖 값 버리기, 필드 생략.
- 자동 채집: 느긋한 작업만 길어지고 기본 작업은 그대로인지, 작업 횟수가 시간에 비례하는지.
- API: 정비 성공 시 재료 차감과 단계 저장, 명장 정비 잠금, 재료 부족, 칭호 지급.
- 화면: 패널과 자동 채집 카드의 표시, 라이트·다크와 390·1280 폭 확인.
