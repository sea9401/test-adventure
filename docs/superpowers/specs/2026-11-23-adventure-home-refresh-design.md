# 모험 홈 정리 (전체 디자인 개편 첫 단계)

## 배경

2026-11-23 오너가 게임 전체 디자인을 개편하기로 했다. 목표는 새 유저와 스토어 스크린샷에서
매력적으로 보이는 것이다.

- 진단: 지역·캐릭터·보스 그림은 좋은데 모험 홈·메뉴·인벤토리가 흰 카드와 목록 위주라 관리용
  앱처럼 보인다.
- 모험 홈을 세 방향으로 그린 시안(https://claude.ai/artifact/SwEy83Uq7DqtcUuDvUxi1Y)에서 오너가
  **C · 단정한 정리**를 골랐다. 지금의 밝은 톤과 주 행동 색을 유지하고, 상자를 줄이고, 사냥터 그림
  띠를 넣는 방향이다.
- LUNES 디자인 시스템은 가져오지 않는다.

이 문서는 C를 실제 모험 홈에 적용한 첫 단계다. 다른 화면은 오너가 이 결과를 본 뒤 이어서 정한다.

## 바꾼 것

### 1. 사냥터 카드 (새 홈 위젯 `hunt_entry`)

`src/adventure/v2/HuntEntryCard.tsx`

- 위에 사냥터 지역 그림 띠(휴대폰 112px, PC 144px), 아래에 제목 "사냥터", 지금 스태미너,
  주 버튼 "사냥하러 가기"(`/battle/dungeon`).
- 스태미나 막대 위젯은 기본 배치에서 숨겨져 있어, 이 카드가 홈에서 스태미너를 보여 주는 자리를
  겸한다.
- 그림은 `huntingGroundImageForDepth(1)`(들판)이다. 홈 상태에는 플레이어가 마지막으로 간
  사냥터가 없어 고정 그림을 쓴다.
- 그림 띠에는 `ui-scene-strip`과 `ui-hunting-ground-image`를 단다. 은신·터미널 모드와 "사냥터
  그림 숨김" 환경 설정에서 그림만 사라지고 제목과 버튼은 남는다.

기본 배치는 캐릭터 → 스태미나(숨김) → **사냥터** → 퀘스트 → 오늘의 모험 체크 순이다.

### 2. 저장된 배치에 새 위젯을 끼워 넣는 규칙

`normalizeAdventureHomePreferences`는 저장된 배치에 없는 위젯을 맨 뒤에 붙였다. 배치를 한 번이라도
저장한 계정에서는 사냥터 카드가 홈 맨 아래에 놓이게 되므로, 없는 위젯은 기본 배치에서 바로 앞에
있던 위젯 뒤에 끼워 넣도록 바꿨다. 앞 위젯이 하나도 없으면 전처럼 맨 뒤에 붙인다.

### 3. 오늘의 모험 체크

- 머리의 주황 색면과 체크 아이콘 타일을 없애고 제목, 초기화 시간, 진행도만 둔다.
- 오늘·이번 주·생활·길드 묶음을 카드 안의 상자로 감싸지 않고 구분선으로 나눈다.
- 횟수를 채우는 진행 중 활동은 "진행 중" 배지 대신 진행 막대를 보여 준다. 읽어 주는 문구
  (`aria-label`)에는 상태가 그대로 남는다.
- 지금 할 수 있는 활동의 주황 행동 배지("수확", "이동")는 그대로 둔다. 완료·대기·반복은 배지가
  아닌 글자로 보여 준다.

### 4. 캐릭터 요약의 장비 칸

여섯 칸을 각각 상자로 감싸던 것을 한 줄로 풀고, 9px이던 이름표를 12px로 키웠다. 누르면 장비
옵션이 뜨는 동작은 그대로다.

## 하지 않은 것

- 시안 C의 머리(상자 없는 프사와 이름, 능력치 카드에 스태미너 합치기): 캐릭터 요약에는 음식·준비물·
  지원권·프리셋 표시와 펼치기가 붙어 있어 구조를 바꾸면 범위가 커진다. 이번에는 장비 칸만 정리했다.
- 아래쪽 고정 탭: 시안에 그린 다섯 탭은 가정이었다. 메인 메뉴 구조는 건드리지 않았다.
- 다른 화면(메뉴·인벤토리·전투), 배포.

## 검증

- 단위 테스트: 사냥터 카드(주 행동·스태미너·그림 띠·숨김 규칙), 배치 정규화(기본 순서, 저장된
  배치에 끼워 넣기), 체크 목록(진행 막대, 상자 없는 묶음), 캐릭터 요약 기존 테스트.
- `/dev/adventure-home`을 390px 라이트·다크, 1280px 라이트로 캡처해 확인했다.
- 타입 검사, lint, `src/adventure/v2`·`src/components`·`src/app/manual` 테스트.
- 디자인 예산 기준을 실측값으로 낮췄다(손칠 버튼 233, 12px 미만 글씨 1193).
