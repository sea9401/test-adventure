# 모험 홈 재배치와 하단 메뉴 바 (전체 디자인 개편 2단계)

## 배경

2026-11-23 오너가 게임 전체 디자인을 개편하기로 했다. 목표는 새 유저와 스토어 스크린샷에서
매력적으로 보이는 것이다.

- 1단계로 시안 C(단정한 정리)를 모험 홈에 적용했으나(`2026-11-23-adventure-home-refresh-design.md`),
  오너가 "기존 화면에 사냥터 카드만 추가된 것"이라고 판단했다.
- 이어서 시안 캔버스(https://claude.ai/artifact/SwEy83Uq7DqtcUuDvUxi1Y)의 아래 세 장으로 방향이
  정해졌다.
  - `A2 + 하단 메뉴 · 홈`: 홈 배치
  - `하단 메뉴에서 전투를 눌렀을 때`: 하단 바에서 하위 메뉴가 위로 펼쳐지는 모양
- 오너가 시안을 보며 정한 것:
  - 장면 그림은 화면 절반을 차지하는 블록이 아니라 뒤에 깔리는 배경으로 쓴다. 진하기는 지금
    게임의 장면 배경과 같게 한다.
  - 프사는 카드 밖으로 튀어나오지 않고 카드 안의 네모 칸에 둔다.
  - 메인 메뉴는 하단 바로 내리되, 지금 드롭다운처럼 탭을 누르면 하위 메뉴가 펼쳐져 한 번에
    목적지로 간다. 메뉴 화면을 한 번 더 거치게 하지 않는다.

## 지금 게임에서 확인한 사실

- 모험 홈에는 이미 마을 그림이 배경으로 깔려 있다(`GameChrome`의 `BG_TABS`, 그림 위에 밝은 회색
  80%). 미리보기 화면(`/dev/adventure-home`)에는 공통 틀이 없어 배경이 안 보였을 뿐이다. 그래서
  "그림을 배경으로"는 새로 만들 것이 없고, 달라지는 것은 배치와 메뉴 위치다.
- 휴대폰의 메인 탭은 상단바 아래 한 줄(전투·마을·생활·캐릭터·길드 5칸)이고, 홈은 상단바의 홈
  아이콘이다. 탭을 누르면 두 줄 격자 드롭다운이 내려온다(`MainTabNav`).
- 상단바(`V2TopBar`)에는 홈 아이콘, 자동 채집·낚시 진행 표시, 스태미나, 사용 가능 골드, 빠른
  메뉴(우편·알림·☰)가 있다.
- 화면 오른쪽 아래에 채팅 버튼이 떠 있고(`ChatButton`), 농장·낚시·강화 등 일부 화면은 아래에
  고정된 조작 줄을 쓴다. 보상 알림도 아래에서 올라온다(`RewardToastProvider`).
- 홈 위젯은 사용자가 순서와 숨김을 정할 수 있다(`adventureDashboard.ts`).

## 설계

### 1. 하단 메뉴 바 (휴대폰 폭)

- 768px 미만에서 메인 탭을 화면 아래 고정 바로 옮긴다. 칸은 홈·전투·마을·생활·캐릭터·길드
  여섯 개다. 홈이 탭으로 들어오므로 상단바의 홈 아이콘은 휴대폰에서 뺀다.
- 탭을 누르면 바 바로 위로 하위 메뉴 패널이 펼쳐진다. 내용과 격자는 지금 드롭다운과 같고,
  바깥을 누르거나 같은 탭을 다시 누르면 닫힌다. 항목을 누르면 바로 이동한다. 누르는 횟수는
  지금과 같다.
- 지금 있는 탭은 위쪽 굵은 선과 강조 색 글자, 펼쳐진 탭은 연한 바탕으로 구분한다. 할 일이 있는
  탭의 알림 점은 그대로 둔다.
- 768px 이상(PC)은 지금처럼 상단 탭과 아래로 내려오는 드롭다운을 유지한다.
- 하단 바와 겹치는 것들을 함께 옮긴다.
  - 채팅 버튼과 보상 알림은 바 높이만큼 위로 올린다.
  - 아래에 고정된 조작 줄을 쓰는 화면(농장·낚시·위험 해역·강화·숙련 증서 창)은 바 위에 놓이게
    한다.
  - 본문 아래 여백을 바 높이와 기기 하단 안전 영역만큼 준다.
- 은신·터미널 모드에서도 하단 바는 같은 자리에 둔다(메뉴 위치가 모드마다 다르면 헷갈린다).

### 2. 상단바 (휴대폰 폭)

메인 탭이 빠진 한 줄만 남는다. 스태미나, 사용 가능 골드, 자동 채집·낚시 진행 표시, 우편·알림·☰는
그대로 둔다. 시안에는 스태미너와 버튼 세 개만 그렸지만 골드와 진행 표시는 기능이라 빼지 않는다.

### 3. 모험 홈 배치

위에서부터 다음 순서다. 위젯 순서와 숨김 설정은 그대로 동작한다.

1. 캐릭터 카드: 왼쪽에 프사 네모 칸(84px), 오른쪽에 이름·레벨, 직업·길드, HP·MP·EXP 막대.
   아래에 장비 칸 한 줄. 음식·준비물·지원권·프리셋 표시와 펼치기 버튼은 지금처럼 남긴다.
2. (뺌) 사냥터로 가기 버튼: 구현해 보였으나 오너가 필요 없다고 보아 뺐다. 하단 바에서 전투 →
   사냥터로 두 번이면 가고, 새 유저 안내는 퀘스트 카드가 한다. 1단계의 사냥터 카드와 새 위젯
   자리 `hunt_entry`, 저장된 배치에 새 위젯을 끼워 넣는 규칙도 함께 되돌렸다.
3. 지금 가능한 행동: 한 줄 안내. 누르면 해당 화면으로 간다. 여러 개면 첫 항목과 개수를 보인다.
4. 오늘의 모험: 진행도와 초기화 시간, 그 아래 타일 세 개. 타일에는 지금 할 수 있거나 진행 중인
   활동을 앞에서부터 넣는다. 활동이 세 개보다 많으면 "전체 보기"로 지금의 목록(오늘·이번 주·
   생활·길드)을 펼친다.
5. 퀘스트, 핫타임, 공지, 게시글, 랭킹: 지금 위젯을 그대로 아래에 둔다.

### 4. 색

시안은 초록을 강조 색으로 그렸지만, 게임의 주 행동 색은 화면 스타일이 정한다(클래식은 보라,
금빛은 금색, `--ui-primary*`). 이번 단계에서는 주 행동 색 토큰을 그대로 쓰고 색은 바꾸지 않는다.
강조 색을 초록으로 바꾸는 것은 모든 화면의 버튼과 탭에 영향을 주므로 별도 결정으로 둔다.

## 1단계(C 적용)에서 이어 쓰는 것과 바꾸는 것

- 이어 쓴다: 장비 칸 한 줄.
- 바꾼다: 오늘의 모험 체크의 기본 모양(목록에서 타일로, 목록은 "전체 보기" 안으로).
- 되돌린다: 사냥터 카드, 위젯 자리 `hunt_entry`, 새 위젯 끼워 넣기 규칙.

## 시안과 달라지는 점

- 강조 색이 초록이 아니라 지금의 주 행동 색이다(위 4번).
- 상단바에 골드와 자동 채집·낚시 표시가 남는다.
- 오늘의 모험은 활동 수가 계정마다 달라 타일 세 개로 다 담지 못한다. "전체 보기"가 붙는다.
- 캐릭터 카드에 음식·준비물·지원권·프리셋 표시와 펼치기 버튼이 남는다.
- 운영 안내 한 줄은 지금의 공지 위젯으로 대신한다.
- PC는 하단 바를 쓰지 않는다.

## 나누는 순서

1. 하단 메뉴 바와 겹침 정리(모든 화면에 영향, 따로 검증).
2. 모험 홈 배치.

각 단계는 테스트를 먼저 쓰고, 로그인한 실제 화면을 390px·1280px, 라이트·다크, 클래식·금빛,
은신 모드로 캡처해 확인한다.

## 하지 않는 것

- 강조 색 변경, 다른 화면(인벤토리·전투·사냥터)의 배치 변경, 배포.
