다음 항목은 기존 설계에서 명시적으로 제외했으며, 현재 작업의 미완료 항목으로 세지 않는다.

- 0.5% 초희귀 보스 장비의 천장 또는 확정 제작
- 중복 보스 고유 전용 분해와 우두머리 핵 환급
- 개척자 무기 드롭 천장·조각 교환·중복 보호
- 특화 재료 선택 슬롯·재료 교환·드롭 천장

- `main` 브랜치 통합, 원격 푸시, 운영 기능 플래그 변경과 배포
