미개척지 중심

탐사 시작

시작 노드 · 1포인트

고정 난도의 미개척지를 개방합니다. 기본 몬스터 풀에서 사냥을 시작하고, 큰 컨셉 노드로 원하는 특화 몬스터의 출현 비중을 더합니다.

100레벨 달성 시 받은 첫 탐사 포인트로 활성화합니다.

현재 사냥 구성

한 번의 사냥에는 한 몬스터가 등장합니다. 특화 풀 합계는 최대 70%, 기본 풀은 최소 30%입니다.

흔적 보관함

풀별 흔적은 비활성화해도 유지됩니다. 흔적 1,000과 테마 재료·골드로 거래 가능한 소환석을 제작합니다.
