## 0. 진단 요약 — 왜 DEX가 못 내려오나

엔드(d50) 풀 승률에서 DEX/LUK 글래스캐넌이 100% 독주. 6+개 너프 레버를 실측했으나 전부
**DEX는 불변 + 나머지 빌드만 붕괴**(상대적으로 DEX가 더 독보). 근본 원인 셋:

1. **템포가 진짜 엔진이고 아무도 안 건드렸다.** DEX→spd→ATB 행동빈도(`actionRate`, RATE_CAP 260 ≈
   ~2배). 모든 실험이 크리·회피·명중 등 *주변부*만 만졌고 행동빈도(2배)는 무손상. 2배 자주
   행동하니 다른 너프를 흡수한다.
2. **더블딥** — DEX는 한 스탯이 공격(템포)이자 방어(회피)다. STR=공격만, VIT=방어만인데 DEX는
   둘 다. LUK도 크리(공격)+회피(방어). 그래서 "유리대포인데 유리가 아니다".
3. **처치 속도(winT 4.9턴)가 진범.** 방어 레버(회피캡↓·몹명중·크리저항)는 "피격당 처벌"이라
   유리대포가 5턴에 끝내 처벌이 쌓이기 전에 전투 종료 → 느린 빌드만 죽는다. 공격 레버(크리 제거)는
   DEX를 느리게 해도 75% 회피로 생존 → 여전히 승리. **DEX를 내리려면 처치속도+생존을 동시 타격**
   해야 하는데, 그건 곧 게임 전체를 느리게/물러지게 만든다(필드 붕괴).

### 실측된 너프 레버 (전부 역효과)
| 레버 | d50 결과 |
|---|---|
| 크리 완전제거(critMult cap→1.0) | DEX 100→100 / BAL 91→10·STR 92→0 (붕괴) |
| 회피 DEX→INT 이전 | DEX 100→100 (LUK으로 회피 누수 65%) / INT +7 |
| +LUK 회피뒷문 차단(EVA_PER_LUK→0) | DEX 100→86 / LUK 62→25 붕괴·필드 −10%p |
| 회피 계수 1/4 (캡 지연) | DEX 100→100(엔드 스탯 거대→여전히 68%) |
| 몹 명중=depth(회피 캡 관통) | DEX 100→100(winT 5턴이라 무관) / STR 92→55·INT 62→13 |
| 종합(회피→INT+명중→SPI+크리base1.2+크리÷3) | DEX 100→79 / 필드 붕괴(VIT 7·BAL 35) |

→ **결론: 너프로는 못 푼다. 약축을 부양해 "전 빌드가 깬다"로 간다. DEX는 가장 빨리 깨는
글래스캐넌 #1로 수용**(승률=생존성 패리티지 속도 패리티 아님).

## 2. PR-2 (설계만) — 크리 배율 점감 곡선

오너 관찰: 테스트 캐릭 크리배율 3.8은 과함. 단 **하드 캡 금지** — 캡 도달 후 크리뎀 스탯/패시브가
죽은 투자가 됨(회피 캡과 같은 포화 문제). 대신:

- **점감(소프트) 곡선**: `critMult = CEIL − (CEIL − BASE) × exp(−k × bonusSum)`. CEIL≈2.5 점근,
  투자는 영원히 한계효용 양수(죽은 구간 없음), 천장만 완만. (또는 완만한 계수↓ + 선형 유지)
- **몹 HP 상쇄 필수**: 크리는 엔드 딜의 척추라 전역 인하 시 전체 DPS↓ → `sim-v2-power-gate`로
  재캘리브해 몹 HP/LADDER를 그만큼 완화해야 곡선 유지(미상쇄 시 필드 붕괴, §0 종합실험 참고).
- 자체 power-gate 재튜닝이 필요해 PR-1과 분리(큰 변경 청킹).
