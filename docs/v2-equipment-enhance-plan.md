# v2 장비 강화 (+강화) 설계

> 2026-06-11. 장비 진척 축이 드랍+굴림 추격뿐인 상태에서 ① 중복 드랍·망굴림 개체의
> 소비처 ② 죽은 분해 밸브(제작 삭제 #621 이후 레시피 공백) ③ 골드 sink 부족을
> 한 번에 채우는 시스템. "기존 아이템을 먹여 업그레이드" 선호 반영.

## 목표·비목표

- 목표: 장비 개체(iid) 단위 +0→+10 강화. 굴림(옵션)과 직교하는 별도 진척 축.
- 목표: 강화석 = **사냥 드랍 전용** 재료 — 초보자도 우연히 주워 거래소에서 환금
  가능한 "돈벌이 드랍"(베테랑 수요 ↔ 초보 공급의 경제 회로).
- 목표: 파괴 없는 실패 모델(+6부터 하락만) — 소수 모수 캐주얼 서버에서 파괴는 이탈 트리거.
- 비목표: 품질/등급 시스템(이전에 명시 기각), 재료 카탈로그 부활(강화석은 캐릭터 세이브
  카운터 2개), 제작 콘텐츠 부활.

## 코어 규칙

### 재료 — 붉은/푸른 강화석 (이득·위험 프로필 분리)

매 강화 시 방식을 **선택** — 골드만(기본) 또는 돌 부스터. 같은 +10 이라도 구성에 따라
최종 수치가 달라진다(개체 정체성·거래 가치). 2026-06-11: 돌 필수 → 선택식(기본=골드만)
— 돌이 없어도 강화는 굴릴 수 있되, 돌의 희소 프리미엄(보너스·성공률)은 유지.

| | 💰 골드만 (기본) | 🔵 푸른 강화석 | 🔴 붉은 강화석 |
|---|---|---|---|
| 성공 시 위력 보너스 | +1%p | +2%p | +3%p |
| 성공률 보정 | −15%p | 없음 | −10%p |

순골드 +10 = +10% / 순푸 +20% / 순붉 +30%.

| | 🔴 붉은 강화석 (맹렬) | 🔵 푸른 강화석 (단단) |
|---|---|---|
| 성공 시 위력 보너스 | **+3%p** | **+2%p** |
| 성공률 보정 | **−10%p** (최저 25%) | 보정 없음 |
| 드랍률(승리당, 초기 다이얼) | **0.1%** (≈1,000승/개) | **0.3%** (≈333승/개) |

- 순붉 +10 = +30%(도박꾼의 길) / 순푸 +10 = +20%(안전 적층). 혼합 자유.
- 붉은 돌이 더 희귀(드랍률 차) — 고위험·고효율 프리미엄이 수급으로도 성립.
- **수급 = 사냥 드랍 전용**(분해 산출 없음 — 분해 부활은 보류). 전 깊이 드랍 —
  얕은 깊이의 초보자도 우연히 줍는다. 깊이별 수량 램프(깊을수록 1~2개)는 후속 다이얼.
- **저장 = 기존 재료 시스템 부활**: V2_MATERIALS 카탈로그에 강화석 2종 등록
  (`character.v2.materials` 맵·기존 드랍 머지 경로 재사용). 제작 삭제(#621) 후 파킹된
  타입/헬퍼가 그대로 살아난다.
- **환금 = 거래소 재료 탭 활성화**: marketplace 재료 인프라(#577, 빈 탭)에 강화석이
  첫 품목 — 베테랑(강화 수요)이 초보(공급)의 돌을 사는 경제 회로. 판매세 5% sink 겸용.

### 효과 — 위력만, 곱연산

- 개체에 누적 보너스 저장: `강화 위력 = base(굴림/카탈로그 power) × (1 + bonusPct/100)`
  내림. **위력만** 증폭(옵션·무게 불변) — 슬롯 매핑은 기존 그대로(무기=물공+마공,
  갑옷/장갑/신발=물방, 반지/목걸이=마방).
- 상한: `ENHANCE_MAX_LEVEL = 10` (보너스 +20~30%). PvP/게이트 영향은 sim 으로 확정.

### 저장 — 비파괴

- `equipment.v2.owned[].enhance?: { level: number, bonusPct: number }`
  (옵셔널 — 옛 세이브·미강화는 부재=0). 표기 예: `+7 (19%)`.
- 거래소는 개체 거래라 강화 수치 자동 승계(고강 = 고가 매물). 판매가 보정은 후속.

### 획득 회로 — 사냥 드랍 + 거래소 + 먹이기 + 골드

- **사냥 드랍**: hunt 승리 시 확률 드랍(위 표) — 기존 DropResult/재료 머지 경로 재사용.
  몬스터 무관 전 깊이 공통(초보 접근성), 수량 깊이 램프는 후속.
- **거래소(유일한 환금처)**: 재료 리스팅 활성화 — NPC 판매 없음(사용자 결정), 시세는
  수요(베테랑 강화)와 공급(전 유저 드랍)이 결정. 매우 희소해 개당 시세가 높게 형성될 것.
- **먹이기(동일 장비)**: 강화 시 같은 id 개체 1개를 재료 슬롯에 넣으면 **그 회차
  강화석 비용 면제(골드만, 돌 선택은 유지)**. 중복 드랍의 명예로운 퇴장.
- **골드 수수료**: 강 수치 비례(sink).
- 분해(salvage)는 이번 사이클 보류 — 강화석 인플레 밸브로 추후 재검토.

### 비용·성공률 (다이얼 — 초기값)

| n→n+1 | 강화석(선택 색) | 골드 | 성공률(푸른 기준) |
|---|---|---|---|
| +0 | `1 + floor(n/3)` 개 | `power × 2 × (n+1)` | 95% |
| +1~+2 | 〃 | 〃 | 90% |
| +3 | 〃 | 〃 | 85% |
| +4 | 〃 | 〃 | 80% |
| +5 | 〃 | 〃 | 70% |
| +6 | 〃 | 〃 | 60% |
| +7 | 〃 | 〃 | 50% |
| +8 | 〃 | 〃 | 40% |
| +9 | 〃 | 〃 | 30% |

- 붉은 돌 사용 시 위 표에서 −10%p (최저 25%).
- 실패: 재료(강화석·골드·먹이) 소실 + **+6부터는 강화 −1 하락**(보너스 평균 비례 차감,
  ENHANCE_DEMOTE_FROM_LEVEL=6). **파괴는 없음.** +0~+5 실패는 재료만.
- 유니크 강화 비용 ×2 (chase 는 드랍에서, 강화는 장기 투자).
- 전부 `src/adventure/data/v2/v2Enhance.ts` 다이얼 상수 — 라이브 실측 후 조정.

## 통합 지점 (코드)

- **derive**: `resolveEquippedForAggregate` 에서 개체의 enhance 를 읽어 굴림(또는
  카탈로그) power 에 배율 적용한 **합성 roll** 을 내려보냄 — `aggregateV2Equipment`/
  엔진 무수정. enhance 부재 시 byte-동일(골든 안전).
- **표시 단일 출처**: `enhancedPower(item, roll, enhance)` 헬퍼(v2EquipVariance) —
  서버 derive 와 클라 카드(인벤토리/거래소/강화 UI)가 공유.
- **API**: `POST /api/v2/me/enhance` body `{ iid, stone: "red"|"blue", feedIid? }` —
  character.v2 + equipment.v2 FOR UPDATE(기존 처분 라우트와 동일 락 순서). 성공률
  롤은 서버. 응답 `{ ok, success, enhance: {level,bonusPct}, stones, gold }`.
- **드랍**: hunt 라우트 승리 보상에 강화석 확률 롤 추가(DropResult 머지 — 기존 재료
  드랍 경로). V2_MATERIALS_ENABLED 게이트 지점 점검 후 강화석만 통과시키거나 플래그 on.
- **UI**: 대장간(`/town/smithy`) = **강화 / 분해 2탭**으로 개편(V2CraftView 의 빈
  제작 화면 대체 — 죽은 화면 부활). 강화 탭: 보유 장비 선택 → 현재/다음 수치 미리보기 →
  먹이 후보(동일 id) → 강화 버튼 → 성공/실패 연출. 인벤토리 카드에 `+N` 뱃지 +
  강화 반영 위력. 시각 폴리시는 Codex 위임.
- **피드(후속)**: +8 이상 성공 시 전체 소식/전광판 "○○ 님이 야수쇄도 대검 +9 강화
  성공!" — FEED_TYPES `enhance_high` 추가(기존 인프라 재사용).

## 밸런스 가드

- **sim**: 풀강(+10) vs 무강 — sim-v2-progression 류로 깊이별 승률 격차, PvP(아레나
  매칭) 격차 측정. ENHANCE_POWER_PCT 확정 입력. 평균 파워 상승분은 `sim-v2-power-gate`
  재실행으로 권장 파워 게이트 재검증(라이브 강화 보급 후).
- 환생 무관 — 장비는 환생 보존이라 강화 가치 안정(장기 투자 정당화).
- 강화석 수급 모델(2026-06-11 희소화): 드랍률 0.3%/0.1%·성공률 상향(후반 60%) 기준
  +10 1부위 ≈ 돌 ~43개(하락 미반영 기대값) ≈ 푸른 ~14,000승 — 자급 비현실,
  **거래소 수급이 본선**. +5까지는 돌 ~7개(~2,400승)로 중장기. 하락(+6~)까지 반영하면
  실효 비용은 더 큼. 초보 "돈벌이"는 시세가 결정(NPC 판매 없음).
  인플레/디플레는 드랍률 다이얼로.
