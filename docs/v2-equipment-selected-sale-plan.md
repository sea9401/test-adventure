# 장비 선택 판매 구현 계획

> 승인된 설계: `docs/v2-equipment-selected-sale-design.md`

1. `v2EquipVariance`에 명시적 `iid` 선택을 원자적으로 검증하고 판매 계획을 반환하는 순수 함수를 테스트 우선으로 추가한다.
2. 기존 장비 일괄 판매 API가 `iids` 요청을 검증하고, 트랜잭션 안에서 선택 변경 시 `409`로 전체 거절하도록 라우트 테스트와 구현을 추가한다.
3. `EquipmentCardGrid`에 다중 선택 표시·토글·비활성 상태를 추가하고 기존 상세/단일 선택 동작을 보존한다.
4. `EquipmentTab`에 선택 모드 진입, 하단 선택 요약, 취소·확정 동작을 추가한다.
5. `V2InventoryView`가 선택 상태를 관리하고 선택 판매 API 호출, 성공 시 잔액/보유 장비 갱신, 상태 변경 시 재조회하도록 연결한다.
6. 장비 매뉴얼에 선택 판매와 장착·잠금 보호 규칙을 안내한다.
7. 집중 테스트, 관련 전체 테스트, 타입 검사, 린트, 빌드를 실행하고 변경 파일만 커밋한다.
