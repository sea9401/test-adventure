# v2 아이템 획득 재설계 — 제작 척추 (Crafting Spine)

2026-06-02 결정. v2 아이템을 "본격적으로" 만들기 위한 획득 경로 마스터플랜.

## 0. 배경 — 토론 결론

v2는 이미 **상점(전 티어 구매) + 장비 드랍 + 재료 드랍(환금 전용·죽은 placeholder)** 하이브리드가 깔려 있었고, 제작은 없었다. 본격적으로 아이템을 채우기 전에 "획득의 척추를 어디 두느냐"를 정함.

핵심 제약: **전투가 완전 자동·단판**이라 플레이어 주도권은 전투가 아니라 **빌드/준비(build/prep)** 에 있다. → 제작은 그 주도권과 동기적(메뉴 열고 "재료 모으러 저 던전 간다")이지만, 드랍은 자동전투라 쾌감이 희석된다(로그로 사후 확인). 그래서:

- **척추 = 제작.** 누구나 도달하는 결정론적 기준선.
- **드랍 = 질감/보너스 + 유니크 chase.** 제작이 못 하는 것(주워야만 나오는 완제품)을 담당.
- **상점 = 캐치업 바닥.** 강등은 나중(Phase 3).

## 1. 확정 결정

| 항목 | 결정 |
|---|---|
| 제작 메커니즘 | **재료 직접 제작** — 재료(+골드) → 완성 장비. (소비-업그레이드 방식은 폐기) |
| 레시피 범위 | T1~T5 전부 제작 가능. T1은 상점에서도 싸게 (입문 캐치업) |
| 재료 구성 | **테마별 확장 (~15~18종)** — 계열별 정체성 |
| 레시피 습득 | **전부 자동 보유** — 재료+골드만 모으면 제작. 수집/게이팅 없음(P1) |
| 드랍 | 완성 장비 드랍 유지(지름길) + 유니크(드랍 전용, Phase 2) |
| 상점 | 강등 안 함(캐치업). Phase 3에서 재검토 |

폐기된 옵션: 소비-업그레이드, 컨셉 고정/전환 결정(직접 제작이라 자동 소멸), 숙련도 게이팅(P1 보류), 레시피 드랍 학습(보류).

## 2. 제작 시스템 — 재료 직접 제작

```
재료 N종 + 골드 → 완성 장비 (이전 장비 안 먹음)
예: 강철 주괴 3 + 약초 2 + 골드 → 강철검(T2, 힘)
```

- 원하는 장비를 재료만 있으면 바로 제작. 계열(컨셉) 제약 없음 — 빌드 유연성은 "어느 재료를 모으느냐"로 자연 발생.
- 골드 비용 = 티어 곡선 (기존 `shopPriceFor` 또는 별도 제작 곡선에서 도출, 상점 구매가보다 싸게 — 제작이 정규 경로가 되도록). sim 캘리브 다이얼.
- 깊은 층 = 상위 재료 = 상위 장비. **"장비 = 던전 전담"** 정신 유지(재료가 던전에서 나오므로).

## 3. 재료 체계 — 테마별 확장

기존 5종(돌멩이·약초·슬라임조각·뼛조각·별빛가루)을 계열 정체성을 가진 ~15~18종으로 확장. **계열 = 어느 장비군에 들어가나 + 어느 구역에서 나오나.**

### 계열 (제안 — 튜닝 대상)

**금속 계열** — 검(힘)·중갑(갑옷/장갑/신발 heavy):
- `v2_rough_ore` 거친 광석 (T1~2)
- `v2_steel_ingot` 강철 주괴 (T2~3)
- `v2_mithril_ore` 미스릴 원석 (T4~5)

**가죽/직물 계열** — 경갑(갑옷/장갑/신발 light)·활(민):
- `v2_tough_hide` 질긴 가죽 (T1~2)
- `v2_silk_thread` 비단실 (T2~3)
- `v2_windweave_cloth` 바람결 천 (T4~5)

**마력 계열** — 지팡이(지)·반지(운)·목걸이(마법):
- `v2_mana_dust` 마력 가루 (T1~2)
- `v2_rune_shard` 룬 조각 (T2~3)
- `v2_arcane_crystal` 비전 수정 (T4~5)

**공용/보조** (계열 무관, 모든 제작의 접착제 + 티어 게이트):
- `v2_herb` 약초 (기존 — 저티어 범용)
- `v2_slime_shard` 슬라임 조각 (기존 — 저티어 접착)
- `v2_bone_fragment` 뼛조각 (기존 — 중티어 공용)
- `v2_beast_sinew` 짐승 힘줄 (중티어 공용)
- `v2_starlit_dust` 별빛 가루 (기존 — T5 공용 게이트)

(돌멩이 `v2_stone_chip`은 `v2_rough_ore`로 흡수하거나 최저티어 범용으로 잔류 — PR-1에서 정리.)

### 재료 출처 — 구역(층) 테마

v2 드랍은 몬스터별이 아니라 **층(구역)별**이라 출처를 구역으로 잡는다. 층마다 계열을 편향:

| 층 (구역) | 주력 재료 | 비고 |
|---|---|---|
| 1 변경 입구 | 거친 광석·질긴 가죽·약초 | 저티어 범용 |
| 2 변경 외곽 | + 강철 주괴·비단실·마력 가루 | 중저 진입 |
| 3 산악 평원 | 강철 주괴↑·뼛조각·룬 조각 | 광산 느낌(금속↑) |
| 4 화염 지대 | 미스릴 원석·짐승 힘줄·비전 수정 | 고티어 진입 |
| 5 별빛 회랑 | 미스릴 원석·바람결 천·비전 수정·별빛 가루 | T5 게이트 |

→ "금속 장비 키우려면 산악, 마법 장비는 별빛" 식으로 **장비군마다 다른 사냥터**로 보냄. 제작에 질감이 생김.

## 4. 레시피

- **범위**: 55종 전부 (또는 T1 제외 시 ~44). 자동 보유.
- **형식**: `{ result: V2EquipmentId, materials: {id, count}[], gold }`.
- **재료 매핑 규칙**: result의 슬롯/컨셉 → 계열 1~2종 + 공용 1~2종, 티어 ↑일수록 상위 재료·수량·골드 ↑.
- 데이터 구조는 v1 recipes 머신을 참고하되 v2 전용 풀(`data/v2/`)에 둔다 — v2_ 접두어 분리 원칙 유지.

## 5. 드랍 · 상점 · 유니크

- **완성 장비 드랍** (`rollEquipDrop`): 유지. 가끔 완성품이 떨어져 한 티어 점프하거나 다른 컨셉을 손에 쥐는 "행운의 지름길". 드랍률 재튜닝은 Phase 2(라이브 데이터).
- **재료 판매(환금)**: 유지(오버플로 밸브). 단 이제 제작 수요 발생.
- **상점**: 강등 안 함. T1 싸게 유지(캐치업). Phase 3 재검토.
- **유니크** (Phase 2 투입):
  - 정규 55종 밖의 **드랍 전용** 완제품. 상점·제작 불가, 분해 불가.
  - **옵션 프로필로 규칙 깨기**: 슬롯 시그니처(장갑=치명/신발=회피/목걸이=MP) 규칙을 깨는 조합 → 강화판이 아니라 사이드그레이드/빌드 정의템 (파워크리프 회피). 새 엔진 코드 0 (옵션 후-가산).
  - **층/보스 시그니처 + 초저확률 별도 롤**(0.1~0.5%대, 깊은 층 가중). 어느 유니크가 어디서 나오는지 의도 명확.
  - id당 유니크(1개) 구조라 중복 방지 자동(ownedSet 제외).
  - 시작 규모: 층/권역당 1개씩 **5~8개**, 반응 보고 확장.

## 6. 단계적 롤아웃 (PR 스택)

순차 의존이 강해 병렬 워크트리보다 스택에 가깝다. (PR-1 재료와 PR-5 유니크 훅만 상호 독립.)

### Phase 1 — 제작 토대
- **PR-1 재료 체계**: 테마별 재료 ~15~18종 데이터 + 층 드랍 풀 테마 개편(`dungeonDrops.ts`). 마이그: 기존 5종 id 보존/흡수. (데이터 only)
- **PR-2 레시피 데이터**: 55(또는 44) 레시피, 재료+골드. 자동 보유. (PR-1 의존)
- **PR-3 제작 엔진 + 라우트**: 재료·골드 소비 → 장비 grant, save 정합. (PR-1/2 의존)
- **PR-4 제작 UI**: 제작 탭/뷰 (슬롯·컨셉·티어 그리드, 재료 부족 표시). (PR-3 의존)
- **PR-5 유니크 훅(데이터 모델만)**: rarity 플래그 + 별도 롤 스캐폴드. 미populate. (독립, 소형)

### Phase 2 — 드랍 질감 (라이브 데이터 후)
- 정규 드랍 품질롤(v1 3단 이식, 위력 배수만, 접사X) + 유니크 5~8개 본격 투입 + 오토헌트 로그 희귀도 부각 + 드랍률 재튜닝.

### Phase 3 — 정리
- 분해(salvage) 설계(교환비·유니크 충돌·상점판매 경쟁 답 먼저) + 상점 T1~2 강등 + 골드 경제 재튜닝.

## 7. 리스크 / 미정 다이얼

- **골드 경제 충격**: 재료가 환금 연료를 일부 그만두고 제작이 골드를 먹음 → 새 싱크지만 재료→골드 수입 감소. **순 영향 Phase 2에서 측정·재튜닝** (monitoring 골드 분포).
- **재료 5종 → 18종 인플레**: 인벤토리/도감 UI 부담. 도감 "재료 → 드랍 구역" 역인덱스(`MATERIAL_DROP_SOURCES`) 확장 필요.
- **레시피 재료 매핑 단조로움 방지**: 같은 티어라도 계열 재료가 갈리도록(금속 vs 마력) 매핑 규칙을 기계적으로 적용하되 검수.
- **마이그레이션**: 기존 `v2_stone_chip` 등 5종 보유분 보존(`mergeDrops` 비파괴 원칙) — id 개명/제거 시 보유분 유실 주의.
- **튜닝 다이얼**: 제작 골드 곡선, 재료 수량/드랍률, 유니크 확률 — 전부 sim 캘리브 단계에서.

## 8. 길드 대장간 / 장인 루프

길드 대장간은 일반 마을 대장간과 분리된 길드 영지 제작 루프다.

- **진입**: 길드가 보유 마을 건축물 슬롯에 `guild_smithy`를 배치해야 제작 탭 사용 가능.
- **장인 성장**: 제작 성공 시 `crafting.v2.artisan.blacksmith`에 숙련도와 제작 횟수 누적.
- **주간 랭킹**: 제작 성공 시 `crafting.v2.weeklyWorkshopStats`에 현재 주차(`YYYY-Www`) 제작 횟수, 품질 제작 횟수, 제작 XP를 기록한다.
- **정렬**: 장인 랭킹은 현재 주차 기준 `제작 횟수 → 품질 제작 횟수 → 주간 제작 XP` 순으로 정렬한다.
- **보상**: 현재 시즌 순위 기준 1위/3위/10위 칭호와 길드 명성을 지급한다. 칭호는 영구 1회, 길드 명성은 시즌당 1회 수령.
- **정산 범위**: 현재 구현은 별도 스냅샷 테이블 없이 현재 시즌 카운터 기준 수령 방식이다. 시즌 종료 후 확정 순위 보관/지난 시즌 우편 보상까지 확장하려면 `artisan_weekly_rankings` 같은 스냅샷 테이블이 필요하다.

제작 전용 장비 밸런스 기준:

- **Lv6 / 대장간 Lv2**: 제작 전용 T3 사이드그레이드 입문. 총 비용은 390~440대, XP는 66~70.
- **Lv7 / 대장간 Lv3**: 장신구·방어구 핵심 제작. 총 비용은 Lv2 구간보다 높게 유지, XP는 82~86.
- **Lv8 / 대장간 Lv4**: 고급 설비 전용 무기. 비용과 XP를 크게 올려 길드 설비 투자 목표로 둔다.
- **Lv9 / 대장간 Lv5**: 최상위 장신구. 현재 길드 대장간 제작 루프의 장기 목표.
