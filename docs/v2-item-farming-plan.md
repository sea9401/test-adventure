# v2 아이템 파밍 구조 재설계 — "밴드 보상 + 굴림 사냥"

> 상태: **설계 확정 · 구현 0** (2026-06-07 설계 논의 + Codex sanity-check). 본 문서가 PR 시리즈를 구동한다.
> 방향: 드랍 중심, **제작/재료 전면 배제**. 무한 프론티어 깊이밴드별 보상 + god-roll(인스턴스 굴림) 추격.

## 0. 한 줄 요약

깊이를 푸시하면 **그 밴드 고유의 세트·유니크 + 더 좋은 *굴림*의 장비**를 드랍으로 추격한다. 티어(T1~T5)는 영구 캡 — 깊이는 티어가 아니라 **굴림 품질 + 수평 밴드 전리품**을 올린다. 빌드 *지정* 주도권은 **상점**(고정스탯 구매), 추격·미세향상은 **드랍**(와이드 굴림). 제작·재료·분해는 없앤다(난잡 제거).

---

## 1. 배경 / 진단 (왜 재설계하나)

현 파밍 루프는 **절반만 구현**:

- ✅ 작동: 장비 드랍(킬당 ~5~12%, 종류당1·중복제외·티어가중·굴림) + 골드/EXP + 상점 구매 + 레벨/숙련 성장.
- ❌ **재료/제작 비활성**: `V2_MATERIALS_ENABLED=false`. 들판 5종만 정의, 깊이 2+ 재료풀 비어있음. V2CraftView·v2Recipes·salvage 는 살아있으나 재료가 없어 **죽은 기능**.
- ❌ **깊이 3+(밴드 A~F) 아이템 진행 정지**: 드랍풀이 `DROP_FLOOR_CAP=8`에서 클램프 → 깊이 13+ 는 floor-8 풀 재탕. **깊이 푸시가 새 아이템을 0개 준다** = 1순위 구조결함.
- ⚠️ 유니크 6종(floor 1~5만), 세트 1종(들가죽·inert), 거래소 없음, 강화/인챈트 축 없음(v2 의도적 제거), 만렙 후 파밍 동기 부재.

**핵심 문제**: 무한 프론티어인데 아이템 보상이 floor 8에서 멈추고, 제작 척추는 죽어있다.

---

## 2. 방향 결정

**채택: "밴드 보상 + 굴림 사냥"(Band-Locked Roll Chase), 드랍 중심.**

- 깊이 = 밴드별 고유 전리품(세트·유니크·슬롯편향) + **굴림 품질**(바닥↑). 티어 캡은 T5 유지.
- 무한 엔드게임 = **god-roll 추격**(같은 장비의 더 좋은 인스턴스 굴림). 디아블로/POE식.
- **제작/재료 전면 배제** — 사용자 결정. 이유: 재료 + 아이템 종류 증가 = 난잡. 빌드 지정 주도권은 *상점*이 대신한다.

**거부한 대안**: ②순수 드랍수집(주도권↓) ③제작 올인(난잡·드랍 도파민↓) ④프론티어 렐릭 treadmill(강화 감성 재현·밴드 정체성 붕괴 — Codex도 "나중·캡 걸고만").

---

## 3. 코어 루프

```
깊이 푸시(수동 프론티어)
  → 상점에서 기반 장비 구매(고정스탯·부위/티어/컨셉/계파무기 지정)
  → 도달한 최고 밴드 파밍
      → 드랍: 밴드 세트·유니크 + 굴림 붙은 장비(보유분 중복 포함)
  → 굴림 비교 → 더 좋으면 교체, 약한 건 판매(수동, ARPG식)
  → 무한 추격: 깊을수록 굴림 바닥↑ + 밴드 전리품
  → 수평: 48계파(4직군×12) × 밴드 세트(문제해결 정체성) = 빌드 다양성
```

상점 = 신뢰 가능한 기반(floor). 드랍 = 그 위를 능가하는 굴림 + 밴드 고유물(추격).

## 4. 메커니즘 상세

### 4.1 밴드 보상 (`rewardBandForDepth`)
- `DROP_FLOOR_CAP=8`(min(depth,8)) → **`rewardBandForDepth(depth)`** 로 교체. 6깊이 테마 밴드(들판/깊은산/마른협곡A/얼음호수B/심층동굴C/잊힌성소D/리자드늪지E/짐승의소굴F[무한루프])에 매핑.
- 밴드마다: **티어 가중**(초반 밴드는 저티어, 중반+ T5 도달) · **밴드 세트 1종** · **밴드 유니크 2~4종** · **슬롯/컨셉 드랍 편향** · **굴림 바닥 보정**.
- 깊이 ↔ 보상: 더 깊다고 *티어*가 오르진 않음(T5 캡). 대신 **굴림 바닥↑ + 밴드 고유물 + 수율↑**. 얕은 밴드는 그 밴드 고유 세트/유니크 때문에 여전히 의미 있음(수평).
- 대략: 깊이 1~12=T1~T3·스타터 / 13~30=T3~T5 전환·첫 빌드세트 / 31~42=T5 상시·진지한 유니크 / 43+=T5만·최고 굴림 바닥·F밴드 세트/유니크.

### 4.2 굴림 (god-roll 추격의 엔진)
- **편차 확대**(현재 `v2EquipVariance` ±30% → 더 체감되게). 단 **최대치는 적당히, 깊은밴드 *최소치*를 더 올림** — "저굴림 소멸 > 고굴림 폭발"(깊이 게이팅·PvP 안정).
- **굴림 % 표시**: 슬롯 가중 점수(무기=위력↑, 방어/장신=방어/옵션, **무게는 낮을수록 좋음** → 단일 %로 환산 + 변동 스탯 행 표기). 모든 스탯 동일 가중 아님.
- **중복 드랍 = 수동 보관(ARPG식)**: no-dup 규칙 완화 — 보유 id 도 새 굴림으로 재드랍. 인벤에 들어오고 플레이어가 비교·교체·판매. ⚠️ 첫카피 보호(슬롯 다 채우기 전엔 미보유 우선) 권장.
- **범람 우려는 과장이었음**: 드랍률 ~5~12%/킬이라 50회 배치 ≈ 드랍 5개 안팎(50개 아님). 인벤 도구(§4.5)로 충분. 드랍타임 keep-임계치 필터는 **선택**(나중 편의).

### 4.3 상점 = 빌드 지정 주도권
- 제작이 없으므로 **상점이 "원하는 부위/티어/컨셉/계파무기를 골드로 지정 획득"** 담당. 계파무기는 이미 상점 전용(noDrop).
- 상점 장비 = **중간 백분위(예 45~55%) 고정 굴림** 기반(현재 굴림 0 → 변경). 드랍이 가끔 능가하되 첫 드랍에 즉시 무효화되지 않게.
- ⚠️ **계파무기 추격 슬롯**: 계파무기가 상점전용·고정이면 무기게이트 계파는 추격할 무기가 없음 → **깊은밴드 굴림 변형**(rolled spec weapon) 또는 frontier-forged 변형 추가.

### 4.4 세트 / 유니크
- 둘 다 **드랍 전용 사이드그레이드·문제해결**(빌드 *필수* 아님 — 상점 기반으로 클리어 가능해야). 밴드 정체성:
  - 협곡=속도/크리, 얼음=HP/지속, 동굴=버스트, 성소=마법, 늪=DoT저항, 소굴=프론티어 푸시.
- craftOnly 폐기 → 세트는 드랍 전용으로 전환. 유니크는 밴드별 populate.
- ⚠️ **유니크 판매정책 먼저 결정**(현재 `shopPriceOf`가 unique=undefined라 판매 불가 → 중복 유니크 처리: 특별가 판매 / 자동변환 / 폐기·잠금 플로우).

### 4.5 인벤토리 도구 (난잡 방지 — 필수 축)
수동 수집 + 와이드 굴림 + 중복 드랍 = 누적. 난잡을 막으려면 **선택이 아니라 필수**:
- 아이템에 **굴림 %** + **굴림순 정렬**
- **일괄 판매**("미장착 전부" / "N% 미만 전부") + **즐겨찾기 잠금**
- (선택) 드랍타임 keep-임계치(플레이어 설정 N% 미만 자동 골드화)

### 4.6 PvP
- **굴림 그대로 반영**(사용자 결정) — god-roll 이 아레나 파워에도. 장비운이 PvP 실력의 일부. **튜닝 레버**: 배포 후 격차 과하면 그때 아레나 굴림 캡/정규화 도입.

### 4.7 제거 (정리)
- 죽은 `V2CraftView`·`v2Recipes`·`/api/v2/me/craft`·`/api/v2/me/salvage`·재료(`dungeonDrops` materials 부분)·인벤 재료 탭 제거.
- ⚠️ **제거 전 craftOnly 재분류**: 들가죽 세트 등 craftOnly 아이템을 삭제/상점화/드랍전용 전환(고아화 방지).

## 5. 결정 로그 (논의 결과)

| 결정 | 값 | 근거 |
|---|---|---|
| 방향 | 밴드 보상 + 굴림 사냥(드랍 중심) | 무한 프론티어 + 자동전투엔 굴림 추격이 무한 엔드게임 |
| 제작/재료 | **전면 배제·제거** | 재료·아이템 종류 = 난잡(사용자가 적극 기피) |
| 빌드 주도권 | 상점(제작 아님) | 계파무기 등 지정획득은 상점이 커버 |
| 중복 드랍 | 수동 보관(ARPG식) | 굴림 고르는 재미·주도권. 드랍률 낮아 범람 안 함 |
| 굴림 편차 | 크게(체감) | god-roll 이 엔드게임이므로 추격 가치 필요 |
| 굴림 형태 | 최대 적당·깊은 최소↑ | 깊이 게이팅·PvP 안정("저굴림 소멸") |
| PvP 굴림 | 그대로 반영 | 장비운도 실력. 캡은 사후 튜닝 레버 |
| 티어 | T5 영구 캡 | 인플레 없는 무한 = 굴림+수평으로 |

## 6. Codex sanity-check 반영

- **순서**: B(중복+와이드)를 D(인벤도구) 전에 내면 위험 → **D를 B 전/함께**.
- **상점 임시화**: 고정스탯이면 첫 드랍에 무효화 → 상점=중간백분위 기반(§4.3).
- **계파무기 추격**: noDrop·고정이면 추격슬롯 없음 → 깊은밴드 굴림 변형(§4.3).
- **굴림이 깊이 게이팅/PvP**: 최대 적당·최소↑·`floorPowerGate` 대조 검증(§4.2, 4.6).
- **craftOnly 고아화**: 제거 전 재분류(§4.7).
- **유니크 판매**: 정책 먼저(§4.4).
- **밴드 정체성 빈약 우려**: 밴드당 최소 세트1+유니크2~4+슬롯편향(§4.1).

## 7. 미결 세부 (구현 중 확정)

- 밴드별 세트 테마·보너스 수치(협곡=속도/크리 …)와 유니크 6밴드 populate.
- 굴림 % 환산 공식(슬롯별 스탯 가중) + 편차 최대/최소 다이얼 값.
- 깊은밴드 계파무기 굴림 변형 메커니즘(드랍? 상점 리롤?).
- 유니크 중복 판매/잠금 정책.
- 첫카피 보호 정확한 규칙(슬롯별 미보유 우선 가중).

## 9. PR 시퀀스 (Codex 조정 순서)

1. **A1 — `rewardBandForDepth` 뼈대**: floor-8 캡 → 밴드 보상 매핑(중복완화 전, 기존 풀 재배치만). 단독 안전·1순위 구조결함 해소.
2. **D1 — 인벤 안전**: 굴림% 표시·굴림순 정렬·즐겨찾기 잠금·일괄판매 API/UI. B의 전제.
3. **B — 중복 드랍 완화 + 굴림 확대 + 굴림% 데이터**: 가드레일(첫카피 보호·최대 캡·깊은밴드 최소↑). (선택) 드랍타임 임계치.
4. **C — 밴드별 세트·유니크 콘텐츠**: 유니크 판매정책 먼저. craftOnly 세트 드랍전용 전환.
5. **A2 — 굴림 바닥/수율 튜닝**: 실측 데이터 후 캘리브(`floorPowerGate` 대조).
6. **E — 제작/재료/분해 제거**: craftOnly 재분류 후 정리.

**단독 위험 PR**: B without D(인벤 범람) · C without 유니크판매정책(못파는 클러터) · E before 재분류(고아화) · 와이드굴림 before PvP 결정(이미 §4.6 그대로반영으로 결정).
