# v2 아이템·스킬 시스템 재설계 — 1차 디자인

**작성일**: 2026-05-26 · **상태**: 1차 안 (codex 검토 대기) · **결정 미정**

## 1. 배경

v2 게임 리워크는 라이브 시스템을 거의 그대로 재활용하면서 새 컨셉(일기토/3:3 토너먼트/본 병사 전쟁/거점 점령/공용 자원 풀) 을 얹은 상태. 골격은 굴러가지만 사용자 직관상 **라이브 솔로 그라인드 시스템이 v2 의 길드 협력 컨셉과 안 어울리거나 꼬일 듯**한 위화감. 이 문서는 어떻게 갈아엎을지 (혹은 어디까지 슬림화 할지) 결정하기 위한 1차 옵션 정리.

**핵심 충돌**:
- 솔로 캐릭 풀세팅(강화+마법부여+룬+set+파라곤)이 길드원 3명을 매 토너먼트마다 관리하는 부담으로 곧장 직결.
- 본 병사 전쟁은 power 단순 계산이라 개인 장비/스킬과 연결이 약함 — "내 캐릭에 투자한 게 길드 전쟁에 어떻게 도움 되나" 가 불투명. 그런데 거점 점령권은 일기토가 아니라 본 병사 전쟁이 결정한다 (`v2/outpost/claim/route.ts`) → 개인 성장의 의미가 더 모호.
- 라이브 25종 AP 스킬 + 일반 스킬 슬롯 + 스탯별 6티어 특기까지 더하면 "전투 효과 과밀". 단판 일기토/토너먼트에서는 누적·페이즈 트리거가 발동 기회조차 없음.
- v2 전투는 derivePlayerCombatFromSaves 가 `paragon.v1`/enchant/rune 효과를 모두 적용. placeholder V2_EQUIPMENT 만 효과 0 → 시스템 절반은 라이브, 절반은 v2 라 일관성 없음.

## 3. 디자인 원칙 (제안)

1. **3명 풀세팅 부담 < 솔로 풀세팅 부담**. 라이브가 솔로 1인에게 N 손잡이라면, v2 는 길드원 1인당 N/3 이하.
2. **개인 진행 → 길드 전쟁에 자연스럽게 기여**. 개인 캐릭 강화가 일기토뿐 아니라 본 병사 전쟁에도 명시적 가산 (예: 장수 보정).
3. **공용 풀이 길드 진행의 주축**. 개인 강화는 슬림하되, 공용 자원/유물/주문서가 길드 협력의 깊이를 담당.
4. **마이그레이션은 비파괴**. v2 키스페이스(character.v2 등) 안에서만 변경, 라이브 키 안 건드림. 폐기되는 v2 placeholder 는 그냥 삭제(test-adventure 라이브 데이터 보존 책임 없음).

## 4. 옵션 4안

### 옵션 A — **풀-라이트** (가장 슬림)

- **장비**: 슬롯 3개 그대로. 각 장비에 5 스탯 중 1~2개 ±N 보너스 (등급 1~5단계, 단순 선형). 강화·마법부여·룬·set 전부 폐기.
- **스킬**: v2 전용 5~10종 신규. 토너먼트 친화 (단판 단발, 페이즈 누적 X). 라이브 25종 AP 스킬 폐기.
- **파라곤**: 폐기.
- **본 병사 전쟁 연동**: 장수(=출전 캐릭) 의 atk·def 가 power 가산 — 이미 있음.

**장점**: 3명 풀세팅이 단 5분. 진입장벽 ↓. v2 컨셉에 가장 정렬.  
**단점**: 솔로 그라인드의 깊이 손실 → "성장의 재미" 가 옅음. 개인 캐릭 진행이 너무 빨라 길드 모드까지 도달 후 할 게 적음.

### 옵션 B — **중간** (라이브 일부 살림) ★

- **장비**: 슬롯 3개 + 등급 + **1 마법부여 슬롯**(랜덤 옵션). 강화는 폐기 (등급으로 대체). 룬·set 폐기.
- **스킬**: 라이브 25종 → 슬림화 10~12종 선별. 누적·페이즈·연속 사냥 위주 스킬 제외, 단판/짧은 전투에 보상 있는 것 위주. v2 전용 신규 2~3종 추가 (예: 토너먼트용 "라스트 스탠드").
- **파라곤**: 폐기.
- **별빛 강화 대체**: 5층 종착 → "별빛 유물" 길드 공용 슬롯 (옵션 C 와 연결).
- **본 병사 전쟁 연동**: 장수 atk/def + 마법부여 옵션 일부가 부대 효과로 변환.

**장점**: 진행감 (마법부여 굴리는 재미) 유지. 길드원 3 관리도 등급+마법부여 1개라 부담 적당.  
**단점**: 두 시스템 (개인 마법부여 + 길드 공용) 병행 관리. 디자인·구현 비용 ↑.

### 옵션 D — **코드 변경 최소** (보수)

- 라이브 시스템 (강화·마법부여·룬·set·파라곤·25종 스킬) **거의 그대로 유지**. v2 placeholder 만 채움.
- V2_EQUIPMENT 에 옵션 효과 추가, 별빛 강화·마법부여 풀을 v2 전용 데이터로 복제.
- 갈아엎지 않고 "v2 의 placeholder 구멍만 메우는" 안.
- 가이드라인 문서로 "v2 에서는 풀세팅 안 하셔도 됩니다" 권장.

**장점**: 구현 비용 최저. 라이브 검증된 시스템 그대로. 솔로 플레이어 친화.  
**단점**: 사용자가 처음 지적한 "안 어울리거나 꼬일 듯" 의 원인을 해결 못 함. 3명 풀세팅 부담 그대로. 컨셉 정렬도 매우 낮음.

### 옵션 C — **길드 공용 시스템 우선** (가장 v2 결)

- **개인 장비/스킬**: 옵션 A 수준 슬림.
- **길드 공용 유물·주문서**: 공용 풀에서 활성화하면 모든 길드원 전투에 효과 (예: "철의 의지" — 모든 길드원 def +10, soldiers 50 소비, 7일 지속). 이게 진행의 주축.
- **장비 강화 자원이 공용 풀**: 개인 장비 등급 업도 stone/주문서로. 즉 개인 강화도 길드 협력의 결.
- **본 병사 전쟁 비중 ↑**: 일기토/토너먼트는 부차, 본 병사 전쟁이 정점.
- **파라곤**: 폐기.

**장점**: v2 컨셉이 가장 일관 (길드 협력 = 진행 = 깊이). 새 차원의 그라인드 (유물 풀).  
**단점**: 솔로 플레이어/소수 길드 입장에서 진입 어려움 (공용 풀이 못 차오름). 구현 비용 가장 큼.

## 6. 추천 — **A 또는 C** (B 는 함정일 가능성)

당초 1차 추천이었던 B 의 약점이 codex 검토에서 드러남:
- B 의 "라이브 마법부여 시스템 재활용" 은 derivePlayerCombat 이 enchant/rune/paragon 이 깊게 엮인 단일 함수 → 슬림화하려면 **별도 v2 derive 분기** 가 필요. 즉 "재활용" 이 아닌 "복제 + 분기". 구현 비용이 옵션 A/C 와 비슷해질 수 있음.
- B 는 개인 마법부여 + 길드 공용 시스템 병행 관리. 사용자 입장에서 학습 비용 ×2.
- "중간" 의 본질적 약점 — 사용자 의도 "갈아엎기" 와도 정합 부족.

**둘 중 하나로 좁히는 게 더 적절**:
- **A (풀-라이트)** — 사용자가 "단순하게 다시 시작" 을 원하면. 만렙 후 진행 부족 위험은 v2 의 5층 ×4 난이도 + 거점/토너먼트 메타게임 으로 충분히 채울 수 있다고 본다면 OK.
- **C (공용 우선)** — 사용자가 "v2 만의 새로운 깊이" 를 원하면. 단 소규모 길드 진입 어려움은 풀 적립 자동화(예: 모든 사냥 골드/재료의 N% 자동 길드 풀로) 로 완화 필요.

옵션 D 는 사용자 직관과 충돌. B 는 함정 가능성. 결정은 사용자 의도에 따라 A vs C.

## 8. Open Questions (사용자 결정 필요)

1. **옵션 A/B/C/D 중 선택** — 또는 변형. 사용자 의도("갈아엎기")는 A 또는 C 로 좁혀짐.
2. **v2 전투의 최종 판정 축이 영웅(일기토/토너먼트) 인가 병사(본 병사 전쟁) 인가** — 현재 거점 점령권은 본 병사 전쟁이 결정 (`v2/outpost/claim`). 일기토를 풀세팅 깊게 가도 점령엔 의미가 옅음. 영웅 = 정점이면 점령 판정 재설계 필요.
3. **개인 성장 → 본 병사 전쟁 영향 비율** — 장수 atk/def 가 부대 power 의 몇 %p 까지 변동시켜야 "내 성장이 의미 있다" 가 느껴지는지 (수치 기준).
4. **장비 등급 1~5 / 1~3 / 1~10** — 진행감과 단순함의 trade.
5. **(옵션 C 만) 공용 풀 적립 자동화** — 모든 사냥 골드의 N% 자동 길드 풀로 → 소규모 길드 진입 완화. 또는 수동 기부만.
6. **파라곤 폐기 확정** — 만렙 후 할 일을 5층 ×4 + 거점 메타게임으로만 충당할지.
7. **마이그레이션 시점** — 지금 갈아엎을지(현재 데이터 적음), v2 메커닉(세금/heartbeat 등) 더 만들어 본 후 갈지.
