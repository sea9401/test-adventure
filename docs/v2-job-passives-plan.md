# v2 직업 시그니처 → 패시브 전환 플랜

작성 2026-06-02. v2 직업 정체성 강화 작업.

## 배경 / 문제

현재 v2 직업이 전투에서 갈리는 지점은 단 둘뿐이다.

- **앵커 스탯 % 보너스** — derive에서 직업 앵커 스탯에 티어별 +%(1차 10 → 2차 18 → 3차 26 → 4차 35). `derivePlayerCombatV2.ts:280` 의 *유일한* 직업 분기.
- **시그니처 스킬** — 직업당 티어별 1개(총 24종), `requireClass` 로 타직업 학습 차단. 상태이상 색(궁=출혈/마=소각/인=중독/무=무력/사=힐/검=순수물뎀)을 담음.

문제는 시그니처가 대부분 "앵커 스탯으로 스케일하는 데미지 스킬(+DoT)" 이라 **공유 7속성 스킬 풀과 구조가 똑같아** 직업을 바꿔도 "또 다른 데미지 스킬" 느낌이라는 것. 데미지가 아닌 효과(사제 힐·무도가 방깎)만 그나마 달라 보인다 → **데미지 아닌 효과일수록 직업색이 산다**는 신호.

## 방향

시그니처(액티브)를 **상시 패시브**로 전면 대체한다.

- 액티브 데미지 스킬이 **구조적으로 못 하는 것**(추가타·받피감·지속회복·명중·크리배율·확률 DoT)을 줌 → 차별화가 큼.
- **자동단판 전투**라 액티브는 턴/AP에 따라 발동이 들쭉날쭉하지만 패시브는 항상 적용 → 직업색이 안정적으로 드러남. 오히려 자동전투에 더 맞다.

## 확정된 결정

1. **전면 대체** — 6직업군 시그니처 전부 패시브로. 일관성.
2. **학습 유지** — 패시브는 지금처럼 숙련 포인트로 학습해 해금/업그레이드(싱크 보존). 전직=게이트, 학습=실제 업그레이드.
3. **상태이상 흡수** — 출혈/소각/중독을 패시브에 흡수.
4. **on-hit DoT은 확률 발동** — 매 평타 확정 갱신이 아니라 확률 판정.
5. **환급 없음** — 학습 비용을 유지하므로 이미 시그니처를 배운 캐릭은 그 비용으로 패시브를 이미 산 셈. 환급하면 이중지급.
6. **슬롯은 자유로 둠** — 시그니처가 슬롯을 안 먹으니 슬롯 여유↑. 전 직업이 같은 속성기로 채워 다시 동질화될 우려는 **후속(직업 전용 스킬 풀, Lever C)** 으로 보완. 이번 범위 아님.

## 패시브 6종

`passive level` = **현재 직업군에서 학습한 시그니처 중 최고 티어**(1~4). 전직으로 다음 티어 학습이 열리고, 학습해야 패시브가 올라간다.

| 직업군(축) | 패시브 | 엔진 구현 | 상태이상 |
|---|---|---|---|
| 검사 STR | 평타 추가타 확률 +% | `extraAttackChancePct` 가산 (기존 재사용) | — |
| 무도가 VIT | 받는 피해 −% | `damageReductionPct` (신규) | — |
| 마법사 INT | 마법공격력 +% | derive에서 `magicAtk ×(1+%)` (엔진 무변경) | 소각 |
| 사제 SPI | 매 턴 자가회복(maxHP %) | 턴시작 힐 훅 (신규) | — |
| 궁수 DEX | 공격 시 출혈 + 명중 +% | on-hit DoT(확률, 신규) + `accuracyPct` 가산 | 출혈 |
| 인술 LUK | 크리뎀 배율 + 공격 시 중독 | `critMult` 가산 (재사용) + on-hit DoT(확률) | 중독 |

- DoT 보유(궁/인/마)는 "스탯 + 상태이상" 콤보, 비DoT(검/무/사)는 단일 기계 효과 — 기존 시그니처 색과 일치(검=순수물뎀, 사=힐, 무=방어).
- **on-hit DoT 판정 규칙**: 플레이어가 그 턴에 피해를 입혔으면(평타든 스킬이든) 확률 판정 → 성공 시 해당 DoT 부여/갱신. 마법사 소각도 마법 스킬 피해에 묻어 발동되도록 "데미지 입힌 턴" 기준으로 통일.

## 엔진 변경 (신규 훅은 3개뿐)

`PlayerCombat`(`engine.ts`)에 옵션 필드 추가, `derivePlayerCombatV2Pure` 가 채움:

- 신규: `damageReductionPct?`, `passiveOnHitDot?: { chancePct; label; dmgPerTurn; turns }`, `passiveTurnHealPct?` (maxHP 비율).
- 재사용(가산만): `extraAttackChancePct`, `critMult`, `accuracyPct`, `magicAtk`(derive 단계에서 %배).

엔진 적용 지점(`advanceTurn`):
- 받피감 — 플레이어가 피해 받는 계산 직후 `× (1 − damageReductionPct/100)`.
- on-hit DoT — 플레이어가 그 턴 피해를 입혔으면 `Math.random()*100 < chancePct` → `applyV2DotsToTarget(enemyDots, [dot])`.
- 턴 자가회복 — 플레이어 페이즈 진입(DoT tick 직후) `hp = min(maxHp, hp + maxHp*pct)`.

> ⚠️ `Math.random` 은 엔진 내 기존 난수 경로를 그대로 사용(시드/리플레이 일관성 유지). 새 난수 도입 금지.

## 데이터 모델 / 마이그레이션

- **새 save 필드 없음.** 시그니처 id는 그대로 `skills.v2.learned[]` 에 남고(= 그 티어 패시브 해금), derive가 `learned ∩ 현재직업군 시그니처` 의 최고 티어로 패시브를 계산.
- `parseV2SkillsState` 가 **비파괴**로 `equipped[]` 에서 시그니처 id 를 제거(슬롯 해제). idempotent.
- `equip-skill` 라우트는 시그니처 장착 거부(패시브는 장착 대상 아님).
- `learn-skill` 라우트·비용(T1 80/T2 150/T3 250/T4 400)·`requireClass`·티어 게이트 = **그대로**.
- 환급 없음. 기존 학습자는 무손실로 패시브 보유 + 슬롯 1칸 회수(순수 이득).

`V2_CLASS_PASSIVE` 데이터는 직업군(`tier1ClassOf`)별 × 티어별 수치 테이블로 신설(classes.ts 또는 신규 `v2Passives.ts`).

## UI

`V2SkillLearnView` 시그니처 섹션 → **"직업 패시브"** 섹션으로:
- 장착 토글·슬롯 카운터 제거.
- 학습=해금(비용 표기 유지). 티어별 효과 텍스트 + 현재 적용 수치 표시.
- 7속성 스킬 섹션은 그대로(여전히 장착·슬롯 사용).
- `/api/v2/me/state` 의 signatures 응답을 패시브 메타(티어/효과/학습여부)로 조정.

## PR 스택 (순차 — 타입→derive→엔진 상호의존, 병렬 청크 부적합)

- **PR-1** 데이터+타입: `V2_CLASS_PASSIVE`(6×4) + `passiveForClass(class, learned)` 헬퍼 + `PlayerCombat` 신규 필드. *additive, 무동작.* 단위테스트.
- **PR-2** derive 배선: `derivePlayerCombatV2Pure` 가 패시브 필드 채움(magicAtk %·extraAttack·critMult·accuracy 가산 + 신규필드). derive 테스트.
- **PR-3** engine 배선: 받피감·on-hit DoT(확률)·턴 자가회복 훅. 엔진 테스트.
- **PR-4** 마이그+시그니처 비장착화: `parseV2SkillsState` equipped 시그니처 제거, `equip-skill` 거부, 시그니처 액티브 발동 경로 정리.
- **PR-5** UI: 학습창 패시브 섹션 + state 라우트 메타.
- **PR-6** sim 캘리브: `sim-v2-progression`/`sim-tower` 류로 6×4 수치 튜닝 + 결과 문서화. PvE 처치턴·탑 도달층 퇴행 점검.

## 제약 (지킬 것)

- **행동불가 디버프 금지** — 기절/턴스킵 류 없음. 본 패시브 전부 DoT·스탯·확률조정 계열로 정합.
- **방어무시 30% 통일 다이얼과 무관** — 새 관통 레버 도입 안 함(검사=추가타이지 관통 아님).
- **자동단판 전투 유지** — 액티브 조작 추가 없음.
