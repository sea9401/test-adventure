# v2 직업 계파(스펙) 패시브 + 4직군 압축 + 자유 수행 재설계 — 플랜

> 작성 2026-06-04. 상태: **설계 초안(미착수)**. 전사(구 검술) 1직군을 샘플로 구체화, 나머지 3직군은
> 패턴 확장(스케치). 라이브 위에서 진행 전제. 관련: [[project-v2-job-passives]](현 패시브),
> [[project-v2-proficiency-redesign]](전직/수행), `docs/handoff-review.md`(전투 모델 — 명중/DoT 연동),
> [[project-v2-combat-sim-calibration-review]].

## 0. 한 줄 요약

세 가지를 묶는 재설계:
1. **6직군 → 4직군 압축**: 전사 / 무도가 / 마법사 / 도적. (궁술 제거, 신술→마법사, 궁수+인술→도적.)
2. **계파(스펙) 패시브**: 1차=넓은 베이스 → **2차 전직에서 계파 선택** → 계파별 패시브 풀에서 **전직마다
   1개씩 골라 해금**(PoE식). 계파 패시브는 **특정 무기 종류 착용 시에만 발동**(무기 타입 신설).
3. **자유 수행**: 직군-스탯 1:1 결합 해제. **수행(cultivation) 대상 스탯을 플레이어가 선택**(가이드 제공,
   오프스탯은 처벌 아닌 무의미). 6스탯은 유지, 직군만 4개로.

→ **직군 = 정체성(계파 패시브 + 무기)** / **스탯 = 자유 수행** 두 축이 직교. 4직군 × ~3계파 = ~12계파로
겹침↓, 옛 6직군 다양성은 (계파 + 자유수행)으로 복원.

---

## 1. 비전 (디자이너 의도)

- 직군당 ~3개 **컨셉 패시브**로 빌드 방향 유도. WoW처럼 같은 직군 안에서도 계파가 갈림.
- **4직군으로 압축**(스킬명 검술/체술 → 아키타입 전사/무도가/마법사/도적):
  - 궁술 제거. **신술(성직자) → 마법사 계파**. **궁수 + 인술 → 도적 계파**.
- 구조: **1차 = 넓은 베이스** → **2차 전직 = 계파 선택**.
- 획득: 계파당 패시브 풀 → **전직 차수마다 1개씩 선택 해금**.
- 무기 종류 추가 + 계파 패시브 = **무기 착용 게이트**(예: 방어=검+방패, 속도·출혈=레이피어).
- **자유 수행**(결정: 가이드형): 수행 스탯을 플레이어가 선택. 계파가 권장 스탯을 제시(UI), 오프스탯은
  자연히 무용(막지 않음). → 마법사+INT수행=공격마법 / 마법사+SPI수행=신성, 도적+DEX=궁수 / 도적+LUK=암살.

## 2. 현재 시스템 (사실) → 무엇이 바뀌나

| 영역 | 현재 (라이브 main) | 변경 |
|---|---|---|
| 직군 | 6직군(검·체·마·신·궁·인), 스탯 1:1 | **4직군(전사·무도가·마법사·도적)**, 스탯 결합 해제 |
| 직업 트리 | 직군별 선형 4차 | 1차=베이스 → **2차에서 계파 분기**(트리) |
| 패시브 | 직군당 1개, `V2_CLASS_PASSIVES[group][tier]` 현 차수 1개 | 베이스 + **선택 해금 계파 패시브 누적** |
| 획득 | 차수 자동 | 전직마다 **풀에서 1개 선택** |
| 무기 | 단일 `weapon` 슬롯, `concept`/tier/power/weight, **타입 없음** | `weapon.type` **신설** + 계파별 무기 |
| 발동 | 항상 ON | 계파 패시브 = **무기 타입 게이트** |
| **수행(스탯성장)** | `applyCultivation`이 **직군 앵커 스탯**으로 floor/cap/grown | **플레이어 선택 스탯**으로 수행(가이드형) |
| 전직 게이트 | 누적 숙련도 + 레벨 | **유지**(직군 숙련=전직 / 스탯 수행=수치, 분리가 더 깨끗) |
| derive | tier→단일 패시브 | 선택 패시브 합산 + 무기 게이트 통과분만 |

엔진 전투 로직은 거의 불변(이미 `passiveXxx` 필드만 읽음). 바뀌는 핵심 = **직군 4압축 + 수행 스탯선택 +
패시브 계파 구조/선택 + 무기 게이트 + 저장/마이그 + UI**.

## 3. 직군 × 계파 설계

### 3-A. 전사 (샘플 — 구 검술/STR, Codex 협의 반영) ✅ 구체화
권장 수행: STR(+방어 계파 VIT, +속도 계파 DEX).

**계파 ① 광검류 (극딜)** — 무기: 대검(greatsword)
| 패시브 | 효과 | 가안 |
|---|---|---|
| 절단의 자세 | 물리 공격력 % | atk +15~25% |
| 갑옷 가르기 | 방어 관통 | defPen +12~22% |
| 일격필살 | 치명 데미지 | critDmg +25~45% |

**계파 ② 철벽검류 (방어·반격)** — 무기: 검방(sword_shield, 단일 아이템)
| 패시브 | 효과 | 가안 |
|---|---|---|
| 방패 숙련 | 받피감 | 12~24% |
| 응수 | 피격 후 확률 반격 | counter 18~32% |
| 검면 반사 | 받은 피해 반사 | reflect 8~18% |

**계파 ③ 혈풍검류 (속도·출혈)** — 무기: 세검(rapier)
| 패시브 | 효과 | 가안 |
|---|---|---|
| 찌르기 연계 | 추가타 확률 | 12~24% |
| 개방상 | 명중 시 출혈 | 25~40%·2~4턴 |
| 빠른 검끝 | 속도 + 명중 | spd +10~18%, acc +8~15% |
⚠️ 명중은 라이브 PvE서 무의미(몹 회피 0) → PvP용. (`docs/handoff-review.md` §2)

### 3-B. 무도가 (구 체술/VIT) — 🔧 스케치
권장 수행: VIT(+LUK 등). ⚠️ 전사 방어 계파와 겹침 주의 → **무기 차별**(맨손/권갑 vs 검방) + **반격이
아닌 흡혈/기공·지속** 방향으로 색 분리. 계파안(가안): 맷집·도발 / 흡혈·기공 / 연타(combo).

### 3-C. 마법사 (구 마술+신술/INT·SPI) — 🔧 스케치
권장 수행: **공격 계파=INT / 신성 계파=SPI**(자유수행이 둘을 가름). 무기: 지팡이류(공격) vs 성물/스태프(신성).
계파안: 공격마법(소각/burn, INT) / 신성·치유(holy·heal, SPI) / 빙결·제어(INT 디버프, 가안).

### 3-D. 도적 (구 궁수+인술/DEX·LUK) — 🔧 스케치
권장 수행: **궁수 계파=DEX / 암살 계파=LUK**. 무기: 활(원거리) vs 단검(암살).
계파안: 궁수(원거리·다타, DEX) / 암살(크리·중독 poison, LUK) / 잠행(속도·회피, 가안).

> 4직군 × 3계파 = **12계파**(옛 18 대비 겹침↓). 흡수된 색(신성·궁수·암살)이 별개 직군이 아니라 **뚜렷한
> 계파**가 되어 차별 명확. 3-B~D 수치/패시브는 전사 슬라이스 검증 후 일괄 설계(§8-5).

## 4. 무기 타입 + 게이팅

- **`weapon.type` 신설(옵션 필드)**(기존 `concept` 와 별개). 전사 **계파 무기 3종**: `greatsword`(대검)/`sword_shield`(검방)/`rapier`(세검). **일반/기존 검 = type 없음(undefined)** → 어느 계파 게이트와도 매칭 안 됨 = 베이스만(별도 "장검" 타입·backfill 불필요).
- **검+방패 = 오프핸드 슬롯 없이 단일 무기 아이템 `sword_shield`**. 게이트 = `weapon.type === ...`. 슬롯 신설 X.
- 폴백: 틀린 무기면 계파 패시브 OFF + 베이스만. **UI 명시**("계파 효과 비활성: 대검 필요"), 조용한 약화 금지.
- 🔴 **auto-battler 펀치 리스크**: 반응 불가라 "장비 잘못=손해". → **각 계파 무기를 2차 전직까지 확정 획득 보장**.

## 5. 패시브 획득 모델 (PoE식 선택 해금)

| 단계 | 역할 | 패시브 |
|---|---|---|
| 1차 | 넓은 베이스(전사/무도가/마법사/도적) | 직군 베이스 패시브 1개 자동 |
| 2차 | **계파 선택** | 계파 풀에서 1개 선택 |
| 3차 | 심화 | 같은 계파에서 1개 추가 |
| 4차 | 완성 | 같은 계파에서 1개 추가 |

- **선택 패시브는 레벨 리셋(전직 prestige) 후에도 유지.**
- **결정: 계파당 패시브 = 3개 고정 키트, 전직마다 1개씩 해금(순서는 플레이어 선택).** 4~5개로 늘리지 않음 —
  계파는 단일 컨셉이라 패시브가 다 같은 방향(트레이드오프 X, 다 갖고 싶음) → "선택용 4~5개"는 필러가 됨.
  현실적으로 3개×12계파=36개도 겹침 없이 뽑기 빠듯. **진짜 빌드 분기 = 계파 선택(12) + 자유수행 + 장비**,
  계파 안은 응집 키트. 해금 순서가 소소한 agency(초반 파워 스파이크 위치).
- (옵션, 나중에) 더 변별 원하면 **마지막 1픽만 2지선다 캡스톤**으로 가볍게. 지금은 채택 X.

## 6. 아키텍처 변경 범위

1. **직군 4압축** `classes.ts`: 6→4 직군, 2차부터 계파 분기(선형→트리). 옛 직군(검/체/마/신/궁/인) 매핑/마이그.
2. **수행 자유화** [[project-v2-proficiency-redesign]] 코어: `applyCultivation`/`V2_CULTIVATE_PROFILE`이 직군 앵커
   대신 **플레이어 선택 스탯**으로 floor/cap/grown 굴림. 전직 게이트(누적 숙련)는 분리 유지.
3. **패시브 데이터** `v2Passives`: `직군 → 계파 → passive[]`(named, 단일책임) + 베이스 패시브 분리.
4. **저장** `specChoice`(계파) + `unlockedPassives`(선택 ids) + `cultivationTargets`(선택 스탯). 레벨과 분리.
5. **derive** 선택·해금 패시브 + 무기 게이트 통과분만 필드 합산.
6. **무기** `weapon.type` 옵션 필드 + 계파 무기 아이템 신설. 일반/기존 무기는 type 없음(backfill 불필요).
7. **UI** 계파 선택·패시브 픽 + **수행 스탯 선택(권장 가이드)** + 무기 게이트 표기 + 전투로그 피드백(§7).
8. **마이그** 옛 6직군 캐릭 → 4직군 매핑(신술→마법사·신성계파, 궁수/인술→도적) + 리스펙 토큰. 수행 스탯=현 스탯 보존.

## 8. 미결 결정 (빌드 전 확정)

**확정됨:** 직군 4압축(전사/무도가/마법사/도적) · 수행 = 가이드형 자유(2번) · 계파 = 무기 게이트 ·
**계파당 패시브 3개 고정 키트(전직마다 1해금, 순서 선택)** — 4~5개 padding 기각 ·
**리스펙 = 테스트 기간 신전 초기화로 전부 무료(계파/수행/패시브 순서 다), 정식 때 유료화**(가격 TBD) ·
**틀린 무기 폴백 = 완전 비활성 + 계파 무기 2차전직까지 지급 보장** · **1차 = 4직군 택1**(4직군 자체가 1차, 무직은 생성 직전 상태).

남은 것 (전사 슬라이스/각 단계서 자연 확정 가능):
1. **전투 피드백 최소선** — 로그 어디까지(반격/출혈/반사/추가타). UI 범위 좌우.
2. **무도가/마법사/도적 계파 확정** — 12계파 겹침 분배(무기·권장스탯·색). 전사 슬라이스 검증 후.
3. **전투 모델 의존** — DoT/명중 패시브는 `docs/handoff-review.md`(flat-base 명중·비율 데미지)와 연동. 그쪽 먼저/같이.

## 9. 단계별 빌드 플랜 (청크)

- **P0 설계 확정** — §8 잔여 결정 + 전사 수치 락 + 무도가/마법사/도적 계파 표.
- **P1 무기 타입** — `weapon.type` 옵션 필드 + 전사 계파 무기 3종(대검/검방/세검) + 게이트 헬퍼(데이터/순수함수, 단독 머지).
- **P2 수행 자유화** — 수행 대상 스탯 선택(가이드) + proficiency 코어 변경 + 저장. sim 검증.
- **P3 패시브 데이터+derive** — 계파 구조 + 선택/해금 저장 + derive 집계 + 무기 게이트. sim.
- **P4 직군 4압축 + 전직/계파 플로우** — classes 트리 + 2차 계파 선택 + 차수 픽 + 6→4 마이그(리스펙 토큰).
- **P5 UI** — 계파/픽/수행선택 화면 + 게이트 표기 + 전투로그 피드백.
- **P6 검증·확장** — 전사 sim 밸런스 → 무도가/마법사/도적 동일 패턴 전개.

전사만 P1~P3 수직 슬라이스로 먼저 증명 → 패턴 굳으면 3직군 확장.
