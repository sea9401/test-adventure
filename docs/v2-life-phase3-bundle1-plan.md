# 3차 생활 확장안 — 첫 묶음 상세 계획

> 기록일: 2026-08-06
> 상태: 첫 묶음 구현 및 검증 완료(미배포)
> 구성: 지역별 생활 환경 + 대형 생활 발견 + 생태·자원 기록도감

## 1. 목표

기존 낚시·벌목·채광을 그대로 반복하는 중에도 다음 세 가지가 자연스럽게 이어지게 한다.

1. 필요한 생활 지역에 오늘은 어떤 특성이 적용되는지 확인한다.
2. 활동 중 특별한 발견을 만나고 조사한다.
3. 발견한 장소·환경·사건이 기록도감에 남는다.

핵심 순환은 다음과 같다.

`오늘의 생활 환경 확인 → 필요한 지역에서 생활 진행 → 대형 발견 조사 → 기록도감 등록 → 칭호·업적 보상`

벌목·채광은 지역마다 주 재료가 다르므로 환경만 보고 자유롭게 지역을 고르는 구조가 아니다. 이번 묶음의 목표는 `오늘 가장 좋은 지역을 고르는 것`보다 `필요한 지역에 매일 다른 특성이 생기는 것`으로 정의한다.

## 2. 이번 묶음의 범위

### 우선 적용

- 낚시터 6곳
- 벌목지 6곳
- 채광지 6곳

세 콘텐츠 모두 이미 지역이 나뉘어 있어 같은 규칙으로 연결하기 쉽다.

### 후속 적용

- 농사는 지역 선택 구조가 없으므로 첫 묶음 안정화 후 `오늘의 작황 + 특수 작물 발견` 형태로 별도 확장한다.
- 요리와 생활 제작의 특별 결과는 이후 `제작 연구 노트`와 함께 다룬다.

### 제외

- 숙소와 가구 제작·배치·가구 효과
- 생활 의뢰 게시판의 추가 확장
- 전투 날씨와 전투 능력치 보정
- 새로운 생활 전용 화폐
- 숨겨진 도안 직접 지급

## 3. 지역별 생활 환경

### 기본 규칙

- 매일 00:00 KST에 각 생활 지역의 환경이 변경된다.
- 활동별 3종 환경이 6개 지역에 정확히 2곳씩 배정된다.
- 같은 지역에 같은 환경만 반복되지 않도록 순환 가방 방식으로 배정한다.
- 환경은 전부 보너스이며 실패율 증가나 획득량 감소 같은 페널티는 두지 않는다.
- 서버와 화면이 동일하게 계산할 수 있는 날짜 기반 결정론적 방식으로 구성한다.
- 환경 ID·효과·서버 현재 시각·종료 시각은 서버가 내려주며, 화면은 기기 시각으로 결과를 결정하지 않고 남은 시간만 표시한다.
- 환경 때문에 자동 벌목·채광이 중단되거나 추가 조작을 요구하지 않는다.

### 낚시 환경

| 환경 | 제안 효과 | 역할 |
|---|---:|---|
| 활발한 어군 | 희귀 이상 티어 가중치 상대값 +8% | 어종 수집 |
| 잔잔한 수면 | 8% 확률로 낚시 경험치 +2 | 숙련 성장 |
| 왕성한 먹이 활동 | 입질 대기시간 -5% | 빠른 진행 |

기존 `물때`와의 구분:

- 물때는 2시간마다 바뀌며 특별 어종과 시간대 효과를 담당한다.
- 지역 생활 환경은 하루 동안 유지되며 낚시터 선택을 담당한다.
- 희귀 이상 티어 가중치 +8%는 물때·미끼·진행도 보정을 먼저 적용한 희귀·영웅·전설의 최종 가중치를 각각 1.08배로 계산하며 8%p를 더하지 않는다.
- 두 효과가 동시에 적용되더라도 낚시 코인, 지도 조각, 이벤트 보스 확률은 추가로 올리지 않는다.
- 환경은 최대어 크기에 영향을 주지 않아 주간 기록 경쟁의 필수 조건이 되지 않게 한다.

### 벌목 환경

| 환경 | 제안 효과 | 역할 |
|---|---:|---|
| 울창한 성장 | 주 목재 추가 획득 확률 5% | 재료 수급 |
| 맑은 작업로 | 작업 시간 -5% | 빠른 진행 |
| 선명한 나이테 | 벌목 경험치 +8% | 숙련 성장 |

### 채광 환경

| 환경 | 제안 효과 | 역할 |
|---|---:|---|
| 드러난 광맥 | 주 광석 추가 획득 확률 5% | 재료 수급 |
| 안정된 암반 | 작업 시간 -5% | 빠른 진행 |
| 결정의 울림 | 부산물 획득 확률 상대값 +10% | 부산물 탐색 |

### 노출 위치

- 월드 생활 지도: 각 지역에 오늘의 환경 배지 표시
- 낚시·벌목·채광 화면: 선택 지역 이름 아래 효과와 남은 시간 표시
- 지역 선택 목록: 환경 효과별 필터 및 정렬 제공
- 20:00 KST 이후에는 다음 날 환경을 함께 예고

### 적용 시점과 시간 감소 상한

- 낚시는 캐스팅 시작 시점, 수동 벌목·채광은 작업 시작 시점의 환경을 결과까지 고정한다.
- 자동 벌목·채광은 자동 세션 시작 시 환경을 고정하며, 자정이 지나도 해당 세션이 끝날 때까지 바꾸지 않는다.
- 낚시의 최종 입질 대기시간 감소는 현재 상한인 50%와 최소 대기 1.8초를 유지한다.
- 벌목·채광은 레벨·패시브·도구·환경을 모두 적용한 최종 시간 감소 상한을 60%, 최소 작업 시간을 1초로 둔다.
- 환경 효과를 추가하면서 기존 레벨·패시브·도구 효과를 하향하지 않는다.

### 환경 보너스 계산 순서

- 잔잔한 수면은 성공한 어획마다 8% 확률로 낚시 경험치 2를 추가하며, 길드 식사 보너스와 별도로 계산한다.
- 낚시 희귀 이상 가중치 +8%는 기존 티어 가중 보정을 먼저 적용한 뒤 별도 1.08배로 계산한다.
- 벌목 주 목재와 채광 주 광석 추가 획득 5%는 기존 보너스에 합산하지 않고 독립 확률로 한 번 판정한다.
- 채광 부산물은 `기본 확률 × 생활 보조품 배율 × 환경 1.10` 순서로 계산하고 최종 확률은 100%를 넘지 않는다.

## 4. 대형 생활 발견

### 발견 목록

| 분야 | 일반 발견 | 희귀 발견 |
|---|---|---|
| 낚시 | 이동하는 대어 떼, 떠내려온 유실물 | 수면 아래 거대한 그림자 |
| 벌목 | 송진이 맺힌 수동, 오래된 나무 구멍 | 세월을 품은 고목 |
| 채광 | 숨겨진 광맥, 결정 동공 | 고대 생물의 화석층 |

명칭은 실제 구현 전 세계관 문체에 맞춰 최종 조정한다.

### 발생 방식

- 정상적으로 완료된 생활 활동에서만 발견 판정을 한다.
- 첫 적용 기준 확률:
  - 낚시: 성공한 챔질당 0.15%
  - 벌목: 나무 한 그루 작업 완료당 0.08%
  - 채광: 광맥 하나 작업 완료당 0.08%
- 해당 지역의 생활 환경과 어울리는 발견은 확률이 최대 1.5배가 된다.
- 한 분야에서 하루 최대 1개의 발견만 얻을 수 있다.
- 하루에 발견 판정을 받을 수 있는 정상 완료 횟수를 다음과 같이 제한한다.
  - 낚시: 성공한 챔질 100회
  - 벌목: 완료한 나무 80그루
  - 채광: 완료한 광맥 80개
- 일일 판정 횟수를 모두 사용하면 추가 활동은 보상과 숙련도를 정상 지급하되, 그날의 발견 판정과 천장 진행은 더 올리지 않는다.
- 분야별 천장은 활동 속도 차이를 반영해 따로 둔다.
  - 낚시: 400회부터 확률이 점진적으로 오르고 800회째에 확정
  - 벌목: 500회부터 확률이 점진적으로 오르고 1,000회째에 확정
  - 채광: 500회부터 확률이 점진적으로 오르고 1,000회째에 확정
- 소프트 천장 구간에서는 현재 미발견 횟수에 따라 기본 확률이 선형으로 증가하며, 확정 직전에는 기본 확률의 최대 3배까지만 오른다.
- 이미 해당 분야의 발견 흔적을 가지고 있거나 그날 발견을 완료한 경우, 판정 횟수와 천장 진행을 소비하지 않고 일시 정지한다.
- 희귀 발견은 전체 발견 중 약 5%를 목표로 하며, 라이브 이용량을 보고 조정한다.

목표 체감은 생활 콘텐츠를 꾸준히 이용하는 이용자가 세 분야를 합쳐 일주일에 약 2~4번 발견을 만나는 수준이다.

### 조사 방식

1. 발견 시 즉시 보상을 지급하지 않고 `발견 흔적`을 기록한다.
2. 발견 흔적은 만료되지 않으며 이용자가 조사하거나 직접 포기할 때까지 보관된다.
3. 발견된 지역에서 정상 생활 활동을 3회 완료하면 조사가 끝난다.
4. 조사 완료 시 재료 보상과 기록도감 항목을 획득한다.

발견은 접속 중인 작업을 강제로 멈추지 않는다.

- 수동 활동: 결과 화면에서 발견 사실을 알리고 바로 조사하거나 나중에 진행할 수 있다.
- 자동 벌목·채광: 자동 작업을 끝까지 진행한 뒤 정산 화면에 발견 흔적을 표시한다. 한 번의 정산에 성공 횟수가 많더라도 남아 있는 일일 판정 횟수까지만 발견 판정에 사용한다.
- 발견이 발생한 자동 정산의 남은 성공 횟수로 조사를 즉시 진행하지 않는다. 이용자가 발견 결과를 확인한 이후 시작한 다음 수동 작업 또는 다음 자동 세션부터 조사 횟수를 센다.
- 조사 진행에는 발견 지역에서 성공한 작업만 반영하며, 환경이 바뀌어도 같은 지역이면 진행할 수 있다.
- 이미 발견 흔적을 보유한 상태에서는 새 흔적을 덮어쓰지 않는다.
- 원하지 않는 흔적은 직접 포기할 수 있으며 포기해도 이미 초기화된 미발견 천장은 되돌리지 않는다.

### 보상 원칙

- 일반 발견: 해당 지역 주 재료 2~4회분, 소량의 생활 경험치, 기록도감 등록
- 희귀 발견: 기존에 존재하는 희귀 생활 재료, 소량의 생활 경험치, 기록도감 희귀 항목
- 새로운 외형 재료나 조각 재료는 추가하지 않는다.
- 숨겨진 도안과 도안 단서는 지급하지 않으며 기존 숨겨진 도안 획득 구조를 유지한다.
- 전투 장비와 전투 능력치는 지급하지 않는다.

### 전광판

- 일반 발견은 개인 결과 화면에만 표시한다.
- 희귀 발견 조사 완료만 전광판에 표시한다.
- 같은 종류의 희귀 발견은 서버 전체에서 10분에 한 번만 노출하여 전광판 도배를 막는다.

## 5. 생태·자원 기록도감

### 기존 도감과의 구분

- 기존 아이템 도감: 아이템을 보유하거나 등록했는지 기록
- 생태·자원 기록도감: 어느 장소에서 어떤 환경과 사건을 관찰했는지 기록

아이템을 소비해 등록하지 않으며, 조건을 처음 충족한 순간 서버가 자동으로 기록한다.

### 도감 구성

#### 지역 기록 18개

- 낚시터 6곳
- 벌목지 6곳
- 채광지 6곳

각 지역에서 생활 활동을 한 번 정상 완료하면 등록한다.

#### 환경 기록 9개

- 낚시 환경 3종
- 벌목 환경 3종
- 채광 환경 3종

해당 환경이 적용된 지역에서 생활 활동을 정상 완료하면 등록한다.

#### 발견 기록 9개

- 낚시 발견 3종
- 벌목 발견 3종
- 채광 발견 3종

발견 흔적의 조사를 완료하면 등록한다.

초기 도감은 총 36개 항목으로 시작한다. 이 중 일반 항목 33개를 기본 완성도로 계산하고 희귀 발견 3개는 장기 도전 항목으로 분리한다. 이후 농사·요리·제작이 확장될 때 별도 장을 추가한다.

- 일반 발견이 발생했을 때 해당 분야에 아직 등록하지 않은 일반 발견은 이미 등록한 발견보다 2배 높은 가중치를 받는다.
- 희귀 발견은 이 미등록 보정에 포함하지 않아 장기 희소성을 유지한다.

### 반복 관찰

- 도감 완성도는 최초 발견만 계산한다.
- 같은 항목을 1회·3회·10회 관찰하면 항목에 동·은·금 기록 표식을 붙인다.
- 반복 관찰은 표식만 제공하고 업적 점수나 재료를 반복 지급하지 않는다.

### 완성도 표시

- 기본 기록은 `33/33 · 100%`처럼 별도 표시한다.
- 희귀 기록은 `0/3`처럼 기본 완성도와 분리한다.
- 전체 36개 수집 현황은 추가 정보로만 표시하고 기본 진행률의 분모로 사용하지 않는다.

### 미등록 안내

- 미등록 항목은 이름을 숨기더라도 발견 장소와 조건에 대한 짧은 힌트를 제공한다.
- 낚시터·벌목지·채광지 목록에 `이 지역의 미등록 기록 존재` 배지를 표시한다.
- 배지를 누르면 해당 도감 항목과 발견 힌트로 바로 이동한다.
- 아직 등장할 수 없는 환경이라면 다음 등장 예정일을 표시한다.

### 마일스톤 보상안

| 달성 조건 | 보상 후보 |
|---|---|
| 5개 등록 | 업적 점수 5 + 브론즈 업적 배지 |
| 15개 등록 | 업적 점수 10 + 칭호 `현장 기록가` + 실버 업적 배지 |
| 30개 등록 | 업적 점수 20 + 골드 업적 배지 |
| 일반 33개 전체 등록 | 업적 점수 30 + 칭호 `생태 조사관` + 전설 업적 배지 |
| 36개 전체 등록 | 히든 칭호 `대지의 목격자` |

전투 능력치와 영구 수급량 증가는 보상에서 제외한다.

업적 점수와 배지·칭호는 각 마일스톤을 처음 달성했을 때 한 번만 지급한다.

여기서 업적 배지는 기존 프로필 업적 전시대에 장착하는 배지를 뜻한다. 게시판 작성자 옆의 활동 레벨 배지와 채팅 꾸미기 배지는 변경하거나 새로 추가하지 않는다.

### 기존 이용자 처리

- 과거 기록만으로는 이용자가 활동한 낚시터를 정확히 복원할 수 없으므로 지역 기록을 소급 등록하지 않는다.
- 벌목·채광만 소급하고 낚시만 다시 진행하게 하는 불일치도 만들지 않는다.
- 지역·환경·발견 기록은 기능 공개 이후 정상 완료한 활동부터 모든 이용자에게 같은 기준으로 등록한다.
- 기존 숙련도, 재료, 낚시 도감, 벌목·채광 누적 기록은 변경하지 않는다.

## 6. 밸런스 안전장치

- 환경으로 늘어나는 장기 평균 재료 획득량은 활동별 5% 안팎을 목표로 한다.
- 발견 보상을 포함해도 전체 생활 재료 공급 증가량이 10%를 넘지 않게 조정한다.
- 자동 활동은 발견 때문에 멈추지 않으며, 수동과 자동은 같은 정상 완료 1회에 같은 확률을 적용한다.
- 수동·자동이 함께 공유하는 일일 판정 횟수 상한으로 자동 작업의 대량 판정 독점을 막는다.
- 발견 일일 상한, 일일 판정 횟수, 분야별 보유 흔적 1개 제한으로 과도한 반복 이득을 막는다.
- 낚시 최대어 크기에는 환경 보정을 적용하지 않는다.
- 시간 감소는 낚시 50%, 벌목·채광 60%의 최종 상한을 넘지 않는다.
- 발견 보상에서 숨겨진 도안과 단서를 제외하여 기존 도안의 희소성을 유지한다.
- 환경 효과·발견 확률·보상량은 데이터 값으로 분리해 배포 없이 운영 설정으로 조정할 수 있게 설계한다.

## 7. 저장·동시성 원칙

- 발견 상태, KST 일일 판정 횟수, 미발견 천장, 조사 진행, 도감 기록을 하나의 생활 기록 상태로 관리한다.
- 수동 성공 처리와 자동 정산은 기존 생활 세이브를 잠근 뒤 생활 기록 상태를 같은 트랜잭션 안에서 잠근다.
- 발견 보상, 도감 등록, 업적·칭호 지급까지 같은 트랜잭션에서 완료한다.
- 수동 작업 세션 ID와 자동 작업 세션 ID를 최근 처리 기록에 남겨 같은 요청의 재시도·새로고침이 판정량이나 보상을 중복 지급하지 못하게 한다.
- 자동 세션은 시작 시점의 KST 날짜 키와 환경 ID를 저장한다. 환경과 일일 발견 판정량은 이 시작 날짜를 기준으로 처리하고, 발견 흔적의 획득 시각만 실제 정산 시각으로 기록한다.
- 이미 처리한 세션 ID는 성공 응답을 재구성하거나 중복 처리 없이 종료한다.

잠금 순서는 기존 수동·자동 생활 라우트의 순서를 유지하며, 새 생활 기록 상태를 임의로 먼저 잠가 교착 상태를 만들지 않는다.

## 8. 화면 구성

### 월드 생활 지도

- 지역 카드에 환경 아이콘, 효과, 남은 시간을 한 줄로 표시
- `재료 / 숙련 / 빠른 작업 / 미등록 기록` 기준 빠른 필터 제공
- 미등록 기록이 있는 지역을 가장 먼저 강조할 수 있는 버튼 제공

### 생활 활동 화면

- 현재 지역 제목과 같은 줄에 환경 배지 표시
- 배지를 누르면 효과와 발견 가능한 기록을 펼쳐 표시
- 발견 흔적이 있으면 상단에 작은 조사 진행 카드 표시
- 분야별 `오늘의 발견 판정 32/80` 진행도와 천장 진행 상태를 표시하고, 흔적 보유 중에는 `발견 판정 정지 중`이라고 안내
- 모바일에서도 지역명과 배지가 작성자명이나 주요 버튼을 밀어내지 않도록 줄바꿈 영역을 분리

### 모험의 서

- `생활 기록` 장을 추가하고 `지역 / 환경 / 발견` 세 탭으로 구분
- 기본 기록 33개와 희귀 기록 3개의 완성도를 분리해 표시
- 각 항목에서 관련 생활 지역으로 바로 이동 가능
- 기존 모험의 서 도움말 확인 기록을 초기화하거나 새 탭 진입 때 도움말을 다시 띄우지 않는다.

## 9. 구현 순서

### 1단계 — 생활 환경 코어와 벌목 시범 적용

- 날짜 기반 환경 배정 데이터와 순환 규칙
- 벌목 서버 보정과 환경 시작 시점 고정
- 월드 생활 지도 및 벌목 화면 배지
- 다음 날 예고

### 2단계 — 채광 적용

- 벌목과 같은 규칙으로 채광 환경 적용
- 재료 공급량과 시간 감소 중첩 검증

### 3단계 — 낚시 적용

- 기존 물때와 별도 축으로 낚시 환경 적용
- 낚시 최대어 크기·코인·지도 조각·이벤트 보스 확률 무보정 검증
- 기존 50% 대기시간 감소 상한 유지

### 4단계 — 대형 생활 발견

- 분야별 발견 카탈로그
- 발견 판정, 일일 판정 횟수, 일일 상한, 분야별 천장, 무기한 보관
- 수동·자동 활동의 동일한 발견 처리
- 자동 정산의 발견과 후속 조사를 서로 다른 세션으로 분리
- 조사 진행과 보상
- 희귀 발견 전광판

### 5단계 — 기록도감

- 지역·환경·발견 자동 기록
- 미등록 배지와 바로가기
- 반복 관찰 표식
- 일반 33개 기본 완성과 희귀 3개 장기 도전 분리
- 마일스톤 업적·칭호·기존 프로필 업적 배지

### 6단계 — 안정화 후 농사 확장

- 오늘의 작황
- 황금 작물·돌연변이 작물 발견
- 농사 기록도감 장 추가

### 7단계 — 운영 안전장치

- 생활 환경 효과 개별 비활성화
- 발견 판정 개별 비활성화
- 발견 보상 개별 비활성화
- 희귀 발견 전광판 개별 비활성화
- 도감 마일스톤 지급 개별 비활성화

각 기능은 서로 독립적으로 끌 수 있게 하여 문제가 생겨도 생활 콘텐츠 전체를 중단하지 않게 한다.

## 10. 검증 기준

### 기능 검증

- 서버와 화면에서 같은 날짜·지역의 환경이 일치한다.
- KST 자정 경계에서 환경이 정확히 변경된다.
- 물때와 생활 환경이 서로의 확률을 잘못 덮어쓰지 않는다.
- 자정이 지나도 시작한 수동·자동 작업에는 시작 시점 환경이 끝까지 유지된다.
- 환경을 포함한 시간 감소가 낚시 50%, 벌목·채광 60% 상한을 넘지 않는다.
- 자동 벌목·채광 도중 발견이 발생해도 작업이 중단되지 않는다.
- 한 번의 자동 정산이 일일 발견 판정 횟수를 초과해 소비하지 않는다.
- 발견이 발생한 자동 정산의 남은 성공 횟수로 조사가 즉시 완료되지 않는다.
- 발견 흔적 보유 중에는 판정 횟수와 천장 진행이 정지한다.
- 자동 세션이 자정을 지나거나 며칠 뒤 정산되어도 시작일의 환경과 일일 판정량을 사용한다.
- 중복 요청과 새로고침으로 발견·보상이 두 번 지급되지 않는다.
- 도감 항목과 업적 보상이 중복 등록되지 않는다.
- 서버 시각과 기기 시각이 달라도 화면의 환경과 서버 보정이 일치한다.
- 기존 모험의 서 도움말을 확인한 이용자에게 새 생활 기록 탭 때문에 도움말이 다시 나타나지 않는다.

### 운영 지표

- 환경별 지역 선택률
- 활동별 평균 재료 공급량 변화
- 수동·자동 활동의 발견 횟수 차이
- 분야별 일일 발견 판정 횟수 소진율
- 분야별 천장 도달 이용자 비율
- 이용자당 주간 발견 횟수
- 희귀 발견 및 전광판 노출 빈도
- 기록도감 15개·30개·전체 완성까지 걸리는 기간

### 1차 목표치

- 생활 재료 공급 증가: 활동별 평균 +5% 안팎
- 주간 발견 체감: 꾸준한 이용자 기준 세 분야 합계 2~4회
- 세 분야의 일일 판정 횟수를 모두 사용하고 유리한 환경을 골라도 기대 발견량이 주 4회 안팎을 넘지 않는 값을 시작점으로 삼음
- 일반 기록 33개 완성: 일반 이용 기준 약 4~8주
- 희귀 기록을 포함한 36개 완성: 장기 목표로 두고 완료 시점을 인위적으로 보장하지 않음
- 숨겨진 도안 획득률: 기존 희소성을 훼손하지 않는 수준 유지

## 11. 구현 전 기준값

문제 가능성을 줄이기 위해 다음 값을 첫 구현 기준으로 사용한다. 라이브 지표가 기준 범위를 벗어날 때만 운영 설정으로 조정한다.

1. 환경 효과 수치: 낚시 희귀 이상 가중치 상대값 +8%·경험치 +8%·대기 -5%, 벌목·채광은 본문의 제안값
2. 발견 흔적 보관 시간: 만료 없음, 직접 조사 또는 포기
3. 조사 요구량: 같은 지역 생활 활동 3회
4. 분야별 일일 발견 상한: 1개
5. 기본 발견 확률: 낚시 0.15%, 벌목·채광 각 0.08%
6. 일일 판정 횟수: 낚시 100회, 벌목·채광 각 80회
7. 미발견 천장: 낚시 800회, 벌목·채광 각 1,000회
8. 소프트 천장 시작: 낚시 400회, 벌목·채광 각 500회, 확정 직전 최대 기본 확률의 3배
9. 시간 감소 최종 상한: 낚시 50%, 벌목·채광 60%
10. 일반 기본 완성: 33개, 희귀 장기 도전: 3개
11. 희귀 발견 비중: 전체 발견의 약 5%
12. 다음 날 환경 예고 시작 시각: 20:00 KST
13. 기록 소급 적용: 없음, 기능 공개 이후 정상 완료부터 기록
14. 업적 배지: 기존 프로필 업적 전시 배지 사용, 게시판 활동 레벨·채팅 배지와 분리
15. 운영 차단: 환경·발견 판정·발견 보상·전광판·마일스톤을 각각 독립 제어
