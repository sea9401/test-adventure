# v2 거점 공성 (성벽 HP) 설계

2026-06-08. 거점 점령을 "단판 승리 = 즉시 통째 이전"에서 **시간에 걸친 성벽 공성**으로 재설계.

## 1. 배경 / 문제

현재 점령(claim)은 한 판 오토배틀(1v1 일기토 또는 양측 2인+면 3v3 토너먼트) 승리로 소유권이
**즉시 통째 이전**된다. "전쟁"이라기엔 가볍고, 단판 분산(운 한 번)에 좌우된다. 시간에 걸친
누적 공성으로 바꿔 무게감을 준다.

이 게임의 제약: **플레이어 소수**(아레나도 봇 폐지·유저전용), 수비자는 거의 항상 **오프라인**,
**오토배틀 전용**(라이브 조작 없음). → 어떤 메커니즘이든 *사람 수비에 의존하지 않는 자동/패시브
방어층*이 핵심.

## 2. 핵심 컨셉: 성벽 HP 공성

- 길드 보유(점령된) 거점에 **성벽 HP**(`fortHp` / `fortMaxHp`).
- 점령 시도 = 한 판 오토배틀. **승리 → 성벽이 깎인다**(즉시 이전 X). `fortHp ≤ 0` 이 되는 순간
  **함락** → 소유권 이전 + 성벽 풀충전 + 보호막.
- 패배 → 성벽 무변동.
- **2층 방어**: ① 수비 전투력 게이트(2026-06-08, `outpostDefense.ts` — "위협할 자격" eligibility)
  + ② 성벽 HP("실제 함락엔 지속 공성" attrition). 둘이 자연스럽게 맞물린다.

## 3. 비동기 공정성 (소수 플레이어 핵심)

- **성벽 자동 재생** — 시간당 `FORT_REGEN_PER_HOUR` 회복(상한 `fortMaxHp`). 잠수 소유주의 패시브
  방어. 공격을 멈추면 성벽이 도로 차오르므로 *지속 압박*이 있어야 함락.
- **금고 자동 수리**(PR-2) — 거점 treasury(누적 NPC 세금) 골드를 자동 소비해 성벽을 추가 보강
  (일일 상한). 수입 = 방어로 직결되고, **골드 sink** 역할. 잠수 길드도 공짜 헌납이 아님.
- → 수비자가 오프라인이어도 "서 있는 성벽 + 재생 + 금고"가 버틴다. 사람 수비는 가속제일 뿐.

## 4. 신규 상태 (DB)

`outpost_occupations` 행에 컬럼 추가:

| 컬럼 | 용도 |
|---|---|
| `fortHp` INTEGER | 현재 성벽(lazy 재생으로 갱신) |
| `fortMaxHp` INTEGER | 성벽 상한 (MVP 플랫 100; 추후 tier/수비전투력 비례 다이얼) |
| `fortUpdatedAt` TIMESTAMP | 재생 계산 기준 시각 |
| `protectedUntil` TIMESTAMP | 함락 직후 재공성 금지(핑퐁 방지) |
| `repairSpentToday` INTEGER + `repairResetAt` TIMESTAMP | 금고 수리 일일 상한 추적 (PR-2) |

마이그레이션: 기존 점령 행 → `fortHp = fortMaxHp = FORT_MAX_HP`, `fortUpdatedAt = now`,
`protectedUntil = now`(즉시 공성 가능).

## 5. 다이얼 (초기값 — 라이브 실측 후 캘리브)

| 다이얼 | 값 | 의미 |
|---|---|---|
| `FORT_MAX_HP` | 100 | 성벽 상한 |
| `SIEGE_DAMAGE_PER_WIN` | 20 | 승리 1회당 성벽 데미지 → **≈ 5승 함락** |
| `FORT_REGEN_PER_HOUR` | 5 | 하루 120 회복 ≈ 6승분 → 하루 ~6승 이상 꽂아야 순증 |
| `POST_CAPTURE_PROTECT_HOURS` | 18 | 함락 후 재공성 금지 |
| `REPAIR_GOLD_PER_HP` / `REPAIR_HP_CAP_PER_DAY` | TBD | 금고 수리 환율·일일 상한 (PR-2) |

## 6. 재생 / 수리 계산 (lazy — 별도 크론 불요)

- 점령 행을 읽거나 공성 타격 시: `elapsedH = (now − fortUpdatedAt)/h`;
  `fortHp = min(fortMaxHp, fortHp + FORT_REGEN_PER_HOUR × elapsedH)`; `fortUpdatedAt = now`.
- 금고 자동 수리(PR-2): 공성 타격 처리 직전, 일일 상한 내에서 treasury 골드로 추가 회복.
  (lazy-on-attack — 공격받는 그 순간에만 수리되면 충분. 또는 기존 npc-attacks 크론 틱에서.)

## 7. 점령 라우트 변경 (`/api/v2/outpost/claim`)

현 흐름: 게이트들 → 전투 → `won` → 소유권 이전.

변경 (점령된 거점 = guild-held, 보호막 아님):
1. 수비 전투력 게이트 통과(현행 유지).
2. 보호막 중이면 `protected` 에러(공성 불가).
3. 성벽 lazy 재생 적용.
4. 전투(1v1/3v3) 실행 — 리플레이 포함(2026-06-08 머지).
5. **승리** → `fortHp -= SIEGE_DAMAGE_PER_WIN`.
   - `fortHp ≤ 0` → **함락**: 소유권 이전 + `fortHp = fortMaxHp` + `protectedUntil = now + PROTECT_HOURS`.
   - `fortHp > 0` → 점령 유지, 성벽만 감소(공성 진행). 응답에 `fortHp/fortMaxHp/captured:false`.
6. **패배** → 성벽 무변동. 응답에 현재 성벽.
- **비점령(NPC) 거점**: 현행 **단판 유지**(성벽 없음) — 빈 땅 초기 점령은 스냅하게. 점령 성공 시
  새 점령 행 `fortHp = fortMaxHp`로 초기화 + 보호막.
- 스태미나: 공성 타격마다 소모(현행). 승/패 무관 소모(전투 실행됨).

## 8. UI (`OutpostView` / `ClaimResultCard`)

- 거점 화면: **성벽 HP 바**(`fortHp/fortMaxHp`) + 재생률 + 보호막 타이머(남은 시간).
- 버튼: 점령된 거점이면 "**공성**"(현 "점령 시도"), 보호막 중이면 비활성 + 안내.
- 결과 카드: "성벽 −20, 남은 성벽 60/100" 또는 "**함락!**". 전투 리플레이 그대로.
- 기존 수비 전투력 / 내 전투력 표시 유지.

## 9. 엣지케이스

- **동시 공성(여러 길드)**: claim 라우트가 점령 행을 `FOR UPDATE` 락 → lazy 재생 후 데미지 적용이
  순차 직렬화돼 안전(read-modify-write).
- **함락 즉시**: `fortHp = max`, `protectedUntil = now + PROTECT_HOURS`, 새 소유주. 곧장 재탈환 불가.
- **공격 중단**: 재생으로 성벽 회복 → 다시 처음부터.
- **보호막 중 hunt/eject**: 영향 없음(공성 경로만 차단).
- **마이그**: 기존 점령 행은 풀성벽·보호막 없음(즉시 공성 가능).

## 10. 단계별 구현

- **PR-1 (핵심)**: 상태 컬럼 + drizzle 마이그 + 라우트("승리 → 성벽 깎기" / 함락 조건 / 보호막) +
  lazy 재생 + UI(성벽 바·"공성" 버튼·결과). 금고 수리 제외(재생만으로 동작).
- **PR-2**: 금고 자동 수리(골드 sink) + 일일 상한.
- **PR-3**: 라이브 실측 후 다이얼 캘리브. 선택: NPC 수비대 자동 방어 / 선포 알림(드라마)
  / tier·수비전투력 비례 `fortMaxHp`.

## 11. 결정 요약 (사용자 승인 2026-06-08)

- 컨셉 **B(성벽 HP 공성)**.
- 수리 = **금고 자동 수리**(+ 패시브 재생).
- 비점령 NPC 거점 = **단판 유지**(공성은 길드 간 뺏기에만).
- 다이얼: 함락 ≈ 5승 / 재생 시간당 +5 / 보호막 18h.
