# v2 리워크 — 큰 그림

## 배경

라이브 게임은 1막 본토부터 6막 별빛까지 권역 이동식 진행으로 만들어졌다. 엔드 컨텐츠로 길드 영지전을 얹어보려 했더니 기존 구조와 자연스럽게 안 묶인다. 권역 이동 흐름이 만렙에서 끊기고, 엔드 컨텐츠가 따로 떠 있는 느낌.

대신 처음부터 **엔드 = 길드 영지 점령전** 을 중심에 놓고 그 앞 단계를 거기 향해 자연스럽게 흐르게 만드는 v2 를 새 repo `test-adventure` 에서 작업한다. 라이브는 그대로 운영, v2 준비 끝나면 라이브를 새 컨텐츠로 교체.

## 비전

### 기본 구조

- **위치 자유** — 시작점은 맵 곳곳에 흩어진 거점 (왕국·공국·마을·산채 등) 중 유저가 선택. 적대 NPC 없는 순수 출발지.
- **던전 기반 성장** — 캐릭터 성장은 어디서든 입장 가능한 던전. 층수가 난이도. 강해질수록 더 깊은 층에서 더 좋은 보상.
- **큰 자유 맵** — 거점이 너무 붙지 않게 분산. 시작 위치는 성장에 영향 없음.

### 본 게임 (성장 후)

- **길드 결성 + 병사 모집**
- **점령전** — 작은 마을·산채부터 시작해서 강해지면 공국·왕국까지. 큰 거점은 매우 강하게 설정해 진짜 도전이 되게.
- **점령 결과** — 영구 (다른 세력이 다시 뺏기 전까지 자기 소유)
- **방어** — 비동기. 점령자가 미리 배치해둔 방어 시설·병사로 자동 방어.

### 점령 후 지속 컨텐츠

- **NPC 정기 공격** — 점령한 거점이 속해 있던 왕국이 적대 관계가 되어 주기적으로 탈환 공격. 큰 거점일수록 강한 공격.
- **타 길드 영지 충돌** — 다른 길드가 같은 거점을 노릴 수 있음 (PvP).
- **유지 비용** — 병사·방어 시설 소모로 자원 sink. 영구 점령 + 유지 비용 = 옛 유저 독점 방지, 신규 유저 진입 틈 보장.

## 점령전 룰 (정해진 것)

| 항목 | 결정 |
|---|---|
| 매치 방식 | 비동기 (방어 시설 자동 방어) |
| 점령 결과 | 영구 |
| 영지 위치 | 맵에 다양한 거점 분산 (왕국·공국·마을·산채) |
| 매치 인원 | 3인 길드 기준 (기존 길드원 그대로) |

## 보존되는 라이브 시스템

스토리·맵만 새로. 다음은 라이브에서 그대로 가져온다:

- 전투 엔진 (자동 전투, AP 스킬, 스탠스 등)
- 스킬·특기 시스템
- 아이템·강화·마법부여
- 레벨 100 + 파라곤 + 룬
- 탑 (솔로)
- 거래소

라이브의 NPC·이미지·몬스터 자산은 새 맵의 던전·거점에 재배치 가능.

## 던전 구조

캐릭 성장의 주 PvE 무대. 어디서든 입장 가능한 단일 던전, 5층 구조.

| 층 | 권장 | 역할 | 보상 |
|---|---|---|---|
| 1 | 1~70렙 | 캐릭 성장 (저~중반) | 일단 없음 |
| 2 | 70~100렙 | 캐릭 성장 (후반) | 일단 없음 |
| 3 | 만렙 + α | 파밍 시작점 (엔드) | 일단 난이도만 |
| 4 | 만렙 + 중반 파라곤 | 중간 파밍 (엔드) | 일단 난이도만 |
| 5 | 만렙 + 만개 파라곤 | 최종 파밍 (엔드) | 일단 난이도만 |

### 룰

- **자유 입장** — 어느 층이든 바로 진입. 게이트 없음. 약하면 죽음.
- **단일 던전** — 여러 종류 던전 없음. 한 던전 5층.
- **몬스터** — 라이브 자산 재활용. 던전 곡선에 맞춰 스탯 재조정. 적당히 어울리게 섞어 배치.
- **드랍** — 1~2층 일단 없음. 3~5층 보상 구조도 나중. 우선 난이도 곡선만.

### 보존되지만 별 컨텐츠인 것

- **탑 (솔로 무한)** — v2 에선 별도 맵으로 나중에 셋업. v2 초기엔 던전이 PvE 의 전부.
