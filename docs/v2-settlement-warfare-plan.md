# v2 정착지 전쟁(방어/PvP) 재설계 — 약탈·정복·참여형 수비

상태: **설계 확정(2026-06-22, 유저 토론)** · 구현 미착수. 정착지 코어([[project-v2-settlement-redesign]])는
이미 LIVE — 이 문서는 그 위에 얹는 **방어/PvP 레이어**다. 옛 거점 점령 전투(**3:3 길드 토너먼트**)를
**전면 대체**한다.

---

## §0 동기

정착지(마을 건설·생산·업그레이드)는 LIVE지만 **"키운 마을을 어떻게 지키고 뺏느냐"가 미정**이었다.
현재 점령 전투 = 마스터가 짜는 **3:3 라인업 토너먼트**(`tournamentBattle.ts`) — 참여가 마스터 1인에 묶이고,
점령 시 개발된 마을이 통째로 공격자에게 넘어가 수비자는 전부 잃는다(`normalizeVillageOwner`: tier/슬롯/이름
유지한 채 소유만 이전). **투자=방어로 이어지지 않고**(수비력 게이트가 거점 tier만 봄·마을 개발도 무시),
**전리품이 전부-아니면-전무**라 긴장이 없다.

→ **약탈/정복 분리 + 참여형 수비 + 건강도 + 영주**로 재설계. 핵심 철학은 정착지와 동일한
**"돌아와 챙겨야 이득"(로그인 리듬)** — 수비 등록·건강도 회복·세금 수확이 모두 접속 이유를 만든다.

---

## §1 최종 스펙 (7줄 요약)

1. **공격 = 모드 선택**(약탈 / 정복) · 등록 불필요. **수비 = 참여형 등록 큐**(길드원 자율 등록·등록순 배치).
2. **건강도** = 전쟁 전용 HP/MP 이월%. 전투 종료 시 남은 HP/MP%가 다음 전쟁 전투 시작 상태. 일반 PvE와 별개.
   회복은 **치료소 시간누적 방문**만. 패배=건강도 ~0 → 큐 탈락.
3. **약탈**: 큐 1번 수비자 처치 → **거점 금고 50% 탈취**, 마을 유지, 진 수비자 큐 탈락.
4. **정복**: 큐 돌파 + 성벽(fortHp) **누적 공성** 완파 → 마을 **tier 1단계 강등**(최하=이관) 후 점령, **금고 그대로**.
5. **영주**: 거점당 1인 · 세금 수확권 · **6h 쿨** · 수확분 **10% 개인 / 90% 길드**.
6. **명예**: ⓐ수비 성공 ⓑ길드 골드 입금(**10만골드/명예1**) → **길드 "명예상점" 탭**(스태미나 회복약 100pt 1종, 후속 추가).
7. 제거: **3:3 토너먼트 전부** · 주변 NPC 침략(보류, 후속 다른 형식).

## §2 메커니즘 디테일

### 2.1 건강도 (war vigor)
- character.v2 신규 영속 필드: 전쟁 전투용 **HP/MP를 풀피로 리셋하지 않고 이월**.
- 전투 종료 시 남은 HP/MP를 최대치 대비 %로 저장. 다음 전쟁 전투는 그 %에서 시작.
- **회복 = 치료소만**. 시간누적(정착지 수확창과 동형 패턴) → 방문 시 누적분만큼 건강도 환원.
- 효과: 무한 공격/방어 스팸 차단(인원 우위 throttle). 이긴 수비자도 닳음.
- 🔑 구현 seam: 현재 claim 라우트는 *싸우기 전 풀피 회복 후 단판*(`hp 회복 적용 후 resolveBattle`).
  전쟁 전투에서 이 풀피를 끄고 **이월 건강도를 읽도록** 바꾸는 게 가장 큰 배선 지점.

### 2.2 참여형 수비 큐
- 신규 테이블 `outpost_defenders`(outpostId, userId, 등록순서, registeredAt). 점령 길드원만 등록.
- 공격 시 **등록 순서대로 1:1 자동 시뮬**(오프라인이어도 저장 캐릭터로 시뮬 — 기존 라인업과 동일).
- 패배(건강도 소진) → 큐에서 자동 제거. 재등록은 건강도 회복 후.

### 2.3 약탈 vs 정복 (모드 선택)
- 공격 개시 시 **약탈/정복 택일.**
- **약탈**: 큐 1번만 격파하면 성공 → **금고 50% 탈취**. 마을·나머지 큐 유지. (가볍고 반복 가능·현금 grab.)
- **정복**: 큐 전원 격파 + **성벽(fortHp) 누적 공성**(여러 차례 공격에 걸쳐 깎임·골드 수리 가능). 성벽 완파 →
  **마을 tier 1단계 강등**(대도시→도시→마을, **마을=최하면 그대로 이관**) 후 점령. **금고는 그대로**(점령자 인수).
  (무겁고 느림·영토+개발+금고 통째.)

### 2.4 영주 + 세금
- 거점당 **영주 1인**(점령 길드원). 임명 방식 = **기본값: 길드 마스터/부마스터가 지정**(추후 변경 가능).
- 세금은 거점 금고(`outpost_treasury.gold`)에 **누적**(수시 자동 회수 폐지 → 약탈 대상 형성).
- 영주만 **수확** 가능: **6h 쿨다운**, 수확분 **10% 영주 개인 골드 / 90% 길드 금고**.
- 🔑 현 모델 reconcile: #853에서 거점 세금이 길드 골드 풀로 자동 흐름 → **영주 수동 수확(6h·10%컷)으로 전환** 필요.

### 2.5 명예
- character 신규 개인 화폐 `honor`. 획득: 수비 성공(주축) + 길드 골드 입금(보조, **10만/1**).
- **길드 "명예상점" 탭**(V2GuildHome 신규 GuildSubTab). 초기 품목 = **스태미나 회복약 100pt 1종**(`stamina_potion` 재활용).
- ⚠️ sink 교훈([[project-v2-outpost-type-redesign]] stone 경제 死): 발행만 풀고 상점 방치 금지 → **상점을 발행과 같은 슬라이스에 출시**.

## §4 다이얼 & 기본값

- 약탈 금고 비율 **50%**. 영주 수확 쿨 **6h** · 개인 컷 **10%**. 입금→명예 **10만/1**. 명예상점 물약 **100pt**.
- 건강도 회복속도·치료소 환원량 = 신규 다이얼(보수적 시작). 정복 성벽 누적 속도 = 기존 `SIEGE_DAMAGE_PER_WIN` 재사용.
- 최하-tier(마을) 정복 = **추가 강등 없이 이관**(확정).

## §5 미결 / 후순위

- 주변 NPC 침략 = **비활성**(현 코드의 정확한 정체 확인 후 — 별도 형식 후속).
- 영주 임명 정밀(자율 선착 vs 지정)·건강도 수치 캘리브·명예상점 품목 확장·수비 게이트 유지 여부·전쟁 롤오버(쟁탈아레나)와의 최종 관계.
