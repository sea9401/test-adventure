# v2 고유 아이템 + 개성 옵션 (Signature Uniques) — 설계

> 베타 직전 "득템의 재미" 충전. 오너 구상(2026-06-26): ① 정체성 있는 고유 아이템이 필요 ②
> 옵션이 뻔함(슬롯=옵션 고정: 신발 속도/장갑 치명피해) → 개성 필요 ③ **잊힌 성소 구간부터**
> 별도 고유 드랍 테이블 + 특별 옵션. 개성 옵션은 **단계적**(Phase 1 변칙 조합 → Phase 2 발동형).

## 0. 현황 (코드 확인)

- **테마/깊이**(`dungeon.ts`): 들판1–6 · 마른협곡7–12 · 얼음호수13–18 · 심층동굴19–24 ·
  **잊힌성소25–30** · 리자드늪지31–36 · 짐승의소굴37–42. `MAX_FRONTIER_DEPTH=42`(테마×6).
- **옵션 모델**(`v2Equipment.ts`/`v2EquipmentCatalog.ts`): 9키(crit/eva/spd/critMult/hp/mp/def/
  magicDef/healPowerPct) 전부 **flat 패시브**. 어떤 옵션이 붙냐는 **카탈로그에 고정**(슬롯 시그니처).
  `rollItemStats`는 **값만** 굴림(±65% VARIANCE)·옵션 종류는 안 굴림. **발동형/조건부 옵션 0개**.
- **드랍 테이블**(`dungeonUniqueDrops.ts`): 밴드별 common pool(9종) + unique pool(2–4종·0.1%).
  유니크는 "변칙 스탯 사이드그레이드"(예: 분쇄 발톱장갑 = 장갑에 crit+critMult)지만 **정체성=이름/설명뿐**,
  코드 레벨 특수효과 없음. 세트 보너스(`V2EquipSet`)는 존재.

## 1. 게이트 — 잊힌 성소(depth 25)부터

고유 드랍 테이블은 **depth 25+ 3개 밴드**에서만 활성: 잊힌성소(25–30)·리자드늪지(31–36)·
짐승의소굴(37–42). 초반(들판~심층동굴 1–24)은 현행 유지 = 온보딩 단순·희소성 보존. 새 테마가
추가되면 자동으로 끝 밴드까지 확장(테마 데이터에 고유 풀만 채우면 됨).

## 2. 고유 아이템 = 정체성 (유니크 재정의)

- **새 등급 신설 안 함 — `common | unique` 그대로 재사용, 의미만 재배치**(오너 결정 2026-06-26):
  - **기존 유니크(굴림 사이드그레이드)는 특별하지 않음 → `common`(일반)으로 강등.** 더는 방송 안 함.
  - **이번 고유 아이템들이 `unique`(유니크)** = "유니크 = 정말 특별한 것"으로 의미 회복.
  - 유니크의 **바이올렛 배너 + `unique_drop` 전광판 방송은 기존 인프라 그대로** — 강등 후 신규 특별템에만 발동.
  - ⚠️ 보스/협동 드랍 유니크(예: 산왕의 쌍도끼)는 "획득=보스 처치"라 특별 → **유니크 유지**(필드 굴림 유니크만 강등). 오너가 보스 것도 일반 원하면 같이 강등.
- 밴드 테마에 맞춘 **명사 아이템**(이름+설명+개성 옵션). 예:
  - 잊힌 성소 → 봉인/성물 계열("잊힌 사제의 ○○")
  - 리자드 늪지 → 맹독/늪 계열("늪지 독왕의 ○○")
  - 짐승의 소굴 → 야수/포식 계열("알파 포식자의 ○○")
- 밴드당 **4–5종**(슬롯 분산)·기본값(조정 가능). 세트는 선택(필요 시 고유 세트 보너스).

## 3. 개성 옵션 — 단계적

### Phase 1 — 변칙 스탯 조합 (전투엔진 무수정·빠름)
슬롯 시그니처를 **깨는** 조합으로 "이 슬롯에서 이게 왜 나와?"를 만든다. 일반템보다 옵션 **수↑**
(2–3개)·의외 조합. 예시 방향:
- 신발에 치명피해(critMult) + 회복(healPowerPct) → "치고 빠지며 자가회복하는 신발"
- 장갑에 회피(eva) + 추가 마방(magicDef) → "받아내는 주먹"
- 목걸이에 속도(spd) + 치명(crit) → 보조 슬롯이 공격축으로
- 반지에 hp + def → 글래스캐넌 슬롯이 탱킹으로
무신메커닉(기존 9키 재배치)·VARIANCE 자동 적용·밸런스 안전. **베타 1차 출시분.**

### Phase 2 — 발동형 시그니처 효과 (신메커니즘)
고유 아이템에 **아이템당 1줄 "시그니처 효과"**(조건부/발동형) 부여 = 진짜 개성. 데이터 주도 소수
아키타입으로 시작(전부 다이얼):
- **on-kill**: 처치 시 N초/N행동 속도↑(또는 버프 스택)
- **low-hp**: 체력 X% 이하일 때 치명↑ / 받피감
- **on-crit**: 크리 시 회복 / 추가타 확률
- **every-N-hits**: N타마다 추가타 / 소규모 광역
- **개편(`V2Equipment.signature?: SignatureEffect`)** + 전투엔진(ATB·damage apply) 평가 훅.
  🔑 시그니처 없는 기존 장비는 훅 미발화 → **골든 byte-identical**. PvP 미러 필수. 보수적 시작.

## 4. 드랍 테이블 (서버 데이터)

- 기존 common/unique pool과 **별개**의 `SIGNATURE_UNIQUE_POOLS`(밴드별 ids).
- **드랍률**: 밴드 유니크(0.1%)보다 희귀 — 시작 **0.05%**(1/2000·다이얼). 레어맵 유니크 배수 적용.
- **중복 억제**: 미보유 우선(정체성 수집감) → 전부 보유 시 중복 허용(고굴림 재획득). `ownedSet` 활용.
- **롤 함수** `rollSignatureUniqueDrop(depth, ownedSet, rng, mult)` — hunt 라우트 드랍부에 추가.
- 인스턴스화는 기존과 동일(`genEquipIid`+`rollItemStats`)·signature 효과 필드는 카탈로그 고정.

## 5. 득템 연출 연계 (별도지만 시너지)

고유 아이템 = 득템 연출의 완벽한 payload. 최소한 **고유템 드랍 시 전용 배너+전광판 방송**(기존
`unique_drop` 피드 확장 또는 `signature_drop` 신설). 등급 사다리/품질 잭팟 연출(앞선 제안)과 함께
가면 "고유템 떴다!"가 사건이 된다. — 연출 패스는 분리 트랙(여기선 최소 방송만 포함).

## 6. 밸런스 다이얼 (한 줄 상수)

| 상수 | 시작값 | 의미 |
|---|---|---|
| 고유 드랍률 | 0.0005 (0.05%) | 밴드당·레어맵 배수 적용 |
| 밴드당 고유 종수 | 4–5 | 정체성 수집 폭 |
| 게이트 깊이 | 25 (잊힌 성소) | 이 깊이부터 풀 활성 |
| 시그니처 효과 강도 | 보수적 | Phase 2·아키타입별 다이얼 |

## 7. PR 슬라이스 / 롤아웃

- **PR-1 (Phase 1)** — (a) 기존 필드 유니크 → `common` 강등(방송 제외) (b) 신규 15종 고유 아이템
  카탈로그(변칙 조합·rarity unique) (c) 밴드 25–42 유니크 풀 교체 + 드랍률 0.05% (d) 세트 3개
  (e) hunt 배선(기존 유니크 배너·방송 재사용) + 테스트. **전투엔진 무수정·골든 불변.** 베타 1차.
- **PR-2 (Phase 2)** — `SignatureEffect` 타입 + 전투엔진 발동 훅 + 아키타입 3–4종 + PvP 미러 +
  골든 재확인(시그니처 없는 장비 불변) + sim 밸런스. 베타 직후 가능.
- **(병행 트랙)** 득템 연출 패스(등급 사다리·품질 잭팟·드랍 리빌) — §5. 별도 PR.

## 8. 결정 사항 (오너 확정 2026-06-26)

1. ✅ **유니크 재정의(신등급 없음)** — 기존 굴림 유니크 → `common` 강등, 신규 고유템이 `unique`.
   유니크 바이올렛 배너 + `unique_drop` 방송 인프라 그대로 재사용. 보스 유니크는 유지(필드만 강등).
2. ✅ **세트형 + 단품형 혼합**(다양성) — 일부 고유템은 세트 시너지, 일부는 단품 정체성.
3. ⬜ Phase 2 시그니처 **아키타입 최종 목록** — 구현 직전 확정.
4. ⬜ 드랍률/종수 최종 캘리브 — 라이브 데이터 후 조정(전부 다이얼).

## 9. Phase 1 로스터 (초안·이름/조합 조정 가능)

밴드별 5종(슬롯 분산)·테마 정체성·슬롯 시그니처 깨는 변칙 조합. **굵게**=세트(2피스), 나머지=단품.
Phase 2 시그니처 효과(괄호)는 *컨셉*(later).

이름 = 테마에 맞춘 적당한 판타지 명(과하지 않게). 성소=성물 / 늪지=독왕 / 소굴=포식자.

### 잊힌 성소(25–30) — 봉인/성물(회복·버팀 정체성)
| 아이템 | 슬롯/컨셉 | 변칙 옵션 | 비고 |
|---|---|---|---|
| **잊힌 사제의 성갑** | armor/heavy | hp+healPowerPct+magicDef | **성물 세트** (회복형 탱) |
| **잊힌 사제의 묵주** | necklace/mana | healPowerPct+hp+mp | **성물 세트** *(처치 시 회복)* |
| 성소의 첨탑검 | weapon/int | critMult+healPowerPct | 마딜+회복 |
| 사제의 경갑화 | boots/light | healPowerPct+spd | 신발에 회복(변칙) |
| 봉인된 반지 | ring/luck | hp+def+eva | 행운슬롯→생존(변칙) |
> 성물 세트 2pc: healPowerPct+magicDef

### 리자드 늪지(31–36) — 맹독/늪(회피·기동 정체성)
| 아이템 | 슬롯/컨셉 | 변칙 옵션 | 비고 |
|---|---|---|---|
| **맹독 손아귀** | gloves/light | crit+spd+eva | **독왕 세트** (공격+기동) |
| **늪지 미끄럼화** | boots/light | eva+spd+magicDef | **독왕 세트** *(회피 시 속도↑)* |
| 늪지 독왕의 비늘갑 | armor/light | eva+hp+def | 회피탱 경갑(변칙) |
| 독니 단검 | weapon/dex | crit+spd | 빠른 치명 |
| 독왕의 송곳니 목걸이 | necklace | crit+critMult | 보조슬롯→공격(변칙) |
> 독왕 세트 2pc: eva+crit

### 짐승의 소굴(37–42) — 야수/포식(폭딜·글래스캐넌 정체성)
| 아이템 | 슬롯/컨셉 | 변칙 옵션 | 비고 |
|---|---|---|---|
| **알파 포식자의 대검** | weapon/str | crit+critMult | **포식자 세트** *(처치 시 공속↑ 스택)* |
| **야수가죽 흉갑** | armor/heavy | hp+crit+spd | **포식자 세트** (공격적 중갑·변칙) |
| 포식자의 발톱장갑 | gloves | crit+critMult+spd | 극공격 장갑 |
| 사냥꾼의 추적화 | boots | spd+crit | 속도+치명(변칙) |
| 알파의 군림목걸이 | necklace | crit+critMult+spd | 보조슬롯 풀공격(변칙) |
> 포식자 세트 2pc: critMult+hp

= 15종 / 세트 3개(각 2pc) / 단품 9개. 밴드마다 정체성이 다름(회복형/회피형/폭딜형).
