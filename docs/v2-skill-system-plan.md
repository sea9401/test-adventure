# v2 스킬 시스템 전면 재설계 — 마스터 플랜

4직군(전사·무도가·마법사·도적)에 **공용 스킬 5종/직군 + 계파 스킬 3종/계파**를 신설한다.
구 원소 스킬 풀(직군당 1종×7속성)은 이 공용 스킬로 대체한다. 계파 패시브(시그니처)·직업특성은
**그대로 유지**하고, 그 위에 액티브 스킬 레이어를 얹는다.

- 공용 20 + 계파 36 = **액티브 56종** + 패시브성 2종(마력구·예기)
- 스킬칸: **3~4칸** (가진 스킬 중 골라 장착)
- 획득: 기존 숙련도 학습 경로 재사용
- 속성: 스킬에 속성 미부여 → 시전 시 **플레이어가 고른 캐릭터 속성** 자동 적용 (무기 속성 폐지와 일관)

## 1. 핵심 메커니즘

### 1-1. 플랫강화 데미지 (flat-heavy)
데미지 = `스탯 × 계수 + 큰 고정값(flat)`. 계수는 ~1.0 위주로 낮추고 flat을 키운다.
- **이유**: 순수 고정값은 후반에 死스킬(평타가 추월). 순수 계수는 off-스탯/저렙이 약함.
  계수 1.0(평타 STR×0.15의 ~6배)이면 끝까지 유효하면서, 큰 flat이 저렙·off-스탯 floor를 보장.
- **예측 쉬움 + off-스탯도 floor 확보** = 사용자 의도.
- 큰 스킬은 계수를 키우지 말고 **flat을 키운다**(계수 일관 ~1.0).

### 1-2. 차수 성장 (계파 스킬 전용)
- **해금**: 2차 = 계파 스킬 1개, 3차 = 2개, 4차 = 3개 (전직마다 1개 해금). 패시브 픽과 동일 구조.
- **강화**: flat이 차수로 성장 (계수는 불변). 예) 대참격 flat 2차 200 / 3차 280 / 4차 360.
- 공용 스킬은 1차부터·차수 무관(스탯으로만 성장).

### 1-3. 발동 확률 (procChance) — 평타가 척추, 스킬은 가끔의 한 방
엔진 메커닉(이미 존재, `combatShared.ts` resolveV2SkillCast):
- 스킬 `procChance` < 100 이면 자동시전 때 롤 → **실패 시 미발동(평타 폴백)**.
- **처리 순서: ① procChance 롤 → ② (성공) MP 소모 → ③ 회피 판정**
  - **발동 실패** = 평타 폴백, **MP·쿨다운 무소모**.
  - **발동 성공 후 적 회피**(빗나감) = 스킬 나갔으니 **MP 소모** + 데미지만 0. (PvE 몹 회피 0이라 주로 PvP.)
- proc 가 낮아 대부분 평타 → **평타가 전투의 척추**, 스킬은 보너스 한 방. (마법사는 마력구로 평타가 마법탄.)
- proc 는 **밸런스 레버**: 센 스킬일수록 낮춰 실효딜 자동 하향.
- 범위: 최저 ~10%, 최고 ~60%.

기본 티어 (역할별):
| 역할 | procChance |
|---|--:|
| 대형 버스트/궁극 | 15% |
| 중형 단일/힐딜 | 30% |
| 다단/저코스트 | 40% |
| payoff(스택·execute) | 20% |
| 버프/디버프/유틸 | 55% |

**계파별 조정** = §4 (성능 sim 반영). **워메이지**는 주문연사 패시브로 +15%p 가산.

### 1-4. MP 철학
- 물리: maxMP ~100, **재생 없음** → 한 전투 = 100 MP. proc 성공 시만 소모 → 사실상 **3~4번 파워무브** + 평타.
- 마법사: maxMP ~600(INT 비례) + (워메이지)마력순환. **마력구로 평타가 마법탄**이라 매턴 캐스팅 강제 해소 →
  물리와 같은 결(평타 + 스킬 proc). 600 MP라 오래 감.
- MP = INT × 2 + 50 (+장비). 물리도 INT 투자로 MP 늘려 스킬 위주 빌드 가능(딜 트레이드).

### 1-5. 신규 메커닉 목록 (구현 필요)
1. **마력구** (마법사 패시브) — 평타 데미지 = magicAtk 기반(INT 비례). 평타가 마법 공격.
2. **예기** (도적 패시브) — `atk += DEX × 0.08` (도적 한정). 죽은 축 DEX 부활(평타 강화).
3. **procChance 정비** — 기본 100 → 스킬별 티어값. 발동/MP/회피 순서 보장. 워메이지 +15 배선.
4. **차수 flat 스케일** — 계파 스킬 flat 2/3/4차 + 해금 1/차수.
5. **방어비례딜** (방패 가격) — 스킬 데미지가 DEF 스케일.
6. **HP소모딜** (사혈격) — 현재 HP 10% 소모, **소모한 HP만큼 추가딜(1:1)**. 자살 방지(현 HP < 비용이면 시전 불가).
7. **힐→딜** (신성 강타) — 자힐 후 **힐량의 100%를 적에게 데미지**.
8. **execute** (처단) — 적 HP 30% 이하 시 대폭딜.
9. **스택 비례 payoff** (참절·중독 폭발·비전 작렬) — 적 출혈/독/마법취약 스택 수에 비례 추가딜.
10. **물리 취약** (속박 사격) — 적 받는 피해 +%(아크메이지 마법취약과 동류).
11. **마력구/예기 = 무료 직군 패시브** (슬롯 안 씀).

> 스턴/행동불가는 **금지**(사장 룰: 과함). 디버프는 DoT·스탯감소·취약·확률조정 방향.
