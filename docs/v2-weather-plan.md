# v2 날씨 시스템 계획 — 속성의 두 번째 축 (2026-06-13)

> 상태: 📐 설계. 사용자 발제 — "속성이 약점 찌르기 말고는 체감이 없다. 지역별로 날씨가
> 주기적으로 바뀌고, 속성마다 특정 날씨에 보너스/페널티를 받게 하자(물=비 오는 날 강함)."

## 1. 목표와 철학

- **속성에 환경 축 추가** — 지금 속성은 "상대(몹)와의 상성" 단일 축. 날씨는 "세계와의
  궁합"이라는 두 번째 축 — 같은 빌드라도 오늘 어디서 사냥하느냐가 달라진다.
- **거점 이동 메타 부활** — 사냥터가 단일 무한 프론티어가 된 뒤 거점 선택은 세금/정책
  외엔 무의미해짐. 권역마다 날씨가 다르면 "내 속성이 강해지는 권역으로 원정"이 생기고,
  거점 점령 가치에도 환경 변수가 붙는다(비 오는 주의 물속성 인구 이동).
- **운영 무부담** — DB 0·cron 0. 날씨는 (권역, 시간 창)의 **결정론적 순수 함수** —
  서버·클라가 같은 답을 계산한다. 라이브 부하·동기화 문제 원천 차단.
- **옵트인 보정** — 약점 찌르기와 같은 철학. 보너스는 달콤하게, 페널티는 가볍게.
  무속성은 무영향(변동성 0 의 안전빵 — 속성 선택의 트레이드오프가 또 하나 생긴다).

## 2. 권역 (날씨 단위)

**6권역** = 5왕국 + 중앙 분쟁지대.
- 거점 → 권역 매핑은 기존 로직 재사용: 지리적 최근 수도(#624 거점 마커 왕국색) +
  중앙 자유도시 2홉 이내 = 분쟁지대(#625). 새 데이터 불필요 — 헬퍼로 파생.
- 사냥은 hunt 라우트가 outpostId 를 이미 받으므로, 그 거점의 권역 날씨를 조회.
  outpostId 없는 사냥(이론상)·아레나·허수아비는 날씨 무관(중립).

## 3. 날씨 카탈로그 (7종 × 속성 효과 매트릭스)

강도 사다리(폐기) 대신 **한 날씨가 여러 속성에 단계적으로 영향** — 사용자 결정
(2026-06-13): "맑음이면 불·빛은 보너스, 바람은 디버프, 물은 소폭 디버프" 식. 날씨
종류는 7개로 묶어 헷갈리지 않게, 효과는 4단계로 다층적이게.

**효과 4단계**: ◎ 대강세 +15% · ○ 강세 +7% · △ 약세 −7% · ▼ 대약세 −15% (⚠️ 다이얼)

| 날씨 | ◎ 대강세 | ○ 강세 | △ 약세 | ▼ 대약세 |
|---|---|---|---|---|
| ☀️ 맑음 | 빛 | 불 | 물 | 어둠 |
| 🌧 비 | 물 | 어둠 | 빛 | 불 |
| ⛈ 뇌우 | 번개 | 물 | 땅 | 빛 |
| 💨 강풍 | 바람 | 번개 | 불 | 땅 |
| 🌪 황사 | 땅 | 바람 | 번개 | 물 |
| 🌫 안개 | 어둠 | 땅 | 바람 | 번개 |
| 🔥 폭염 | 불 | 빛 | 어둠 | 바람 |

**완전 균형 설계** — 7날씨 × 4칸 = 28 = 7속성 × 4단계. 모든 속성이 정확히:
대강세 1 · 강세 1 · 약세 1 · 대약세 1 + 중립 3 날씨를 가진다. 날씨 가중치를
**균등(각 1/7)**으로 두면 모든 속성의 기대 보정이 0 — 속성 간 장기 밸런스 자동 보장.
(맑음을 더 흔하게 하고 싶으면 빛/불이 평균적으로 이득을 보므로 비균등 가중은
밸런스 결정과 함께 — v1 은 균등.)

테마 읽기: 비=물◎·먹구름(어둠○)·해 가림(빛△)·불이 꺼짐(불▼) / 안개=어둠◎·무풍(바람△)
/ 폭염=열돔 무풍(바람▼)·긴 낮(어둠△) / 황사=건조(물▼) / 강풍=대지가 흩날림(땅▼).

- 무속성: 모든 날씨에서 ×1.0 (변동성 0 안전빵 — 속성 선택 트레이드오프).
- (후속) 권역별 가중 편향 — 북부는 비↑·서남 광산은 폭염↑ 같은 지역 개성(편향을 주면
  균형이 깨지므로 밸런스 검토와 함께).

## 4. 시간 모델 — 결정론적 창

```
windowIndex = floor(now / WEATHER_WINDOW_MS)        // 창 길이 4시간 (하루 6창)
seed        = hash(`${regionKey}:${windowIndex}`)    // 문자열 해시 (xmur3 등 32bit)
weather     = uniformPick(WEATHERS, seed)            // 7종 균등 (가중은 다이얼)
```

- **WEATHER_WINDOW_MS = 4h** (다이얼). 짧으면 체감 산만, 길면 하루종일 페널티 박힘.
- **예보 공짜**: windowIndex+1, +2 를 미리 계산 → "3시간 뒤 비" UI. 계획 세우는 재미.
- 경계 스냅샷: 전투 시작 시점(`now`) 기준. 일괄 50판 중 창이 바뀌면 판마다 자연 반영
  (runOneHunt 가 판마다 now 재계산 — 기존 구조 그대로).
- 연속 동일 날씨 방지 같은 보정은 안 한다(독립 추첨) — 단순함 우선, 맑음 30%라
  병적 연속은 드묾.

## 5. 효과 모델

- **적용 대상: PvE 사냥만** (1차). 내 **공격 속성**(무기 속성 ?? 캐릭 속성 — 기존
  basicAttackElement 그대로)의 그 날씨 단계(◎○△▼)에 따라 atk·magicAtk 에
  ±7/±15% — §3 매트릭스.
- **적용 지점**: hunt 라우트의 약점 찌르기 배율과 같은 곳 —
  `atk = atk × elemMult × weatherMult` (곱연산). 최대 결합 1.25×1.15 ≈ +44%
  (대강세 + 약점 찌르기).
  엔진 무수정 — 라우트에서 baked(약점 찌르기와 동일 패턴, 스킬은 combatShared 재정규화
  경로도 동일 배율 전달 필요 여부 확인 — 1차는 평타·스킬 공통 baked 로 충분).
- **제외**: 아레나/PvP(운빨 변수 차단·메타 불변), 허수아비, 협동 보스(전 서버 공용
  토벌이라 권역 개념 없음 — 후속 검토: "보스 소환 시점의 날씨 고정" 같은 변형).
- **몬스터 쪽 무보정**: 약점 찌르기처럼 공격 전용 철학 유지 — 몹이 날씨로 세지는
  페널티는 없음(비대칭·옵트인).
- 무속성: 항상 ×1.0.

## 6. UI / 가시성

1. **사냥터 화면** — 헤더에 날씨 배지(아이콘+이름) + 내 속성의 단계 강조 + 전체
   효과 4칸 요약(◎물 ○어둠 △빛 ▼불).
   내 공격 속성이 강세면 배지 강조(약점 찌르기 "약점!" 강조와 같은 결).
2. **결과 카드** — 날씨 보정 적용 시 강도 명칭으로 표기("🌧 폭우 — 물속성 대강세!").
3. **지도** — 권역마다 날씨 아이콘(거점 마커 위 또는 권역 라벨 옆) + 예보 툴팁.
4. **거점 화면** — 현재 날씨 + "N시간 뒤 ○○" 예보 1칸.
5. (후속) 전체 소식/전광판은 노이즈라 제외 — 날씨는 상시 정보지 사건이 아님.

## 7. 후속 아이디어 (1차 제외)

- 낚시: 비 오는 날 입질 간격 단축(소소한 플레이버).
- 발굴: 맑은 날 단서 1회 보너스.
- 권역 가중 편향(§3)·계절(주 단위 메타 사이클).
- 몹 풀 미세 변화(비 오는 날 물속성 몹 출현률↑) — 도감 헌터에게 의미.
